# Abatacept：從類風濕性關節炎到類風濕性血管炎

## 一句話總結

Abatacept 是一種 CTLA4-Ig 融合蛋白，原本用於類風濕性關節炎、幼年特發性關節炎及脊椎關節病變。
TxGNN 模型預測它可能對**類風濕性血管炎 (Rheumatoid Vasculitis)** 有效，但目前僅有個案報告層級的文獻，且證據方向不一致，沒有針對此適應症的對照試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Abatacept 是 CTLA4-Ig 融合蛋白，可阻斷 CD28-CD80/86 的 T 細胞共刺激訊號，從而抑制 T 細胞活化。

類風濕性血管炎是類風濕性關節炎的嚴重關節外併發症，與 T 細胞驅動的免疫發炎有關。因此在機轉上，共刺激阻斷理論上可能緩解此類血管炎。

然而文獻訊號並不一致。一份個案報告顯示 abatacept 讓難治性類風濕性血管炎快速改善；另一份報告卻指出患者在 abatacept 治療期間新發類風濕性血管炎，後來改用 rituximab 才好轉。目前沒有任何對照數據。

## 安全性考量

- **藥物交互作用**：資料庫共記載 73 筆交互作用。主要需注意的重度（Major）交互作用包括：
  - Adalimumab
  - Baricitinib
  - Certolizumab pegol
  - BCG 活疫苗（Tice 株）
  
  中度交互作用包括其他免疫抑制或生物製劑（如 anakinra、canakinumab、alemtuzumab、azathioprine）及多種活性疫苗。與鋅製劑的交互作用為輕度。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此適應症僅有個案報告，且結果互相矛盾（有改善也有新發血管炎），沒有任何對照研究。TxGNN 分數雖高，但不足以支持推進。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症
- 補充詳細的作用機轉資料
- 系統性蒐集 abatacept 治療類風濕性血管炎的病例系列或登錄資料，釐清療效與風險
- 設計小型前瞻性研究，與標準治療（如 rituximab）比較

---

**附註：其他預測適應症**

- **多關節型幼年類風濕性關節炎**：證據等級 L1，有多項已完成的 Phase 3 試驗（如 NCT00095173、NCT01844518），但屬於已核准的適應症範圍，嚴格來說不算再利用。
- **發炎性脊椎病變**：主要證據來自 Phase 3 乾癬性關節炎試驗 NCT01860976，不能推論到整個類別；軸性疾病證據薄弱，文獻指出 abatacept 對強直性脊椎炎無效。
- **其餘預測**（尾骨過度活動、Kummell 病、短指並指症候群等）：僅有模型預測，缺乏合理的生物學依據。
