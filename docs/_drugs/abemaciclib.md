# Abemaciclib：從乳癌到類風濕性關節炎

## 一句話總結

Abemaciclib（商品名 Verzenio）是 CDK4/6 抑制劑，臨床試驗資料顯示其核准用途為荷爾蒙受體陽性、HER2 陰性的乳癌。
TxGNN 模型預測它可能對**類風濕性關節炎 (Rheumatoid Arthritis)** 有效。
目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Abemaciclib 屬於 CDK4/6 抑制劑，用於抑制細胞週期進展，在乳癌中的療效已有 Phase 3 試驗（MONARCH 2）佐證。

類風濕性關節炎的特徵之一，是滑膜纖維母細胞與活化淋巴球過度增生。從機轉推測，阻斷 CDK4/6 可能抑制這些細胞增殖，因此預測有其生物學上的想像空間。

不過這只是假說。資料集中沒有任何試驗或文獻支持，機轉也未經驗證。原適應症（腫瘤）與類風濕性關節炎在疾病本質上差異很大，目前無法判斷兩者的關聯性。

## 結論與下一步

**決策：Hold**

**理由：**
類風濕性關節炎這項預測分數雖高（97.32%），但沒有任何臨床試驗或文獻佐證，屬於 L5 等級。原始機轉資料也缺乏，且目前無法確認與原適應症的關聯。

**若要推進需要：**
- 補齊 Abemaciclib 的作用機轉資料（DrugBank）
- 取得香港衛生署仿單，確認警語與禁忌症
- 進行類風濕性關節炎的前臨床研究（如滑膜纖維母細胞或發炎模型中 CDK4/6 抑制的效果）
- 評估長期用藥的安全性，特別是 QTc、血栓與腎功能

**補充：同一藥物其他預測項目的證據較多，但也僅到 L4，且都不建議直接推進。**
