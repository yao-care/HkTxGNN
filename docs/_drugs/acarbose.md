# Acarbose：從第二型糖尿病相關用途到局限性僵硬肢體症候群

## 一句話總結

Acarbose 是腸道 α-葡萄糖苷酶抑制劑，用於降低餐後血糖（本 Evidence Pack 未載明原適應症）。
TxGNN 模型預測它可能對**局限性僵硬肢體症候群 (Focal Stiff Limb Syndrome)** 有效，
但目前**無任何臨床試驗與文獻**支持此預測，僅為模型預測（L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Acarbose 是 α-葡萄糖苷酶抑制劑，藉由延緩腸道碳水化合物吸收來降低餐後血糖。

僵硬肢體症候群屬脊髓與腦幹抑制性迴路異常的神經疾病，Acarbose 對這些迴路沒有已知作用，**機轉上並無直接關聯**。模型分數偏高，可能來自於僵人症候群譜系常合併自體免疫性糖尿病，屬於知識圖譜上的間接關聯，而非藥理上的支持。

因此這個預測應視為假說，不宜視為有療效根據。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測適應症皆無臨床試驗，首位預測也無文獻，證據等級僅為 L5。
- 機轉上沒有可信的關聯，高分很可能來自知識圖譜中糖尿病相關節點的鄰近性。

**若要推進需要：**
- 取得 Acarbose 的作用機轉與原適應症資料（DrugBank）
- 取得香港衛生署仿單，補齊警語與禁忌症，才能進行安全性篩選
- 若仍有興趣，先以文獻回顧確認僵人症候群譜系與糖尿病共病的關聯，並評估是否有任何直接的機轉假說
- 優先評估與血糖相關的預測（如硫胺素反應性功能障礙症候群合併糖尿病）是否有臨床意義
