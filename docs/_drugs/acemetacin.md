# Acemetacin：從（原適應症未載明）到骨關節炎易感性

## 一句話總結

Acemetacin 是一種非類固醇消炎藥（NSAID），為 indomethacin 的前驅藥。
TxGNN 模型預測它可能對**骨關節炎易感性 (Osteoarthritis Susceptibility)** 有效，
但目前**沒有臨床試驗和文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（original_moa 為資料缺口）。以下說明來自一般藥理知識，並非來自本次提供的資料：Acemetacin 是 indomethacin 的乙醇酸酯前驅藥，屬 NSAID，透過抑制 COX-1 與 COX-2 減少前列腺素合成，進而緩解疼痛與發炎。這在機轉上與症狀性骨關節炎（疼痛、發炎）相符。

不過有兩點需要留意。第一，「骨關節炎易感性」是一個與遺傳傾向相關的疾病節點，並非一般的臨床病況，模型的高分可能反映的是知識圖譜中與骨關節炎相關基因或藥物的鄰近關係，而不代表有可治療的適應症。第二，Acemetacin 在部分市場據稱已用於骨關節炎疼痛，因此這可能是既有標示用途，而非真正的老藥新用，需對照各國法規標示查證。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有模型預測（證據等級 L5），沒有任何臨床試驗或文獻佐證。預測標的「骨關節炎易感性」又是遺傳傾向節點，不是可直接治療的臨床病況，且原適應症與安全性資料都有缺口，尚無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症、核准適應症），確認是否已有骨關節炎相關標示
- 從 DrugBank 補齊作用機轉（MOA）與原適應症資料
- 將預測標的改對應到臨床上可治療的疾病（如骨關節炎症狀治療），再檢索臨床試驗與文獻
- 查證 Acemetacin 在其他市場的骨關節炎標示，判斷是否屬於真正的老藥新用
