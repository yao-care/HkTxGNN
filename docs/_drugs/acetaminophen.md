# Acetaminophen：從頭痛／偏頭痛到伴腦幹先兆的偏頭痛

## 一句話總結

Acetaminophen（對乙醯氨基酚，即 paracetamol）原本用於緩解頭痛、偏頭痛、感冒與鼻炎相關症狀。
TxGNN 模型預測它可能對**伴腦幹先兆的偏頭痛 (Migraine with Brainstem Aura)** 有效，
但目前**沒有相關臨床試驗**，僅有 **19 篇文獻**提供間接背景，且沒有任何一篇專門針對腦幹先兆。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Acetaminophen 已被用於急性偏頭痛與頭痛的處理，其在一般偏頭痛中的角色已有文獻描述。伴腦幹先兆的偏頭痛是偏頭痛的亞型，因此機轉上可能適用。

一般認為其鎮痛作用可能與中樞 COX 抑制，以及血清素與內源性大麻素路徑的調節有關。但這是推論而非已證實的結論。

TxGNN 的高分（0.99）較可能反映它與既有偏頭痛適應症在知識圖譜中相近，而不是亞型專屬的證據。目前提供的資料中，沒有試驗或論文專門探討腦幹先兆。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：肝衰竭、肝病、膽囊疾病、肝硬化、肝性腦病變、肝昏迷。這些來自藥物與疾病的關聯資料，並非仿單文字。
- **藥物交互作用**：資料庫共記錄 100 筆，以下為前 20 筆的摘要。
  - 中度：活性碳 (Activated charcoal)、glycerol phenylbutyrate、naltrexone
  - 輕微：atropine、cimetidine、clidinium、dicyclomine、glycopyrronium、hyoscyamine、liraglutide、metoclopramide、ranitidine、scopolamine 等抗膽鹼或腸胃道用藥
  - 等級未明：維生素 A、calcitriol

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold（列為研究問題）**

**理由：**
- Acetaminophen 在一般偏頭痛中已有使用，且香港已廣泛上市，但沒有任何臨床試驗或文獻專門針對伴腦幹先兆的偏頭痛。
- 證據等級僅 L4，高預測分數主要反映與既有偏頭痛適應症的相近性，機轉也只是推論。

**若要推進需要：**
- 取得並確認作用機轉（MOA）資料，檢驗與腦幹先兆病理機轉的關聯。
- 取得香港衛生署仿單中的警語與禁忌資料，完成安全性篩選。
- 檢視現有偏頭痛試驗中伴先兆（尤其腦幹先兆）亞群的結果。
- 若有需要，設計針對該亞型的觀察性研究或小型臨床試驗。
