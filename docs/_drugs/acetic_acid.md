# 醋酸（Acetic Acid）：從外耳炎到體癬（Tinea Corporis）

## 一句話總結

醋酸是一種外用抗菌劑，原本用於外耳炎與外耳疾病。
TxGNN 模型的預測排名第一為**細菌感染後疾患 (post-bacterial disorder)**，但該預測完全沒有實證支持，且機轉上缺乏合理性。
在所有預測中，證據相對最多的是**體癬 (Tinea Corporis)**：有 **0 個臨床試驗**、**10 篇文獻**（多為年代久遠的報告或體外研究）。因此本報告以體癬作為主要討論對象，並說明排名第一預測的限制。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，醋酸是外用抗菌劑，可酸化局部環境，抑制 Pseudomonas 等細菌生長。這解釋了它用於外耳炎的原因。

**排名第一的「細菌感染後疾患」**屬於感染後的非感染性後遺症，外用抗菌劑的酸化作用無法解釋其療效，機轉連結不成立。排名第 2 至第 7 的預測（感染後血管炎、感染後症候群、恰加斯心肌病變、感染性尿道狹窄、感染相關溶血性尿毒症候群、藥物引起的骨質疏鬆）同樣沒有臨床試驗或直接文獻，且機轉上也不合理。

**體癬**則有較合理的機轉：酸性環境可抑制皮癬菌生長，與醋酸在外耳炎中的抗菌作用概念相近。支持證據包括：
- 1946–1958 年間關於頭癬與足癬使用稀釋醋酸（常與碘合用）的歷史報告
- 體外甲癬模型與有機酸抑制皮癬菌的實驗室研究

這些證據多屬間接、年代久遠、無對照或受合併治療干擾，且沒有現代對照研究針對體癬。

## 安全性考量

- **知識圖譜中的禁忌疾病**（來自知識圖譜關聯，非仿單內容）：遺傳性紫質症、紫質代謝疾病、紫質症、單純疱疹感染、膝狀神經節帶狀疱疹。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 排名第一的預測（細菌感染後疾患）及其他多數預測僅有模型分數，無臨床試驗或直接文獻，機轉上亦不合理，不建議推進。
- 體癬雖有合理的局部抗真菌機轉，但證據僅為歷史報告與體外研究，無現代對照研究，也無試驗登記，因此維持證據等級 L4，可作為研究問題而非開發決策。

**若要推進需要：**
- 取得醋酸的作用機轉資料（如 DrugBank）
- 取得香港許可證的仿單，確認警語、禁忌與核准適應症
- 針對體癬設計體外 MIC 試驗，測試不同濃度醋酸對皮癬菌的抑制效果，並與標準抗真菌藥比較
- 若體外結果良好，再設計小規模、有對照的外用濃度與皮膚刺激性研究
- 確認適用的外用劑型與安全濃度範圍，評估燒傷與皮膚刺激風險
