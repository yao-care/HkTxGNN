# Acetylsalicylic acid（阿斯匹靈）：從心肌梗塞與關節炎到偏頭痛（伴腦幹先兆）

## 一句話總結

阿斯匹靈（acetylsalicylic acid）是常用的抗血小板與解熱鎮痛藥，原本用於心肌梗塞、冠狀動脈血栓、類風濕性關節炎、偏頭痛及頭痛等。
TxGNN 模型預測它可能對**伴腦幹先兆的偏頭痛 (Migraine with brainstem aura)** 有效，
目前**沒有相關臨床試驗**，但有 **20 篇文獻**提供間接支持（多為一般偏頭痛或有先兆偏頭痛，並非針對此亞型）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原廠資料中未收錄）。根據已知資訊，阿斯匹靈透過抑制環氧合酶（COX）、減少前列腺素介導的神經源性發炎，並抑制血小板凝集，已被用於偏頭痛的急性治療，部分指引也將其列為預防選項。

原適應症中本來就包含偏頭痛與頭痛，因此預測的新適應症與既有用途高度相關，只是亞型更特定。一項回溯性研究顯示低劑量阿斯匹靈可能有助於預防有先兆偏頭痛；另一項較早的研究指出，阿斯匹靈能活化頭痛患者的抗傷害性腦幹反射活動，與腦幹先兆的病理可能有關。

需要注意的是，**沒有任何證據專門針對腦幹先兆亞型**，目前的支持是從一般有先兆偏頭痛推論而來。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.94%），但沒有針對腦幹先兆亞型的臨床試驗，現有證據來自一般偏頭痛或有先兆偏頭痛的間接推論，屬於 L3 層級。阿斯匹靈本身已有偏頭痛相關用途，因此較適合作為「研究問題」而非立即推進的新適應症。

**若要推進需要：**
- 針對腦幹先兆（或有先兆）偏頭痛的前瞻性對照試驗，驗證低劑量阿斯匹靈的預防效果
- 補充詳細的作用機轉資料（MOA）
- 取得香港衛生署核准仿單，確認適應症、警語與禁忌症
- 評估出血風險與用藥交互作用的監測計畫
