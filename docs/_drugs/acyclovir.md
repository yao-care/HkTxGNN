## Acyclovir：核苷類抗病毒藥物 → 點狀上皮角膜結膜炎 (punctate epithelial keratoconjunctivitis)
{: .text-alpha }

## 一句話總結

Acyclovir 是一種核苷類抗病毒藥物，在香港已有多張許可證。
TxGNN 模型預測它可能對**點狀上皮角膜結膜炎 (punctate epithelial keratoconjunctivitis)** 有效，
但目前**沒有臨床試驗**，僅有 2 篇與此疾病並不直接相關的文獻，證據相當薄弱。

## 為什麼這個預測合理？

Acyclovir 被病毒的胸苷激酶活化後，會抑制皰疹病毒的 DNA 聚合酶。目前缺乏詳細的作用機轉資料庫記錄，以上為一般藥理知識。

點狀上皮角膜炎可由單純皰疹病毒 (HSV) 或水痘帶狀皰疹病毒 (VZV) 引起，因此在抗病毒機轉上有合理的連結。

不過，目前取得的 2 篇文獻分別探討微孢子蟲角膜結膜炎與愛滋病患者的角膜脂質沉積，這兩者都不是 acyclovir 有效的疾病。因此這個預測目前僅是模型推論，尚無臨床證據支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測只有模型分數支持，沒有直接研究此疾病的臨床試驗或文獻，證據等級為 L5。
- 雖然抗病毒機轉上有合理性（HSV/VZV 所致者），但取得的文獻與 acyclovir 療效無關。

**若要推進需要：**
- 搜尋 acyclovir 用於 HSV/VZV 相關點狀上皮角膜炎的臨床研究
- 釐清此疾病的病因分型，確認哪些亞型適用抗皰疹病毒藥物
- 取得詳細作用機轉資料與眼用劑型（如眼用凝膠或軟膏）的可行性評估
- 取得原廠仿單的警語與禁忌症資料，完成安全性審查
