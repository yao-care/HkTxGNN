# Adalimumab：從克隆氏症與類風濕性關節炎到類風濕性血管炎

## 一句話總結

Adalimumab 是一種抗 TNF-α 單株抗體，原本用於克隆氏症、類風濕性關節炎、乾癬性關節炎、僵直性脊椎炎、潰瘍性結腸炎、幼年特發性關節炎、化膿性汗腺炎及非感染性葡萄膜炎等自體免疫疾病。
TxGNN 模型預測排名第一的新適應症為**類風濕性血管炎 (Rheumatoid Vasculitis)**，但目前僅有 **1 個不相關的臨床試驗**和以病例報告為主的文獻，證據薄弱。
排名第 3 與第 5 的預測（發炎性脊椎病變、多關節型幼年類風濕性關節炎）證據較強，但多與既有適應症重疊，並非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Adalimumab 是中和 TNF-α 的全人源單株抗體。TNF-α 是類風濕性關節炎及其血管發炎的核心細胞激素，因此機轉上可能適用於類風濕性血管炎。

類風濕性血管炎是類風濕性關節炎的嚴重關節外併發症，與原適應症病理機轉相近。不過現有證據僅限於個案：一例類風濕性關節炎合併指端血管炎對 adalimumab 反應良好；另一例類風濕性血管炎患者減量 adalimumab 後，發生急性肺高壓危象。

另一方面，抗 TNF 藥物本身也有誘發血管炎與自體免疫現象的報告，例如 adalimumab 相關抗磷脂症候群、類風濕性關節炎治療中出現 ANCA 相關腎炎、白血球破裂性血管炎等。因此利弊尚不明確，需要更嚴謹的研究。

其他預測中，「尾骨過度活動」與「Kummell 病」僅有模型預測，沒有試驗或文獻，也缺乏抗 TNF 的機轉依據。「脊椎疾病」範圍太廣，支持證據間接來自脊椎關節炎的適應症。

## 結論與下一步

**決策：Hold**

**理由：**
- 首選預測（類風濕性血管炎）僅有個案報告，唯一的臨床試驗與療效無關，且抗 TNF 藥物本身可能誘發血管炎，利弊尚不明確。
- 發炎性脊椎病變（L1）與多關節型幼年類風濕性關節炎（L1）有多項 Phase 3 試驗支持，可考慮以「Proceed with Guardrails」處理，但多與既有適應症重疊，並非真正的藥物再利用。

**若要推進需要：**
- 針對類風濕性血管炎的前瞻性研究或病例系列，評估療效與誘發血管炎的風險
- 補齊作用機轉資料與香港仿單的警語及禁忌症
- 若採用於脊椎關節炎或幼年關節炎，需有防護措施：結核與 B 型肝炎篩檢、感染風險監測、葡萄膜炎監測、兒童依體重給藥
- 將「脊椎疾病」等廣泛預測縮小為具體的發炎性疾病後再評估
- 對於僅有模型預測的「尾骨過度活動」與「Kummell 病」，缺乏機轉依據，不建議投入資源
