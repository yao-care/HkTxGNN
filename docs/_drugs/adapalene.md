# Adapalene：從痤瘡（推定）到血漿鋅升高

## 一句話總結

Adapalene 是一種外用類視黃醇（retinoid），香港許可證資料未記載核准適應症（一般用於痤瘡，但此點不在提供的資料內）。
TxGNN 模型預測它可能對**血漿鋅升高 (zinc, elevated plasma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Adapalene 屬於外用類視黃醇，一般認為作用於視黃酸受體（RAR-beta/gamma），但此資訊並非來自本次資料包中的 DrugBank 欄位，僅供參考。

視黃醇類可能經由維生素 A 與鋅的交互作用、視黃醇結合蛋白合成等途徑間接影響鋅代謝，但這只是推測，並無直接的機轉證據。此外，血漿鋅升高是一項實驗室檢驗結果，而非可直接治療的疾病；外用 adapalene 的全身暴露量也很低。

因此，0.995 的高分很可能是知識圖譜的統計假象，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
只有模型預測（L5），沒有臨床試驗與文獻，機轉關聯薄弱。血漿鋅升高是檢驗數值而非明確的治療目標，外用劑型的全身暴露又低，目前不宜推進。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症與安全性資訊
- 補齊 DrugBank 的作用機轉資料
- 釐清「血漿鋅升高」是否為可治療的臨床目標
- 評估外用劑型的全身暴露量是否足以影響鋅代謝
- 文獻檢索是否有視黃醇類與鋅代謝的相關研究

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後方能應用。*
