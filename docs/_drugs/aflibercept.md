# Aflibercept：從大腸癌轉移與視網膜疾病到斜視（Esotropia）

## 一句話總結

Aflibercept 是一種 VEGF 誘餌受體（VEGF trap），原本用於轉移性大腸癌、黃斑部病變、視網膜動脈阻塞及糖尿病黃斑部水腫。
TxGNN 模型預測它可能對**內斜視 (Esotropia)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Aflibercept 是 VEGF-A、VEGF-B 與 PlGF 的誘餌受體，透過抑制血管新生與血管通透性，在眼底新生血管疾病及大腸癌中發揮作用。

然而，內斜視是眼位排列異常，成因主要是神經肌肉或屈光因素，與 VEGF 驅動的血管病變沒有明顯的直接關聯。0.994 的高分僅是模型的圖譜推論，**機轉上並不合理**，很可能是知識圖譜中「眼科用藥」關聯所造成的假象。

同一份資料中，其他排名靠前的預測（如食道靜脈曲張、尿道結石、腺苷脫胺酶缺乏症等）同樣缺乏證據，多數機轉上不合理，說明高分不等於高可信度。

## 細胞毒性

Aflibercept 為抗 VEGF 之生物製劑（標靶藥物），並非傳統細胞毒性藥物，其在大腸癌的用途（ZALTRAP）屬抗腫瘤治療。

## 安全性考量

- **藥物交互作用**：資料庫共記錄 78 筆交互作用，以下為部分重要項目：
  - **嚴重 (Major)**：Deferiprone、Samarium (153Sm) lexidronam、Adalimumab、Baricitinib、Certolizumab pegol、Cladribine、Clozapine
  - **中度 (Moderate)**：Strontium chloride Sr-89、Roflumilast、Chloramphenicol、Zidovudine、Alefacept、Alemtuzumab、Anakinra、Azathioprine、Canakinumab 及部分疫苗（破傷風類毒素、炭疽、霍亂活疫苗）
- **類別效應風險**：根據預測分析，VEGF 抑制劑有出血與消化道穿孔的已知風險，在出血性疾病情境下尤需謹慎。

主要警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 內斜視的預測僅來自模型分數，沒有任何臨床試驗或文獻，且機轉上缺乏合理關聯，證據等級為 L5。
- 現有安全性與作用機轉資料也不完整，無法進入安全性篩選階段。

**若要推進需要：**
- 補充香港衛生署仿單中的警語與禁忌症
- 取得 DrugBank 的詳細作用機轉資料
- 提出內斜視與 VEGF 通路之間可信的生物學假說，並進行前臨床驗證
- 建議優先評估其他有機轉基礎的候選適應症（例如其他 VEGF 驅動的腫瘤或眼底血管疾病），而非內斜視
