# Aflibercept：從眼科血管新生疾病到食道靜脈曲張（預測）

## 一句話總結

Aflibercept 是一種 VEGF 誘捕蛋白（VEGF-A/VEGF-B/PlGF trap），在香港以 EYLEA（玻璃體內注射）與 ZALTRAP（靜脈輸注）上市。
TxGNN 模型預測分數最高的新適應症是**斜視 (Esotropia)**，但這些預測**均無臨床試驗或文獻直接支持**，僅為模型推論。
唯一連結到的一項試驗，研究的是眼部疾病而非預測適應症，不構成有效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫未收錄 MOA）。根據已知資訊，Aflibercept 是 VEGF-A、VEGF-B 與胎盤生長因子（PlGF）的誘捕蛋白，透過抑制血管新生與血管通透性發揮作用。

就斜視而言，它屬於神經肌肉或屈光問題，目前沒有已知機轉能把 VEGF 阻斷和眼位不正連結起來。0.994 的高分只反映知識圖譜的關聯，很可能是圖譜假象（artifact），並非真實的藥理訊號。

在其他排名靠前的預測中，只有少數具備間接的機轉合理性：

- **食道靜脈曲張（有／無出血）**：VEGF 驅動的血管新生與門脈高壓的側枝循環形成有關，動物模型有一定合理性。但全身性抑制 VEGF 會增加出血風險，對已出血的患者尤其是安全疑慮。
- **神經內分泌腫瘤（如中耳）、外胚間葉瘤等罕見腫瘤**：抗血管新生療法對實體瘤有一般性的理論基礎，但沒有針對這些腫瘤的 VEGF 依賴性資料。
- **尿道結石、腺苷去胺酶缺乏症、新生兒出血症**：找不到合理的機轉連結。

## 臨床試驗證據

## 安全性考量

安全性資訊請參考原廠仿單。

另請注意：本藥在預測適應症的情境下，全身性抑制 VEGF 帶有出血風險，這對食道靜脈曲張、新生兒出血症等出血相關疾病是重大疑慮。

## 結論與下一步

**決策：Hold**

**理由：**
- 十項預測皆為 L5（僅有模型預測），沒有任何直接的臨床試驗或文獻支持。
- 首位預測（斜視）缺乏機轉依據，應視為知識圖譜假象；出血相關預測則有明確的安全疑慮。

**若要推進需要：**
- 補齊香港衛生署仿單的警語、禁忌與核准適應症（目前為阻礙性資料缺口）
- 補充 Aflibercept 的作用機轉資料（可查詢 DrugBank）
- 若要優先探索，可先針對機轉相對合理的方向（如食道靜脈曲張的 VEGF 側枝血管新生、神經內分泌腫瘤）做文獻與前臨床回顧，並評估全身出血風險
- 確認給藥途徑相容性（EYLEA 為玻璃體內注射，全身性適應症未必適用）
