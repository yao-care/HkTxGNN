# Agomelatine：從憂鬱症到嬰兒良性陣發性斜頸

## 一句話總結

Agomelatine 是一種抗憂鬱藥，原本用於單極性憂鬱症、重度憂鬱症與焦慮症。
TxGNN 模型預測它可能對**嬰兒良性陣發性斜頸 (Benign Paroxysmal Torticollis of Infancy)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，agomelatine 是褪黑激素 MT1/MT2 受體促效劑，同時為血清素 5-HT2C 受體拮抗劑，可調節晝夜節律，已在憂鬱症與焦慮症中使用。

然而，嬰兒良性陣發性斜頸是一種好發於嬰幼兒、與偏頭痛譜系及離子通道相關的疾病。現有資料中找不到它與 agomelatine 作用機轉之間的合理連結。這個高分更可能是知識圖譜運算的結果，而非真實的藥理訊號。

值得一提的是，同一份預測清單中的其他項目（如焦慮相關的懼曠症、憂鬱症亞型的憂鬱性精神病、輕度憂鬱、低落性情感障礙）與原適應症高度重疊，生物學上較合理，但多屬既有適應症的延伸，並非真正的再利用機會。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有臨床試驗與文獻佐證，機轉上也缺乏合理連結，證據等級為 L5。
- 此外，原廠仿單的警語與禁忌症資料尚未取得，無法進行安全性篩選。

**若要推進需要：**
- 取得完整的作用機轉資料，確認與該疾病病理機轉（偏頭痛譜系、離子通道）是否有關聯
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症
- 進行系統性文獻檢索與前臨床研究，確認是否有任何支持訊號
- 若要尋找實際可推進的方向，建議改評估與既有適應症相鄰、已有間接文獻的候選（如輕度慢性憂鬱的低落性情感障礙），並進一步確認 agomelatine 是否納入相關研究
