# Alanine：從（原適應症未載明）到胃輕癱

## 一句話總結

Alanine（丙胺酸）是一種非必需胺基酸，多用於複方胺基酸輸液，但資料中未載明明確的原適應症。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，
但目前沒有任何直接針對 alanine 的臨床試驗或文獻支持，**證據僅停留在模型預測階段**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，alanine 是複方胺基酸輸液的成分之一，
主要作為營養與蛋白質合成的原料，其在胃輕癱的角色尚無研究證實。

理論上，膳食胺基酸可經腸道內分泌的營養感受機制（例如刺激 CCK 與 GLP-1 釋放）影響胃排空，
所以在機轉上並非完全不可能。但目前沒有證據顯示補充 alanine 能改善胃蠕動或胃輕癱症狀。

TxGNN 的高分較可能來自知識圖譜中，代謝與糖尿病相關節點的網路鄰近性，而非已驗證的作用機轉。
因此這個預測目前屬於推測性質。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測，沒有任何以 alanine 為介入的臨床試驗或研究，證據等級為 L5。
- 作用機轉與原適應症資料缺漏，無法驗證預測的合理性，安全性資料也不足以進入篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症
- 從 DrugBank 補充作用機轉資料，釐清 alanine 與胃排空的可能機轉
- 搜尋 alanine 或胺基酸營養介入對胃排空、胃輕癱影響的前臨床與臨床研究
- 評估給藥途徑是否相容（現有製劑為輸液，胃輕癱通常需口服或腸道給藥）
