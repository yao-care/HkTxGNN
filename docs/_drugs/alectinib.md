## Alectinib：ALK/RET 酪胺酸激酶抑制劑 → 牙齦纖維瘤病 (fibromatosis, gingival)
{: .text-alpha }

## 一句話總結

Alectinib 是一種 ALK/RET 酪胺酸激酶抑制劑。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (fibromatosis, gingival)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬於模型運算的預測結果。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Alectinib 屬於 ALK/RET 抑制劑，主要透過阻斷 ALK 驅動的訊號傳遞來抑制腫瘤生長。

然而，遺傳性牙齦纖維瘤病並未有已知的 ALK 驅動病理機制，也沒有資料顯示 RET 或 ALK 抑制與該疾病相關。因此，這項預測目前找不到可靠的機轉依據，僅能視為高分的運算結果，需要進一步的基礎研究來驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有任何臨床試驗或文獻直接研究牙齦纖維瘤病，且缺乏合理的作用機轉，證據等級僅為 L5。
- 此疾病為良性、非 ALK 驅動的病變，而 Alectinib 屬於抗腫瘤標靶藥物，風險效益尚無法評估。

**若要推進需要：**
- 釐清牙齦纖維瘤病中是否存在 ALK 或 RET 相關的致病機轉（基礎與前臨床研究）
- 取得 Alectinib 完整的作用機轉資料
- 取得香港仿單的警語與禁忌症，完成安全性評估
- 在有機轉依據之前，不建議投入臨床試驗設計
