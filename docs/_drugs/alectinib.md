# Alectinib：從 ALK 陽性非小細胞肺癌到牙齦纖維瘤病

## 一句話總結

Alectinib 是一種 ALK 抑制劑，原本用於 ALK 陽性非小細胞肺癌（NSCLC）。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向。這是純模型預測，機轉上也找不到合理連結，較可能是知識圖譜的假象。

TxGNN 分數已趨近飽和（本次前 10 名預測皆約 99.95%–99.97%），無法用來區分預測的優劣，不宜單獨作為判斷依據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Alectinib 是選擇性 ALK（間變性淋巴瘤激酶）抑制劑，其在 ALK 融合陽性肺癌的療效已有多項 Phase 3 試驗證實（如 ALEX、J-ALEX、ALESIA）。

牙齦纖維瘤病是牙齦組織的纖維增生，與 ALK 或 RET 驅動的腫瘤生物學沒有已知關聯。分析認為這個預測很可能是知識圖譜的計算假象，而非真實的藥理連結。

因此，機轉上並沒有支持 Alectinib 適用於牙齦纖維瘤病的依據。若要成立，至少需要先有研究顯示該疾病存在 ALK 相關的病理機轉。

## 安全性考量

香港衛生署仿單的警語與禁忌症目前尚未取得，DrugBank 查無藥物交互作用資料。正式安全性資訊請參考原廠仿單。

本次檢索到的文獻另有 Alectinib 相關不良事件的個案報告或回溯分析（非本適應症的證據，僅供參考）：
- **代謝毒性**：高三酸甘油脂血症引發胰臟炎
- **皮膚反應**：DRESS 症候群、多形性紅斑
- **體重增加**：回溯分析指出約 10% 患者出現
- **心臟電生理**：Phase 2 試驗以密集心電圖評估 QTc 與心搏過緩

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有臨床試驗或文獻支持，機轉上也無合理連結，證據等級僅為 L5，預測分數又已飽和而無鑑別力。
- 安全性資料有缺口（香港仿單為阻斷性缺口，無法進入安全性篩選）。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症（目前的阻斷性資料缺口）。
- 補齊 DrugBank 的作用機轉資料。
- 找出牙齦纖維瘤病與 ALK 通路相關的病理或基因證據；若找不到，建議終止此方向。
- 同一批預測中有更值得追蹤的項目：
  - 「肺良性腫瘤」的文獻其實是 ALK 陽性 NSCLC 的既有適應症證據，建議重新對應到 NSCLC。
  - 「肺生殖細胞瘤」有個案報告與 DETERMINE 稀有腫瘤 Phase 2/3 試驗（NCT05770037），可列為研究性問題。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
