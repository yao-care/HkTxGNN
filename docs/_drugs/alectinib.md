# Alectinib：從非小細胞肺癌到牙齦纖維瘤病

## 一句話總結

Alectinib 是一種 ALK 抑制劑，原本用於治療非小細胞肺癌（ALK 陽性）。
TxGNN 模型預測它可能對**遺傳性牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型運算結果。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Alectinib 是 ALK（間變性淋巴瘤激酶）／RET 抑制劑，在 ALK 陽性非小細胞肺癌中的療效已有大型第三期試驗證實。

不過，遺傳性牙齦纖維瘤病並無已知的 ALK 驅動病理機轉，原適應症（惡性肺癌）與這個良性纖維增生疾病之間也找不到明確的生物學關聯。預測分數雖然很高（99.97%），但整體排名僅為第 1143 名，且沒有任何實證支持，應視為純計算預測，需要進一步的機轉研究才能判斷合理性。

## 安全性考量

- **藥物交互作用**：共查得 92 筆交互作用，以下為部分範例：
  - 嚴重（Major）：Aminolevulinic acid
  - 中度（Moderate）：Dolasetron、Naltrexone、Mefloquine、Quinine、Atazanavir、Bedaquiline、Atenolol、Bisoprolol、Acebutolol、Betaxolol 等
- **文獻中的已知不良反應（個案報告）**：高三酸甘油脂血症引發的胰臟炎、溶血性貧血、DRESS 症候群、多形性紅斑、體重明顯增加。這些皮膚不良反應也需在考慮皮膚黏膜相關疾病時留意。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有臨床試驗與文獻佐證，也沒有合理的 ALK/RET 機轉連結，證據等級為 L5。
- 此為罕見遺傳性疾病，與 Alectinib 的作用靶點無關，且 Alectinib 可能引起皮膚不良反應，風險效益尚無依據。

**若要推進需要：**
- 釐清牙齦纖維瘤病與 ALK/RET 訊號路徑是否存在關聯（機轉與前臨床研究）
- 補齊 Alectinib 的作用機轉資料與香港仿單的警語、禁忌症資料
- 在有任何機轉或前臨床證據之前，不建議投入臨床開發資源
