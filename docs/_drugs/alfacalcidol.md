## Alfacalcidol：活性維生素 D 類似物 → 顱面錐體發育不良 (craniofacial conodysplasia)
{: .text-alpha }

## 一句話總結

Alfacalcidol 是活性維生素 D 類似物（1-alpha-hydroxycholecalciferol），作用於鈣磷恆定與骨礦化。
TxGNN 模型預測它可能對**顱面錐體發育不良 (craniofacial conodysplasia)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Alfacalcidol 是活性維生素 D 類似物，可繞過腎臟 1-alpha 羟化步驟，直接參與鈣、磷代謝與骨礦化調節。

顱面錐體發育不良屬於骨骼發育異常。從骨骼與礦物質代謝的角度，兩者之間存在概念上的關聯，但目前沒有任何文件記載的機轉或數據能支持 alfacalcidol 對此疾病有效。

因此，這個預測的高分應視為模型推論的假說，不能視為療效證據。
