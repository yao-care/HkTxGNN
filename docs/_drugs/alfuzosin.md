# Alfuzosin：從良性前列腺增生到 Ambras 型全身性多毛症

## 一句話總結

Alfuzosin 是 α1 腎上腺素受體拮抗劑，原本用於治療良性前列腺增生 (BPH)。
TxGNN 模型預測它可能對 **Ambras 型先天性全身性多毛症 (Ambras type hypertrichosis universalis congenita)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Alfuzosin 屬於 α1 腎上腺素受體拮抗劑，對前列腺的 α1A 受體具有較高選擇性，其在良性前列腺增生中的療效已被證實。

然而，Ambras 症候群是罕見的先天性疾病，與影響 TRPS1 調控的基因組重排有關，這條路徑與 α1 阻斷並無關聯。目前**無法建立合理的機轉連結**。

高預測分數僅反映知識圖譜上的關聯，並無臨床或文獻佐證。其他排名靠前的預測（如一般多毛症、遺傳性毛幹異常、低毛症等）同樣沒有證據，且多為先天性或遺傳性疾病，α1 阻斷劑預期不會改變其病理。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來源為知識圖譜，非仿單內容）：多系統萎縮、姿勢性直立心搏過速症候群、姿勢性低血壓、長 QT 症候群（含家族性）、尖端扭轉型心室頻脈、肝衰竭、肝病、膽囊疾病、低血壓疾患、術中虹膜鬆弛症候群 (IFIS)。
- **藥物交互作用**：共查得 100 筆，以下為主要項目：
  - **嚴重 (Major)**：Cisapride、Clarithromycin、Dolasetron
  - **中度 (Moderate)**：Famotidine、Aprepitant、Bupropion、Canagliflozin、Dapagliflozin、Empagliflozin、Granisetron、Levofloxacin 等
  - **輕微 (Minor)**：Cimetidine

  多項嚴重交互作用與 QT 延長風險相關，與上述長 QT 禁忌相呼應。

詳細警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測新適應症沒有任何臨床試驗或文獻，證據等級僅 L5，且缺乏 α1 阻斷與 Ambras 症候群之間的機轉連結。
- 此疾病為先天性遺傳疾病，成人 BPH 藥物預期無法改變其病理，且藥物有低血壓與 QT 相關安全顧慮。

**若要推進需要：**
- 取得詳細的作用機轉（MOA）資料，並評估是否存在任何生物學連結
- 取得香港衛生署核准的仿單，確認警語與禁忌症
- 進行前臨床或機轉研究，作為提升證據等級的起點
- 若仍要探索，建議重新評估其他預測適應症，並優先選擇機轉上較合理者
