# Alirocumab：從血脂異常與動脈粥狀硬化到 X 染色體連鎖魚鱗癬

## 一句話總結

Alirocumab 是一種 PCSK9 中和抗體，原本用於血脂異常與動脈粥狀硬化相關疾病。
TxGNN 模型預測它可能對 **X 染色體連鎖魚鱗癬（無類固醇硫酸酯酶缺乏型）** 有效，但目前**沒有任何臨床試驗與文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，Alirocumab 是 PCSK9 中和抗體，透過抑制 PCSK9 來增加 LDL 受體（LDLR）的回收，進而降低血中 LDL-C。

X 染色體連鎖魚鱗癬與膽固醇硫酸鹽的蓄積有關，因此在膽固醇代謝上存在鬆散的概念性關聯。然而，Alirocumab 的作用在於降低循環中的 LDL-C，目前沒有證據顯示它能直接作用於皮膚屏障疾病的致病機轉。

整體而言，此預測屬於模型推論，機轉上的支持相當薄弱，需要更多基礎研究才能判斷是否合理。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自模型（證據等級 L5），沒有臨床試驗或文獻佐證，機轉上也缺乏直接連結。
- 預測的疾病為皮膚屏障疾病，與 PCSK9 抑制的作用路徑差異大。

**若要推進需要：**
- 取得詳細的作用機轉資料，並評估 PCSK9 抑制與膽固醇硫酸鹽代謝的關聯
- 進行基礎或前臨床研究（如細胞或動物模型），驗證對魚鱗癬皮膚表現的影響
- 取得香港仿單的警語與禁忌症資料，完成安全性篩選
- 若要找尋較有機會的方向，可另行評估同組預測中證據較多的項目（如黃色瘤，目前有個案報告層級的間接證據），但這些與原適應症高度重疊，並非嚴格意義上的新適應症
