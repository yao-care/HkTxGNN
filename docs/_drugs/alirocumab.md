# Alirocumab：從高膽固醇血症到 X 連鎖魚鱗癬（無類固醇硫酸酯酶缺乏）

## 一句話總結

Alirocumab 是 PCSK9 單株抗體，原本用於降低 LDL 膽固醇（高膽固醇血症）。
TxGNN 模型預測它可能對**X 連鎖魚鱗癬（無類固醇硫酸酯酶缺乏）**有效，
但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。已知 Alirocumab 是 PCSK9 單株抗體，
透過結合循環中的 PCSK9，保留肝臟 LDL 受體，進而降低血中 LDL 膽固醇。

就這個新適應症而言，PCSK9 抑制與 X 連鎖魚鱗癬之間**沒有已確立的關聯**。
高分來自知識圖譜的關聯推論。理論上，膽固醇硫酸或脂質代謝可能是連結點，但這只是推測，尚未經任何研究驗證。

因此這個預測目前只能視為假說。沒有試驗或文獻能支持它，也無法判斷機轉上是否適用。

## 結論與下一步

**決策：Hold**

**理由：**
這個預測只有模型分數，沒有任何臨床試驗或文獻佐證（L5），機轉上也找不到合理連結。現階段不建議投入資源。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症，才能進入安全性初篩
- 補充 DrugBank 的作用機轉資料，以便分析機轉連結
- 驗證 PCSK9 或膽固醇代謝與 X 連鎖魚鱗癬之間是否有生物學關聯，例如膽固醇硫酸路徑
- 若有興趣，可優先檢視同一份預測清單中證據較多的候選：
  - 黃色瘤 (xanthomatosis)：機轉上屬於間接關聯，需先確認是否來自 LDL 下降的效果，目前僅有案例報告
  - 膽固醇分解代謝疾病：與原適應症高度重疊，可能屬於既有適應症，不算真正的老藥新用
