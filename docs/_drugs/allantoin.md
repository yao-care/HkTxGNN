# Allantoin：從皮膚保護劑到嚴重非增殖性糖尿病視網膜病變（預測，證據薄弱）

## 一句話總結

Allantoin（尿囊素）是外用皮膚保護與修護成分，常見於軟膏、凝膠與眼藥水等製劑。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效，
但目前**沒有任何臨床試驗與文獻**支持，屬於純模型預測，機轉上也找不到合理連結，可能是知識圖譜的假象。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Allantoin 是外用皮膚保護劑，具有角質溶解與促進上皮再生的作用，在皮膚保護與護理上被廣泛使用。

然而，外用製劑沒有已知途徑可到達視網膜，也與糖尿病微血管病變的病理無關。
0.996 的高分只反映知識圖譜中的關聯，**應視為圖譜假象，而非機轉上的合理預測**。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測的糖尿病視網膜病變沒有任何臨床試驗或文獻，機轉上也無合理連結，外用藥無法作用於視網膜，高分很可能是知識圖譜的假象。
- 8 個預測中，只有「痤瘡性瘢痕疙瘩」與「發疹」在機轉上稍有合理性，但證據仍很薄弱，僅能視為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與核准適應症
- 補充 Allantoin 的作用機轉資料（DrugBank）
- 若要繼續探索，建議優先評估皮膚相關的預測（如痤瘡性瘢痕疙瘩），而非視網膜病變
- 針對單一成分 Allantoin 設計對照試驗，因現有試驗皆為複方產品，無法歸因
