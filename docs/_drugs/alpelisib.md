# Alpelisib：從乳癌到肺動脈高壓

## 一句話總結

Alpelisib 是 PI3Kα 抑制劑，在香港以 PIQRAY 上市，檢索到的試驗背景為 PIK3CA 突變的荷爾蒙受體陽性乳癌。
TxGNN 模型預測它可能對**肺動脈高壓 (Pulmonary Hypertension)** 有效，但這只是圖譜模型的預測。
檢索到 **1 個臨床試驗**（與肺動脈高壓無關）和 **2 篇文獻**（皆不支持療效，反而提示肺部安全性疑慮）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供 MOA）。已知 Alpelisib 是 PI3Kα 選擇性抑制劑，PI3K/AKT 訊號路徑與肺血管重塑有關，因此在機轉上有一個推測性的前臨床理由。

不過，這個理由目前只停留在假設。檢索到的文獻沒有顯示 Alpelisib 對肺動脈高壓有療效。其中一篇是 Alpelisib 引起間質性肺病的個案報告，屬於肺部安全性訊號。另一篇動物研究顯示，PI3Kα 抑制合併 doxorubicin 會造成雙心室萎縮與右心室功能障礙，這對肺動脈高壓（右心負荷疾病）可能是負面訊號。

原適應症（乳癌）與肺動脈高壓在疾病性質上差異很大，兩者的關聯僅來自知識圖譜的間接推論。目前沒有肺動脈高壓專屬的臨床或前臨床療效資料。

## 安全性考量

安全性資訊請參考原廠仿單。

文獻另提示兩點：
- 已有 alpelisib 相關間質性肺病的個案報告，若用於肺部疾病族群需特別留意。
- 動物研究顯示 PI3Kα 抑制可能影響右心室功能，對肺動脈高壓病人可能是風險。

---

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測，沒有任何肺動脈高壓相關的療效證據，檢索到的唯一試驗與此適應症無關。
- 現有文獻偏向風險訊號（肺部不良反應、右心功能影響），機轉上也缺乏支持，不建議推進。
- 同批預測的其他適應症（偏頭痛、類風濕性關節炎、血栓性疾病、多發性內分泌腫瘤等）證據同樣為 L4–L5，也是 Hold。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症（目前為阻擋性資料缺口，無法進入安全性篩選）。
- 補齊 DrugBank 的作用機轉資料。
- 找出 PI3Kα 抑制在肺血管重塑的前臨床療效證據（細胞或動物模型）。
- 評估肺部與右心室安全性風險是否可接受。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。
