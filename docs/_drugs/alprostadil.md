# Alprostadil：從先天性心臟病導管依賴型循環到主動脈畸形

## 一句話總結

Alprostadil（前列腺素 E1，PGE1）在香港以 Prostin VR Pediatric 注射劑上市，臨床上用於維持新生兒動脈導管開放。
TxGNN 模型預測它可能對**主動脈畸形 (Aortic Malformation)** 有效，
目前有 **2 個臨床試驗**（皆為間接相關）和 **20 篇文獻**，證據以回溯性、觀察性研究為主。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻，Alprostadil (PGE1) 透過 EP 受體／cAMP 訊號路徑使動脈導管平滑肌鬆弛，讓導管維持開放。

在主動脈中斷（interrupted aortic arch）、重度主動脈瓣狹窄、主動脈閉鎖等「全身循環依賴導管」的病變中，導管開放可在手術前維持全身灌流。文獻指出，PGE1 在 1970 年代後期的引入，徹底改變了主動脈弓中斷的處置。

原適應症欄位為空白，推測是資料缺漏，因為此用法在臨床上早已確立。證據多為回溯性或觀察性研究，並非 Phase 3 RCT。

## 安全性考量

- **藥物交互作用**：資料庫查無交互作用資料。
- **文獻中的不良反應**：長期輸注可能引起肥厚性幽門狹窄（[25263728](https://pubmed.ncbi.nlm.nih.gov/25263728/)、[23521358](https://pubmed.ncbi.nlm.nih.gov/23521358/)），並有低劑量長期輸注後出現房室傳導阻滯的個案（[28508920](https://pubmed.ncbi.nlm.nih.gov/28508920/)）。

香港衛生署仿單的警語與禁忌症資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 在導管依賴型全身循環病變（主動脈弓中斷、重度主動脈狹窄、主動脈閉鎖）中，PGE1 是長期確立的術前橋接用藥，機轉合理，且已在香港上市。
- 但證據僅來自回溯性、觀察性研究與病例報告，缺乏 Phase 3 RCT，僅 1 個間接相關的 Phase 1 試驗（提前終止）。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症（目前為阻斷性資料缺口）
- 補齊作用機轉資料（DrugBank）
- 確認原適應症是否已涵蓋導管依賴型先天性心臟病，釐清此預測是「新用途」還是「既有用途」
- 建立長期輸注的監測計畫（呼吸暫停、幽門狹窄、傳導阻滯等）
