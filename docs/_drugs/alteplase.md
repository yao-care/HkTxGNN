# Alteplase：從纖維蛋白溶解療法到後側壁心肌梗塞

## 一句話總結

Alteplase 是重組組織型纖維蛋白溶解酵素原活化劑（rt-PA），屬於血栓溶解藥物。TxGNN 模型預測它可能對**後側壁心肌梗塞 (Posterolateral Myocardial Infarction)** 有效。目前**沒有臨床試驗**，只有 **3 篇文獻**（1 篇診斷性世代研究、2 篇個案報告或回顧），且都不是針對 alteplase 的直接療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，alteplase 是重組 tPA，可將纖維蛋白溶解酵素原轉換為纖維蛋白溶解酶（plasmin），溶解阻塞冠狀動脈的纖維蛋白血栓。

後側壁心肌梗塞是急性心肌梗塞的解剖亞型，成因同樣是冠狀動脈血栓性阻塞。因此在機轉上，alteplase 可直接作用於這類病灶。

但要注意，本次資料的「原適應症」欄位是空的，香港許可證也沒有登載適應症文字。因此無法從輸入資料確認「急性心肌梗塞」是否為香港的核准適應症，也沒有針對此亞型的 alteplase 專屬資料。這個預測較像是「既有用途下的亞型延伸」，而不是全新的機轉發現。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉上合理，且此病症是急性心肌梗塞的亞型，但沒有臨床試驗，文獻也沒有針對此亞型的 alteplase 療效資料。
- 香港仿單的警語與禁忌症尚未取得，安全性篩選無法進行。
- 溶栓治療的出血風險高，必須先補齊資料。

**若要推進需要：**
- 取得香港衛生署核准的仿單，確認適應症、警語與禁忌症。
- 確認 alteplase 在香港對急性心肌梗塞的核准狀態，判斷這是否屬於既有適應症的延伸。
- 補充 alteplase 用於後側壁或後壁心肌梗塞的專屬證據，例如亞群分析或 STEMI 溶栓試驗。
- 建立與原發性 PCI 的比較框架，並訂出治療時間窗與出血風險篩檢條件。
- 補充作用機轉資料（DrugBank）。
