# Ambroxol：從祛痰／黏液溶解到鼻腔疾病

## 一句話總結

Ambroxol 是一種祛痰藥（黏液溶解劑），作用於呼吸道黏液。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效。
目前**沒有臨床試驗**，只有 **1 篇間接相關的文獻**（急性咳嗽的綜述），證據很薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ambroxol 是作用於呼吸道黏液的祛痰／黏液溶解劑。
這類藥物在呼吸道疾病中的用途已相當確立，機轉上可能適用於上呼吸道相關疾病。

鼻腔屬於上呼吸道，黏液分泌與清除異常是許多鼻腔疾病的共通特徵，因此兩者在生物學上有合理的關聯。
不過這個關聯是依藥物類別推論的，並未被所提供的資料證實。

TxGNN 的高分主要反映知識圖譜中的關聯，不等於臨床療效。
唯一的支持文獻談的是急性咳嗽，不是鼻腔疾病本身，所以屬於間接證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗，唯一的文獻只是間接證據，機轉資料也缺乏。預測目前只能當作研究問題，不足以支持推進。
- 同一份預測清單中的其他四項（急性喉咽炎、外陰陰道念珠菌病、咽喉白喉、頸椎椎間盤退行性疾患）都沒有任何試驗或文獻，證據等級為 L5，同樣建議 Hold。
- 其中白喉與外陰陰道念珠菌病在機轉上缺乏合理路徑，很可能是圖譜的假關聯。

**若要推進需要：**
- 補齊 Ambroxol 的作用機轉資料（例如查詢 DrugBank）。
- 取得香港衛生署核准的仿單，確認警語、禁忌與核准適應症。
- 針對鼻腔疾病（如鼻炎、鼻竇炎）系統性檢索臨床試驗與 RCT，確認是否有直接證據。
- 確認具體的鼻腔疾病亞型與可用劑型／給藥途徑是否相容。
