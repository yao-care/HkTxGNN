# Aminocaproic Acid：從抗纖溶藥物到嚴重非增殖性糖尿病視網膜病變

## 一句話總結

Aminocaproic Acid（胺基己酸）是一種賴胺酸類似物，一般藥理上屬於抗纖維蛋白溶解藥物。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。從一般藥理知識來看，Aminocaproic Acid 是賴胺酸類似物，能抑制纖維蛋白溶酶原（plasminogen）的活化，進而抑制纖維蛋白溶解。

糖尿病視網膜病變涉及視網膜血管滲漏與玻璃體出血。理論上，纖溶或纖維蛋白溶酶（plasmin）相關路徑可能與這些變化有關，因此模型給出高分並非完全無跡可循。不過這只是推測，提供的資料中沒有任何直接證據支持。

另一方面，抗纖溶藥物有促血栓風險。糖尿病患者本身血管風險就偏高，可能包括視網膜血管阻塞。高 TxGNN 分數本身不等於療效或安全性的證據。

## 安全性考量

- **需留意的風險**：抗纖溶藥物可能增加血栓風險。糖尿病族群血管風險本就較高，需特別評估視網膜血管阻塞等問題。

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有 TxGNN 模型的高分預測，沒有臨床試驗、文獻或明確的作用機轉支持，證據等級為 L5。
- 促血栓風險與糖尿病族群的血管風險疊加，在安全性資料補齊前不宜推進。

**若要推進需要：**
- 取得香港衛生署的仿單資料（警語與禁忌症），完成安全性初篩
- 補齊 DrugBank 的作用機轉資料，分析與糖尿病視網膜病變的機轉關聯
- 系統性檢索 PubMed 與臨床試驗登記平台，確認是否有前臨床或臨床研究
- 釐清給藥途徑是否適用（目前香港產品為眼藥水，其相容性尚待評估）
- 評估對糖尿病患者的血栓與視網膜血管風險
