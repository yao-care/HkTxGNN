# Amlodipine：從高血壓到腦幹梗塞

## 一句話總結

Amlodipine 是二氫吡啶類鈣離子通道阻斷劑，臨床上主要用於降血壓。
TxGNN 模型預測它可能對**腦幹梗塞 (Brain Stem Infarction)** 有效。
目前**沒有臨床試驗和文獻**直接支持這個適應症，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Amlodipine 阻斷 L 型鈣離子通道，使血管舒張並降低血壓。降血壓可能降低血管性風險，因此在機轉上有可能與腦梗塞相關。

不過這只是理論上的推論。針對腦幹梗塞這個特定適應症，目前沒有任何臨床試驗或文獻佐證，TxGNN 的高分不能取代實際研究。

## 結論與下一步

**決策：Hold**

**理由：**
腦幹梗塞這個預測只有模型分數，沒有任何臨床試驗或文獻支持（L5）。此外，香港衛生署仿單的警語與禁忌資料尚未取得，無法進行安全性初篩。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與藥物交互作用資料
- 補齊 DrugBank 的作用機轉資料
- 針對腦幹梗塞檢索 Amlodipine 的臨床或前臨床研究
- 同一份資料中，**顱內出血 (Intracerebral Hemorrhage)** 的證據較完整（L1，建議 Proceed with Guardrails）。TRIDENT 是 Phase 3 RCT，測試含 Amlodipine 的低劑量三合一降血壓複方，用於預防出血性中風復發。該證據支持的是整個複方策略，不是 Amlodipine 單藥，建議優先評估這個方向。

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
