# Amorolfine：從抗真菌（甲癬）到藥物誘發性骨質疏鬆症

## 一句話總結

Amorolfine 是一種外用嗎啉類抗真菌藥，主要用於治療甲癬（灰指甲），透過抑制真菌麥角固醇合成發揮殺菌作用。
TxGNN 模型預測它可能對**藥物誘發性骨質疏鬆症 (drug-induced osteoporosis)** 有效，
然而目前**無任何臨床試驗**及**無任何文獻**支持此方向，屬純模型預測。

## 為什麼這個預測合理？

Amorolfine 屬嗎啉類（morpholine）抗真菌藥，其作用機轉為抑制真菌麥角固醇（ergosterol）生合成路徑中的兩個關鍵酶：**Δ14-reductase** 與 **Δ7-Δ8 isomerase**。因此，真菌細胞膜因固醇成分異常而失去完整性，導致真菌死亡。

與骨質疏鬆症的機轉連結屬於**極度推測性**：Δ14-reductase 在哺乳動物體內存在類似物（SC5D／lathosterol oxidase），理論上可能影響膽固醇代謝路徑，而膽固醇代謝確實對成骨細胞（osteoblast）功能有間接影響。然而，此推論橫跨多個缺乏直接證據的步驟，尚無任何人體骨代謝數據支持此假說。

此外，Amorolfine 目前劑型為**外用指甲油**，系統性生物利用度極低（<10%），即使機轉假說成立，現有劑型也無法達到骨組織所需的有效濃度。此預測最有可能為知識圖譜模型（KG model）在固醇代謝相關節點上產生的偽陽性訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有 10 個 TxGNN 預測適應症均無任何臨床試驗或文獻支持，全數落在最低證據等級 L5；
- 最高排名的「藥物誘發性骨質疏鬆症」之機轉連結屬極度推測性，且現有外用劑型的系統性暴露量不足以產生骨骼層面的藥效；
- 藥物在香港尚未上市，需先建立基礎監管資料才能推進任何再利用評估。

**若要推進需要：**
1. **補齊 MOA 資料（DG002）**：從 DrugBank API 取得完整作用機轉與 pharmacology 資訊，評估哺乳類 Δ14-reductase 同源物的相關性
2. **補齊安全性資料（DG001）**：取得香港衛生署或其他已上市地區（如歐盟 EMA、英國 MHRA）的仿單，確認警語與禁忌
3. **評估劑型可行性**：若要測試系統性效果，須先確認是否有或能否開發口服／注射劑型，並進行 PK/PD 前臨床評估
4. **前臨床概念驗證**：在骨代謝細胞模型（成骨細胞/破骨細胞體外試驗）中測試 Amorolfine 的實際效果，以決定是否升級評估層級
