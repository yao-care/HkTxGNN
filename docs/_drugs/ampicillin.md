# Ampicillin：從細菌感染到喉炎

## 一句話總結

Ampicillin 是一種 β-內醯胺類抗生素，原本用於泌尿道感染、中耳炎、細菌性肺炎、細菌性腦膜炎等多種細菌感染。
TxGNN 模型預測它可能對**喉炎 (Laryngitis)** 有效，但目前**沒有臨床試驗**，僅有 **20 篇文獻**，且多為個案報告、回顧或微生物調查，缺乏直接療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ampicillin 屬於 β-內醯胺類抗生素，透過抑制細菌細胞壁合成而殺菌。其在多種細菌感染中的療效已被證實，機轉上可能適用於細菌引起的喉部感染，例如由 B 型流感嗜血桿菌 (*Haemophilus influenzae*) 引起的會厭炎。

不過，目前的文獻多為會厭炎、喉膿瘍等個案報告或回顧，並非直接針對 Ampicillin 治療喉炎的研究。此外，許多流感嗜血桿菌菌株已會產生 β-內醯胺酶，使經驗性用藥受限。喉炎多數為病毒性，抗生素並非常規治療。TxGNN 的高分應視為模型訊號，尚未獲得臨床證據支持。

## 安全性考量

- **知識圖譜標示的相關疾病（禁忌／需謹慎）**：腎臟疾病、腎功能不全、血液疾病、消化性潰瘍、困難梭狀芽孢桿菌結腸炎、傳染性單核球增多症、慢性 EB 病毒感染症候群、急性尿酸性腎病變等。這些來自知識圖譜，並非仿單內容。
- **藥物交互作用**：共查得 61 筆。中度交互作用包括 Doxycycline、Minocycline、Tetracycline（四環素類）、Kanamycin、Balsalazide、Lansoprazole、Dexlansoprazole、Picosulfuric acid；輕度包括 Clarithromycin。

其他警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有臨床試驗，文獻僅為個案報告、回顧與微生物調查，無直接療效證據（證據等級 L4）。
- 喉炎多為病毒性，細菌性會厭炎又面臨 β-內醯胺酶抗藥問題，且 Ampicillin 本身已屬於廣泛的抗菌適應症，並非真正的新用途。

**若要推進需要：**
- 針對細菌性喉部感染（如會厭炎）的 Ampicillin 對照試驗或高品質觀察性研究。
- 當地流感嗜血桿菌的抗藥性監測資料。
- 取得香港原廠仿單，確認核准適應症、警語與禁忌。
- 補充詳細的作用機轉資料。
