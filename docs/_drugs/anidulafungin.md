# Anidulafungin：從食道念珠菌症與念珠菌血症到膿痂疹（預測）

## 一句話總結

Anidulafungin 是一種棘球白素（echinocandin）類抗黴菌藥，原本用於治療食道念珠菌症與念珠菌血症。
TxGNN 模型預測它可能對**膿痂疹 (Impetigo)** 有效，但目前**沒有任何臨床試驗或相關文獻**支持，僅是模型預測，機轉上也缺乏合理性。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Anidulafungin 屬於棘球白素類抗黴菌藥，一般認為其作用是抑制真菌細胞壁的 β-(1,3)-D-葡聚醣合成酶，已用於治療念珠菌感染。

膿痂疹是皮膚淺層感染，主要由金黃色葡萄球菌和化膿性鏈球菌等細菌引起。細菌沒有 β-葡聚醣細胞壁，因此 Anidulafungin 沒有已知的抗菌活性，機轉上看不出合理的連結。這個高分很可能來自知識圖譜中感染性皮膚疾病之間的網絡關聯，而非真實的藥理關係。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：肝臟疾病、膽囊疾病（此為知識圖譜的藥物－疾病關聯，並非仿單文字，須以原廠仿單確認）
- **藥物交互作用**：資料庫共查得 1 項，與 Cyclosporine 的交互作用為輕微（Minor）等級

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測（膿痂疹）僅有模型分數，沒有任何臨床試驗或文獻，證據等級為 L5。
- Anidulafungin 沒有抗菌活性，而膿痂疹是細菌感染，機轉上不合理。其餘多數預測（間皮瘤、細菌性皮膚或梭狀芽孢桿菌感染等）同樣缺乏支持。

**若要推進需要：**
- 補齊作用機轉資料（MOA）
- 取得香港衛生署仿單的警語與禁忌症
- 提出膿痂疹或其他預測疾病的合理機轉假說，並以體外或前臨床實驗驗證
- 若仍想探索，較值得優先評估的是真菌性膿胸這類與抗黴菌活性相關的小眾情境，因為藥物已證實可進入胸腔液，但仍需臨床療效資料
