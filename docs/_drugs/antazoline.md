# Antazoline：從眼部過敏症狀到過敏性蕁麻疹

## 一句話總結

Antazoline 是第一代 H1 抗組織胺藥，在香港以眼藥水形式上市。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，
但目前**沒有臨床試驗**，僅有 **2 篇間接相關文獻**，證據以模型預測為主。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。不過 Antazoline 屬於第一代 H1 受體拮抗劑。過敏性蕁麻疹的風團與紅斑主要由肥大細胞釋放組織胺所引起，因此阻斷 H1 受體在機轉上是合理的，這也與 TxGNN 給出的極高分數（0.9999）相符。

但要注意，這是類別效應的推論。目前沒有任何 Antazoline 用於蕁麻疹的臨床資料，而第二代抗組織胺藥是現行指引的標準治療。Antazoline 相較於它們有什麼優勢，尚未確立。

其他預測的適應症（寒冷性蕁麻疹、頑固性異位性皮膚炎、異位性 IgE 反應、鼻腔疾病、急性喉咽炎）證據等級皆為 L5，只有模型預測，建議一律暫緩（Hold）。其中頑固性異位性皮膚炎與急性喉咽炎的機轉依據較弱；鼻腔疾病與 IgE 反應性則是定義不明確的廣泛標籤。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但缺乏 Antazoline 用於蕁麻疹的直接臨床證據，僅能依 H1 阻斷的類別效應推論。
- 現有產品為眼用劑型，而蕁麻疹通常需要全身性治療，且第二代抗組織胺藥已是標準選擇。

**若要推進需要：**
- 取得香港衛生署仿單，確認原核准適應症、警語與禁忌症
- 補齊 DrugBank 作用機轉資料
- 確認給藥途徑的可行性（目前僅有眼用劑型）
- 與第二代抗組織胺藥比較，說明 Antazoline 的附加價值
- 系統性檢索 Antazoline 與蕁麻疹相關的臨床與文獻證據

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
