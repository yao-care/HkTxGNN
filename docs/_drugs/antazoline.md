# Antazoline：從過敏性鼻炎等過敏性疾病到過敏性蕁麻疹

## 一句話總結

Antazoline 是第一代 H1 抗組織胺，原本用於過敏性鼻炎、結膜炎、蕁麻疹等過敏相關症狀。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，但目前**沒有臨床試驗**，僅有 **2 篇間接相關文獻**。蕁麻疹與血管性水腫本身已列在原適應症中，因此這並非真正的新適應症。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Antazoline 屬於第一代 H1 抗組織胺，蕁麻疹主要由肥大細胞釋放組織胺所引起，因此以 H1 受體阻斷來緩解症狀，在機轉上是合理的。

不過要注意，蕁麻疹和血管性水腫已經是 Antazoline 的原適應症之一，所以這個預測更像是對既有用途的再確認，而不是真正的藥物再利用。

其他預測的適應症中，冷型蕁麻疹同樣是組織胺介導，機轉合理，但無任何臨床資料，且臨床上多偏好研究較充分的第二代抗組織胺。頑固性異位性皮膚炎的機轉契合度較弱，因為其病程主要由第二型發炎（IL-4/IL-13）與皮膚屏障缺損驅動，抗組織胺療效有限。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測的適應症缺乏直接的臨床試驗與文獻支持，證據僅達 L4，且蕁麻疹本來就是原適應症，不構成實質的再利用機會。
- 其他預測（冷型蕁麻疹、頑固性異位性皮膚炎、異位性 IgE 反應、鼻腔疾病、急性喉咽炎）均僅有模型預測（L5），其中部分適應症過於籠統，或機轉契合度低。

**若要推進需要：**
- 取得 Antazoline 的作用機轉資料（MOA）。
- 取得香港衛生署仿單中的警語與禁忌症。
- 釐清香港上市產品皆為眼用滴劑，與蕁麻疹等全身性適應症的給藥途徑是否相容。
- 補充 Antazoline 對蕁麻疹的直接臨床或文獻證據，並與第二代抗組織胺比較。
