# Apomorphine：從帕金森氏症到精神分裂症（模型預測，證據薄弱）

## 一句話總結

Apomorphine 是多巴胺 D1/D2 受體促效劑，原本用於帕金森氏症及相關的帕金森症候群。
TxGNN 模型預測分數最高的新適應症為「顱周多小腦回伴小腦發育不全與關節攣縮」，但這項預測完全沒有臨床試驗或文獻支持。
以文獻數量而言，**精神分裂症 (Schizophrenia)**（排名第 5）是唯一有文獻的預測，共 **20 篇**，皆為間接證據（探針研究、機轉研究、綜述），**0 個臨床試驗**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Apomorphine 是多巴胺 D1/D2 受體促效劑，在帕金森氏症中用於改善運動症狀。

**排名第 1 的預測**：未找到任何機轉連結。多巴胺受體促效作用與先天性神經發育畸形之間沒有已知關聯，這純粹是計算模型的預測結果。

**其他高分預測**：多數同樣缺乏機轉依據（如糖基化缺陷、脫髓鞘型神經病變、甘胺酸腦病變、無腦迴畸形等）。視網膜多巴胺訊號與近視、視網膜病變的眼球生長調控有間接關聯，但僅屬推測，並無針對這些遺傳性疾病的證據。

**精神分裂症**：多巴胺假說認為此病與多巴胺失調有關，Apomorphine 過去多被用作探測 D2 受體功能的藥理工具。然而，D1/D2 促效劑理論上傾向加重精神病症狀而非治療，與治療用途的機轉邏輯相悖。1980 年代的低劑量研究（如 25 位男性患者、0.75 mg 皮下注射）未觀察到明顯改善或惡化。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第 1 的預測沒有任何臨床試驗、文獻或機轉依據，屬純計算結果。
- 精神分裂症雖有文獻，但多為間接證據，既有小型研究未顯示療效，機轉上 D1/D2 促效劑反而可能惡化精神病，且該病類在禁忌清單中，建議僅列為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單的警語、禁忌與核准適應症資料（目前為阻斷性資料缺口）
- 補齊作用機轉資料（如從 DrugBank 取得）
- 對排名靠前的預測做機轉合理性重新評估，必要時以細胞或動物模型進行前臨床驗證
- 若考慮精神分裂症方向，需先釐清促效劑與其病理機轉的矛盾，並設計嚴格的安全監測
