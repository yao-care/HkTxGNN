# Arginine：從（原適應症未載明）到胃輕癱

## 一句話總結

Arginine（精胺酸）是一種胺基酸，在香港以輸液等多種製劑上市，但資料庫中未載明原適應症。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，
目前僅有 **1 個registered 臨床試驗（相關性低）**和 **9 篇文獻（皆為動物研究或個案報告）**，尚無人體證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。不過，精胺酸是一氧化氮合成酶（nNOS）的受質，而一氧化氮訊號（nitrergic signaling）參與胃部放鬆、胃容納功能與幽門放鬆。

前臨床研究提供了間接線索：小鼠實驗顯示，糖皮質素誘發的胃輕癱與 L-精胺酸耗竭有關；四氫生物蝶呤（BH4，nNOS 必要輔因子）缺乏會使新生小鼠出現胃輕癱；帕金森氏症大鼠模型也發現幽門的一氧化氮放鬆功能受損。這些發現支持「補充精胺酸、恢復精胺酸—一氧化氮軸線」的假說。

但這些都是動物研究，尚無精胺酸用於胃輕癱的人體療效或安全性資料。0.994 的 TxGNN 分數僅是計算模型預測，不能取代臨床驗證。

## 結論與下一步

**決策：Hold**

**理由：**
證據僅停留在前臨床動物研究與模型預測（L4），沒有任何人體研究，唯一的臨床試驗也與精胺酸無關。目前只適合作為研究假說，尚不足以推進。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症（目前為阻擋性缺口，無法進入安全性篩選）
- 補充 DrugBank 的作用機轉資料，以及原適應症資料
- 針對精胺酸補充是否能直接改善動物胃輕癱模型的胃排空，設計驗證性前臨床實驗
- 若動物實驗有正向結果，再評估小規模人體探索性試驗（含劑型與給藥途徑的適配性）
