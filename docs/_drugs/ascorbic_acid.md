# Ascorbic Acid：從維生素 C 缺乏症／壞血病到食道疾病

## 一句話總結

Ascorbic Acid（維生素 C）原本用於治療維生素 C 缺乏症與壞血病。
TxGNN 模型預測它可能對**食道疾病 (Esophageal Disease)** 有效（預測排名第 2），
但目前**沒有相關臨床試驗**，僅有 **20 篇文獻**，且以回顧、流行病學與動物或細胞研究為主，並有一項動物研究顯示潛在的安全疑慮。

> 說明：預測排名第 1 的「非症候群性食道畸形」（分數 99.96%）僅有模型預測，無任何試驗或文獻，也無機轉依據（L5）。因此本報告以有文獻可評估的第 2 名「食道疾病」為主軸。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，維生素 C 是強效抗氧化劑，也是膠原蛋白合成的輔因子，並能抑制 N-亞硝胺的生成。

這使它與食道致癌作用及逆流相關的氧化傷害之間有可能的關聯。例如，流行病學研究發現，在中國食道癌高發區補充維生素 C 可降低體內亞硝基脯胺酸 (nitrosoproline) 的形成。

但證據並不一致。回顧文獻指出，維生素 C 對食道癌的保護證據弱於胃癌。一項大鼠研究（PMID 17953708）更發現，在酸逆流模型中合併維生素 C 與亞硝酸鈉，反而**增強**食道致癌。另有病例報告指出口服維生素 C 可能造成局部食道炎。因此這個預測在機轉上有線索，但方向可能是保護也可能是傷害。

## 安全性考量

- **禁忌症（知識圖譜關聯，非仿單內容）**：模型圖譜列出的相關疾病包括高血壓、癲癇、腎臟疾病、肝病、消化性潰瘍、糖尿病、高鈣血症、腎鈣質沉著症、原發性高草酸尿症、遺傳性血色素沉著症、鐮刀型貧血等。實際禁忌請以原廠仿單為準。
- **藥物交互作用**：共查得 25 筆，列出主要幾項：
  - 中度：Amphetamine、Dextroamphetamine、Lisdexamfetamine、Metamfetamine、Benzphetamine、Aluminum hydroxide、Bortezomib、Deferoxamine
  - 輕度：Paclitaxel、Cisplatin、Doxorubicin、Ethinylestradiol、Pseudoephedrine、Ephedrine、Flecainide、Fluphenazine、Indinavir、Mexiletine 等
- **與預測適應症相關的安全訊號**：酸逆流大鼠模型中，維生素 C 合併亞硝酸鹽可能增強食道致癌（PMID 17953708）；另有口服維生素 C 造成局部食道炎的報告（PMID 131047）。

仿單的警語與注意事項請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數、文獻與機轉線索，沒有任何臨床試驗，證據等級為 L4。
- 現有文獻對食道方面的保護作用並不一致，且有動物研究顯示在酸逆流情境下可能增強致癌，需先釐清風險。

**若要推進需要：**
- 釐清要針對的具體食道疾病（如食道癌預防、逆流性食道炎等），而不是籠統的「食道疾病」
- 針對酸逆流合併亞硝酸鹽暴露下的安全疑慮，進行更完整的文獻與毒理評估
- 取得詳細作用機轉資料與香港原廠仿單的警語與禁忌
- 若機轉與安全性評估支持，再設計小規模前瞻性臨床試驗

**其他預測適應症的補充：**
- 「損傷 (injury)」有 Phase 2 RCT 與一項 Phase 3 小型試驗，證據等級 L2，但疾病定義過於異質，目前列為研究問題，不宜直接推進。
- 「維生素缺乏症」與原適應症重疊，不屬於真正的藥物再利用。
- 其餘預測（先天性凝血酶原缺乏、生物素代謝疾病、骨性異常增生等）缺乏合理機轉或證據，建議暫緩。
