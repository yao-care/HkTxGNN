# Asfotase alfa：從低磷酸酶症到粒線體氧化磷酸化異常（核 DNA 異常所致）

## 一句話總結

Asfotase alfa 是一種重組酵素替代療法，原本用於治療**低磷酸酶症 (hypophosphatasia)**。
TxGNN 模型預測它可能對**核 DNA 異常所致的粒線體氧化磷酸化異常**有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Asfotase alfa 是重組的組織非特異性鹼性磷酸酶 (TNAP) 酵素替代療法，能分解無機焦磷酸、磷酸吡哆醛 (PLP) 與磷酸乙醇胺，以支持骨礦化。

然而，粒線體氧化磷酸化異常源自核基因編碼的呼吸鏈成分缺陷，而細胞外的磷酸酶活性並不能彌補這類缺陷。因此，目前**沒有已記載的機轉連結**。高預測分數僅來自知識圖譜的推算，應視為待驗證的假說，而非有實質依據的結論。

此外，排名前 10 的其他預測（如 Steel 症候群、胰臟外分泌功能不全、Scheie 症候群、Hurler 症候群、胱胺酸症等）同樣缺乏機轉與臨床證據，多半可能是酵素替代療法類別或骨骼表型關聯造成的圖譜假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，沒有任何臨床試驗或文獻，且機轉上 TNAP 酵素替代無法補足核 DNA 異常所致的呼吸鏈缺陷。
- 高 TxGNN 分數僅反映圖譜關聯，不足以支持推進。

**若要推進需要：**
- 取得詳細的作用機轉資料，並釐清與粒線體氧化磷酸化缺陷之間是否有任何生物學連結
- 進行前臨床（細胞或動物模型）研究，驗證 TNAP 替代對粒線體功能的影響
- 取得香港衛生署仿單的警語與禁忌資訊，完成安全性評估
- 確認給藥途徑（本品為注射劑）與目標疾病的適配性
