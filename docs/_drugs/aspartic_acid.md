# Aspartic Acid：從鉀缺乏症到腎小管酸中毒

## 一句話總結

Aspartic Acid（天門冬胺酸）是一種胺基酸，原本的適應症為鉀缺乏症（potassium deficiency disease）。
TxGNN 模型預測它可能對**腎小管酸中毒 (Renal Tubular Acidosis)** 有效，
但目前**沒有臨床試驗**，僅有 **4 篇相關文獻**，且皆非針對此藥療效的研究，證據偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，天門冬胺酸常以鉀鹽或鎂鹽（如天門冬胺酸鉀）形式使用，在香港則主要作為複方輸液與全靜脈營養製劑中的胺基酸成分。其在鉀缺乏症中的角色，機轉上可能與電解質補充有關。

腎小管酸中毒的核心問題，是腎小管酸鹼運輸的先天性或後天性缺陷（例如 SLC4A1 陰離子交換蛋白突變）。胺基酸代謝與腎臟氨生成（ammoniagenesis）確有交集，可能是模型找到的關聯，但這一連結仍屬推測、未經證實。

必須提醒：單純補充胺基酸不太可能矯正這類運輸缺陷。標準治療是鹼劑（碳酸氫鹽或檸檬酸鹽），鉀補充本來就是 RTA 處置的一部分。因此即使觀察到益處，也可能來自鉀而非天門冬胺酸本身。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自藥物－疾病關聯資料，並非仿單原文）：腎臟疾病、輸尿管積膿、腹瀉性疾病、慢性腹瀉性疾病、房室傳導阻滯、高血鉀型週期性麻痺、週期性麻痺、醛固酮低下症、先天性肌強直症、胃輕癱。

其中腎臟疾病與房室傳導阻滯、高血鉀相關的條件，與腎小管酸中毒族群的臨床情境有重疊，值得特別留意，尤其若製劑含鉀鹽時。

其他警語、禁忌與藥物交互作用資料請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有任何臨床試驗，文獻也不含天門冬胺酸治療 RTA 的療效證據。
- 機轉上缺乏支持，標準治療（鹼劑）已確立，且知識圖譜顯示腎臟疾病可能是禁忌，因此目前不建議推進。

**若要推進需要：**
- 取得香港仿單的警語與禁忌資料，完成安全性篩選
- 補齊作用機轉資料（如查詢 DrugBank）
- 釐清療效究竟來自天門冬胺酸還是鉀（例如鉀鹽與非鉀鹽對照）
- 前臨床或小規模機轉研究，驗證其對腎臟氨生成與酸鹼調節的影響
- 評估路徑相容性（目前無劑型與給藥途徑資料）
