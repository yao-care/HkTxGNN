# Aspartic Acid：從（原適應症未載明）到腎小管酸中毒

## 一句話總結

Aspartic Acid（天門冬胺酸）是一種胺基酸，在香港主要作為靜脈輸注用胺基酸複方的成分，但資料中未載明原適應症。
TxGNN 模型預測它可能對**腎小管酸中毒 (Renal Tubular Acidosis)** 有效，
但目前**沒有直接相關的臨床試驗**，10 篇文獻皆為間接或基礎研究，證據僅止於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Aspartic Acid 是靜脈輸注胺基酸複方的成分之一，作為營養支持使用，但原適應症的療效資料在本次資料中並未提供，因此無法據此推論其對新適應症的作用。

從生理角度看，天門冬胺酸是腎臟胺基酸代謝的受質，與麩醯胺酸／麩胺酸代謝及腎臟製氨作用有關，這可能是模型將其與腎小管酸中毒連結的原因。

然而，這個預測的機轉合理性偏低：
- 遠端腎小管酸中毒主要由轉運蛋白或基因缺陷（如 SLC4A1）所致，標準治療是鹼性藥物補充。
- 天門冬胺酸本身屬酸性胺基酸，可能增加酸負荷，治療效益在機轉上有疑慮，甚至可能有害。
- 目前沒有任何檢索到的來源顯示補充天門冬胺酸能改善腎小管酸化缺陷。

0.995 的分數僅反映知識圖譜上的關聯，並非療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，僅有模型預測，沒有任何直接相關的臨床試驗或文獻。
- 天門冬胺酸屬酸性胺基酸，用於酸中毒在機轉上有疑慮，且缺乏安全性與作用機轉資料，不宜推進。

**若要推進需要：**
- 取得香港衞生署的仿單，確認警語與禁忌症
- 補齊 DrugBank 的作用機轉資料
- 提出天門冬胺酸如何改善腎小管酸化的機轉假說，並以前臨床模型驗證
- 評估其酸負荷是否會加重酸中毒
