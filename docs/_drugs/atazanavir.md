# Atazanavir：從 HIV-1 感染到猿猴免疫缺陷病毒感染

## 一句話總結

Atazanavir 是 HIV-1 蛋白酶抑制劑，在香港已有 2 張上市許可證。
TxGNN 模型預測它可能對**猿猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效。
目前**沒有臨床試驗**，只有 **1 篇**獼猴動物研究文獻支持，屬於動物模型層級的證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Atazanavir 屬於 HIV-1 蛋白酶抑制劑，透過阻斷病毒蛋白酶來抑制病毒成熟。SIV 的蛋白酶與 HIV-1 同源，因此抗病毒活性在機轉上是可能的。

這個預測分數很高，主要是因為知識圖譜中已有 atazanavir 與 HIV-1 的關係，並不代表 SIV 有獨立的新證據。SIV 是動物（猿猴）的病毒感染，不是人類適應症，對人類藥物再利用的實際價值有限。

現有的唯一文獻是獼猴接受 HAART（高效抗反轉錄病毒療法）的研究。該研究顯示治療可降低中樞神經系統的病毒複製與發炎，但病毒 DNA 仍然存在。這是複方療法的結果，並非 atazanavir 單一藥物的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的證據是獼猴動物研究，且是 HAART 複方而非 atazanavir 單方。SIV 也不是人類適應症，高分主要來自知識圖譜中既有的 HIV-1 關聯。
- 本次評估未涵蓋香港衛生署仿單的警語與禁忌，安全性篩選尚無法進行。

**若要推進需要：**
- 確認此預測的目標是人類適應症還是獸醫／動物模型研究，再決定是否值得投入
- 補充作用機轉資料（DrugBank）
- 取得香港衛生署仿單，補齊警語與禁忌資料
- 同一份資料中另有兩個相關候選可優先檢視：
  - 「AIDS 相關症候群」證據等級 L2，但實質上等同 HIV-1 的原適應症，並非新的再利用方向，仍需先確認核准仿單與試驗設計
  - 「先天性 HIV」證據等級 L3，僅有藥動學與世代研究，缺乏該族群專屬的第 3 期隨機對照試驗
