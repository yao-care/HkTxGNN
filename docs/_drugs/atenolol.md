# Atenolol：從 β1 選擇性阻斷劑到後下壁心肌梗塞

## 一句話總結

Atenolol 是 β1 選擇性阻斷劑，在香港已有 20 張上市許可證，但資料中未附核准適應症文字。
TxGNN 模型預測它可能對**後下壁心肌梗塞 (Posteroinferior Myocardial Infarction)** 有效。
目前**沒有相關臨床試驗**，只有 **1 篇 1985 年的小型文獻**，屬間接證據。

## 為什麼這個預測合理？

Atenolol 是 β1 選擇性阻斷劑，能降低心跳速率與心肌收縮力，進而減少心肌耗氧量。這些作用對缺血心肌有潛在好處，所以模型把它連到心肌梗塞。

不過，心肌梗塞後使用 β 阻斷劑本來就是已確立的一般作法，因此這**不算真正的老藥新用訊號**。目前也沒有證據顯示它對「後下壁」這個特定區域有特別效果。

目前缺乏詳細的作用機轉資料（DrugBank MOA 欄位未取得），以上機轉推論來自 β1 阻斷劑的類別特性。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的證據是一篇 1985 年的小型交叉試驗，測的是運動誘發的抗缺血作用，不是梗塞預後，也沒有針對後下壁區域。
- 香港仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。
- 同一份預測清單中的其他項目（後外側心肌梗塞、惡性腎血管性高血壓、肺高壓等）證據更弱，目前也都建議 Hold。

**若要推進需要：**
- 取得香港衛生署的仿單資料（警語、禁忌症、核准適應症），這是目前的阻擋項目。
- 補齊 DrugBank 的作用機轉資料。
- 確認全文中的實際療效結果，並搜尋心肌梗塞後 β 阻斷劑的大型試驗與統合分析（例如 REDUCE-SWEDEHEART，NCT03278509，為 β 阻斷劑通則性試驗，非 atenolol 專屬）。
- 由臨床專家判斷這項預測是否有別於既有標準治療，是否值得作為研究問題。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
