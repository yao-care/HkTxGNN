# Atosiban：從早產宮縮抑制到原發性遺傳性青光眼

## 一句話總結

Atosiban 是催產素／血管加壓素 V1a 受體拮抗劑，在證據包中的相關試驗與文獻裡，用於抑制早產宮縮（保胎）。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Atosiban 是催產素／血管加壓素 V1a 受體拮抗劑，主要在早產宮縮抑制的情境中使用。

從現有資料看不出受體拮抗作用與青光眼的直接關聯。房水流出路徑或眼壓調控的機轉，都沒有資料支持，任何連結目前都只是推測。這個高分較可能來自知識圖譜中相鄰節點的相似性，而不是已記載的生物學證據。

證據包中排名第 2 的預測「開角型青光眼 (open-angle glaucoma)」分數幾乎相同（99.92%），同樣沒有證據。這兩者不算獨立佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗、文獻或可辨識的機轉連結，證據等級為 L5。
- 香港仿單的警語與禁忌尚未取得（屬阻斷性資料缺口），無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症資料。
- 補充 Atosiban 的詳細作用機轉資料（例如查詢 DrugBank）。
- 檢索眼部組織中催產素／血管加壓素受體訊號與眼壓調控的前臨床研究，確認是否存在機轉連結。
- 評估其他排名的預測。目前僅「血管疾病 (vascular disease)」有間接文獻（L4），但多為催產素促效劑的大鼠心臟保護研究，作用方向可能與拮抗劑相反。一項世代研究也顯示，早產兒暴露於保胎藥與腦室內出血及死亡有關，屬安全性訊號而非療效證據。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
