# Avatrombopag：從慢性肝病與免疫性血小板低下到遺傳性巨血小板低下症

## 一句話總結

Avatrombopag 是血小板生成素受體（TPO-R）促效劑，已知用於慢性肝病及慢性免疫性血小板低下症（ITP）的血小板低下。
TxGNN 模型預測它可能對**巨血小板低下症合併二尖瓣閉鎖不全 (Marcothrombocytopenia with mitral valve insufficiency)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測，屬於研究假說階段。

## 為什麼這個預測合理？

Avatrombopag 是 TPO-R（c-Mpl）促效劑，能刺激巨核細胞生成、提升血小板數量。輸入資料未提供詳細的作用機轉欄位和香港許可證的適應症文字，以上說明來自預測模型附帶的機轉推論。

對於血小板生成不足的遺傳性巨血小板低下症，TPO-R 促效劑在機轉上有合理的作用空間。不過療效取決於背後的基因缺陷，而且二尖瓣閉鎖不全屬於心臟瓣膜問題，並不在這類藥物的作用範圍內。

目前這個預測只有模型分數和藥物類別效應支持，沒有實際研究佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有臨床試驗或文獻佐證，且香港仿單的警語與禁忌資料尚未取得，無法進行安全性篩選。
- 排名前列的遺傳性血小板低下症在機轉上較合理，但適應症定義不明確；其餘預測（如 ALS 等神經疾病）缺乏機轉基礎。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌、核准適應症），完成安全性篩選
- 補充 DrugBank 的作用機轉資料
- 釐清「遺傳性血小板低下症」的具體疾病定義、基因型和血小板生成缺陷類型
- 檢索 ClinicalTrials.gov 與 PubMed，確認是否有 TPO-R 促效劑用於遺傳性血小板低下症的既有證據
- 評估新生兒或兒童族群的安全性與藥動學資料（若考慮新生兒血小板低下症）
