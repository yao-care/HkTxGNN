# Avibactam：從革蘭氏陰性菌感染到肺炎鏈球菌肺炎

## 一句話總結

Avibactam 是一種非 β-內醯胺類的 β-內醯胺酶抑制劑，需與搭配的 β-內醯胺抗生素併用，原本用於革蘭氏陰性菌感染。
TxGNN 模型預測它可能對**肺炎鏈球菌肺炎 (Streptococcal Pneumonia)** 有效，但目前有 **0 個臨床試驗**和 **0 篇文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Avibactam 是 β-內醯胺酶抑制劑，本身沒有明顯的抗菌活性，療效取決於搭配的 β-內醯胺抗生素。它的標示用途針對革蘭氏陰性病原體。

肺炎鏈球菌是革蘭氏陽性菌，其抗藥性通常不是由 β-內醯胺酶造成，所以抑制 β-內醯胺酶對它的生物學基礎偏弱。儘管圖譜分數很高，機轉上的合理性有限。這個高分較可能來自知識圖譜中「肺炎」與 Avibactam 適應症的關聯，而非真正的治療訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有任何臨床試驗或文獻支持。
- 肺炎鏈球菌屬革蘭氏陽性菌，抗藥性通常非 β-內醯胺酶所致，機轉上的合理性弱。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料。
- 補充詳細的作用機轉資料（MOA）。
- 提出具體的機轉假說，例如搭配哪種 β-內醯胺抗生素，並以體外或前臨床實驗驗證。

**其他預測的參考：**
- 在其餘預測中，只有**金黃色葡萄球菌感染**達到 L4，可作為研究問題。相關證據來自 ceftaroline-avibactam 的體外研究（PMID 22733066），抗 MRSA 的活性來自搭配藥物，Avibactam 本身無此活性，所以不宜視為獨立候選。
- 其餘預測（如流感易感性、輸尿管結核、泌尿道血吸蟲病、高澱粉酶血症）多屬圖譜關聯的假象，不建議推進。
