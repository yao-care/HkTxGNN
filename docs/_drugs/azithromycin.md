# Azithromycin：從抗菌治療到高澱粉酶血症

## 一句話總結

Azithromycin 是大環內酯類抗生素，在香港已有多張上市許可證。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Azithromycin 是大環內酯類抗菌藥，具有抗菌與免疫調節特性，但無法確認這些特性與高澱粉酶血症有何關聯。

高澱粉酶血症是一種實驗室檢驗異常，不是一個可直接治療的疾病實體。目前找不到任何機轉上的連結，0.998 的高分只代表知識圖譜上的關聯，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的預測沒有臨床試驗、文獻或機轉依據，證據等級僅 L5。
- 香港藥品仿單的警語與禁忌資料尚缺（阻斷性資料缺口），無法進入安全性初篩。

**其他預測適應症的補充觀察：**
排名較後的幾項預測反而有少量間接證據，可作為研究方向參考，但都不足以支持臨床應用：

- **單株免疫球蛋白病變 (Monoclonal gammopathy)**：體外研究顯示大環內酯類可阻斷自噬流，並增強 bortezomib 對骨髓瘤細胞的毒性 (PMID 23546223)。這只針對惡性漿細胞，不是針對意義未明的單株免疫球蛋白病變，其餘文獻多為個案報告。
- **先天性血液疾病 (Congenital hematological disorder)**：兩項針對鐮刀型貧血的大環內酯類或 azithromycin 試驗（NCT02960503、NCT02630394）皆已撤回，入組人數為 0，沒有產生任何資料。
- **敗血性鼠疫 (Septicemic plague)**：僅有體外藥敏資料，且顯示 azithromycin 對鼠疫桿菌活性差 (PMID 8540736)，已有更成熟的標準用藥。
- **點狀上皮性角結膜炎**：眼表疾病使用 azithromycin 在機轉上合理，但唯一的文獻是診斷性個案報告，沒有療效資料。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料（DG001，阻斷性缺口）。
- 從 DrugBank 補齊 Azithromycin 的作用機轉資料（DG002）。
- 若要進一步探索，建議優先評估有間接證據的方向，例如鐮刀型貧血相關肺部併發症與骨髓瘤前臨床研究，再設計前瞻性研究。
- 高澱粉酶血症本身需先釐清是否屬於可治療的臨床目標，再決定是否值得投入資源。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。*
