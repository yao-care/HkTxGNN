# Baricitinib：從免疫介導性發炎疾病到眼組織缺損型小眼症－近端肢體發育不良症候群

## 一句話總結

Baricitinib 是一種 JAK1/JAK2 抑制劑，一般用於免疫介導性發炎疾病。
TxGNN 模型預測它可能對**眼組織缺損型小眼症－近端肢體發育不良症候群 (Colobomatous microphthalmia-rhizomelic dysplasia syndrome)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Baricitinib 一般被認為是 JAK1/JAK2 抑制劑，主要用於免疫介導性發炎疾病。

預測的新適應症是罕見的先天性發育異常，特徵為眼部畸形合併肢體骨骼發育不良。現有資料看不出 JAK-STAT 路徑與這類疾病的致病機轉有關，因此原用途與新適應症之間**找不到有資料支持的機轉關聯**。

0.9994 的高分只是模型輸出，不能當作支持證據。超罕見疾病在知識圖譜中連結稀疏，分數可能偏高，未必反映真實的生物學關係。

同一批預測中，排名第二的是**指趾短小－併指症候群 (Brachydactyly-syndactyly syndrome)**，分數為 99.94%，同樣是先天性肢體畸形，也同樣沒有臨床試驗或文獻佐證。這類結構性先天異常，對出生後才使用的免疫調節劑來說，治療邏輯並不清楚。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有 TxGNN 模型分數，沒有臨床試驗、文獻或機轉證據，屬於 L5。
- 疾病為超罕見的先天發育異常，與 JAK-STAT 路徑無明確關聯，高分可能是知識圖譜連結稀疏所致。

**若要推進需要：**
- 取得 Baricitinib 完整的作用機轉資料（DrugBank）。
- 確認 JAK-STAT 訊號與該症候群的致病基因或路徑是否有關。
- 檢索有無病例報告、動物模型或體外研究。
- 從香港衛生署下載仿單，補齊警語與禁忌症，才能進行安全性篩選。
- 確認核准適應症，釐清原適應症與預測新適應症的關聯。
