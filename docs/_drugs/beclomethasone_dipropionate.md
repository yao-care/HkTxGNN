## Beclomethasone Dipropionate：合成糖皮質素類藥物 → 異位性皮膚炎 (atopic eczema)
{: .text-alpha }

## 一句話總結

Beclomethasone Dipropionate 是一種合成糖皮質素（皮質類固醇），在香港以鼻噴劑與吸入劑型上市。
TxGNN 模型預測它可能對**異位性皮膚炎 (atopic eczema)** 有效，
目前**沒有臨床試驗登記**，文獻有 **9 篇**，但多為間接相關的安全性、劑型或機轉研究，並非直接證明療效的對照試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Beclomethasone Dipropionate 屬於合成糖皮質素類別，這類藥物透過活化糖皮質素受體，降低促發炎細胞激素的表現並抑制免疫細胞活化。

異位性皮膚炎是以 Th2 免疫反應為主的發炎性皮膚病，外用與全身性皮質類固醇是已確立的治療類別，因此從類別藥理來看，這個預測在生物學上說得通，也與模型給出的高分（0.9941）一致。不過這個推論建立在皮質類固醇的類別特性上，並非此藥物本身的機轉資料。

需要留意的是，有一項體外研究（PMID 8765824）指出，外用類固醇在異位性皮膚炎患者中會增強自發性 IgE 生成，這是一個可能不利的免疫訊號。

## 安全性考量

- **藥物交互作用**：共查得 49 筆交互作用。重要者包括：
  - 重大（Major）：Desmopressin
  - 中度（Moderate）：Acetazolamide、Foscarnet、Furosemide、Hydrochlorothiazide、Amphotericin B（各劑型）、Bumetanide、Cisplatin 等利尿劑與具腎毒性或電解質影響的藥物
  - 輕微（Minor）：Formoterol、Salbutamol、Arformoterol
- **文獻提示的安全疑慮**：全身性吸收可能造成腎上腺抑制，兒童長期使用可能影響線性生長與骨代謝；外用類固醇亦有接觸性過敏的報告。

原廠仿單的警語與禁忌症資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何直接以異位性皮膚炎為對象、以療效為終點的臨床試驗或對照研究，因此證據等級僅為 L5（僅有模型預測）。現有文獻多為安全性或劑型研究，且顯示兒童全身性暴露的風險，並出現不利的 IgE 訊號。
- 香港現有劑型為鼻用與吸入劑型，與皮膚適應症的給藥途徑不符。

**若要推進需要：**
- 取得 Beclomethasone Dipropionate 的作用機轉資料與香港仿單的警語、禁忌症
- 系統性檢索直接針對異位性皮膚炎的隨機對照試驗，並與現有外用類固醇做療效與安全性比較
- 評估外用皮膚劑型的可行性與本地註冊途徑
- 針對兒童族群制定腎上腺功能與生長監測計畫
