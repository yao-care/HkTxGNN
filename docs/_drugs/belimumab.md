# Belimumab：從（許可證未載明適應症）到原發性血小板釋放障礙

## 一句話總結

Belimumab 是一種抑制 BLyS/BAFF 的生物製劑，在香港已有 3 張許可證，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**原發性血小板釋放障礙 (Primary release disorder of platelets)** 有效。
目前僅有 **1 個不相符疾病的臨床試驗**，且**沒有相關文獻**，證據只停留在模型預測層級。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。依現有分析，Belimumab 抑制可溶性 BLyS/BAFF，降低自體反應性 B 細胞的存活。

不過，原發性血小板釋放障礙多為遺傳性或後天性的血小板功能缺陷，並不明顯由 B 細胞或自體抗體驅動。因此機轉上**沒有直接關聯**，TxGNN 的高分（99.96%）只是知識圖譜的推論，沒有實證支持。

其他預測疾病中，只有**胎兒與新生兒同種免疫性血小板低下症**在生物學上相對合理：母體同種抗體由 B 細胞與漿細胞產生，阻斷 BAFF 理論上可降低抗體生成。但 Belimumab 對已成熟的漿細胞作用有限，懷孕期安全性資料也很少，目前只能算研究假說。Glanzmann 血小板無力症只有間接、推測性的連結，其餘預測（假性血管性血友病、重度非增殖性糖尿病視網膜病變、體染色體顯性巨血小板症）則看不到合理機轉。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，僅有模型預測。唯一的臨床試驗針對不相符的疾病，且沒有任何文獻。
- 主要預測疾病在機轉上缺乏合理連結，高分很可能是知識圖譜的假象。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌症（目前缺少，無法進行安全性篩選）。
- 補齊 DrugBank 的作用機轉資料。
- 若要繼續探索，建議優先聚焦「胎兒與新生兒同種免疫性血小板低下症」，先做系統性文獻檢索，並評估懷孕期安全性。
- 其餘預測疾病在找到新的機轉證據前，不建議投入資源。
