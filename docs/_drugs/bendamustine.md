## Bendamustine：烷化劑（細胞毒性化療藥物） → 被套細胞淋巴瘤 (mantle cell lymphoma)
{: .text-alpha }

## 一句話總結

Bendamustine 是一種兼具烷化與類嘌呤結構特性的細胞毒性化療藥物，TxGNN 模型預測它可能對**被套細胞淋巴瘤 (mantle cell lymphoma)** 有效。
目前資料中有 **多項直接研究被套細胞淋巴瘤的臨床試驗**（包含數個 Phase 3 隨機試驗）與 **多篇相關文獻**（含 RCT）支持這個方向。

## 為什麼這個預測合理？

Bendamustine 是烷化劑，並帶有類嘌呤的結構，可造成 DNA 交聯並誘導 B 細胞惡性腫瘤細胞凋亡。目前缺乏詳細的作用機轉資料（DrugBank 未提供 MOA），以上機轉描述來自本報告整理的推論資料。

被套細胞淋巴瘤屬於成熟 B 細胞腫瘤，與 bendamustine 已有研究的濾泡性淋巴瘤等 B 細胞惡性腫瘤在生物學上相近。更重要的是，bendamustine 加 rituximab (BR) 已是被套細胞淋巴瘤第一線治療的常用骨幹方案，並被用作大型隨機試驗中與 BTK 抑制劑搭配或比較的方案。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有多項直接研究被套細胞淋巴瘤的已完成 Phase 3 隨機試驗（如 NCT00991211、NCT00877006、NCT01776840），並有 Lancet、NEJM 等期刊的 RCT 文獻，BR 方案已是該疾病第一線常用骨幹。
- 但 bendamustine 骨髓抑制與感染風險高，且香港仿單的警語與禁忌資料尚缺。

**若要推進需要：**
- 取得並解析香港衛生署核准仿單（核准適應症、警語、禁忌症）
- 補充詳細的作用機轉資料
- 建立血球計數監測、感染預防與特定族群（腎、肝功能不全者）的用藥計畫
