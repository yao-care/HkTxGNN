# Benralizumab：從嗜酸性球性氣喘到免疫性血小板減少症

## 一句話總結

Benralizumab 是抗 IL-5Rα 單株抗體，臨床上主要用於嗜酸性球性氣喘（此為一般藥理知識，證據包內的香港許可證未載明適應症）。
TxGNN 模型預測它可能對**免疫性血小板減少症 (Thrombocytopenia due to immune destruction)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據已知資訊，Benralizumab 靶向嗜酸性球與嗜鹼性球表面的 IL-5Rα，並透過抗體依賴性細胞毒性（ADCC）清除這些細胞。

免疫性血小板減少症主要由抗血小板自體抗體與 T 細胞失調驅動，與嗜酸性球或 IL-5 路徑沒有已知的直接關聯。因此，**機轉上看不出明確的連結**。0.993 的高分只是知識圖譜上的關聯推論，並非來自實際的臨床或文獻證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有試驗、文獻，也沒有合理的機轉連結，證據等級為 L5。
- 免疫性血小板減少症的病因與嗜酸性球無關，不建議優先投入資源。

**若要推進需要：**
- 先補足 IL-5Rα 或嗜酸性球在免疫性血小板減少症中角色的機轉證據，例如前臨床研究或病例系列。
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選。
- 從 DrugBank 補齊作用機轉資料。

**補充：其他候選預測**
- 同一份預測清單中，只有**皮膚炎 (dermatitis)** 有實際研究，證據等級為 L2。
- 其 Phase 2 RCT（HILLIER，NCT04605094）顯示 Benralizumab 對中重度異位性皮膚炎**沒有療效**，試驗已終止。
- 機轉研究顯示皮膚病灶中的 IL-5Rα 陽性細胞確實被清除，但這並未轉化為臨床改善。
- 另有 1 例 Benralizumab 引起間質性肉芽腫性皮膚炎的個案報告。
- 該項建議同樣為 Hold，僅嗜酸性球主導的皮膚病（如 DRESS，NCT06734884 尚未開始招募）仍有可能。
- 痤瘡性瘢痕瘤、新生兒皮肌炎、無肌病性皮肌炎這三項預測同樣沒有證據與機轉支持，均為 L5、Hold。

*本報告僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
