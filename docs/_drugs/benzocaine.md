## Benzocaine：局部麻醉藥（鈉離子通道阻斷劑） → 乳突狀結膜炎 (papillary conjunctivitis)
{: .text-alpha }

## 一句話總結

Benzocaine 是一種酯類局部麻醉藥，在香港以口含錠及軟膏等劑型上市。
TxGNN 模型預測它可能對**乳突狀結膜炎 (papillary conjunctivitis)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。依一般藥理學，Benzocaine 屬於酯類局部麻醉藥，
推測是阻斷電壓門控鈉離子通道，產生表面止痛效果。以下為依藥物類別所作的推論，並非來自本報告所整理的資料。

可能的關聯是緩解乳突狀結膜炎伴隨的眼部不適或搔癢。
但它無法處理根本病因（過敏、隱形眼鏡相關或機械性刺激），因此即使機轉上說得通，
也只能算症狀緩解，不是疾病治療。

另有重要的安全疑慮：眼部反覆使用可能造成角膜毒性、延遲上皮癒合，
也可能引起致敏或接觸性過敏，反而使乳突狀結膜炎惡化。
此外 Benzocaine 並非標準眼科麻醉劑，眼科一般使用 proparacaine 或 tetracaine。

## 安全性考量

- **眼部使用風險**：反覆使用可能造成角膜毒性與延遲上皮癒合；Benzocaine 為已知的接觸性致敏原，可能加重結膜發炎。

其餘警語、禁忌症與藥物交互作用資料不足，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自模型計算，沒有任何直接研究支持，證據等級為 L5。
- 眼部使用有角膜毒性與致敏風險，且已有更合適的標準眼科麻醉劑可用。

**若要推進需要：**
- 針對乳突狀結膜炎的前臨床或臨床研究（含眼部耐受性與角膜安全性評估）
- 完整的作用機轉資料
- 香港仿單的警語與禁忌症
- 與現有眼科局部麻醉劑及抗過敏治療的比較，以及是否有適合眼用的劑型與給藥途徑
