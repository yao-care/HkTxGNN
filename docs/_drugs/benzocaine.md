# Benzocaine：從皮膚黴菌感染與咽炎到乳頭狀結膜炎

## 一句話總結

Benzocaine 是一種外用局部麻醉劑，原本用於足癬、皮膚炎、咽炎、體癬等相關症狀的處置。
TxGNN 模型預測它可能對**乳頭狀結膜炎 (Papillary Conjunctivitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型的計算預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。依一般藥理知識，Benzocaine 是酯類局部麻醉劑，
可阻斷電壓門控鈉離子通道，產生表面止痛效果。此說明來自藥物類別的一般知識，並非本報告所整理資料中的機轉紀錄。

在機轉上，一個可能但尚未被驗證的關聯，是緩解乳頭狀結膜炎的眼部不適或搔癢感。
但它只能緩解症狀，無法處理病因（過敏、隱形眼鏡相關或機械性刺激）。

此外，Benzocaine 並非已確立的眼科用藥，眼科麻醉的標準選擇是 proparacaine 或 tetracaine。
眼部使用 Benzocaine 還有安全疑慮：反覆使用可能造成角膜毒性、延遲上皮癒合，
以及致敏或接觸性過敏（Benzocaine 已知的問題），反而可能使乳頭狀結膜炎惡化。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來源為 TxGNN 知識圖譜的藥物－疾病禁忌關聯，並非仿單內容）：
  - 肝臟與腎臟：肝衰竭、肝病、肝性昏迷、肝性腦病變、腎臟疾病
  - 血液：血小板低下、嗜中性白血球低下、顆粒球缺乏症、凝血疾病
  - 代謝：遺傳性卟啉症（卟啉症）、糖尿病、糖尿病酮酸中毒、副甲狀腺機能亢進、高鈣血症、腎鈣質沉著症
  - 神經精神：癲癇、焦慮症、精神官能症、輕鬱症、物質濫用／依賴
  - 其他：膽囊疾病、胃炎、單純疱疹、結節病、皮疹、輸尿管積膿
- **眼部使用的額外疑慮**：角膜毒性、延遲上皮癒合、接觸性過敏（見上方機轉段落）。

其餘警語、禁忌症與藥物交互作用資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.38%），但目前完全沒有臨床試驗或文獻佐證（證據等級 L5），且 Benzocaine 眼部使用有角膜毒性與致敏風險，另有標準的眼科麻醉替代藥物。

**若要推進需要：**
- 補齊作用機轉資料（MOA）
- 取得香港衛生署仿單的警語與禁忌症，完成安全性初篩
- 評估給藥途徑相容性（現有香港產品為口含錠與軟膏，無眼用劑型）
- 進行文獻與臨床試驗檢索，確認是否有支持乳頭狀結膜炎的證據
- 進行前臨床眼部安全性評估（角膜毒性、致敏性），並與現有眼科麻醉劑比較
