# Benzocaine：從局部麻醉到乳突狀結膜炎

## 一句話總結

Benzocaine 是酯類局部麻醉劑，資料庫未載明原適應症，香港現有 5 張含此成分的許可證。
TxGNN 模型預測它可能對**乳突狀結膜炎 (Papillary Conjunctivitis)** 有效。
目前**沒有臨床試驗**和**文獻**支持，證據僅來自模型預測，且機轉上有安全疑慮。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥理常識，Benzocaine 是外用酯類局部麻醉劑，作用是阻斷電壓門控鈉通道，抑制感覺神經放電。

理論上，這可能緩解乳突狀結膜炎的眼部搔癢或不適。但乳突狀結膜炎的核心病理是免疫介導（過敏性，或隱形眼鏡等機械刺激），Benzocaine 只能壓制症狀，無法處理病因。

Benzocaine 屬 PABA 酯類，是已知的接觸致敏原。眼部使用反而可能加重結膜的過敏性發炎。因此 0.994 的高分缺乏生物學支持，可能只是知識圖譜中它與其他麻醉劑或眼科藥物距離相近所致。

## 安全性考量

安全性資訊請參考原廠仿單。

另有一項來自機轉推論的風險：Benzocaine 是已知接觸致敏原，眼部暴露可能惡化過敏性結膜炎。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅有模型預測，沒有任何臨床試驗或文獻。
- Benzocaine 最多只能緩解症狀，且其致敏性可能使病況惡化，機轉上不支持這個預測。

**若要推進需要：**
- 取得 Benzocaine 的作用機轉與原適應症資料，補齊 DrugBank 資訊。
- 取得香港衛生署仿單，確認警語與禁忌症。
- 評估眼用給藥途徑的可行性，包括是否有眼用劑型、黏膜刺激與致敏風險。
- 進行文獻回顧，確認局部麻醉劑用於結膜炎的既有研究與眼部安全性。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。*
