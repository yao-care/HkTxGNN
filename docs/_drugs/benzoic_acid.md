# Benzoic Acid（苯甲酸）：從皮膚纖維化相關疾病到支氣管炎

## 一句話總結

Benzoic Acid 是一種具抗菌與角質溶解特性的成分，原本在知識圖譜中與天疱瘡、佩洛尼氏病、硬皮症等皮膚及纖維化疾病相關。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有臨床試驗**，僅有 **2 篇間接相關文獻**，且文獻均未直接研究苯甲酸，屬於純模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，苯甲酸是一種防腐劑與抗菌成分，外用時具有角質溶解與抗真菌作用，在香港多以外用軟膏、粉劑、噴劑等單一成分製劑上市。

原適應症多為皮膚與纖維化疾病，與支氣管炎（呼吸道炎症）在疾病類型上並無明顯關聯。本次檢索到的兩篇文獻，一篇討論瑞格列奈（repaglinide）用於第 2 型糖尿病，另一篇探討可溶性環氧化物水解酶抑制劑在菸害誘發 COPD 的作用，**均未研究苯甲酸**。因此，目前找不到可信的機轉連結，高分預測應視為僅供假說生成的計算結果。

## 結論與下一步

**決策：Hold**

**理由：**
- 本預測僅來自模型計算，沒有任何臨床試驗，檢索到的文獻也未直接研究苯甲酸，且找不到合理的機轉連結。
- 苯甲酸在香港主要為外用製劑，而支氣管炎的治療需考慮呼吸道給藥或全身性給藥，劑型與路徑相容性尚未評估。

**若要推進需要：**
- 補齊苯甲酸的作用機轉資料（MOA）。
- 取得香港衛生署的仿單，完成警語與禁忌症的安全性篩選。
- 針對苯甲酸與呼吸道炎症做直接的前臨床或機轉研究。
- 評估給藥途徑的可行性（現有製劑多為外用）。
- 另可考慮排名較後的纖維化相關預測（如掌筋膜纖維瘤病、Ledderhose 病），其與原適應症中的纖維化疾病較有主題上的關聯，但同樣缺乏證據，仍須先建立機轉依據。
