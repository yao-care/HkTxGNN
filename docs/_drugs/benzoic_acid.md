# Benzoic Acid：從防腐劑／抗菌輔藥到支氣管炎

## 一句話總結

Benzoic Acid（苯甲酸）是一種廣泛應用於食品及藥品的防腐劑，具有弱抗菌特性，目前在香港無任何核准醫療適應症的上市紀錄。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，
然而目前僅有 **0 個臨床試驗**和 **2 篇間接文獻**，整體證據極為薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，苯甲酸是一種簡單的芳香族羧酸，歷史上主要用途為食品添加物（E210 防腐劑）及局部抗黴菌製劑成分（如 Whitfield 藥膏），對革蘭氏陽性菌具弱度抑菌活性。

苯甲酸與支氣管炎的潛在連結高度推測性。部分苯甲酸衍生物（如苯甲酸鈉）在動物模型中顯示抗氧化特性，理論上或許能減輕支氣管黏膜的氧化壓力，但此機轉連結缺乏直接藥理數據支持。目前找到的文獻均屬苯甲酸衍生物的相關研究（如 repaglinide 用於糖尿病、sEH 抑制劑用於 COPD），與苯甲酸本身直接治療支氣管炎的關聯極為間接。

TxGNN 模型給出高預測分數（99.98%）很可能源自知識圖譜中苯甲酸及其衍生物與呼吸道疾病節點之間的間接路徑連結，而非直接藥理機轉，需審慎解讀。

## 結論與下一步

**決策：Hold**

**理由：**
全部 10 項預測適應症均屬 L5 證據等級（僅模型預測，無直接研究支持），且苯甲酸本身在香港無任何核准適應症或上市紀錄。現有文獻均為苯甲酸衍生物的間接研究，機轉連結高度推測性，不具推進老藥新用評估的最低條件。

**若要推進需要：**
- 補充苯甲酸的完整藥理作用機轉資料（MOA），包括抗菌、抗炎路徑
- 確認 TxGNN 知識圖譜中苯甲酸連結支氣管炎的具體路徑，釐清是直接連結或透過衍生物節點
- 尋找苯甲酸（非其衍生物）在呼吸道疾病模型中的前臨床研究
- 取得香港藥監局（衛生署）或其他主要監管機構的完整安全性資料
- 評估苯甲酸作為藥物活性成分（而非輔料）的可行性與劑量合理性
