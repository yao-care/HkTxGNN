# 過氧化苯甲醯 (Benzoyl Peroxide)：從痤瘡到外陰倒置性毛囊角化症

## 一句話總結

過氧化苯甲醯是外用角質溶解、抗粉刺及抗菌藥物，主要用於痤瘡（此為依預測理由推論，許可證未載明適應症）。
TxGNN 模型預測它可能對**外陰倒置性毛囊角化症 (Vulvar Inverted Follicular Keratosis)** 有效。
目前**沒有臨床試驗和文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，過氧化苯甲醯是外用角質溶解、抗粉刺及抗菌藥物，作用於毛囊上皮。其在痤瘡等毛囊相關疾病中的用途已被廣泛認識，機轉上可能與毛囊角化性病灶有關。

倒置性毛囊角化症是良性病灶，通常以切除處理。過氧化苯甲醯作用於毛囊上皮，與這類病灶只有表面上的關聯，目前僅屬推測。

TxGNN 分數雖高 (99.92%)，但這只是模型預測，沒有臨床、機轉或文獻佐證。此外，將已知刺激物用於外陰黏膜也有安全疑慮。

## 安全性考量

安全性資訊請參考原廠仿單。

另外，同一份預測清單中的「2-羥乙基甲基丙烯酸酯 (HEMA) 致敏」可能是安全性訊號，而非治療適應症。過氧化苯甲醯是丙烯酸酯與甲基丙烯酸酯聚合的自由基起始劑，本身也是已知接觸性過敏原。將已知刺激物用於外陰黏膜，也需要特別留意。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測只有模型分數，沒有臨床試驗、文獻或機轉支持，證據等級為 L5。
- 該病灶通常以切除處理，外用過氧化苯甲醯用於外陰黏膜還有刺激性疑慮。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉 (MOA) 資料。
- 取得香港衛生署仿單的警語與禁忌症，完成安全性篩選。
- 查找過氧化苯甲醯用於倒置性毛囊角化症的病例報告或機轉研究。
- 評估外陰黏膜的用藥途徑與耐受性。
- 同一清單中的「痤瘡瘢痕瘤 (acne keloid)」證據等級為 L4，屬於研究問題，可優先做文獻回顧，但目前也沒有直接測試過氧化苯甲醯的研究。
