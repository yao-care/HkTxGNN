# Benzoyl Peroxide：從痤瘡與皮膚炎到外陰倒置性毛囊角化症

## 一句話總結

Benzoyl Peroxide（過氧化苯甲醯）是常見的外用藥，原本用於痤瘡、各類皮膚炎及脂漏性角化症等皮膚疾病。
TxGNN 模型預測它可能對**外陰倒置性毛囊角化症 (Vulvar Inverted Follicular Keratosis)** 有效，
但目前**沒有臨床試驗，也沒有直接相關文獻**，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Benzoyl Peroxide 具有角質溶解、抗菌及刺激毛囊的作用，在痤瘡等毛囊相關皮膚疾病中的療效已被證實。

倒置性毛囊角化症是一種良性、源自毛囊的病灶，與脂漏性角化症相關，而脂漏性角化症本身就在 Benzoyl Peroxide 的原適應症之列。這是模型預測的主要關聯。

不過，這個關聯目前只是推論。沒有任何臨床試驗或文獻支持用於此外陰病灶，且外陰黏膜對刺激特別敏感，是需要特別留意的安全疑慮。

## 安全性考量

- **知識圖譜中的禁忌疾病**（來自模型知識圖譜，並非仿單內容）：光敏感相關疾病、肛門生殖器人類乳突病毒感染、尋常疣、腎臟疾病、腎上腺皮質功能不全 / 艾迪森氏症、克隆氏症、發炎性腸道疾病、潰瘍性結腸炎、困難梭狀芽孢桿菌結腸炎、剝脫性皮膚炎、皮膚炎、糖尿病及酮酸中毒、皮膚萎縮、微血管擴張症、遺傳性出血性微血管擴張症、周邊血管疾病、周邊動脈疾病等。
- **預測適應症相關的安全疑慮**：外陰黏膜易受刺激；Benzoyl Peroxide 是已知接觸致敏原。

其餘警語、禁忌與藥物交互作用資訊，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的預測適應症只有模型分數（99.92%），沒有任何臨床試驗或文獻，證據等級為 L5。
- 外陰黏膜對刺激敏感，且 Benzoyl Peroxide 本身是接觸致敏原，在缺乏證據下不宜推進。

**若要推進需要：**
- 取得香港仿單的警語與禁忌資料，以進行安全性篩選
- 補齊作用機轉（MOA）資料
- 針對外陰倒置性毛囊角化症蒐集病例報告或文獻，並評估黏膜耐受性
- 若優先考慮其他預測，瘢痕疙瘩性痤瘡（L4）較適合先以研究問題形式探討，並留意刺激與色素沉著風險
