# Benzyl Alcohol：從（原適應症未載明）到支氣管炎

## 一句話總結

Benzyl Alcohol（苯甲醇）在香港有 1 張上市許可證，但原適應症資料未載明。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有臨床試驗**，檢索到的文獻也不支持療效。
現有文獻反而指出，含苯甲醇防腐劑的抑菌生理食鹽水經霧化吸入後，可能誘發支氣管炎。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Benzyl Alcohol 常作為藥品防腐劑使用，並具有輕微的局部麻醉與抗菌特性。但沒有資料顯示這些特性能用於治療支氣管炎。

TxGNN 分數很高，但這只是知識圖譜的預測，可能反映的是圖譜中的關聯接近（例如與呼吸道相關實體共同出現），不代表真正有療效。

檢索到的文獻方向相反。多篇報告指出，含苯甲醇的抑菌生理食鹽水經霧化吸入，會刺激氣管支氣管黏膜，造成支氣管炎或支氣管痙攣。這是**安全性警訊**，不是療效證據。因此這個預測的合理性目前不足。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅 L5：只有模型預測，沒有臨床試驗，也沒有支持療效的文獻。
- 現有文獻顯示，苯甲醇經霧化吸入可能刺激呼吸道並誘發支氣管炎，方向與預測相反。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌與核准適應症（目前為阻斷性資料缺口）。
- 補齊 DrugBank 的作用機轉資料，評估是否存在合理的機轉連結。
- 釐清苯甲醇在呼吸道的局部刺激與吸入安全性。
- 若無新的療效證據，不建議進入後續篩選。
