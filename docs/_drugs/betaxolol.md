# Betaxolol：從高血壓與開角型青光眼到原發性遺傳性青光眼

## 一句話總結

Betaxolol 是 β1 選擇性腎上腺素受體拮抗劑，原本用於高血壓、開角型青光眼與高眼壓。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
但目前**沒有臨床試驗與文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA 欄位未收錄）。根據已知資訊，Betaxolol 是 β1 選擇性腎上腺素受體拮抗劑，已核准用於開角型青光眼與高眼壓。其降眼壓作用一般認為是透過減少睫狀體的房水生成。

原發性遺傳性青光眼（例如原發性先天性青光眼，或與 MYOC/CYP1B1 變異相關的青少年型開角型青光眼）同樣以眼壓升高為特徵，因此降眼壓機轉在理論上可能適用。TxGNN 的高分很可能反映它與已核准青光眼適應症在知識網路上非常接近。

需要注意：此預測適應症與現有標示用途（開角型青光眼）高度重疊，較像是**亞型延伸**，而非真正的新用途。此外，原發性先天性青光眼通常以手術為第一線治療，兒童使用時的心搏過緩與支氣管痙攣風險也需另行評估。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自模型知識圖譜，非仿單文字）：包括氣喘（含內因性與過敏性）、肺氣腫與支氣管疾病、房室傳導阻滯、糖尿病與糖尿病酮酸中毒、低血糖、嗜鉻細胞瘤與相關腎上腺腫瘤、重症肌無力與神經肌肉接合部疾病、乾癬、肝臟與腎臟疾病、膽囊疾病，以及焦慮與相關情緒障礙。
- **藥物交互作用**：共查得 100 筆，以下為部分範例。
  - 中度：Epinephrine、Morphine、Bupropion、Atropine、Hyoscyamine，以及多種皮質類固醇（Hydrocortisone、Dexamethasone、Betamethasone、Triamcinolone、Budesonide）。
  - 中度：Acetohexamide，以及多種鈣鹽（Calcium carbonate、Calcium gluconate 等）。
  - 輕度：Acetylsalicylic acid、Aluminum hydroxide、Attapulgite。

其餘警語與禁忌的仿單資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測（L5），沒有任何臨床試驗或文獻佐證。
- 預測適應症與已核准的開角型青光眼高度重疊，新增價值有限。
- 兒童族群的心肺安全性疑慮尚未評估。

**若要推進需要：**
- 補充作用機轉（MOA）資料
- 取得香港衛生署仿單的警語、禁忌與適應症文字，完成安全性篩查
- 針對原發性遺傳性青光眼（含先天性亞型）進行系統性文獻與試驗檢索
- 釐清此預測是否為真正的新適應症，或僅是開角型青光眼的亞型
- 若涉及兒童族群，另行制定心搏過緩與支氣管痙攣的安全性評估與監測計畫
