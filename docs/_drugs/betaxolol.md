# Betaxolol：從（原適應症未載明）到原發性遺傳性青光眼

## 一句話總結

Betaxolol 是選擇性 beta-1 腎上腺素受體拮抗劑，香港已有眼藥水與口服錠劑上市，但資料中未載明原適應症。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
目前**沒有臨床試驗和文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。不過 Betaxolol 屬於 beta-1 選擇性腎上腺素拮抗劑。眼用 beta 阻斷劑一般透過減少睫狀體的房水生成來降低眼壓，因此機轉上可能適用於青光眼。

需要留意的是，本筆資料沒有記載原適應症，TxGNN 的高分（99.74%）可能只是反映知識圖譜中既有的「beta 阻斷劑—青光眼」類別關聯，而不是新穎的再利用訊號。此外，原發性遺傳性（先天性／幼年型）青光眼通常以手術為主要治療，局部藥物多作為輔助或暫時性治療；兒童使用 beta 阻斷劑的安全性（心搏過緩、支氣管痙攣）也需要另行評估。
