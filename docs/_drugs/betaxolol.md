# Betaxolol：從高眼壓症到原發性遺傳性青光眼

## 一句話總結

Betaxolol 是選擇性 β1 腎上腺素受體拮抗劑，臨床上用於降低眼壓（高眼壓症、開角型青光眼）及控制高血壓。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
目前支持來自機轉層面的理論依據，**尚無臨床試驗或文獻**直接針對此遺傳亞型進行研究。

## 為什麼這個預測合理？

Betaxolol 是高度選擇性的 β1 腎上腺素受體拮抗劑（pKi β1 ≈ 9.0），作用於眼睛睫狀體上皮的 β 受體，透過抑制 cAMP 生成來減少房水（aqueous humor）分泌，進而有效降低眼壓（IOP），降幅約 20–25%。

原發性遺傳性青光眼（涵蓋 MYOC、OPTN、WDR36 等基因突變型）的核心病理機制為：小梁網（trabecular meshwork）功能異常 → 眼壓持續升高 → 視神經軸突損傷。Betaxolol 透過降低眼壓，可有效緩解此連鎖損傷的下游效應，其降壓作用與青光眼的遺傳病因並無直接關聯，因此在機轉上對遺傳性青光眼亞型同樣適用。

值得注意的是，相較於非選擇性 β 阻斷劑 timolol，betaxolol 因具有鈣通道阻斷特性，可能對視神經血流（optic nerve blood flow）提供額外保護效應。這對視神經受損較嚴重的遺傳性青光眼患者尤具理論優勢，是此預測合理性的加分論據。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 模型預測分數高達 99.74%，機轉關聯性充分且具說服力；然而目前完全缺乏針對「原發性遺傳性青光眼」的臨床試驗及文獻，現有證據屬機轉推論層級（L4），尚不足以支持直接進入臨床評估。此外，香港目前無 betaxolol 上市許可，且藥物安全性資料（警語、禁忌）均缺失，需優先補齊基礎資料。

**若要推進需要：**
- 補充 betaxolol 完整安全性資料（警語、禁忌症、主要藥物交互作用）
- 系統性回顧 betaxolol 用於一般青光眼與高眼壓症的臨床文獻，評估其結果外推至遺傳亞型的可行性
- 搜尋基因型特異性青光眼（如 MYOC 突變型）的輔助降眼壓治療相關研究
- 評估香港是否有同類藥物（timolol、carteolol 等）的上市先例，作為監管路徑參考
- 若決定推進，需諮詢香港藥劑業及毒藥管理局的孤兒藥或特殊適應症申請途徑
