# Bimatoprost：從青光眼與高眼壓症到落髮（Alopecia）

## 一句話總結

Bimatoprost 是前列腺素 F2α 類似物（prostamide），原本用於開角型青光眼與高眼壓症的治療。
TxGNN 模型預測分數最高的是結構性畸形症候群等項目，但這些預測缺乏證據支持。本報告以證據最完整的**落髮 (Alopecia)** 作為主要評估方向，目前有 **11 個臨床試驗**和 **20 篇文獻**支持這個方向，其中包含 3 個已完成的 Phase 2 試驗（共約 850 位受試者）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原廠機轉欄位為空）。根據已知資訊，Bimatoprost 是 prostamide／前列腺素 F2α 類似物，作用於毛囊的 FP 受體與 prostamide 受體。

臨床上，使用此類藥物治療青光眼的患者常出現睫毛變長、變濃的副作用。這一觀察促成了睫毛稀疏症的核准用途，並延伸到頭皮落髮的研究。其機轉被認為是延長毛髮生長期（anagen）並促進休止期轉入生長期。

不過，睫毛毛囊不受雄性素影響，頭皮毛囊則會，因此睫毛的療效不能直接類推到頭皮。頭皮落髮的療效目前尚未確立。

至於其他排名靠前的預測（如 Dandy-Walker 症候群、肺動靜脈畸形、牙周畸形症候群）沒有可辨識的機轉關聯，應視為知識圖譜的假象。Ambras 型多毛症則是 Bimatoprost 本身就會引起多毛，用藥只會加重而非治療。

## 安全性考量

- **知識圖譜標示的相關疾病（非仿單文字）**：肝病、膽囊疾病、葡萄膜炎、虹膜疾病、睫狀體疾病、全葡萄膜炎、黃斑部水腫、囊樣黃斑部水腫、虹膜炎。
- **藥物交互作用**：資料庫共查得 66 筆，例如 Calcitriol、Phentermine、Pantoprazole、Morphine、Metformin，但嚴重程度皆為未知，無法據以判斷臨床意義。
- **已知副作用**：睫毛與毛髮增生、眼瞼色素沉著（來自文獻摘要）。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails（僅限落髮方向）**

**理由：**
- 落髮方向有 3 個已完成、受試者數百人的 Phase 2 試驗，另有睫毛稀疏症的核准用途，證據等級為 L2。但頭皮療效尚未確立，且香港許可證目前並未涵蓋此用途。
- 其他預測（牙周畸形、Dandy-Walker、肺動靜脈畸形、Ambras 型多毛症等）無證據且無機轉依據，建議 Hold。頭皮遺傳性落髮與稀毛症僅列為研究問題（Research Question）。

**若要推進需要：**
- 取得 Phase 2 試驗（NCT01325337、NCT01325350、NCT01904721）的完整療效結果，確認是否優於安慰劑或 minoxidil。
- 補充作用機轉資料與香港仿單的警語與禁忌症。
- 評估外用頭皮劑型與現有眼用製劑的路徑差異，以及毛髮外用的安全性（含色素沉著與全身暴露）。
- 針對知識圖譜所列的相關疾病（如葡萄膜炎、黃斑部水腫）擬定篩選與監測計畫。
