## Bimatoprost：前列腺素 F2α 類似物（prostamide） → 顱面牙周畸形症候群 (malformation syndrome with odontal and/or periodontal component)
{: .text-alpha }

## 一句話總結

Bimatoprost 是一種前列腺素 F2α 類似物（prostamide），目前以眼用製劑形式在香港上市。
TxGNN 模型預測它可能對**伴有牙齒和/或牙周異常的畸形症候群 (malformation syndrome with odontal and/or periodontal component)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，bimatoprost 屬於前列腺素 F2α 類似物（prostamide），作用於 FP 與 prostamide 受體，在眼科用於降低眼壓，並因促進毛髮生長而被用於睫毛增生。

然而，這個預測的疾病是一種涉及牙齒與牙周結構的先天性畸形症候群。以現有資料來看，找不到可辨識的機轉連結：沒有試驗或文獻顯示 prostamide 類藥物對此類症候群性畸形有作用。高分僅反映模型的圖形式預測，不代表有生物學或臨床依據。

因此，這個預測目前只能視為假說，需要先有機轉或基礎研究支持，才有進一步評估的價值。
