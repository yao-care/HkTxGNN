# Bimekizumab：從（原適應症未載明）到糖尿病性白內障

## 一句話總結

Bimekizumab 是一種 IL-17A/IL-17F 雙重中和抗體（依一般藥理知識，DrugBank 的 MOA 欄位缺資料），目前在香港已上市。
TxGNN 模型預測它可能對**糖尿病性白內障 (Diabetic Cataract)** 有效，但**目前沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供 MOA）。依一般藥理知識，Bimekizumab 同時中和 IL-17A 與 IL-17F，屬於免疫調節型生物製劑。

IL-17 訊號與糖尿病併發症中的發炎反應有些鬆散的關聯，但與晶體混濁沒有已知的直接關係。糖尿病性白內障主要由高血糖、多元醇路徑和氧化壓力驅動，阻斷 IL-17 並不是公認的介入方式。

因此，這個高分較可能來自知識圖譜中鄰近節點的相似性，而不是真實的生物學證據。其他預測結果（成熟性、未成熟性、皮質性、核性、老年性白內障等各型白內障，以及第 2 型抗凝血酶缺乏症）同樣沒有機轉或臨床支持。多個白內障亞型重複出現高分，很可能是圖譜嵌入的系統性假象，應視為同一個未獲支持的假說，而非多個獨立訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測（L5），沒有臨床試驗、文獻，也找不到合理的機轉連結；抗 IL-17A/F 抗體不預期能逆轉晶體的結構性混濁，白內障目前的標準處置為手術。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症（目前為阻擋性資料缺口）
- 補齊 DrugBank 的作用機轉資料
- 檢索是否有 IL-17 訊號與晶體病變（特別是糖尿病性白內障）的前臨床研究，作為機轉依據
- 在有前臨床證據之前，不建議投入臨床試驗設計

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
