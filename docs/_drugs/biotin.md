# Biotin：從營養性生物素缺乏症到消化不良

## 一句話總結

Biotin（生物素）是一種水溶性維生素，原本用於治療營養性生物素缺乏症。
TxGNN 模型預測它可能對**消化不良 (Dyspepsia)** 有效，但目前**沒有臨床試驗**，僅有 **6 篇相關度偏低的文獻**，且無一直接評估生物素治療消化不良，證據相當薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知生物素是多種羧化酶的輔因子，參與碳水化合物、脂肪及胺基酸代謝，缺乏時可能出現腸胃道症狀。

因此，兩者之間最多只存在**間接關聯**：補充生物素可能改善與缺乏相關的腸胃不適。但這不等於對功能性消化不良有治療效果。目前取得的文獻主要涉及生物素缺乏、大腸急躁症的胃內分泌細胞、腸道菌群及幽門螺旋桿菌胃炎，沒有任何一篇評估生物素用於治療消化不良。

TxGNN 的高分可能反映知識圖譜中的鄰近關係，而非實際療效，仍需驗證。

另外，排名第二的預測為**輕癱 (Gastroparesis)**（分數 99.42%），同樣沒有臨床試驗或文獻支持，也無法從現有資料建立生物素與胃動力之間的合理關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自 TxGNN 模型分數，沒有臨床試驗，現有文獻也未評估生物素對消化不良的治療效果，證據等級為 L5。
- 作用機轉資料缺乏，且仿單的警語與禁忌資料尚未取得，無法進行安全性篩選。

**若要推進需要：**
- 取得生物素的作用機轉資料，釐清與消化不良的機轉關聯
- 下載並解析香港衛生署的仿單，補齊警語、禁忌與核准適應症
- 針對生物素與功能性消化不良進行系統性文獻回顧，確認是否存在直接證據
- 確認給藥途徑與劑型是否適合此新適應症（目前香港許可證多為注射劑與複方營養產品）
- 若有初步證據，再設計小型探索性臨床研究
