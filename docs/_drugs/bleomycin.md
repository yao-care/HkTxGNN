# Bleomycin：從惡性腫瘤化療到馬尾腫瘤

## 一句話總結

Bleomycin 是細胞毒性抗腫瘤藥物，香港許可證資料未載明原核准適應症。
TxGNN 模型預測它可能對**馬尾腫瘤 (Cauda Equina Neoplasm)** 有效，但目前**沒有臨床試驗**，只有 **3 篇間接相關的文獻**，且都不是直接測試 bleomycin 對此疾病的研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料。已知 Bleomycin 會透過依賴鐵離子的自由基反應造成 DNA 股斷裂，對快速增殖的腫瘤細胞在機轉上有殺傷可能，這是預測合理性的主要依據。

但這個預測有明顯限制。Bleomycin 的中樞神經與腦脊髓液穿透性差，本資料集中也沒有任何證據顯示它對脊髓或馬尾腫瘤有活性。TxGNN 分數只是知識圖譜的模型預測，不能取代實際研究。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，3 篇文獻都只是間接相關，且沒有一篇直接測試 bleomycin 對馬尾腫瘤的療效。
- Bleomycin 的中樞神經穿透性差，肺毒性也是重要的風險。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與核准適應症（目前為阻斷性資料缺口）。
- 補充詳細的作用機轉資料（例如查詢 DrugBank）。
- 進行針對脊髓或馬尾腫瘤的系統性文獻回顧，並評估鞘內或腫瘤內給藥等能繞過血腦屏障的途徑。

**補充說明：** 同一藥物的其他預測適應症中，「網狀細胞肉瘤」（歷史名詞，相當於侵襲性非何杰金氏淋巴瘤）的證據明顯較強，有多項 Phase 3 試驗，證據等級 L1。若要優先評估 Bleomycin 的再利用方向，建議從該適應症著手，但 bleomycin 在其中均與其他藥物併用，單獨療效無法分離，且現行標準治療（R-CHOP）已不含 bleomycin。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後才能應用。
