# Brigatinib：從 ALK 陽性非小細胞肺癌到牙齦纖維瘤病

## 一句話總結

Brigatinib（香港品名 ALUNBRIG）是 ALK 抑制劑，原本用於 ALK 陽性非小細胞肺癌。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效，預測分數很高。
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Brigatinib 是新一代 ALK 酪胺酸激酶抑制劑，在 ALK 陽性 NSCLC 的療效已有 Phase 3 試驗（ALTA-1L）證實。文獻也顯示它對 EGFR 等多種激酶有抑制作用。

不過，現有資料中沒有任何路徑把 Brigatinib 的作用連到牙齦纖維瘤病。牙齦纖維瘤病是牙齦組織纖維性增生的疾病，並非已知的 ALK 驅動疾病。

TxGNN 的高分主要來自知識圖譜的統計關聯，不代表已有生物學或臨床證據。目前只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.89%），但沒有臨床試驗、文獻或機轉證據，只有模型預測（L5）。
- 缺少仿單安全性資料，現階段無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌資料。
- 補充 DrugBank 的作用機轉資料。
- 文獻回顧：查證 ALK 或 Brigatinib 所抑制的其他激酶是否與牙齦纖維化有關。
- 目前資料中同一藥物的其他預測較值得優先看：
  - **NF2 相關神經鞘瘤病**：有 2024 年 NEJM 的臨床報告與前臨床研究，應另列為獨立適應症評估。
  - **肺良性腫瘤**：所列 20 篇文獻其實都是 NSCLC 研究，屬術語對應的假象，不能當作證據。
