# Brinzolamide：從青光眼與高眼壓到原發性遺傳性青光眼

## 一句話總結

Brinzolamide 是碳酸酐酶抑制劑（滴眼劑），臨床上用於降低眼內壓。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥理學一般知識，Brinzolamide 是碳酸酐酶 II 抑制劑，能減少睫狀體分泌房水，進而降低眼內壓。此說明來自一般藥理知識，並非 Evidence Pack 所提供的資料。

降低眼內壓是各類青光眼共通的治療目標，包括原發性先天性青光眼或青少年開放角青光眼等遺傳性類型，因此機轉上合理。

需要注意：0.995 的高分可能反映的是藥物本身已知的青光眼與高眼壓用途，也就是與既有適應症高度重疊，而不是真正新穎的再利用訊號。「原發性遺傳性青光眼」究竟是既有適應症的亞型，還是另一群獨立的病人族群，仍需釐清。兒童或先天性族群也需要另行評估安全性與療效。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有模型預測，沒有臨床試驗或文獻佐證（L5）。高分很可能來自藥物既有的青光眼用途，不一定是新的再利用發現。香港許可證也沒有登載適應症文字，無法確認預測的疾病是否已在核准範圍內。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌
- 釐清「原發性遺傳性青光眼」與現有適應症（青光眼、高眼壓）的關係
- 補充 Brinzolamide 的作用機轉資料（如 DrugBank）
- 檢索遺傳性、先天性或青少年青光眼的臨床與文獻證據
- 評估兒童族群的安全性與療效
