# Brolucizumab：從眼科抗 VEGF 治療到粒線體氧化磷酸化障礙

## 一句話總結

Brolucizumab 是一種玻璃體內注射的抗 VEGF-A 單鏈抗體片段，在香港以 BEOVU 品牌上市，標示用途為新生血管性年齡相關黃斑部病變（AMD）與糖尿病黃斑部水腫（DME）。TxGNN 模型預測它可能對**核 DNA 異常所致的粒線體氧化磷酸化障礙**有效。目前**沒有任何臨床試驗與文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Brolucizumab 是抗 VEGF-A 的單鏈抗體片段，以玻璃體內注射給藥，作用是阻斷 VEGF-A 訊號、抑制異常血管新生與血管滲漏。

核 DNA 異常所致的氧化磷酸化障礙，本質上是粒線體能量生成缺陷，與 VEGF-A 訊號路徑沒有已知交集。**我們沒有找到可信的機轉連結。** 0.997 的高分只是知識圖譜的關聯推論，沒有試驗或文獻佐證，不宜解讀為療效證據。

TxGNN 另外還預測了三個適應症，同樣只有模型分數，沒有任何試驗或文獻：

- **食道靜脈曲張（有出血、無出血）**，分數皆為 99.12%。VEGF 驅動的血管新生與門脈高壓、側枝血管形成有間接關聯，僅有前臨床層級的想法。但玻璃體內用藥難以轉用於此，全身性抗 VEGF 又有出血與血栓風險，對正在出血的族群尤其是疑慮。
- **外分泌型胰臟功能不全**，分數為 99.07%。沒有明確機轉連結，VEGF-A 阻斷並不能恢復腺泡細胞的消化酵素分泌。

## 結論與下一步

**決策：Hold**

**理由：**
- 四個預測適應症都只有 TxGNN 分數，沒有臨床試驗、文獻或可信的機轉連結，證據等級為 L5。
- 玻璃體內給藥與新適應症所需的給藥途徑不相容，全身性抗 VEGF 還有出血與血栓風險，因此目前不建議投入資源。

**若要推進需要：**
- 補齊 Brolucizumab 的作用機轉資料（如 DrugBank）。
- 取得香港衛生署仿單，確認警語、禁忌與核准適應症。
- 進行文獻與試驗檢索，確認粒線體疾病或門脈高壓模型中是否有抗 VEGF 的前臨床證據。
- 評估給藥途徑的可行性；若新適應症需要全身給藥，須先釐清安全性。
