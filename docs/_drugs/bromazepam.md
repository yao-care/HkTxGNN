# Bromazepam：從（原適應症未載明）到偏頭痛

## 一句話總結

Bromazepam 是一種苯二氮平類（benzodiazepine）藥物，在香港已有上市許可，但本報告所整理的資料中未載明其核准適應症。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前**沒有臨床試驗或文獻**支持，僅屬模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Bromazepam 屬苯二氮平類，作為 GABA-A 受體的正向異位調節劑，具有抗焦慮、肌肉鬆弛、鎮靜及抗痙攣作用。

與偏頭痛的可能關聯是間接的：降低神經元過度興奮、緩解肌肉緊繃，以及減輕可能誘發或加重發作的焦慮與壓力。

但需要強調，這個關聯目前只是假設，尚未被驗證。苯二氮平類並非偏頭痛的標準治療，且有依賴性、鎮靜，以及類似藥物過度使用的風險。0.99 的 TxGNN 分數僅代表計算模型的預測結果，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測（L5），沒有任何臨床試驗或文獻支持。
- 苯二氮平類不是偏頭痛的既有療法，且有依賴性與鎮靜等風險，機轉關聯仍屬假設。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症與完整的警語、禁忌症
- 補充詳細的作用機轉資料，釐清與偏頭痛的機轉關聯
- 系統性檢索 Bromazepam 或同類藥物用於偏頭痛的臨床試驗與文獻
- 評估與現有偏頭痛標準治療相比的風險效益，特別是依賴性與藥物過度使用問題
