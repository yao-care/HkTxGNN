# Bromazepam：從（未載明原適應症）到偏頭痛

## 一句話總結

Bromazepam 是一種苯二氮平類（benzodiazepine）藥物，在香港已上市，但本次資料未載明其核准適應症。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前僅有 **1 個間接相關的臨床試驗**，**沒有文獻**支持，屬於模型預測階段的候選。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，DrugBank 也未列出適應症。Bromazepam 屬於苯二氮平類，一般推定是 GABA-A 受體的正向異位調節劑，具有抗焦慮、鎮靜與肌肉鬆弛作用。

它與偏頭痛的關聯只是間接的。它可能緩解藥物過度使用型頭痛（MOH）患者在戒斷期間的焦慮、失眠或戒斷症狀。它不是已知的偏頭痛預防或急性發作機轉。

99.06% 的高分只是知識圖譜的預測，不是臨床證據。苯二氮平類還有依賴與反彈風險，一般不建議用於頭痛疾患，可能加重藥物過度使用的問題。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據只有模型預測，加上一個與 Bromazepam 關聯不明的小型 Phase 4 試驗，沒有文獻支持。
- 機轉上與偏頭痛的連結薄弱且屬間接，而苯二氮平類的依賴與反彈風險，在頭痛疾患中可能弊大於利。

**若要推進需要：**
- 確認 NCT04410536 是否使用 Bromazepam，以及其角色。
- 取得 Bromazepam 的作用機轉資料（可透過 DrugBank 查詢）。
- 取得香港衞生署的仿單，補齊警語、禁忌與核准適應症。
- 搜尋 Bromazepam 用於偏頭痛或 MOH 戒斷的臨床研究與文獻。
- 評估依賴、反彈與加重藥物過度使用的風險。
