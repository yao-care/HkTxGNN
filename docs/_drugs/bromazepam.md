# Bromazepam：從鎮靜/抗焦慮到偏頭痛

## 一句話總結

Bromazepam 是苯二氮平類（Benzodiazepine）藥物，透過增強中樞 GABAergic 抑制作用產生鎮靜與抗焦慮效果，目前在香港無上市登記。TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 具有潛在療效，預測分數達 **99.06%**；然而目前僅有 **1 個間接相關臨床試驗**，且完全缺乏直接支持文獻，整體證據基礎薄弱。

## 為什麼這個預測合理？

目前缺乏 Bromazepam 詳細的作用機轉資料（MOA）。根據已知藥物分類，Bromazepam 屬於**苯二氮平類藥物（Benzodiazepine）**，透過正向調節 GABA-A 受體，增強中樞神經系統的 GABAergic 抑制訊號，具有鎮靜、抗焦慮、肌肉鬆弛等藥理特性。

理論上，透過抑制中樞神經系統的過度興奮性，可間接干預偏頭痛相關的**皮質擴散性抑制（Cortical Spreading Depression, CSD）**路徑。這一推論邏輯或可解釋 TxGNN 模型給出高預測分數的機制依據。

然而此機轉連結屬於**高度間接推論**：偏頭痛的病理核心涉及 CGRP 釋放、三叉神經血管系統活化及 5-HT 路徑，與 GABA-A 受體調節的直接關聯性薄弱。加之 Bromazepam 在香港未上市、整體藥理資料極為有限，目前無法充分支撐機轉可信度的評估，需進一步查詢 DrugBank 及文獻加以確認。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 預測分數雖高（99.06%），但現有唯一臨床試驗與 Bromazepam 直接用於偏頭痛治療的關聯性極低，完全缺乏支持文獻，機轉連結亦屬高度間接推論。藥物在香港未上市、安全性與 MOA 資料雙重缺乏，目前不具備安全推進的基本條件。

**若要推進需要：**
- 補充 Bromazepam 完整 MOA 資料（建議查詢 DrugBank API，解決 DG002）
- 取得原廠仿單的警語、禁忌症及藥物交互作用資料（解決 DG001）
- 主動搜尋 Bromazepam 或其他苯二氮平類藥物用於偏頭痛（預防或急性治療）的直接前臨床或臨床研究
- 評估是否有苯二氮平類藥物（如 Diazepam、Clonazepam）之偏頭痛相關系統性回顧，作為機轉類比參考
- 確認香港或國際市場是否有已核准的偏頭痛適應症路徑可供銜接
