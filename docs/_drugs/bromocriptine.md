# Bromocriptine：從帕金森氏症與高泌乳素血症到先天性糖基化異常（岩藻糖基化缺陷型）

## 一句話總結

Bromocriptine 是多巴胺 D2 受體促效劑，原本用於帕金森氏症、高泌乳素血症及肢端肥大症。
TxGNN 模型預測它可能對**岩藻糖基化缺陷型先天性糖基化異常 (congenital disorder of glycosylation with defective fucosylation)** 有效（預測分數 99.83%），但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Bromocriptine 屬於 D2 多巴胺受體促效劑，在帕金森氏症、高泌乳素血症與肢端肥大症中的療效已被證實。

然而，多巴胺促效作用與岩藻糖基化（蛋白質糖修飾）途徑之間，目前沒有已知的連結。此預測分數雖高，但僅來自知識圖譜的推論，未找到可信的機轉依據。

整體而言，這個預測應視為假說，不宜視為已有支持的再利用方向。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單文字）：高血壓、肝病、膽囊疾病、冠狀動脈疾病、中風／腦血管疾病、腦梗塞、子癇前症（輕度與重度）、HELLP 症候群。
- **藥物交互作用**：共彙整 87 筆，以下為部分範例。
  - 嚴重 (Major)：Isometheptene、Lorcaserin
  - 中度 (Moderate)：Morphine、Clarithromycin、Metoclopramide、Promethazine、Ethanol、Dronabinol 等

其他警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自模型（證據等級 L5），沒有臨床試驗或文獻，也找不到多巴胺促效與岩藻糖基化之間的機轉連結。
- 此藥已有多項知識圖譜標示的心血管與肝臟相關禁忌，在缺乏療效依據下不宜推進。

**若要推進需要：**
- 釐清 Bromocriptine 的作用機轉資料，並評估與糖基化途徑是否有合理連結
- 進行細胞或動物模型的前臨床驗證
- 取得香港仿單的警語與禁忌資訊，完成安全性篩選
- 若仍想探索其他方向，可另行評估排名較後的預測（例如精神分裂症合併糖尿病前期的小型試驗），但需留意 Bromocriptine 可能誘發精神症狀的風險
