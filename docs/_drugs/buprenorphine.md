# Buprenorphine：從（原適應症未載明）到急性間歇性紫質症

## 一句話總結

Buprenorphine（丁基原啡因）是一種鴉片類藥物，在香港有 Temgesic 與 Suboxone 等 4 張許可證，但資料中未載明原適應症。
TxGNN 模型預測它可能對**急性間歇性紫質症 (Acute Intermittent Porphyria)** 有效，
但目前**沒有臨床試驗**，僅有 **1 篇病例報告**，且內容屬於麻醉管理，並非療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Buprenorphine 屬於鴉片類藥物，Suboxone 為其與另一成分的複方舌下錠，但資料中沒有原適應症，無法建立原適應症與新適應症之間的關聯。

現有資料不支持任何機轉上的連結。99.41% 的分數僅是知識圖譜的預測結果。唯一的一篇文獻是急性間歇性紫質症病人的麻醉管理病例，屬於術中安全性的情境，不能當作治療有效的證據。紫質症患者用藥安全是另一個問題，與老藥新用的療效無關。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗，唯一文獻是麻醉管理病例報告，不能證明療效。
- 作用機轉與原適應症都缺資料，無法評估預測的合理性；安全性資料（警語、禁忌）也仍有缺口，尚無法進入安全性篩選。

**若要推進需要：**
- 從 DrugBank 補齊作用機轉（MOA）
- 從香港衛生署下載並解析仿單，取得原適應症、警語與禁忌症
- 針對急性間歇性紫質症，確認 buprenorphine 的紫質生成風險與療效文獻
- 若有意評估其他預測適應症，需先做針對性的文獻檢索
