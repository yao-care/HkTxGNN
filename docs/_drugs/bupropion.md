## Bupropion：去甲腎上腺素與多巴胺再攝取抑制劑 → 注意力不足過動症 (attention deficit-hyperactivity disorder)
{: .text-alpha }

## 一句話總結

Bupropion 是一種去甲腎上腺素與多巴胺再攝取抑制劑。
TxGNN 模型預測它可能對**注意力不足過動症 (attention deficit-hyperactivity disorder)** 有效，
目前有 **6 個臨床試驗**和 **18 篇文獻**與此方向相關，其中包含 1 個已完成的 Phase 3 隨機對照試驗。

## 為什麼這個預測合理？

Bupropion 的主要作用機轉是抑制去甲腎上腺素與多巴胺的再攝取，不具血清素活性。（本次整理的資料中缺乏詳細的作用機轉欄位，此處根據文獻綜述中的一般說法。）

注意力不足過動症的核心病理與腦內去甲腎上腺素及多巴胺系統功能失調有關，興奮劑與 atomoxetine 等既有療法也是作用在這些路徑上。因此 bupropion 在機轉上有合理的適用性，文獻綜述也將其列為興奮劑無效或不耐受時的非興奮劑選項之一。

需要注意的是，目前的臨床試驗多為共病物質使用障礙的特殊族群，對一般 ADHD 族群的直接證據主要來自一項 Phase 3 試驗。

## 安全性考量

- **藥物交互作用**：本次整理的資料顯示有大量交互作用紀錄，其中屬「嚴重 (Major)」等級者包括 fentanyl、lidocaine、dihydrocodeine、codeine、tramadol、methylphenidate、hydrocortisone、aldesleukin、alfentanil、amantadine 等；中度者包括 chlorpheniramine、nifedipine、alprazolam、ethanol、hydrochlorothiazide 等。
- **使用時需留意的風險**：癲癇發作風險（與劑量相關）、血壓監測，以及在物質使用或飲食障礙患者中須謹慎；CYP2D6 抑制相關的交互作用負擔也較大。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有 1 個已完成的 Phase 3 隨機雙盲安慰劑對照試驗直接在成人 ADHD 測試 bupropion，另有多個 Phase 2/3、Phase 4 試驗與 Cochrane 系統性回顧，且機轉上與既有 ADHD 療法相近。
- 由於僅有 1 個已完成的 Phase 3 試驗，且其他試驗多為共病族群，故證據等級為 L2；同時癲癇與血壓風險及大量藥物交互作用需設置防護措施。

**若要推進需要：**
- 取得 NCT00048360 的完整結果與對照組設計，確認療效幅度
- 取得香港衛生署核准仿單的警語與禁忌症
- 補充詳細作用機轉資料
- 制定癲癇風險、血壓監測與併用藥物（特別是阿片類與 methylphenidate）的篩檢與管理計畫
- 評估在無物質使用共病的一般 ADHD 族群中的療效與安全性
