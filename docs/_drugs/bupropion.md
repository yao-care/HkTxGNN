# Bupropion：從憂鬱症到注意力不足過動症 (ADHD)

## 一句話總結

Bupropion 是一種去甲腎上腺素與多巴胺再吸收抑制劑（NDRI），文獻記載其用於憂鬱症與戒菸。
TxGNN 模型預測它可能對**注意力不足過動症 (Attention Deficit-Hyperactivity Disorder)** 有效，
目前有 **8 個 ADHD 相關臨床試驗**（其中 5 個為直接相關的已完成試驗）和 **20 篇文獻**支持這個方向，包含 1 篇 Cochrane 系統性回顧與多篇網絡統合分析。

## 為什麼這個預測合理？

目前缺乏資料庫中的詳細作用機轉欄位，但依已知藥理，Bupropion 是 NDRI，沒有血清素活性。它抑制去甲腎上腺素與多巴胺的再吸收，藉此增強中樞的兒茶酚胺訊號。

ADHD 的病理與前額葉的多巴胺、去甲腎上腺素功能失調有關。核准的 ADHD 用藥（如興奮劑、atomoxetine）也是作用在同一條路徑。Bupropion 作用於相同的機轉類別，但不是興奮劑，因此常被視為興奮劑無效或無法耐受時的非興奮劑替代選項。

TxGNN 分數極高（0.9999），與上述機轉上的合理性一致。不過各指引多將它定位為二線或仿單外使用，而非首選。

## 安全性考量

- **藥物交互作用**：資料庫查詢無紀錄，並不代表沒有交互作用。
- **評估建議的防護重點**（來自預測評估，非仿單內容）：
  - 癲癇風險，且與劑量相關。
  - 患有飲食障礙，或正處於酒精、苯二氮平類藥物突然戒斷期者，不宜使用。
  - 需監測血壓。
  - 需留意與 CYP2D6 相關的藥物交互作用。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有 Phase 2/3、Phase 3 與 Phase 4 的 ADHD 相關試驗完成，另有 Cochrane 回顧與多篇網絡統合分析支持，機轉上也與核准的 ADHD 藥物同類。
- 但本藥在指引中多屬二線或仿單外使用，且癲癇風險等安全性限制明確，香港仿單資料也尚未取得。

**若要推進需要：**
- 確認 NCT00048360 是否為 Bupropion 的 Phase 3 隨機對照試驗。若確認，證據等級可升為 L1。
- 取得並解析香港衛生署仿單的警語與禁忌（目前為阻擋性資料缺口，須先補齊才能進入安全性篩選）。
- 補上 DrugBank 的正式作用機轉資料。
- 針對香港的核准劑型（緩釋與持續釋放錠）評估 ADHD 用法的劑量與監測計畫。
- 其他預測適應症處理：「ADHD 注意力不足型」屬 ADHD 的亞型，證據繼承自母適應症，僅列為研究問題；其餘 8 項（如 faciodigitogenital syndrome、chondromyxoid fibroma 等）無實質證據，建議暫緩（Hold）。
