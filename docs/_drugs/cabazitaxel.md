# Cabazitaxel：從原適應症（許可證未載明）到女性乳癌

## 一句話總結

Cabazitaxel 是一種半合成紫杉烷（taxane）類抗腫瘤藥物，香港已有多張許可證上市，但本次整理的許可證資料未載明核准適應症。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效，
目前**沒有臨床試驗登記**，有 **19 篇文獻**，其中多為前臨床研究或綜述，另有 1 項 Phase II 研究（GENEVIEVE）及其長期追蹤。

## 為什麼這個預測合理？

目前缺乏經資料庫確認的詳細作用機轉。根據已知資訊，Cabazitaxel 是半合成紫杉烷，可穩定微管並抑制有絲分裂紡錘體解聚，造成細胞有絲分裂停滯與死亡。

乳癌本來就是紫杉烷類（paclitaxel、docetaxel）的既有適應症，因此同類藥物作用於乳癌在機轉上合理。此外，Cabazitaxel 是 P-糖蛋白（P-gp）外排泵的較差受質，理論上可能對已出現紫杉烷抗藥性的乳癌仍有活性。

不過，現有文獻多為奈米粒子、脂質載體等製劑的細胞株或動物實驗，以及紫杉烷的一般性綜述，尚不足以直接支持臨床使用。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖然機轉上合理，且 TxGNN 分數很高，但目前沒有已登記的臨床試驗，文獻也以前臨床及綜述為主，僅有 GENEVIEVE 等少數 Phase II 或 Phase I/II 研究，證據等級為 L4。
- 此藥骨髓抑制風險高，且仿單安全性資料尚未取得，現階段宜列為研究問題而非推進臨床應用。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌
- 查證詳細作用機轉資料（如 DrugBank）
- 深入審閱 GENEVIEVE 試驗的療效與安全性結果，並評估相對於既有紫杉烷（paclitaxel、docetaxel）的臨床價值
- 針對紫杉烷抗藥性乳癌族群，規劃臨床試驗或進一步的臨床證據彙整
- 制定骨髓抑制與感染風險的監測計畫

**其他預測適應症備註：** 排名第 2 至第 10 的預測（鐮狀細胞相關疾病、HIV、甲狀腺機能亢進、神經母細胞瘤、類風濕性關節炎等）皆無臨床試驗或文獻支持，僅為模型預測（L5），建議暫緩（Hold）。其中各鐮狀細胞症候群分數完全相同，可能反映圖譜結構的共同假象，而非疾病特異性訊號。
