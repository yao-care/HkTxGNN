# Cabergoline：從多巴胺 D2 受體促效劑到垂體腺癌

## 一句話總結

Cabergoline 是一種多巴胺 D2 受體促效劑，已知可抑制垂體腫瘤細胞的荷爾蒙分泌與增生。
TxGNN 模型預測它可能對**垂體腺癌 (Pituitary Adenocarcinoma)** 有效，但目前沒有相關臨床試驗，只有 **3 篇個案報告**，其中 2 篇與此適應症無關，證據等級僅 **L4**。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。以現有資訊判斷，Cabergoline 透過 D2 受體抑制泌乳素細胞瘤及部分促腎上腺皮質素（ACTH）細胞瘤的荷爾蒙分泌與生長。對垂體腫瘤而言，這個機轉原則上說得通。

原適應症資料在許可證中未載明。但既有研究顯示，Cabergoline 已用於泌乳素瘤，也曾在無功能性腺瘤和庫欣氏病（Cushing's disease）的促皮質素腫瘤中被研究。垂體腺癌同屬垂體來源腫瘤，這是預測合理的基礎。

不過，這項預測的直接證據很薄弱。唯一相關的文獻是一篇異位 ACTH 分泌的個案報告，該患者使用 octreotide 或 cabergoline 治療。它並未證明 Cabergoline 對真正的垂體癌有益。目前的支持主要來自模型分數和機轉上的推論。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.06%），但這個適應症沒有臨床試驗，只有 1 篇間接相關的個案報告，實際證據仍停在 L4。
- 本次結論僅針對排名第一的垂體腺癌。同批預測中的「垂體癌 (Pituitary Cancer)」有多項 Phase 3 試驗和統合分析，但它們針對的是垂體腺瘤，也就是良性腫瘤，而非癌。這兩個預測應分開評估，不能把腺瘤的證據直接套用到腺癌。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症，並查詢 DrugBank 的作用機轉資料。
- 針對侵襲性垂體腫瘤或垂體癌，系統性檢索 Cabergoline 的病例系列或前瞻性研究。
- 確認研究族群及可接受的劑量，並規劃瓣膜病變（心臟超音波）與衝動控制障礙的監測。
