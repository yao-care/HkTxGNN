# Cabotegravir：從 HIV-1 感染到類風濕性關節炎

## 一句話總結

Cabotegravir 是 HIV-1 整合酶抑制劑，在香港以 Vocabria 品牌上市（錠劑與長效注射懸浮液）。
TxGNN 模型預測它可能對**類風濕性關節炎 (Rheumatoid Arthritis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cabotegravir 一般已知為 HIV-1 整合酶鏈轉移抑制劑，但本次資料未提供 MOA 內容。

現有資料未支持原適應症與類風濕性關節炎之間的機轉關聯。整合酶抑制作用與自體免疫性關節發炎之間沒有已建立的連結，因此 99.45% 的高分只能視為知識圖譜的模型預測，並無臨床試驗或文獻佐證。

其他排名前列的預測（硬化性膽管炎、支氣管炎、罕見發育症候群、重度非增殖性糖尿病視網膜病變）同樣缺乏機轉依據與證據，顯示高分可能反映知識圖譜結構的偏誤，而非生物學上的合理性。

**若要推進需要：**

- 從 DrugBank 補充作用機轉（MOA），評估與類風濕性關節炎的機轉關聯
