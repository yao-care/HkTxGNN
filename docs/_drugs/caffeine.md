# Caffeine：從頭痛／鼻炎到鼻腔疾病

## 一句話總結

Caffeine（咖啡因）原本用於偏頭痛、叢集性頭痛、過敏性鼻炎、感冒與咽炎等症狀的治療，常作為複方止痛藥的輔助成分。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，
但目前**無臨床試驗**，僅有 **3 篇間接文獻**（綜述、前臨床配方研究、動物實驗），證據相當薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，咖啡因是腺苷受體拮抗劑與磷酸二酯酶抑制劑，其在頭痛及鼻炎領域的使用已有一定歷史，機轉上可能與鼻腔組織有關聯。

原適應症中已包含過敏性鼻炎與血管運動性鼻炎，因此「鼻腔組織」與咖啡因之間存在合理的關聯。另一個可能的機轉線索是氣道中的苦味受體 (TAS2R)，咖啡因可活化這類受體，可能影響黏膜纖毛清除與局部先天免疫。

不過，這些都只是推論。目前僅有一項前臨床的鼻用咖啡因凝膠研究，探討的是睡眠剝奪後的認知改善，證明鼻腔給藥可行，但與鼻腔疾病治療無關。極高的 TxGNN 分數並沒有疾病特異性的臨床資料支持。

## 安全性考量

- **禁忌症（來自知識圖譜的藥物-疾病關聯，非仿單內容）：**
  - 心血管：高血壓、姿勢性低血壓、姿勢性直立心搏過速症候群、多系統萎縮、長 QT 症候群
  - 神經精神：癲癇、失眠、焦慮症、神經官能症、輕度憂鬱症
  - 肝腎胰膽：肝衰竭、肝病、腎病、膿輸尿管、胰臟炎、膽囊疾病
  - 腸胃與呼吸：胃潰瘍、消化性潰瘍、發炎性腸道疾病、慢性阻塞性肺病
  - 其他：紫質症、血小板減少症、甲狀腺功能低下（含黏液水腫）
- **藥物交互作用：** 共查得 75 筆。其中**重大 (Major)** 等級包括鼻用與外用古柯鹼 (Cocaine)；**中度 (Moderate)** 包括 Alosetron、Obeticholic acid、Adenosine、Anagrelide、Bendamustine、Capmatinib、Ciprofloxacin、Cycloserine、Dipyridamole、Duloxetine 等。使用 Adenosine 或 Dipyridamole 相關檢查時，咖啡因可能干擾結果。

其餘警語與仿單禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.91%），但沒有任何針對鼻腔疾病的臨床試驗，現有文獻僅為苦味受體綜述、鼻用配方的前臨床研究與動物實驗，證據等級僅為 L4。
- 咖啡因的禁忌族群廣泛（心血管、癲癇、肝腎等），且缺乏仿單層級的安全性資料，目前不宜推進。

**若要推進需要：**
- 補齊作用機轉資料（MOA）與香港仿單的警語及禁忌資訊
- 釐清「鼻腔疾病」的具體亞型（如過敏性鼻炎、慢性鼻竇炎等），並與現有已知適應症區分
- 進行針對鼻腔黏膜（含 TAS2R 路徑）的機轉與前臨床研究
- 評估鼻腔局部給藥的劑型可行性與局部／全身安全性
- 設計小規模探索性臨床試驗，取得疾病特異性的療效訊號
