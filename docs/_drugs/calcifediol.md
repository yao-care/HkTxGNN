# Calcifediol：從原適應症（許可證未載明）到維生素 D 缺乏症（已過時術語）

## 一句話總結

Calcifediol（25-羥基維生素 D）是體內主要的循環型維生素 D 代謝物，香港已有 2 張上市許可證，但許可證未載明原適應症。
TxGNN 模型預測它可能對**維生素 D 缺乏症（obsolete vitamin D deficiency）**有效，預測分數很高，但該疾病術語在本體論中已標為「過時」。
目前**沒有臨床試驗和文獻**支持這個預測，僅有模型預測（L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA）。從已知資訊看，Calcifediol 是維生素 D 的主要循環代謝物，與維生素 D 缺乏症在生物學上直接相關，因此預測方向合理。

但有三點需要謹慎：
- 「obsolete vitamin D deficiency」在本體論中被標為過時概念，可能是舊詞條或已合併的詞條。
- 高預測分數（0.9999）只是模型輸出，不等於臨床證據。
- 原適應症和作用機轉都沒有資料，無法做機轉層面的比對。

**同一藥物的其他預測適應症（僅供參考）：**

| 預測適應症 | TxGNN 分數 | 證據等級 | 說明 |
|-----------|-----------|---------|------|
| 腎小管酸中毒 | 99.86% | L4 | 僅有 3 篇舊文獻（1987–2001，個案報告與檢測方法）。Calcifediol 至多可能改善合併的骨病變，對酸中毒本身沒有作用。 |
| 遺傳性低磷佝僂病 | 99.76% | L4 | 僅有間接文獻，沒有直接評估 Calcifediol 的研究。此病的 1-α 羥化作用被抑制，Calcifediol 的效益可能僅限於矯正合併的營養性維生素 D 不足。 |
| 維生素 D 依賴型佝僂病 | 99.18% | L3 | 機轉最吻合。第 1B 型（25-羥化酶缺乏）的阻斷點正好被 Calcifediol 繞過。第 1A 型與第 2 型的缺陷在其下游，預期幫助有限。 |

上述 L3/L4 分級僅依標題判定，需以全文核實。

## 安全性考量

安全性資訊請參考原廠仿單。香港衛生署仿單的警語與禁忌症尚未取得，藥物交互作用查詢也無結果。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測適應症只有模型分數，沒有任何臨床試驗或文獻，且疾病術語已過時，無法評估臨床價值。
- 安全性資料缺口屬於阻斷級，目前無法進入安全性篩選。

**若要推進需要：**
- 將「obsolete vitamin D deficiency」重新對應到現行的維生素 D 缺乏症概念，再重跑證據收集。
- 補齊作用機轉（MOA）：從 DrugBank 查詢。
- 取得香港衛生署仿單，補齊警語、禁忌症與適應症。
- 若要往維生素 D 依賴型佝僂病 1B 型推進，先以全文核實相關文獻，再評估是否設計 Calcifediol 的直接研究。目前該方向也只是研究問題（Research Question），尚無 Phase 2/3 RCT。
