## Calcitriol：活性維生素 D 類似物 → 已淘汰的維生素 D 缺乏症 (obsolete vitamin D deficiency)
{: .text-alpha }

## 一句話總結

Calcitriol 是活性型維生素 D（1,25-二羥維生素 D3），用於調節鈣磷代謝。
TxGNN 模型預測它可能對**已淘汰的維生素 D 缺乏症 (obsolete vitamin D deficiency)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Calcitriol 是維生素 D 的活性形式，因此與維生素 D 缺乏在生物學上有明顯關聯，這也是模型給出高分的可能原因。

但此預測有兩個問題。第一，該疾病術語在本體論中已被標記為「已淘汰」，預測很可能只是舊術語造成的結果。第二，營養性維生素 D 缺乏通常以 cholecalciferol 或 ergocalciferol 補充，並非以 calcitriol 為首選。

整體而言，這個預測缺乏臨床證據支持，不宜視為有效的再利用方向。

  - 重大等級：Cholecalciferol、Calcifediol、Burosumab（其他維生素 D 類製劑或磷調節藥物，合併使用有高血鈣、高血磷等風險）
  - 中度等級：Hydrochlorothiazide 等噻嗪類利尿劑、Digoxin、Carbamazepine、Fosphenytoin、巴比妥類、含鋁抗酸劑、膽酸結合劑（Cholestyramine、Colestipol、Colesevelam）

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測雖分數很高（0.9996），但沒有任何臨床試驗或文獻，證據等級僅為 L5。
- 疾病術語已被淘汰，且營養性缺乏本就有更常用的維生素 D 製劑，因此不建議投入資源。

**若要推進需要：**
- 確認此疾病術語在現行分類中對應的疾病，並明確定義目標族群
- 取得 calcitriol 與 cholecalciferol 等標準療法的比較資料
- 取得作用機轉資料與香港仿單的警語及禁忌資訊
- 在有任何臨床或文獻證據之前，維持觀察
