# Calcitriol：從高血鈣與磷代謝異常到遺傳性低磷佝僂病

## 一句話總結

Calcitriol 是活性型維生素 D，原本用於高血鈣、腎鈣質沉著症、磷代謝異常、低磷血症、副甲狀腺低下及腎性骨病變等鈣磷代謝相關疾病。
TxGNN 排名第一的預測是「已過時的維生素 D 缺乏症」，但該疾病術語已被淘汰，且沒有任何試驗或文獻支持。本報告因此另以證據最完整的**遺傳性低磷佝僂病 (Hereditary Hypophosphatemic Rickets)** 作為重點評估對象，目前有 **2 個臨床試驗**和 **19 篇文獻**，但沒有 Phase 3 RCT。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Calcitriol 是維生素 D 的活性代謝物，主要作用是促進腸道吸收鈣與磷，並調節副甲狀腺素。這些作用與其原有的鈣磷代謝適應症相符。

**排名第一的預測（維生素 D 缺乏症）：** Calcitriol 是活性型維生素 D，兩者在生物學上有關聯，這可能是高分的原因。不過該疾病術語已被標為過時，也沒有檢索到任何試驗或文獻。營養性缺乏通常使用 cholecalciferol 或 ergocalciferol，而非 calcitriol。因此這項預測較可能是舊版本體論術語造成的假象。

**遺傳性低磷佝僂病：** 以 X 連鎖低磷血症 (XLH) 為例，FGF23 過量會抑制腎臟 1-α 羥化酶與磷再吸收，造成內源性 calcitriol 偏低。Calcitriol 搭配磷補充劑是長期的標準治療，與原適應症中的低磷血症、磷代謝異常相符。目前的研究問題在於 burosumab 等新療法出現後，calcitriol 的最佳劑量與定位。

**其他預測：** 腎小管酸中毒 (L4) 的文獻多為個案報告與敘述性回顧，主要描述 calcitriol 濃度或相關骨病，未顯示 calcitriol 對疾病本身的療效。家族性孤立性副甲狀腺低下屬於原適應症的延伸，僅有模型預測。其餘三項預測（Campailla-Martinelli 型肢中段發育不良、顱面錐形發育不良、Dahlberg-Borer-Newcomer 症候群）找不到明確機轉連結，檢索到的文獻也與疾病本身無關，應視為檢索雜訊。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：腎臟疾病、輸尿管積膿、類肉瘤病、高血鈣、腎鈣質沉著症、磷代謝異常、腎結石、急性尿酸腎病變、高磷血症、維生素過多症、閉塞性動脈硬化。這些來自知識圖譜的藥物—疾病關聯，並非仿單內容，實際使用請以原廠仿單為準。
- **藥物交互作用**：共查詢到 100 筆，以下為其中的重點。
  - 重度：Cholecalciferol、Calcifediol、Burosumab。
  - 中度：Fosphenytoin、Carbamazepine、巴比妥類（Amobarbital、Butalbital、Butabarbital）、噻嗪類利尿劑（Hydrochlorothiazide、Chlorothiazide 等）、Digoxin、Digitoxin、膽酸結合劑（Cholestyramine、Colesevelam、Colestipol）、含鋁制酸劑、外用 Calcipotriol。
  - 其中 Burosumab 為 XLH 的新療法，與 calcitriol 屬重度交互作用，考慮併用或替換時需特別留意。

仿單警語與禁忌的完整內容，請參考原廠仿單。

## 結論與下一步

**決策：Hold（排名第一的預測）；遺傳性低磷佝僂病建議 Proceed with Guardrails**

**理由：**
- 排名第一的預測（維生素 D 缺乏症）沒有任何臨床證據，疾病術語已過時，不建議推進。
- 遺傳性低磷佝僂病中，calcitriol 搭配磷補充是長期的傳統治療，機轉合理，但直接證據僅有一個小型 Early Phase 1 研究與一個狀態未知的 Phase 4 研究，沒有 Phase 3 RCT，且已有 burosumab 等替代療法。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料（目前為資料缺口）。
- 補充詳細的作用機轉資料。
- 與 burosumab 比較 calcitriol 的最佳劑量與定位，並設計更高等級的對照研究。
- 建立高血鈣、高尿鈣與腎臟鈣化的監測計畫（尤其是腎臟疾病與腎結石族群）。
- 確認劑型與給藥途徑的相容性（目前尚未評估）。
