# Calcium Glycerophosphate：從原適應症未登載到鈣鹼症候群

## 一句話總結

Calcium Glycerophosphate（甘油磷酸鈣）是一種鈣與有機磷的補充來源，在香港以 AMINOLEBAN 系列口服粉劑上市，但許可證未登載原適應症。
TxGNN 模型預測它可能對**鈣鹼症候群 (Calcium-alkali syndrome)** 有效，但目前**沒有臨床試驗與文獻**支持，這很可能是知識圖譜的假關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Calcium Glycerophosphate 是鈣與甘油磷酸的鹽類，臨床上常作為鈣和磷的補充來源。

鈣鹼症候群（又稱乳鹼症候群）是因攝取過量鈣與鹼性物質所引起。因此，以鈣為主要成分的藥物，較可能是風險因子，而非治療選項。機轉上找不到合理的治療路徑。

TxGNN 的高分（0.9995）反映的是知識圖譜中節點的相近程度，不代表治療效益。我們判斷這個預測**很可能是模型的假關聯**。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有任何臨床試驗或文獻，證據等級為 L5。
- 鈣鹼症候群本身由過量鈣攝取引起，機轉上不合理。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症。
- 補充 DrugBank 的作用機轉資料。
- 建議把研究重心轉向同一藥物的其他預測。**低磷血症 (Hypophosphatemia)** 的證據等級為 L4，建議定位為研究問題（Research Question）。
  - 甘油磷酸鹽在體內水解釋出無機磷，且可避免與鈣在腸道外營養液中沉澱。
  - 有 2 項早產兒腸道外營養的世代研究（PMID 35007810、36255046），但它們評估的是甘油磷酸鈉，並非鈣鹽，屬間接證據。
  - 有 2 項低磷血症相關的登記試驗，但都未確認使用甘油磷酸鈣。
  - 若要推進，需釐清甘油磷酸鈣是否適合作為新生兒腸道外營養或重症照護中的磷來源。
