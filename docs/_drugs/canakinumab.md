# Canakinumab：從痛風與週期性發燒症候群到家族性地中海熱（顯性遺傳型）

## 一句話總結

Canakinumab 是一種抗介白素-1β (IL-1β) 的單株抗體，原本用於痛風、冷吡啉相關週期性症候群 (CAPS)、幼年型特發性關節炎等疾病。
TxGNN 模型預測它可能對**家族性地中海熱（顯性遺傳型，Familial Mediterranean Fever, autosomal dominant）**有效，
目前有 **3 個 Phase 3 臨床試驗**和 **20 篇文獻**支持這個方向。
不過需注意，家族性地中海熱本身已列在此藥的原適應症中，這比較接近既有適應症的延伸，而非全新的再利用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，canakinumab 是 IL-1β 中和型單株抗體，能直接阻斷 IL-1β 的訊號傳遞，在多種自體發炎疾病中的療效已被證實。

家族性地中海熱 (FMF) 由 MEFV 基因的功能增強突變引起，造成 pyrin 發炎體失調，進而過度釋放 IL-1β。因此直接中和 IL-1β，在機轉上有很強的合理性。

目前 FMF 的第一線治療是秋水仙素 (colchicine)，但約 5–10% 的患者無反應或無法耐受。對這群秋水仙素抗藥或不耐受的患者，抗 IL-1 藥物是替代選擇。多項系統性回顧與統合分析支持這個用法。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- FMF 已在 canakinumab 的原適應症之列，有 Phase 3 試驗（以 CAPS 為主）和多篇系統性回顧支持抗 IL-1 治療，機轉也相當明確。
- 但缺乏 FMF 專屬的 Phase 3 RCT 資料，且香港許可證的核准適應症文字未能取得，需先確認本地標示範圍。

**若要推進需要：**
- 取得香港仿單，確認核准適應症、警語與禁忌症
- 以秋水仙素抗藥或不耐受的患者作為主要對象
- 建立感染風險監測與長期安全性追蹤計畫
- 補充詳細的作用機轉資料（MOA）

### 附註：其他預測適應症

資料中的其他預測多為 L5（僅有模型預測）：肝梗塞、肝靜脈阻塞症、肝紫斑症、肝血管肉瘤等皆無臨床試驗或文獻，建議 Hold。Blau 症候群 (L3) 有小型病例系列支持，可列為研究問題；複合免疫缺陷症候群 (L4) 僅有一篇 CAPS 病例報告，並未證明對該疾病有效。單一 X 染色體 (monosomy X) 的檢索文獻皆為無關匹配，並無可信的機轉連結。
