# Candesartan Cilexetil：從 ARB 類降血壓藥到惡性腎血管性高血壓

## 一句話總結

Candesartan Cilexetil 是血管張力素 II 第一型受體阻斷劑（ARB），在香港已上市，但本次提供的資料沒有載明原適應症。
TxGNN 模型預測它可能對**惡性腎血管性高血壓 (Malignant Renovascular Hypertension)** 有效。
目前**沒有臨床試驗**，也沒有直接相關的文獻，這個預測僅來自模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Candesartan 屬於 ARB 類藥物，透過阻斷血管張力素 II 第一型受體，抑制腎素-血管張力素系統（RAS）的作用。

腎血管性高血壓的主要驅動力，正是 RAS 活化。因此從藥物類別來看，用 ARB 阻斷這條路徑，在機轉上說得通。

不過這個推論只建立在藥物類別和模型分數上，沒有任何試驗或文獻直接佐證。
雙側腎動脈狹窄或單一腎臟的患者使用 ARB，可能誘發急性腎損傷，安全性必須先評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數，沒有臨床試驗與文獻支持（L5），僅能視為研究假設。
- 腎血管性高血壓患者使用 ARB 有急性腎損傷的風險，且本次缺乏仿單層級的安全資料。
- 另有一筆相近預測「惡性高血壓性腎病」，分數相同，很可能是相關的本體節點，兩者不能視為獨立證據。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌症與適應症
- 補充 DrugBank 作用機轉資料
- 針對 ARB 用於腎血管性高血壓，做專項文獻搜尋，包括病例報告與觀察性研究
- 評估腎功能與高血鉀的監測方案，並特別排除雙側腎動脈狹窄或單一腎臟的患者
