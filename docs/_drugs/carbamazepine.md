# Carbamazepine：從癲癇與三叉神經痛到三叉神經腫瘤

## 一句話總結

Carbamazepine（卡巴馬平）是常用的抗癲癇藥，原本用於癲癇、躁鬱症及三叉神經痛等適應症。
TxGNN 模型預測它可能對**三叉神經腫瘤 (trigeminal nerve neoplasm)** 有效，但目前**沒有臨床試驗**，僅有 **18 篇文獻**（多為個案報告與回顧）。這些文獻多半是腫瘤造成三叉神經痛、再以本藥緩解症狀，並非證明它能對抗腫瘤本身。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，carbamazepine 屬於鈉離子通道阻斷型的抗癲癇藥，對部分性發作、全身性強直陣攣發作及三叉神經痛等神經病變性疼痛有確立療效。

三叉神經腫瘤（如神經鞘瘤、腦膜瘤、淋巴瘤、皮樣囊腫）常會壓迫神經而引發繼發性三叉神經痛，因此 carbamazepine 可能緩解**症狀**。但沒有證據顯示它對腫瘤本身有作用。

這個高分更可能反映模型中它與「三叉神經痛」在語意上的相近，而不是真正的抗腫瘤效果。因此，這個預測應解讀為「症狀緩解」，而非「治療腫瘤」。

## 安全性考量

- **知識圖譜標示的禁忌或需謹慎疾病**（非仿單文字）：
  - 血液系統：血小板低下、嗜中性球低下、顆粒球缺乏症、全血球低下、貧血
  - 肝腎疾病：肝病、腎臟病、腎功能不全
  - 心血管：心臟傳導疾病、房室傳導阻滯、冠狀動脈疾病、心因性猝死、高血壓
  - 眼科：青光眼、高眼壓
  - 其他：抗利尿激素分泌不適當症候群、失神性癲癇
- **藥物交互作用**：已查得 100 筆。其中列為嚴重（Major）的包括 **Clarithromycin** 與 **Eliglustat**。另有多項中度交互作用，如 Doxycycline、類固醇（Hydrocortisone、Dexamethasone 等）、Bupropion、Aprepitant、Morphine、Metronidazole、Cimetidine。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗，文獻多為個案報告，且不少案例顯示 carbamazepine 對腫瘤相關疼痛效果有限或後來失效。
- 它的作用僅限於症狀（神經痛）控制，沒有抗腫瘤證據，高 TxGNN 分數可能是語意相近造成。

**若要推進需要：**
- 釐清真正的研究問題：是「腫瘤相關三叉神經痛的症狀控制」，而非「抗腫瘤治療」。
- 針對腫瘤相關繼發性三叉神經痛，進行系統性回顧或回溯性世代研究。
- 補齊作用機轉資料及香港仿單的警語、禁忌與核准適應症。
- 若用於腫瘤患者，需評估血液學與肝腎功能風險，以及與化療藥物的交互作用。
