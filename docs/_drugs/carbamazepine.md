## Carbamazepine：鈉離子通道阻斷型抗癲癇藥 → 三叉神經腫瘤 (trigeminal nerve neoplasm)
{: .text-alpha }

## 一句話總結

Carbamazepine 是一種抗癲癇與神經痛藥物，在香港已有多張單一成分許可證上市。
TxGNN 模型預測它可能對**三叉神經腫瘤 (trigeminal nerve neoplasm)** 有效，但目前沒有臨床試驗，文獻也只是病例報告與三叉神經痛的綜述，並未直接研究以 carbamazepine 治療該腫瘤。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。一般認為 carbamazepine 作用於鈉離子通道，可抑制神經異常放電，因此對神經痛有效。

三叉神經的腫瘤（如神經鞘瘤、腦膜瘤、淋巴瘤、皮樣囊腫）常以三叉神經痛為首發表現，病人因此可能被處方 carbamazepine。所以 carbamazepine 或許能緩解這類腫瘤引起的疼痛症狀。

但沒有證據顯示它對腫瘤本身有抗腫瘤作用。高分數較可能反映的是與三叉神經痛在語意與網絡上的接近，而非真正的抗腫瘤效果。多篇病例報告也顯示，在腫瘤引起的神經痛中，carbamazepine 常常效果不佳或逐漸失效，最終仍須手術處理腫瘤。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗或文獻直接研究 carbamazepine 對三叉神經腫瘤本身的作用，證據等級為 L5。
- 它最多只能緩解腫瘤引起的神經痛症狀，高預測分數很可能反映與三叉神經痛的語意接近，而非抗腫瘤機轉。

**若要推進需要：**
- 釐清臨床目標：是症狀控制（神經痛），還是抑制腫瘤。
- 若目標是抗腫瘤，需有前臨床證據（如細胞或動物模型）。
- 取得詳細作用機轉資料與香港仿單的警語和禁忌症。
- 若僅用於症狀控制，應與既有的三叉神經痛適應症區分，不視為新的藥物再利用。
