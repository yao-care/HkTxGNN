# Carbenoxolone：從（原適應症資料未登載）到非症候群性食道畸形

## 一句話總結

Carbenoxolone 是一種源自甘草的藥物，香港有 1 張外用凝膠製劑許可證，但許可證上沒有登載適應症。
TxGNN 模型預測它可能對**非症候群性食道畸形 (Non-syndromic Esophageal Malformation)** 有效，分數很高（99.9988%）。
但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測，證據等級為 L5。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Carbenoxolone 是甘草衍生物，歷史上用於食道與胃潰瘍等上消化道黏膜疾病，作用偏向黏膜保護。

食道畸形是先天性結構異常，黏膜保護作用無法解釋為何能治療這類問題。這個高分較可能來自知識圖譜的拓撲關係（例如共享鄰居節點），而不是已驗證的生物學關聯。

因此，這個預測目前只能視為待驗證的假說，機轉上的合理性不足。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測完全來自模型，沒有臨床試驗、文獻或機轉資料佐證。
- 已知藥理與先天性食道畸形之間缺乏合理連結。
- 香港許可證也未登載適應症與安全性資料，無法進一步評估。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料，再重新評估機轉連結。
- 針對食道畸形，以及較有推測空間的膽管疾病，做系統性文獻檢索。
- 評估給藥途徑相容性：現有香港製劑為外用凝膠，是否適用於食道或膽道疾病尚未評估。
