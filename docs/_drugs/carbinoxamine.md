# Carbinoxamine：從第一代 H1 抗組織胺到過敏性蕁麻疹

## 一句話總結

Carbinoxamine 是第一代 H1 抗組織胺，但本次提供的資料未列出原適應症。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效。
目前有 **0 個臨床試驗**和 **0 篇文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Carbinoxamine 屬於第一代 H1 抗組織胺。蕁麻疹的核心機轉是組織胺驅動的肥大細胞活化，因此阻斷 H1 受體在機轉上合理。

需要留意，這個預測可能更接近已知或既有的用途，而不是真正的老藥新用。但輸入資料沒有列出原適應症和機轉，無法從現有資料確認。TxGNN 分數只是模型預測，不等於臨床證據。

其他預測適應症如下，證據等級皆為 L5，決策皆為 Hold：

|------|-----------|-----------|-----------|
| 2 | 寒冷性蕁麻疹 (Cold Urticaria) | 99.96% | 組織胺介導的物理性蕁麻疹，H1 抗組織胺是標準第一線藥物類別。但沒有 Carbinoxamine 專屬證據，類別層級的合理性不能當作該藥的證據 |
| 3 | 鼻腔疾病 (Nasal Cavity Disease) | 99.88% | 疾病名稱過於籠統。H1 阻斷可能緩解過敏性或血管運動性鼻炎症狀，但無法評估 |
