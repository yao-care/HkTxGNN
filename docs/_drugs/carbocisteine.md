# Carbocisteine：從呼吸道黏液異常（祛痰）到痛風

## 一句話總結

Carbocisteine（羧甲司坦）一般作為黏液溶解劑（祛痰藥）使用，在香港已有多張上市許可證。
TxGNN 模型預測它可能對**痛風 (Gout)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型層級的推測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。輸入資料未提供 Carbocisteine 的 MOA，也沒有登錄原適應症，因此無法把 TxGNN 的高分追溯到具體的生物路徑。

一般認為 Carbocisteine 是黏液溶解劑，並有抗氧化與抗發炎活性的相關報告。急性痛風發作涉及嗜中性白血球與氧化壓力驅動的發炎反應，所以這兩者之間可能有關聯。

不過，現有資料中沒有任何證據顯示它會影響尿酸生成、腎臟尿酸排泄，或結晶誘發的發炎反應。以上僅是推測，需要獨立驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有臨床試驗、文獻或已知機轉支持，證據等級僅 L5。
- 原適應症與作用機轉資料缺漏，也無法確認痛風與祛痰用途之間的關聯。

**若要推進需要：**
- 取得香港衞生署核准仿單，確認適應症、警語與禁忌症
- 補齊 DrugBank 的作用機轉資料，並評估與尿酸代謝或痛風發炎路徑的關聯
- 系統性檢索 PubMed、ClinicalTrials.gov 與 ICTRP，確認是否有痛風相關的前臨床或臨床研究
- 若找到機轉或前臨床證據，再重新評估是否進入下一階段
