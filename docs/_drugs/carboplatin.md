# Carboplatin：從卵巢癌到女性乳癌

## 一句話總結

Carboplatin（卡鉑）是含鉑的 DNA 交聯類化療藥，原本用於卵巢癌及相關婦科惡性腫瘤的治療。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效，
目前有 **多項臨床試驗**（其中包含已完成的 Phase 3 試驗）和 **多篇文獻**（含多項隨機對照試驗）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Carboplatin 是鉑類 DNA 交聯劑，其在卵巢癌中的療效已被證實。這類藥物對同源重組修復缺陷（HRD，例如 BRCA 突變）的腫瘤特別敏感。

卵巢癌與三陰性乳癌、BRCA 相關乳癌在生物學上有共通點，都與 DNA 修復缺陷有關。這是 Carboplatin 在兩種癌症中都有活性的合理解釋。多項隨機新輔助治療試驗（GeparSixto、CALGB 40603、BrighTNess）顯示，在三陰性乳癌中加入 Carboplatin 可提高病理完全緩解率 (pCR)。不過，對長期存活的助益較不一致，且會增加血液毒性，需要妥善管理。

## 安全性考量

- **知識圖譜所列的禁忌相關疾病**（來源為知識圖譜，非仿單文字）：腎臟疾病、肝臟疾病、膽囊疾病、血小板低下、嗜中性白血球低下、顆粒球缺乏症、白血球低下、貧血、凝血疾病、周邊神經疾病／周邊神經病變、聽力障礙／聽覺系統疾病、功能性視力喪失。
- **藥物交互作用**：共查得 100 筆。主要為中度等級，例如：
  - 氫離子幫浦抑制劑（Rabeprazole、Omeprazole、Esomeprazole、Lansoprazole、Pantoprazole、Dexlansoprazole）
  - 胺基糖苷類及相關抗生素（Kanamycin、Neomycin、Streptomycin、Vancomycin）
  - Metronidazole、Tinidazole
  - Rosuvastatin、Simvastatin
  - 另有 Levofloxacin（輕微）及數項等級未知者

仿單的警語與禁忌資訊尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有多項已完成的 Phase 3 試驗和隨機對照試驗，尤其是三陰性乳癌的新輔助治療，顯示加入 Carboplatin 可提高病理完全緩解率。
- 長期存活獲益的證據不一致，且血液毒性明顯，因此需要在適當的族群中、搭配嚴密監測使用。

**若要推進需要：**
- 取得香港仿單中的警語、禁忌與核准適應症文字
- 補充詳細的作用機轉資料（MOA）
- 明確界定目標族群（如三陰性乳癌、BRCA 突變、HER2 陽性）並確認長期存活證據
- 制定血液學監測與劑量調整計畫，並考慮腎功能與藥物交互作用

---

**其他預測適應症簡述（證據較弱）：**
- **成人生殖細胞腫瘤**（分數 99.24%，L2）：Carboplatin 在高劑量救援方案與精原細胞瘤中有應用，證據以 Phase 1/2 及系統性回顧為主。部分試驗屬神經膠質瘤，與此適應症無關，且在非精原細胞瘤中療效可能不及 Cisplatin。建議 Proceed with Guardrails。
- **子宮內膜混合型腺癌**（分數 99.20%，L1）：Carboplatin/Paclitaxel 是晚期或復發子宮內膜癌的標準化療骨幹，Phase 3 試驗探討的是加入免疫或 HER2 治療，而非 Carboplatin 單獨效果。建議 Proceed with Guardrails。
- **子宮頸黏液性腺癌、子宮內膜黏液性腺癌**（L3）：僅有小型 Phase 1 試驗與病例報告，列為研究性問題。
- **直腸黏液性腺癌、結腸黏液性腺癌、膽囊黏液性腺癌、肝外膽管黏液性腺癌、絨毛腺型子宮內膜樣腺癌**：多為僅有模型預測或僅有病例報告，缺乏特定證據，建議 Hold。
