# Carfilzomib：從（原適應症未載明）到黑色素瘤

## 一句話總結

Carfilzomib 是不可逆的蛋白酶體抑制劑，在香港以 KYPROLIS 注射劑上市，但本次資料未載明其核准適應症。
TxGNN 模型預測它可能對**黑色素瘤 (Melanoma)** 有效。
目前**沒有臨床試驗**，僅有 **5 篇文獻**，且皆為細胞、機轉或電腦模擬的前臨床研究。

## 為什麼這個預測合理？

Carfilzomib 是不可逆的蛋白酶體抑制劑，作用於 20S 蛋白酶體的 beta-5 次單位。DrugBank 的 MOA 欄位在本次資料中缺漏，此處機轉描述來自預測資料中的推論說明。蛋白酶體被抑制後，細胞內蛋白質堆積，產生蛋白毒性壓力，可誘發癌細胞凋亡。

黑色素瘤細胞理論上對蛋白酶體抑制有一定依賴，這是模型預測的機轉基礎。現有文獻中，最直接的是一篇 2021 年研究：carfilzomib 併用 bortezomib，可在小鼠 B16-F1 黑色素瘤細胞中增強凋亡。

但這些證據都很間接。細胞株結果不等於臨床療效，目前沒有黑色素瘤的人體療效或安全性資料。葡萄膜與黏膜（如外陰）黑色素瘤在生物學上不同於皮膚黑色素瘤，前臨床訊號不能直接外推。軟腦膜疾病還有一個未解問題：carfilzomib 能否進入中樞神經，資料中並未確立。

## 結論與下一步

**決策：Hold**

**理由：**
黑色素瘤只有前臨床證據（細胞株、機轉、電腦模擬），沒有臨床試驗，也沒有人體資料，屬 L4。其餘四個預測適應症僅有模型分數（L5）。TxGNN 分數是模型輸出，不是臨床證據。此外，香港仿單的警語與禁忌資料尚缺，安全性篩選無法進行。

**若要推進需要：**
- 取得香港衛生署 KYPROLIS 仿單，補齊警語、禁忌症與核准適應症
- 補齊 carfilzomib 的作用機轉（DrugBank）
- 在人類黑色素瘤細胞株或動物模型中驗證單用與併用的效果
- 分亞型（皮膚、葡萄膜、黏膜）評估，並確認中樞神經穿透性後，再考慮軟腦膜黑色素瘤
- 檢索黑色素瘤相關臨床試驗登記與人體研究，再重新評估證據等級

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
