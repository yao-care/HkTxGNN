# Carteolol：從眼用 β 阻斷劑到原發性遺傳性青光眼

## 一句話總結

Carteolol 是非選擇性 β 腎上腺素阻斷劑，香港已有眼藥水劑型上市，但現有資料未載明原核准適應症。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。以下說明來自一般藥理知識，並非輸入資料所提供。Carteolol 屬於非選擇性 β 阻斷劑。眼用 β 阻斷劑透過抑制睫狀體的房水生成來降低眼壓，這個機轉原則上適用於各種病因的青光眼。

需要注意的是，Carteolol 在許多市場已用於開放性青光眼與高眼壓症。因此 0.999 的高分可能只是反映同類藥物既有的青光眼用途，而不是真正的新用途訊號。

至於遺傳性或先天性青光眼亞型（包含兒童使用）是否適用，目前沒有任何證據可以佐證。β 阻斷劑在嬰幼兒也有全身性安全疑慮，例如心搏過緩與支氣管痙攣。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有模型預測（L5），沒有臨床試驗或文獻。高分很可能反映 β 阻斷劑在青光眼的既有用途，並非針對遺傳性青光眼的新證據。仿單與安全性資料也尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌症
- 從 DrugBank 補齊作用機轉 (MOA) 資料
- 檢索 Carteolol 用於遺傳性或先天性青光眼（含兒童族群）的臨床試驗與文獻
- 釐清此預測與已知的開放性青光眼適應症有何區別
- 評估劑型與給藥途徑的相容性
