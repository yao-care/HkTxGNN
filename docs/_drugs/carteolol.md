# Carteolol：從高血壓與開角型青光眼到原發性遺傳性青光眼

## 一句話總結

Carteolol 是一種非選擇性 β 受體阻斷劑，原本用於高血壓、開角型青光眼與高眼壓。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏來自藥物資料庫的詳細作用機轉資料。以下說明根據一般藥理知識推論：Carteolol 是帶有內在擬交感活性的非選擇性 β 腎上腺素受體阻斷劑，已被用於開角型青光眼與高眼壓，透過減少房水生成來降低眼壓。

原發性遺傳性青光眼與已核准的青光眼適應症在病理上有共同點，都涉及眼壓升高。這很可能是 TxGNN 給出高分（99.92%）的原因，因為在知識圖譜中，兩者與已核准適應症距離很近。

不過需要謹慎看待。遺傳性青光眼（例如與 MYOC、CYP1B1 或 FOXC1 變異相關的先天性或青少年型青光眼）常伴有前房角結構異常（小樑網發育不良）。這類病人使用 β 受體阻斷劑通常只是輔助或手術前的暫時性措施，而非根本性治療。目前也沒有針對遺傳性青光眼的機轉證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有臨床試驗或文獻佐證，且遺傳性青光眼多伴結構性異常，β 受體阻斷劑多半只能作為輔助。
- 香港仿單的安全性資料與作用機轉資料尚缺。

**若要推進需要：**
- 取得並解析香港衛生署仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉資料
- 系統性檢索遺傳性青光眼（先天性、青少年型）使用 carteolol 或其他 β 受體阻斷劑的臨床與文獻證據
- 確認製劑與給藥途徑適用於目標族群，特別是兒童病人
- 評估心肺相關禁忌（氣喘、心衰竭、房室傳導阻滯等）對目標族群的影響
