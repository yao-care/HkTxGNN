# Carvedilol：從心血管用藥到惡性腎血管性高血壓

## 一句話總結

Carvedilol 是非選擇性 β 阻斷劑，兼具 α1 阻斷作用，已在香港上市。
TxGNN 模型預測它可能對**惡性腎血管性高血壓 (Malignant Renovascular Hypertension)** 有效。
目前**沒有臨床試驗和文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Carvedilol 是非選擇性 β 阻斷劑，並帶有 α1 阻斷作用，可以降低血壓。β1 阻斷還能減少腎素釋放。

腎血管性高血壓的病理與腎素-血管張力素系統活化有關，因此降壓與抑制腎素在機轉上說得通。

但這個預測有明顯限制：
- 0.995 的分數只是知識圖譜的推論，不是臨床證據。
- 惡性高血壓屬於緊急狀況，通常用可滴定的靜脈注射藥物處理，口服 Carvedilol 的角色尚未被證實。

同時預測的「惡性高血壓性腎臟病」分數完全相同（99.55%），較可能是兩者在圖譜中位置相近，不是各自獨立的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測（L5），沒有任何臨床試驗或文獻。
- 惡性高血壓是緊急狀況，口服 β 阻斷劑並非常規選項，目前只能視為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症，並確認原適應症與作用機轉。
- 系統性檢索 Carvedilol 用於腎血管性高血壓或惡性高血壓的臨床與文獻證據，包括病例報告。
- 評估口服 Carvedilol 與現行急性降壓處置的適用性和角色。
- 補完藥物交互作用查詢，目前查無資料。

**其他預測適應症（供參考）：**
- 「肺高壓（肺部疾病／缺氧所致）」、「病因不明的多因素肺高壓」與「Braddock 症候群」同樣只有 L5 證據，建議皆為 Hold。
- 肺高壓項下檢索到的文獻只是一般缺氧生物學，並未提及 Carvedilol。
- 非選擇性 β 阻斷劑用於缺氧性肺病或肺高壓時，可能有支氣管痙攣和右心功能惡化的疑慮，需審慎評估。

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後才能應用。
