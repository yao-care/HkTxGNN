# Caspofungin：從抗真菌治療到胃泌素分泌異常

## 一句話總結

Caspofungin 是一種 echinocandin 類抗真菌藥物，目前資料庫中缺乏原適應症的記載。
TxGNN 模型預測它可能對**胃泌素分泌異常 (Gastrin Secretion Abnormality)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Caspofungin 屬於 echinocandin 類抗真菌藥，作用是抑制真菌細胞壁的 β-(1,3)-D-葡聚醣合成酶。

但這個預測在機轉上**並不合理**。哺乳動物細胞沒有這個標的，也沒有已知路徑能連結到胃泌素分泌、G 細胞功能或胃酸調節。此外，Caspofungin 為靜脈注射，口服生體可用率差，因此也難以透過局部作用影響腸胃道。

99.44% 的高分只是模型輸出，可能反映的是知識圖譜的拓撲結構，而非真實的生物學關係，尤其是原藥的作用機轉與適應症在資料中皆為空白。目前沒有獨立證據支持此預測。

## 結論與下一步

**決策：Hold**

**理由：**
預測僅來自模型分數，沒有任何臨床試驗或文獻佐證，機轉上也找不到合理連結。Caspofungin 的作用標的（真菌葡聚醣合成酶）在人體不存在，與胃泌素調節無關。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料（目前為阻斷性缺口，無法進入安全性篩選）
- 補齊原適應症與作用機轉資料（可查詢 DrugBank）
- 找到獨立的機轉或前臨床證據，說明 Caspofungin 如何影響胃泌素分泌
- 確認給藥途徑是否與目標疾病相容（目前為靜脈注射）
