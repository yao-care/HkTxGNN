# Cefditoren：從細菌感染到骨關節炎易感性（預測缺乏證據支持）

## 一句話總結

Cefditoren 是第三代口服頭孢菌素類抗生素，原本用於細菌感染治療。
TxGNN 模型預測它可能對**骨關節炎易感性 (Osteoarthritis Susceptibility)** 有效，
但目前**沒有任何臨床試驗與文獻**支持，屬於純模型預測，且機轉上找不到合理關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。依藥物分類，Cefditoren 是第三代頭孢菌素，
透過結合細菌的青黴素結合蛋白 (PBP)，抑制細菌細胞壁合成而殺菌。

「骨關節炎易感性」是一種遺傳易感性特徵，並非抗菌藥可以處理的藥物靶點。
Cefditoren 沒有已知的軟骨保護、止痛或抗發炎作用，因此**機轉上找不到合理的關聯**。

TxGNN 給出 99.16% 的高分，較可能反映知識圖譜中節點的相近性，而非實際生物學關係。
本報告列出的前 10 個預測（包含類風濕性關節炎、骨關節炎、血紅素病變及多種罕見骨骼發育不良症候群）都有相同問題：
0 個臨床試驗、0 篇文獻，機轉上亦無合理依據。
