# Cefpodoxime：從抗菌治療到退化性關節炎易感性

## 一句話總結

Cefpodoxime 是第三代頭孢菌素類抗生素，在香港已有 2 張上市許可證。
TxGNN 模型預測它可能對**退化性關節炎易感性 (Osteoarthritis Susceptibility)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，僅為模型輸出。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥物分類，Cefpodoxime 是第三代頭孢菌素，透過結合青黴素結合蛋白 (PBP) 抑制細菌細胞壁合成，屬於抗菌作用。

抗菌機轉與退化性關節炎的病理（關節軟骨退化、發炎、基因易感性）之間，目前找不到已知的關聯。同時，本藥的香港許可證也沒有提供核准適應症文字，無法比對原適應症與新適應症的關係。

TxGNN 給出高分，較可能來自知識圖譜的拓撲結構（例如與骨骼、關節疾病共享鄰近節點），而非實際的生物學機轉。因此這個預測在機轉上**缺乏支持**，應視為待驗證的模型訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.35%），但沒有臨床試驗、文獻或合理的作用機轉支持，證據等級僅為 L5。
- 同一份預測清單中的前 10 名（包括骨關節炎、類風濕性關節炎、多種罕見骨骼發育不良症）也都是 L5、無任何證據，整體看來像是模型的圖譜偏差。

**若要推進需要：**
- 取得香港衞生署仿單，補齊核准適應症、警語與禁忌（目前為阻斷性資料缺口）。
- 從 DrugBank 補齊作用機轉資料，以評估是否有任何可能的機轉連結。
- 進行系統性文獻檢索，確認是否有抗生素與退化性關節炎的前臨床或觀察性研究。
- 在取得上述資料前，不建議投入資源做進一步的臨床開發。
