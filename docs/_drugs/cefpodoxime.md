## Cefpodoxime：從細菌感染到骨關節炎
{: .text-alpha }

## 一句話總結

Cefpodoxime 是第三代口服頭孢菌素類抗生素，已在香港取得許可證。
TxGNN 模型預測它可能對**骨關節炎 (Osteoarthritis)** 有效（另預測類風濕性關節炎），
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cefpodoxime 是第三代口服頭孢菌素，一般認為透過結合青黴素結合蛋白（PBP）抑制細菌細胞壁合成，用於細菌感染。

骨關節炎主要是退化性、非感染性疾病，與抗菌機轉缺乏明確關聯。Cefpodoxime 並無已知的抗發炎、軟骨保護或止痛作用。此高分來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，而非生物學證據。

第二個預測適應症為**類風濕性關節炎**（分數 0.9924）。同樣缺乏證據：Cefpodoxime 不作用於 TNF、IL-6、JAK/STAT 或 B/T 細胞訊號等自體免疫路徑。需注意，化膿性關節炎是不同的疾病，不應與類風濕性關節炎混為一談。

## 結論與下一步

**決策：Hold**

**理由：**
兩個預測適應症（骨關節炎、類風濕性關節炎）都只有模型分數，沒有臨床試驗或文獻佐證，機轉上也缺乏合理連結，證據等級為 L5。

**若要推進需要：**
- 取得 Cefpodoxime 的作用機轉資料，並評估與關節疾病的生物學關聯
- 系統性檢索是否有針對骨關節炎或類風濕性關節炎的前臨床或臨床研究
- 取得香港衛生署核准的仿單，確認適應症、警語與禁忌症
- 若有機轉假說支持，再設計前臨床驗證，之後才考慮臨床試驗
