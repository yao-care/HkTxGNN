# Ceftolozane：從細菌感染治療到淋菌性尿道炎

## 一句話總結

Ceftolozane 是一種頭孢菌素類抗生素，在香港以 ZERBAXA（與 tazobactam 的複方）上市。
TxGNN 模型預測它可能對**淋菌性尿道炎 (Gonococcal urethritis)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ceftolozane 是 β-內醯胺類頭孢菌素，與 tazobactam（β-內醯胺酶抑制劑）組成複方，對革蘭氏陰性菌有活性。其他頭孢菌素已被用於治療淋病奈瑟菌 (*Neisseria gonorrhoeae*) 感染，所以從藥物類別來看有一定合理性。

但這只是類別效應的推論。本次提供的資料中沒有 Ceftolozane 對淋病奈瑟菌的感受性數據，也沒有任何臨床資料。

需要特別留意的是，「淋菌性尿道炎」與「Ureaplasma 尿道炎」的預測分數完全相同（99.89%）。這表示分數可能來自知識圖譜中「尿道炎」節點的鄰近關係，而不是 Ceftolozane 本身的訊號。因此不宜把高分直接當成療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（淋菌性尿道炎）沒有任何試驗或文獻，證據等級為 L5，且高分可能是圖譜鄰近效應造成。
- 香港仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症資料。
- 補充 Ceftolozane/tazobactam 對淋病奈瑟菌的體外感受性數據（MIC）。
- 補充 DrugBank 的作用機轉資料。
- 在現行淋病治療指引下評估其定位，因為既有的注射頭孢菌素已有明確地位。
- 若要優先探索，可先看黃色肉芽腫性腎盂腎炎（L4），但需先釐清抗生素在此病中僅為輔助角色。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
