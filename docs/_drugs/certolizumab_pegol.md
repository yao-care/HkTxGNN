# Certolizumab Pegol：從克隆氏症到類風濕性血管炎

## 一句話總結

Certolizumab pegol 是一種 PEG 化、不含 Fc 段的抗 TNF-α 抗體片段，原本用於克隆氏症、類風濕性關節炎、乾癬性關節炎與僵直性脊椎炎等免疫發炎疾病。
TxGNN 模型預測排名第一的新適應症為**類風濕性血管炎 (Rheumatoid Vasculitis)**，但目前僅有 **7 篇文獻**（皆為個案報告、藥物不良反應報告或間接研究）、**0 個臨床試驗**，且多篇文獻顯示此藥反而可能誘發血管炎，證據薄弱且有安全疑慮。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，certolizumab pegol 是 PEG 化的抗 TNF-α Fab 片段，能選擇性中和 TNF-α。類風濕性血管炎是嚴重類風濕性關節炎的併發症，發炎過程與 TNF 相關，因此從機轉上看，TNF 阻斷有一定合理性。

然而文獻結果並不一致。一篇個案報告描述此藥改善了類風濕性血管炎所致的腿部潰瘍，但另有多篇報告指出 certolizumab（及其他抗 TNF 藥物）反而可能引起血管炎、蕁麻疹性血管炎或腎絲球腎炎。這種「矛盾性」抗 TNF 誘發血管炎是已知的不良反應，削弱了機轉上的支持，也帶來安全疑慮。

此外，高預測分數很可能源自此藥已確立的類風濕性關節炎適應症，而非獨立的證據。

## 安全性考量

- **藥物交互作用**：共查詢到 100 筆交互作用，以下為主要項目。
  - 重大 (Major)：Hydrocortisone、Prednisolone、Prednisone、Dexamethasone、Betamethasone、Budesonide、Triamcinolone（含眼用劑型）等皮質類固醇，以及 Deferiprone、Ibritumomab tiuxetan、Iobenguane (I-131)、Tositumomab (I-131)
  - 中度 (Moderate)：Metronidazole、Tinidazole、Rosuvastatin、Simvastatin、Pegvaliase
  - 輕微 (Minor)：醋酸鋅、葡萄糖酸鋅、硫酸鋅
- **與本預測相關的安全疑慮**：文獻顯示 certolizumab 可能引起矛盾性血管炎、蕁麻疹性血管炎與腎絲球腎炎，用於血管炎族群需特別審慎。
- **一般抗 TNF 風險**：嚴重感染、結核病再活化、脫髓鞘病變（來自證據評估資料）。

其餘警語與禁忌症資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 類風濕性血管炎僅有一篇正面個案報告，且有多篇報告指出 certolizumab 可能誘發血管炎，證據薄弱、風險與效益方向矛盾。
- 高 TxGNN 分數可能反映的是既有類風濕性關節炎適應症，而非獨立證據。

**若要推進需要：**
- 補充詳細的作用機轉資料（MOA）與香港仿單的警語、禁忌症
- 系統性評估抗 TNF 誘發血管炎與治療血管炎的風險效益
- 設計針對類風濕性血管炎的前瞻性研究或病例系列，釐清療效與安全性
- 若重點在高證據等級的方向：「發炎性脊椎病變」(L1) 與多關節型幼年類風濕性關節炎 (L2) 值得進一步評估，但前者大多與現有適應症重疊，需先確認是否已涵蓋於現行仿單，後者則需取得對照試驗的療效資料
