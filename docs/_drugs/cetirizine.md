# Cetirizine：從 H1 抗組織胺過敏用藥到過敏性蕁麻疹

## 一句話總結

Cetirizine 是第二代 H1 抗組織胺，香港已有多張許可證上市，但許可證資料未載明適應症文字。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效。
目前有 **3 個臨床試驗**和 **18 篇文獻**，但沒有已完成的確證性 Phase 3 試驗。多數文獻是綜述，部分談的是其他抗組織胺藥物。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cetirizine 是選擇性的周邊 H1 受體拮抗劑。蕁麻疹的風團和搔癢主要由肥大細胞釋放的組織胺引起，阻斷 H1 受體正好作用在這條路徑上。

需要留意，這個預測可能不算真正的「老藥新用」。Cetirizine 在許多國家已標示用於蕁麻疹，此處原適應症資料為空，較可能是既有或已確立的用途。建議先確認香港許可證的標示範圍。

## 安全性考量

- **停藥後反應**：有個案報告指出，長期使用 cetirizine 後停藥，可能出現反彈性搔癢與蕁麻疹（PMID 41602253）。這只是個案證據，尚無大型研究確認。

主要警語、禁忌症與藥物交互作用資料目前皆缺。安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 機轉上 H1 阻斷直接對應蕁麻疹的組織胺路徑，且有一個已完成的 Phase 3 先導試驗（n=36）和多篇綜述支持。
- 但該試驗是可行性研究，不是確證性 RCT，證據停在 L2。
- 香港許可證缺乏適應症文字和安全性資料，需先補齊。

**若要推進需要：**
- 取得香港衛生署許可證與仿單，確認蕁麻疹是否已是核准適應症。這也是取得警語與禁忌症資料的前提。
- 補充作用機轉資料（例如查詢 DrugBank）。
- 找出或設計以 cetirizine 為主體的蕁麻疹確證性 RCT，並確認 NCT02023164 的後續 Phase 3 結果。
- 其他預測適應症目前證據較弱，建議先不推進：寒冷性蕁麻疹為 L3、鼻腔疾病為 L4，均屬研究問題；急性喉咽炎、酒糟性結膜炎、頑固性異位性皮膚炎僅有模型預測（L5），建議暫緩。

*本報告僅供研究參考，不構成醫療建議；預測結果需經臨床驗證後才能應用。*
