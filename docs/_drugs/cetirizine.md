## Cetirizine：H1 抗組織胺藥 → 鼻腔疾病 (nasal cavity disease)
{: .text-alpha }

## 一句話總結

Cetirizine 是一種抗組織胺藥物，常見於過敏性症狀的治療。
TxGNN 模型預測它可能對**鼻腔疾病 (nasal cavity disease)** 有效，
目前**沒有臨床試驗**，僅有 **5 篇文獻**（多為綜述與不直接針對本藥的研究）作為背景參考。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cetirizine 屬於 H1 受體拮抗劑（抗組織胺藥），而 H1 受體存在於神經末梢、平滑肌與腺體細胞，競爭性阻斷組織胺結合是此類藥物的主要作用方式。

鼻腔黏膜的充血、腫脹與黏液分泌，部分由組織胺介導，因此 H1 阻斷在機轉上可能減輕鼻腔發炎與症狀。文獻中的綜述也討論了 H1 抗組織胺藥在過敏性鼻炎及相關上呼吸道發炎的角色。

不過，「鼻腔疾病」是範圍很廣的類別，所蒐集的文獻多為一般性綜述、其他藥物的前臨床研究，以及一篇中藥動物實驗，並沒有針對 Cetirizine 與特定鼻腔疾病的直接研究。因此這項預測目前只能視為模型提示，需要先縮小到更具體的疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何直接研究 Cetirizine 用於鼻腔疾病的臨床試驗或文獻，現有文獻多為綜述與其他藥物的前臨床研究，證據僅達 L5（模型預測）。
- 「鼻腔疾病」範圍過廣，無法據此設計具體的評估方向。

**若要推進需要：**
- 將預測縮小為具體且非現有標示的鼻腔疾病亞型
- 取得詳細的作用機轉資料
- 針對該亞型的 Cetirizine 臨床或觀察性研究
- 香港仿單的警語與禁忌症資料，以完成安全性篩選
