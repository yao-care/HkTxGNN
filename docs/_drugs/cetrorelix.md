# Cetrorelix：從輔助生殖用藥到多毛症

## 一句話總結

Cetrorelix 是 GnRH 受體拮抗劑，香港的許可證資料未載明原適應症（一般已知用於輔助生殖的卵巢刺激療程）。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cetrorelix 是 GnRH 受體拮抗劑，會競爭性阻斷腦下垂體的 GnRH 受體，快速抑制 LH/FSH，並降低下游性荷爾蒙。

**這個預測的機轉連結薄弱。** 多毛症 (Hypertrichosis) 的定義是與雄性素無關的毛髮過度生長，這一點和雄性素依賴的多毛症 (Hirsutism) 不同。抑制性荷爾蒙軸，理論上不會改善這類毛髮表現。0.9998 的高分較可能來自知識圖譜中相近毛髮疾病節點的關聯，不代表有實質療效訊號。

**其他預測適應症的評估：**
- 排名 2、5、7（Ambras 型先天性全身多毛症、遺傳性毛幹異常、家族性睫毛過長）：成因是結構蛋白或基因調控異常，與荷爾蒙軸無關，判斷為圖譜關聯的假象。
- 排名 3、4、6（牙周相關畸形症候群、Dandy-Walker 相關症候群、新生兒持續性肺高壓）：找不到機轉連結。
- 排名 8、9（家族性男性限定性早熟、芳香環轉化酶過量症候群）：成因分別是 LHCGR 活化突變和 CYP19A1 功能增益，都不由 GnRH 驅動。標準治療分別是抗雄性素加芳香環轉化酶抑制劑，以及直接的芳香環轉化酶抑制劑。
- **排名 10（中樞性性早熟 1 型，分數 99.29%）是機轉上最合理的預測。** 中樞性性早熟源於下視丘-腦下垂體-性腺軸過早活化，Cetrorelix 可直接阻斷該軸。但標準治療是長效 GnRH 促效劑，Cetrorelix 作用時間短、需頻繁注射，且未檢索到長效劑型或兒童試驗資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測（多毛症）沒有任何臨床或文獻證據，機轉上也缺乏合理連結，僅為模型預測（L5）。
- 十個預測中只有「中樞性性早熟」在機轉上說得通，可另列為研究問題，但仍缺乏直接證據，且現有標準治療（長效 GnRH 促效劑）已相當成熟。

**若要推進需要：**
- 取得香港衛生署的仿單，確認原適應症、警語與禁忌症。
- 從 DrugBank 補齊作用機轉 (MOA) 資料。
- 針對「中樞性性早熟」做前臨床或藥理文獻回顧，評估 GnRH 拮抗劑用於兒童性腺抑制的可行性，並確認是否有長效劑型。
- 針對首位預測（多毛症）不建議投入資源，除非找到新的機轉證據。
