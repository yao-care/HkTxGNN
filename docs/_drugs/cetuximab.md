# Cetuximab：從 EGFR 標靶抗腫瘤治療到軟骨樣錯構瘤

## 一句話總結

Cetuximab 是一種抗 EGFR 的單株抗體，在香港以 Erbitux 輸注溶液上市。
TxGNN 模型預測它可能對**軟骨樣錯構瘤 (Chondroid Hamartoma)** 有效，分數很高，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cetuximab 已知會阻斷 EGFR（表皮生長因子受體）訊號，在 EGFR 表現的上皮性腫瘤中有標靶治療的基礎。

不過，現有資料中沒有任何內容顯示軟骨樣錯構瘤依賴 EGFR 訊號。這個預測只來自 TxGNN 的高分。在良性病灶上使用會引起輸注反應和皮膚毒性的生物製劑，風險效益也需要審慎評估。原適應症與新適應症的相似性尚待評估，機轉上是否適用目前無法確認。

補充：本次資料包中的臨床試驗（NCT00896896，n=538）與個案報告（PMID 39415301）顯示，Cetuximab 有輸注過敏反應風險。另有回溯性研究（PMID 30141310）討論其皮膚反應。這些僅為風險提示，並非完整警語。

## 結論與下一步

**決策：Hold**

**理由：**
- 軟骨樣錯構瘤沒有任何試驗或文獻支持，只有模型分數。
- 香港仿單的警語與禁忌資料也尚未取得，無法進入安全性篩選。

**其他預測適應症的參考：**
- 「囊性腫瘤 (Cystic Neoplasm)」證據等級 L3。相關試驗多為實體瘤 Phase 1 與腺樣囊性癌 (adenoid cystic carcinoma) 研究，疾病對應有歧義。
- 「癌前病變 (Pre-malignant Neoplasm)」證據等級 L4。相關試驗多為已確立的惡性腫瘤，屬間接證據。
- 「會厭腫瘤 (Epiglottis Neoplasm)」可能與已核准的頭頸部鱗狀細胞癌重疊，需先與仿單適應症對照。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症。
- 補充 DrugBank 作用機轉資料。
- 檢索 EGFR 在軟骨樣錯構瘤的表現與功能證據，確認機轉合理性。
- 確認疾病映射是否正確，避免與其他腫瘤標籤混淆。
- 尚無任何臨床證據前，不建議進入臨床評估。
