# Chenodeoxycholic Acid：從腦腱黃瘤症到同型合子家族性高膽固醇血症

## 一句話總結

Chenodeoxycholic Acid（CDCA，鵝去氧膽酸）是一種膽酸，已知用於腦腱黃瘤症 (CTX)。
TxGNN 模型預測它可能對**同型合子家族性高膽固醇血症 (Homozygous Familial Hypercholesterolemia, HoFH)** 有效。
目前**沒有臨床試驗**，僅有 **1 篇文獻**（且是 CTX 的綜述，並非 HoFH 研究），證據非常薄弱。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。CDCA 是天然膽酸，其在 CTX 中的用途已被接受。CTX 是膽酸合成障礙（CYP27A1 基因突變），會造成膽固醇醇 (cholestanol) 等固醇類物質異常堆積。CDCA 可透過 FXR 介導的回饋機制，抑制肝臟膽酸合成 (CYP7A1/CYP27A1)。

這使 CDCA 與膽固醇代謝之間有「合理但間接」的關聯，也是模型給出高分的可能原因。

不過，這個推論有明顯限制：

- 唯一的引用文獻是 CTX 綜述，沒有任何 HoFH 專屬的臨床資料。
- 有報告指出 CDCA 在膽結石患者中可能**升高 LDL-C**，對血脂的作用方向並不確定，甚至可能與 HoFH 的治療目標相反。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅靠 TxGNN 模型分數支撐，沒有 HoFH 臨床試驗，唯一文獻也不是 HoFH 研究。
- CDCA 可能升高 LDL-C，作用方向與治療目標可能相反。
- 安全性資料缺口屬於阻擋等級，尚無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與核准適應症。
- 補充 DrugBank 的作用機轉資料。
- 搜尋 CDCA 對 LDL-C／HoFH 的直接證據（臨床或前臨床），釐清對血脂的影響方向。

**其他預測適應症（皆為 Hold）：**
- 腦小血管病 1 型（含或不含眼部異常）：L5，文獻皆為先天性眼部異常的一般性綜述，未提及 CDCA，屬關鍵字誤配。
- 家族性血尿-視網膜小動脈迂曲-攣縮症候群：L5，無試驗、無文獻。
- 家族性複合型高脂血症（已廢棄術語）：L5，需先對應到現行疾病本體詞條。
- 高尿酸血症（已廢棄術語）：L5，無證據，也無已知機轉。
