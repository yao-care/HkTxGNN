# Chlorambucil：從慢性淋巴球性白血病 (CLL) 到 IGHV 突變型 CLL/SLL

## 一句話總結

Chlorambucil 是 DNA 烷化劑（氮芥類），CLL/SLL 是它的經典治療對象。
TxGNN 預測它可能對**伴 IGHV 體細胞高突變的 CLL/SLL** 有效，但這只是母疾病 CLL 的分子亞型。
**目前沒有臨床試驗，也沒有針對此亞型的文獻**，證據僅來自模型預測。

## 為什麼這個預測合理？

資料包未提供 DrugBank 的詳細作用機轉。已知 Chlorambucil 是氮芥類 DNA 烷化劑，透過損傷 DNA 殺死增生中的淋巴細胞。CLL/SLL 是它的傳統治療對象。

這個預測分數很高 (0.997)，較可能是因為該亞型在知識圖譜中緊鄰母疾病 CLL 節點。IGHV 突變狀態是 CLL 內部的生物學分型，並不代表新的疾病類別。因此這項預測更接近「既有用途的細分」，不算真正的老藥新用。

**沒有任何亞型專屬資料**支持 Chlorambucil 對 IGHV 突變型 CLL 的療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測是已知適應症 CLL 的亞型，沒有任何亞型專屬的試驗或文獻，證據只有模型預測。
- 香港仿單的警語與禁忌尚未取得，資料包將其列為阻斷性缺口，無法進入安全性篩選。

**若要推進需要：**
- 下載並解析衛生署核准的仿單，確認核准適應症、警語與禁忌。
- 取得 Chlorambucil 用於 IGHV 突變型 CLL 的亞型資料，例如既有 CLL 試驗的亞組分析。
- 從 DrugBank 補齊作用機轉。
- 另行評估**原發性肺淋巴瘤**（L3，證據相對最多），建議先由血液腫瘤專家審閱。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。
