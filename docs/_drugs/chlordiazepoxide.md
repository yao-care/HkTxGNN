## Chlordiazepoxide：從焦慮症與酒精戒斷到失眠
{: .text-alpha }

## 一句話總結

Chlordiazepoxide（氯二氮平）是第一個上市的苯二氮平類藥物，原本用於焦慮症、酒精戒斷及消化性潰瘍相關症狀等。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有臨床試驗登記**，僅有 **5 篇相關文獻**，且多為綜述與舊研究，證據相當有限。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就藥理類別而言，Chlordiazepoxide 屬於苯二氮平類，一般認為其作用是增強 GABA-A 受體活性，產生鎮靜、抗焦慮與助眠效果。

焦慮與失眠常同時出現，原適應症（焦慮、酒精戒斷）也涉及過度興奮與睡眠障礙，因此機轉上確有合理的連結。

但目前檢索到的文獻多為苯二氮平類藥物的藥動學綜述、老年人使用助眠藥的評論，以及早期焦慮研究。沒有專門針對 Chlordiazepoxide 治療失眠的試驗，而老年人使用文獻反而強調潛在不適當用藥的安全疑慮。

## 安全性考量

- **禁忌症（來自知識圖譜關聯，非仿單原文）**：高血壓、姿勢性低血壓、長 QT 症候群、尖端扭轉型心律不整、癲癇、胃潰瘍、紫質症、腎病、肝病、膽囊疾病、甲狀腺功能低下、開角型青光眼、全身性紅斑性狼瘡、精神病性疾患、躁症等。
- **藥物交互作用**（共查得 100 筆，以下列出主要者）：
  - 重大：Morphine、Morphine（脂質體）——與鴉片類併用有中樞神經與呼吸抑制風險
  - 中等：Bupropion、Omeprazole、Cimetidine、Clarithromycin、Dronabinol、Metoclopramide、Nabilone、Opium、Sibutramine、Teduglutide
  - 輕微：Aluminum hydroxide、Calcium carbonate、Magaldrate 及多種鎂鹽制酸劑
- **其他疑慮**：文獻指出苯二氮平類在老年人中風險較高，且有依賴、戒斷及濫用潛力。

其餘警語與仿單資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉上合理，但缺乏針對 Chlordiazepoxide 治療失眠的直接臨床試驗，現有文獻多為綜述與舊研究。
- 市面上已有更常用、半衰期較短的助眠苯二氮平類與其他選擇，加上依賴與老年人風險，目前不建議推進。

**若要推進需要：**
- 取得完整的作用機轉資料（MOA）
- 取得香港衛生署仿單的警語與禁忌症
- 設計針對失眠的隨機對照試驗，並與現行助眠藥物比較
- 制定老年與高風險族群的安全性監測及依賴風險管理計畫
