# Chlorobutanol：從局部止痛與防腐用途到勃起功能障礙（預測，證據不足）

## 一句話總結

Chlorobutanol（氯丁醇）在香港以牙痛滴劑與外用乳膏成分上市，一般用作防腐劑、輕度鎮靜劑與局部麻醉劑。
TxGNN 模型預測它可能對**勃起功能障礙 (Erectile Dysfunction)** 有效，但目前**沒有任何直接支持的臨床試驗或文獻**，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Chlorobutanol 主要作為防腐劑、輕度鎮靜劑與局部麻醉劑使用，與勃起生理沒有已知關聯。

以本次預測的勃起功能障礙而言，Evidence Pack 的機轉評估認為**找不到合理的作用機制**。0.998 的高分較可能是知識圖譜結構造成的假象，而非真實的藥理訊號。

其他預測中，偏頭痛僅有假設性連結：鎮靜作用或離子通道、GABA 系統理論上可能影響神經興奮性，但這尚未經驗證。妥瑞氏症、拔毛癖、ADHD 及數種罕見疾病則完全沒有機轉或臨床資料支持。ADHD 方面，鎮靜特性反而可能不利。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測適應症均為 L5（僅有模型預測）。勃起功能障礙的兩個相關試驗皆為無關的前列腺癌研究，且找不到合理的作用機制，高分很可能是知識圖譜的假象。
- 作用機轉與安全性資料皆缺，尚無法進入安全性篩選階段。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料
- 取得香港衛生署仿單，確認警語、禁忌與核准適應症
- 確認劑型與給藥途徑（現有產品為牙痛滴劑與外用乳膏，是否能用於預測適應症尚未評估）
- 針對機轉相對較可能的神經系統適應症（如偏頭痛）做體外或前臨床驗證
- 在取得任何直接證據之前，不建議投入臨床開發資源

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
