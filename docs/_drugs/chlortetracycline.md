# Chlortetracycline：從抗菌用途到感染後血管炎 (Postinfectious Vasculitis)

## 一句話總結

Chlortetracycline（金黴素）是四環黴素類抗生素，屬 30S 核糖體抑制劑。香港目前登記的產品為眼用軟膏。
TxGNN 模型預測它可能對**感染後血管炎 (Postinfectious Vasculitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Chlortetracycline 是四環黴素類抗生素，透過結合細菌 30S 核糖體亞單位來抑制蛋白質合成，主要用於抗菌。

四環黴素類藥物有報告指出具抗發炎與抑制基質金屬蛋白酶 (MMP) 的作用，理論上可能與血管炎的發炎機轉有關。但這一點**僅屬推測**，沒有針對此適應症的直接證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.82%），但沒有臨床試驗與文獻佐證，證據等級僅為 L5。
- 作用機轉與血管炎的連結只是推測，且香港現有產品為眼用軟膏，給藥途徑與全身性疾病是否相容尚未評估。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料，分析與感染後血管炎的機轉關聯。
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌。
- 系統性檢索四環黴素類（如 doxycycline）用於血管炎的文獻與試驗，作為間接證據。
- 評估給藥途徑相容性（眼用軟膏 vs. 全身性治療需求）。

**其他預測適應症備註：** 排名第 5 的外耳炎 (Otitis Externa) 有一篇 1950 年的歷史文獻（僅憑標題判讀，證據等級 L3），但這較接近傳統抗菌用途，而非新的藥物再利用。排名第 7 的感染相關溶血性尿毒症候群，因抗生素可能增加 HUS 風險，不應假設有益。
