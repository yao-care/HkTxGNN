# Chlorthalidone：從高血壓到原發性遺傳性青光眼

## 一句話總結

Chlorthalidone 是一種噻嗪類（thiazide-like）利尿劑，廣泛用於高血壓的治療，為 ALLHAT 大型臨床試驗的核心研究藥物。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
然而目前**無相關臨床試驗**、**無直接文獻**支持此方向，整體屬純模型預測層級。

## 為什麼這個預測合理？

目前缺乏 Chlorthalidone 的詳細作用機轉資料（MOA 待補）。根據已知資訊，Chlorthalidone 屬於噻嗪類（sulfonamide）利尿劑，其主要機轉為抑制腎臟遠曲小管的鈉-氯共同轉運體（NCC），達到利尿、降低血容量進而降低血壓的效果。

理論上，噻嗪類利尿劑可能透過降低全身體液壓力，間接影響眼內房水（aqueous humor）的生成，進而降低眼壓（IOP）。此外，Chlorthalidone 的磺醯胺結構與碳酸酐酶抑制劑（如 acetazolamide）在化學上具有相似性，後者已被用於降眼壓，存在間接的機轉類比空間。

然而，原發性遺傳性青光眼的病因涉及特定基因突變（如 MYOC、OPTN、TBK1），屬結構性、遺傳性病變，利尿機轉無法針對病因進行修正，機轉關聯性仍屬間接推論，尚缺乏直接研究支撐。

## 結論與下一步

**決策：Hold**

**理由：**
目前針對 Chlorthalidone 用於原發性遺傳性青光眼，完全缺乏臨床試驗與直接文獻支持（L5 等級），機轉關聯性亦屬間接推論；加之香港無上市紀錄、安全性資料不完整，現階段不具備推進條件。

**若要推進需要：**
- 補充 Chlorthalidone 的完整作用機轉（MOA）資料，評估與房水生成的關聯性
- 調查是否有體外或動物模型研究支持噻嗪類利尿劑的降眼壓效果
- 取得原廠仿單，確認主要警語、禁忌症及藥物交互作用
- 評估香港藥監申請路徑（目前零許可證，若有再利用潛力需規劃完整法規策略）
- 考慮在 Rank 8（慢性肺心病）和 Rank 9（急性肺心病）進行優先深化，因該方向有少量直接文獻及臨床試驗可供分析
