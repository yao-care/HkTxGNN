# Chlorzoxazone：從骨骼肌鬆弛劑到偏頭痛

## 一句話總結

Chlorzoxazone 是一種中樞作用的骨骼肌鬆弛劑，在香港已上市。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效。
目前**沒有臨床試驗**，只有 **3 篇間接相關的文獻**（2 篇眩暈與小腦疾病的回顧、1 篇小鼠前臨床研究），沒有任何一篇直接在偏頭痛患者身上測試此藥。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Chlorzoxazone 屬於中樞作用的骨骼肌鬆弛劑，在肌肉痙攣相關疾病中已有長期使用。機轉上是否適用於偏頭痛，仍缺乏直接證據。

唯一的機轉線索來自 2012 年的小鼠研究（PMID 23115190）。該研究發現，鈣離子依賴性鉀通道 (KCa) 活化劑可減輕 CaV2.1 電流增強所引起的小腦運動失調。Chlorzoxazone 是已知的 KCa 通道活化劑。CaV2.1 由 *CACNA1A* 基因編碼，這個基因的突變也與家族性偏癱型偏頭痛有關，因此可以推測兩者在離子通道層面有關聯。

不過這條推論仍屬**間接且未經驗證**。研究對象是小腦運動失調的小鼠模型，不是偏頭痛，也沒有測試 Chlorzoxazone 本身。另外兩篇文獻是眩暈與小腦疾病的藥物治療回顧，並非偏頭痛試驗。TxGNN 的高分更可能來自知識圖譜的關聯傳播，不代表已有臨床證據。

## 安全性考量

安全性資訊請參考原廠仿單。

補充：一篇 2006 年病例報告（PMID 19606800）描述一名患者同時大量服用多種藥物（含 chlorzoxazone），因而發生高鐵血紅素血症。該案例屬多藥過量，無法歸因於單一藥物，僅供安全性參考。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何直接在偏頭痛中測試 Chlorzoxazone 的臨床試驗或文獻。
- 機轉線索僅來自小鼠小腦運動失調模型，證據等級為 L4。
- 同一份預測中的其他適應症（偏頭痛亞型、類風濕性關節炎、頭痛等）證據同樣薄弱，皆為 Hold。

**若要推進需要：**
- 補齊 Chlorzoxazone 的作用機轉資料（DrugBank）。
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症。
- 進行偏頭痛專屬的文獻檢索，並以電生理或動物模型驗證 KCa 通道活化劑在偏頭痛中的作用。
- 若前臨床證據成立，再設計小型探索性臨床試驗。

*本報告僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
