# Chlorzoxazone：從肌肉骨骼疾病到偏頭痛

## 一句話總結

Chlorzoxazone 是一種骨骼肌鬆弛劑，在香港已有上市許可證，但資料中未登載核准適應症文字。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前**沒有臨床試驗**，僅有 **3 篇間接相關文獻**（主題為眩暈與小腦疾病），尚無偏頭痛的直接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Chlorzoxazone 是單一成分的骨骼肌鬆弛劑，一般用於緩解肌肉痙攣與相關疼痛，但本報告所用資料並未載明其原適應症與作用機轉。

在機轉上，有一個間接但尚未驗證的假說：Chlorzoxazone 已知為鈣離子依賴性鉀離子通道（KCa，SK/IK）的活化劑。一篇小鼠研究（PMID 23115190）顯示，活化此類通道可減輕由 CaV2.1 電流增強所引起的小鼠小腦運動失調。CaV2.1（CACNA1A）基因突變與家族性偏頭痛有關，因此理論上存在通道調節的連結。

然而，這只是推測。目前提供的文獻談的是眩暈與小腦疾病，並非偏頭痛，也沒有任何偏頭痛專屬的臨床或前臨床資料。TxGNN 分數雖高，但不能取代實際證據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自模型知識圖譜，非仿單內容）：肝衰竭、肝臟疾病、膽囊疾病、物質濫用/依賴、藥物性肝損傷、乙醯胺酚（paracetamol）中毒。
- **藥物交互作用**：共查得 72 筆，主要包括：
  - **重度**：Morphine、Morphine (liposomal)
  - **中度**：Dronabinol、Metoclopramide、Nabilone、Naltrexone、Opium、Sibutramine、Ethanol、Promethazine
  - 其餘多筆（如 Warfarin、Metformin、Omeprazole 等）等級未知。
- **過量風險**：一篇病例報告（PMID 19606800）描述多種藥物（含 48 錠 Chlorzoxazone）過量後發生高鐵血紅素血症，屬於安全性訊號。

其他警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.73%），但沒有任何臨床試驗，現有文獻也與偏頭痛無直接關聯，僅有間接的鉀/鈣通道假說，證據等級為 L5。
- 同批預測中，類風濕性關節炎（L4）僅有間接的症狀緩解證據，其他預測（如肺高壓、腎因性抗利尿不當症候群）則完全缺乏支持，目前沒有任何一項適合推進。

**若要推進需要：**
- 補齊作用機轉資料（MOA）與香港仿單的核准適應症、警語與禁忌。
- 進行偏頭痛專屬的前臨床研究（如 KCa 通道活化在偏頭痛模型的效果）。
- 若前臨床結果正面，再規劃小型探索性臨床試驗，並預先納入肝功能與藥物交互作用（尤其鴉片類與酒精）的監測計畫。
