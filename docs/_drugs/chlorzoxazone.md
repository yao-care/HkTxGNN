# Chlorzoxazone：從肌肉骨骼痙攣到偏頭痛

## 一句話總結

Chlorzoxazone 是中樞性肌肉鬆弛劑，傳統用於緩解肌肉骨骼痙攣與相關疼痛。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前有 **0 個臨床試驗**和 **3 篇文獻**提供間接機轉支持。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Chlorzoxazone 除了作為中樞性肌肉鬆弛劑之外，亦被識別為 **BKCa（大電導鈣依賴性鉀）通道開啟劑**。BKCa 通道廣泛表達於三叉神經末梢及腦血管平滑肌，其活化可降低神經元過度興奮並調節血管張力，理論上可干預偏頭痛的神經血管發病機制。

偏頭痛（尤其家族性偏癱性偏頭痛 FHM1）與 *CACNA1A* 基因編碼的 CaV2.1 鈣通道功能獲得性突變有直接遺傳關聯。前臨床研究（PMID 23115190）顯示，BKCa 激活可對抗 CaV2.1 過度電流引發的小腦神經元異常放電，提供了間接的跨病機轉連結。

然而，目前所有相關文獻均針對小腦性共濟失調或前庭疾病，**尚無任何以偏頭痛患者為直接對象的臨床試驗或觀察性研究**。此預測目前停留在機轉假說階段，尚待前臨床概念驗證。

## 結論與下一步

**決策：Hold**

**理由：**
現有文獻均屬間接機轉支持（前臨床及敘述性回顧），完全缺乏針對偏頭痛的臨床試驗或觀察性研究；加之藥物在香港未上市，監管路徑尚需建立，現階段不具備推進再利用評估的充分條件。

值得一提的是，**類風濕關節炎（RA, Rank #9）**的再利用方向在本批次預測中擁有更豐富的歷史文獻（7 篇，含 1 篇 Cochrane 系統性回顧），證據等級達 **L3**，作為輔助症狀管理藥物（配合 NSAID/類固醇）的歷史使用有一定根據，可考慮優先評估。
