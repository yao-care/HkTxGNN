# Choline salicylate：從原適應症（許可證未載明）到變異型心絞痛 (Prinzmetal angina)

## 一句話總結

Choline salicylate 是一種非乙醯化水楊酸鹽，在香港以凝膠類製劑上市，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**變異型心絞痛 (Prinzmetal angina)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Choline salicylate 屬於水楊酸鹽類，此類藥物一般透過抑制 COX 與血栓素發揮作用，因此在抗血小板方面有一定的合理性。

不過在血管痙攣性心絞痛，高劑量水楊酸鹽可能降低具血管擴張作用的前列環素 (prostacyclin)。它是否有益尚未證實，也無法排除可能造成傷害。

原適應症資料缺漏，無法進一步分析新舊適應症的關聯。這個預測目前只能視為模型產生的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測（變異型心絞痛）只有模型分數，沒有試驗與文獻，機轉上還可能有害。
- 香港仿單的警語與禁忌資料缺漏（屬 Blocking 等級的資料缺口），目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衞生署仿單，補齊警語、禁忌症與原適應症。
- 從 DrugBank 補充作用機轉（MOA）。
- 針對變異型心絞痛做前臨床或機轉文獻回顧，先確認水楊酸鹽對前列環素的影響。
- 若要投入資源，建議優先評估類風濕性關節炎與偏頭痛，這兩項證據較多。

本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後才能應用。
