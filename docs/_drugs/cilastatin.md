# Cilastatin：從細菌性肺炎等感染症到金黃色葡萄球菌感染

## 一句話總結

Cilastatin 是腎脫氫肽酶-I（DHP-1）抑制劑，本身沒有抗菌活性，通常與 imipenem 組成複方，原本用於細菌性肺炎、腹膜炎、心內膜炎等感染症。
TxGNN 模型預測它可能對**金黃色葡萄球菌感染 (Staphylococcus aureus infection)** 有效，目前有 **1 個臨床試驗**和 **20 篇文獻**與此方向相關，但證據多為間接證據（效果來自 imipenem，而非 cilastatin 本身）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cilastatin 是 DHP-1 抑制劑，與 imipenem 組成複方使用。它能防止 imipenem 在腎臟被降解，使其達到有效的尿中與全身濃度。

Cilastatin 本身沒有抗菌作用，任何抗葡萄球菌效果都來自 imipenem。因此，這個「新適應症」較像是既有 imipenem/cilastatin 抗菌譜的延伸，而不是 cilastatin 本身的真正藥物再利用。

臨床上，imipenem/cilastatin 對甲氧西林敏感的金黃色葡萄球菌（MSSA）有活性，對 MRSA 的活性有限且不穩定。有個案報告描述 imipenem/cilastatin 與 fosfomycin 合併，用於治療難治性 MRSA 感染。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：癲癇、腎臟病、輸尿管積膿、困難梭狀芽孢桿菌結腸炎、周產期壞死性腸炎（此為知識圖譜的藥物-疾病禁忌關聯，非仿單原文）。
- **藥物交互作用**：資料庫僅列出藥理層面的作用標的 Dipeptidase 1（DHP-1），未提供具臨床意義的藥物交互作用分級。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold（作為研究問題保留）**

**理由：**
- 金黃色葡萄球菌的證據多為舊的小型臨床研究、動物實驗與個案報告，抗菌效果來自 imipenem 而非 cilastatin，不屬於真正的藥物再利用。
- 現有唯一臨床試驗為間接證據，且對 MRSA 的活性有限，與現行抗 MRSA 標準治療相比缺乏優勢。

**補充說明（其他預測適應症）：**
- **肺炎**：證據最強（L1），有多項已完成的 Phase 3 RCT，包括 imipenem/cilastatin/relebactam 用於院內／呼吸器相關細菌性肺炎的試驗。但肺炎本來就屬於原適應症，等於是對既有用途的確認，療效來自 imipenem 與 relebactam。
- **支氣管炎、沙門氏菌病**：僅有舊的非對照研究或個案報告（L3）；碳青黴烯類不適合用於單純支氣管炎（抗生素管理考量）。
- **鼻竇炎**：證據間接（L4）。
- **慢性鼻竇炎、慢性篩竇炎、副鼻竇腫瘤、副傷寒、瀰漫性硬皮症**：僅有模型預測、沒有任何研究證據（L5），且缺乏合理機轉，建議暫不推進。

**若要推進需要：**
- 補齊作用機轉資料（MOA）。
- 取得香港衛生署仿單的警語與禁忌資料，以進行安全性篩選。
- 釐清香港許可證的核准適應症與劑型（目前資料皆為空白）。
- 針對 MSSA／MRSA，設計 imipenem/cilastatin 與現行標準治療的比較性研究，並明確區分 imipenem 與 cilastatin 各自的貢獻。
