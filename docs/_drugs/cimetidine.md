# Cimetidine：從 H2 受體拮抗劑（原適應症未載明）到冒煙型系統性肥大細胞增生症

## 一句話總結

Cimetidine（DrugBank：DB00501）是一種組織胺 H2 受體拮抗劑，香港許可證資料未載明原核准適應症。
TxGNN 模型預測它可能對**冒煙型系統性肥大細胞增生症 (Smouldering systemic mastocytosis)** 有效。
目前**沒有臨床試驗和文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cimetidine 屬於 H2 受體拮抗劑，透過阻斷組織胺在 H2 受體上的作用，抑制胃酸分泌。

肥大細胞增生症的症狀有一部分來自肥大細胞釋放的組織胺，例如胃酸過度分泌。因此在機轉上，阻斷 H2 受體可能緩解這類症狀。

但這只是模型預測。證據包中沒有任何試驗或文獻佐證，而且症狀緩解不會改變疾病本身的克隆性 (clonal) 病程。

## 結論與下一步

**決策：Hold**

**理由：**
這個預測只有模型分數，沒有任何臨床試驗或文獻支持（L5）。H2 阻斷最多只能緩解症狀，無法針對疾病本身治療，這類罕見疾病的主要處置是細胞減量或標靶治療。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌與核准適應症（目前為阻擋性缺口）
- 補齊作用機轉資料（查詢 DrugBank）
- 針對肥大細胞增生症進行文獻與試驗檢索，確認 H2 拮抗劑用於症狀控制的實際證據

**補充說明：**
同一份預測清單中，「活動性消化性潰瘍」（第 2 名）已有多篇對照試驗支持 cimetidine（如 PMID 73792、7034155），證據等級為 L1。但這很可能是既有適應症，不算真正的老藥新用，且質子幫浦抑制劑 (PPI) 在此領域已大幅取代 H2 拮抗劑。若要評估實際價值，建議另案處理，並先核對仿單。
