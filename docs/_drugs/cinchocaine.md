# Cinchocaine：從痔瘡相關局部麻醉用途到支氣管炎

## 一句話總結

Cinchocaine 是醯胺類局部麻醉劑，在香港以栓劑與直腸軟膏形式上市。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cinchocaine 屬於醯胺類局部麻醉劑，一般認為其作用是阻斷電壓門控鈉通道，抑制神經傳導。

理論上，阻斷呼吸道感覺神經可能減輕咳嗽，但這只是症狀緩解，並非治療支氣管炎本身。此外，全身或吸入使用 Cinchocaine 有毒性疑慮，主要是心臟與中樞神經系統影響。

99.77% 的高分只是模型預測，機轉上的合理性並未建立。其他排名前列的預測（如皮膚炎、皮肌炎、間質性肺病等）同樣沒有機轉依據，分數可能反映的是知識圖譜中節點的鄰近關係，而非藥理作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有臨床試驗、文獻或機轉資料支持，證據等級為 L5。
- 目前上市劑型（栓劑、直腸軟膏）與支氣管炎所需的給藥途徑不相容，且全身或吸入使用有毒性疑慮。

**若要推進需要：**
- 補齊作用機轉（MOA）資料
- 取得香港衛生署仿單的警語與禁忌症
- 確認給藥途徑的可行性，並評估呼吸道給藥的安全性
- 取得任何支持 Cinchocaine 用於支氣管炎的前臨床或臨床證據
