# Cinchocaine：從皮膚炎到支氣管炎

## 一句話總結

Cinchocaine（又稱 dibucaine）是一種醯胺類局部麻醉藥，原本用於皮膚炎相關治療。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬於模型的計算預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cinchocaine 是醯胺類局部麻醉藥，一般認為其作用是阻斷電壓門控鈉離子通道，進而抑制神經傳導。

從理論上推測，局部或呼吸道的麻醉效果可能減緩咳嗽反射或氣道刺激，因此對支氣管炎的症狀可能有幫助。但這只是機轉上的推論，並沒有臨床或文獻證據支持。TxGNN 的高分（99.77%）僅代表知識圖譜中的網路關聯，尚未經過任何驗證。

原適應症（皮膚炎）與支氣管炎分屬不同器官系統，兩者的相似性目前尚未評估。此外，用藥途徑是否相容（目前香港製劑多為栓劑與軟膏）也尚未確認。

此外，模型也預測了其他幾項適應症，包括萎縮性慢性肢端皮膚炎、新生兒皮肌炎、兒童結締組織病相關間質性肺病、痤瘡性瘢痕疙瘩、家族性種痘樣水皰病及無肌病性皮肌炎。這些預測同樣沒有臨床試驗或文獻佐證，證據等級皆為 L5，建議皆為 Hold。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎的預測僅來自模型計算，沒有任何臨床試驗或文獻，證據等級為 L5。
- 作用機轉資料缺失，且知識圖譜顯示該藥與呼吸衰竭、心血管疾病等有潛在禁忌關聯，目前不適合推進。

**若要推進需要：**
- 取得香港仿單的警語與禁忌症，完成安全性初步篩查
- 補齊作用機轉（MOA）資料，釐清與支氣管炎的機轉關聯
- 進行文獻與臨床試驗的系統性檢索，確認是否有任何支持證據
- 評估用藥途徑相容性（現有製劑為栓劑、軟膏與口含錠，是否適用於呼吸道）
- 若仍想探索，可優先考慮前臨床或機轉研究，以提升證據等級
