# Cisatracurium：從麻醉肌肉鬆弛到馬尾症候群

## 一句話總結

Cisatracurium 是非去極化神經肌肉阻斷劑，臨床上用於麻醉時的肌肉鬆弛。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，分數很高（99.99%）。
但這個方向目前**沒有任何臨床試驗或文獻**支持，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cisatracurium 屬於非去極化神經肌肉阻斷劑，作用於菸鹼型乙醯膽鹼受體（拮抗劑），使骨骼肌鬆弛。它的既有角色是麻醉輔助，而不是治療疾病本身。

馬尾症候群是脊椎神經根受壓迫的神經外科急症。目前資料無法建立這個疾病與神經肌肉阻斷之間的合理機轉連結，也沒有任何研究把 Cisatracurium 用於此病。因此，高分只能視為知識圖譜的關聯推論，不能當作療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的預測（馬尾症候群）沒有任何臨床試驗或文獻，證據等級只有 L5，機轉上也找不到合理連結。
- 其餘預測中，子癇前症和血栓性疾病雖有零星紀錄，但都只是麻醉情境或鎂鹽交互作用的間接資訊，並非 Cisatracurium 的療效證據。

**若要推進需要：**
- 取得香港衞生署核准的仿單，確認警語、禁忌症與核准適應症。
- 補齊 DrugBank 的作用機轉資料。
- 尋找能說明神經肌肉阻斷與目標疾病（如馬尾症候群）之間關聯的機轉或前臨床研究。
- 若要往子癇前症方向探討，需先釐清鎂鹽併用時的神經肌肉阻斷交互作用，這屬於麻醉安全議題，不是新適應症證據。

*本報告僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
