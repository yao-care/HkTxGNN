## Citalopram: 強迫症 (obsessive-compulsive disorder)
{: .text-alpha }

## 一句話總結

Citalopram 是一種選擇性血清素再吸收抑制劑 (SSRI)。
TxGNN 模型預測它可能對**強迫症 (obsessive-compulsive disorder)** 有效，
目前有 **4 個臨床試驗**和 **16 篇文獻**與此方向相關，其中直接以 citalopram 治療強迫症的研究多為小型、開放標示或單盲試驗，證據等級為 **L2**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，citalopram 屬於 SSRI 類別，其藥理作用是抑制血清素再吸收，提高突觸間隙的血清素濃度。

血清素系統失調被認為與強迫症的病理有密切關係，SSRI 類藥物是強迫症的一線藥物治療。文獻（如 "Obsessive compulsive disorder: serotonin and beyond"）也支持這個機轉觀點。

在 citalopram 本身的研究方面，已有小型隨機單盲比較（fluvoxamine、paroxetine 與 citalopram，PMID 9241005）、難治型強迫症的隨機開放標示試驗（PMID 10572334），以及成人與兒童青少年的開放標示研究。需要注意，這些研究樣本小、缺乏安慰劑對照的 Phase 3 試驗，所列臨床試驗也多屬 SSRI 類別層級的證據，並非 citalopram 專屬。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- Citalopram 為 SSRI，SSRI 類藥物是強迫症的標準治療，且已有數項直接以 citalopram 治療強迫症的小型隨機單盲及開放標示研究，成人與兒童皆有，故證據等級為 L2。
- 但尚無安慰劑對照的 Phase 3 試驗，列出的臨床試驗多屬類別層級或使用其他藥物，因此需設定防護條件再推進。

**若要推進需要：**
- 確認 citalopram 專屬的對照試驗（理想為安慰劑對照的 RCT）
- 取得本地仿單的警語、禁忌症與完整適應症資料
- 評估 QT 延長等心臟風險及與重大交互作用藥物併用的處理計畫
- 補充詳細的作用機轉資料
