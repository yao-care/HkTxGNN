# Citric Acid：從消化不良與頭痛到胃部疾病

## 一句話總結

Citric Acid（檸檬酸）原本用於消化不良與頭痛類疾病。
TxGNN 模型預測它可能對**胃部疾病 (Stomach Disease)** 有效，但目前**沒有臨床試驗**，僅有 **20 篇間接文獻**，且多為診斷輔助、基礎研究或動物研究，尚無直接證明療效的證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，檸檬酸已被用於消化不良，因此胃部適應症與原用途在位置與症狀上相近，這可能是模型給出高分的原因。

不過，與胃部最直接相關的文獻，是以檸檬酸試驗餐提高 13C 尿素呼氣試驗（幽門螺旋桿菌檢測）的準確度。這屬於診斷輔助用途，並非治療效果。其餘文獻涉及一般營養、幽門螺旋桿菌生理、胃癌代謝體學、獸醫與動物研究，皆屬間接證據。

因此 0.997 的分數目前只是計算預測，沒有臨床佐證。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自藥物－疾病關聯，非仿單內容）：高血壓、腎臟疾病與腎功能不全、無尿、肝病、膽囊疾病、血小板低下、充血性心衰竭、腎上腺功能不全（含 Addison 病、先天性腎上腺增生等）、消化性潰瘍、痛風、高血鈣、腎鈣質沉著症、磷代謝疾病、貧血、血友病、慢性腹瀉疾病、物質濫用／依賴等。
- **藥物交互作用**（共 15 項）：
  - **重大 (Major)**：氫氧化鋁（Aluminum hydroxide）。
  - **中度 (Moderate)**：多種喹諾酮類抗生素，包括 Ciprofloxacin、Levofloxacin、Moxifloxacin、Ofloxacin、Norfloxacin、Enoxacin、Gatifloxacin、Gemifloxacin、Lomefloxacin、Trovafloxacin、Grepafloxacin、Sparfloxacin、Cinoxacin、Nalidixic acid。

其他警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，文獻也只顯示檸檬酸作為幽門螺旋桿菌檢測的診斷輔助，並非治療效果；高 TxGNN 分數缺乏臨床佐證。
- 知識圖譜顯示的禁忌疾病範圍廣（包含消化性潰瘍），對胃部疾病族群的適用性需要審慎評估。

**若要推進需要：**
- 詳細的作用機轉（MOA）資料
- 針對胃部疾病的前臨床或小型臨床研究，證明治療效果而非診斷用途
- 取得香港原廠仿單，確認警語、禁忌與核准適應症
- 針對消化性潰瘍等相關族群與喹諾酮、含鋁制酸劑交互作用的安全性評估
