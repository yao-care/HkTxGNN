# Citric Acid：從（原適應症未載明）到胃部疾病

## 一句話總結

Citric Acid（檸檬酸）在香港以咳嗽糖漿、腸道清潔粉劑、泡騰鹽等複方產品上市，但資料庫未載明其原適應症。
TxGNN 模型預測它可能對**胃部疾病 (Stomach Disease)** 有效，但目前**無相關臨床試驗**，僅有 **20 篇文獻**，且多為診斷輔助或生物標記研究，並非治療證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，檸檬酸是多種複方製劑的成分（咳嗽糖漿、腸道清潔劑、泡騰鹽），其在原用途中的角色多為賦形劑或輔助成分，機轉上是否適用於胃部疾病尚無法確認。

從現有文獻看，檸檬酸與胃部疾病的關聯主要是**診斷或生物標記性質**，而非治療作用：
- 在 13C-尿素呼氣試驗中作為試驗餐，用於幽門螺旋桿菌檢測。
- 是胃液的天然成分之一。
- 在胃癌代謝體學與能量代謝研究中，檸檬酸（TCA 循環中間產物）可作為代謝標記；一項韓國研究發現胃癌發病前血清檸檬酸偏高。

因此，高 TxGNN 分數目前只是模型預測，沒有證據顯示檸檬酸能治療胃部疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗，文獻多屬診斷輔助、生物標記或基礎代謝研究，並未顯示檸檬酸對胃部疾病有治療效果。
- 作用機轉與安全性資料皆缺，TxGNN 高分僅是模型預測。

**若要推進需要：**
- 補齊 DrugBank 作用機轉資料，釐清檸檬酸與胃部疾病的治療性機轉關聯。
- 取得香港衞生署仿單，確認警語與禁忌。
- 明確定義預期的治療用途（例如胃酸相關症狀），並找出相應的臨床前或臨床研究。
- 其他預測（咽炎、鼻腔疾病、鼻炎等）證據同樣薄弱（多為 L4-L5），建議以胃部疾病為主軸先補足證據。
