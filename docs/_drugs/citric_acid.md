# Citric Acid：從天然代謝物到胃病

## 一句話總結

Citric Acid（檸檬酸）是 TCA 循環的天然中間代謝物，廣泛存在於人體與食物中，目前無正式藥品適應症登記。
TxGNN 模型預測它可能與**胃病 (Stomach Disease)** 相關，
目前有 **0 個臨床試驗**和 **20 篇文獻**涉及此方向，但多數為代謝生物標記研究，而非直接治療介入。

## 為什麼這個預測合理？

Citric Acid（檸檬酸，DB04272）是克氏循環（TCA cycle）的核心中間代謝物，廣泛存在於柑橘類食物、人體血液及胃液中。目前缺乏正式的藥品作用機轉資料（MOA），以下分析基於現有文獻推斷。

作為胃液的天然成分（PMID 6027230），檸檬酸在胃部環境研究中已有多項角色：(1) 作為 13C-尿素呼氣試驗（UBT）的「試驗餐」輔助劑，提高 *Helicobacter pylori* 診斷準確性（PMID 31505905）；(2) 與鉍化合物結合形成具胃黏膜保護活性的新型鹽類（MX1），對大鼠應激性潰瘍具保護作用（PMID 9379358）；(3) 在胃癌代謝組學研究中，胃癌發生前患者血清檸檬酸水平顯著升高，提示其可能為早期生物標記（PMID 35900644）。

近年胃癌研究聚焦於能量代謝重程（Warburg effect、TCA cycle 失調），檸檬酸作為 TCA cycle 的直接成員在理論上具有通路關聯性（PMID 37477784, 38959111）。然而，所有現有文獻均為診斷輔助或代謝相關性觀察，**目前完全缺乏以檸檬酸為主角的胃病治療干預研究**，作為再利用治療藥物的直接機轉依據薄弱。

## 結論與下一步

**決策：Hold**

**理由：**
雖然 TxGNN 預測分數高達 99.74%，但現有 20 篇文獻均為代謝生物標記研究、診斷輔助用途或動物實驗，缺乏將檸檬酸作為**主要治療藥物**用於胃病的任何臨床試驗或系統性干預研究；加之香港未有上市許可，安全性資料亦付之闕如，整體再利用可行性尚不足以推進評估。

**若要推進需要：**
- 補充正式作用機轉資料（MOA），釐清檸檬酸在胃病中的直接治療角色
- 取得藥品仿單，確認安全性警語、禁忌症與劑量設定
- 設計前臨床干預研究，驗證檸檬酸（或含檸檬酸製劑）在胃潰瘍/H. pylori 模型中的治療效果
- 評估以「製劑活性成分」（如鉍-檸檬酸鹽複合物）而非單純檸檬酸進行開發的可行性，後者具更強的現有機轉依據（PMID 9379358）
