## Clavulanic Acid：β-內醯胺酶抑制劑 → 淋病性尿道炎 (gonococcal urethritis)
{: .text-alpha }

## 一句話總結

Clavulanic Acid（克拉維酸）是一種 β-內醯胺酶抑制劑，常與 amoxicillin 合用於抗菌治療。
TxGNN 模型預測它可能對**淋病性尿道炎 (gonococcal urethritis)** 有效，
目前無臨床試驗登記，但有 **9 篇相關文獻**（多為 1980 年代的臨床研究）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫未收錄）。根據已知的藥理學，克拉維酸可抑制 β-內醯胺酶，使 amoxicillin 對產青黴素酶的淋病奈瑟菌 (*Neisseria gonorrhoeae*) 恢復活性。

淋病性尿道炎的重要抗藥機制之一，就是病原菌產生青黴素酶。因此從機轉上看，「amoxicillin 加克拉維酸」有合理的作用基礎。1980 年代多項研究也顯示，單次或兩次劑量的 amoxicillin／克拉維酸在男性患者中有相當的治癒率。

但這些研究年代久遠，之後淋球菌的抗藥性型態已大幅改變，目前指引多優先建議其他藥物（如 ceftriaxone）。因此臨床相關性在今日相當有限。

- 其他警語與禁忌症資料不足，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉上合理，且有多項 1980 年代的臨床研究顯示 amoxicillin／克拉維酸對淋病性尿道炎有效。
- 但這些資料年代久遠，現今淋球菌抗藥性已改變、指引優先使用其他藥物，目前無臨床試驗登記，再利用價值有限。

**若要推進需要：**
- 取得近年本地淋球菌對 amoxicillin／克拉維酸的藥敏資料
- 與現行指引建議藥物（如 ceftriaxone）進行比較評估
- 補充作用機轉與原廠仿單的警語、禁忌症資料
- 確認本地許可證所載的核准適應症與劑型
