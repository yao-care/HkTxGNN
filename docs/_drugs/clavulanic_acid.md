# Clavulanic Acid：從泌尿道感染到淋病性尿道炎

## 一句話總結

Clavulanic Acid（clavulanate）是 β-內醯胺酶抑制劑，常與 amoxicillin 組成複方，原本用於泌尿道感染、細菌性肺炎、葡萄球菌感染等。
TxGNN 模型預測它可能對**淋病性尿道炎 (Gonococcal Urethritis)** 有效，
目前有 **0 個臨床試驗**和 **9 篇文獻**支持這個方向，其中多數為 1980 年代的臨床研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Clavulanic Acid 是 β-內醯胺酶抑制劑，常與 amoxicillin 合用。
其成分在細菌感染中的療效已被證實，機轉上可能適用於淋病性尿道炎。

淋病奈瑟菌 (*Neisseria gonorrhoeae*) 的部分菌株會產生青黴素酶 (PPNG)，使 amoxicillin 失效。
Clavulanic Acid 抑制 β-內醯胺酶，可恢復 amoxicillin 對這類菌株的活性，與其已上市的抗菌用途在機轉上一致。

不過，現有臨床研究多為 1980 年代的單劑或雙劑療法，之後細菌的抗藥性型態已有改變。
目前指引多偏好 ceftriaxone 等其他藥物，因此現今的臨床相關性有限。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉合理，且有 1980 年代的臨床研究顯示 amoxicillin/clavulanate 對淋病性尿道炎有效，但沒有登記中的臨床試驗，抗藥性型態也已改變，現行指引偏好其他藥物，臨床價值有限。
- 其他預測適應症中，子宮發炎性疾病證據多為獸醫或動物研究，Ureaplasma 尿道炎機轉上不合理（無細胞壁），其餘多屬圖譜假象或僅有理論基礎，均不建議推進。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症
- 補充詳細的作用機轉資料
- 分析本地淋病奈瑟菌對 amoxicillin/clavulanate 的最新抗藥性監測資料
- 與現行指引首選藥物（如 ceftriaxone）進行比較
