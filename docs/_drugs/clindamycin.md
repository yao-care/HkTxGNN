# Clindamycin：從細菌感染到點狀上皮角膜結膜炎

## 一句話總結

Clindamycin（克林達黴素）是一種抗生素，香港現有的上市產品為 1% 外用凝膠或外用溶液。
TxGNN 模型預測它可能對**點狀上皮角膜結膜炎 (Punctate Epithelial Keratoconjunctivitis)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Clindamycin 屬於林可胺類抗生素，一般認為透過抑制細菌 50S 核糖體亞基來抑制蛋白質合成，主要對革蘭氏陽性菌與厭氧菌有效。

點狀上皮角膜結膜炎通常由病毒（如腺病毒）或毒性、發炎因素引起。Clindamycin 沒有抗病毒活性，機轉上與這類疾病沒有明確連結。這個高分預測較可能來自知識圖譜中的間接關聯，而不是共同的致病機轉。

因此，這個預測目前只能視為待驗證的假說，機轉上的合理性尚無法確認。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有臨床試驗或文獻佐證（L5）。
- 該疾病多為病毒性或毒性/發炎性，與 clindamycin 的抗菌機轉缺乏明確關聯。
- 香港現有產品皆為皮膚外用劑型，沒有眼用製劑。
- 其他排名靠前的預測（暴露性角膜炎、神經營養性角膜病變、流行性角膜結膜炎、萎縮性陰道炎）同樣沒有直接證據。這些預測多半來自疾病名稱相似或相鄰用途，也不建議推進。

**若要推進需要：**
- 補齊作用機轉資料（MOA）。
- 取得香港衛生署的仿單，確認警語與禁忌症。
- 針對該疾病做系統性文獻檢索，確認是否有細菌性合併感染的證據。
- 評估眼用給藥途徑與製劑的可行性（目前無眼用製劑）。
- 取得任何直接證據（臨床前或臨床研究）後，再重新評估。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
