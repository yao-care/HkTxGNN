## Clindamycin：細菌蛋白質合成抑制劑（抗生素） → 點狀上皮角結膜炎 (punctate epithelial keratoconjunctivitis)
{: .text-alpha }

## 一句話總結

Clindamycin 是一種作用於細菌 50S 核糖體次單位的抗生素，主要對革蘭氏陽性菌與厭氧菌有效。
TxGNN 模型預測它可能對**點狀上皮角結膜炎 (punctate epithelial keratoconjunctivitis)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，屬於純模型預測。

## 為什麼這個預測合理？

Clindamycin 屬於林可胺類抗生素，透過結合細菌 50S 核糖體次單位抑制蛋白質合成，對革蘭氏陽性菌及厭氧菌有活性。目前缺乏詳細的作用機轉資料，上述說明為該藥物類別的一般已知特性。

然而，點狀上皮角結膜炎常與病毒感染或毒性／發炎反應有關，並非典型的細菌性疾病，因此抗菌機轉與此疾病之間的合理連結尚未建立。此預測目前僅來自模型分數，缺乏機轉或臨床層面的佐證。

此外，用於眼部的給藥途徑、角膜穿透性及局部安全性，在目前資料中均無法確認。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（0.9997），但沒有任何臨床試驗或文獻直接研究此疾病，證據等級為 L5。
- 此疾病多為病毒性或毒性／發炎性，抗菌機轉缺乏合理依據。

**若要推進需要：**
- 釐清 clindamycin 與此疾病的機轉關聯（含完整 MOA 資料）
- 眼部給藥途徑、角膜穿透性及眼部耐受性的前臨床資料
- 至少有針對此疾病的初步臨床或實驗研究
- 取得原廠仿單中的警語與禁忌症資訊，完成安全性篩選
