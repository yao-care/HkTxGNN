# Clobetasone：從局部皮質類固醇適應症到原發性皮膚 T 細胞淋巴瘤

## 一句話總結

Clobetasone 是中效價外用皮質類固醇，已在香港上市。
TxGNN 模型預測它可能對**原發性皮膚 T 細胞淋巴瘤 (primary cutaneous T-cell lymphoma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。Clobetasone 是外用糖皮質激素（皮質類固醇），機轉上屬於此類藥物的抗發炎與免疫抑制作用。

外用皮質類固醇作為一個藥物類別，常用於早期皮膚 T 細胞淋巴瘤的皮膚導向治療。這是類別層級的背景知識，**並非針對 Clobetasone 檢索到的證據**。

另外，糖皮質激素具有一般性的淋巴細胞溶解作用，這可能是模型給出高分的原因之一。不過這只是圖譜鄰近關係的推論，仍需實際研究驗證。

## 安全性考量

- **藥物交互作用**：查詢結果為未找到相關資料。
- **長期外用的系統性風險**：預測結果中提到，長期外用類固醇可能抑制 HPA 軸並導致腎上腺功能不全。這是類別層級的考量，需以原廠仿單為準。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測皆僅來自 TxGNN 模型分數（L5），沒有任何臨床試驗或文獻支持。
- 皮膚 T 細胞淋巴瘤雖有類別層級的合理性，但缺乏 Clobetasone 專屬證據；其餘多數預測在途徑或藥動學上不合理。

**若要推進需要：**
- 取得 Clobetasone 的作用機轉資料（DrugBank）。
- 取得香港衞生署仿單，補齊核准適應症、警語與禁忌症。
- 系統性檢索 Clobetasone 或中效外用類固醇用於早期皮膚 T 細胞淋巴瘤的臨床與文獻證據。
- 與現行標準的皮膚導向治療比較，確認 Clobetasone 是否有實際的增益價值。
