## Clozapine: 躁狂型雙相情感障礙 (manic bipolar affective disorder)
{: .text-alpha }

## 一句話總結

Clozapine 是一種非典型抗精神病藥。
TxGNN 模型預測它可能對**躁狂型雙相情感障礙 (manic bipolar affective disorder)** 有效。
目前有 **1 個直接針對躁狂的 Phase 2 臨床試驗**，另有數個雙相情感障礙相關試驗，以及多篇文獻（含 1 篇系統性回顧與統合分析）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥理類別推論，Clozapine 具有廣泛的受體作用，包括 D2 與 5-HT2A 拮抗，並影響其他單胺與麩胺酸系統，可能支持抗躁與情緒穩定效果。

這個機轉在難治型患者中尤其合理。部分躁狂患者對傳統治療反應不佳或無法耐受副作用，Clozapine 可作為替代選項。上述機轉連結是依藥物類別藥理與臨床文獻推論，並非來自已確認的作用機轉資料。

## 安全性考量

- **藥物交互作用**：已查詢到 100 筆交互作用記錄。屬重度（Major）的包括 Bupropion、Morphine、Potassium citrate。中度的包括 Acarbose、Famotidine、Epinephrine、Metformin、Pioglitazone、Omeprazole、Atropine、Cimetidine 等。

其他警語與禁忌症請參考原廠仿單。文獻另提到 Clozapine 的代謝負擔，以及與電痙攣治療合併時可能出現延長的痙攣發作。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
已有直接針對躁狂的 Phase 2 雙盲試驗，並有雙相情感障礙的 Phase 3 試驗與系統性回顧、統合分析支持。但躁狂專屬試驗規模小（42 人），且機轉資料缺乏，因此需在嚴格監測下推進。

**若要推進需要：**
- 取得完整的作用機轉資料與香港原廠仿單的警語、禁忌症
- 確認 NCT00029458 的詳細結果，並評估成人躁狂族群的更大型對照試驗
- 建立血液學與代謝等安全性監測計畫，並審查潛在的藥物交互作用
