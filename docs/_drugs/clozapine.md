# Clozapine：從難治型思覺失調症到躁期雙相情感障礙

## 一句話總結

Clozapine 是一種非典型抗精神病藥，已知的標示用途為難治型思覺失調症。
TxGNN 模型預測它可能對**躁期雙相情感障礙 (Manic Bipolar Affective Disorder)** 有效。
目前有 **6 個臨床試驗**（其中僅 1 個直接相關）和 **20 篇文獻**，最直接的證據是一項小型 Phase 2 雙盲試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Clozapine 具有廣泛的受體作用（多巴胺 D2、血清素 5-HT2A、蕈毒鹼及腎上腺素受體）。這種受體特性在難治型精神病症狀上的療效已被證實，機轉上可能也適用於躁症與相關症狀。

雙相情感障礙的躁期與精神病症狀在臨床上常有重疊。傳統治療反應不佳或無法耐受副作用的患者，Clozapine 常被視為替代選項。文獻也提出它可能對雙相情感障礙的自殺傾向有幫助。

這個方向主要有一項 Phase 2 雙盲試驗和數篇系統性回顧支持，但回顧內容多屬觀察性研究。此用途在香港屬於**適應症外使用**，且尚無已確認的 Phase 3 療效結果。

## 安全性考量

安全性資訊請參考原廠仿單。香港衛生署仿單的警語與禁忌尚未取得，藥物交互作用查詢也無資料。

以下為本次預測分析註記的主要風險，待仿單確認：
- 顆粒球缺乏症（需監測 ANC）
- 心肌炎
- 癲癇發作
- 代謝風險

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有 1 個已完成的 Phase 2 雙盲試驗和多篇系統性回顧支持難治型躁症的使用，但樣本小、缺乏 Phase 3 確認。
- Clozapine 有血液學與心臟風險，且此用途屬適應症外使用，應限縮在難治型病例。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌（目前為阻擋性資料缺口，需先完成安全篩查）
- 取得詳細的作用機轉資料（DrugBank）
- 確認 NCT05603104 是否納入 Clozapine 及是否有躁症終點
- 建立強制監測計畫：ANC、心臟與代謝指標
- 補充更大型的對照試驗證據。證據包中「雙相情感障礙」項目另列有已完成的兒童難治型雙相 Phase 3 試驗 NCT00036582（Clozapine 對照安慰劑，n=116），可一併評估
