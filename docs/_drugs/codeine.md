# Codeine：從咳嗽與疼痛到鼻腔疾病（預測不成立，建議暫緩）

## 一句話總結

Codeine（可待因）是鴉片類藥物，香港已有多張許可證上市，常見劑型為糖漿、口服液與錠劑。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，但目前**沒有臨床試驗**，僅有 **2 篇個案報告**，且內容都是鴉片類藥物濫用造成的傷害，並非療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Codeine 是鴉片類藥物，在許多國家用於鎮咳與輕中度疼痛，但本次資料未提供香港核准適應症，因此無法確認原適應症與新適應症的關聯。

現有兩篇文獻都是傷害通報：一篇是經鼻吸入 hydrocodone-acetaminophen 造成鼻腔與咽部壞死；另一篇是含 codeine 與鴉片的異物滯留鼻腔，形成鼻石（rhinolith，文中稱為「opioma」）。兩者都不支持治療效果。

99.93% 的高分較可能反映知識圖譜中藥物與鼻腔病變的關聯，而非治療作用。因此，這個預測在機轉與臨床上都缺乏支持。

## 安全性考量

安全性資訊請參考原廠仿單。

其他預測適應症的文獻也提示風險：codeine 會直接刺激皮膚肥大細胞釋放組織胺，可能誘發或加重蕁麻疹，因此在蕁麻疹方向應視為安全性訊號，而非治療機會。

## 結論與下一步

**決策：Hold**

**理由：**
- 現有文獻只有鴉片類藥物濫用傷害的個案報告，沒有療效證據，高分很可能只是知識圖譜的關聯假象。
- 其餘預測（急性喉咽炎、三叉神經自律神經性頭痛、過敏性蕁麻疹）也沒有可支持治療的證據；蕁麻疹反而顯示潛在風險。

**若要推進需要：**
- 取得香港衛生署仿單，確認原適應症、警語與禁忌症
- 補齊 codeine 的作用機轉資料（DrugBank）
- 若仍想探索，須先有臨床前或臨床證據顯示 codeine 對鼻腔疾病有治療作用
- 蕁麻疹方向建議改做安全性審查，而非老藥新用
