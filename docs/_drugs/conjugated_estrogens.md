# Conjugated estrogens：從雌激素補充治療到偏頭痛

## 一句話總結

Conjugated estrogens（結合型雌激素）是雌激素製劑，香港有 6 張許可證，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效。
目前**沒有臨床試驗登記**，只有 **16 篇文獻**（綜述、世代研究和小型臨床研究，無 RCT），證據停在 L3，屬於「研究問題」階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Conjugated estrogens 屬於雌激素類藥物，目前資料無法確認其原適應症，因此只能從偏頭痛與雌激素的關聯來推論。

偏頭痛和雌二醇濃度的波動關係密切。文獻指出，雌激素「撤退」是經期無預兆偏頭痛的誘因，高雌激素則可能誘發預兆。穩定雌激素濃度，例如在經期前後或更年期轉換期，理論上可能減少發作。

但文獻結果並不一致，口服或濃度起伏大的荷爾蒙補充治療 (HRT) 也有加重偏頭痛的報告，給藥途徑和劑量模式會影響結果。Conjugated estrogens 是口服製劑，濃度波動可能比經皮雌二醇大，推論到偏頭痛的不確定性高。99.77% 的分數只是模型預測，不等於療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有觀察性研究和綜述，沒有試驗登記或 RCT，且文獻結果不一致，口服 HRT 也有加重偏頭痛的報告。
- 香港仿單的警語與禁忌資料缺漏，屬於阻斷性缺口，無法進入安全性篩選。
- 有預兆偏頭痛本身與缺血性中風風險相關，雌激素可能疊加這項風險。同一批預測中的血栓相關疾病（如血栓形成傾向、抗凝血酶缺乏）在機轉上也不適用，屬模型的凝血路徑關聯。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症。
- 補充 DrugBank 作用機轉資料，以及原適應症資料。
- 設計偏頭痛族群（尤其經期相關、更年期偏頭痛）的對照試驗，並比較口服與經皮給藥的差異。
- 排除或分層處理有預兆偏頭痛、血栓風險高的族群。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。*
