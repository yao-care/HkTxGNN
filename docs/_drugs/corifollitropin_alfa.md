# Corifollitropin alfa：從控制性卵巢刺激到胃十二指腸炎（模型預測，證據極弱）

## 一句話總結

Corifollitropin alfa 是長效型 FSH 類似物，在香港以 ELONVA 品名上市，用於控制性卵巢刺激（原適應症資料庫未提供明確文字）。
TxGNN 模型預測它可能對**胃十二指腸炎 (Gastroduodenitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Corifollitropin alfa 是長效 FSH 類似物，作用於性腺的 FSH 受體，已知用於控制性卵巢刺激。

胃十二指腸炎屬於上消化道黏膜發炎，與 FSH 受體訊號之間沒有已知的機轉關聯。這個高分預測（99.65%）很可能是知識圖譜相近性造成的假象，而非真實的藥理訊號。

其他排名靠前的預測（消化性潰瘍、消化性食道炎、偏頭痛各型、雷諾氏病、肺高壓等）同樣沒有機轉或臨床支持。偏頭痛與性荷爾蒙波動雖有間接關聯，但促性腺激素刺激會升高雌二醇，反而可能加重偏頭痛。
