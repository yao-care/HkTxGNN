# Crizotinib：從 ALK 陽性非小細胞肺癌到遺傳性牙齦纖維瘤病

## 一句話總結

Crizotinib 是 ALK / ROS1 / MET 三種激酶的抑制劑，原本用於 ALK 或 ROS1 陽性的非小細胞肺癌（NSCLC）。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，只有模型分數。

## 為什麼這個預測合理？

Crizotinib 是 ATP 競爭型小分子酪胺酸激酶抑制劑，標的為 ALK、ROS1 與 c-MET。DrugBank 的作用機轉欄位目前缺資料，以上標的來自文獻與證據包的機轉分析。

**這個預測在機轉上缺乏支持。** 遺傳性牙齦纖維瘤病並非已知由 ALK、ROS1 或 MET 驅動的疾病。TxGNN 給出 99.81% 的高分，較可能反映知識圖譜中的間接關聯，而不是實際的藥理依據。目前沒有任何試驗或文獻能佐證。

因此這個預測只能視為需要進一步驗證的假說，不宜視為有效的老藥新用候選。

## 安全性考量

官方警語、禁忌症與藥物交互作用資料尚未取得（香港衛生署仿單未解析），請參考原廠仿單。

文獻中報告過以下安全性訊號，若進入任何再利用評估，都需納入考量：
- **肝毒性**：曾有致死性猛爆型肝衰竭的個案報告
- **心臟毒性**：心搏過緩、QT 間期延長、心包膜炎等
- **肺部毒性**：藥物誘發的間質性肺病與機化性肺炎

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測沒有臨床試驗、文獻或機轉依據，只有模型分數，證據等級為 L5。
- 仿單的警語與禁忌症資料缺失，屬於阻斷性缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得並解析香港衛生署仿單，補齊警語與禁忌症（DG001，阻斷性缺口）
- 從 DrugBank 補齊作用機轉資料（DG002）
- 查證牙齦纖維瘤病是否存在 ALK / ROS1 / MET 相關的分子機轉，例如前臨床研究
- 確認此預測是否為疾病本體映射造成的假訊號
- 現階段建議把資源轉向同一藥物下證據較強的候選。例如 rank 4 的肺門癌有 ALK / ROS1 陽性肺腺癌的個案報告，但較接近原適應症族群；rank 7 的肺生殖細胞瘤有腫瘤不分類型的生物標記導向試驗（如 NCI-MATCH），但仍需先確認腫瘤帶有 ALK / ROS1 / MET 變異。
