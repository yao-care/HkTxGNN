# Crotamiton：從疥瘡與皮膚搔癢到恙蟲皮膚炎

## 一句話總結

Crotamiton 是外用殺疥蟎與止癢藥，在香港以 10% 乳膏等外用製劑上市。
TxGNN 模型預測它可能對**恙蟲皮膚炎 (Trombiculiasis)** 有效。
目前**沒有臨床試驗**，也**沒有文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，DrugBank 也沒有提供原適應症。以下推論來自一般藥理知識，並非本次提供的證據。Crotamiton 是外用殺疥蟎與止癢藥，已知用於疥瘡與皮膚搔癢。

恙蟲皮膚炎（俗稱 chigger 皮膚炎）是恙蟎幼蟲叮咬造成的皮膚病，特徵是劇烈搔癢。它與疥瘡同屬蟎類相關的搔癢性皮膚病，TxGNN 的高分很可能反映這種相似性。這個關聯在生物學上說得通，但需要臨床資料驗證。

同一份預測清單的第 2 到第 10 名分別是淋巴結柵欄狀肌纖維母細胞瘤、腹腔動脈壓迫症候群、腹部囊性淋巴管瘤、腹部異位妊娠、薦骨脊索瘤、麥粒腫等。這些疾病與外用止癢劑的藥理沒有合理關聯，多半是知識圖譜結構造成的假象，不建議作為研究方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（96.24%），但沒有任何臨床試驗或文獻佐證，證據等級僅 L5。
- 作用機轉與原適應症資料都缺漏，機轉推論只靠一般藥理知識。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症。
- 從 DrugBank 補齊作用機轉與原適應症資料。
- 系統性檢索 Crotamiton 用於恙蟲皮膚炎或類似蟎類皮膚炎的臨床與文獻報告。
- 評估外用於皮膚破損處的安全性與使用族群限制。
