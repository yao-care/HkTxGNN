# Cyclopentolate：從眼科用藥到馬尾症候群

## 一句話總結

Cyclopentolate 是一種局部使用的眼科藥物（點眼液），在香港已有 2 張上市許可證。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 提供的詳細作用機轉資料。依一般藥理知識，Cyclopentolate 是一種毒蕈鹼受體拮抗劑（抗膽鹼藥物）。

馬尾症候群是需要手術處理的神經壓迫急症。抗毒蕈鹼藥物頂多能緩解繼發的神經性膀胱症狀，無法處理疾病本身。因此我們認為兩者之間**沒有直接的機轉關聯**。0.995 的高分很可能來自知識圖譜中與膀胱或神經肌肉功能障礙節點的相近性，並非真正的治療關係。

此外，Cyclopentolate 目前僅有眼用劑型。若要全身給藥，需另行評估安全性。

## 結論與下一步

**決策：Hold**

**理由：**
三個預測適應症都只有模型分數，沒有任何試驗或文獻。馬尾症候群在機轉上並無關聯，神經性膀胱和大腸激躁症雖在類別層級上合理，但已有核准的抗膽鹼藥物，重新開發的附加價值有限。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料，這是進入安全性篩選的前提
- 補齊 DrugBank 的作用機轉資料
- 將「已淘汰」的神經性膀胱術語對應到現行疾病概念，再重新評估
- 若考慮全身給藥，需另做劑型與全身性抗膽鹼安全性評估
- 檢索是否有神經性膀胱或腸道痙攣方向的臨床前或臨床研究

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
