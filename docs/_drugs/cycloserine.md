# Cycloserine：從抗菌用途到腸躁症

## 一句話總結

Cycloserine 是一種抑制細菌細胞壁合成的藥物，香港有 1 張許可證，但許可證未載明核准適應症。
TxGNN 模型預測它可能對**腸躁症 (Irritable Bowel Syndrome)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Cycloserine 已知屬於細菌細胞壁合成抑制劑，其抗菌作用已被認識。它的 D 型異構物也被研究為 NMDA 甘胺酸位點的部分促效劑。但現有資料無法建立從這些機轉到腸躁症的合理路徑。

腸躁症是功能性腸道疾病，和抗菌作用沒有直接的已知關聯。是否經由 NMDA 調節或腸道菌叢影響症狀，目前沒有任何資料可以驗證。

TxGNN 分數很高（99.95%，全體排名第 1560），但這只是知識圖譜的模型推論，本身不構成證據。

## 結論與下一步

**決策：Hold**

**理由：**
腸躁症這個預測只有模型分數，沒有試驗、文獻或明確的機轉支持（L5）。香港仿單的警語與禁忌資料也尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉資料，評估與腸躁症的機轉關聯
- 系統性檢索 cycloserine 或 D-cycloserine 用於功能性腸道疾病的研究
- 確認許可證的核准適應症與劑型

**其他預測適應症備註：**
同一份預測中，失眠 (Insomnia) 有 3 個間接相關的 D-cycloserine 試驗，但目標疾病是創傷後壓力症、纖維肌痛與雙相憂鬱。另有一篇個案報告指出 cycloserine 可能**誘發**失眠與精神症狀，與預測方向相反，須留意這個安全訊號。結膜炎僅有 1960 年代的間接文獻。這些適應症目前也都是 Hold。
