# Cyproterone Acetate：從抗雄性素黃體素到偏頭痛

## 一句話總結

Cyproterone Acetate（CPA，環丙孕酮）是一種具抗雄性素作用的黃體素類藥物，可抑制促性腺激素。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前**沒有相關臨床試驗**，3 篇文獻也都沒有直接證明 CPA 能治療或預防偏頭痛。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，CPA 是抗雄性素黃體素，能抑制促性腺激素。偏頭痛與荷爾蒙變化（例如雌激素下降）有關，因此兩者之間有間接的連結。

文獻中有一些神經層面的線索。一篇 2003 年的回顧指出，CPA 會增加多巴胺反應，並與鴉片受體結合，這些作用與其經典的抗雄性素作用無關。不過這只是基礎機轉的討論，並未證明能改善偏頭痛。

整體來說，這個預測主要來自知識圖譜的鄰近關係。已檢索到的文獻談的是黃體素對腦部的影響、停經後荷爾蒙治療和婦科副作用，沒有一篇顯示 CPA 能治療或預防偏頭痛。

## 安全性考量

安全性資訊請參考原廠仿單。

另外，本次檢索到的文獻對含 CPA 的產品提出了以下警訊：

- **靜脈血栓風險**：含 CPA 的複方避孕藥與較高的靜脈血栓栓塞 (VTE) 風險、凝血酶生成增加和活化蛋白 C 抗性有關，也與第五凝血因子 Leiden 突變有不良交互作用。
- **伴前兆的偏頭痛**：這類偏頭痛是缺血性中風的已知風險因子，使用複方荷爾蒙避孕藥時需特別謹慎。含 CPA 的產品若用於這類患者，可能造成傷害而非益處。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.66%），但屬於純模型預測，沒有臨床試驗，文獻中也沒有 CPA 用於偏頭痛的直接證據。
- 血栓風險與伴前兆偏頭痛的中風風險，使這個方向的風險效益比不明。

**若要推進需要：**
- 補上 CPA 的作用機轉資料（MOA），釐清它與偏頭痛病理的關聯。
- 取得香港衛生署仿單的警語與禁忌症，完成安全性初篩。
- 有針對 CPA 的偏頭痛臨床或前臨床研究，並評估血栓風險。
- 另一個預測適應症「閉經 (Amenorrhea)」的證據較強（L3，有 1 個 Phase 4 試驗與多篇臨床報告），可優先評估。但其試驗多為多囊卵巢症候群或月經不規則的研究，且缺乏 Phase 3 RCT，同樣需要衡量血栓風險。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選須經臨床驗證後才能應用。*
