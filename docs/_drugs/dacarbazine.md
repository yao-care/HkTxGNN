# Dacarbazine：從何杰金氏淋巴瘤與轉移性黑色素瘤到上呼吸消化道腫瘤

## 一句話總結

Dacarbazine 是一種烷化劑類化療藥物，原本用於何杰金氏淋巴瘤與轉移性黑色素瘤。
TxGNN 模型預測它可能對**上呼吸消化道腫瘤 (Upper Aerodigestive Tract Neoplasm)** 有效，但目前**沒有相關臨床試驗**，僅有 **20 篇間接相關文獻**，證據仍屬初步。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Dacarbazine 是烷化劑，屬 DNA 甲基化前驅藥，經肝臟 CYP 代謝活化為 MTIC 後發揮細胞毒性。

原適應症與新適應症之間的關聯主要是**部位上的間接關聯**：黑色素瘤可轉移至頭頸或上呼吸消化道黏膜，何杰金氏淋巴瘤也可侵犯頭頸部的結外或淋巴結部位。

需要注意，0.993 的高分很可能來自與已核准適應症的重疊，而非 Dacarbazine 對上呼吸消化道鱗狀細胞癌有療效的直接證據。目前文獻也未顯示單用 Dacarbazine 對此類腫瘤有益。

仿單的警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 模型分數雖高，但沒有任何臨床試驗，文獻也僅為間接關聯，未顯示單用 Dacarbazine 對上呼吸消化道腫瘤有療效。
- 該藥骨髓抑制風險高，且仿單安全性資料與作用機轉資料均尚未取得。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌
- 補充 DrugBank 作用機轉資料
- 界定具體的目標腫瘤類型（例如頭頸部黏膜黑色素瘤與鱗狀細胞癌的區別）
- 檢索 Dacarbazine 用於該腫瘤類型的直接臨床研究，並評估與現行標準治療相比的角色
- 若評估推進，需制定血液學監測與肝腎功能風險管理計畫
