# Dapoxetine：從（原適應症未記載）到偏頭痛

## 一句話總結

Dapoxetine 是一種短效型選擇性血清素再吸收抑制劑（SSRI），在香港已有上市許可證。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
但目前**沒有臨床試驗**，僅有 **2 篇文獻**（皆為間接證據），屬於模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Dapoxetine 是短效型 SSRI，透過抑制血清素再吸收發揮作用。血清素調節與偏頭痛的病理生理有一定關聯，機轉上可能適用於偏頭痛。

不過，支持證據相當間接。唯一相關的文獻是一篇 SSRI 類別的off-label 用途回顧，並非針對 dapoxetine。另一篇文獻探討的是 dapoxetine 在早發性射精患者的用藥順從性，與偏頭痛無關。

此外，Dapoxetine 設計為按需使用，半衰期短，與偏頭痛預防所需的長期持續給藥不太相符。TxGNN 分數雖高，但僅是計算預測。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有模型預測與間接的類別層級文獻，沒有任何 dapoxetine 用於偏頭痛的臨床試驗。
此外，短效、按需使用的藥動特性與偏頭痛預防的長期給藥需求不符。

**若要推進需要：**
- 取得香港衞生署仿單，確認警語與禁忌症（目前為阻擋性資料缺口）
- 補齊作用機轉（MOA）資料，例如查詢 DrugBank
- 確認核准適應症文字，釐清原適應症
- 找出 dapoxetine 或短效 SSRI 用於偏頭痛的直接臨床或前臨床證據
- 評估其藥動特性是否適合偏頭痛治療情境
