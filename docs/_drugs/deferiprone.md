# Deferiprone：從輸血性鐵過載（地中海型貧血）到肝性卟啉症

## 一句話總結

Deferiprone 是一種口服鐵螯合劑，原本用於 β 型地中海型貧血等血液疾病相關的鐵過載治療。
TxGNN 模型預測它可能對**肝性卟啉症 (Hepatic Porphyria)** 有效，
目前**沒有臨床試驗**，僅有 **2 篇前臨床文獻**支持這個方向，屬於初步的研究假說。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Deferiprone 是口服鐵螯合劑，已用於地中海型貧血的鐵過載管理，機轉上可能適用於與鐵過載相關的肝性卟啉症。

鐵過載會加劇尿卟啉的堆積。以晚發性皮膚卟啉症（porphyria cutanea tarda）為例，肝臟鐵含量升高是重要的致病因素，放血療法透過降低肝鐵而有效。因此，以螯合劑降低體內鐵，理論上可減輕卟啉堆積與疾病活性。

不過，目前證據是間接的：來自小鼠模型，以及另一種卟啉症亞型（先天性紅血球生成性卟啉症）的研究，尚無肝性卟啉症的人體試驗。

## 安全性考量

- **藥物交互作用**：已查得 100 筆交互作用紀錄，以下為列出的主要項目，皆為中度。
  - 含多價金屬陽離子的制酸劑與補充劑：鈣鹽（磷酸鈣、醋酸鈣、碳酸鈣、檸檬酸鈣、葡萄糖酸鈣、乳酸鈣等）、鎂鹽（氧化鎂、氫氧化鎂、碳酸鎂、硫酸鎂等）、氫氧化鋁
  - 鐵劑
  - 其他：高嶺土 (Kaolin)、厚朴土 (Attapulgite)、Sucralfate

  這類藥物可能與 deferiprone 螯合而影響吸收，合併使用時需留意服藥間隔。

其餘安全性資訊（警語、禁忌症）請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.20%），但證據僅限於小鼠模型與不同卟啉症亞型的前臨床研究（L4），沒有任何人體試驗，目前僅能視為研究假說。
- 安全性資料（仿單警語與禁忌）尚未取得，無法進行安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語、禁忌症與核准適應症
- 補充 deferiprone 的作用機轉資料
- 針對肝性卟啉症（如晚發性皮膚卟啉症）進行系統性文獻回顧，並設計小規模的概念驗證研究
- 評估與鐵過載狀態（血清鐵蛋白、肝鐵含量）的關聯，以界定可能受益的族群

---

**附註：** 其他預測適應症（肝肺症候群、特發性銅相關肝硬化、原發性門靜脈血栓、肝門脈硬化症、早發性家族性非肝硬化性門脈高壓、丙酮酸激酶缺乏症、遺傳性焦棘狀紅血球症）均無臨床試驗與文獻，僅屬模型預測（L5），建議暫緩。其中 β 型地中海型貧血伴其他表現屬於既有適應症的亞型，並非新的再利用訊號。
