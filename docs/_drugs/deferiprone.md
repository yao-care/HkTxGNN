# Deferiprone：從口服鐵螯合劑到肝性卟啉症

## 一句話總結

Deferiprone 是口服鐵螯合劑，已在香港上市。
TxGNN 模型預測它可能對**肝性卟啉症 (Hepatic Porphyria)** 有效。
目前**沒有臨床試驗**，只有 **2 篇前臨床（小鼠模型）文獻**支持這個方向，證據仍屬研究假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Deferiprone 是口服鐵螯合劑，能降低體內可用的鐵。在鐵過載相關疾病中，這個作用方向有其道理。

在數種卟啉症（包括遲發性皮膚卟啉症與先天性紅血球生成性卟啉症）中，鐵會促進卟啉堆積。降低鐵的可用量，理論上可減少卟啉累積。小鼠研究顯示，鐵螯合能改善先天性紅血球生成性卟啉症 (CEP) 的溶血性貧血與皮膚光敏感。在遲發性皮膚卟啉症型模型中，也能減少尿卟啉堆積。

但有兩點限制：
- 所有證據都來自動物實驗，尚無人體資料。
- CEP 嚴格來說不屬於肝性卟啉症，與預測疾病名稱只有部分吻合。

## 安全性考量

安全性資訊請參考原廠仿單。

已知 Deferiprone 有無顆粒球症風險，若推進研究需要嚴密的血液學監測。

---

## 結論與下一步

**決策：Hold**

**理由：**
- 證據只有小鼠模型，沒有任何臨床試驗，屬於「研究問題」層級。
- 動物模型的疾病（CEP、遲發性皮膚卟啉症型）與預測的「肝性卟啉症」也不完全對應。

**若要推進需要：**
- 補齊香港仿單的警語與禁忌資料，以及作用機轉資料，才能進入安全性篩選。
- 釐清目標卟啉症亞型（遲發性皮膚卟啉症或 CEP），並搜尋人體病例報告或臨床研究。
- 針對無顆粒球症風險，擬定血液學監測計畫。

**其他預測適應症備註：**
- 「β 型地中海貧血（其他表現）」（分數 99.03%，L4）在機轉上最直接，因為輸血依賴型貧血會造成鐵過載。但現有文獻只有綜述與觀察性研究，並非 Deferiprone 專屬的對照證據。建議先對照法規仿單與試驗登記，確認是否已有核准或試驗支持。
- 其餘 7 項預測（肝肺症候群、特發性銅相關肝硬化、原發性門靜脈血栓、肝門脈硬化、早發性家族性非肝硬化性門脈高壓、丙酮酸激酶缺乏症、遺傳性熱變形紅血球增多症）都沒有試驗或文獻，機轉關聯薄弱，建議 Hold。
