# Degarelix：從晚期前列腺癌到多毛症（預測）

## 一句話總結

Degarelix 是 GnRH 受體拮抗劑，已知用於成人前列腺癌的荷爾蒙治療。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測，機轉上的關聯也很弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供 MOA）。根據已知資訊，Degarelix 是 GnRH 受體拮抗劑，會阻斷腦下垂體的 GnRH 受體，降低 LH/FSH 與性腺雄性素的分泌。

多毛症通常與雄性素無關，因此和 Degarelix 的作用途徑連結薄弱。模型給出高分，較可能是知識圖譜結構造成的假象，而不是真實的藥理關聯。

**其他排名靠前的預測也大多缺乏合理機轉**，例如 Ambras 型先天性全身多毛症（染色體 8 重排影響 TRPS1）、Dandy-Walker 畸形症候群、遺傳性毛幹異常。它們都不受 GnRH－性腺軸驅動。

**唯一生物學上較連貫的候選是中樞性性早熟 (Central Precocious Puberty)**（預測分數 99.67%）。這個疾病由 GnRH 過早脈衝式分泌驅動，Degarelix 阻斷 GnRH 受體在機轉上說得通。但目前標準治療已是 GnRH 促效劑，拮抗劑能否帶來額外價值仍是待研究的問題，且沒有兒科資料、試驗或文獻。此項被標為「Research Question」。

## 結論與下一步

**決策：Hold**

**理由：**
- 全部預測都停留在 L5（僅有模型預測），排名第一的多毛症沒有試驗與文獻，機轉上也缺乏合理連結。
- 香港仿單的警語與禁忌症資料尚未取得，無法進入安全性篩選（S1）。

**若要推進需要：**
- 從香港衛生署下載並解析仿單，補齊警語、禁忌症與核准適應症。
- 從 DrugBank 補齊作用機轉資料。
- 若要探索，優先針對中樞性性早熟，檢視 GnRH 拮抗劑的兒科資料與文獻，並評估相對於 GnRH 促效劑的附加價值。
- 對其他低機轉合理性的預測，建議不投入資源，除非出現獨立的文獻或試驗訊號。
