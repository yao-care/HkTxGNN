# Demeclocycline：從（原適應症未載明）到慢性篩竇炎

## 一句話總結

Demeclocycline 是四環素類抗生素，但目前資料中沒有記載其原適應症。
TxGNN 模型預測它可能對**慢性篩竇炎 (Chronic Ethmoidal Sinusitis)** 有效，
目前**沒有臨床試驗**，只有 **1 篇**間接相關文獻（僅描述疾病病理，未評估此藥），屬於純模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Demeclocycline 屬於四環素類抗生素，這一類藥物被報告具有抗發炎與抑制基質金屬蛋白酶（MMP）的作用。

慢性篩竇炎的特徵是黏膜慢性發炎，並可能伴隨鄰近骨質的重塑。類別層級的推論是：抗發炎與 MMP 抑制作用可能與黏膜及骨質重塑有關。但這只是假說，尚未針對 Demeclocycline 驗證。

TxGNN 分數很高（99.14%），但這是知識圖譜的預測結果，可能反映的是與鼻竇相關疾病在圖譜上的鄰近程度，不代表療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有任何臨床試驗，唯一的文獻也未評估此藥，證據等級為 L5。
- 作用機轉與原適應症資料缺漏，且安全性資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症
- 從 DrugBank 補充作用機轉與原適應症
- 確認許可證產品（LEDERMIX PASTE）的劑型、核准適應症與給藥途徑是否適用於鼻竇疾病
- 搜尋四環素類（含 Demeclocycline）用於慢性鼻竇炎的臨床或前臨床研究，以建立實質證據
