## Desogestrel：從避孕到閉經（Amenorrhea）
{: .text-alpha }

## 一句話總結

Desogestrel 是一種第三代黃體素（progestin），在香港以口服避孕藥成分上市。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，
目前有 **1 個臨床試驗**（與本藥直接關聯性低）和 **11 篇文獻**，證據多為間接或類別層級，屬於研究假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Desogestrel 是黃體素類藥物，可抑制下視丘－腦下垂體－卵巢軸，常與乙炔雌二醇（ethinylestradiol）合併作為複方口服避孕藥使用。

在下視丘性寡經／閉經（例如運動員）的情況下，複方口服避孕藥可提供外源性雌激素與黃體素支持，使撤退性出血恢復規律，並可能有助於維持骨密度。不過這只是改善症狀（月經缺失），並不能恢復自身的排卵功能，因此其關聯性屬於「支持性」而非「疾病修飾性」。

其他排名較高的預測（如乳房腺病、乳房膿瘍、原發性卵巢衰竭等）幾乎沒有臨床或文獻證據，高分較可能反映知識圖譜中的網絡鄰近性，並非治療依據。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（來自藥物－疾病禁忌關聯，並非仿單內容）：高血壓、癲癇、卟啉症、肝臟疾病、膽囊疾病、高血糖／糖尿病、高三酸甘油脂血症、高鈣血症、甲狀腺功能低下、全身性紅斑狼瘡、氣喘、乳癌、血栓性靜脈炎、子宮肌瘤等。
- **藥物交互作用**：共查得 43 筆，其中列出的多為中度（Moderate）等級，主要涉及降血糖藥物，可能影響血糖控制，例如：
  - 胰島素類（degludec、detemir、glulisine、aspart 等）
  - Metformin、Rosiglitazone、Nateglinide
  - DPP-4 抑制劑（Alogliptin、Linagliptin）
  - GLP-1 促效劑（Liraglutide、Lixisenatide、Albiglutide）
  - SGLT2 抑制劑（Dapagliflozin、Ertugliflozin）
  - 其他：Aprepitant、Glycerol phenylbutyrate、Metreleptin

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的相關臨床試驗與 Desogestrel 的直接關聯性低，文獻多為綜述或類別層級資料，目前僅能視為研究問題。
- 複方口服避孕藥對下視丘性閉經僅能改善症狀，且知識圖譜顯示多項潛在禁忌，需謹慎評估風險與效益。

**若要推進需要：**
- 取得針對 Desogestrel（含單方與複方）治療閉經的對照試驗或高品質觀察性研究
- 補充詳細的作用機轉資料（MOA）
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌
- 評估目標族群（如運動員、青少女）的血栓與代謝風險，並與雌激素替代療法作比較
- 釐清各許可證的劑型與核准適應症資料
