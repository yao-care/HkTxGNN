# Dexchlorpheniramine Maleate：從（原適應症未載明）到急性間歇性紫質症

## 一句話總結

Dexchlorpheniramine Maleate（右氯非尼拉敏）是第一代 H1 受體拮抗劑（抗組織胺藥物），在香港已有多張單方許可證。
TxGNN 模型預測它可能對**急性間歇性紫質症 (Acute Intermittent Porphyria, AIP)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅是模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Dexchlorpheniramine 屬於烷基胺類 (alkylamine) 第一代 H1 受體拮抗劑，具有抗膽鹼與鎮靜特性。AIP 是血紅素合成途徑的疾病（porphobilinogen deaminase 缺乏），目前並未建立 H1 拮抗作用與矯正此途徑之間的直接機轉關聯。

可能的連結僅限於症狀處理，例如搔癢、噁心、焦慮或失眠，但這屬推測，缺乏本次資料的支持。

需特別注意：部分第一代抗組織胺在紫質症藥物安全資料庫中有被列出。此藥用於 AIP 是否安全，必須先對照權威的紫質症藥物資料庫（如美國紫質症基金會 American Porphyria Foundation 或歐洲紫質症網絡 European Porphyria Network）確認，之後才能進一步考慮。

0.991 的分數是計算模型的預測結果，不等同於療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測（證據等級 L5），沒有臨床試驗或文獻支持，作用機轉資料也缺乏。
- 第一代抗組織胺在紫質症患者的安全性尚未確認，存在潛在風險，需先釐清。

**若要推進需要：**
- 對照權威紫質症藥物安全資料庫（美國紫質症基金會、歐洲紫質症網絡），確認 Dexchlorpheniramine 在 AIP 患者的安全性
- 補齊作用機轉 (MOA) 資料，並分析其與 AIP 病理的機轉關聯
- 取得香港衛生署的仿單，取得警語與禁忌資訊，並確認原適應症
- 系統性檢索臨床試驗與文獻，判斷是否有任何支持證據
- 若安全性無疑慮，再釐清預期的臨床用途（例如是否僅為症狀處理）
