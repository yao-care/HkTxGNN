# Dexlansoprazole：從胃食道逆流疾病到活動性消化性潰瘍

## 一句話總結

Dexlansoprazole 是雙重延遲釋放型質子幫浦抑制劑（PPI），文獻與臨床試驗顯示它主要用於逆流性食道炎與胃食道逆流疾病。
TxGNN 預測它可能對**活動性消化性潰瘍 (Active Peptic Ulcer Disease)** 有效。
目前有 **17 個相關試驗登記**和 **4 篇文獻**，但直接針對 dexlansoprazole 與潰瘍的證據很少，多數是同類藥物（lansoprazole 等）的間接證據。

## 為什麼這個預測合理？

Dexlansoprazole 不可逆地抑制胃壁細胞的 H+/K+-ATPase（質子幫浦），減少胃酸分泌，這是 PPI 類藥物的共同機轉。它的雙重釋放設計可延長抑酸時間。

消化性潰瘍屬於酸依賴性疾病，抑制胃酸有助於潰瘍癒合，並降低復發與出血風險，PPI 也是潰瘍治療的第一線藥物。逆流性食道炎與潰瘍的病理都與胃酸有關，因此這個預測在機轉上合理。

但要注意，現有潰瘍證據大多來自 lansoprazole（dexlansoprazole 的母體消旋物）和其他 PPI／P-CAB 的試驗。這是類別效應，不是 dexlansoprazole 本身的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高，機轉也合理，但缺乏直接針對 dexlansoprazole 與潰瘍的臨床證據，現有證據只有 L4，來自 lansoprazole 等同類藥物。
- 香港仿單的警語與禁忌資料尚缺，安全性篩選無法進行。
- 這個方向目前適合作為研究問題，不宜直接推進。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與核准適應症。
- 查證 NCT05448001 等試驗中 dexlansoprazole 的實際角色（研究藥或對照藥）。
- 尋找或設計 dexlansoprazole 針對胃潰瘍或十二指腸潰瘍的直接比較試驗。
- 補充 DrugBank 的作用機轉資料，並評估與 clopidogrel 等藥物的交互作用。

**補充：**同一份預測中，十二指腸潰瘍與胃潰瘍同樣只有類別層級證據。失酸症、皮革胃等預測與 PPI 機轉不符，可能是知識圖譜的假關聯，不建議追蹤。
