# Dexpanthenol：從皮膚黏膜修護到肛門直腸狹窄

## 一句話總結

Dexpanthenol（泛醇）為泛酸（維生素 B5）前驅物，全球廣泛用於皮膚屏障修復、傷口照護及黏膜保護（以 Bepanthen® 系列產品聞名），惟在香港尚無正式藥品許可記錄。TxGNN 模型以高分（99.72%）預測其對**肛門直腸狹窄 (Anorectal Stricture)** 具再利用潛力，然而目前**無任何臨床試驗或文獻**支持此特定方向，屬純模型預測信號，建議暫緩推進。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Dexpanthenol 是泛酸（Vitamin B5）的活性醇型前驅物，吸收後在體內轉換為泛酸並進入輔酶 A（CoA）合成路徑，支持細胞代謝與組織修復。局部應用時，可促進角質形成細胞及成纖維細胞增殖、抑制促炎細胞因子（IL-1α、TNF-α），並增強皮膚及黏膜屏障完整性。這些特性使其在皮膚及黏膜損傷情境下具有廣泛的既有應用基礎。

肛門直腸狹窄的核心病理機轉為**纖維化瘢痕組織的異常堆積**，通常繼發於手術吻合、放射治療損傷或慢性炎症（如克隆氏症、潰瘍性直腸炎）。理論上，Dexpanthenol 在術後早期可能透過促進黏膜上皮再生、抑制過度炎症反應，減緩早期纖維化的進展；部分歐洲市場亦有 Bepanthen® 栓劑用於直腸術後黏膜照護的實務應用。

然而，對於**已成熟的纖維化狹窄**，現有機轉缺乏能逆轉膠原蛋白過度沉積的依據。TxGNN 的高分（0.9972）可能源自知識圖譜中結直腸組織類型的相似性聯結，以及 Dexpanthenol 在直腸黏膜保護的間接應用紀錄，而非針對狹窄病理的直接治療信號。在無任何臨床或文獻數據的情況下，此預測的臨床可信度有限。

## 結論與下一步

**決策：Hold**

**理由：**
肛門直腸狹窄以纖維化為核心病理，標準治療為外科切除或內鏡擴張；Dexpanthenol 的黏膜修復機轉對已成熟纖維化狹窄缺乏有效干預依據，且本資料集無任何臨床試驗或文獻支持，僅憑 TxGNN 知識圖譜預測分數，不足以進入正式再利用評估流程。

**若要推進需要：**
- 補充 Dexpanthenol 完整作用機轉資料（來源：DrugBank API，缺口 DG002）
- 補充香港仿單警語與禁忌事項（來源：衛生署官網，缺口 DG001）
- 針對「直腸術後黏膜保護」而非「治療既有狹窄」重新定義切入點，並進行 PubMed 補充文獻搜尋
- 評估是否以「預防性應用（術後早期纖維化抑制）」作為概念驗證研究的替代框架
- **優先建議**：本次預測包含多個適應症候選，其中 **Rank 6「Exanthem（皮疹）」** 已具備 L2 等級臨床證據（1 個 Phase 3 RCT，n=160），且機轉吻合度高，建議優先評估此方向而非肛門直腸狹窄
