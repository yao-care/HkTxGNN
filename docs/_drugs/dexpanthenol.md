# Dexpanthenol：從香港已上市眼用製劑到肛門直腸狹窄 (Anorectal Stricture)

## 一句話總結

Dexpanthenol（右旋泛醇，維生素 B5 前驅物）在香港已有 2 張眼用製劑許可證。
TxGNN 模型預測它可能對**肛門直腸狹窄 (Anorectal Stricture)** 有效。
目前**沒有任何臨床試驗或文獻**支持，這只是模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Dexpanthenol 在體內會轉換為泛酸，而泛酸是輔酶 A 的前驅物。一般認為它有助於上皮修復與傷口癒合，這是預測與上市製劑之間唯一較鬆散的生物學連結。

但肛門直腸狹窄的本質是纖維化與結構性狹窄。外用或維生素衍生物的促修復作用，是否能改善這類病變，目前並無證據，合理性偏低。TxGNN 分數雖高（99.72%），僅代表知識圖譜上的關聯，不等於療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測（L5），沒有試驗或文獻，機轉上也缺乏可信的支持。
- 肛門直腸狹窄屬結構性纖維化病變，外用修復類成分不太可能改善。

**若要推進需要：**
- 針對「dexpanthenol + anorectal stricture」做專項文獻搜尋，確認是否有任何直接證據。
- 取得香港衞生署仿單，補齊原適應症、警語與禁忌。
- 補充 DrugBank 的作用機轉資料。
- 同一藥物的其他預測中，**發疹 (Exanthem)** 已有間接的臨床試驗（含 1 個 Phase 3 RCT，NCT01136005），證據等級 L4。**直腸炎**與**點狀上皮角結膜炎**機轉上較合理，但目前尚無證據。建議優先評估這些方向，而不是肛門直腸狹窄。
