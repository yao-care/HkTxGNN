# Dexrazoxane：從化療心臟保護到硬化性膽管炎

## 一句話總結

Dexrazoxane 是一種化療保護劑，在香港已有 1 張上市許可證。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅是模型預測，證據等級為 L5。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Dexrazoxane 已知的作用包括鐵螯合，以及對拓樸異構酶 II 的催化抑制，通常作為化療期間的心臟與組織保護劑。

依現有資料，這些作用與膽管病變之間沒有已確立的關聯。0.99 以上的高分應視為知識圖譜結構上的推論，不代表已有生物學依據。原適應症在香港許可證中也未登載，因此無法從「原適應症與新適應症的關聯」來佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有試驗與文獻佐證，機轉上也找不到合理連結，因此不建議在此適應症上投入資源。
- 同批預測的其他適應症（支氣管炎、傷寒類感染、結膜炎、泌尿道感染等）同樣沒有證據，且 dexrazoxane 沒有抗菌活性，生物學上不合理。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌資料（目前是阻擋性缺口，無法進入安全性篩選）。
- 補充 DrugBank 的作用機轉資料，再重新評估與膽管病變的機轉關聯。
- 系統性檢索 dexrazoxane 與硬化性膽管炎的前臨床與臨床研究。

**補充觀察：**
預測清單中，**膀胱炎 (Cystitis)** 是唯一有間接合理性的適應症（證據等級 L4，建議列為研究問題）。前臨床研究顯示，鐵死亡 (ferroptosis) 參與環磷醯胺誘發的出血性膀胱炎，而 dexrazoxane 的鐵螯合特性可能干擾鐵依賴性損傷。另有兩篇化療保護劑的綜述提到 dexrazoxane。但目前沒有試驗直接測試，綜述也非針對此適應症，且僅適用於化療引起的出血性膀胱炎，不適用於感染性膀胱炎。若要優先探索，這個方向比硬化性膽管炎更值得。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。*
