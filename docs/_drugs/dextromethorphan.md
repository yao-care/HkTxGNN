# Dextromethorphan：從鎮咳到鼻腔疾病

## 一句話總結

Dextromethorphan（右美沙芬）是常見的中樞性鎮咳藥，香港已有多張許可證上市。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，
但目前**沒有直接相關的臨床試驗或文獻**，僅有 1 個間接相關的試驗（憂鬱症 Phase 3），證據等級為 L4，屬於研究假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Dextromethorphan 是 NMDA 受體拮抗劑、sigma-1 受體促效劑，也是中樞性鎮咳藥。

鼻腔疾病常伴隨咳嗽、鼻後滴流等上呼吸道症狀，鎮咳作用在機轉上可能緩解這類症狀。不過這種關聯是間接的，只能緩解症狀，並非治療疾病本身；而且「鼻腔疾病」範圍很廣，關聯尚未獲得證實。

其他預測結果（如急性喉咽炎）同樣只有症狀緩解層面的推論，且都沒有臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高（99.98%），但沒有針對鼻腔疾病的直接臨床試驗或文獻，機轉關聯也只是間接推論。
- 其他預測適應症（如急性喉咽炎、白喉、過敏性蕁麻疹等）同樣缺乏證據，其中咽白喉和過敏性蕁麻疹在機轉上找不到合理依據。

**若要推進需要：**
- 補齊藥物作用機轉資料（可查詢 DrugBank）
- 取得香港衛生署仿單，確認警語、禁忌與原核准適應症
- 確認 NCT06958692 的登記內容，判斷是否與上呼吸道或鼻腔適應症有關
- 針對鼻腔疾病的具體亞型（如鼻炎、鼻竇炎）搜尋臨床試驗與文獻
- 釐清預測是要治療疾病本身，還是僅緩解症狀
