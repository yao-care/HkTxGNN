# Diazepam：從癲癇與焦慮到失眠

## 一句話總結

Diazepam（地西泮）是苯二氮平類藥物，原本用於癲癇、癲癇持續狀態、酒精戒斷、焦慮及破傷風等。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有臨床試驗**，僅有**約 18 篇間接文獻**，且多為綜述、中草藥研究與苯二氮平安全性論文，屬於模型預測加上機轉推論的階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。不過依文獻，Diazepam 屬於 GABA-A 受體的正向異位調節劑（PAM），具鎮靜、安眠作用。增強 GABA 抑制性傳導可縮短入睡時間、提升睡眠連續性，因此機轉上適用於失眠是合理的。

原適應症中的焦慮、癲癇與酒精戒斷，同樣依賴中樞神經抑制作用，與失眠在神經藥理上有共通點。

但需要注意：Diazepam 已在臨床上以標示外方式用於短期睡眠障礙，所以這並非真正的新穎再利用訊號。半衰期長、隔日鎮靜、依賴性及對睡眠結構的影響，也限制了它作為失眠藥物的角色。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜關聯，非仿單原文）：肝衰竭、肝病、膽囊疾病、開角型與閉角型青光眼、阻塞性睡眠呼吸中止症、先天性中樞性低通氣症候群、呼吸衰竭、肺部疾病、重症肌無力、神經肌肉接合部疾病、物質濫用/依賴、焦慮相關疾患及神經症等。
- **藥物交互作用**：共查得 100 筆，主要例子如下：
  - **Major**：Morphine（合併使用有呼吸抑制風險）
  - **Moderate**：Bupropion、Aprepitant、Omeprazole、Esomeprazole、Cimetidine、Clarithromycin、Cisapride、Clotrimazole、Miconazole、Metoclopramide、Dronabinol
  - **Minor**：Dexamethasone、Betamethasone，以及多種制酸劑（氫氧化鋁、碳酸鈣、氧化鎂等）
- **文獻提示的風險**：依賴與濫用、長期使用相關的認知與跌倒風險、對睡眠結構的影響，以及兒童可能出現的矛盾反應。

其他警語與仿單禁忌資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L4：沒有臨床試驗，文獻多為間接證據，且偏向風險而非效益。
- Diazepam 對失眠的作用屬已知的藥物類別效應，已有標示外短期使用，缺乏真正的再利用價值；半衰期長、依賴性與隔日鎮靜也限制其角色，較新的安眠藥物更具優勢。

**若要推進需要：**
- 補齊作用機轉（MOA）與香港仿單的警語、禁忌與核准適應症資料
- 以 Diazepam 與現行首選療法（如 CBT-I、新型安眠藥）進行比較的臨床證據
- 針對老年人與長期使用者的依賴性、跌倒及認知風險評估

**其他預測適應症簡述（全部不建議推進）：**
- 睡眠障礙（入睡與維持）：證據屬 L4，只有類別層級的間接資料，且偏向風險。
- 巴比妥類濫用：證據屬 L4，僅為酒精戒斷適應症的延伸，且 Diazepam 本身有濫用風險。
- 幻覺劑濫用：證據屬 L4，僅為症狀處置，缺乏對照證據。
- 抗憂鬱藥濫用：證據屬 L4，疾病標籤疑似與文獻不符。
- 注意力不足過動症（含注意力不足型）、特定發展障礙：證據屬 L5，文獻提示可能有害。
- 馬尾症候群、已廢止的神經性膀胱：證據屬 L5，無任何研究資料。
