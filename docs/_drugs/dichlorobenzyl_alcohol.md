# Dichlorobenzyl Alcohol：從喉嚨不適（咽喉殺菌）到支氣管炎

## 一句話總結

Dichlorobenzyl Alcohol（二氯苄醇）是一種溫和的抗菌劑，常見於喉糖（含片）產品。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗**，且唯一檢索到的 **1 篇文獻**與本藥無關，證據僅限於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Dichlorobenzyl Alcohol 是喉嚨含片中的輕度抗菌成分，可能對上呼吸道刺激提供症狀緩解與局部抗菌作用。

支氣管炎主要影響下呼吸道，而含片作用於口腔與咽喉局部，藥物並不會到達支氣管。因此，兩者之間只存在間接、推測性的關聯，並未建立直接的機轉連結。

TxGNN 的高分（99.21%）屬於計算預測，沒有臨床資料支持，應謹慎解讀。

另一個預測適應症為**偏頭痛 (Migraine Disorder)**（分數 99.02%）。該預測同樣沒有試驗或文獻，也找不到與 CGRP、血清素或三叉神經血管路徑相關的機轉連結，目前不建議推進。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎與偏頭痛兩個預測皆僅有模型分數，沒有臨床試驗，也沒有直接相關的文獻。
- 含片作用於咽喉局部，無法到達下呼吸道，機轉上缺乏合理依據。

**若要推進需要：**
- 補齊作用機轉（MOA）資料，並評估局部作用能否延伸到下呼吸道
- 取得香港仿單中的核准適應症、警語與禁忌症
- 評估劑型與給藥途徑是否適合支氣管炎（目前僅有含片）
- 重新檢索與 Dichlorobenzyl Alcohol 直接相關的臨床前或臨床研究
