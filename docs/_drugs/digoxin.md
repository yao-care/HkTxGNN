# Digoxin：從心臟疾病到變異型心絞痛（Prinzmetal angina）

## 一句話總結

Digoxin（地高辛）是洋地黃類強心配糖體，在香港以 Lanoxin 系列上市。
TxGNN 模型預測它可能對**變異型心絞痛 (Prinzmetal angina)** 有效，但目前**沒有臨床試驗**，僅有 **2 篇相關性很低的文獻**，證據僅止於模型預測，機轉上也不支持。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Digoxin 抑制 Na⁺/K⁺-ATPase，使細胞內鈣濃度上升，並增加迷走神經張力，藉此增強心肌收縮力與控制心室率。

變異型心絞痛的成因是冠狀動脈痙攣。Digoxin 可能促進血管收縮，因此在血管痙攣型心絞痛中是否有益，在生物學上令人存疑。目前找不到 Digoxin 與冠狀動脈痙攣之間有支持性的機轉連結。

TxGNN 的高分（0.998）只是知識圖譜的模型預測，不代表藥理上合理。這個預測需要謹慎看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測，沒有臨床試驗，兩篇文獻也與 Digoxin 療效無關。
- 機轉上，Digoxin 可能促進血管收縮，對冠狀動脈痙攣型心絞痛反而有疑慮。

**若要推進需要：**
- 取得香港衞生署的仿單，確認原適應症、警語與禁忌症
- 補充 Digoxin 的作用機轉資料
- 找出 Digoxin 與冠狀動脈痙攣之間的直接機轉或臨床證據；若找不到，建議不再往此方向推進
- 其他預測適應症（十二指腸阻塞、十二指腸潰瘍、十二指腸胃反流、缺血性中風易感性、低 α 脂蛋白血症）同樣只有模型預測，且缺乏機轉或臨床支持，目前也都維持 Hold
