# Diiodohydroxyquinoline：從阿米巴感染到骨放射壞死

## 一句話總結

Diiodohydroxyquinoline（碘羥喹，又稱 iodoquinol）是含碘的羥基喹啉類藥物，屬於腸腔內抗阿米巴藥，香港已有 1 張陰道錠許可證。
TxGNN 模型預測它可能對**骨放射壞死 (Osteoradionecrosis)** 有效，預測分數 97.96%。
目前**沒有臨床試驗，也沒有直接相關的文獻**，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Diiodohydroxyquinoline 是鹵化羥基喹啉類藥物，已知具有金屬螯合與抗微生物活性。它在阿米巴感染的用途已有長期臨床使用紀錄，但這些特性與放射線造成的骨損傷之間，資料中沒有任何文件化的機轉連結。

骨放射壞死的病理涉及組織缺氧、血管損傷與纖維化，並常合併局部感染。若要推論這個藥可能有用，只能假設抗微生物或螯合作用有幫助，這仍是**推測**，沒有實驗或臨床資料支持。

此外，此藥為腸腔內抗阿米巴藥，全身吸收有限，這與治療深部骨組織病變的需求並不吻合。TxGNN 的高分較可能來自知識圖譜的關聯性，並非已驗證的藥理機轉。

## 結論與下一步

**決策：Hold**

**理由：**
- 骨放射壞死的預測分數雖高（97.96%），但沒有任何試驗或文獻，也沒有機轉資料，證據等級僅 L5。
- 安全性資料（警語、禁忌症）也尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料，分析藥物與骨放射壞死之間的機轉連結。
- 評估陰道錠劑型與骨放射壞死所需給藥途徑是否相容。
- 檢索骨放射壞死相關的前臨床研究，例如抗菌、抗發炎或抗纖維化的動物模型。
- 若前臨床證據出現，再重新評估是否升級決策。
