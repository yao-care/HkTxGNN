# Diltiazem：從（原適應症資料缺漏）到缺血性中風易感性

## 一句話總結

Diltiazem 是一種非二氫吡啶類鈣離子通道阻斷劑，具血管擴張與降血壓作用，但本資料包未收錄其原適應症。
TxGNN 模型預測它可能對**缺血性中風易感性（obsolete susceptibility to ischemic stroke）**有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Diltiazem 是非二氫吡啶類鈣離子通道阻斷劑，具血管擴張與降血壓作用。機轉上，透過控制血壓、降低血管張力，可能有助於降低腦血管風險，但這個推論尚未經任何研究驗證。

需要特別留意：預測的疾病項目是本體論（ontology）中**已過時的條目**，描述的是「易感性」表型，而非可直接治療的臨床適應症。因此 0.99 的高分可能反映知識圖譜的結構特性，而非真實的治療訊號。

此外，原適應症與作用機轉資料都缺漏，無法將預測結果與已知藥理交叉比對。

**理由：**
- 僅有模型預測分數，無臨床試驗與文獻佐證（證據等級 L5）。
