# Dimenhydrinate：從暈動症與中樞性眩暈到過敏性蕁麻疹

## 一句話總結

Dimenhydrinate（茶苯海明）是 diphenhydramine 與 8-chlorotheophylline 的鹽類，原本用於**中樞神經源性眩暈**與**暈動症**。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，
但目前**沒有臨床試驗**，僅有 **1 篇文獻**（犬隻藥動學先導研究），證據相當有限。

## 為什麼這個預測合理？

Dimenhydrinate 是 diphenhydramine（第一代 H1 抗組織胺）與 8-chlorotheophylline 的鹽類。Diphenhydramine 成分可阻斷組織胺 H1 受體，而該受體正是介導蕁麻疹風團與紅斑反應的關鍵，因此機轉上具生物學合理性，也與第一代抗組織胺用於蕁麻疹的類別用法一致。

不過，目前缺乏詳細的作用機轉資料。Dimenhydrinate 現有適應症（暈動症、眩暈）主要仰賴中樞抗膽鹼與抗組織胺作用，且目前沒有針對 dimenhydrinate 本身用於蕁麻疹的資料。0.997 的預測分數僅為計算模型的推論。

另一個預測適應症為**寒冷性蕁麻疹 (Cold Urticaria)**（分數 99.24%，證據等級 L5）。其推論同樣僅基於抗組織胺類別，尚無任何 dimenhydrinate 或 diphenhydramine 的專屬資料，建議視為次要探索方向。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容，僅供參考）：
  - 心血管：高血壓、低血壓、急性冠心症、冠狀動脈疾病、心肌梗塞
  - 眼部：高眼壓、閉角型青光眼
  - 消化與泌尿：消化性潰瘍、幽門狹窄、良性攝護腺肥大、膀胱頸阻塞
  - 代謝與內分泌：糖尿病、糖尿病酮酸中毒、高血糖、痛風、甲狀腺機能亢進（含 Graves 病）、低磷血症
  - 血液與肝膽：肝病、膽囊疾病、血小板低下、凝血疾病、血紅素異常
  - 其他：物質濫用／依賴
- **藥物交互作用**：共查得 67 筆。
  - 重大 (Major)：氯化鉀 (Potassium chloride)、檸檬酸鉀 (Potassium citrate)
  - 中度 (Moderate)：多為抗膽鹼藥物（atropine、scopolamine、hyoscyamine、glycopyrronium、dicyclomine 等）以及嗎啡、鴉片、loperamide、metoclopramide、nabilone 等中樞抑制或腸蠕動相關藥物

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉（H1 阻斷）合理，但目前僅有一篇犬隻藥動學研究，沒有任何人體臨床試驗。
- 現有第一代抗組織胺與更新的第二代抗組織胺已是蕁麻疹的既有選擇，dimenhydrinate 的嗜睡與抗膽鹼副作用較明顯，相對優勢尚不明確。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料（目前缺口，屬阻斷性）
- 補充詳細的作用機轉資料
- 系統性搜尋 diphenhydramine／dimenhydrinate 用於蕁麻疹的人體證據
- 與現行蕁麻疹標準治療比較，評估臨床定位與效益風險
