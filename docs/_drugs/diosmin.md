# Diosmin：從靜脈功能不全到閉經

## 一句話總結

Diosmin 是一種黃酮苷類植物化合物，傳統上用於慢性靜脈功能不全與痔瘡相關的靜脈張力調節。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，預測分數高達 **99.42%**。
然而，目前**無任何臨床試驗或文獻**直接支持此預測方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據現有資訊，Diosmin 是一種天然黃酮苷，屬於靜脈強化劑（venotonic）類別，其主要藥理活性涉及改善靜脈張力、增強微血管通透性及抗炎作用。

TxGNN 模型的高分預測（0.994）最可能源自知識圖譜中的間接拓撲關聯，而非直接實驗驗證路徑。潛在的推論路徑包含三條假設性機轉：

1. **植物雌激素假說**：Diosmin 的黃酮骨架在結構上與雌激素有部分相似性，理論上可能與 ERα/ERβ 產生弱配體互動，進而影響下視丘-垂體-卵巢軸（HPO axis）。然而，Diosmin 本身的雌激素受體結合親和力數據目前缺乏。
2. **子宮微循環假說**：Diosmin 已知能改善靜脈張力與微血管功能，理論上可增加子宮內膜血流，對因子宮微循環不良所導致的繼發性閉經具有間接影響，但目前缺乏子宮特異性藥理研究。
3. **抗炎假說**：慢性炎症可能抑制排卵，而 Diosmin 具有 NF-κB 抑制活性，或許有間接助益；然而現有的炎症研究聚焦於腸道與靜脈系統，並非生殖系統。

綜合而言，Diosmin 與閉經的潛在機轉連結屬於「多跳式推論」路徑，尚無直接實驗支持。

## 結論與下一步

**決策：Hold**

**理由：**
目前 Diosmin 用於閉經的預測完全缺乏臨床試驗與文獻支持（證據等級 L5），且 Diosmin 在香港並無任何核准上市記錄，再加上作用機轉資料缺口（DG002）與安全性資訊缺口（DG001），現階段不具備推進條件。

**若要推進需要：**
- 補充 Diosmin 的詳細作用機轉資料（建議查詢 DrugBank API，對應資料缺口 DG002）
- 取得香港衛生署或原廠核准之仿單，確認警語與禁忌（對應資料缺口 DG001）
