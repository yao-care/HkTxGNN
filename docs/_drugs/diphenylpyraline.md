# Diphenylpyraline：從過敏性鼻炎等過敏／上呼吸道症狀到過敏性蕁麻疹

## 一句話總結

Diphenylpyraline 是第一代 H1 抗組織胺，原本用於過敏性鼻炎、血管運動性鼻炎、咽炎、感冒、結膜炎、蕁麻疹與血管性水腫等症狀。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，但目前**沒有臨床試驗與文獻**支持，僅有模型預測。
此預測很可能反映的是既有的蕁麻疹適應症，而非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Diphenylpyraline 屬於第一代 H1 抗組織胺，其類別特性是阻斷 H1 受體，減少組織胺引起的風團與紅斑反應，機轉上可能適用於過敏性蕁麻疹。

過敏性蕁麻疹屬於蕁麻疹的亞型，而蕁麻疹與血管性水腫本來就在此藥的既有適應症中。因此 0.996 的高分更可能反映既有的標示內用途，而不是全新的再利用訊號。

另外兩個預測也有類似情況：急性喉咽炎與既有的咽炎適應症相近，療效可能來自 H1 阻斷與第一代抗組織胺的抗膽鹼乾燥作用（減少分泌物與鼻後滴漏），屬於症狀緩解；鼻腔疾病則是範圍過廣的類別，與過敏性鼻炎、血管運動性鼻炎、感冒重疊，無法形成獨立的再利用假說。以上推論皆來自藥物類別知識，並無實際研究證據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜的藥物－疾病禁忌關聯，非仿單內容）：
  - 高血壓、眼壓過高
  - 消化性潰瘍
  - 良性前列腺增生、膀胱頸阻塞
  - 隅角閉鎖型青光眼
  - 甲狀腺機能亢進、葛瑞夫茲氏病、甲狀腺毒症

這些與第一代抗組織胺的抗膽鹼與擬交感神經相關風險一致。其餘警語、禁忌與藥物交互作用資料目前缺乏，詳細資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 三項預測皆只有模型分數，沒有任何臨床試驗或文獻，證據等級為 L5。
- 排名第一的預測與既有適應症高度重疊，不構成真正的新適應症；且仿單的警語與禁忌資料尚缺，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署許可證的仿單（警語、禁忌、適應症），確認 HK-52251 的實際核准適應症
- 補齊作用機轉（MOA）資料
- 釐清過敏性蕁麻疹是否已屬標示內用途；若是，應視為既有適應症確認，而非再利用
- 針對急性喉咽炎等預測，檢索並評估相關臨床試驗與文獻
- 針對高血壓、青光眼、前列腺肥大等禁忌族群，制定安全性監測方案
