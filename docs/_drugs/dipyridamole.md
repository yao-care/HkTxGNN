## Dipyridamole：從知識圖譜記錄的心房顫動到血栓性疾病
{: .text-alpha }

## 一句話總結

Dipyridamole（雙嘧達莫）是一種已在香港上市的抗血小板藥物，知識圖譜中記錄它與心房顫動有關聯，但這並非香港許可證上的核准適應症。
TxGNN 模型預測它可能對**血栓性疾病 (thrombotic disease)** 有效。
目前**沒有相關臨床試驗**，僅有 **20 篇文獻**，多為綜述，屬間接證據。

## 為什麼這個預測合理？

目前缺乏完整的作用機轉資料庫記錄。以下機轉來自本報告所整理的文獻：Dipyridamole 會抑制腺苷再攝取與磷酸二酯酶活性，使血小板內的 cAMP 與 cGMP 上升，進而可逆地抑制血小板凝集。這是明確的抗血栓機轉。

這個機轉與血栓性疾病在生物學上高度相關。血小板活化是動脈血栓形成的核心步驟，而 dipyridamole 本身就是以抗血栓與血管擴張用途使用的藥物。因此模型給出高分並不意外。

但需要保守看待。「血栓性疾病」是範圍很廣的類別，所提供的文獻多為抗血小板藥物的一般性回顧。其中夾雜與本藥無關的文章，例如一篇間皮瘤的 bevacizumab 試驗。證據符合藥理學常理，但不是針對本藥的特定再利用訊號。

## 安全性考量

- **知識圖譜記錄的禁忌關聯（並非仿單內容）**：圖譜中記錄與下列疾病有禁忌關聯，包括血小板低下、消化性潰瘍、出血性疾病（如血友病）、心肌梗塞與急性冠心症、低血壓、腎臟與肝臟疾病、痛風、貧血等。實際禁忌請以仿單為準。
- **藥物交互作用**：資料庫共記錄 100 筆交互作用。其中列為中度的有 Dexfenfluramine、Sibutramine、Fenfluramine。其餘多數等級未明，包括阿斯匹靈、質子幫浦抑制劑（omeprazole、pantoprazole、lansoprazole）、metformin、glimepiride、morphine、simvastatin 等。合併使用抗血小板藥物時尤須留意出血風險。

警語與禁忌的仿單原文尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉合理，藥物也已在香港上市。但針對「血栓性疾病」這個廣泛類別，沒有任何臨床試驗，文獻也多為間接的綜述，無法支持明確的再利用結論。
- 證據等級為 L4（僅有機轉與綜述層級的支持）。

**若要推進需要：**
- 把「血栓性疾病」縮小為具體病況，例如二級中風預防、TTP 等。補充該病況的對照試驗或系統性回顧。
- 另一項預測「短暫性腦缺血發作 (TIA)」已有大型試驗 ESPRIT（4,500 人，aspirin 加 dipyridamole）與多篇統合分析。這屬於不同疾病，建議另行評估。
- 取得香港仿單的警語、禁忌與核准適應症，完成安全性篩選。
- 補齊作用機轉的正式資料，並釐清目標適應症的劑型與給藥途徑是否與現有製劑相符。
