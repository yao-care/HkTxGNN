# Distigmine：從膽鹼酯酶抑制劑到重症肌無力（合併胸腺增生）

## 一句話總結

Distigmine 是一種長效膽鹼酯酶抑制劑，香港已有上市許可證，但原適應症資料缺漏。
TxGNN 模型預測它可能對**重症肌無力合併胸腺增生 (Myasthenia Gravis with Thymus Hyperplasia)** 有效。
目前**沒有臨床試驗，也沒有直接文獻**支持這個預測，只有模型分數和類別藥理的推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，原適應症也未記錄。根據已知資訊，Distigmine 屬於長效膽鹼酯酶抑制劑。這類藥物能提高突觸間隙的乙醯膽鹼濃度。

自體免疫型重症肌無力的核心問題，是神經肌肉接合處的乙醯膽鹼受體 (AChR) 被抗體破壞而減少。提高乙醯膽鹼濃度，理論上可以補償受體減少造成的訊號傳遞不足。因此膽鹼酯酶抑制劑在這類疾病中屬於症狀緩解的機轉。

不過要注意，這個推論來自類別藥理和模型分數，並非 Distigmine 本身的實證。另有一篇 2010 年前臨床研究（PMID 20410601）顯示，Distigmine 對血液乙醯膽鹼酯酶的抑制作用弱於 Neostigmine，但能直接結合蕈毒鹼與菸鹼受體。這篇研究的情境是逼尿肌收縮無力，不是重症肌無力，只能視為間接的機轉參考。

### 其他預測適應症的參考

TxGNN 對 Distigmine 共列出 10 個預測，多數同樣沒有證據。以下依與重症肌無力機轉的關聯整理：

| 預測適應症 | 分數 | 證據等級 | 評估 |
|-----------|------|---------|------|
| 自體免疫性肢帶型肌無力 | 99.998% | L5 | 機轉合理（症狀性），無臨床證據，列為研究問題 |
| 新生兒重症肌無力 | 99.998% | L5 | 機轉相關，但新生兒劑量與膽鹼性毒性需另行評估，Distigmine 半衰期長是特別顧慮 |
| 先天性肌無力症候群（伴管狀聚集體） | 99.674% | L5 | 部分亞型（如 GFPT1 相關）對此類藥物有反應，需依基因型評估 |
| 周邊神經自體免疫疾病 | 99.998% | L5 | 分類過於籠統，高分可能來自圖譜上與重症肌無力相近，Hold |
| 受體活性疾病 | 99.998% | L4 | 非特定疾病名稱，僅有 1 篇間接機轉研究（[20410601](https://pubmed.ncbi.nlm.nih.gov/20410601/)，2010，前臨床受體結合研究），需先對應到具體疾病，Hold |
| 先天性肌無力（對膽鹼酯酶抑制劑無效型） | 99.671% | L4 | 定義上對此類藥物無效，甚至可能惡化，與預測機轉相反。唯一文獻（[19172815](https://pubmed.ncbi.nlm.nih.gov/19172815/)，2009，個案報告）主題是一名 AChR 缺乏型患者的治療，從標題看不出是否使用 Distigmine，Hold |
| 脾功能亢進 | 99.964% | L5 | 無合理機轉，可能是圖譜假象，Hold |
| 非典型溶血性尿毒症候群（B 因子異常） | 99.957% | L5 | 補體旁路疾病，無膽鹼性機轉，Hold |
| 胎兒運動不能變形序列 | 99.941% | L5 | 發生在產前且屬結構性問題，出生後使用此類藥物意義有限，Hold |

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（重症肌無力合併胸腺增生）只有模型分數和類別藥理支持，沒有任何臨床試驗或文獻。
- 香港仿單的警語與禁忌尚未取得，缺乏安全性資料，無法進入安全篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌症。
- 補上 DrugBank 的作用機轉與原適應症資料。
- 針對 Distigmine 在重症肌無力的臨床使用，做專門的文獻與試驗檢索。
- 評估在自體免疫型重症肌無力之外，其他亞型（如先天性肌無力症候群）是否需依基因型個別評估。
- 評估長半衰期帶來的膽鹼性危象風險。
