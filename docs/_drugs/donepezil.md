# Donepezil：從阿茲海默症到心因性動作障礙

## 一句話總結

Donepezil 是乙醯膽鹼酯酶抑制劑，一般用於阿茲海默症型失智症（本次資料的許可證欄位未載明適應症）。
TxGNN 模型預測它可能對**心因性動作障礙 (Psychogenic Movement Disorders)** 有效，
但目前有 **0 個臨床試驗**和 **0 篇文獻**支持，這個預測只有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Donepezil 屬於乙醯膽鹼酯酶抑制劑，一般認為是提高腦內乙醯膽鹼濃度。此機轉說明來自藥理常識，並非本次資料所提供。

目前的資料無法建立心因性動作障礙與原適應症之間的機轉關聯。這個疾病屬功能性（非結構性）動作障礙，沒有檢索到任何試驗或文獻，也看不出合理的作用路徑。0.99 的高分在缺乏佐證時，不應視為有效訊號。

## 安全性考量

安全性資訊請參考原廠仿單。

另有一項與動作症狀相關的文獻訊號：2025 年系統性回顧 (PMID 40224553) 探討阿茲海默症患者使用膽鹼酯酶抑制劑（含 Donepezil）後出現的動作障礙。因此對於動作障礙類的新適應症，需特別留意藥物本身可能加重或誘發症狀。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第 1 的預測適應症沒有任何臨床試驗或文獻，只有模型分數（L5），也找不到合理的機轉依據。
- 膽鹼酯酶抑制劑本身有動作障礙的安全性訊號，在缺乏證據時不宜推進。

**若要推進需要：**
- 取得 Donepezil 的作用機轉資料（DrugBank）
- 取得香港衛生署仿單的警語與禁忌症
- 針對心因性動作障礙做專項文獻與試驗檢索，確認是否存在任何證據
- 若要優先投入研究，建議改評估排名 2 的慢性抽動症，該項至少有臨床與機轉層面的初步證據
