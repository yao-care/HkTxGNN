# Doravirine：從 HIV-1 感染到猴免疫缺陷病毒感染

## 一句話總結

Doravirine 是非核苷類逆轉錄酶抑制劑（NNRTI），原本用於 HIV-1 感染的治療。
TxGNN 模型預測它可能對**猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效，但這是非人類靈長類的病毒，不是人類臨床適應症。
目前有 **0 個臨床試驗**，只有 **1 篇**間接相關文獻，且該文獻談的是另一個藥物（islatravir）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供）。根據已知資訊，Doravirine 是 HIV-1 用的 NNRTI，它在 HIV-1 的療效已被證實，機轉是抑制病毒逆轉錄酶。

SIV 與 HIV 同屬慢病毒，在知識圖譜中距離很近，這很可能是分數偏高的原因。但這個預測的機轉支持很弱。NNRTI 對 HIV-1 具高度專一性，對 HIV-2/SIV 譜系的逆轉錄酶通常有天然抗性，不能預期能有效抑制。即使有價值，也只是作為前臨床動物模型的參考，而不是新的臨床用途。

同一批預測中的另外兩項也不建議推進：

- **貓後天免疫缺乏症候群 (FIV)**（分數 99.93%）：屬獸醫用途，沒有任何試驗或文獻，機轉支持同樣屬推測。
- **神經發育障礙併共濟失調步態、無語言能力及皮質白質減少**（分數 99.91%）：找不到 HIV-1 逆轉錄酶抑制與這個罕見遺傳疾病的機轉關聯，應屬知識圖譜的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測新適應症是非人類靈長類病毒感染，不是人類適應症，且無任何直接的臨床或前臨床證據。
- 高分很可能來自 SIV 與 HIV 在知識圖譜中的相近性，而 NNRTI 對 SIV 的活性在機轉上並不被看好。

**若要推進需要：**
- 補上原適應症與許可證適應症文字（香港衛生署資料）。
- 取得 DrugBank 的作用機轉資料，並下載香港衛生署仿單以完成警語與禁忌症的安全性篩選。
- 確認是否有 doravirine 對 SIV 或 HIV-2 逆轉錄酶的體外活性資料；若沒有，建議不再投入資源。
