# Dornase alfa：從囊腫性纖維化到前列腺黏液性腺癌（預測）

## 一句話總結

Dornase alfa 是重組人類 DNase I，原本用於治療囊腫性纖維化 (cystic fibrosis)。
TxGNN 模型預測它可能對**前列腺腺泡黏液性腺癌 (acinar prostate mucinous adenocarcinoma)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，預測分數 50% 也缺乏區辨力。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Dornase alfa 是重組人類 DNase I，能分解細胞外 DNA，在囊腫性纖維化中用於降低呼吸道分泌物黏稠度。

在腫瘤領域，有假說認為細胞外 DNA 與嗜中性球胞外網狀結構 (NETs) 可能參與部分癌症的進展與轉移，因此有推測性的理論依據。然而，目前沒有任何資料將此機轉與前列腺黏液性腺癌連結起來。

TxGNN 分數為 0.5，無法提供區辨訊息，應視為缺乏實質支持的純計算預測。

同一批預測中的其他候選疾病（例如 1p35 缺失症候群、ACTH 分泌型垂體腺瘤、苯妥英中毒、多種單基因神經發展障礙等）同樣沒有機轉依據與證據，且分數皆為 0.5。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測（L5），沒有臨床試驗、文獻或明確機轉支持，且 TxGNN 分數 0.5 沒有區辨力。
- 此藥為吸入劑型，對前列腺等全身性或遠端器官的暴露有限，使新適應症的可行性更低。

**若要推進需要：**
- 補齊作用機轉資料，並評估 NETs／細胞外 DNA 在前列腺黏液性腺癌中的角色
- 進行系統性文獻與臨床試驗檢索，確認是否有任何前臨床證據
- 評估給藥途徑的相容性（吸入劑型是否能達到目標組織）
- 取得香港原廠仿單，完成警語與禁忌症的安全性審查
