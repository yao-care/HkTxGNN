# Dorzolamide：從開角型青光眼到原發性遺傳性青光眼

## 一句話總結

Dorzolamide 是碳酸酐酶抑制劑（CAI），透過減少睫狀體房水分泌來降低眼內壓，廣泛用於開角型青光眼及高眼壓症的治療。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效，
目前有 **1 個已完成的 Phase 2 臨床試驗**支持這個方向，尚無相關文獻。

## 為什麼這個預測合理？

Dorzolamide 為局部眼用碳酸酐酶抑制劑，作用於睫狀體上皮細胞的碳酸酐酶 II 型（CA-II），抑制碳酸氫鹽的生成，進而減少房水分泌量，達到降低眼內壓（IOP）的效果。這是當前開角型青光眼藥物治療中重要的機轉之一，與前列腺素類似物及 β-阻斷劑並列為一線或輔助治療選項。

原發性遺傳性青光眼（包含先天性青光眼與青少年型青光眼）的核心病理機轉同樣為房水引流異常、眼內壓升高，導致視神經進行性損傷。由於眼壓升高是遺傳性與後天性青光眼的共同終端通路，Dorzolamide 的降眼壓機轉理論上可適用於此類患者的輔助控壓治療，尤其在手術治療後仍有眼壓殘留的情況下。

值得注意的是，此類患者（尤其兒童/先天性）以手術矯正為優先，藥物僅扮演術後輔助角色，因此臨床獲益預期有限，但機轉連結具合理性。此外，TxGNN 同時對開角型青光眼（rank 6-7）給出 L1 等級的強力支持，說明整個青光眼疾病群的機轉與證據鏈是一致的。

## 結論與下一步

**決策：Hold**

**理由：**
- 原發性遺傳性青光眼目前僅有 1 項小型 Phase 2 RCT（n=37）提供直接證據，證據等級 L2，尚不充分支持推進
- Dorzolamide 在香港無上市許可（0 張許可證），需先解決法規層面的進入壁壘

**若要推進需要：**
- 補充完整仿單資料（MOA、警語、禁忌症），以完成安全性初評（DG001/DG002 缺口）
- 評估透過衞生署特殊管道在香港取得 Dorzolamide 的可行性
- 追蹤 NCT01527682 的同行評審發表論文，確認完整療效與安全性數據
- 考慮優先評估**開角型青光眼**適應症（TxGNN rank 7, L1 等級，具備多個 Phase 3/4 RCT 支持），後者證據基礎更完整，或可作為香港引進此藥的主要申請依據
