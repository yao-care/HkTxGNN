# Dostarlimab：從（原適應症資料未載明）到先天性腎上腺功能不全伴 46,XY 性逆轉（CYP11A1 缺乏）

## 一句話總結

Dostarlimab 是一種 PD-1 抗體，香港已有 1 張上市許可證，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**先天性腎上腺功能不全伴 46,XY 性逆轉（CYP11A1 缺乏）**有效。
目前**沒有臨床試驗**，只有 **5 篇文獻**，且都在談疾病本身，沒有一篇研究 dostarlimab，因此證據僅止於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。從同一份資料中的臨床試驗描述可知，dostarlimab 是人源化 IgG4 kappa 單株抗體，會結合 PD-1，阻斷 PD-1 與 PD-L1／PD-L2 的結合，用於腫瘤免疫治療。

預測的新適應症是 CYP11A1（P450scc）缺乏所致的先天性腎上腺功能不全。這是一種遺傳性類固醇合成缺陷：膽固醇無法轉換成孕烯醇酮，造成腎上腺與性腺類固醇激素普遍缺乏，並使 46,XY 個體出現性發育異常。

從機轉來看，PD-1 阻斷是調節 T 細胞免疫，而該疾病的核心是單一基因造成的酵素缺陷，兩者沒有明顯關聯。文獻也沒有任何 PD-1 抑制劑用於類固醇合成缺陷疾病的報告。這個預測分數僅 50%，排名約在 252 萬名，較可能是知識圖譜的統計關聯，缺乏生物學上的支持。

## 安全性考量

- **心臟安全性**：一項濃度－QTc 分析顯示 dostarlimab 不會造成 QT 延長（PMID 36823349）。另有藥物安全監視研究指出，免疫檢查點抑制劑類藥物有心房顫動的通報訊號（PMID 40290514）。
- **免疫相關不良反應**：此類藥物可能引發免疫媒介的不良反應。

其餘警語、禁忌症與藥物交互作用資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 該適應症沒有臨床試驗，5 篇文獻都與 dostarlimab 無關，證據等級為 L5。
- PD-1 阻斷與 CYP11A1 缺乏這類單基因類固醇合成缺陷之間，沒有可辨識的機轉關聯，建議不投入資源。

**若要推進需要：**
- 補齊作用機轉資料，並說明 PD-1 阻斷與 CYP11A1 缺乏之間的機轉關聯。
- 取得香港衛生署核准仿單，確認原適應症、警語與禁忌症。
- 檢視是否有任何細胞或動物層級的前臨床證據，目前沒有。
- 若後續決定推進，需針對罕見兒科族群另行評估風險效益。免疫檢查點抑制劑的免疫相關不良反應，可能加重原本就有腎上腺功能不全的患者的風險。

> 本報告僅供研究參考，不構成醫療建議。預測結果需經臨床驗證後才能應用。
