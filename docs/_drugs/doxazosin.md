# Doxazosin：從高血壓／良性前列腺增生到偏頭痛

## 一句話總結

Doxazosin 是一種 α₁-腎上腺素受體拮抗劑，臨床上廣泛用於高血壓及良性前列腺增生的治療。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前僅有 **1 篇文獻**（1997 年的回顧性評論）支持這個方向，尚無任何登記中的臨床試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Doxazosin 屬於 α₁-腎上腺素受體拮抗劑，透過阻斷血管平滑肌上的 α₁ 受體，降低周邊血管阻力與血壓，其成效在高血壓與良性前列腺增生的治療中已被廣泛驗證。

偏頭痛與高血壓同樣涉及血管調節機轉。舊有的偏頭痛病理理論聚焦於顱內外血管的收縮／舒張失調，α₁ 受體拮抗劑理論上可透過調節腦血管反應性，提供預防性療效。1997 年的一份小型臨床觀察報告即基於此假設，對 terazosin 與 doxazosin 用於偏頭痛預防提出初步的正面觀察。

然而，現代偏頭痛病理學已更聚焦於 CGRP、5-HT 系統及三叉神經血管通路，α₁ 拮抗路徑在此框架下僅為輔助性假設，機轉關聯屬間接性，臨床驗證嚴重不足，需謹慎看待此預測的實際轉化潛力。

## 結論與下一步

**決策：Hold**

**理由：**
目前僅有 1 篇 1997 年的小型回顧性評論（n=10）作為支持依據，證據等級極低（L4），且無任何已登記的臨床試驗。現代偏頭痛預防已有機轉更直接的藥物（如 CGRP 拮抗劑、β 受體阻斷劑），Doxazosin 的 α₁ 拮抗路徑在此適應症中的定位尚未獲得充分驗證，現階段不宜主動推進。

**若要推進需要：**
- 補充 Doxazosin 完整的作用機轉（MOA）與安全性資料（仿單警語、禁忌症）
- 設計前瞻性小型概念驗證（Proof-of-Concept）研究，以釐清 α₁ 拮抗是否在現代偏頭痛病理框架中具有獨立貢獻
- 評估與現有一線預防藥物（propranolol、topiramate、CGRP 抗體）的比較優勢與定位差異
- 若擬於香港開展臨床評估，需先申請藥品許可或進行試驗用藥申請（IND-equivalent）
