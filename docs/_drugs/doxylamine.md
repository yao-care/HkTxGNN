# Doxylamine：從過敏性鼻炎等上呼吸道過敏症狀到過敏性蕁麻疹

## 一句話總結

Doxylamine 是第一代 H1 抗組織胺藥，原本用於過敏性鼻炎、感冒、蕁麻疹和血管性水腫等症狀。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效。
目前**沒有直接的臨床試驗或文獻**支持，僅有模型預測與藥理類別推論。這個預測與既有適應症高度重疊，比較像是原有適應症的延伸，而非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Doxylamine 是第一代 H1 抗組織胺藥，具有抗組織胺與抗膽鹼（抗蕈毒鹼）作用。其在過敏性疾病與上呼吸道症狀中的療效已有類別層級的認知，機轉上可能適用於過敏性蕁麻疹。

過敏性蕁麻疹由組織胺介導，阻斷 H1 受體在機轉上是合理的。知識圖譜顯示 Doxylamine 的既有適應症已包含蕁麻疹與血管性水腫，因此 TxGNN 的高分（0.998）很可能反映與這些適應症的重疊。

其他排名較前的預測也有類似情形：

- **鼻腔疾病（99.36%）**：範圍很廣，與過敏性鼻炎、感冒重疊，H1 阻斷與抗膽鹼作用可能緩解流鼻水、打噴嚏，但缺乏明確的疾病目標。
- **急性喉咽炎（99.34%）**：抗組織胺與抗膽鹼作用可能緩解鼻漏、後鼻滴流，但無法處理感染病因，對喉部病變的益處未經證實。
- **寒冷性蕁麻疹（99.26%）**：屬物理性蕁麻疹，H1 抗組織胺是標準一線治療，但現行指引偏好第二代藥物。第一代藥物的鎮靜與抗膽鹼副作用相對不利。

## 安全性考量

- **知識圖譜標示的禁忌疾病（非仿單內容，僅供參考）**：高血壓、肝衰竭／肝病、胰臟炎、膽囊疾病、消化性潰瘍、糖尿病與酮酸中毒、良性前列腺增生、膀胱頸阻塞、物質濫用／依賴、冠狀動脈疾病、心肌梗塞、動脈粥樣硬化、青光眼（閉角型）與高眼壓、對乙醯胺酚中毒、甲狀腺功能亢進（含 Graves 病）、血紅蛋白病、心室心搏過速。
- **藥物交互作用**：資料庫共有 100 筆交互作用紀錄，以下為其中列出的主要項目：
  - **重大 (Major)**：氯化鉀 (Potassium chloride)、檸檬酸鉀 (Potassium citrate)
  - **中度 (Moderate)**：多種抗膽鹼藥物（Hyoscyamine、Atropine、Scopolamine、Glycopyrronium、Dicyclomine、Propantheline 等）、鴉片類（Morphine、Opium）、Loperamide、Metoclopramide、Dronabinol、Nabilone、Eluxadoline
  - 與其他中樞抑制或抗膽鹼藥物併用，可能加重嗜睡與抗膽鹼作用。

香港仿單的警語與禁忌資料尚未取得，詳細內容請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測與 Doxylamine 既有的蕁麻疹適應症高度重疊，並非真正的再利用機會，且沒有任何直接的臨床試驗或文獻支持。
- 指引偏好第二代抗組織胺藥，第一代藥物的鎮靜與抗膽鹼副作用不利，加上香港仿單安全性資料尚未取得。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌（目前為阻礙性資料缺口）
- 補充詳細的作用機轉資料（DrugBank）
- 搜尋 Doxylamine 用於各類蕁麻疹的臨床試驗與文獻，並與第二代抗組織胺藥比較
- 釐清此預測相對於既有適應症的實際新增價值
