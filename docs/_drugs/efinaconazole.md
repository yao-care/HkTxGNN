# Efinaconazole：從甲癬到皮膚肉瘤

## 一句話總結

Efinaconazole 是外用三唑類抗黴菌藥，原本用於治療甲癬（tinea unguium，俗稱灰指甲）。
TxGNN 模型預測它可能對**皮膚肉瘤 (Skin Sarcoma)** 有效，但預測分數僅 50%，目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型推測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Efinaconazole 是外用三唑類抗黴菌藥，一般認為其作用是抑制真菌的羊毛固醇 14-α 去甲基酶（CYP51），但此機轉並未收錄於本報告編纂的資料中。

目前無法建立甲癬與皮膚肉瘤之間的機轉關聯。皮膚肉瘤是間質來源的惡性腫瘤，與真菌感染的生物學並無已知連結。該藥為外用甲劑型，全身吸收極少，要在腫瘤組織達到有意義的濃度並不容易。

此預測的唯一依據是 TxGNN 分數 0.5，這是非特異性的數值，不足以作為再利用的理由。同批預測的其他候選適應症（如淋巴瘤、鼻竇癌、胃腺癌等）也都是相同分數，同樣沒有證據支持，顯示這類預測應審慎看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測（分數 50%），沒有臨床試驗、文獻或機轉證據，證據等級為 L5。
- 外用甲劑型的全身暴露很低，用於皮膚肉瘤在藥物遞送上也缺乏合理性。

**若要推進需要：**
- 補齊作用機轉（MOA）資料，並評估是否有機轉上的連結
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選
- 進行細胞株或前臨床實驗，確認 Efinaconazole 對皮膚肉瘤是否有任何活性
- 評估外用劑型是否能在目標組織達到有效濃度，必要時考慮其他給藥途徑
