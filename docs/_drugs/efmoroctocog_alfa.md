# Efmoroctocog Alfa：從血友病 A 到偽血管性血友病（Pseudo-von Willebrand Disease）

## 一句話總結

Efmoroctocog alfa（商品名 ELOCTATE）是重組 Fc 融合第八凝血因子（FVIII），屬於 FVIII 補充療法。
TxGNN 模型預測它可能對**偽血管性血友病 (Pseudo-von Willebrand Disease)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測，且機轉上的關聯性偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Efmoroctocog alfa 是重組 Fc 融合 FVIII 製劑，用於補充血友病 A 患者缺乏的第八凝血因子，機轉上屬於凝血級聯中的因子替代。

偽血管性血友病（血小板型 VWD）是由 GP1BA 功能增強型突變所致，使血小板與 VWF 的結合增加。它的核心問題在血小板受體，而非 FVIII 缺乏，因此補充 FVIII 並不能矯正根本缺陷，機轉上的關聯性偏弱。

模型給出高分，較可能是因為這些疾病在知識圖譜中同屬凝血與出血性疾病群集，距離相近，而非有實際的機轉依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測的新適應症（偽血管性血友病）為血小板受體缺陷，與 FVIII 補充的機轉不相符，且沒有任何臨床試驗或文獻佐證，僅有模型預測（L5）。
- 藥物層級的 MOA 與香港仿單的警語、禁忌資料皆缺漏，無法進入安全性篩選。

**若要推進需要：**
- 從香港衛生署取得仿單，補齊警語、禁忌症與核准適應症（目前為阻斷性資料缺口）。
- 透過 DrugBank 補齊作用機轉資料。
- 確認原適應症（預期為血友病 A），並釐清「合併血管異常的血友病 A」是否與既有適應症重疊；若重疊，屬標示或映射問題，非真正的老藥新用。
- 若仍要探索偽血管性血友病，需先做文獻回顧與機轉研究，確認是否存在合理的生物學依據。
- 後天性凝血因子缺乏需先縮小到 FVIII 相關的子群，再重新評估。
