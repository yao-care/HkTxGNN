# Eftrenonacog Alfa：從血友病 B 到偽性血管性血友病

## 一句話總結

Eftrenonacog Alfa 是重組第九凝血因子 Fc 融合蛋白（商品名 Alprolix），一般用於血友病 B 的出血控制與預防（此為一般藥理知識，Evidence Pack 未提供原適應症）。
TxGNN 模型預測它可能對**偽性血管性血友病 (pseudo-von Willebrand disease)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Eftrenonacog Alfa 為重組第九凝血因子與 IgG1 Fc 區域的融合蛋白，一般用於補充血友病 B 患者缺乏的第九因子，作用於內在凝血路徑。

偽性血管性血友病（血小板型 VWD）的病因是血小板 GPIb-alpha 功能增強，使其與 VWF 過度結合。這是血小板端的缺陷，補充第九因子無法矯正，因此從機轉上看不出明顯的關聯。

模型給出高分，較可能是因為藥物與凝血、出血性疾病節點在知識圖譜中距離接近，而非有實質的藥理依據。同樣的推論也適用於另外兩個預測（血小板釋放障礙、Glanzmann 血小板無力症），兩者的病因都在血小板功能，而非第九因子缺乏。

## 結論與下一步

**決策：Hold**

**理由：**
預測僅來自模型分數，沒有任何臨床試驗或文獻佐證，證據等級為 L5。三個預測疾病的病因都在血小板功能，與第九因子補充的機轉不符，看不出合理的機轉連結。

**若要推進需要：**
- 補齊作用機轉資料（DrugBank）
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌
- 進行文獻與臨床試驗的系統性檢索，確認是否有任何支持證據
- 若無機轉或臨床訊號，建議不再投入資源於此預測
