# Emedastine：從（原適應症未載明）到過敏性蕁麻疹

## 一句話總結

Emedastine 是選擇性 H1 組織胺受體拮抗劑，在香港以眼藥水形式上市，但本次資料未載明原適應症。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，
目前有 **1 篇 RCT**、**2 篇回顧**與 **1 篇前臨床文獻**支持這個方向，尚無臨床試驗登記。

> 證據等級說明：文獻中有 1 篇隨機對照試驗（emedastine 對比 loratadine，192 位慢性特發性蕁麻疹患者），但為單一研究，且無登記試驗可確認其階段。依本報告的判定規則（L2 需已完成的 Phase 2/3 RCT），此處保守判為 L3。Evidence Pack 內部評分為 L2，兩者略有差異，請留意。

## 為什麼這個預測合理？

Emedastine 是選擇性 H1 組織胺受體拮抗劑。蕁麻疹的風團與紅斑主要由肥大細胞釋放組織胺所致，因此阻斷 H1 受體在機轉上合理。

目前缺乏 DrugBank 的詳細作用機轉資料，也沒有原適應症紀錄。上述機轉連結來自藥物類別與所檢索到的文獻，而非輸入資料本身。已知 emedastine 在香港的製劑為 0.05% 眼藥水，一般用於過敏性眼部症狀。

文獻回顧指出，emedastine difumarate（口服製劑）已被用於過敏性鼻炎、過敏性結膜炎、蕁麻疹、過敏性皮膚炎等，且心血管不良反應與抗膽鹼作用較低。TxGNN 的高分（99.96%）與此一致，但屬電腦預測，不等同臨床證據。

需要注意：支持蕁麻疹的證據來自口服 emedastine，而香港上市的是眼藥水，劑型與給藥途徑並不相同。

## 結論與下一步

**決策：Hold**

**理由：**
- 有 1 篇 RCT 支持口服 emedastine 用於慢性特發性蕁麻疹，機轉也合理，但證據僅限於單一研究，且與香港上市的眼藥水劑型不同。
- 安全性資料（仿單警語與禁忌）尚未取得，屬阻斷性缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉與原適應症
- 確認是否有口服劑型可在香港使用（目前僅見眼藥水）
- 進一步搜尋更多蕁麻疹相關的 RCT 或系統性回顧

### 附註：次要預測（冷凝性蕁麻疹）

TxGNN 對**冷凝性蕁麻疹 (Cold Urticaria)** 也給出高分（99.82%），機轉上同屬肥大細胞與組織胺介導，H1 阻斷合理。但目前完全沒有 emedastine 專屬的臨床試驗或文獻，證據等級為 L5，建議決策為 Hold。
