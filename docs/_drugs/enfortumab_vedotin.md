# Enfortumab vedotin：從尿路上皮癌到痲瘋病（Leprosy）

## 一句話總結

Enfortumab vedotin 是以 Nectin-4 為標靶的抗體藥物複合體（ADC），原本用於尿路上皮癌治療。
TxGNN 模型預測它可能對**痲瘋病 (Leprosy)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為知識圖譜的模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據已知資訊，Enfortumab vedotin 是 Nectin-4 標靶的 ADC，透過抗體把 MMAE（微管破壞型細胞毒性藥物）送進表現 Nectin-4 的腫瘤細胞。

**這個預測在機轉上找不到合理連結。** 痲瘋病由痲瘋分枝桿菌 (*Mycobacterium leprae*) 感染引起，Enfortumab vedotin 的標靶與作用方式都與這種細菌的生物學無關。高分只是知識圖譜運算的結果，沒有臨床證據支撐。

## 結論與下一步

**決策：Hold**

**理由：**
- 痲瘋病的預測完全沒有臨床試驗與文獻，機轉上也缺乏合理連結，證據等級僅 L5。
- 細胞毒性 ADC 用於感染症的風險大於潛在益處，不建議投入資源。

**若要推進需要：**
- 提出 Nectin-4 或 MMAE 與痲瘋分枝桿菌感染之間的機轉假說，並有前臨床證據。
- 取得香港衞生署仿單，補齊警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料。

**備註：**同一份預測清單中，第 10 名的 HER2 陽性乳癌有間接文獻與泛腫瘤試驗（例如 EV-202, NCT04225117），證據等級為 L4，建議列為研究問題另行評估。這個方向的機轉取決於 Nectin-4 表現，而非 HER2 狀態。
