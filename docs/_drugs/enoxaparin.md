# Enoxaparin：從抗凝血治療到蛋白 C 缺乏所致血栓形成傾向

## 一句話總結

Enoxaparin 是低分子量肝素（LMWH），屬於抗凝血藥物，香港許可證資料未載明原核准適應症。
TxGNN 模型預測它可能對**體染色體隱性蛋白 C 缺乏所致血栓形成傾向 (Thrombophilia due to protein C deficiency, autosomal recessive)** 有效。
目前**沒有臨床試驗和文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

Enoxaparin 是低分子量肝素，會增強抗凝血酶的作用，主要抑制第 Xa 因子，進而減少凝血酶的生成。目前缺乏 DrugBank 的詳細作用機轉資料，以上為藥物類別的一般認識。

蛋白 C 缺乏會削弱蛋白 C 抗凝血路徑（負責使第 Va 和 VIIIa 因子失活），患者因此容易產生過量凝血酶而形成血栓。Enoxaparin 走的是抗凝血酶路徑，不依賴蛋白 C，兩者機轉上互補，所以這個預測在生物學上說得通。

但這個關聯只是推論，並非資料所證實。TxGNN 分數 (0.996) 只是模型預測。原適應症與 MOA 欄位都缺資料，無法用現有資料交叉驗證。要升級證據等級，必須先從指引、病例系列等獨立來源確認遺傳性蛋白 C 缺乏使用抗凝血藥物的做法。重度（同型合子或複合異型合子）患者的出血風險與劑量，現有資料也完全沒有涵蓋。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有 TxGNN 模型預測（證據等級 L5），沒有任何臨床試驗或文獻，原適應症、MOA 與仿單安全性資料也都缺漏，尚無法進入安全性篩選。機轉上雖然合理，但重度蛋白 C 缺乏患者的出血風險與劑量問題完全沒有資料。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症、核准適應症）
- 補齊 DrugBank 的作用機轉資料
- 從指引、病例系列與系統性回顧等獨立來源，確認 LMWH 用於遺傳性蛋白 C 缺乏的實際證據
- 評估重度（同型合子或複合異型合子）患者的出血風險與劑量
- 確認劑型與給藥途徑是否符合此族群的需求

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。
