# Enrofloxacin：從細菌感染（獸用抗菌藥）到心臟疾病

## 一句話總結

Enrofloxacin 是一種獸用氟喹諾酮類（fluoroquinolone）抗生素，在香港登記為動物用藥。
TxGNN 模型預測它可能對**心臟疾病 (heart disease)** 有效，但目前**沒有任何臨床試驗**，相關的 20 篇文獻幾乎都是動物或環境研究，**不支持**這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，enrofloxacin 屬於氟喹諾酮類抗菌藥，一般認為是透過抑制細菌 DNA gyrase 而殺菌，用於動物的細菌感染。

從機轉角度看，抗生素與心臟疾病之間沒有合理的治療連結。充其量，它只能治療造成心臟病變的**底層細菌感染**（例如感染性心內膜炎），無法治療心臟疾病本身。因此，0.9994 的高預測分數較可能是知識圖譜運算的假象，而非真實的治療訊號。

其他排名前 10 的預測（Laubry-Pezzi 症候群、Pierre Robin 症候群、染色體 7q 部分缺失、唇顎裂症候群、肺動脈瓣疾病、二尖瓣疾病等）多為先天性結構或染色體異常，同樣缺乏機轉依據，且多數沒有任何研究證據。

## 安全性考量

安全性資訊請參考原廠仿單。

文獻中另有值得留意的獸醫毒性報告：貓使用 enrofloxacin 後可能發生視網膜退化等眼部病變（見 PMID 17269886 及 41584252）。這些資料來自動物，僅供風險參考。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但機轉上沒有合理的治療連結，也沒有臨床試驗；現有文獻都是動物或環境研究，且多數指向毒性而非療效。
- 現有許可證皆為獸用產品，不具人用適應症基礎。

**若要推進需要：**
- 取得 enrofloxacin 的作用機轉資料，並釐清與心臟疾病的任何生物學關聯
- 取得香港衛生署仿單的警語與禁忌症
- 若仍想探索，應先改以具體的感染性心臟疾病（如感染性心內膜炎）作為假說，並確認人用氟喹諾酮類的現有證據
- 在上述資料補齊前，不建議投入進一步資源
