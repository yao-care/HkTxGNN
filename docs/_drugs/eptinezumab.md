# Eptinezumab：從偏頭痛到伴腦幹先兆的偏頭痛

## 一句話總結

Eptinezumab 是一種靜脈注射的單株抗體，原本用於偏頭痛（含或不含先兆）的治療。
TxGNN 模型預測它可能對**伴腦幹先兆的偏頭痛 (Migraine with Brainstem Aura)** 有效，
目前**無已登記的臨床試驗**，但有 **10 篇相關文獻**，多數為偏頭痛整體或 CGRP 路徑的研究，並非直接針對腦幹先兆。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記載。根據已知資訊，Eptinezumab 是靜脈注射的單株抗體，可中和 CGRP（降鈣素基因相關胜肽）配體。CGRP 是三叉神經血管系統活化與偏頭痛病理生理的關鍵介質。

伴腦幹先兆的偏頭痛是偏頭痛的亞型，與已核准的偏頭痛適應症共享相同的 CGRP 依賴性頭痛機轉，因此在機轉上有合理性。

不過需要注意：
- 0.999 的高預測分數主要反映該疾病與已核准偏頭痛適應症在知識圖譜中的高度鄰近，並非獨立的新證據。
- 先兆被認為與皮質擴散性抑制有關，其與 CGRP 的關係尚不明確。
- 2025 年一項隨機試驗顯示，PACAP38 誘發的偏頭痛發作不依賴 CGRP 訊號，代表阻斷 CGRP 可能無法涵蓋所有偏頭痛路徑。
- 遺傳性偏頭痛疾患（包括偏癱型與腦幹型表型）對 CGRP 路徑拮抗劑的反應不一。

## 結論與下一步

**決策：Hold（列為研究問題）**

**理由：**
- 目前沒有針對伴腦幹先兆偏頭痛的臨床試驗，文獻多為偏頭痛整體或 CGRP 路徑的研究，證據等級僅為 L4。
- 高預測分數主要反映與已核准偏頭痛適應症的重疊，且有證據顯示 CGRP 阻斷可能無法涵蓋所有偏頭痛路徑，先兆亞型的反應仍不確定。

**若要推進需要：**
- 取得詳細的作用機轉資料（MOA）
- 取得香港衛生署仿單的警語與禁忌症，完成安全性篩選
- 補充香港許可證的核准適應症與劑型資料
- 針對腦幹先兆亞型分析 PROMISE-1/2 等既有試驗資料，或設計小型探索性研究
- 評估 CGRP 阻斷在此亞型（含遺傳性表型）的療效與血管安全性（如缺血性事件）
