# Eptinezumab：從偏頭痛預防到伴腦幹先兆偏頭痛

## 一句話總結

Eptinezumab 是靜脈注射的抗 CGRP 單株抗體，已上市用於預防偏頭痛。
TxGNN 模型預測它可能對**伴腦幹先兆偏頭痛 (Migraine with Brainstem Aura)** 有效。
目前**沒有臨床試驗**，只有 **7 篇文獻**（1 篇 RCT 事後分析、其餘為綜述、病例報告與機轉研究），且沒有任何研究直接在腦幹先兆患者中測試 eptinezumab。

## 為什麼這個預測合理？

Eptinezumab 是抗 CGRP（降鈣素基因相關胜肽）單株抗體，以靜脈輸注方式給藥。CGRP 訊號在偏頭痛的病理機轉中居核心地位。DrugBank 目前缺乏詳細的作用機轉資料，也未列出原適應症，以上機轉說明來自藥物類別與文獻。

伴腦幹先兆偏頭痛是伴先兆偏頭痛的一種亞型，與一般偏頭痛共享相同的病理基礎。因此抗 CGRP 療法在機轉上有可能適用。

不過，2025 年一項 PACAP38 的 RCT（PMID 40229719）顯示，部分偏頭痛發作可以不經 CGRP 途徑誘發。這表示 eptinezumab 可能只對部分患者有效。另外，TxGNN 的 0.999 分是計算模型的預測，不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
沒有任何臨床試驗，也沒有研究直接在腦幹先兆患者中測試 eptinezumab。現有證據只有先兆亞群的事後分析、病例報告與機轉綜述。此外，香港衛生署仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。目前只適合列為研究問題。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症、核准適應症）
- 補齊 DrugBank 的作用機轉與原適應症資料
- 針對腦幹先兆亞群，設計或檢索專門的前瞻性研究或登錄資料
- 評估 CGRP 非依賴途徑（如 PACAP38）對療效的可能限制
