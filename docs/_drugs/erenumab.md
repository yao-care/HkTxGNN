## Erenumab：從偏頭痛到伴隨腦幹先兆的偏頭痛
{: .text-alpha }

## 一句話總結

Erenumab 是一種針對 CGRP 受體的單株抗體，原本用於預防偏頭痛。
TxGNN 模型預測它可能對**伴隨腦幹先兆的偏頭痛 (Migraine with Brainstem Aura)** 有效，
目前**沒有臨床試驗**登記，有 **20 篇文獻**提供間接支持，但皆非針對腦幹先兆。

## 為什麼這個預測合理？

Erenumab 是針對 CGRP 受體的單株抗體，可阻斷 CGRP 訊號。實驗資料顯示，它能抑制 CGRP 引起的 cAMP 生成，對 CGRP 受體的選擇性比其他降鈣素家族受體高約 5000 倍。目前缺乏完整的作用機轉資料，以上說明來自藥理學資料。

伴隨腦幹先兆的偏頭痛屬於有先兆偏頭痛的亞型，而 CGRP 訊號被認為與偏頭痛的病理機轉有關，因此機轉上有合理的連結。

不過，這個預測的證據是間接的。現有文獻談的是一般有先兆或無先兆的偏頭痛，沒有一篇專門探討腦幹先兆。腦幹先兆的症狀（如構音障礙、眩暈、複視、共濟失調）是不同的臨床表現，erenumab 在這群患者的表現並無資料。此外，0.9989 的高分很可能反映它與已核准偏頭痛適應症在本體論上的接近程度，而非獨立的新證據。

## 安全性考量

- **藥物交互作用**：本報告彙整的資料中，僅有 erenumab 與其作用標的 CGRP 受體的藥理關係，並無具體的藥物間交互作用等級資料。
- **血管安全性**：CGRP 通路藥物的血管安全性是公認需留意的面向。已有針對有先兆偏頭痛患者的血管風險事後分析（PMID 36942409）與腦血流動力學研究（PMID 32867533），但兩者都非針對腦幹先兆。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- Erenumab 已在香港上市並用於偏頭痛預防，機轉上也合理，但沒有任何臨床試驗或文獻直接針對腦幹先兆，證據僅達 L4，高 TxGNN 分數可能只是反映與原適應症的相近性。
- 香港仿單的警語與禁忌症資料尚未取得，安全性評估無法進行。

**若要推進需要：**
- 取得香港衛生署核准仿單，補齊適應症、警語與禁忌症
- 取得詳細的作用機轉資料（MOA）
- 針對腦幹先兆（含偏癱型等相關亞型）收集直接的臨床資料，或設計探索性研究
- 進一步評估血管安全性，尤其是腦幹先兆患者的缺血性風險
- 檢視已有的有先兆偏頭痛研究（如 REFORM）能否提供腦幹先兆的亞群分析
