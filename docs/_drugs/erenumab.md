# Erenumab：從偏頭痛預防到伴腦幹先兆的偏頭痛

## 一句話總結

Erenumab 是一種 CGRP 受體單株抗體，在香港以 Aimovig 名稱上市，用於偏頭痛預防。
TxGNN 模型預測它可能對**伴腦幹先兆的偏頭痛 (Migraine with Brainstem Aura)** 有效，
目前**沒有臨床試驗登記**，有 **19 篇文獻**，但多數屬於一般偏頭痛或「伴先兆偏頭痛」整體，並無針對此亞型的直接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫欄位為空）。根據已知資訊，Erenumab 是針對 CGRP 受體的單株抗體，已用於偏頭痛預防。CGRP 訊號在偏頭痛的病理機轉中扮演重要角色，因此機轉上可能適用於偏頭痛的各個亞型，包括伴先兆的類型。

原適應症與預測新適應症同屬偏頭痛家族。TxGNN 的高分（0.999）很可能反映的是兩者在疾病本體上的高度相近，而不是針對此亞型的專屬證據。這點需要特別留意。

另外，CGRP 具有血管擴張作用，而腦幹先兆涉及後循環症狀，因此需要特別關注血管安全性。現有的血管風險與腦血流動力學研究（PMID 36942409、32867533）結果令人放心，但並非針對此亞型。

## 安全性考量

安全性資訊請參考原廠仿單。

目前藥物交互作用查詢無結果。另外，血管安全性對此亞型特別值得關注：CGRP 具血管擴張作用，而腦幹先兆涉及後循環症狀。現有的一般偏頭痛研究結果令人放心，但尚無此亞型專屬的安全性資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有臨床試驗，文獻也沒有專門針對腦幹先兆亞型，證據僅屬 L4，高分預測主要來自與一般偏頭痛的本體相近性。
- 香港仿單的警語與禁忌資料尚未取得（阻擋性資料缺口），無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症文字
- 補齊 DrugBank 的作用機轉資料
- 搜尋並確認是否有專門針對腦幹先兆（或家族性偏癱型偏頭痛等相關亞型）的病例報告或亞群分析
- 制定針對後循環症狀患者的血管安全性評估與監測計畫
- 如證據累積，考慮設計亞型專屬的臨床研究
