# ESCULIN：從天然香豆素化合物到閉經

## 一句話總結

ESCULIN 是一種天然香豆素配糖體（6,7-dihydroxycoumarin glucoside），目前無已核准臨床適應症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，
然而目前**無任何臨床試驗或文獻**支持這個方向，預測純屬模型推算。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA 標記為 Data Gap）。根據已知資訊，ESCULIN 是一種香豆素配糖體，結構上屬於 6,7-dihydroxycoumarin 的葡萄糖苷衍生物。

部分結構相近的香豆素類化合物（例如 Coumestrol）已知具有植物雌激素活性，能與雌激素受體 ERα/ERβ 結合。理論上，若 ESCULIN 具有類似特性，或許可對雌激素缺乏性閉經（下視丘、腦下垂體或卵巢型）產生潛在影響。

然而，**ESCULIN 本身從未有植物雌激素活性的直接實驗數據**。TxGNN 高預測分數（0.9921）推測源自知識圖譜中共享蛋白靶點或代謝路徑節點的結構關聯，而非直接因果機轉。此預測目前屬純推測，不具可操作性。

## 結論與下一步

**決策：Hold**

**理由：**
ESCULIN 在香港未上市、無已核准適應症、無閉經相關臨床試驗或文獻，安全性資料亦缺乏。現有預測僅依賴 TxGNN 模型的知識圖譜推算，機轉關聯為純推測，整體證據強度為 L5，不足以推進。

**若要推進需要：**
- 查明 ESCULIN 的完整作用機轉（MOA），確認是否具植物雌激素活性
- 取得 ESCULIN 的安全性資料（警語、禁忌、藥物交互作用）
- 搜尋 ESCULIN 或其母化合物（Esculetin）在婦科或內分泌領域的前臨床研究
- 若前臨床數據支持，才考慮規劃 Phase 1/2 試驗設計
