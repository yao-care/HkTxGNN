# Esculin：從痔瘡外用軟膏（依品名推測）到閉經

## 一句話總結

Esculin（七葉苷）是一種香豆素苷類化合物，在香港以多款 "HEMO OINTMENT" 軟膏上市，但許可證未載明核准適應症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Esculin 一般被描述為具有抗發炎、抗氧化與血管保護作用的香豆素苷，但提供的資料中沒有任何內容，能把這些特性和下視丘－腦下垂體－卵巢軸，或閉經的成因（荷爾蒙、結構或全身性因素）連起來。

由於原適應症未載明，也沒有 MOA，0.992 的分數無法對應到已知的藥理路徑。這個分數只是知識圖譜的預測，尚未獲得臨床或文獻證據佐證。

閉經是異質性很高的症狀。任何再利用假說都必須先鎖定具體的病因或亞型。此外，香港現有產品都是軟膏，與閉經通常需要的全身性給藥是否相容，目前尚待評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級只有 L5，沒有臨床試驗、文獻或可辨識的作用機轉支持。
- 原適應症資料缺漏，且現有產品皆為外用軟膏，與閉經的可能給藥途徑相容性不明。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料，分析 Esculin 與生殖內分泌路徑的連結。
- 取得香港衛生署許可證的仿單，確認核准適應症、警語與禁忌症。
- 針對閉經的具體病因或亞型（例如原發性或續發性）提出明確假說。
- 檢索臨床前與臨床研究，確認是否有任何支持證據。
- 評估外用劑型是否能達到所需的全身暴露量，或是否需要其他給藥途徑。
