# Esketamine：從（原適應症資料缺漏）到 agoraphobia（懼曠症）

## 一句話總結

Esketamine 是 NMDA 受體拮抗劑，在香港以 Spravato 鼻噴劑上市，但本次資料中未載明原核准適應症。
TxGNN 模型預測它可能對**懼曠症 (Agoraphobia)** 有效，

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。依藥理常識，Esketamine 是 NMDA 受體拮抗劑，可調節麩胺酸神經傳導。

焦慮與恐懼相關疾患被認為與麩胺酸系統失調及突觸可塑性受損有關，因此機轉上有其合理性。但這個連結來自藥物的一般藥理特性，並非針對懼曠症的直接資料。

TxGNN 的高分（0.996）只是計算預測，不等同臨床證據。

**另一個預測：** 排名第 2 的「嬰兒良性陣發性斜頸」（分數 99.49%）找不到明確機轉依據。該病是罕見、可自行緩解的嬰兒期陣發性動作疾患，常與 CACNA1A 通道病變及偏頭痛譜系相關，NMDA 拮抗劑在其中沒有既定角色。此預測無任何臨床或文獻支持，建議 Hold，不作進一步分析。

## 結論與下一步

**決策：Hold**

**理由：**
- 懼曠症沒有任何臨床試驗登記，唯一的文獻是一般性的焦慮症藥物回顧，機轉連結也僅為推論。
- 本藥的香港仿單警語與禁忌資料尚未取得，無法進行安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊核准適應症、警語與禁忌症
- 補充 Esketamine 的作用機轉資料（如自 DrugBank 取得）
- 搜尋 Esketamine 或 ketamine 用於懼曠症／恐慌症的臨床研究，人工確認該篇回顧是否真的涉及此藥
- 評估鼻噴劑在該族群的使用可行性與安全監測計畫
