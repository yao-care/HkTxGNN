# Ethinylestradiol：從痤瘡與停經後骨質疏鬆到血漿鋅偏高

## 一句話總結

Ethinylestradiol（炔雌醇）是常見的合成雌激素，原本用於痤瘡、停經後骨質疏鬆、骨質疏鬆及停經後萎縮性陰道炎等。
TxGNN 模型預測它可能對**血漿鋅偏高 (zinc, elevated plasma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，ethinylestradiol 是雌激素類藥物，常見於口服避孕藥複方，其在原適應症中的作用已被廣泛使用，但在機轉上是否適用於血漿鋅偏高，無法由現有資料驗證。

文獻上已知含雌激素的口服避孕藥可能改變血中微量元素（如鋅與銅）的濃度，但一般方向是**鋅降低**，因此對「鋅偏高」是否有益並不明確。此為假說，本次資料中沒有任何證據支持。

此外，血漿鋅偏高屬於實驗室檢驗結果，而非具有明確治療標靶的疾病，治療適應症的合理性較低。高預測分數較可能反映知識圖譜中的關聯接近度，而非臨床相關性。

- **知識圖譜所列禁忌疾病**（來自藥物－疾病禁忌關聯，非仿單文字）：高血壓、癲癇、焦慮症、卟啉症、腎臟疾病、肝臟疾病、膽囊疾病、高血糖、充血性心衰竭、腎上腺皮質功能不全（Addison 病）、甲狀腺功能低下、全身性紅斑狼瘡、氣喘、糖尿病（含酮酸中毒）、良性攝護腺增生、高鈣血症等。
- **藥物交互作用**：共查得 412 筆，已列出的項目多為中度，主要包括：
  - 降血糖藥：acarbose、acetohexamide、albiglutide、alogliptin、dulaglutide、empagliflozin、glimepiride、glipizide、glyburide、chlorpropamide
  - 皮質類固醇：betamethasone、budesonide、dexamethasone
  - 抗生素：doxycycline、amoxicillin、clarithromycin
  - 其他：chenodeoxycholic acid、eliglustat（中度）；ascorbic acid、cimetidine（輕度）

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅有模型分數支持，沒有臨床試驗與文獻，證據等級為 L5。
- 雌激素對血漿鋅的已知影響方向多為降低，且血漿鋅偏高屬檢驗異常而非明確疾病，治療合理性不足。

**若要推進需要：**
- 補充作用機轉資料，並釐清雌激素與鋅代謝的實際關聯與方向
- 文獻回顧雌激素類藥物對血清鋅的影響，確認是否有任何臨床意義
- 確認「血漿鋅偏高」作為治療目標的臨床必要性與可行的療效指標
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性評估
