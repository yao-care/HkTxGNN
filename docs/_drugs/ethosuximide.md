# Ethosuximide：從失神發作到腎因性抗利尿激素分泌不當症候群

## 一句話總結

Ethosuximide 是 T 型鈣離子通道阻斷劑，用於治療失神發作（absence seizures）。
TxGNN 模型預測它可能對**腎因性抗利尿激素分泌不當症候群 (Nephrogenic Syndrome of Inappropriate Antidiuresis, NSIAD)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

**機轉上找不到合理的連結。** Ethosuximide 的作用是阻斷 T 型鈣離子通道 (Cav3.x)，藉此抑制失神發作。它對血管加壓素 V2 受體、cAMP 訊號或水通道蛋白-2 (aquaporin-2) 的運輸都沒有已知作用。

NSIAD 的成因是 *AVPR2* 基因的功能增益突變（如 R137C、R137L），使 V2 受體持續活化。這會促使水通道蛋白-2 插入細胞膜，造成水分滯留與低血鈉，而且與血中血管加壓素濃度無關。缺陷在受體層級，調控上游神經或荷爾蒙路徑，預期無法矯正這個問題。

0.999 的高分較可能來自知識圖譜中，與低血鈉、抗利尿相關節點的網路鄰近性，不代表有生物學上的因果關係。此外，資料中缺少原適應症與作用機轉欄位，也限制了機轉驗證。本報告對原適應症與機轉的描述，來自預測資料中的機轉分析文字，並非香港許可證上的適應症。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，沒有任何臨床試驗或文獻。
- 藥物的作用機轉與 NSIAD 的致病機轉（V2 受體功能增益）不相符，高分只反映模型預測。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料（目前為阻斷性缺口，無法進入安全性篩選）。
- 確認 Ethosuximide 在香港的核准適應症與 DrugBank 作用機轉資料。
- 找出任何支持 T 型鈣離子通道與 V2 受體、cAMP 或水通道蛋白-2 訊號之間關聯的前臨床證據。若找不到，建議不再優先投入。

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
