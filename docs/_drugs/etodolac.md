# Etodolac：從 NSAID 類消炎止痛用藥到肢端中肢發育不良（Hunter-Thompson 型）

## 一句話總結

Etodolac 是一種非類固醇消炎藥（NSAID），文獻中主要用於類風濕性關節炎、骨關節炎、僵直性脊椎炎及疼痛治療。
TxGNN 模型預測它可能對**肢端中肢發育不良 Hunter-Thompson 型 (Acromesomelic dysplasia, Hunter-Thompson type)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅是模型預測。

## 為什麼這個預測合理？

目前缺乏完整的作用機轉資料。根據文獻，Etodolac 的主要抗發炎機轉是偏向抑制環氧合酶-2（COX-2），減少前列腺素介導的發炎與疼痛。這也是 NSAID 成為軸性脊椎關節炎第一線症狀治療的原因。

肢端中肢發育不良 Hunter-Thompson 型是單基因遺傳的骨骼發育不全，與 GDF5/CDMP1 訊息路徑有關。Etodolac 對這條路徑沒有已知作用。

因此，這個高分較可能反映知識圖譜中「肌肉骨骼疾病」的網絡鄰近性，而不是真正的機轉關聯。就算有效，最多也只是止痛，無法改變疾病進程。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗、文獻或機轉支持，證據等級為 L5。
- Etodolac 的 COX 抑制機轉與 GDF5 路徑無關，即使有效也只是症狀緩解。
- 同一份候選清單中，證據較多的方向是**僵直性脊椎炎（L3）**與**發炎性脊椎病變（L4）**。它們有 Etodolac 的回顧文獻和開放標籤研究，但屬於 NSAID 類別效應的延伸，不是新機轉。若要投入資源，建議優先評估這兩個方向。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症（目前為阻斷性缺口，無法進入安全性篩選）
- 補齊 Etodolac 的作用機轉資料（可查詢 DrugBank）
- 針對 GDF5 路徑做前臨床或機轉研究，證明有生物學上的關聯
- 若改評估僵直性脊椎炎，需要 Etodolac 專屬的 RCT 或系統性回顧

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
