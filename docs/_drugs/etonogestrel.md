# Etonogestrel：從避孕到閉經（預測結果需高度審慎）

## 一句話總結

Etonogestrel 是一種黃體素（progestin），為皮下植入劑 IMPLANON NXT 的活性成分；Evidence Pack 未記載原適應症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前**沒有任何臨床試驗或文獻**支持，且此預測在機轉上有明顯矛盾。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。不過，根據已知資訊，etonogestrel 是黃體素類藥物，也是 desogestrel 的活性代謝物，會抑制排卵並使子宮內膜變薄。

閉經其實是含 etonogestrel 製劑的**已知效應**，而不是治療目標。TxGNN 的高分（0.998）很可能反映的是知識圖譜中「藥物—表現型」的關聯，並非治療效益。

以機轉來看，用這個藥治療閉經是自相矛盾的：它會維持無排卵、低雌激素或內膜萎縮的狀態，反而可能加重閉經。由於原適應症與作用機轉皆缺乏資料，這項預測也無法與仿單用途交叉驗證。因此，**這個預測不建議視為有效的老藥新用候選**。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（閉經）在機轉上與藥物作用相反，高分很可能來自知識圖譜中的副作用關聯，並非治療潛力。
- 全部預測皆為 L5，僅有模型預測，沒有任何臨床試驗或文獻。

**若要推進需要：**
- 取得香港衛生署仿單，確認原適應症、警語與禁忌症（此為阻擋性缺口，未補齊無法進入安全性篩選）
- 補充作用機轉資料（可查詢 DrugBank）
- 若仍想探索，只針對「乳房纖維囊腫病」做針對性文獻回顧，並將重疊的乳房病名合併評估
- 確認劑型與給藥途徑的相容性（目前為待確認）

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
