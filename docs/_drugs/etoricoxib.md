# Etoricoxib：從 COX-2 抗發炎止痛適應症到偏頭痛

## 一句話總結

Etoricoxib 是選擇性 COX-2 抑制劑，在香港已有 20 張有效許可證。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，分數很高。
但目前**沒有臨床試驗**，只有 1 篇相關綜述，直接證據極少，屬於模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Etoricoxib 是選擇性 COX-2 抑制劑，可減少前列腺素 E2（PGE2）的合成。藥理資料顯示其臨床用途包括類風濕性關節炎、骨關節炎、慢性下背痛、僵直性脊椎炎、急性疼痛與痛風。

PGE2 與偏頭痛中的三叉神經血管敏感化及神經性發炎有關，因此 COX-2 抑制在機轉上有合理性。另有一項大鼠三叉神經節的前臨床研究（PMID 29209105）探討 NSAIDs 對 CGRP 與 PGE2 釋放的影響，但該研究對應的是「偏頭痛易感性」這個遺傳概念，不是可直接治療的臨床疾病，且不屬於臨床證據。

需要強調：高 TxGNN 分數只是模型預測，並非療效證明。

## 安全性考量

- **藥物交互作用**：目前僅有藥理層面的資料，顯示其作用標的為 COX-2（PTGS2），無具體藥物交互作用分級。
- **文獻中的安全訊號**：
  - 病例報告顯示，etoricoxib 合併 telmisartan 與高鉀飲食，曾引發危及生命的高血鉀與急性腎功能異常（PMID 21373319）。
  - 病例報告指出可能誘發可逆性腦血管收縮症候群（PMID 25229174）。
  - COX-2 抑制劑一般與心血管及腎臟風險、體液滯留相關，使用前須評估。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 偏頭痛預測僅有模型分數與機轉合理性，沒有臨床試驗，也沒有直接檢驗 etoricoxib 的偏頭痛文獻，證據等級為 L5。
- 在廣義頭痛疾患（如 indomethacin 反應型頭痛、刺痛性頭痛）中有個案層級的正向報告，值得作為研究問題，但仍不足以支持臨床推進，且需考量心血管、腎臟與腦血管的安全風險。

**若要推進需要：**
- 系統性文獻回顧，檢索 etoricoxib 或 COX-2 抑制劑用於偏頭痛的臨床研究。
- 取得香港原廠仿單，確認核准適應症、警語與禁忌症。
- 補充詳細的作用機轉資料（DrugBank）。
- 設計小規模探索性試驗，並建立心血管、腎功能與血鉀的安全監測計畫。
