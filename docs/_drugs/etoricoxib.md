# Etoricoxib：從選擇性 COX-2 抑制劑到偏頭痛

## 一句話總結

Etoricoxib 是一種選擇性 COX-2 抑制劑，目前在香港已上市。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，預測分數很高（99.90%）。
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。已知 Etoricoxib 屬於選擇性 COX-2 抑制劑，可減少前列腺素的生成。

偏頭痛的病理與前列腺素介導的神經源性發炎、三叉神經血管敏感化有關。因此，抑制 COX-2 在機轉上有可能減輕偏頭痛。這個關聯屬於**推論，尚未被驗證**。TxGNN 分數雖高（排名 2715），但在現有資料中找不到任何 Etoricoxib 用於偏頭痛的研究。在升級證據等級之前，需要先系統性搜尋既有研究。

同一批預測中，還有幾個與頭痛相關的項目：偏頭痛伴腦幹先兆、偏頭痛易感性（基因易感性，並非可治療的臨床適應症）、一般頭痛疾患、三叉神經自主神經性頭痛。它們大多是偏頭痛在知識圖譜上的鄰近節點，建議與偏頭痛合併評估。

其餘預測（萎縮性毛囊皮膚病、肺動脈高壓、良性前列腺增生、脊柱後側凸心臟病等）缺乏機轉依據，多半是圖譜假象。肺動脈高壓方向還有疑慮：COX-2 抑制會降低血管前列環素 (PGI2)，且 coxib 類藥物與水腫、高血壓和心血管風險相關。

**理由：**
- 只有模型預測，沒有任何臨床試驗或文獻，證據等級為 L5。
- 機轉推論合理，但未經驗證；香港仿單的安全性資料也尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單（警語與禁忌），完成安全性篩選（目前為阻擋項）。
- 從 DrugBank 補齊作用機轉資料。
- 系統性搜尋 Etoricoxib 用於偏頭痛與頭痛的既有臨床研究和文獻。
- 將偏頭痛、偏頭痛亞型、偏頭痛易感性與頭痛疾患合併為單一適應症評估。
- 評估心血管與腎臟風險是否適用於目標族群。
