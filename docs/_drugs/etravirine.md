# Etravirine：從 HIV-1 感染到貓後天免疫缺乏症候群

## 一句話總結

Etravirine 是一種 HIV-1 非核苷類逆轉錄酶抑制劑（NNRTI）。
TxGNN 模型預測它可能對**貓後天免疫缺乏症候群 (Feline Acquired Immunodeficiency Syndrome)** 有效。
目前**沒有任何臨床試驗與文獻**支持，機轉上也有疑慮，僅屬模型預測。

## 為什麼這個預測合理？

Etravirine 是 HIV-1 的 NNRTI，作用是抑制病毒的逆轉錄酶。目前缺乏 DrugBank 的詳細作用機轉資料，以上是根據藥物類別推論。

模型給出高分，可能是因為知識圖譜中 Etravirine 與 HIV 相關節點距離很近。貓免疫缺乏病毒（FIV）的逆轉錄酶，一般認為對 NNRTI 不敏感，所以這個預測的機轉基礎薄弱。

換句話說，這個高分較可能反映圖譜的鄰近關係，而不是真正的藥理適用性。此預測也屬動物疾病，與人類臨床應用無直接關聯。

## 安全性考量

安全性資訊請參考原廠仿單。藥物交互作用查詢結果為無資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（貓免疫缺乏症候群）只有模型分數，沒有任何試驗或文獻，機轉上也有疑慮，且屬動物疾病。
- 排名 4、5 的 HIV 相關項目較可能是原適應症未對應所致，不算真正的老藥新用。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料（目前為阻斷性缺口，無法進入安全性篩選）
- 從 DrugBank 補充作用機轉與原適應症資料
- 確認 FIV / SIV 逆轉錄酶對 Etravirine 的體外敏感性資料
- 把排名 4、5 重新對應到已核准的 HIV-1 適應症，避免誤判為新適應症
