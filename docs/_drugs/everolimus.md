## Everolimus：從腎細胞癌到脂肪肉瘤
{: .text-alpha }

## 一句話總結

Everolimus 是 mTOR 抑制劑，知識圖譜中記錄的相關疾病包括腎細胞癌、乳癌、腎血管平滑肌脂肪瘤與結節性硬化症等。
TxGNN 模型預測它可能對**脂肪肉瘤 (Liposarcoma)** 有效。
目前有 **1 個直接相關的 Phase 2 臨床試驗**和 **1 篇相關臨床試驗報告**，但皆為與 ribociclib 併用，尚無法單獨評估 everolimus 的貢獻。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原廠機轉欄位無資料）。就一般藥理知識而言，everolimus 為 mTORC1 抑制劑，作用於 PI3K/AKT/mTOR 訊號路徑下游。

去分化型脂肪肉瘤的特徵是 CDK4/MDM2 擴增。試驗設計是以 CDK4/6 抑制劑 ribociclib 搭配 everolimus，同時阻斷兩條平行的增殖與存活路徑。文獻指出兩者在多種腫瘤模型中有協同抑制生長的作用。

不過，現有資料中尚無單臂試驗的療效結果，且併用療法無法分離 everolimus 本身的貢獻，因此此預測目前僅屬研究假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一直接研究脂肪肉瘤的是與 ribociclib 併用的單臂 Phase 2 試驗，仍在進行中且療效結果未公開，無法判斷 everolimus 的獨立貢獻。
- 依證據等級規則，必須有已完成的 RCT 才能列為 L2 以上；現有資料僅為進行中的單臂試驗，嚴格而言證據偏弱，應審慎看待系統給定的 L2 等級。
- 其餘預測（如卵巢黏液樣脂肪肉瘤、橫紋肌肉瘤亞型）僅有模型預測，或僅有混合族群的早期研究。

**若要推進需要：**
- 取得 NCT03114527 的完整療效與安全性結果
- 作用機轉資料，以及香港仿單的警語與禁忌症
- 能分離 everolimus 單獨貢獻的證據（如單藥研究或對照設計）
- 針對血液學、代謝與肺部毒性的監測計畫
