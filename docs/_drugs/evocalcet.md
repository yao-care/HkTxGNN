# Evocalcet：從繼發性副甲狀腺功能亢進到高磷血症

## 一句話總結

Evocalcet 是一種鈣敏感受體（CaSR）促效劑（擬鈣劑），原本用於治療繼發性副甲狀腺功能亢進。
TxGNN 模型預測它可能對**高磷血症 (Hyperphosphatemia)** 有效，
目前**沒有臨床試驗**，只有 **2 篇文獻**（1 篇前臨床研究、1 篇個案報告），證據仍屬初步。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Evocalcet 屬於擬鈣劑，作用於副甲狀腺細胞的鈣敏感受體，用來抑制副甲狀腺素（PTH）分泌，其在繼發性副甲狀腺功能亢進的角色已有前臨床研究支持。

繼發性副甲狀腺功能亢進常見於慢性腎臟病與透析患者，這些患者同時也容易有血磷升高。降低 PTH 可能間接減少骨轉換，並影響血磷，所以機轉上有生物學上的合理性。

不過，控制血磷並不是這類藥物的主要作用。TxGNN 的高分是圖譜模型的推論，並非實證結果，仍需臨床資料驗證。

其餘 4 個預測（家族性高磷血症腫瘤性鈣質沉著症及其變異型、胰臟炎、遺傳性高胡蘿蔔素血症合併維生素 A 缺乏）證據更弱，都是 Hold。前兩者的病因在 FGF23/Klotho 軸，鈣敏感受體促效劑沒有直接作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，加上一篇前臨床研究和一篇不直接相關的個案報告，沒有任何臨床試驗，高磷血症也不是這類藥物的主要作用。
- 安全性資料（香港衛生署仿單的警語與禁忌）缺漏，屬於阻斷性缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症資料
- 從 DrugBank 補充作用機轉（MOA）與原適應症資料
- 系統性檢索 Evocalcet 對血磷影響的臨床研究（特別是透析患者的血磷數據），確認是否有實際降磷效果
- 若有正向訊號，再設計以血磷為主要終點的探索性研究
