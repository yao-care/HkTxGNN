# Famotidine：從胃潰瘍／胃食道逆流到十二指腸胃逆流

## 一句話總結

Famotidine 是一種 H2 受體拮抗劑，原本用於胃潰瘍、十二指腸潰瘍、胃食道逆流及 Zollinger-Ellison 症候群等胃酸相關疾病。
TxGNN 模型預測它可能對**十二指腸胃逆流 (duodenogastric reflux)** 有效，
但目前**沒有相關臨床試驗**，僅有 **2 篇文獻**，證據屬前期探索階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Famotidine 是組織胺 H2 受體拮抗劑，可阻斷胃壁細胞上的 H2 受體、降低胃酸分泌。降低胃酸有可能減少逆流物中的酸性成分，並減輕黏膜損傷。

不過，十二指腸胃逆流的主要內容物是膽汁與鹼性消化液，抑制胃酸只能間接改善，並非針對病因。再者，這個預測與 Famotidine 既有的胃食道逆流、食道炎適應症十分接近，因此不算是明確的「新用途」。

現有的 2 篇文獻（2003 年重症病人研究、2004 年早期胃十二指腸逆流病 H2 阻斷劑綜述）顯示可能有症狀或生理上的效果，但缺乏完整試驗設計與全文，無法確認療效。

## 安全性考量

- **知識圖譜中的禁忌疾病關聯**（非仿單內容）：腎臟疾病、腎功能不全、肝臟疾病、膽囊疾病、腎結石、高鈣血症、腹瀉、便秘、胃癌等。此為模型資料庫的關聯，不等同於正式禁忌症，須以仿單為準。
- **藥物交互作用**：共查得 100 筆，以下為部分範例：
  - 中度：Abiraterone、Acalabrutinib、Tramadol、Amiodarone、Amitriptyline、Aripiprazole、Salbutamol
  - 輕度：Alendronic acid、Aluminum hydroxide

正式的警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 十二指腸胃逆流以膽汁／鹼性逆流為主，Famotidine 的抑酸作用只能間接緩解，且與既有的逆流適應症高度重疊，不算明確的新用途。
- 目前無臨床試驗，僅有 2 篇設計不明或綜述性質的文獻，證據仍屬 L4。

**若要推進需要：**
- 取得兩篇文獻的全文，確認研究設計與結果
- 補充 Famotidine 的作用機轉資料（MOA）
- 取得香港仿單的警語與禁忌症，以進行安全性篩選
- 設計針對膽汁逆流的對照臨床研究，並與其他藥物（如促動力藥、膽酸結合劑）比較
