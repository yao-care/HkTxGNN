# Famotidine：從胃酸相關疾病到十二指腸胃逆流

## 一句話總結

Famotidine（法莫替丁）是 H2 受體拮抗劑，一般用於胃酸相關疾病，例如消化性潰瘍。
TxGNN 模型預測它可能對**十二指腸胃逆流 (Duodenogastric Reflux)** 有效，
目前**沒有臨床試驗**，只有 **2 篇文獻**，且設計與結果尚待確認。

## 為什麼這個預測合理？

Famotidine 競爭性阻斷胃壁細胞上的 H2 受體，降低基礎、夜間及受刺激時的胃酸分泌。目前缺乏 DrugBank 的詳細作用機轉資料，以上為依文獻整理的已知機轉。

十二指腸胃逆流是膽汁與十二指腸內容物逆流回胃部，抑制胃酸並不能直接處理這個機制。若有益處，較可能是間接的：在混合型逆流中減輕胃酸造成的黏膜傷害或症狀。

TxGNN 分數很高，但較可能反映知識圖譜中它與胃酸相關消化道疾病距離很近，並不代表有針對此疾病的特定機轉。兩篇文獻的分類僅依標題判斷，實驗設計與終點指標都無法確認。

## 結論與下一步

**決策：Hold**

**理由：**
- 十二指腸胃逆流以膽汁逆流為主，抑制胃酸並不針對此機轉。
- 目前沒有臨床試驗，僅有 2 篇設計不明、結果未知的文獻，證據不足以支持推進。
- 補充一點：同一份預測中，「活動性消化性潰瘍」有多項 RCT 支持，但那是 famotidine 的既有適應症，不是新用途，也不是本報告的預測標的。

**若要推進需要：**
- 取得兩篇文獻全文，確認研究設計、族群與終點指標，並判讀實際結果。
- 檢索是否有針對膽汁逆流或混合型逆流的對照試驗，特別是與 PPI 或促胃腸動力藥的比較。
- 補齊 DrugBank 作用機轉資料，以及香港衛生署仿單的警語與禁忌症。
- 補正藥物記錄中缺漏的原適應症欄位。
