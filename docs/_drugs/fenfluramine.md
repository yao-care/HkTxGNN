# Fenfluramine：從癲癇發作到 16p11.2 近端微缺失症候群

## 一句話總結

Fenfluramine 是血清素釋放劑，並具有 sigma-1 受體活性。它已上市用於癲癇發作，過去也曾作為食慾抑制劑。
TxGNN 模型預測它可能對 **16p11.2 近端微缺失症候群 (proximal 16p11.2 microdeletion syndrome)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Fenfluramine 是血清素釋放劑，具 sigma-1 受體活性，用於癲癇發作，過去也曾作為食慾抑制劑。

16p11.2 近端微缺失症候群常伴隨癲癇、神經發展障礙和肥胖。這三個表現與 Fenfluramine 的已知藥理作用（抗癲癇、抑制食慾）有部分重疊，這可能是模型給出高分的原因。

這只是尚未驗證的假說，適合作為機轉文獻回顧的起點，不能視為療效證據。若真要考慮使用，需要監測心臟瓣膜病變與肺動脈高壓。

**決策：Hold**

**理由：**
- 只有模型預測（L5），沒有試驗或文獻。

**若要推進需要：**
- 進行機轉導向的文獻回顧，檢視 Fenfluramine 在 16p11.2 缺失相關癲癇、神經發展與肥胖表現上的證據。
- 取得香港衛生署的仿單，補齊警語與禁忌資料。
- 從 DrugBank 補齊作用機轉資料。
- 補齊許可證的劑型與核准適應症。
- 其他三個預測（hypervitaminosis、obsolete hypertelorism、frontorhiny）找不到合理的藥理關聯，很可能是知識圖譜的假象，其中 obsolete hypertelorism 是已過時的本體節點，建議重新映射或排除。
