# Ferrous Fumarate：從缺鐵（補鐵）到非症候群性食道畸形

## 一句話總結

Ferrous Fumarate（富馬酸亞鐵）是口服補鐵劑，用於治療和預防缺鐵。
TxGNN 模型預測它可能對**非症候群性食道畸形 (Non-syndromic Esophageal Malformation)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，這只是模型預測，機轉上也找不到合理連結。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ferrous Fumarate 是口服鐵劑，用來治療和預防缺鐵，其原適應症的療效已被證實。但這一點無法支持它適用於食道畸形。

非症候群性食道畸形（例如食道閉鎖、氣管食道瘻管）是胚胎發育期形成的先天結構異常，通常需要手術矯正。補鐵不太可能逆轉或治療這類結構性問題。

因此我們**沒有找到可信的機轉連結**。0.995 的高分只是模型算出來的結果，比較可能是知識圖譜的假象，例如與鐵相關或消化道相關的泛用關聯所致。這個預測沒有臨床或機轉資料支持，也無法和已知藥理交叉驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅 L5，只有模型預測，沒有試驗或文獻。
- 先天結構異常與補鐵劑的藥理作用沒有合理關聯，高預測分數很可能是知識圖譜的假象。

**若要推進需要：**
- 取得香港衞生署仿單，確認警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料。
- 找出能解釋鐵代謝與食道發育關聯的機轉或前臨床證據。
- 若仍找不到證據，建議結案，不再投入資源。
