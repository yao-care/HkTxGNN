# Ferrous Fumarate：從缺鐵性貧血到非綜合症型食道畸形

## 一句話總結

Ferrous Fumarate（亞鐵富馬酸鹽）是常見的鐵質補充劑，主要用於治療缺鐵性貧血。TxGNN 模型預測它可能對**非綜合症型食道畸形 (non-syndromic esophageal malformation)** 有效，但目前**無任何臨床試驗或文獻**支持這個方向，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA 為 Data Gap）。根據已知資訊，Ferrous Fumarate 是一種口服鐵補充劑，透過提供二價鐵離子（Fe²⁺）補充體內鐵質，核心用途為改善缺鐵性貧血。

非綜合症型食道畸形（包括食道閉鎖、食道氣管瘻管等）屬於胚胎發育期的形態發生缺陷，成因主要涉及 Notch、Wnt、Sonic Hedgehog 等信號通路的異常，與鐵代謝並無直接已知的分子機制連結。

唯一可推測的間接路徑是：孕期母體鐵缺乏可能影響胎兒整體發育，但此假說指向孕期預防而非出生後的結構異常治療，且目前無直接對應本適應症的實驗室或動物模型佐證。**機轉關聯性極弱，此預測目前難以獲得機轉層面的支持。**
