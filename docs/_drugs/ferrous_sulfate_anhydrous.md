# Ferrous sulfate anhydrous：從缺鐵性貧血到 Plummer-Vinson 症候群

## 一句話總結

Ferrous sulfate anhydrous（無水硫酸亞鐵）是常見的口服鐵劑，原本用於缺鐵性貧血及其他營養缺乏性貧血。
TxGNN 模型預測它可能對 **Plummer-Vinson 症候群** 等疾病有效（以下依 TxGNN 預測排序列出，第 1 名為先天性巨母紅血球性貧血）。
目前**沒有任何臨床試驗或文獻**支持這些預測，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。鐵劑的已知角色是補充體內鐵質、矯正缺鐵，因此在缺鐵性貧血及相關貧血中的療效已被證實。以下依各預測逐一評估其機轉合理性：

**Plummer-Vinson 症候群（最合理）：** 此症候群以缺鐵性貧血、吞嚥困難和上食道蹼為特徵，補鐵是公認的標準治療，常可改善吞嚥困難。這項預測實際上較像是既有缺鐵性貧血適應症的延伸，而非真正的藥物再利用。臨床上很可能已有病例報告或回顧文獻，但本報告所編整的資料並未收錄，建議做針對性文獻搜尋後再定級。若確認有此類文獻，證據等級可能提升至 L3–L4。

**先天性巨母紅血球性貧血（合理性低）：** 此類貧血源於 DNA 合成受損（與 B12／葉酸路徑缺陷有關），而非缺鐵。鐵劑沒有已建立的治療依據，僅在同時有缺鐵時才有幫助。高分可能只是反映圖譜中各貧血節點彼此相近。

**生物素代謝疾病（合理性低）：** 這類疾病（如生物素酶缺乏症）以補充生物素治療，鐵在生物素循環或羧化酶活化中沒有已知作用。高分可能來自原適應症包含維生素缺乏症所造成的圖譜關聯。

**非症候群性食道畸形（合理性低且有安全疑慮）：** 食道閉鎖或狹窄等結構性缺陷需手術或內視鏡處理，口服鐵劑無法矯正。預測可能源自食道異常與 Plummer-Vinson 症候群（食道蹼）的關聯。此外，口服鐵劑可能刺激或傷害食道，結構異常患者更需留意。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜的藥物—疾病禁忌關聯，非仿單文字）：消化性潰瘍、鐮型細胞貧血、遺傳性胎兒血紅素持續存在症、原發性高草酸尿症、遺傳性血色素沉著症、含鐵血黃素沉著症、鐵代謝疾病、Wilson 病、潰瘍性結腸炎、發炎性腸道疾病、溶血性貧血、食道運動異常、腸胃炎。
- **藥物交互作用**：共查得 37 筆，以下為已列出的主要項目：
  - 中度：Rabeprazole、Omeprazole、Lansoprazole、Pantoprazole、Esomeprazole、Dexlansoprazole（質子幫浦抑制劑，可能降低鐵吸收）；Doxycycline、Tetracycline、Minocycline、Levofloxacin（抗生素，可能與鐵形成螯合而降低吸收）；Magnesium oxide、Calcium carbonate、Aluminum hydroxide、Magaldrate（制酸劑／礦物質）；Pancrelipase、Sodium sulfate、Triethylenetetramine。
  - 輕微：Cimetidine、Zinc sulfate、Zinc acetate。
- **預測適應症相關提醒**：口服鐵劑可能刺激食道，若用於食道結構異常患者需特別謹慎，且食道運動異常本身已列於上述圖譜禁忌。

## 結論與下一步

**決策：Hold**

**理由：**
- 四個預測適應症均無臨床試驗或文獻支持，證據等級皆為 L5，高 TxGNN 分數僅代表圖譜上的相近性。
- 其中僅 Plummer-Vinson 症候群有明確的生物學合理性（缺鐵為其核心病理），但它較像既有適應症的延伸；其餘三項缺乏機轉依據，其中食道畸形還有鐵劑刺激食道的安全疑慮。

**若要推進需要：**
- 針對 Plummer-Vinson 症候群進行系統性文獻搜尋（病例系列、回顧），確認後重新定級（可能升至 L3–L4）。
- 取得香港衛生署許可證的仿單（警語、禁忌、核准適應症與劑型），目前這些資料缺漏，無法進行安全性篩選。
- 補齊詳細的作用機轉（MOA）資料。
- 對機轉依據不足的三項預測（巨母紅血球性貧血、生物素代謝疾病、食道畸形）建議不再優先投入，除非有新的證據出現。
