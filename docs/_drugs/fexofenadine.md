# Fexofenadine：從抗組織胺藥到酒糟性結膜炎

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。從一般藥理知識來看，Fexofenadine 是週邊選擇性的 H1 受體拮抗劑，也就是第二代抗組織胺藥。這個說明不是來自本次提供的資料。

眼部酒糟性病變的主要成因是瞼板腺功能異常、先天免疫活化和發炎介質，組織胺的角色不確定，可能不大。抗組織胺藥對過敏性結膜炎有幫助，但這不代表對酒糟性結膜炎也有效。

因此這個連結「合理但未驗證」。0.998 的高分可能只反映知識圖譜中，藥物與過敏性或結膜發炎類疾病距離相近，並非酒糟性結膜炎專屬的機轉。TxGNN 分數是計算預測，不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測，沒有任何臨床試驗或文獻，證據等級為 L5。
- 機轉上的關聯未經確認，眼部酒糟性病變中組織胺的角色也不明確。
- 香港仿單的警語與禁忌症資料尚未取得，無法進入安全性初篩。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症。
- 補充 DrugBank 的作用機轉資料。
- 檢索抗組織胺藥用於酒糟性結膜炎或眼部酒糟性病變的文獻，並確認是否有相關臨床試驗。
- 評估給藥途徑是否合適：目前上市劑型皆為口服錠劑，眼部適應症可能需要不同劑型。
- 釐清高分是來自過敏性結膜炎的圖譜鄰近性，還是酒糟性結膜炎專屬的訊號。
