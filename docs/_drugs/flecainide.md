## Flecainide：從心房顫動到中風
{: .text-alpha }

## 一句話總結

Flecainide 是 IC 類鈉離子通道阻斷劑，原本用於心房顫動 (atrial fibrillation) 的節律控制。
TxGNN 模型預測它可能對**中風 (stroke disorder)** 有效，但目前只有 **1 個間接相關的 Phase 3 臨床試驗**和一批以心房顫動管理為主的文獻，證據屬於間接推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Flecainide 是 IC 類鈉離子通道阻斷劑，用於心房顫動的節律控制。

心房顫動是心源性栓塞中風的主要危險因子。若 Flecainide 能維持竇性心律，理論上可能間接降低中風風險。這種關聯是經由抑制心房顫動所間接產生的，並非直接的神經保護作用。

需要注意，目前沒有直接證據顯示 Flecainide 能預防中風。相關臨床試驗的主要終點是心律不整，而不是中風復發。

## 安全性考量

- **知識圖譜標示的相關疾病（禁忌或需謹慎）**：腎臟疾病、肝臟疾病、膽囊疾病、心肌梗塞、冠狀動脈血栓、房室傳導阻滯、病竇症候群、缺鉀、血紅素病變等。此資訊來自知識圖譜，並非仿單內容。
- **藥物交互作用**：共查得 100 筆，主要包括：
  - 嚴重 (Major)：Dolasetron、Eliglustat
  - 中度 (Moderate)：Clarithromycin、Levofloxacin、Bupropion、Cimetidine、Famotidine、Palonosetron、Trospium 等
- **文獻提示的風險**：可能引發心律不整（proarrhythmia）；過量時可能誘發 Brugada 波型；結構性心臟病患者使用受限。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 中風的預測完全屬於間接推論，唯一的 Phase 3 試驗終點為心律不整，文獻也以心房顫動管理為主，沒有直接證據。
- Flecainide 在結構性心臟病、心肌梗塞及傳導疾病患者有明確的安全疑慮，需要嚴格的防護措施。

**若要推進需要：**
- 以中風或腦血管事件為主要終點的直接臨床證據（例如 NCT05213104 的最終結果，以及相關追蹤分析）
- 詳細的作用機轉資料
- 取得香港原廠仿單的警語與禁忌資料，完成安全性篩選
- 明確界定適用族群（排除結構性心臟病與傳導異常），並評估與抗凝血劑併用的交互作用
