# Flubendazole：從（原適應症未載明）到膀胱癌

## 一句話總結

Flubendazole 是苯并咪唑（benzimidazole）類驅蟲藥，香港已有 1 張上市許可證，但資料中未載明原適應症。
TxGNN 模型預測它可能對**膀胱尿路上皮癌 (Urinary Bladder Carcinoma)** 有效，
目前**沒有臨床試驗**，僅有 **1 篇間接文獻**（針對同類藥物 fenbendazole），證據極弱。

## 為什麼這個預測合理？

目前缺乏 Flubendazole 詳細的作用機轉資料。根據已知資訊，Flubendazole 屬於苯并咪唑類驅蟲藥，這類藥物可結合 β-微管蛋白（beta-tubulin）並干擾微管聚合。這個機轉理論上可能影響快速增殖的腫瘤細胞。

原適應症與膀胱癌的關聯目前尚無法確認（原適應症資料缺漏）。預測分數偏高，很可能反映知識圖譜中與膀胱癌各節點的鄰近性，而不是針對 Flubendazole 的實際生物學證據。

這只是類別層級的推測，並未經 Flubendazole 本身驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測皆缺乏 Flubendazole 本身的臨床試驗或文獻，僅有模型分數與同類藥物 fenbendazole 的間接前臨床資料。
- 原適應症、作用機轉與仿單安全性資料均有缺口，無法進行安全性初篩。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉資料
- 進行 Flubendazole 在膀胱癌細胞株與動物模型的前臨床研究
- 評估局部（膀胱內灌注）給藥的可行性，Flubendazole 水溶性與生體可用率通常較低，需先確認劑型與給藥途徑
- 補充原適應症資料，釐清與膀胱癌的關聯
