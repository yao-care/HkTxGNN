## Flucloxacillin：從抗葡萄球菌感染到結膜炎
{: .text-alpha }

## 一句話總結

Flucloxacillin 是抗葡萄球菌的 β-內醯胺類（青黴素類）抗生素，目前在香港有 3 張有效的單方許可證。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效，但目前**沒有臨床試驗**，僅有 **1 篇個案報告**，且該報告並未直接測試 flucloxacillin，因此證據非常薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，flucloxacillin 屬於抗葡萄球菌的 β-內醯胺類抗生素，對金黃色葡萄球菌等革蘭氏陽性菌具活性。結膜炎的細菌性病原包括葡萄球菌，因此在生物學上有一定的合理性。

不過，目前找到的唯一文獻是淋球菌性淚腺炎的個案報告。該報告的病原體不同（淋病奈瑟菌），感染部位也不同（淚腺），並未評估 flucloxacillin 對結膜炎的效果。TxGNN 的高分屬於純計算預測，不能視為臨床證據。

其他排名較前的預測也值得留意：類風濕性關節炎、痲瘋病、變異型心絞痛、血栓性疾病等，要不是缺乏合理的機轉連結，就是文獻僅涉及感染處置或藥物不良反應，並非療效證據。

## 安全性考量

安全性資訊請參考原廠仿單。

為預測新適應症所檢索的文獻中，另有 flucloxacillin 相關不良反應的個案報告，供風險評估參考：
- 長期使用 flucloxacillin 後發生顆粒球缺乏症（agranulocytosis）的個案，再次給藥後復發。
- 史蒂芬強生症候群／毒性表皮壞死溶解症（SJS/TEN）的致命個案，與 doxycycline 或 flucloxacillin 有關。

這些均為個案報告，無法推論發生率，但提示用藥時需留意血液學與嚴重皮膚反應。

## 結論與下一步

**決策：Hold**

**理由：**
- 結膜炎預測僅有計算模型分數和一篇不直接相關的個案報告，沒有任何臨床試驗，實際證據不足以支持推進。
- 香港許可證缺少適應症文字，安全性與作用機轉資料也不完整，目前無法進行安全性篩選。

**若要推進需要：**
- 從香港衛生署網站取得仿單，補齊核准適應症、警語與禁忌症。
- 補充 flucloxacillin 的作用機轉資料（如 DrugBank）。
- 檢索 flucloxacillin 或同類抗葡萄球菌青黴素用於細菌性結膜炎的直接研究。
- 評估給藥途徑的可行性：現有劑型為口服膠囊和口服溶液，而結膜炎通常以局部（眼用）給藥，目前香港沒有眼用劑型。
