## Fludarabine: 漿細胞骨髓瘤 (plasma cell myeloma)
{: .text-alpha }

## 一句話總結

Fludarabine 是一種嘌呤核苷類似物，屬於抗代謝類細胞毒性藥物。
TxGNN 模型預測它可能對**漿細胞骨髓瘤 (plasma cell myeloma)** 有效。
目前有 **多項臨床試驗**與**多篇文獻**涉及此方向，但多為移植前處理或 CAR-T 淋巴清除情境，證據等級為 **L3**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Fludarabine 為嘌呤核苷類似物，具淋巴細胞清除（lymphodepletion）與免疫抑制作用，這是其在血液惡性腫瘤治療中的主要角色。

在骨髓瘤領域，fludarabine 主要不是單獨的抗骨髓瘤療法，而是作為支持性的處理成分：一是搭配 cyclophosphamide，用於 BCMA 導向 CAR-T 療法（如 idecabtagene vicleucel、ciltacabtagene autoleucel）前的淋巴清除；二是用於異體造血幹細胞移植的減低強度前處理，借助移植物抗骨髓瘤效應。此外，有體外與動物實驗顯示 fludarabine 對骨髓瘤細胞具抑制活性（PMID 17976186），但該研究屬前臨床研究，且文中亦提到其抗骨髓瘤活性仍有爭議。

需注意：已有文獻指出 fludarabine 暴露量與 ide-cel 治療後的毒性相關（PMID 40972962），因此劑量需要適當控管。

## 安全性考量

- **藥物交互作用**：資料顯示共有 100 筆交互作用紀錄，其中中度者包括 Metronidazole、Rosuvastatin、Simvastatin、Tinidazole；輕度者為 Levofloxacin；其餘多為分級未明（如 Doxycycline、Cimetidine、Amphotericin B、Omeprazole、Metformin 等）。
- 與 ide-cel 合用時，fludarabine 暴露量與毒性相關（PMID 40972962），需控管劑量。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- Fludarabine 已廣泛用於骨髓瘤相關的移植前處理與 CAR-T 淋巴清除，多項臨床研究與回溯分析支持其在這些情境的可行性。
- 但這些證據多為單臂或回溯性研究，沒有隨機試驗檢驗 fludarabine 本身，且它是支持性成分，而非獨立的抗骨髓瘤療法，因此證據等級為 L3。

**若要推進需要：**
- 補充作用機轉資料，釐清 fludarabine 在骨髓瘤中的角色。
- 針對 CAR-T 淋巴清除，建立劑量與暴露量的監測及調整方案（考量腎功能與毒性）。
- 取得本地原廠仿單，確認警語、禁忌症與核准適應症。
- 設計比較不同前處理或淋巴清除方案的前瞻性研究，以區分 fludarabine 的獨立貢獻。
