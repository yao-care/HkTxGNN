# Flunitrazepam：從鎮靜催眠到失眠

## 一句話總結

Flunitrazepam（商品名 Rohypnol）是效力約為 diazepam 7–10 倍的強效苯二氮平類鎮靜催眠藥物，歷史上曾在多國用於失眠與術前鎮靜，然香港未核准上市。
TxGNN 模型預測其最高適應症為**失眠 (Insomnia)**，預測分數 99.89%；
目前有 **1 個觀察性臨床試驗**和 **11 篇文獻**支持，惟現有文獻多聚焦於濫用與毒理，受控治療研究極為有限。

## 為什麼這個預測合理？

Flunitrazepam 屬苯二氮平類（benzodiazepine）藥物，透過正向調節 GABA-A 受體的苯二氮平結合位點，增強 GABA 誘導的氯離子內流，產生中樞神經抑制、鎮靜與催眠效果。其效力約為 diazepam 的 7–10 倍，起效快速且具顯著順行性失憶效應。

TxGNN 預測失眠為最高順位適應症，機轉上完全合理——此藥本身即屬催眠藥物類別，多篇睡眠多導圖（polysomnography）研究已記錄其縮短睡眠潛伏期、增加非 REM 第 2 期睡眠的效果（PMID 17559、6120270）。然而，模型實際上是「重新預測」了藥物的已知用途，此情形屬再利用模型的已知侷限性，並不代表新的適應症機會。

值得特別注意的是：flunitrazepam 因高度濫用潛力（包括作為約會強暴藥物使用）已在美國被列為 Schedule I 管制物質，其他多國亦有嚴格管制。現有文獻中，大量研究聚焦於其濫用現象、毒理學及法醫鑑識，而非受控的治療性臨床試驗，這從根本上限制了臨床再利用的可行性。

## 香港上市資訊

Flunitrazepam 在香港**未取得任何上市許可**，無許可證紀錄，亦無核准適應症。本藥物因高度濫用潛力，在香港屬受管制藥物。

## 安全性考量

安全性資訊請參考原廠仿單。

> **重要提示（來源：Evidence Pack 文獻記錄）**：多篇文獻記載 flunitrazepam 具有顯著的濫用風險，包括與酒精協同加重 CNS 抑制（PMID 38676788）、高度記憶損害與精神運動損傷（PMID 16087304、9860106）、停藥反彈性失眠（PMID 430730）及作為約會強暴藥物的犯罪使用紀錄。在安全性資料正式補全前，臨床使用評估應將上述風險列為首要考量。

## 結論與下一步

**決策：Hold**

**理由：**
Flunitrazepam 雖然對失眠的機轉相關性直接，但 TxGNN 實際上是重新預測了藥物本身的已知用途，並非真正的新適應症發現。更關鍵的是，本藥在香港未上市、在多國列為嚴格管制藥物，且現有文獻中的安全性信號（濫用、遺忘、致命中毒）遠超其治療潛力，無差異化療效優勢。

**若要推進需要：**
- 完成法規可行性評估：確認香港現行管制框架下是否允許研究性使用
- 補充 TFDA/香港衞生署仿單取得正式安全性警語與禁忌資料（DG001 修復）
- 補充詳細 MOA 資料（DrugBank API 查詢，DG002 修復）
- 評估同機轉、安全性更佳的替代候選藥物（如 temazepam、lormetazepam）是否可作為替代方案
