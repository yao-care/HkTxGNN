# Flunitrazepam：從苯二氮平類鎮靜安眠藥到失眠

## 一句話總結

Flunitrazepam 是苯二氮平（benzodiazepine）類藥物，在香港以安眠藥形式上市，但資料庫未記載原適應症。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效。目前有 **1 個臨床試驗**（觀察性世代研究）和 **10 篇相關文獻**，沒有 Phase 2/3 RCT。
失眠很可能本來就是它的既有用途，並非真正的老藥新用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料。依藥理學已知資訊，Flunitrazepam 是苯二氮平類藥物，作為 GABA-A 受體的正向異位調節劑，產生鎮靜與催眠作用。

這與失眠的治療目標直接吻合。多篇文獻也指出它在許多國家是常用的處方安眠藥。
因此，「失眠」較可能是既有的標示用途，而不是新發現的適應症。原適應症欄位為空白，較可能是來源資料缺漏。

文獻同時顯示明顯的風險訊號，包括停藥後的反彈性失眠、身體平衡受損、對呼吸的影響、記憶受損，以及濫用與毒性問題。

## 安全性考量

安全性資訊請參考原廠仿單。

香港衛生署仿單的警語與禁忌尚未取得，目前也查無藥物交互作用資料。
以下只是文獻中觀察到的風險訊號，不是仿單內容：
- 停藥後反彈性失眠
- 身體平衡與站立穩定度受損（跌倒與髖部骨折風險）
- 記憶與精神動作功能受損
- 與酒精併用會增強中樞抑制
- 對呼吸有影響（如嚴重 COPD 病人）
- 有濫用與毒性報告
- 老年人對藥效較敏感

## 結論與下一步

**決策：Hold**

**理由：**
- 失眠與 Flunitrazepam 的作用機轉直接吻合，藥物在香港也以安眠藥上市，但目前沒有已完成的 Phase 2/3 RCT 資料，證據停在 L3。
- 香港衛生署仿單的警語與禁忌資料缺失，屬阻斷性資料缺口，無法進入安全性篩選。文獻中的反彈性失眠、記憶受損與濫用風險也需要納入評估。

**若要推進需要：**
- 取得並解析香港衛生署仿單，確認核准適應症、警語與禁忌
- 確認失眠是否已是三張許可證的核准適應症；若是，就不屬於老藥新用
- 補充 DrugBank 的作用機轉資料
- 針對老年、COPD 等族群建立安全性監測計畫

**其他預測適應症（不建議推進）：**
- 偏頭痛（Migraine Disorder）與腦幹先兆偏頭痛：僅有模型預測，無試驗與文獻（L5），Hold。
- 焦慮（Anxiety）與焦慮症（Anxiety Disorder）：證據多為濫用、毒性與精神動作受損，缺乏針對焦慮療效的研究（L4），Hold。
