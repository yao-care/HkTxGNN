# Fluocinolone Acetonide：從局部皮質類固醇到肥厚性扁平苔癬

## 一句話總結

Fluocinolone Acetonide 在香港以外用乳膏形式上市，屬於皮質類固醇類藥物，但註冊資料未載明原適應症。
TxGNN 模型預測它可能對**肥厚性扁平苔癬 (Hypertrophic Lichen Planus)** 有效。
目前**沒有臨床試驗**，也**沒有文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Fluocinolone Acetonide 是外用皮質類固醇，這是依藥物一般類別推論，並非來自本次提供的資料。其抗發炎作用在皮膚發炎性疾病中已被廣泛應用，機轉上可能適用於 T 細胞介導的苔癬樣皮膚病。

扁平苔癬屬於發炎性皮膚病，肥厚性型態的皮損通常使用強效外用類固醇治療。因此在 TxGNN 的四個預測中，肥厚性扁平苔癬在生物學上最合理。

同時預測的其他扁平苔癬變異型分數相近，但支持度較低：

- **環狀萎縮性扁平苔癬（99.42%）**：長期使用強效類固醇有加重皮膚萎縮的風險。
- **色素性扁平苔癬（99.42%）**：對外用類固醇的反應不確定。
- **扁平苔癬類天疱瘡（99.34%）**：罕見的重疊疾病，重症時可能需要全身性治療。

這三者目前都建議 Hold。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 分數很高（99.42%），但沒有任何臨床試驗或文獻佐證，證據等級僅為 L5。作用機轉與香港仿單的警語、禁忌症也都缺資料，目前只能視為研究問題。

**若要推進需要：**
- 系統性文獻搜尋，確認外用強效類固醇用於肥厚性扁平苔癬的既有證據
- 取得香港衞生署仿單，補齊警語、禁忌症與核准適應症
- 從 DrugBank 補充作用機轉資料
- 評估長期使用的皮膚萎縮風險，尤其是對萎縮性變異型
- 確認外用劑型與目標病灶的給藥途徑是否相容
