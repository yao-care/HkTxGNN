# Fluorescein：從眼科診斷染劑到 Prinzmetal 變異型心絞痛

## 一句話總結

Fluorescein（螢光素）是眼科常用的診斷染劑，用於眼角膜染色與眼底血管攝影，本身不是治療藥物。
TxGNN 模型預測它可能對 **Prinzmetal 變異型心絞痛 (Prinzmetal angina)** 有效，但目前**沒有任何臨床試驗或文獻**支持，這個預測很可能是知識圖譜的假象。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Fluorescein 是惰性的診斷用染劑，靠螢光顯影，沒有已知的藥理治療作用。

Prinzmetal 變異型心絞痛是冠狀動脈痙攣造成的心臟疾病，和 fluorescein 的診斷用途沒有任何已知關聯，也找不到合理的作用機轉。
模型給出 99.81% 的高分，卻缺乏臨床與文獻佐證，較可能是知識圖譜的統計假象，不應視為有效訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測只來自模型分數，沒有臨床試驗與文獻，證據等級為 L5。
- Fluorescein 是診斷染劑，對冠狀動脈痙攣沒有可想像的治療機轉。

**補充觀察：**
同一份預測清單中，類風濕性關節炎、甲狀腺功能亢進、血紅素病變等項目雖有較多研究，但這些研究都是把 fluorescein 當作診斷或染色工具（如乾眼評估、眼底血管攝影），並非用它治療疾病，因此也不構成再利用證據。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與核准適應症。
- 補充 fluorescein 的作用機轉資料（DrugBank）。
- 出現任何以 fluorescein 為治療介入的研究證據，再重新評估；在此之前不建議投入資源。
