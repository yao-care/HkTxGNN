# Flupentixol：從思覺失調症到視網膜失養症

## 一句話總結

Flupentixol 是一種 thioxanthene 類抗精神病藥，原本用於治療思覺失調症（schizophrenia）。
TxGNN 模型預測它可能對**視網膜失養症（retinal dystrophy with or without extraocular anomalies）**有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，flupentixol 是 thioxanthene 類抗精神病藥，藥理上作用於多巴胺受體（D1、D2、D3、D5），在思覺失調症中的用途已被確立。

不過，視網膜失養症是一組遺傳異質性高的疾病，目前沒有資料顯示多巴胺受體拮抗與其病理機轉有關。這個高分預測（0.9999）僅來自知識圖譜的計算結果，**無法由現有資料建立機轉上的連結**。

另外值得注意的是，TxGNN 同時預測了其他多個疾病（如 X 染色體連鎖近視、Charcot-Marie-Tooth 病 1G 型、水腦無腦畸形等），同樣沒有臨床或文獻證據支持。其中眼部相關疾病（近視類）雖有「視網膜多巴胺訊號參與眼球生長調控」的一般性假說，但拮抗劑的方向性可能反而不利，仍屬高度推測。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測新適應症僅有 TxGNN 模型分數，沒有任何臨床試驗或文獻，證據等級為 L5。
- 作用機轉資料缺漏，且多巴胺受體拮抗與視網膜失養症之間沒有已知的機轉關聯，不建議推進。

**若要推進需要：**
- 補齊 flupentixol 的作用機轉資料（MOA）。
- 取得香港衛生署仿單的警語與禁忌症資料，完成安全性篩選。
- 進行文獻回顧與前臨床研究，確認多巴胺訊號與視網膜失養症之間是否存在可驗證的機轉連結。
- 若考慮其他預測適應症，需先確認有無實質證據，再重新評估優先順序。
