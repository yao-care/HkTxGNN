# Flutamide：從前列腺癌到良性生殖系統腫瘤

## 一句話總結

Flutamide 是一種非類固醇雄性素受體拮抗劑，原本用於前列腺癌治療。
在本次彙整的預測結果中，排名第一的是「前列腺癌／腦癌易感性」，但它屬於遺傳風險標籤，並非可治療的臨床適應症，而且沒有任何試驗或文獻支持。
因此本報告以**有文獻資料的「良性生殖系統腫瘤 (benign reproductive system neoplasm)」**作為主要評估對象，目前有 **0 個臨床試驗**和 **14 篇文獻**，其中多為小型、描述性或機轉類研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Flutamide 是雄性素受體拮抗劑，可阻斷雄性素在前列腺等雄性素依賴組織中的作用，這是它治療前列腺癌的基礎。

生殖系統組織（前列腺、性腺等）多受性類固醇荷爾蒙調控。現有文獻顯示，Flutamide 對良性前列腺組織確有藥效學作用：例如在良性前列腺增生 (BPH) 患者中，Flutamide 與前列腺體積、PSA 及睪固酮的變化相關；與 LHRH 促效劑併用時，良性前列腺腺體出現明顯萎縮。這些結果提示雄性素阻斷可影響良性生殖組織。

需要提醒的是，這些證據多屬年代久遠、規模小或描述性研究，部分來自前列腺癌患者或動物模型，並非直接針對「良性生殖系統腫瘤」的療效試驗。高分預測也可能主要來自知識圖譜中與前列腺癌節點的鄰近性，而非獨立的臨床訊號。

- **肝毒性**：Flutamide 已知有肝毒性風險，若用於良性疾病，這點在效益風險評估中分量很重。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測的 TxGNN 分數都很高（約 99.98%），但沒有任何臨床試驗，且高分很可能來自知識圖譜中與前列腺癌的鄰近性。唯一有文獻的「良性生殖系統腫瘤」，證據也多是年代久遠、規模小或描述性的研究，僅能列為研究問題。
- Flutamide 的肝毒性風險明確，若用於良性疾病，風險效益比需謹慎評估。

**若要推進需要：**
- 釐清「良性生殖系統腫瘤」的具體疾病定義，鎖定單一可治療的臨床適應症
- 取得 Flutamide 的作用機轉資料（目前缺乏）
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩查
- 針對目標良性疾病進行系統性文獻回顧，並考慮設計前瞻性研究
- 擬定肝功能監測與肝毒性風險管理計畫，並與較新、肝毒性較低的抗雄性素藥物比較
