# Flutamide：從原適應症未載明到前列腺癌／腦癌易感性

## 一句話總結

Flutamide 是一種非類固醇雄性素受體拮抗劑，本次提供的資料未載明其原適應症。
TxGNN 模型預測它可能對**前列腺癌／腦癌易感性 (prostate cancer/brain cancer susceptibility)** 有效，
但目前**沒有臨床試驗、也沒有文獻**支持這個預測，證據等級為 L5（僅有模型預測）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Flutamide 屬於雄性素受體拮抗劑，透過阻斷雄性素訊號，抑制雄性素依賴組織的生長。這解釋了模型為何把它與前列腺相關疾病連在一起。

99.98% 的高分很可能來自知識圖譜中，Flutamide 與雄性素受體及前列腺癌節點距離很近。但這個預測有兩個問題：

- 「前列腺癌／腦癌易感性」是合併後的疾病實體，屬於易感性標籤，不是可以直接治療的臨床適應症。
- Flutamide 在前列腺癌的既有用途，並未記錄在本次資料的原適應症中。這個預測因此可能只是重複已知用途，沒有帶來新的老藥新用價值。

要判斷這個預測有沒有意義，需要先整理這個疾病實體的對應關係。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有任何臨床試驗或文獻佐證。
- 預測對象是易感性標籤，不是可治療的適應症，而且可能只是重複 Flutamide 已知的前列腺癌用途。

**若要推進需要：**
- 整理「前列腺癌／腦癌易感性」的疾病實體對應，釐清它是否代表可治療的適應症。
- 補齊原適應症與作用機轉（DrugBank）。
- 取得香港衛生署仿單，完成安全性篩選（目前為阻斷性缺口）。

**其他候選預測：**
在同一份資料的其他預測中，「良性生殖系統腫瘤 (benign reproductive system neoplasm)」證據較多，評為 L3、建議列為研究問題。
其中 PMID 1722793（1991 年）是 Flutamide 用於良性前列腺增生的人體資料。
但資料僅有小型、較舊的觀察性或機轉研究，沒有 RCT，也沒有登記試驗。
Flutamide 另有肝毒性疑慮，因此需先做安全性與效益風險評估。
