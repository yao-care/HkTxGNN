# Fluvoxamine：從社交畏懼症／強迫症到焦慮症

## 一句話總結

Fluvoxamine（氟伏沙明）是一種 SSRI 類藥物，原本用於社交畏懼症、恐懼症及強迫症。
TxGNN 模型預測它可能對**焦慮症 (Anxiety Disorder)** 有效，目前有 **14 個臨床試驗**和 **20 篇文獻**支持這個方向。
需要注意的是，焦慮症與原適應症高度重疊，這比較接近「已知用途的延伸」，而非全新的再利用方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Fluvoxamine 屬於選擇性血清素再吸收抑制劑（SSRI），透過抑制血清素再吸收來調節情緒與焦慮相關的神經迴路。

它在強迫症與社交焦慮症中的療效已有相當證據，而這兩者本身就屬於焦慮譜系疾病。因此，機轉上推測它也可能適用於恐慌症、廣泛性焦慮症等其他焦慮症。文獻中包括 2025 年針對 fluvoxamine 在焦慮症與強迫症的系統性回顧總覽，以及社交焦慮症的 meta-analysis，均支持此方向。

需特別說明：這項預測與原適應症大幅重疊，更像是 on-label 用途的延伸，而非真正的新用途發現。

## 安全性考量

- **知識圖譜標示的潛在禁忌／風險族群**：癲癇、雙相情緒障礙、重度情感性疾患、肝病、膽囊疾病、凝血疾病、抗精神病藥惡性症候群、抗利尿激素不當分泌症候群（含腎因性）、血清素症候群。此資料來自知識圖譜，並非仿單文字。
- **藥物交互作用**：共查得 100 筆交互作用，以下為部分主要項目。
  - 嚴重（Major）：Alosetron、Diethylpropion、Dolasetron、Bupropion
  - 中度（Moderate）：Aspirin、Clarithromycin、Morphine、Pioglitazone、Aprepitant、多種皮質類固醇（如 Dexamethasone、Hydrocortisone）等
- **文獻提示的安全訊號**：與 phenothiazine 類（levomepromazine）併用曾有誘發癲癇的個案報告；與 methadone 併用曾有毒性個案報告；SSRI 類有性功能障礙、多汗及腸胃道副作用的報告。兒童與青少年使用需留意自殺意念監測，並可參考 CPIC 基因型導向劑量建議。

仿單的正式警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 焦慮症有多項 Phase 3 試驗（含兒童焦慮症與強迫症）、網絡統合分析及系統性回顧支持，證據等級為 L1。但這與原適應症高度重疊，應視為既有用途的延伸，而非新發現。
- 藥物交互作用多，並有若干嚴重等級，使用上需設置安全防護。

**若要推進需要：**
- 取得香港衛生署核准仿單，確認正式適應症、警語與禁忌（目前許可證未載明適應症文字）
- 補充詳細作用機轉資料
- 建立交互作用篩檢機制（特別是 CYP 相關藥物、抗精神病藥、Bupropion 等）
- 兒童與青少年族群的自殺意念監測計畫，並考慮 CPIC 藥物基因體學劑量建議
- 其他預測項目的後續追蹤：恐慌症／懼曠症（L2，有雙盲 RCT 但無登記試驗）及內因性憂鬱症（L2，有 Phase 2 試驗但狀態未知）可列為次要方向；各類人格障礙預測僅有模型分數，建議暫緩（Hold）
