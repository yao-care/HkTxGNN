# Folic Acid（葉酸）：從維生素補充到生物素代謝疾病

## 一句話總結

Folic Acid（葉酸，Vitamin B9）是人體必需的水溶性維生素，廣泛用於補充葉酸缺乏及預防神經管缺陷。TxGNN 模型預測它可能對**生物素代謝疾病 (Biotin Metabolic Disease)** 有效，預測分數高達 99.49%，但目前**無任何直接臨床試驗或文獻**支持此再利用方向，現有 13 個臨床試驗均為間接或不相關研究。

## 為什麼這個預測合理？

葉酸（Vitamin B9）與生物素（Vitamin B7）同屬 B 群維生素，在一碳代謝循環中存在間接代謝交互。生物素依賴性羧化酶（丙酮酸羧化酶、乙醯 CoA 羧化酶、丙酸 CoA 羧化酶）缺乏時，下游代謝物的累積可能間接影響葉酸依賴的甲硫胺酸循環效率，兩者在生化層面存在拓撲上的鄰近性。

然而，機轉方向根本上相反。生物素代謝疾病（包括生物素酶缺乏症 BTD 及全羧化酶合成酶缺乏症 MCD）的標準治療是**直接補充生物素**，葉酸在生化上無法作為生物素輔酶的替代物，亦無法修復生物素酶活性不足的問題。

TxGNN 的高預測分數（0.9948）極可能源自知識圖譜中 B 群維生素節點的**拓撲聚集效應**（B 群維生素彼此在 KG 中相鄰），而非特異性的藥物-疾病機轉支持。零篇直接臨床文獻進一步確認此連結缺乏實際臨床證據基礎。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 高分（99.49%）很可能是知識圖譜中 B 群維生素節點拓撲聚集所致，而非真實的藥物-疾病機轉連結。生物素代謝疾病的標準治療為**補充生物素本身**，葉酸無法替代生物素輔酶功能，機轉上缺乏再利用合理性；加上目前零篇直接文獻、零個直接臨床試驗，不建議進入下一階段評估。

**若要推進需要：**
- 取得葉酸完整仿單安全性資料（DG001 阻斷項目）
- 確認 MOA 資料（DG002 高影響缺口），查詢 DrugBank API 補充作用機轉
- 針對生物素代謝疾病進行針對性文獻搜尋，確認是否有任何葉酸-生物素代謝交互的基礎研究
- 若仍無文獻支持，建議**關閉此候選**，資源移至更具機轉合理性的預測適應症
