# 葉酸 (Folic Acid)：從原適應症未載明到生物素代謝疾病 (Biotin Metabolic Disease)

## 一句話總結

葉酸是水溶性 B 群維生素（B9），在香港有 11 張已登記的許可證，但資料中沒有載明原適應症。
TxGNN 模型預測它可能對**生物素代謝疾病 (Biotin Metabolic Disease)** 有效。
目前有 **12 個臨床試驗登記**，但都只是間接相關（多為營養補充或代謝支持研究），**沒有任何文獻**直接支持。

註：Evidence Pack 初步標示為 L4。但已登記的試驗都不是針對生物素代謝疾病，也沒有機轉研究或文獻，因此本報告依判定規則保守列為 L5。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，資料中也沒有列出原適應症。葉酸（B9）與生物素（B7）都是水溶性 B 群維生素，都參與一碳代謝與羧化酶相關的代謝路徑。TxGNN 的高分很可能反映了知識圖譜中維生素與輔因子節點之間的網路鄰近性，而非已證實的藥理關聯。

目前**找不到直接的機轉連結**。典型的生物素代謝疾病（如生物素酶缺乏症、全羧化酶合成酶缺乏症）的標準治療是補充生物素，而不是葉酸。若葉酸有任何助益，最多是輔助性的，例如矯正併存的葉酸缺乏。

由於缺少原機轉與原適應症資料，無法用已知藥理驗證這個預測。因此這個高分應視為需要進一步查證的線索，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.49%），但很可能來自維生素節點在知識圖譜中的相近性。沒有直接機轉連結，也沒有針對生物素代謝疾病的試驗或文獻。
- 已知的生物素代謝疾病以生物素治療，葉酸即使有效也只是輔助性質。香港仿單的警語與禁忌資料也尚未取得。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症（目前為阻擋性缺口）
- 從 DrugBank 補齊葉酸的作用機轉與原適應症資料
- 由臨床專家確認生物素代謝疾病中是否存在合併葉酸缺乏的族群，並評估葉酸作為輔助治療的合理性
- 完成 NCT03360435、NCT03444155、NCT01474486 的相關性評估，並針對生物素酶缺乏症、全羧化酶合成酶缺乏症等疾病補做專題文獻搜尋
