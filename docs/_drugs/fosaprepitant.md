# Fosaprepitant：從化療引起的噁心嘔吐到腎因性抗利尿不適當症候群

## 一句話總結

Fosaprepitant 是 aprepitant 的前驅藥（prodrug），屬於 NK1 受體拮抗劑，既有用途是預防化療引起的噁心與嘔吐。
TxGNN 模型預測它可能對**腎因性抗利尿不適當症候群 (Nephrogenic Syndrome of Inappropriate Antidiuresis, NSIAD)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏經整理的作用機轉資料。已知 fosaprepitant 在體內轉換為 aprepitant，透過阻斷 substance P 與 NK1 受體，抑制化療引起的噁心與嘔吐。

NSIAD 的成因是抗利尿激素第二型受體（AVPR2）的功能獲得性突變。目前沒有已知的 NK1 路徑會影響這個受體，因此原適應症與預測適應症之間看不出明確的機轉關聯。

99.92% 的分數只代表模型預測，沒有任何研究資料佐證。這個預測目前只能視為待驗證的假說，不能當作療效依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測適應症沒有任何臨床試驗或文獻，證據等級僅為 L5。
- 機轉上找不到 NK1 拮抗作用與 NSIAD 的關聯。
- 同一份資料中，其他排名靠前的預測（肺囊蟲肺炎、痲瘋、隱球菌腦膜炎、多發性內分泌腫瘤）也都缺乏機轉依據。
- 多發性內分泌腫瘤名下連結的 3 個試驗，都是化療噁心嘔吐的支持性治療研究，並未測試疾病本身的療效。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌症，才能進行安全性篩選。
- 補齊 DrugBank 的作用機轉資料，並評估 NK1 訊號與 AVPR2 或抗利尿調控之間是否有任何文獻依據。
- 進行系統性文獻回顧與臨床前研究，確認有生物學合理性後，再考慮重新評估。
