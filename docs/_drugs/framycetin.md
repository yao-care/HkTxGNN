# Framycetin：從外用抗生素到硬化性膽管炎

## 一句話總結

Framycetin（又稱 neomycin B）是一種胺基糖苷類抗生素，腸道吸收差，主要以外用方式使用。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測（L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Framycetin 屬於胺基糖苷類抗生素，這類藥物主要對革蘭氏陰性菌有抗菌活性。但 Framycetin 腸道吸收極差，通常只做外用，全身暴露量很低。

模型給出 99.66% 的高分，只是知識圖譜上的關聯，並非藥理機轉的證據。硬化性膽管炎是慢性膽道發炎與纖維化疾病，目前沒有資料顯示 Framycetin 對它有作用。由於原適應症與機轉資料缺失，兩者的關聯也無法驗證。因此，**目前找不到合理的機轉連結**。

同一藥物的其他預測也有類似問題。排名前 7 的預測多為泌尿生殖道感染，例如泌尿道感染、淋病性尿道炎、黃色肉芽腫性腎盂腎炎，另有先天性凝血酶原缺乏症。
- 感染類預測：在類別層級上有抗菌活性的可能，但 Framycetin 全身吸收極少，難以在尿液或組織中達到治療濃度。
- 先天性凝血酶原缺乏症：屬遺傳性凝血因子疾病，抗菌藥沒有已知作用，較可能是知識圖譜的假關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 7 個預測適應症都只有模型分數，沒有臨床試驗或文獻。第一名的硬化性膽管炎也找不到合理的機轉。
- 香港唯一的許可證是動物用外用藥，與人用全身治療的預測不符。

**若要推進需要：**
- 補齊 Framycetin 的作用機轉與原適應症資料（DrugBank）。
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選。
- 確認劑型與給藥途徑是否可能達到目標器官所需的暴露量。
- 檢索硬化性膽管炎與 Framycetin／neomycin 的臨床前及臨床研究。若仍無任何證據，建議不再優先考慮此預測。
