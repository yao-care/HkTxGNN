# Fremanezumab：從偏頭痛預防到腦幹先兆偏頭痛

## 一句話總結

Fremanezumab 是抗 CGRP 單株抗體，在香港以 AJOVY 預充填注射劑上市，一般用於偏頭痛預防。
TxGNN 模型預測它可能對**腦幹先兆偏頭痛 (Migraine with Brainstem Aura)** 有效。
目前**無臨床試驗登記**，有 **20 篇文獻**，多為間接證據（真實世界觀察研究、動物模型、綜述），沒有直接針對腦幹先兆的研究。

## 為什麼這個預測合理？

資料庫未收錄詳細的作用機轉。但從文獻可知，Fremanezumab 是完全人源化的單株抗體，選擇性結合降鈣素基因相關肽 (CGRP)。CGRP 是強效血管擴張因子，在偏頭痛病理生理中扮演核心角色。

腦幹先兆偏頭痛屬於伴隨先兆的偏頭痛亞型，與 Fremanezumab 已知的偏頭痛適應症在病理上同源。先兆被認為與皮質擴散性抑制 (CSD) 有關，因此 CGRP 阻斷理論上可能影響先兆。

不過機轉證據並不一致。大鼠 CSD 模型顯示：
- Fremanezumab 可減緩 CSD 傳播速度、縮短皮質恢復期，但無法阻止 CSD 發生（PMID 31895266）。
- 它也不影響 CSD 引起的動脈擴張與血漿蛋白外漏（PMID 31127003）。

這使得「CGRP 阻斷能直接預防先兆」的推論只能說部分成立。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何直接針對腦幹先兆偏頭痛的臨床試驗，現有文獻多為其他偏頭痛族群的觀察研究、少數先兆／偏癱型病例報告，以及機轉上結果不一的動物實驗。
- 香港仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與適應症資料。
- 查詢 DrugBank，補齊作用機轉。
- 收集腦幹先兆或偏癱型偏頭痛的更直接證據，例如登記研究、個案系列或前瞻性研究。
- 確認腦幹先兆患者的診斷與使用族群（此族群常被排除於 RCT 之外）。

另外，排名第 2 的預測「蠕蟲狀皮膚萎縮 (Atrophoderma Vermiculata)」分數為 99.04%，但無任何試驗或文獻，也沒有合理的機轉連結，僅為模型預測（證據等級 L5，建議 Hold）。
