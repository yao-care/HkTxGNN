# Fulvestrant：從荷爾蒙受體陽性乳癌到 HIV 感染

## 一句話總結

Fulvestrant 是選擇性雌激素受體降解劑（SERD），原本用於荷爾蒙受體陽性的乳癌治療。本地許可證資料未列出適應症文字，此處依相關試驗與藥物類別判斷。
TxGNN 模型預測它可能對 **HIV 感染 (HIV infectious disease)** 有效，但目前有 **0 個臨床試驗**，僅有 **1 篇文獻**，且該文獻研究的是 HTLV-1 而非 HIV，因此實質上僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位尚未取得）。已知 Fulvestrant 是雌激素受體降解劑，用於雌激素受體陽性的乳癌。

以目前資訊來看，**找不到合理的機轉連結**。Fulvestrant 沒有已知的抗反轉錄病毒或宿主導向的抗 HIV 活性。0.999 的高分只是知識圖譜的預測結果，並非生物學證據。

原適應症（乳癌）與 HIV 感染在疾病性質上沒有明顯關聯。這個預測較可能來自知識圖譜中的鄰近節點關係，不宜視為有藥理學依據的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗，唯一的文獻研究的是 HTLV-1 而非 HIV，也找不到合理的機轉。
- 同一藥物的其他預測（多發性內分泌腫瘤、貓免疫缺乏症候群、猴免疫缺乏病毒感染、罕見神經發展疾患）也都缺乏直接證據。
- 多發性內分泌腫瘤的試驗實際上都是乳癌試驗，屬於原有適應症，不能當作新適應症的支持證據。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉（MOA）資料，重新評估是否存在機轉連結
- 取得香港衛生署仿單的警語與禁忌症
- 找到直接測試 Fulvestrant 於 HIV 的前臨床或臨床研究，目前沒有這類證據，建議先以文獻檢索確認
- 補充許可證核准適應症文字，以確認原適應症
