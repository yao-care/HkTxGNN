# Gadobenic acid：從 MRI 對比劑到退化性關節炎（Osteoarthritis）

## 一句話總結

Gadobenic acid（gadobenate dimeglumine）是含釓（gadolinium）的 MRI 診斷用對比劑，本身沒有治療用途。
TxGNN 模型預測它可能對**退化性關節炎 (Osteoarthritis)** 有效，但**沒有任何臨床試驗**，僅有 **1 篇文獻**，而且該文獻是把它當作影像工具，並非治療證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Gadobenic acid 是釓類 MRI 對比劑，用於增強影像對比，沒有已知的治療機轉。

TxGNN 的高分很可能來自知識圖譜中的「影像共現」關聯。文獻中確實有研究用釓對比劑做 dGEMRIC（延遲釓增強 MRI 軟骨造影）來評估膝關節軟骨品質，模型因此把藥物與骨關節炎連在一起。這是診斷用途的關聯，不代表藥物能改善關節炎。

同樣的情況也出現在排名第 3 的類風濕性關節炎：4 篇文獻都是用 gadobenate dimeglumine 做手、腕、寰樞關節的 MRI 造影，評估滑膜炎，同樣沒有疾病治療效果的證據。其餘預測（如 brachyolmia、假性軟骨發育不全、良性攝護腺肥大、禿髮等）只有模型分數，沒有任何試驗或文獻，也沒有合理的藥理機轉。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測缺乏治療證據。唯一的文獻是診斷影像研究，藥物在其中是造影工具，而非治療藥物。
- 作為診斷用對比劑，它沒有合理的抗關節炎機轉，模型高分可能只是知識圖譜的鄰近關係假象。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症。目前這是阻擋性缺口，無法進入安全性篩選。
- 補齊 DrugBank 的作用機轉資料。
- 除非有新的治療性研究證據，否則不建議推進。這個藥的價值在於診斷，而非老藥新用。
