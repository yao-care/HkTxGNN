## Galantamine：從阿茲海默症到心因性運動障礙
{: .text-alpha }

## 一句話總結

Galantamine 是一種用於阿茲海默症的藥物。TxGNN 模型預測它可能對**心因性運動障礙 (Psychogenic Movement Disorders)** 有效，但目前**沒有任何臨床試驗或文獻**直接研究這個疾病，僅有模型預測支持。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻中的描述，galantamine 是乙醯膽鹼酯酶抑制劑，同時是菸鹼型乙醯膽鹼受體的正向異位調節劑。

理論上，膽鹼系統調節可能影響基底核迴路，但心因性運動障礙並沒有已知的膽鹼系統病理基礎。這個連結目前只是推測，沒有數據支持。分數來自 TxGNN 模型（深度學習），可能反映模型從相關疾病之間學到的相似性，並非生物學證據，不能代替臨床證據。

## 安全性考量

- **知識圖譜記錄的禁忌關聯**（非仿單內容）：家族性長 QT 症候群、肝衰竭、癲癇、慢性阻塞性肺病、腎臟疾病、肝臟疾病、膽囊疾病、消化性潰瘍、氣喘、膀胱頸阻塞、十二指腸潰瘍、房室傳導阻滯等。
- **藥物交互作用**：共查得 100 筆，以下為部分範例。
  - **重大 (Major)**：Bupropion
  - **中度 (Moderate)**：Famotidine、Ranitidine、Cimetidine、Atropine、Clarithromycin、Metronidazole、Dicyclomine、Hyoscyamine、Glycopyrronium、Trospium 等（多為抗膽鹼藥物或影響代謝的藥物）
- **與預測適應症相關的額外提醒**：膽鹼酯酶抑制劑可能加重帕金森症狀與顫抖，且有誘發肌張力不全的通報。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測適應症（心因性運動障礙）沒有任何臨床試驗或文獻，證據等級為 L5，僅憑模型分數不足以推進。
- 現有間接文獻顯示膽鹼酯酶抑制劑可能加重運動症狀，風險與效益方向不明。

**若要推進需要：**
- 補充詳細的作用機轉（MOA）資料。
- 取得香港仿單的警語、禁忌與核准適應症文字。
- 針對心因性運動障礙進行文獻與試驗檢索，或設計小型探索性研究。
- 若考慮遲發性運動異常方向，需先釐清 galantamine 專屬證據，而非僅依賴藥物類別層級的資料。
- 評估運動障礙族群中，膽鹼酯酶抑制劑是否可能惡化症狀的安全性風險。
