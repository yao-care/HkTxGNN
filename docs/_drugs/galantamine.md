# Galantamine：從阿茲海默症到心因性運動障礙

## 一句話總結

Galantamine 是一種膽鹼酯酶抑制劑，原本用於阿茲海默症等神經退化性疾病的治療。
TxGNN 模型預測它可能對**心因性運動障礙 (Psychogenic Movement Disorders)** 有效，
但目前**沒有臨床試驗和文獻**直接支持此預測，僅屬模型推論。

## 為什麼這個預測合理？

Galantamine 是膽鹼酯酶抑制劑，同時是菸鹼型乙醯膽鹼受體 (nAChR) 的別位增強劑，臨床上用於改善阿茲海默症的認知功能。

目前缺乏詳細的作用機轉資料。就現有資訊而言，沒有證據支持膽鹼系統調節與心因性（功能性）運動障礙的病理機轉有直接關聯。此預測較可能反映知識圖譜中，該疾病與其他神經系統疾病在網絡上的鄰近性，而非已驗證的藥理機轉。

此外，膽鹼增強也可能加重部分運動症狀，作用方向並不確定，需要謹慎看待。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容，需以原廠仿單確認）：家族性長 QT 症候群、房室傳導阻滯、肝衰竭／肝病、腎臟病、癲癇、慢性阻塞性肺病、氣喘、消化性潰瘍／十二指腸潰瘍、膽囊疾病、膀胱頸阻塞、輸尿管積膿。
- **藥物交互作用**：共查得 100 筆，以下為部分代表。
  - **重度**：Bupropion。
  - **中度**：抗膽鹼藥物（Atropine、Hyoscyamine、Dicyclomine、Glycopyrronium、Clidinium、Trospium，藥理作用相互拮抗）；H2 受體阻斷劑（Famotidine、Ranitidine、Cimetidine）；Clarithromycin、Metronidazole；Dolasetron、Palonosetron；Eliglustat、Loperamide、Lorcaserin。

仿單的警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（分數 99.90%），沒有任何臨床試驗或文獻支持，證據等級為 L5。
- 缺乏機轉資料，且膽鹼增強可能加重運動症狀；既有文獻多指出此類藥物與運動障礙相關，而非用於治療。
- 其他預測適應症（慢性抽動症、原發性姿勢性顫抖、良性顫抖發作）同樣僅屬模型預測，建議皆為 Hold；「錐體外徑與運動疾病」雖有 L4 間接文獻，但內容並不支持療效。

**若要推進需要：**
- 補充 galantamine 的詳細作用機轉資料。
- 取得香港仿單的警語、禁忌與核准適應症。
- 建立心因性運動障礙與膽鹼／菸鹼系統的機轉假說，並進行系統性文獻與臨床試驗檢索。
- 若有初步前臨床或小型探索性研究的支持，再重新評估；同時需評估禁忌疾病與抗膽鹼藥物交互作用的風險。
