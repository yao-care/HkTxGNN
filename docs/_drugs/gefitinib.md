# Gefitinib：從肺癌到牙齦纖維瘤病

## 一句話總結

Gefitinib 是一種 EGFR 酪胺酸激酶抑制劑，已知用於 EGFR 突變的肺癌治療（本資料包未登載原適應症）。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Gefitinib 屬於 EGFR 酪胺酸激酶抑制劑，其在 EGFR 驅動的肺癌中的療效已被證實。EGFR 訊號也曾在纖維增生過程中被討論，但這只是推測，本資料包沒有任何數據支持。

牙齦纖維瘤病是牙齦組織的纖維增生性疾病，與肺癌在疾病性質上差異很大。目前看不到 gefitinib 與此疾病之間有明確的機轉連結。這項預測完全來自 TxGNN 的高分（99.89%），沒有臨床試驗或文獻佐證。

## 結論與下一步

**決策：Hold**

**理由：**
這項預測只有模型分數，沒有任何臨床試驗或文獻，也沒有機轉依據，證據等級為 L5。此外，香港仿單的警語與禁忌症資料缺失，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症
- 從 DrugBank 補齊 gefitinib 的作用機轉（MOA）
- 針對 EGFR 訊號在牙齦纖維增生中的角色做文獻調查，確認是否有機轉依據
- 補上原適應症的正式登載內容

**另一項觀察：** 同一份預測清單中，「肺門癌 (lung hilum carcinoma)」有一篇 gefitinib 用於晚期肺腺癌的病例報告（PMID 22688581）。這個方向在生物學上較合理，但屬於既有肺癌適應症的延伸，且需要 EGFR 突變狀態與組織型資料，證據等級為 L4。
