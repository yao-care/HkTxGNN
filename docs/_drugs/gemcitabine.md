## Gemcitabine：從卵巢癌到女性乳癌
{: .text-alpha }

## 一句話總結

Gemcitabine 是一種核苷類似物化療藥，原本用於卵巢癌及相關婦科腫瘤的治療。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效，
目前資料中有 **35 個臨床試驗**（其中多項為乳癌直接相關）和 **20 篇文獻**支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記錄。根據已知資訊，Gemcitabine 是一種核苷類似物，透過抑制核糖核苷酸還原酶並嵌入 DNA，阻斷 DNA 合成，對快速分裂的腫瘤細胞具細胞毒性。

卵巢癌與乳癌同屬婦女常見的上皮性惡性腫瘤，且都對 DNA 合成抑制類化療有反應。Gemcitabine 在卵巢癌中的作用機轉，理論上同樣適用於乳癌細胞。

文獻顯示，Gemcitabine 與紫杉類、鉑類、蒽環類及抗 HER2 治療合併使用時，在前臨床與臨床研究中呈現相加或協同效果。單藥在轉移性乳癌的反應率約 16%–37%，合併療法可更高。

## 安全性考量

- **知識圖譜中的禁忌關聯疾病**（非仿單內容）：腎臟疾病、肝臟疾病、膽囊疾病、血小板減少、白血球減少、貧血（含巨球性貧血）、間質性肺病、感染性疾病、膿輸尿管、溶血性尿毒症候群（含典型）。
- **藥物交互作用**：資料庫共查得 100 筆交互作用。已列出的項目中，Naltrexone 為中度（Moderate），Levofloxacin 為輕度（Minor），其餘（如 Calcitriol、Doxycycline、Pantoprazole、Omeprazole、Metformin、Morphine、Prednisone、Aprepitant 等）等級未知。
- 另有個案報告指出 Gemcitabine 可能引起視網膜病變。

香港仿單的警語與禁忌尚未取得，詳細資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 乳癌方面已有多項 Phase 3 隨機試驗（如 NCT00006459、NCT00093795），且有多項已完成的 Phase 2 研究與大量回顧文獻，證據達 L1。但文獻資料以回顧性文章為主，且 Gemcitabine 於乳癌的實際核准適應症需另行核對。
- 安全性資料尚不完整（香港仿單警語與禁忌缺漏），且藥物具骨髓抑制風險，須設置防護措施。

**若要推進需要：**
- 取得香港衛生署仿單，完成警語與禁忌的確認
- 補充 DrugBank 作用機轉資料
- 核對各 Phase 3 試驗的已發表結果（尤其是 NCT00006459 與 NCT00093795 的主要終點）
- 確認香港各許可證的核准適應症是否已涵蓋乳癌
- 制定骨髓抑制、肝腎功能的監測計畫，並特別留意上述知識圖譜所列的高風險族群
