# Gemfibrozil：從高三酸甘油脂血症到類風濕性關節炎

## 一句話總結

Gemfibrozil 是一種纖維酸類降血脂藥，原本用於治療高三酸甘油脂血症。
TxGNN 模型預測分數最高的新適應症為**類風濕性關節炎 (Rheumatoid Arthritis)**，但目前僅有**動物與前臨床研究**支持，並無臨床試驗。
相較之下，**HIV 感染相關代謝異常**（排名第 3）與**低 HDL 血症**（排名第 4）的人體研究證據較多，較具進一步探索價值。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Gemfibrozil 是 PPAR-α 促效劑，在高三酸甘油脂血症中的療效已被證實。

PPAR 促效作用具有抗發炎與免疫調節效果（例如調節 T 細胞反應與細胞激素訊號），這與自體免疫性關節發炎有合理的關聯。支持資料包括：相關的泛 PPAR 促效劑 Bezafibrate 在實驗性關節炎的前臨床研究，以及 2019 年大鼠模型中 Gemfibrozil 搭配減量類固醇的研究。

不過，目前沒有 Gemfibrozil 用於類風濕性關節炎的人體對照研究。這個預測停留在機轉合理、動物證據的階段。

## 安全性考量

- **禁忌症（來自知識圖譜，非仿單內容）**：肝臟疾病、膽囊疾病、膽結石（含膽囊結石、膽總管結石）、原發性膽汁性膽管炎、腎功能不全、血小板減少、白血球減少、貧血（含巨球性貧血）、Reynolds 症候群。
- **藥物交互作用**：共查得 100 筆，以下為主要項目：
  - **嚴重 (Major)**：Rosuvastatin、Simvastatin（併用有橫紋肌溶解風險，HIV 病例報告亦見 Cerivastatin 併用案例）、Pioglitazone、Repaglinide、Loperamide、Eluxadoline
  - **中度 (Moderate)**：多種胰島素、Chlorpropamide、Tolazamide、Nateglinide、Rosiglitazone、Chenodeoxycholic acid、Rifaximin
  - 若用於 HIV 族群，還需留意與抗反轉錄病毒藥物（尤其蛋白酶抑制劑）的交互作用。

仿單的警語與禁忌資料目前尚未取得，詳細內容請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 類風濕性關節炎的證據僅限於動物與前臨床層級（L4），沒有人體試驗，高預測分數主要來自模型運算。
- 排名第 2 與第 5 的預測缺乏任何證據與合理機轉，不建議推進。HIV 相關代謝異常與低 HDL 血症雖有較多人體研究，但本質上是原血脂適應症的延伸，而非全新疾病機轉。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選
- 補充詳細的作用機轉（MOA）資料
- 針對類風濕性關節炎，需要更完整的動物模型驗證，再評估是否設計早期人體試驗
- 若轉向 HIV 相關血脂異常，應優先評估與抗反轉錄病毒藥物及 Statin 的交互作用管理計畫
