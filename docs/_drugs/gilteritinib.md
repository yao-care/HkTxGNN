# Gilteritinib：從急性骨髓性白血病到延髓型小兒麻痺

## 一句話總結

Gilteritinib 是 FLT3/AXL 酪胺酸激酶抑制劑，一般已知用於治療復發或難治性、帶有 FLT3 突變的急性骨髓性白血病（AML）。
TxGNN 模型預測它可能對**延髓型小兒麻痺 (Bulbar Polio)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Gilteritinib 屬於 FLT3/AXL 激酶抑制劑，其療效已在 FLT3 突變 AML 中獲得證實。

但就現有資料，**看不出機轉上適用於延髓型小兒麻痺的合理連結**。延髓型小兒麻痺是小兒麻痺病毒（picornavirus）感染，會破壞腦幹的運動神經元。目前沒有已知路徑把 FLT3/AXL 抑制連到病毒複製或神經保護。AXL 雖曾在部分病毒進入與免疫逃逸的討論中出現，但沒有針對小兒麻痺病毒的證據，屬於推測。

0.991 的分數只是知識圖譜的預測結果，不等於有生物學或臨床依據。此外，小兒麻痺是疫苗可預防、且有全球根除計畫的疾病，腫瘤用激酶抑制劑不太可能成為優先方向。

## 安全性考量

安全性資訊請參考原廠仿單。

一般已知 gilteritinib 可能造成骨髓抑制、QT 間期延長與分化症候群（differentiation syndrome）。這類風險不適合用於急性神經感染性疾病。以上為一般藥理知識，非本次資料包內容。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測僅來自模型分數，沒有臨床試驗、文獻或可辨識的機轉連結支持（證據等級 L5）。
- 藥物的安全性特徵與預測適應症不相容，且該疾病有疫苗預防與根除計畫。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌症資料（目前為阻斷性資料缺口）。
- 補充藥物作用機轉資料（DrugBank）。
- 取得 FLT3/AXL 與小兒麻痺病毒感染或運動神經元損傷相關的前臨床證據，才有重新評估的基礎。
