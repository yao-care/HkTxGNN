# Gilteritinib：從急性骨髓性白血病到延髓型小兒麻痺（Bulbar Polio）

## 一句話總結

Gilteritinib 是一種 FLT3/AXL 酪胺酸激酶抑制劑，原本用於治療急性骨髓性白血病（AML）。
TxGNN 模型預測它可能對**延髓型小兒麻痺 (Bulbar Polio)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Gilteritinib 是 FLT3/AXL 酪胺酸激酶抑制劑，用於 FLT3 突變的復發或難治性 AML。

FLT3/AXL 抑制與小兒麻痺病毒感染腦幹運動神經元之間，**沒有已知的生物學關聯**。若要建立關聯，只能做推測，例如宿主激酶對病毒進入或複製的影響，或對神經發炎的作用，但目前沒有任何資料支持。

此外，小兒麻痺是可由疫苗預防的病毒性疾病，目前沒有核准的抗病毒藥物。這個高分預測可能來自知識圖譜的拓撲結構假象，而非真實的生物學。該藥物的腫瘤治療特性（骨髓抑制、QT 延長、分化症候群，以及 100 筆藥物交互作用紀錄）也不適合在缺乏強力證據下用於病毒性神經疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的支持是 TxGNN 的高預測分數（99.10%），沒有臨床試驗、文獻或機轉依據，證據等級為 L5。
- FLT3/AXL 抑制與小兒麻痺病毒感染之間缺乏生物學關聯，且藥物的毒性特性不利於此適應症。

**若要推進需要：**
- 補充作用機轉（MOA）資料，並釐清是否有任何宿主激酶與小兒麻痺病毒感染相關的機轉。
- 進行體外抗病毒或神經元感染模型的前臨床研究，驗證是否有活性。
- 取得香港仿單的警語與禁忌症，完成安全性篩選。
- 評估風險效益：在已有疫苗預防的疾病中，使用具骨髓抑制與 QT 延長風險的腫瘤藥物是否合理。
