# GINSENG（人參）：從原適應症未登載到藥物性骨質疏鬆

## 一句話總結

人參 (Ginseng) 在香港有 2 張上市許可證，但許可證資料沒有登載原適應症。
TxGNN 模型預測它可能對**藥物性骨質疏鬆 (Drug-induced Osteoporosis)** 有效。
目前只有 **1 個臨床試驗**，且相關性僅屬 C 級（間接、待確認），**沒有文獻**支持，因此證據仍以模型預測為主。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，許可證資料也沒有原適應症。人參是傳統草本藥材，其成分人參皂苷 (ginsenosides) 在前臨床研究中被提出可能影響成骨細胞與蝕骨細胞的活性，機轉上或許與骨代謝有關。但這個說法並未被本次提供的資料支持。

99.95% 的預測分數來自知識圖譜的關聯推論，不是實際研究結果。原適應症與新適應症的關聯性目前也無法評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5。唯一的臨床試驗是針對停經婦女骨代謝的非 Phase 3 試驗，不能算作藥物性骨質疏鬆的直接證據。
- 沒有文獻、作用機轉資料和安全性資料，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署 (Department of Health) 的仿單，補齊警語與禁忌症（目前為阻斷性資料缺口）。
- 從 DrugBank 補充作用機轉資料。
- 確認 NCT02763280 的收案條件與主要終點，判斷是否與藥物性骨質疏鬆相關。
- 檢索人參與骨質疏鬆（尤其是糖皮質素誘發）的前臨床與臨床文獻。
- 釐清 2 張許可證的成分與核准適應症。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
