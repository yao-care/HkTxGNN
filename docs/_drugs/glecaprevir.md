## Glecaprevir：從慢性 C 型肝炎到 HIV 感染
{: .text-alpha }

## 一句話總結

Glecaprevir 是一種 C 型肝炎病毒 (HCV) NS3/4A 蛋白酶抑制劑，原本用於治療慢性 C 型肝炎。
TxGNN 模型預測它可能對 **HIV 感染 (HIV infectious disease)** 有效，但現有 **7 個臨床試驗**和 **20 篇文獻**探討的都是 HIV/HCV 共感染病人的 C 肝治療，並非直接治療 HIV。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Glecaprevir 是 HCV NS3/4A 蛋白酶抑制劑，臨床上與 pibrentasvir（NS5A 抑制劑）組成固定劑量複方使用，在 C 型肝炎的療效已被證實。

目前沒有證據顯示 Glecaprevir 對 HIV 本身有直接抗病毒活性。TxGNN 的高分可能來自知識圖譜中 HIV 與 HCV 的網路鄰近性，例如同屬抗病毒藥物類別、臨床上常見共感染。

因此，若有任何 HIV 相關益處，也應是間接的，例如治癒 HCV 後降低肝臟與心血管風險。這比較接近「HIV 族群中的 C 肝治療」，而不是真正的 HIV 新適應症。

## 安全性考量

- **藥物交互作用**：共記錄 57 項交互作用。主要包括：
  - **重大 (Major)**：Rosuvastatin、Simvastatin、Edoxaban
  - **中度 (Moderate)**：Dexamethasone、Esomeprazole、Omeprazole、Apixaban、Betrixaban、Cobicistat、Deferasirox 等
- 與 HIV 抗反轉錄病毒藥物併用時，需特別評估交互作用。
- 文獻提示，C 肝病毒 DAA 治療期間需留意 B 型肝炎病毒再活化。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- Glecaprevir 沒有已知的直接抗 HIV 機轉，所有臨床證據都是 HIV/HCV 共感染病人的 C 肝治療，並未證明對 HIV 本身有效。TxGNN 的高分應視為網路相似性所致，不宜當作 HIV 療效訊號。
- 排名較後的預測（B 型肝炎、猿猴免疫缺陷病毒、貓後天免疫缺乏症候群、E 型肝炎）證據更薄弱或機轉不成立，更不建議推進。

**若要推進需要：**
- 體外抗 HIV 活性試驗，確認是否有任何直接作用
- 詳細的作用機轉資料 (MOA)
- 香港仿單的警語與禁忌症
- 若轉向「HIV/HCV 共感染」族群的 C 肝治療，應另以該定位重新評估，並制定與抗反轉錄病毒藥物的交互作用管理計畫
