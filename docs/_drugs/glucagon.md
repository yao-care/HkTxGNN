# Glucagon：從（原適應症資料缺漏）到腸躁症

## 一句話總結

Glucagon（升糖素）是一種胰臟來源的胜肽類激素，在香港有一張已上市的單方許可證，但本報告所整理的資料中沒有記載核准適應症。
TxGNN 模型預測它可能對**腸躁症 (Irritable Bowel Syndrome)** 有效。
目前有 **2 個臨床試驗**和 **20 篇文獻**，但這些證據多半針對 GLP-1 類藥物，而非升糖素本身，屬於間接支持。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，升糖素是由前升糖素（proglucagon）衍生的胜肽，作用於升糖素受體，也已知能放鬆胃腸道平滑肌、降低腸道蠕動。

腸躁症的症狀與腸道蠕動異常、內臟痛覺敏感以及腦腸軸訊號有關。升糖素的抗痙攣作用，理論上可能緩解部分症狀，這是此預測在機轉上的合理之處。

不過，目前找到的證據大多是 GLP-1 及其類似物（如 ROSE-010）。它們與升糖素同屬前升糖素衍生胜肽，但藥理作用不同。與升糖素本身的連結因此是間接的。TxGNN 的高分是計算預測，不能取代直接的臨床證據。

## 安全性考量

- **藥物交互作用**：共查得 25 筆交互作用，列出的皆為輕度（Minor）。主要涉及 Warfarin 與多種 β 阻斷劑，例如 Atenolol、Metoprolol、Propranolol、Carvedilol、Bisoprolol、Labetalol 等，包含眼用劑型（如 Timolol、Betaxolol）。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 現有證據多半來自 GLP-1 及其類似物，沒有直接測試升糖素用於腸躁症的臨床研究。TxGNN 的高分預測僅能視為待驗證的研究假說。
- 香港許可證缺少核准適應症與仿單安全性資料，也缺乏作用機轉資料。

**若要推進需要：**
- 取得香港衛生署仿單，補齊核准適應症、警語與禁忌症
- 補充升糖素的作用機轉資料（如 DrugBank）
- 尋找或設計直接以升糖素治療腸躁症的臨床研究（如小型概念驗證試驗）
- 評估劑型與給藥途徑是否適合腸躁症的長期使用，現有許可證為注射劑型
