# Glutamic Acid：從（原適應症未載明）到停經後骨質疏鬆症

## 一句話總結

Glutamic Acid（麩胺酸）是一種胺基酸，在香港以複方胺基酸輸液成分的形式上市，但資料中未載明其原適應症。
TxGNN 模型預測它可能對**停經後骨質疏鬆症 (Postmenopausal Osteoporosis)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Glutamic Acid 在香港以複方胺基酸輸液的成分上市，但原適應症與作用機轉皆未在資料中載明，因此無法將預測與已知機轉做比對。

麩胺酸訊號（NMDA 與 AMPA 受體、麩胺酸轉運蛋白）在成骨細胞與蝕骨細胞中已有描述，這是可能的連結。但這屬於前臨床生物學，並沒有確立的治療方向。

TxGNN 的高分**不等於臨床證據**，目前只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 首選預測（停經後骨質疏鬆症）沒有任何臨床試驗或文獻，證據等級為 L5，僅有模型預測。
- 原適應症、作用機轉與香港仿單的警語和禁忌症皆缺漏，無法進行安全性篩選。
- 青光眼的預測還有作用方向相反的疑慮。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症（目前為阻斷性缺口）
- 從 DrugBank 補充作用機轉資料，釐清原適應症
- 蒐集麩胺酸與骨代謝的前臨床或觀察性研究，確認作用方向
- 確認各許可證的劑型與核准適應症

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後方可應用。
