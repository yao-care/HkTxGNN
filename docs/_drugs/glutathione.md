# Glutathione：從（原適應症未載明）到硬化性膽管炎

## 一句話總結

Glutathione（麩胱甘肽）是細胞內主要的抗氧化分子，香港目前有 1 張單方許可證（眼科用途製劑），但許可證上沒有登載核准適應症文字。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有臨床試驗**，僅有 **18 篇間接相關文獻**，且尚無研究顯示補充 glutathione 能改善此疾病。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Glutathione 是細胞內最主要的抗氧化物質，負責清除活性氧並參與解毒反應。

氧化壓力與膽管損傷被認為與膽汁淤滯性疾病的發展有關，包括原發性硬化性膽管炎（PSC）。文獻顯示 PSC 病人存在與 glutathione 相關的生物學異常，例如抗 GST（glutathione S-transferase）自體抗體、肝臟銅滯留，以及化學物誘發的膽管纖維化動物模型。

不過，這些證據都是間接且關聯性的。沒有任何研究證明給予 glutathione 能使硬化性膽管炎受益，因此目前只能視為值得研究的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖然 TxGNN 分數很高，但沒有任何臨床試驗，文獻僅顯示 glutathione 相關生物學與 PSC 有關聯，並無治療效果的直接證據。
- 香港現有製劑為眼科用途，與肝膽疾病所需的給藥途徑可能不一致。

**若要推進需要：**
- 詳細的作用機轉資料（MOA）
- 評估適合肝膽疾病的給藥途徑與劑型
- 前臨床研究（例如 PSC 動物模型中直接測試 glutathione 或其前驅物）
- 取得仿單中的警語、禁忌症與藥物交互作用資訊
