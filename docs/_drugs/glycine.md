# Glycine：從原適應症未登載到鼻腔疾病

## 一句話總結

Glycine（甘胺酸）是一種胺基酸，在香港有 20 張含此成分的許可證，但資料中未登載明確的原適應症。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效。
目前僅有 **1 個無關的臨床試驗**和 **2 篇前臨床文獻**，皆未直接評估甘胺酸，證據實質上只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，許可證資料中也沒有列出原適應症。已知甘胺酸是抑制性神經傳導物質，也是一般代謝用的胺基酸。這兩種角色都沒有資料顯示與鼻黏膜病變有關。

TxGNN 分數很高（99.85%），但這只是知識圖譜的推論結果。目前找不到任何研究把甘胺酸用於鼻腔疾病，因此我們無法建立可信的機轉連結。

原適應症資料缺漏，也讓我們無法比較原適應症與新適應症的關聯。這個預測目前只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有 TxGNN 模型預測。唯一的臨床試驗是與甘胺酸無關的造影研究，兩篇文獻也是不相關的前臨床研究。
- 缺少作用機轉與原適應症資料，無法建立合理的機轉連結。安全性資料也不完整。
- 同一份資料中的第二個預測「急性喉咽炎 (Acute Laryngopharyngitis)」同樣是 L5，唯一檢索到的文獻是討論另一種藥物（sivelestat），同樣不支持。

**若要推進需要：**
- 取得香港衛生署許可證的仿單，補齊警語、禁忌與核准適應症
- 補充甘胺酸的作用機轉資料（例如查詢 DrugBank）
- 檢索甘胺酸與鼻腔疾病的直接研究（臨床或前臨床）
- 補上上述資料後，重新評估機轉合理性與證據等級
