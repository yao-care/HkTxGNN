# Glycocholic acid：從（原適應症資料缺漏）到 Prinzmetal 心絞痛

## 一句話總結

Glycocholic acid（甘膽酸）是一種結合型初級膽酸，本次資料中沒有記載原適應症。
TxGNN 模型預測它可能對 **Prinzmetal 心絞痛 (Prinzmetal angina)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，原適應症也沒有記錄。Glycocholic acid 是結合型初級膽酸，現有資料無法建立它與冠狀動脈痙攣（Prinzmetal 心絞痛的病理基礎）之間的合理機轉。

TxGNN 分數很高（99.98%），但這只代表知識圖譜中的關聯訊號，不等於有生物學或臨床依據。本次沒有提供任何試驗或文獻，因此這個預測目前**缺乏可驗證的支持**，應視為待查假說。

## 結論與下一步

**決策：Hold**

**理由：**
- Prinzmetal 心絞痛的預測僅有模型分數，沒有試驗、沒有文獻，也沒有可支持的機轉，證據等級為 L5。
- 原適應症、作用機轉與安全性資料都缺漏，目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症（此為阻斷性缺口）。
- 從 DrugBank 補齊作用機轉，並確認 Glycocholic acid 在 CERNEVIT 中的角色（主成分或賦形劑）。
- 針對 Prinzmetal 心絞痛與冠狀動脈痙攣，以膽酸為關鍵詞做系統性文獻檢索，確認是否存在直接證據。
- 若要在心血管方向繼續評估，先釐清心肌梗塞相關的生物標記關聯究竟是致病因子還是疾病結果，再決定是否值得做前臨床研究。
