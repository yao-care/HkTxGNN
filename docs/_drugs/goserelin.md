## Goserelin: Amenorrhea (disease)
{: .text-alpha }

## 一句話總結

Goserelin 是一種 GnRH 促效劑，原本用於子宮內膜異位症的治療。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前僅有 **1 個間接相關的臨床試驗**和 **15 篇文獻**，且閉經多被視為藥物的藥理作用，而非獨立待治療的疾病，因此這個預測是否算真正的再利用仍有疑問。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥物類別，Goserelin 是 GnRH 促效劑。持續給藥會使腦下垂體的 GnRH 受體去敏感化，抑制 LH/FSH 分泌及卵巢雌二醇生成，造成可逆的低雌激素狀態，進而導致閉經。

這個效果與它在子宮內膜異位症的作用機制相同：抑制雌激素以縮減異位內膜病灶。因此「閉經」在藥理上是可預期的結果，也是治療的副產物，並不是另一個獨立的治療標的。

文獻中，閉經大多出現在兩種脈絡：乳癌的卵巢抑制治療，以及化療相關的閉經或卵巢保護。把閉經當成一種要治療的疾病，並沒有明確支持。TxGNN 模型（深度學習）的高分可能反映模型學到的相關疾病之間的相似性，而非生物學證據，應謹慎解讀。

## 結論與下一步

**決策：Hold**

**理由：**
- 閉經是 Goserelin 抑制性腺軸的預期藥理效果，與原適應症為同一機轉，文獻也多將其視為治療的結果而非待治療的疾病。唯一的 Phase 3 試驗是乳癌試驗，狀態未知，只提供間接支持。
- 即使 TxGNN 分數很高，是否能視為有意義的再利用適應症仍有疑問。

**若要推進需要：**
- 釐清臨床上「閉經」要治療的具體情境（例如：誘導閉經以控制月經出血、化療期間卵巢保護），並重新定義適應症。
- 取得詳細的作用機轉資料（MOA）。
- 取得香港仿單的警語與禁忌資料，完成安全性篩選。
- 針對重新定義後的情境，尋找直接的 RCT 證據。

**附註：**排名第 2、3 的預測（腎發育不全、雙側腎發育不全）雖然分數約 0.9906，但沒有臨床試驗或文獻，機轉上也看不出關聯，分數來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，而非生物學證據，證據等級為 L5，建議 Hold。
