# Guaiacol：從（原適應症未載明）到急性喉咽炎

## 一句話總結

Guaiacol 在香港有一張上市許可證（外用膏藥製劑），但資料中未載明原適應症。
TxGNN 模型預測它可能對**急性喉咽炎 (Acute Laryngopharyngitis)** 有效，
目前**沒有直接的臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Guaiacol 歷來被用作局部抗菌劑與祛痰類產品的成分，
理論上可能與上呼吸道黏膜刺激有關，但這只是推測，現有證據並未支持。

急性喉咽炎屬上呼吸道發炎，與 Guaiacol 過去的使用場景（呼吸道相關）有概念上的關聯。
不過目前唯一的支持是 TxGNN 圖譜的高分（0.996），沒有臨床試驗或文獻佐證，
因此僅能視為待驗證的假說。

### 另一個值得留意的預測：鼻腔疾病

TxGNN 對 Guaiacol 的第二個預測是**鼻腔疾病 (Nasal Cavity Disease)**（分數 99.51%，證據等級 L4，建議：研究問題）。
有 1 個 Phase 2 試驗，但測試的是結構相近的 **Guaifenesin**（癒創甘油醚），並非 Guaiacol 本身，屬間接證據。
Guaifenesin 是祛痰劑，可稀釋呼吸道黏液，可能與慢性鼻炎相關；Guaiacol 是否有相同作用尚未確立。

## 結論與下一步

**決策：Hold**

**理由：**
急性喉咽炎的預測只有 TxGNN 模型分數支持，沒有臨床試驗與文獻，證據等級為 L5。
鼻腔疾病方向雖有 1 個 Phase 2 試驗，但用藥是 Guaifenesin，無法直接代表 Guaiacol。
此外，作用機轉與香港仿單的安全性資料都缺漏，尚無法進入安全性篩選。

**若要推進需要：**
- 從 DrugBank 取得 Guaiacol 的作用機轉（MOA）
- 從香港衛生署下載並解析仿單，補齊警語與禁忌症
- 確認上市製劑的劑型、核准適應症與給藥途徑，並評估與預測適應症的途徑相容性
- 搜尋 Guaiacol 本身（而非 Guaifenesin）在上呼吸道疾病的臨床或前臨床研究
