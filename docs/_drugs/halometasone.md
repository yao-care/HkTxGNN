# Halometasone：從外用皮質類固醇到原發性皮膚 T 細胞淋巴瘤

## 一句話總結

Halometasone 是外用皮質類固醇，在香港以乳膏劑型上市。
TxGNN 模型預測它可能對**原發性皮膚 T 細胞淋巴瘤 (Primary Cutaneous T-cell Lymphoma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Halometasone 屬於外用皮質類固醇，這類藥物透過活化糖皮質素受體 (glucocorticoid receptor)，產生抗發炎與抗增生作用。

外用皮質類固醇在臨床上常用於早期皮膚 T 細胞淋巴瘤的皮膚局部治療，所以從藥物類別來看，這個預測有一定合理性。不過目前沒有針對 halometasone 本身的試驗或文獻，這個關聯只是合理推測，尚未經驗證。

TxGNN 分數（99.62%）是模型輸出，不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測（L5），沒有任何臨床試驗或文獻。
- 香港仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症（阻斷性缺口）。
- 補上 DrugBank 的作用機轉資料。
- 檢索 halometasone 或同類外用皮質類固醇用於皮膚 T 細胞淋巴瘤的臨床試驗與文獻。
- 確認劑型與給藥途徑是否符合新適應症需求（目前尚待評估）。

**其他預測適應症：**
模型另外預測了聲帶息肉、中耳息肉、子宮息肉、外耳道息肉，這四項同樣是 L5 且建議 Hold。
- 外用皮膚劑型並不適用於這些部位。
- 四項分數幾乎相同（99.56%–99.57%），較像是圖譜鄰近關係造成的假象，而非各疾病的獨立訊號。
