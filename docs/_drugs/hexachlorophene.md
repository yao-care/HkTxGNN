# Hexachlorophene：從外用抗菌消毒到脂漏性角化症

## 一句話總結

Hexachlorophene（六氯酚）是一種酚類抗菌消毒劑，香港已有含此成分的外用軟膏上市。
TxGNN 模型預測它可能對**脂漏性角化症 (Seborrheic Keratosis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Hexachlorophene 是雙酚類抗菌消毒劑，主要對金黃色葡萄球菌等革蘭氏陽性菌有抑菌作用，但原適應症的完整資料並未提供。

脂漏性角化症是良性的表皮增生病變，並非感染性疾病。抗菌消毒劑與它之間沒有明確的病理或藥理關聯。

99.97% 的高分是知識圖譜上的鄰近關係推論，可能來自與其他角化性皮膚疾病的圖譜距離。這個預測目前沒有文獻記載的機轉連結，應視為純粹的模型訊號。

## 安全性考量

安全性資訊請參考原廠仿單。藥物交互作用查詢無結果。

補充說明：Hexachlorophene 經皮吸收後有神經毒性疑慮，特別是用於嬰幼兒或受損皮膚時。相關歷史文獻曾報告早產兒使用 3% 乳劑後出現中樞神經系統空泡化。若要進一步評估，這是最優先的安全議題。

## 結論與下一步

**決策：Hold**

**理由：**
- 該適應症證據等級僅為 L5，沒有臨床試驗與文獻，機轉上也缺乏合理連結。
- 藥物本身有經皮吸收與神經毒性疑慮，不建議投入資源。

**若要推進需要：**
- 取得完整的作用機轉資料與香港衛生署仿單（警語、禁忌症）。
- 確認 HK-23582 的劑型與核准適應症。
- 若仍想探索，建議改看同一藥物排名第 3 的「皮膚疾病」方向。該方向有 2 個已完成的試驗（含 MRSA 去定殖），可聚焦於明確的適應症，例如金黃色葡萄球菌去定殖。
- 進行安全性評估，重點在經皮吸收與神經毒性。
