# 組胺酸 (Histidine)：從胺基酸補充製劑到胃輕癱

## 一句話總結

組胺酸是一種胺基酸，在香港以胺基酸輸液等複方產品上市，但資料中未記載明確的核准適應症。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，預測分數很高。
目前**沒有臨床試驗，也沒有文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，組胺酸是胺基酸類成分，主要見於胺基酸輸液與複方營養製劑。它在原適應症的療效與機轉並無資料可引用。

組胺酸是組織胺 (histamine) 的前驅物，經 L-組胺酸脫羧酶 (HDC) 轉換而成。組織胺可能影響胃腸蠕動與分泌，因此理論上與胃輕癱有關聯。但這只是推測，現有資料不支持任何具體的機轉連結。這個候選目前只靠 TxGNN 的高分。

另有一點需要注意。TxGNN 的第 2 名預測是硬化性膽管炎。檢索到的前臨床研究顯示，肥大細胞釋放的組織胺及 H1/H2 受體訊號會促進膽管增生與纖維化，抑制組織胺訊號或剔除 HDC 反而改善病變。這個方向與「補充組胺酸有益」相反，是潛在的風險訊號。它不直接適用於胃輕癱，但提醒我們組胺酸的組織胺路徑在不同器官的作用可能不同。

## 結論與下一步

**決策：Hold**

**理由：**
- 胃輕癱這個預測沒有任何臨床試驗或文獻，證據等級為 L5，機轉連結也只是推測。
- 相鄰的硬化性膽管炎前臨床資料顯示，組織胺路徑可能有害而非有益，需要審慎看待。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料（目前是阻擋性缺口，無法進入安全性篩選）
- 補充作用機轉資料（例如查詢 DrugBank）
- 系統性檢索組胺酸或組織胺路徑與胃輕癱、胃排空的文獻
- 釐清各產品的核准適應症與劑型，並確認給藥途徑是否適合胃輕癱
