# Histidine：從營養補充（胺基酸輸液成分）到胃輕癱

## 一句話總結

Histidine（組胺酸）是人體必需胺基酸，在香港主要作為胺基酸輸液與靜脈營養製劑的成分使用。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，但目前**沒有任何臨床試驗**，僅有 **1 篇**間接相關的文獻，且該文獻並不支持此預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Histidine 是胺基酸輸液與靜脈營養複方的成分之一，主要功能是提供蛋白質合成所需的必需胺基酸。

在胃輕癱方面，唯一檢索到的文獻（PMID 42668409）探討的是 ATTRv 類澱粉變性症中的胃部類澱粉病變與黏膜去神經支配，屬於疾病病理的背景研究，並未評估 Histidine 或任何組胺酸相關路徑作為治療手段。因此，**目前資料無法支持 Histidine 與胃動力之間存在合理的機轉關聯**。

TxGNN 分數雖高（99.55%），但這只是模型預測，不等同於臨床證據。

## 其他值得注意的預測：硬化性膽管炎

TxGNN 對**硬化性膽管炎 (Sclerosing Cholangitis)** 的預測分數為 99.27%，證據等級 L4，僅有前臨床與間接研究，無臨床試驗：

- Histidine 是組胺的前驅物（經 L-組胺酸脫羧酶 HDC 轉換）。
- 小鼠研究顯示，肥大細胞分泌的組胺會增加膽管增生與纖維化（PMID 27351144、35799467）。
- 缺乏 HDC 的小鼠膽管損傷與肝纖維化減輕（PMID 32054995）。
- 阻斷 H1/H2 組胺受體可減輕 Mdr2-/- 小鼠的損傷與纖維化（PMID 29601088）。

這些證據顯示組胺訊號過度活化對疾病有害，補充 Histidine 作為組胺前驅物，**理論上可能加重而非改善疾病**，作用方向不確定，甚至可能相反。其餘文獻多為生物標記、遺傳學或肝移植後膽管病變，並未測試 Histidine 的治療效果。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（來自 TxGNN 知識圖譜的藥物—疾病關聯，非仿單內容）：腎臟疾病（含慢性腎臟病、末期腎衰竭）、高鈣血症與腎鈣沉著症、腎結石、急性尿酸腎病變、心臟與心血管疾病、地高辛中毒、心室顫動、苯酮尿症及苯丙胺酸代謝異常、結節病、磷代謝異常。

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 兩項預測目前都只有模型分數支持：胃輕癱無臨床試驗，唯一文獻也不支持；硬化性膽管炎的前臨床證據反而提示補充 Histidine 可能有害。
- 缺乏作用機轉與仿單安全性資料，目前不足以推進。

**若要推進需要：**
- 補齊 Histidine 的作用機轉資料（MOA）
- 取得香港衛生署仿單的警語與禁忌資料
- 針對胃輕癱，找出 Histidine 與胃動力調控之間的機轉證據
- 針對硬化性膽管炎，先釐清補充 Histidine 是否會增加組胺訊號、加重疾病（方向性驗證）
- 在有機轉依據後，再規劃前臨床或小型探索性試驗
