# Homatropine：從（許可證未載明原適應症）到脊髓馬尾症候群

## 一句話總結

Homatropine 是一種抗膽鹼（毒蕈鹼拮抗）藥物，香港現有登記的產品為 2% 眼藥水，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**脊髓馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Homatropine 屬於毒蕈鹼拮抗劑（抗膽鹼藥物），透過阻斷毒蕈鹼受體發揮作用。

**這個排名第一的預測，機轉上並不合理。** 脊髓馬尾症候群是神經根受壓迫造成的外科急症，治療核心是緊急手術減壓，而非藥物。即使與膀胱功能障礙有關，抗膽鹼藥物也只能作用於症狀，還可能加重尿滯留。因此 99.89% 的高分只是模型輸出，沒有實證支持，不應直接解讀為療效。

其他三個預測適應症的機轉合理性較高，但同樣缺乏 Homatropine 本身的證據：

| 預測適應症 | TxGNN 分數 | 機轉評估 |
|-----------|-----------|---------|
| 過時的神經originated膀胱（已淘汰疾病術語） | 99.75% | 阻斷毒蕈鹼受體可降低逼尿肌過度活動，生物學上說得通。但該疾病術語已在本體論中標為過時，需先對應到現行術語 |
| 胃十二指腸炎 (Gastroduodenitis) | 99.51% | 抗毒蕈鹼藥可減少胃酸分泌與腸胃蠕動，但並非發炎性胃十二指腸疾病的標準治療 |
| 膀胱過動症 (Overactive Bladder) | 99.16% | 抗毒蕈鹼藥是此適應症的既有藥物類別（M2/M3 阻斷），類別層級合理。但 Homatropine 缺乏膀胱選擇性，全身性抗膽鹼負擔未被評估 |

## 結論與下一步

**決策：Hold**

**理由：**
- 四個預測適應症都只有模型分數，沒有臨床試驗、文獻或藥物特異性證據（證據等級 L5）。
- 排名第一的脊髓馬尾症候群缺乏合理的機轉路徑，抗膽鹼作用還可能加重尿滯留。
- 香港現有的 Homatropine 產品是局部眼用劑型，與預測適應症所需的給藥途徑是否相容，尚未確認。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊原適應症、警語與禁忌症。
- 補充 Homatropine 的作用機轉資料（例如查詢 DrugBank）。
- 若要繼續評估，建議優先改看膀胱過動症，並將「過時的神經originated膀胱」對應到現行疾病術語。
- 針對優先候選適應症做系統性文獻與臨床試驗檢索，並評估全身性抗膽鹼風險。
- 釐清給藥途徑相容性（現有為眼藥水，預測適應症多需全身給藥）。

> 本報告結果僅供研究參考，不構成醫療建議。預測適應症需經臨床驗證後才能應用。
