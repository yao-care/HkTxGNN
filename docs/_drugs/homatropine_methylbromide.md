# Homatropine Methylbromide：從抗蕈毒鹼藥物到胃十二指腸炎

## 一句話總結

Homatropine Methylbromide 是一種四級銨類抗蕈毒鹼（抗膽鹼）藥物，目前資料中沒有登載其原適應症。
TxGNN 模型預測它可能對**胃十二指腸炎 (Gastroduodenitis)** 有效。
目前**沒有臨床試驗**和**沒有文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。以下推論是根據藥物類別，並非已記錄的機轉。Homatropine Methylbromide 屬於四級銨類抗蕈毒鹼藥物。阻斷蕈毒鹼受體可以減少胃酸分泌，也能緩解胃腸平滑肌痙攣。因此，它在緩解胃十二指腸的痙攣或分泌過多症狀上，生物學上說得通。

不過要注意，抗膽鹼藥物並非胃十二指腸炎的疾病修飾療法。這類發炎通常由幽門螺旋桿菌、NSAID 或胃酸損傷引起，抗膽鹼藥物頂多改善症狀，無法處理病因。

TxGNN 給出 0.994 的高分，但這只是模型預測，沒有任何試驗或文獻佐證，不應直接視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級只有 L5，沒有任何臨床試驗或文獻，機轉資料也缺漏。
- 抗膽鹼藥物只可能緩解症狀，無法針對胃十二指腸炎的常見病因，暫不建議推進。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症，這是進入安全性篩選的前提。
- 從 DrugBank 補齊作用機轉（MOA）資料。
- 搜尋並評估抗膽鹼藥物用於胃十二指腸症狀的臨床試驗與文獻。
- 釐清目標是症狀緩解還是疾病治療，再決定是否值得進一步研究。

**補充：** 排名第二的預測「馬尾症候群 (Cauda Equina Syndrome)」不建議推進。該病是需要緊急手術減壓的神經壓迫急症，此藥無法處理病因，抗膽鹼作用還可能加重其典型的尿滯留。高分（99.10%）可能是知識圖譜的假象，且同樣沒有試驗或文獻支持。
