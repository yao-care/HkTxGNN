# 人類 C1 酯酶抑制劑 (Human C1-Esterase Inhibitor)：從原適應症（資料未載明）到嚴重非增殖性糖尿病視網膜病變

## 一句話總結

人類 C1 酯酶抑制劑是血漿衍生蛋白質藥物，香港許可證與證據包皆未載明其原適應症。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效。
目前**沒有臨床試驗和文獻**直接支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供 MOA）。以下說明來自預測推論，屬合理但未證實的假說。

C1 酯酶抑制劑會調控補體的古典途徑與凝集素途徑，同時抑制血漿激肽釋放酶 (plasma kallikrein) 與活化的第 XII 凝血因子 (factor XIIa)。補體活化與激肽釋放酶–激肽 (kallikrein-kinin) 訊號，都被認為與糖尿病視網膜病變中視網膜血管通透性升高和發炎有關。因此在標的生物學上，這個預測並非毫無道理。

但目前沒有針對此病變嚴重程度的臨床或前臨床資料。TxGNN 的 0.996 分只是模型預測，不是證據。此外，這是全身性使用的血漿衍生蛋白質，眼內給藥的可行性與安全性完全沒有被討論過。

## 結論與下一步

**決策：Hold**

**理由：**
- 嚴重非增殖性糖尿病視網膜病變沒有任何臨床試驗或文獻，證據等級僅 L5，且缺乏眼部給藥與安全性的討論。
- 高分只反映模型預測，不足以支持推進。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌症（目前為阻擋性資料缺口，無法進入安全性篩選）。
- 補齊 DrugBank 的作用機轉資料。
- 進行前臨床或機轉評估，例如量測玻璃體中補體與激肽釋放酶的活性。
- 評估眼內給藥的可行性。
- 若要優先挑選方向，可先看排名第 3 的「糖尿病視網膜病變」（證據等級 L4，有補體途徑的遺傳關聯研究），較適合作為研究問題。
- 排名第 2 的「原發性血小板釋放障礙」與排名第 4 的「偽性血管性血友病」，機轉上缺乏合理連結，且沒有任何試驗或文獻，暫不建議追蹤。
