# Hyaluronidase：從（原適應症未載明）到內斜視 (Esotropia)

## 一句話總結

Hyaluronidase 是一種分解玻尿酸的酵素，在香港已有 1 張上市許可證，但資料中未載明其原適應症。
TxGNN 模型預測排名第一的新適應症是**內斜視 (Esotropia)**，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。
在同一批預測中，**糖尿病視網膜病變 (Diabetic Retinopathy)** 的證據明顯較強，有 2 個已完成的 Phase 3 試驗與多篇文獻，詳見「其他值得關注的預測」。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Hyaluronidase 的作用是分解玻尿酸（透明質酸），但這與斜視（眼外肌控制的問題）之間，資料中沒有找到任何機轉上的關聯。

原適應症資料也是空白，無法比較原適應症與內斜視的關聯。

因此這個預測目前只能視為模型的統計結果，機轉上的合理性未獲支持，需要進一步研究才能判斷。

**需要注意的限制：**
- 兩個 Phase 3 試驗的標題只提到嚴重玻璃體出血，尚未確認是否納入糖尿病視網膜病變族群。
- 試驗的療效結果也未在資料中提供。
- 因此證據等級暫定 L2。若確認族群與主要結果為陽性，可升為 L1。

## 安全性考量

安全性資訊請參考原廠仿單。

文獻中另有一篇 2024 年的回顧（[PMID 37145319](https://pubmed.ncbi.nlm.nih.gov/37145319/)）指出，注射 Hyaluronidase 可能引起過敏反應，臨床上常被誤診。

## 結論與下一步

**決策：Hold**

**理由：**
- 以內斜視為預測適應症，目前只有模型分數，沒有試驗、文獻或機轉支持，證據等級為 L5。
- 若要發展，糖尿病視網膜病變是更值得優先評估的方向。

**若要推進需要：**
- 補齊藥物的作用機轉與原適應症資料。
- 取得香港衞生署的仿單，完成警語與禁忌症的安全性篩選。
- 確認 NCT00198510、NCT00198497 是否納入糖尿病視網膜病變族群，並取得其主要療效結果。
- 內斜視需先找出任何機轉或臨床線索，否則不建議投入資源。
