## Hydrocortisone Acetate：從自體免疫與發炎性疾病到圓形禿 (Alopecia Areata)
{: .text-alpha }

## 一句話總結

Hydrocortisone Acetate 是低效價的皮質類固醇，知識圖譜中記錄的相關用途包括自體免疫疾病、腎上腺皮質功能不全與發炎性腸道疾病等。
TxGNN 模型預測它可能對**圓形禿 (Alopecia Areata)** 有效，目前有 **1 個 Phase 3 臨床試驗**和 **2 篇文獻**與此方向相關，但該試驗中 hydrocortisone 僅作為對照組。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Hydrocortisone 屬於皮質類固醇，一般具有抗發炎與免疫抑制作用，這部分為類別層級的一般知識，並非來自本次彙整的 MOA 資料。

圓形禿是 T 細胞媒介的自體免疫疾病，毛囊的免疫豁免狀態瓦解。皮質類固醇可抑制局部發炎與 T 細胞活性，因此機轉上與知識圖譜中記錄的自體免疫、抗發炎關聯一致。

需注意，hydrocortisone 為低效價類固醇，預期療效弱於高效價藥物。唯一的 Phase 3 試驗以 hydrocortisone 1% 作為 clobetasol 0.05% 的對照，因此不能直接證明其相對於安慰劑的療效。

## 安全性考量

- **知識圖譜記錄的禁忌關聯**（非仿單文字）：高血壓、癲癇、胃潰瘍、腎臟疾病、肝臟疾病、膽囊疾病、高血糖、麻疹、單純疱疹病毒角膜炎，以及腦下垂體功能低下與相關生長激素缺乏、性腺功能低下等疾病。

其餘警語、禁忌與藥物交互作用資料不足，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有一項直接研究兒童圓形禿的 Phase 3 試驗，且圓形禿為自體免疫疾病，類固醇的機轉合理；但 hydrocortisone 僅為對照組、樣本小、效價低，療效證據有限。
- 其他預測疾病（如休止期落髮、毛囊黏蛋白症等）皆無試驗或文獻，僅為模型預測（L5），建議暫緩（Hold）。

**若要推進需要：**
- 取得 NCT01453686 的完整結果，確認 hydrocortisone 組的實際反應率。
- 設計與安慰劑或其他效價類固醇的比較研究。
- 取得香港仿單的適應症、警語與禁忌資料，確認各製劑核准用途。
- 補充詳細作用機轉資料，並確認劑型與給藥途徑是否適用於頭皮病灶。
