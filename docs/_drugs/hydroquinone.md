## Hydroquinone：從色素沉著相關外用治療到脂漏性角化症
{: .text-alpha }

## 一句話總結

Hydroquinone（對苯二酚）是外用美白／淡斑成分，透過抑制酪胺酸酶來減少黑色素生成。
TxGNN 模型預測它可能對**脂漏性角化症 (Seborrheic Keratosis)** 有效，
但目前**沒有臨床試驗**，僅有 **1 篇間接的觀察性文獻**，證據相當有限。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未收錄於本次整理的資料中）。根據已知資訊，Hydroquinone 能抑制酪胺酸酶、降低黑色素合成，是常見的外用淡斑成分。

脂漏性角化症常帶有色素沉著，因此理論上，減少黑色素可能使病灶顏色變淡。不過，脂漏性角化症本質上是表皮細胞的良性增生，淡化色素並不會改變病灶本身的增生特性。

目前唯一的文獻是針對亞洲患者顏面色素異常的複合治療觀察性研究，屬於間接證據，無法證明 Hydroquinone 對此病灶有效。高預測分數僅代表計算模型的推論。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，唯一的文獻是間接的觀察性研究，證據等級僅為 L4。
- 脂漏性角化症是良性增生性病灶，Hydroquinone 的淡化色素機轉無法直接解釋治療效益。高預測分數僅是模型推論。

**若要推進需要：**
- 取得香港原廠仿單，確認核准適應症、警語與禁忌症
- 補充詳細的作用機轉資料
- 設計針對脂漏性角化症的對照研究，或系統性回顧 Hydroquinone 用於色素性良性病灶的資料
- 評估外用劑型與目標病灶的給藥途徑相容性
- 若與知識圖譜中的禁忌疾病（如皮膚萎縮、皮膚炎）重疊，需先釐清安全性風險
