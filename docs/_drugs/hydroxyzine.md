# Hydroxyzine：從第一代 H1 抗組織胺到過敏性蕁麻疹

## 一句話總結

Hydroxyzine 是第一代 H1 抗組織胺，在香港已有 11 張許可證，處於上市狀態。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效。
目前只有 **1 個間接相關的臨床試驗**（測試的是其活性代謝物 cetirizine）和 **20 篇文獻**，皆為間接證據，沒有直接針對 hydroxyzine 的高等級試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Hydroxyzine 屬於第一代 H1 受體拮抗劑，其活性代謝物是 cetirizine。皮膚肥大細胞釋放組織胺，會造成風團與紅斑，阻斷 H1 受體在機轉上合理，TxGNN 給出很高的分數也與此一致。

蕁麻疹的標準治療從抗組織胺開始。文獻指出 hydroxyzine 和 diphenhydramine 等第一代藥物過去曾以類似方式使用（PMID 28913986）。這說明預測方向符合臨床邏輯。

不過目前的證據多為間接：
- 唯一的臨床試驗測的是 cetirizine，不是 hydroxyzine。
- 文獻多是第二代抗組織胺的回顧。
- 加拿大過敏與臨床免疫學會（CSACI）的立場聲明（PMID 31582993）指出，新一代 H1 抗組織胺比第一代更安全，應作為一線用藥。

**補充：** 預測清單中的「寒冷性蕁麻疹 (Cold Urticaria)」排名第 3，證據等級 L3。1984 年有一項比較研究（PMID 6480953）直接評估了 hydroxyzine，但發表年代久遠，設計細節無法從現有資料確認。

## 安全性考量

安全性資訊請參考原廠仿單。

文獻提及的第一代抗組織胺共通風險（非仿單資料）：
- 鎮靜、認知功能下降、睡眠品質不佳。
- 口乾、頭暈、姿勢性低血壓。
- 過量或意外事故相關的死亡，以及心臟性猝死（PMID 31582993）。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數很高，機轉也合理。但唯一的臨床試驗測的是代謝物 cetirizine，文獻多為第二代抗組織胺的回顧，缺乏直接針對 hydroxyzine 的證據。
- 香港仿單的警語與禁忌資料缺口被列為 Blocking，無法進入安全性篩選。第一代藥物的鎮靜與抗膽鹼副作用也需要防護。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與核准適應症，解除 Blocking 缺口。
- 補充 hydroxyzine 的作用機轉資料（如 DrugBank）。
- 查核 1984 年比較研究（PMID 6480953）全文，並搜尋 hydroxyzine 直接對照的蕁麻疹 RCT。
- 評估與新一代抗組織胺相比的效益與風險，並訂定鎮靜、抗膽鹼及高齡族群的防護措施。
