# Hypromellose：從眼部潤滑到肝靜脈阻塞性疾病伴免疫缺陷症候群

## 一句話總結

Hypromellose（羥丙基甲基纖維素）是一種惰性的纖維素衍生物，在香港主要作為人工淚液（眼藥水）使用。
TxGNN 模型預測它可能對**肝靜脈阻塞性疾病伴免疫缺陷症候群 (hepatic veno-occlusive disease-immunodeficiency syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，這個預測應視為模型運算的結果，而非有根據的治療方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Hypromellose 是一種惰性的纖維素衍生賦形劑，可作為黏度增強劑、成膜劑與眼部潤滑劑，且幾乎不被全身吸收。

此預測的目標疾病是與 SP110 相關的原發性免疫缺陷症，病理涉及肝臟微血管（竇狀隙）與免疫功能異常。Hypromellose 對免疫細胞、內皮細胞或肝臟沒有已知的藥理活性，因此**找不到合理的機轉連結**。

較可能的解釋是，這個高分反映的是知識圖譜的拓撲結構，而不是真正的生物學關聯。其他排名前十的預測（如 IKZF1 相關全血球減少症、CRAC 通道缺陷、HHV-8 相關腫瘤等）也都沒有機轉支持。排名第 8 的乾癬 (psoriasis) 僅有微弱的間接理由：Hypromellose 凝膠或薄膜理論上可作為外用載體或屏障劑，但這屬於載體效應，並非藥物本身的抗乾癬作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗或文獻支持，證據等級僅為 L5。
- Hypromellose 是幾乎不被全身吸收的惰性賦形劑，與預測疾病之間找不到合理的生物學機轉。高分很可能是知識圖譜的運算假象。

**若要推進需要：**
- 取得明確的機轉假說，說明惰性、非吸收性聚合物如何影響目標疾病的病理。
- 補齊作用機轉（MOA）與香港仿單的警語及禁忌資料。
- 若要評估乾癬方向，需先有外用載體效應之外的藥效證據，並做外用劑型的可行性評估。
- 建議把資源轉向機轉上更合理的候選藥物。
