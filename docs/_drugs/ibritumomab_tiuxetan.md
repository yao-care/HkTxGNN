# Ibritumomab Tiuxetan：從（原適應症未載明）到急性淋巴母細胞白血病

## 一句話總結

Ibritumomab tiuxetan（商品名 Zevalin）是一種靶向 CD20 的放射免疫治療藥物（釔-90 標記），目前在香港已有 1 張上市許可證，但資料中未載明原核准適應症。
TxGNN 模型預測它可能對**急性淋巴母細胞白血病 (Acute Lymphoblastic/Lymphocytic Leukemia)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥物類別，Ibritumomab tiuxetan 是 CD20 導向的放射免疫治療藥物（釔-90 結合物），機轉上可能適用於表現 CD20 的 B 細胞惡性腫瘤。以下推論來自一般藥物類別知識，並非來自本次提供的資料。

然而，這個預測的關聯性偏弱。只有部分 B 系列急性淋巴母細胞白血病會表現 CD20，T 系列則不表現，因此療效可能因亞型而異。TxGNN 分數 (99.78%) 僅為模型預測，不等同於實際療效。

另外，模型也預測了其他 4 個適應症（小腸伯奇氏淋巴瘤，以及小腸、甲狀腺、乳房的黏膜相關淋巴組織 MALT 淋巴瘤），分數介於 99.68%–99.72%。這些預測分數非常接近，很可能來自知識圖譜中相同的鄰近區域，不應視為彼此獨立的證據。

## 結論與下一步

**決策：Hold**

**理由：**
目前僅有模型預測（證據等級 L5），沒有臨床試驗或文獻佐證。急性淋巴母細胞白血病中只有部分亞型表現 CD20，機轉連結偏弱，且缺乏安全性與作用機轉資料，暫不建議推進。

**若要推進需要：**
- 取得香港衛生署的藥品仿單，確認警語、禁忌症與核准適應症
- 補充 DrugBank 的作用機轉（MOA）資料
- 進行 PubMed 與臨床試驗登記系統的文獻與試驗檢索
- 評估 CD20 陽性 B 系列 ALL 亞型的適用性
- 若評估其他預測（如 MALT 淋巴瘤，機轉上較為合理）可列為研究問題，優先於本項
