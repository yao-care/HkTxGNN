# Icatibant：從遺傳性血管性水腫急性發作到 C1 抑制劑缺乏症

## 一句話總結

Icatibant 是選擇性緩激肽 B2 受體拮抗劑，在香港以 Firazyr 預充式針筒注射液上市，用於治療血管性水腫急性發作。
TxGNN 預測它對 **C1 抑制劑缺乏症 (C1 inhibitor deficiency)** 有效，目前有 **22 個臨床試驗**和 **19 篇文獻**支持，其中包含多個已完成的 Phase 3 隨機對照試驗。
此預測較接近已上市適應症的確認，而非嚴格意義的老藥新用。

## 為什麼這個預測合理？

Icatibant 是十肽結構的緩激肽 B2 受體拮抗劑。C1 抑制劑缺乏（遺傳性或後天性）會使激肽釋放酶–激肽系統失控活化，造成緩激肽過量，引發血管性水腫發作。Icatibant 直接阻斷緩激肽的受體，因此機轉上與疾病成因直接對應。

需要說明的是，輸入資料沒有列出原適應症，但 Icatibant 已是上市的 HAE 治療藥，所以本預測大多屬於原有適應症，不是全新的用途。後天性 C1 抑制劑缺乏 (AAE) 目前只有觀察性研究支持，應視為仿單外使用，需再確認。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有 3 個已完成的 Phase 3 隨機雙盲試驗（NCT00097695、NCT00912093、NCT00500656），加上大型登錄研究與日本、中國的上市後資料，HAE 的證據充分，達 L1。
- 後天性 C1 抑制劑缺乏目前只有小規模觀察性研究支持，需按仿單外使用處理。

**若要推進需要：**
- 取得香港衛生署核准的仿單，確認核准適應症、適用族群（成人及兒童）、警語與禁忌；這是進入安全性篩選的前提。
- 確認 HAE 為已核准的適應症，並將後天性 C1 抑制劑缺乏另列為仿單外使用，評估是否需要前瞻性證據。
- 補充作用機轉資料（例如查詢 DrugBank）。

TxGNN 另外預測的四個疾病（serpin 病變、偽性血管性血友病、血小板釋放障礙、免疫介導壞死性肌病）沒有臨床試驗或文獻，也找不到合理的機轉關聯，多半是知識圖譜的近鄰效應，建議暫緩（Hold）。
