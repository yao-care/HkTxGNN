## Ifosfamide：從香港許可證未載明的原適應症到女性乳癌
{: .text-alpha }

## 一句話總結

Ifosfamide（異環磷醯胺）是一種烷化劑類化療藥物，香港許可證資料未載明其核准適應症。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效。
目前有 **6 個臨床試驗**和 **20 篇文獻**與此方向相關，但多為較早期的 Phase 2 研究、回顧與世代研究，缺乏已完成的 Phase 3 RCT。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記錄。根據本報告彙整的資料，Ifosfamide 是需經肝臟 CYP450 活化的 DNA 烷化前驅藥。其活性代謝物 isophosphoramide mustard 會造成 DNA 交叉連結，使快速增生的細胞凋亡。

這種廣泛的細胞毒性機轉在乳癌上有合理性，特別是侵襲性或對化療反應不佳的亞型，例如化生性乳癌 (metaplastic breast cancer)、惡性葉狀瘤與放射線誘發的血管肉瘤。另有研究在乳癌組織微粒體中觀察到 CYP3A4、CYP2C9、CYP2B6 的表現與 Ifosfamide 的代謝，顯示腫瘤內可能有局部活化。

文獻回顧指出，Ifosfamide 單用於曾接受治療的晚期乳癌，反應率約為 7–30%。與其他對乳癌有效的藥物併用時，反應率更高。不過這些證據多來自 1990 年代至 2000 年代初期的研究，目前未見現代的大型對照試驗。

## 安全性考量

- **知識圖譜記錄的禁忌關聯**（非仿單文字）：腎臟疾病、肝臟疾病、膽囊疾病、血小板減少、貧血、白血球減少、低血鉀、高膽紅素血症、Gilbert 症候群、腎小管酸中毒、Fanconi 症候群、膿尿輸尿管等。
- **藥物交互作用**：資料庫共記錄 100 筆，多數為中度。主要包括：
  - 抗黴菌藥：Amphotericin B（含脂質複合物）。
  - 胺基糖苷類：Kanamycin、Neomycin。
  - 磺醯脲類及促胰島素分泌劑：Chlorpropamide、Glimepiride、Glipizide、Glyburide、Tolazamide、Acetohexamide、Nateglinide、Repaglinide。
  - 其他：Bupropion、Aprepitant、Morphine、Metoclopramide、Scopolamine、Dronabinol、Nabilone。
  - Levofloxacin 為輕度。

完整警語與禁忌請以原廠仿單為準。

## 結論與下一步

**決策：Hold**

**理由：**
- 有多項針對乳癌的 Phase 2 研究、回顧與世代研究顯示 Ifosfamide 有活性，但缺乏已完成的 Phase 2/3 隨機對照試驗。試驗狀態多為未知或已終止，且多為併用方案，難以分離出 Ifosfamide 的獨立貢獻。
- 香港許可證資料也未載明核准適應症，加上明顯的骨髓、腎臟與泌尿毒性，目前不宜直接推進臨床使用。

**若要推進需要：**
- 與現行標準乳癌化療比較的對照試驗資料，或針對特定亞型（如化生性乳癌、惡性葉狀瘤）的前瞻性研究。
- 取得香港原廠仿單，確認核准適應症、警語與禁忌。
- 評估 Ifosfamide 相對於現行標準治療的療效與毒性取捨，並擬定骨髓、腎功能與泌尿毒性的監測與 Mesna 防護計畫。
