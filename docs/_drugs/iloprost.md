# Iloprost：從肺動脈高壓到先天性心臟病相關肺動脈高壓

## 一句話總結

Iloprost 是一種前列環素（prostacyclin）類似物，原本用於治療肺動脈高壓。
TxGNN 模型的最高分預測為「毛髮稀少症」，但該預測完全沒有證據支持。因此本報告以**證據最充分的預測：先天性心臟病相關肺動脈高壓 (PAH associated with congenital heart disease)** 為主軸，目前有 **0 個臨床試驗**登記，但有 **19 篇文獻**支持這個方向，且多為觀察性研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Iloprost 是前列環素類似物，作用於 IP 受體，可造成肺血管擴張、抑制血小板聚集與平滑肌增生。

先天性心臟病相關肺動脈高壓（包括艾森曼格症候群）屬於肺動脈高壓 Group 1 的亞型，與 Iloprost 原本的適應症本質上相同。機轉上高度合理，也因此這比較接近「適應症範圍內的亞群」，而非真正跨疾病的再利用。

其他預測的合理性較低：毛髮稀少症屬於遺傳性毛髮疾患，沒有明確機轉可由前列環素類似物矯正；肺動靜脈畸形為結構性分流，血管擴張理論上可能加重右向左分流與低血氧。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（來自知識圖譜關聯，非仿單文字）：肝衰竭、慢性阻塞性肺病（含重度早發型）、低血壓疾患、肺水腫、支氣管疾病。
- **藥物交互作用**：共查得 100 筆，以下為部分中度交互作用：
  - 腎上腺素 (Epinephrine)、麻黃素 (Ephedrine)
  - 乙醯水楊酸 (Acetylsalicylic acid)
  - SGLT2 抑制劑：Canagliflozin、Dapagliflozin、Empagliflozin、Ertugliflozin
  - 吸入型胰島素、甘露醇、甘油、罌粟鹼 (Papaverine)
  - Fenfluramine、Dexfenfluramine、Sibutramine
- 其他尚未分級的交互作用包括 Calcitriol、Pantoprazole、Morphine、Metformin、Omeprazole。

仿單的警語與禁忌資料目前缺乏，詳細安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails（僅限先天性心臟病相關肺動脈高壓）**

**理由：**
- 此亞群與 Iloprost 已核准的 PAH 機轉相同，且有多項世代研究、病例系列及一項先導性安慰劑對照交叉試驗支持，但證據多為非隨機研究，屬 L3。
- 毛髮稀少症、先天性毛髮稀少伴粟丘疹與肺動靜脈畸形均為 L5，建議 Hold；慢性溶血性貧血相關 PAH 目前僅列為研究問題。

**若要推進需要：**
- 取得香港仿單，確認先天性心臟病亞群是否在核准適應症範圍內（目前許可證未載明適應症文字）
- 補齊作用機轉與仿單警語、禁忌資料
- 監測全身性低血壓及分流方向變化，並由肺高壓專科中心監督，兒童使用尤須謹慎
- 針對該亞群進行前瞻性或隨機對照研究，並檢視知識圖譜標示的潛在禁忌（如低血壓、肺水腫、COPD、肝衰竭）
- 針對慢性溶血性貧血相關 PAH 進行 Iloprost 專屬文獻檢索後，再決定是否推進
