# Imatinib：從慢性骨髓性白血病與胃腸道間質瘤到心臟纖維肉瘤

## 一句話總結

Imatinib 是酪胺酸激酶抑制劑，原本用於慢性骨髓性白血病（CML）、胃腸道間質瘤（GIST）、隆突性皮膚纖維肉瘤、肥大細胞增生症及嗜酸性白血球增多症等疾病。
TxGNN 模型預測它可能對**心臟纖維肉瘤 (Heart Fibrosarcoma)** 有效，但目前**無臨床試驗**，僅有 **1 篇**一般性文獻，且與心臟腫瘤無直接關聯，證據相當薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻與已知資訊，Imatinib 抑制 PDGFR 與 KIT。隆突性皮膚纖維肉瘤（DFSP）帶有 COL1A1-PDGFB 融合，會持續活化 PDGFRB 訊號，這是 Imatinib 在該病的作用基礎。

纖維母細胞來源的肉瘤在組織學上相近，因此模型把 Imatinib 與心臟纖維肉瘤連結起來，機轉上是合理但**間接**的推論。

不過，目前沒有任何心臟腫瘤的專屬資料。唯一一篇文獻是藥物簡訊，討論 Imatinib 的新適應症，並非針對心臟腫瘤。因此這個高分預測目前缺乏臨床支持。

## 安全性考量

- **知識圖譜禁忌關聯（非仿單內容）**：包含肝衰竭、肝病、腎病、充血性心衰竭、心臟瓣膜疾病、心包積液、血小板低下、嗜中性白血球低下、顆粒球缺乏症、貧血、肺水腫、腦水腫、糖尿病、活動性消化性潰瘍、低磷血症等。對心臟腫瘤病人尤其需留意心臟相關的關聯。
- **藥物交互作用**：共查得 100 筆，以下為部分主要項目：
  - **嚴重 (Major)**：Eliglustat、Naloxegol
  - **中度 (Moderate)**：Hydrocortisone、Dexamethasone、Clarithromycin、Cimetidine、Pioglitazone、Morphine、Aprepitant、Glimepiride 等

原廠仿單的警語與禁忌資料尚未取得，完整安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 心臟纖維肉瘤沒有任何臨床試驗，唯一的文獻也與該疾病無關，預測僅來自模型與間接機轉推論。
- 仿單安全性資料與詳細作用機轉資料皆有缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌。
- 取得完整的作用機轉資料。
- 搜尋 Imatinib 用於心臟肉瘤的病例報告或病例系列，並確認腫瘤是否有 PDGFR/KIT 活化。
- 評估心臟毒性風險，因為此為心臟原發腫瘤病人，且知識圖譜顯示與心衰竭、心包積液有關。

**補充觀察（其他預測適應症）：**
- 纖維母細胞腫瘤（fibroblastic neoplasm）的文獻幾乎都在討論 DFSP，而 DFSP 已是 Imatinib 的既有適應症，因此並非新的再利用機會。
- 液化脂肪肉瘤（liposarcoma）有 3 個已完成的 Phase 1/2 與 Phase 2 軟組織肉瘤試驗，但機轉上不甚契合，也沒有脂肪肉瘤專屬的結果。
- 家族性地中海熱、卵巢黏液樣脂肪肉瘤、家族性橫紋肌樣瘤等預測則完全沒有證據支持。
