# Imidapril：從 ACE 抑制劑（降血壓）到肺高壓

## 一句話總結

Imidapril 是一種 ACE 抑制劑前驅藥（活性代謝物為 imidaprilat），香港許可證未載明核准適應症，其藥理分類一般用於降血壓。
TxGNN 模型預測它可能對**肺高壓（成因不明的多因子機轉，Pulmonary Hypertension）**有效，預測分數很高。
但目前**沒有臨床試驗、也沒有相關文獻**支持，證據僅有模型預測（L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Imidapril 是 ACE 抑制劑類前驅藥，透過活性代謝物 imidaprilat 抑制腎素-血管張力素系統（RAAS）。RAAS 活化可能參與肺血管重塑，這是預測在機轉上唯一的線索。

不過，ACE 抑制劑在肺高壓治療上尚未證實有明確療效，因此這個預測的說服力有限。目前支持它的只有 TxGNN 分數，沒有任何試驗或文獻直接佐證，較像知識圖譜的關聯推論。

同一模型還預測了另外四個適應症：

- 肺高壓（肺疾病或缺氧所致）
- 惡性高血壓性腎病
- 惡性腎血管性高血壓
- Braddock 症候群

其中兩個惡性高血壓相關預測，與 ACE 抑制劑降血壓、減輕血管張力素 II 造成的腎血管傷害在機轉上較吻合，是五個預測中生物學上最合理的。Braddock 症候群則查不到與 ACE 抑制的機轉關聯，高分可能只是知識圖譜的關聯假象。

## 安全性考量

安全性資訊請參考原廠仿單。DDI 查詢未找到資料。

從機轉來看，ACE 抑制劑本身需留意：

- 高血鉀與急性腎損傷風險。
- 雙側腎動脈狹窄或單一腎臟患者，腎功能可能惡化，若用於腎血管性高血壓，需由專科評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 五個預測都只有模型分數（證據等級 L5、決策階段 S0），沒有臨床試驗與相關文獻。
- 機轉資料與香港仿單的警語與禁忌症資料也都缺漏，無法進入安全性篩選。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料。
- 下載並解析衛生署仿單，取得警語與禁忌症，這是進入安全性篩選的前提。
- 針對 ACE 抑制劑與肺高壓、惡性/腎血管性高血壓，重新檢索有針對性的文獻與試驗（以 imidapril 或 ACE inhibitor 搭配疾病名稱，而非單以「hypoxia」比對）。
- 優先評估惡性高血壓性腎病與腎血管性高血壓兩個較合理的方向，並由專科審視腎功能風險。
- 確認各預測適應症的給藥途徑相容性。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。
