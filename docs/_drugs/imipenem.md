## Imipenem: 瀰漫性硬皮症 (diffuse scleroderma)
{: .text-alpha }

## 一句話總結

Imipenem 是碳青黴烯類（carbapenem）β-內醯胺抗生素，透過抑制細菌細胞壁合成發揮抗菌作用。
TxGNN 模型預測它可能對**瀰漫性硬皮症 (diffuse scleroderma)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Imipenem 為碳青黴烯類抗生素，其作用是抑制細菌細胞壁合成，主要針對細菌感染。

瀰漫性硬皮症是一種自體免疫性纖維化疾病，沒有已知的細菌性致病因子。Imipenem 的抗菌機轉與此疾病的病理過程之間，看不出合理的機轉關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 本預測沒有任何臨床試驗或文獻支持，證據等級為 L5，且在機轉上缺乏合理關聯，高分很可能是模型假象。
- Imipenem 為抗菌藥物，與自體免疫性纖維化疾病之間沒有已知的藥理連結。

**若要推進需要：**
- 提出可驗證的機轉假說，說明抗菌作用或其他藥理作用如何影響硬皮症病理。
- 進行前臨床研究或機轉研究，作為任何臨床探索的前提。
- 補充作用機轉與仿單安全性資料。
