# Imipramine：從三環抗憂鬱劑到注意力不足過動症

## 一句話總結

Imipramine 是三環抗憂鬱劑，香港目前有 3 張許可證，但許可證資料未載明核准適應症。
TxGNN 模型預測它可能對**注意力不足過動症 (Attention Deficit-Hyperactivity Disorder, ADHD)** 有效。
目前有 **1 個臨床試驗**（但並未測試 Imipramine）和 **20 篇文獻**，其中多為綜述與間接研究，尚無已確認的 Imipramine 專屬 RCT。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Imipramine 是三環抗憂鬱劑（TCA），一般認為它抑制正腎上腺素與血清素的再攝取，這一點是依藥物類別推斷，並非來自資料庫內容。

ADHD 的藥物治療以刺激劑為主，但文獻指出非選擇性正腎上腺素再攝取抑制劑（如 desipramine、imipramine）也可能有效（PMID 17078784）。因此從正腎上腺素路徑來看，這個預測在機轉上說得通，TCA 也長期被討論為 ADHD 的次線選項。

不過，0.999 的高分只是模型預測。現有文獻多為一般性綜述，僅有少數研究直接以 Imipramine 治療 ADHD 兒童（例如對刺激劑無反應者的 EEG 研究）。這些研究的療效結論仍需查閱全文確認。

## 結論與下一步

**決策：Hold**

**理由：**
- 模型分數高，機轉上有合理推論，但證據僅到 L4。沒有已確認的 Imipramine 專屬 RCT，唯一的臨床試驗也與 Imipramine 無關。
- 香港仿單的警語與禁忌症資料缺口屬於阻擋性問題（Blocking），目前無法進行安全性篩選。
- 其他預測適應症中，強迫症（OCD）有較直接的 Imipramine 研究（如 PMID 3887445、3615688），但療效方向需查閱全文；其餘候選幾乎沒有支持證據，同樣列為 Hold。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症
- 從 DrugBank 補充作用機轉（MOA）資料
- 閱讀 PMID 9465283、18304665 等 Imipramine 用於 ADHD 的研究全文，確認療效與安全性結論
- 系統性搜尋 Imipramine 用於 ADHD 的 RCT 與統合分析
- 評估兒童族群的心血管與自殺風險等安全性議題
