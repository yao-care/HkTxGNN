# 胰島素 Glargine (Insulin Glargine)：從糖尿病血糖控制到自體免疫性卵巢炎

## 一句話總結

Insulin glargine 是長效基礎胰島素類似物，臨床上用於糖尿病的血糖控制（香港許可證資料未載明適應症文字）。
TxGNN 模型預測它可能對**自體免疫性卵巢炎 (Autoimmune Oophoritis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Insulin glargine 是作用於胰島素受體的基礎胰島素類似物，沒有已知的免疫調節作用，也沒有直接機轉可以連到卵巢的自體免疫。

模型給出高分，較可能是知識圖譜中的間接關聯。自體免疫性卵巢炎常與第 1 型糖尿病、自體免疫多內分泌症候群等自體免疫內分泌疾病共病，圖譜可能因此把兩者連在一起。這種關聯反映的是共病，不代表藥物能治療卵巢的自體免疫反應。原適應症與機轉資料也缺漏，無法拿標示用途來交叉驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 這是純模型預測（L5），沒有臨床試驗、文獻，也沒有直接的作用機轉。高分較可能來自糖尿病與自體免疫疾病的共病關聯，並非藥物對卵巢自體免疫有療效。
- 香港仿單的警語與禁忌資料缺漏，無法進行安全性初篩。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌、核准適應症），補齊安全性資料。
- 補充 insulin glargine 的作用機轉（DrugBank）與原適應症資料。
- 系統性檢索 PubMed 與臨床試驗登記，確認是否有自體免疫性卵巢炎與胰島素的相關研究。
- 釐清知識圖譜中的關聯路徑，確認是否僅為糖尿病共病所致。若是，應排除為非真正的老藥新用候選。
- 若仍要探討，需先做前臨床機轉驗證，再評估臨床可行性。

*本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。*
