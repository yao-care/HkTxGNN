# 人類胰島素 (Insulin Human)：從糖尿病到自體免疫性卵巢炎

## 一句話總結

人類胰島素 (Insulin Human) 是常見的血糖控制藥物，在香港有 18 張許可證。
TxGNN 模型預測它可能對**自體免疫性卵巢炎 (Autoimmune Oophoritis)** 有效。
目前**沒有臨床試驗和文獻**支持，僅有模型預測，證據等級為 L5。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。人類胰島素是胰島素類藥物，在血糖控制上的療效已被廣泛使用，但本次提供的資料沒有記錄其 MOA，因此無法評估機轉層面的關聯。

模型給出的高分是圖譜式預測。可能的推測是，卵巢自體免疫常與其他自體免疫內分泌疾病並存，因此在知識圖譜中與胰島素相關疾病靠近。但沒有任何證據顯示胰島素能治療自體免疫性卵巢炎，這個連結目前只是推測。

其他預測適應症的狀況也類似：

- **典型僵人症候群、局部僵硬肢症候群**：與第一型糖尿病共有抗 GAD 自體免疫，只是共同的自體抗原，不代表胰島素有療效。
- **硫胺素反應性功能障礙症候群**：糖尿病是其臨床表現之一，胰島素頂多處理併發的高血糖，既定的機轉性治療是補充硫胺素。
- **Opsismodysplasia**：INPPL1 (SHIP2) 功能喪失突變已會增強胰島素／PI3K 訊號，外源性胰島素沒有明確的治療理由。

## 結論與下一步

**決策：Hold**

**理由：**
自體免疫性卵巢炎沒有任何臨床試驗或文獻支持，證據等級為 L5，機轉上也找不到胰島素的治療依據。高 TxGNN 分數不足以推進。

**若要推進需要：**
- 補齊人類胰島素的作用機轉 (MOA) 資料（DrugBank）
- 取得香港衛生署的仿單警語與禁忌資料，這是進入安全性篩選的阻擋項目
- 針對胰島素與卵巢自體免疫的關聯做系統性文獻搜尋，確認是否有任何直接或間接證據
- 若後續發現有意義的證據，再評估給藥途徑與目標族群的相容性
