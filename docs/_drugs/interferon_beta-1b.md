# Interferon beta-1b：從多發性硬化症到毛細胞白血病

## 一句話總結

Interferon beta-1b（香港商品名 Betaferon）在證據包中沒有登記原適應症，但相關臨床試驗與文獻皆指向多發性硬化症（MS）。
TxGNN 模型預測它可能對**毛細胞白血病 (Hairy Cell Leukemia)** 有效。
目前**沒有臨床試驗**，有 **4 篇 1987–1990 年的早期文獻**（皆為小型研究或回顧性經驗），證據偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Interferon beta-1b 屬於第一型干擾素（Type I interferon），根據已知類別資訊，它與 interferon alpha 共用 IFNAR 受體，對 B 細胞惡性腫瘤具有抗增生與免疫調節作用，機轉上可能適用於毛細胞白血病。

Interferon alpha 在毛細胞白血病有明確的歷史用藥地位，因此 interferon beta 存在「類別效應」的合理推論。這與 TxGNN 的高分預測一致。1980 年代末的早期研究也確實在少數病人身上觀察到血球數值改善。

不過這只是類別層級的推論，缺乏 interferon beta-1b 本身的機轉資料。另外，早期研究使用的劑量是每次 90 百萬單位（MU），遠高於香港許可證產品的 8 MIU 規格。

## 結論與下一步

**決策：Hold**

**理由：**
- 毛細胞白血病的證據只有 1980 年代末的小型研究與回顧性經驗，沒有臨床試驗登記，也缺乏藥物專屬的機轉與安全性資料。
- 早期研究的劑量（90 MU）與香港許可證規格（8 MIU）差距很大，且缺乏與現行治療的比較，目前不建議推進。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症，這是進入安全性篩選的前提
- 從 DrugBank 補齊作用機轉（MOA）資料
- 釐清早期研究劑量與現有規格的差異，並評估與現行標準治療比較的可行性
- 搜尋 1990 年代以後的證據，確認 interferon beta 在毛細胞白血病是否已被取代

**補充：** 同一份證據包中的第二個預測適應症「中樞神經自體免疫疾病」（實際證據為多發性硬化症），有 Phase 3 延伸試驗（NCT00185211）、BENEFIT 長期追蹤（NCT01795872）等多項 Phase 2–4 試驗及系統性回顧支持，證據等級為 L1，建議為 Proceed with Guardrails。這部分也屬於既有適應症的範疇，若以老藥新用價值優先，應另案評估。
