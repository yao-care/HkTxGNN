# Iodixanol：從碘化顯影劑到退化性關節炎易感性

## 一句話總結

Iodixanol 是等滲透壓的碘化放射顯影劑，用於影像診斷，並非治療用藥。
TxGNN 模型預測它可能對**退化性關節炎易感性 (Osteoarthritis Susceptibility)** 有效，但**目前沒有臨床試驗或文獻**支持，只有模型預測。
相關文獻都把它當作關節軟骨的 CT 影像探針，屬於診斷用途，不是治療證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Iodixanol 是等滲透壓的碘化顯影劑，主要功能是提高 X 光與 CT 的影像對比。它本身沒有已知的疾病修飾藥理作用。

TxGNN 的高分（99.16%）來自知識圖譜的關聯推論，並非來自實際的藥理或臨床發現。證據包中沒有找到任何機轉上的連結，因此這項預測目前**缺乏合理性支持**。

值得留意的是，Iodixanol 常被用來研究關節軟骨的溶質傳輸與擴散，可能因此在圖譜中與關節炎相關節點連結。這是診斷研究工具的用法，不代表治療效果。

## 安全性考量

安全性資訊請參考原廠仿單。

文獻中有一項間接的安全性訊號：傳統上高滲透壓碘顯影劑在鐮刀型貧血患者中可能引發紅血球脫水，PMID 11754395 以體外方式比較了包含 Visipaque 在內的顯影劑，但只是體外資料，不足以作為臨床建議。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數支持，沒有臨床試驗，也沒有治療性文獻（L5）。現有文獻都是把 Iodixanol 當作診斷影像探針，看不到治療機轉。
- 原始機轉資料缺失，香港仿單的警語與禁忌資料也未取得，無法進入安全性篩選。

**若要推進需要：**
- 從 DrugBank 補齊作用機轉（MOA）。
- 下載並解析衛生署（Department of Health）的仿單，取得警語與禁忌。
- 找出任何 Iodixanol 具治療效果的前臨床或臨床證據；否則建議停止對此藥物進行治療性重新定位。
- 若目標是關節影像診斷，應改以「診斷用途拓展」評估，不要套用治療性老藥新用的流程。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。*
