# Iodixanol：從放射診斷造影到退化性關節炎（骨關節炎）

## 一句話總結

Iodixanol 是一種碘化、非離子型、等滲透壓的放射造影劑，用於影像診斷。
TxGNN 模型預測它可能對**骨關節炎易感性 (Osteoarthritis Susceptibility)** 有關，但這只是模型的運算結果。
目前**沒有任何臨床試驗**，相關文獻也僅涉及診斷影像或實驗用途，並無治療效果的證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Iodixanol 是碘化、非離子型、等滲透壓的放射造影劑，其作用是增加 X 光與 CT 影像的對比，並無已知的藥理活性可影響骨關節炎的遺傳易感性。

TxGNN 給出的高分（99.16%）應視為純粹的運算預測，可能來自知識圖譜中的網路鄰近性，而非真實的生物學關聯。排名第一的預測並無任何臨床試驗或文獻支持。

排名第二的「骨關節炎」雖有 5 篇文獻，但內容都是將 iodixanol 當作造影或實驗工具，用於觀察軟骨結構與溶質傳輸，並非治療用途。因此，這些文獻無法支持其治療效果。

## 安全性考量

- **藥物交互作用**：已查詢到 100 筆交互作用紀錄，主要項目包括：
  - 重大 (Major)：Metformin、Amphotericin B（含脂質複合體、膽固醇硫酸酯及脂質體劑型）、Mesalazine、Balsalazide、Olsalazine、Sulfasalazine、Vancomycin、Kanamycin、Neomycin、Streptomycin、Polymyxin B
  - 中等 (Moderate)：Mannitol

多數重大交互作用涉及腎毒性藥物或雙胍類藥物，使用造影劑時應特別留意腎功能。

警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測缺乏任何機轉依據、臨床試驗或治療性文獻，僅屬運算結果。Iodixanol 是診斷用造影劑，與骨關節炎的遺傳易感性沒有已知的藥理關聯。
- 其他排名前十的預測（如血紅素病變、多種罕見骨骼發育不良）同樣為 L5，且無任何支持證據。

**若要推進需要：**
- 補充作用機轉資料，並釐清模型預測的生物學依據
- 取得香港原廠仿單，確認警語、禁忌症與核准適應症
- 若要探討治療用途，需有前臨床研究（如關節腔內給藥的療效與安全性）
- 評估給藥途徑的可行性，因目前的注射造影劑劑型是否適合關節內治療尚未評估
