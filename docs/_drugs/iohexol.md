# Iohexol：從 X 光顯影劑到失眠

## 一句話總結

Iohexol 是非離子型含碘 X 光顯影劑，用於放射診斷造影，本身沒有治療作用。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向。
這個高分很可能是知識圖譜的假象，不是真正的藥理訊號。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Iohexol 是非離子型含碘顯影劑，在藥理上幾乎是惰性的，主要作用是在影像檢查中提供對比。它沒有已知的中樞神經或睡眠調節活性。

原適應症（診斷造影）和失眠之間沒有藥理上的關聯，機轉上也找不到合理的作用途徑。因此，我們判斷這個預測**缺乏合理性**。99.87% 的分數較可能來自知識圖譜中的間接關聯，例如 Iohexol 常被用作腎功能（GFR）檢測探針，並非睡眠相關的治療證據。

同一份預測清單中的其他項目（焦慮、類風濕性關節炎、抗凝血酶缺乏、纖維肌痛等）也有相同問題。檢索到的試驗和文獻都只是把 Iohexol 當作造影或檢測工具，不是評估它的療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 失眠適應症只有模型預測（L5），沒有任何臨床試驗或文獻，也沒有合理的藥理機轉。
- Iohexol 是惰性顯影劑，高分很可能是知識圖譜假象，不建議投入資源。

**若要推進需要：**
- 取得香港衛生署的仿單資料（警語與禁忌症），這是目前的阻斷性資料缺口。
- 補齊 DrugBank 作用機轉資料。
- 出現直接評估 Iohexol 對睡眠有作用的實驗或臨床證據，否則不建議重新評估。
