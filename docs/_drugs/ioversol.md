# Ioversol：從顯影劑到骨關節炎易感性

## 一句話總結

Ioversol 是非離子型含碘放射顯影劑，用於醫學影像檢查（如 CT、血管攝影）的顯影增強，並非治療特定疾病的藥物。TxGNN 模型預測它可能與**骨關節炎易感性 (Osteoarthritis Susceptibility)** 有關聯，但目前**沒有任何臨床試驗或文獻**支持這個方向，證據等級為最低的 L5。

## 為什麼這個預測合理？

目前缺乏 Ioversol 的詳細作用機轉資料。根據評估紀錄，Ioversol 是非離子型碘化放射顯影劑，其藥理作用僅限於 X 光/電腦斷層等影像檢查中的組織對比增強，並無已知能解釋與「骨關節炎易感性」之間關聯的藥理機轉。

需特別說明的是，這裡的預測標的是「骨關節炎**易感性**」（一種遺傳風險傾向），而非骨關節炎疾病本身，這與治療性適應症的性質不同，進一步降低了可解釋性。

根據評估結果，此預測**應視為知識圖譜嵌入相似性的產物，而非生物學假說**——沒有任何臨床試驗或文獻資料可支持顯影劑與此易感性之間存在因果或機轉關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 無作用機轉資料、無臨床試驗、無文獻支持，證據等級僅 L5（純模型預測）
- Ioversol 目前未在香港上市，無許可證資料
- 預測標的為「易感性」而非疾病本身，機轉可解釋性低

**若要推進需要：**
- 取得 Ioversol 完整仿單警語與禁忌症資料（目前為 Blocking 等級資料缺口，無法進入安全性初評）
- 補充 DrugBank 作用機轉 (MOA) 資料
- 尋找針對顯影劑與骨關節炎（或其易感性）關聯性的機轉或轉譯研究，作為後續評估基礎

*註：同一評估中另有 9 個候選適應症（如骨關節炎、類風濕性關節炎、血紅蛋白病等），證據等級介於 L4–L5，均建議 Hold，未發現具臨床開發價值的信號。*
