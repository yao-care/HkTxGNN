# Isoleucine（異白胺酸）：預測用於胃輕癱（原適應症資料未提供）

## 一句話總結

Isoleucine 是一種支鏈胺基酸，在香港以胺基酸輸液與顆粒製劑上市，但資料中沒有原適應症的記載。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，也沒有原適應症資料，TxGNN 的知識圖譜推論路徑同樣未提供，因此這個預測無法驗證。已知 Isoleucine 是支鏈胺基酸，參與蛋白質合成、葡萄糖攝取與胰島素訊號傳遞。

一個推測性的連結是糖尿病性胃輕癱，或代謝與營養支持。但腸腔內的胺基酸會刺激十二指腸營養回饋機制（例如釋放 CCK、GLP-1），這通常會**減慢**胃排空。因此作用方向並不確定，甚至可能不利。以上僅是供審查的假說，資料中沒有任何證據支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，沒有臨床試驗或文獻。
- 機轉推論顯示作用方向不確定，可能減慢胃排空而不利於胃輕癱。
- 香港仿單的警語與禁忌症資料缺漏，屬阻斷性缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌症、核准適應症），補齊安全性資料。
- 從 DrugBank 補充作用機轉（MOA）與原適應症。
- 取得 TxGNN 預測的知識圖譜路徑，確認預測依據。
- 文獻回顧胺基酸對胃排空的影響，特別是支鏈胺基酸與胃輕癱患者的關聯。
- 若上述評估支持，再檢視劑型與給藥途徑是否適用於胃輕癱。
