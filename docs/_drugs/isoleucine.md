# Isoleucine：從（原適應症未載明）到胃輕癱

## 一句話總結

Isoleucine（異白胺酸）是一種支鏈胺基酸，在香港多用於胺基酸輸液與營養補充製劑，但本次資料未載明具體的核准適應症。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，
但目前**沒有臨床試驗與文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，也沒有記載原適應症。因此無法從已知藥理機轉直接推導出對胃輕癱的作用路徑，這項預測的唯一依據是 TxGNN 知識圖譜給出的高分。

一個尚未被驗證的推測是：支鏈胺基酸可能影響營養感知、腸道荷爾蒙分泌（如 GLP-1、CCK）或腸道平滑肌代謝，進而影響胃的蠕動。但這沒有任何本次資料中的證據支持。

另外需要留意：膳食中的胺基酸與蛋白質本身可能減緩胃排空，因此作用方向不明，甚至可能對胃輕癱患者不利。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅有模型預測（L5），沒有臨床試驗、文獻或機轉資料支持。
- 胺基酸可能減緩胃排空，作用方向不明，且知識圖譜顯示多項腎臟與代謝方面的潛在禁忌。

**若要推進需要：**
- 補齊作用機轉（MOA）與原適應症資料
- 取得香港衛生署仿單，確認警語與禁忌症
- 進行文獻與臨床試驗檢索，確認異白胺酸或支鏈胺基酸對胃排空的影響方向
- 若有前臨床或機轉證據支持，再評估給藥途徑與目標族群（特別是腎功能不全者）
