# Isoniazid：從抗結核治療到結膜炎

## 一句話總結

Isoniazid（異菸鹼醯肼）是抗結核分枝桿菌藥物，香港已有 6 張許可證。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效。
目前有 **1 個臨床試驗**（與結膜炎無直接關聯）和 **20 篇文獻**（多為病例報告，並無療效試驗），證據等級僅 L4。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Isoniazid 是殺菌性抗分枝桿菌藥物，透過抑制 InhA 而阻斷黴菌酸合成。

結膜炎與結核病之間只在少數情況有關聯。例如結核性結膜炎，或與結核感染相關的泡疹性（phlyctenular）角結膜炎，這類病灶可在治療底層結核感染後改善。對於常見的細菌性、病毒性或過敏性結膜炎，Isoniazid 沒有合理的作用基礎。

TxGNN 的高分（0.994）較可能來自知識圖譜中「結核病」與「眼部疾病」的鄰近關係，而非直接療效。檢索到的文獻中，也有數篇是把結膜炎描述為結核治療或 BCG 暴露的不良反應或伴隨事件，而不是治療目標。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數雖高（99.36%），但唯一的臨床試驗與結膜炎無關，文獻多為結核性眼病的病例報告，或把結膜炎當作不良反應的報告，沒有任何針對結膜炎的療效試驗。
- 合理的作用場景僅限結核性或泡疹性結膜炎這類罕見病因，對一般結膜炎缺乏機轉依據。此外，香港仿單的警語與禁忌資料尚未取得（標記為阻斷性缺口），目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症資料，補上安全性篩選。
- 補齊 Isoniazid 的作用機轉資料（如自 DrugBank 取得）。
- 將預測適應症縮窄為「結核性／泡疹性角結膜炎」，並重新檢索針對該族群的研究。
- 確認眼部使用的給藥途徑是否可行（目前路徑相容性尚未評估）。
- 若有臨床興趣，先進行結核性眼病的系統性文獻回顧，再評估是否值得設計前瞻性研究。
