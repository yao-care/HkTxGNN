# Ivabradine：從心率控制到多毛症

## 一句話總結

Ivabradine 是一種降低心率的藥物，在香港已有 10 張許可證，但許可證資料未載明適應症文字。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，預測分數很高（99.79%）。
不過目前**沒有任何臨床試驗，也沒有直接相關的文獻**，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫的 MOA 欄位為空）。依已知藥理，Ivabradine 選擇性抑制 HCN 通道，也就是心臟的 If 電流，藉此降低心率。

坦白說，這個預測的機轉支持度很弱。HCN 通道抑制與毛囊週期、毛髮生長之間，沒有已知的作用路徑。高分較可能來自知識圖譜的拓撲結構，例如共同的離子通道或基因鄰居，而非生物學證據。多毛症本身也很異質，包含先天型、後天型和藥物誘發型，若要驗證，必須先指定亞型並提出對應機轉。

其他排名前 5 的預測也有相同問題，同樣只有模型分數，機轉上找不到合理的連結：

- 安布拉斯型先天性全身多毛症：這是超罕見的先天疾病，通常與 TRPS1 調控區的基因體重組有關，HCN 阻斷劑不太可能矯正發育期的基因調控缺陷。
- 伴有牙齒或牙周成分的畸形症候群：檢索到的 20 篇文獻（顯示 10 篇）都是一般牙周炎文獻，完全沒有提到 Ivabradine 或 HCN 通道。
- 以 Dandy-Walker 畸形為主要特徵的症候群：這是胚胎期的結構性畸形，沒有已知機轉可與 Ivabradine 連結。
- 孤立性遺傳性毛幹異常：這是毛幹結構缺陷，HCN 抑制在毛幹形成中沒有已知角色。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有模型預測，沒有臨床試驗，也沒有直接支持的文獻。
- 機轉上找不到 HCN 抑制與毛髮生長或發育性畸形的合理連結，高分很可能是知識圖譜的假象。

**若要推進需要：**
- 補齊 MOA 資料（DrugBank），並檢視 HCN 通道在毛囊生物學中是否有任何表現或功能證據。
- 取得香港衛生署仿單的警語與禁忌症，完成安全性初篩。
- 針對「Ivabradine + 多毛症」進行專屬文獻檢索，包括藥物誘發多毛症的案例通報，確認是否有直接證據。
- 明確界定多毛症的目標亞型，再重新評估機轉可行性。
