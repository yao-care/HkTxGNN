# Ivabradine：從心衰竭／穩定型心絞痛到多毛症

## 一句話總結

Ivabradine 是一種 HCN 通道（If 電流）抑制劑，原本用於心衰竭與穩定型心絞痛的治療。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，且藥理機轉上找不到合理連結。

## 為什麼這個預測合理？

Ivabradine 是竇房結 HCN 通道（If 電流）的選擇性抑制劑，透過減緩心跳速率發揮療效，臨床用於心衰竭與穩定型心絞痛。詳細的正式作用機轉（MOA）資料目前缺失，僅能依證據包中敘述性資訊判斷其藥理類別。

就本次排名第一的預測——多毛症而言，證據包本身即明確指出：**HCN 通道抑制與毛髮生長調控之間沒有已知的生物學關聯**。TxGNN 給出的高分（99.79%）屬於知識圖譜 embedding 的推測性關聯，並非源自藥理機轉的可解釋路徑，也沒有任何臨床試驗或文獻佐證。

其餘 4 個預測適應症（Ambras 型先天性全身多毛症、牙周相關畸形症候群、Dandy-Walker 相關症候群、遺傳性毛幹結構異常）同樣缺乏機轉基礎——其中「牙周相關畸形症候群」雖檢索到 20 篇文獻，但經審視皆為牙周病一般病理生理綜述，未提及 ivabradine 或 HCN 通道，僅因疾病關鍵字匹配被收錄，不構成真實藥物-疾病證據。整體而言，本輪 TxGNN 預測批次的機轉可信度偏低。

## 結論與下一步

**決策：Hold**

**理由：**
排名第一的預測適應症（多毛症）評為 L5——僅有模型分數，無任何臨床試驗、文獻或機轉支持；其餘候選適應症同樣缺乏實證，且證據包本身已明確標註機轉上無合理連結。此外藥物在香港未上市、無許可證資料，也缺乏 MOA 與仿單安全性資訊，尚不具備進入安全性初評（S1）的條件。

**若要推進需要：**
- 補齊 TFDA／香港衛生署仿單警語與禁忌症資料（DG001，屬 Blocking 缺口）
- 補齊 DrugBank 作用機轉資料以支持機轉關聯性分析（DG002）
- 針對多毛症及其他候選適應症，尋找是否有 ivabradine 相關的體外/動物實驗或個案報告作為機轉佐證
- 若持續無實證支持，建議將本輪候選適應症降低優先序，暫不投入後續資源
