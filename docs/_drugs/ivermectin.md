# Ivermectin：從抗寄生蟲感染到外陰陰道念珠菌病（預測）

## 一句話總結

Ivermectin 是 avermectin 類抗寄生蟲藥物，作用於無脊椎動物的麩胺酸閘控氯離子通道，臨床上用於治療疥瘡、糞線蟲病等寄生蟲感染（本證據包未提供正式核准適應症清單）。
TxGNN 模型預測其可能對**外陰陰道念珠菌病 (Vulvovaginal Candidiasis)** 有效，
但目前**沒有任何臨床試驗**、也**沒有相關文獻**支持這個方向，屬於純模型預測。

## 為什麼這個預測合理？

Ivermectin 是 avermectin 類抗寄生蟲藥，主要透過結合無脊椎動物的麩胺酸閘控氯離子通道，
造成寄生蟲神經肌肉麻痺而死亡。這個機轉是抗寄生蟲/抗蠕蟲專一的，**目前沒有任何已知的抗真菌（抗 Candida）活性資料**。

外陰陰道念珠菌病是由 *Candida* 屬真菌引起的感染，治療上依賴 azole 類等抗真菌藥物，
與 ivermectin 的作用標的完全不同。TxGNN 給出的高分（99.95%）較可能反映知識圖譜上「感染」「發炎」相關節點的間接關聯，而非真正的生物學機轉支持。

目前缺乏詳細的作用機轉資料（MOA 為 Data Gap），本節內容僅根據證據包中各候選適應症的 `mechanistic_link` 描述整理而成，並非正式藥理學文獻確認。

## 結論與下一步

**決策：Hold**

**理由：**
本次證據包中 10 個 TxGNN 預測適應症全數為 L5（僅模型預測），無任何臨床試驗或直接文獻支持，
機轉上也缺乏抗真菌/抗病毒活性佐證。同時安全性核心資料（仿單警語、禁忌症、DDI）與作用機轉均為缺失狀態，
其中仿單警語缺口屬 Blocking 等級，無法進入下一階段安全性初評。

**若要推進需要：**
- 補齊 TFDA 仿單警語與禁忌症資料（DG001，Blocking）
- 補齊 Ivermectin 詳細作用機轉資料（DG002，High）
- 尋找具生物學合理性的體外/動物實驗數據，建立抗真菌或抗病毒機轉基礎
- 若持續無法建立機轉支持，建議終止此系列預測適應症的探索
