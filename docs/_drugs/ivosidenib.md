# Ivosidenib：從急性骨髓性白血病到 bulbar polio（延髓型小兒麻痺）

## 一句話總結

Ivosidenib 是一種口服藥物，原本用於急性骨髓性白血病（AML）及相關骨髓性腫瘤的治療。
TxGNN 模型對 **bulbar polio（延髓型小兒麻痺）** 給出高預測分數，但目前**沒有任何臨床試驗或文獻**支持，且機轉上找不到合理的關聯，應視為模型的預測假象。
排名較後但生物學上較合理的方向，是**烷化劑或放射線相關的 AML／骨髓增生異常症候群**，這兩者其實屬於原適應症的亞型。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫中的 MOA 欄位為空）。不過，Ivosidenib 已知是**突變型 IDH1（異檸檬酸脫氫酶 1）抑制劑**，能降低 IDH1 突變癌症中的致癌代謝物 2-羥基戊二酸（2-HG），進而促進白血病母細胞分化。

**Bulbar polio 這個預測缺乏合理性。** 它是由脊髓灰質炎病毒感染運動神經元所造成的急性病毒性神經疾病，不涉及 IDH1 突變或相關代謝路徑。0.993 的高分較可能是知識圖譜推論的假象，且沒有任何臨床試驗或文獻佐證。

**較合理的方向是排名第 2、第 3 的預測：**
- **烷化劑相關的 AML／MDS**（分數 99.26%）
- **放射線相關的 AML／MDS**（分數 99.26%）

這兩者都屬於治療相關的骨髓性腫瘤，與原適應症清單中的「治療相關 AML 與 MDS」高度重疊。若腫瘤帶有 IDH1 突變，Ivosidenib 促進骨髓分化的機轉理論上適用。這比較像是原適應症的子集，而非真正的藥物再利用。目前也沒有直接證據支持這兩個亞型，只能由相近的已核准適應症間接推論。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第 1 的 bulbar polio 預測沒有任何臨床試驗或文獻，機轉上也沒有關聯，僅有模型預測（L5），不建議推進。
- 烷化劑與放射線相關的 AML／MDS 生物學上合理（L4），但本質上屬於原適應症的子集，並非新的再利用機會，且缺乏直接證據。

**若要推進需要：**
- 取得香港仿單的警語與禁忌症，完成安全性篩選（目前為阻斷性資料缺口）。
- 補充 DrugBank 的作用機轉資料。
- 若關注治療相關 AML／MDS，需蒐集 IDH1 突變患者在這些病因下的臨床證據，並確認是否已涵蓋於現有核准適應症內。
- 取得香港許可證的核准適應症文字，以確認實際上市範圍。
