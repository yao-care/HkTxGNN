# Ivosidenib：從 IDH1 突變型 AML 到治療相關 AML/MDS 亞型

## 一句話總結

Ivosidenib（DrugBank DB14568）是 IDH1 突變抑制劑，原核准用於帶有 IDH1 突變的急性骨髓性白血病（AML）。
TxGNN 模型針對此藥物產出 3 個預測適應症，其中排名第 1 的「Bulbar polio」經機轉分析後判定為**知識圖譜偽陽性**，
真正具機轉合理性的是排名第 2、3 的**治療相關 AML/MDS 亞型**（alkylating agent 誘發、放射線誘發），
但這兩者目前皆**無任何臨床試驗或文獻佐證**，證據等級僅為 L4（機轉推論）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA 為 [Data Gap]）。但根據 evidence pack 內 `repurposing_rationale` 提供的資訊，Ivosidenib 是 IDH1（異檸檬酸去氫酶）突變抑制劑，已核准用於 IDH1 突變之 AML（含復發/難治性及新診斷不適合強化療者）。

排名第 2、3 的預測——「alkylating agent 相關」與「放射線相關」的 AML/MDS——屬於 AML/MDS 大分類下依病因區分的亞型。若病灶帶有 IDH1 突變，機轉上與原核准適應症一致，差異只在於病因是「治療/暴露相關」而非新的疾病靶點，因此這是適應症邊界的延伸，而非全新機轉假說。不過，目前尚無資料確認這兩個亞型族群中 IDH1 突變盛行率是否與原核准族群相當。

**排名第 1「Bulbar polio」則不具機轉合理性**：此病為脊髓灰質炎病毒感染延腦運動神經元所致之急性神經肌肉麻痺，與 IDH1 代謝突變或 ivosidenib 的抗腫瘤/表觀遺傳機轉無已知路徑重疊。儘管 TxGNN 分數高達 99.31%，evidence pack 明確將其標註為知識圖譜嵌入空間中的偽陽性（node embedding artifact），不應視為真實生物學訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第 1 的預測（Bulbar polio）已被機轉分析判定為模型偽陽性，不具生物學意義；
- 機轉上合理的候選（治療相關 AML/MDS 亞型）完全無臨床試驗或文獻支持，證據等級僅 L4；
- 仿單警語/禁忌資料缺口為 Blocking 等級，無法完成 S1 安全性初評；
- 該藥物於香港尚未上市（0 張許可證）。

**若要推進需要：**
- 向 TFDA／香港藥監機構取得仿單警語與禁忌症資料，解除 Blocking 資料缺口
- 補齊完整 MOA 資料，強化機轉關聯分析
- 針對治療相關 AML/MDS 亞型，確認該族群 IDH1 突變盛行率，並設計探索性研究
- 「Bulbar polio」預測應予排除，不建議投入後續資源
