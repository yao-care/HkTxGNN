# Ivosidenib：從 IDH1 突變血液／膽道腫瘤到延髓型小兒麻痺（bulbar polio）

## 一句話總結

Ivosidenib 是突變型 IDH1 抑制劑，原本用於 IDH1 突變的骨髓性血液腫瘤與膽道癌。
TxGNN 排名第一的預測是**延髓型小兒麻痺 (bulbar polio)**，分數很高，但機轉上找不到合理關聯，**沒有任何臨床試驗或文獻**支持，較可能是知識圖譜的假象。
排名第二、三的預測是治療相關（烷化劑、放射線）的 AML/MDS，生物學上合理，但同樣沒有直接證據。

## 為什麼這個預測合理？

**排名 1：延髓型小兒麻痺，機轉上不合理。** Ivosidenib 抑制突變型 IDH1，降低 2-羥基戊二酸 (2-HG)，解除骨髓細胞的分化阻斷。小兒麻痺是病毒感染運動神經元，目前已知沒有任何 IDH1 相關路徑參與。0.993 的高分很可能反映知識圖譜的人為偏差，而非真實生物學。

**排名 2、3：治療相關 AML／MDS，生物學上可信。** IDH1 突變見於一部分 AML 與 MDS，包括續發性與治療相關疾病。Ivosidenib 已核准用於 IDH1 突變的 AML 與 MDS，但這只是間接支持。目前資料沒有針對烷化劑或放射線相關疾病的試驗或文獻，療效取決於 IDH1 突變狀態，而非治療相關的病因。

這兩個項目的 TxGNN 分數完全相同，很可能是同一個圖譜訊號重複出現，不能算兩份獨立證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的預測（延髓型小兒麻痺）沒有機轉關聯，也沒有任何試驗或文獻，不建議推進。
- 排名二、三的治療相關 AML／MDS 有間接的生物學合理性，可列為研究問題，但目前沒有直接證據。

**若要推進需要：**
- 在現有 ivosidenib 試驗中，針對 IDH1 突變的治療相關 AML／MDS 亞群做定向搜尋。
- 取得該族群的 IDH1 突變頻率資料。
- 取得香港衛生署核准仿單，補齊適應症、警語與禁忌症。
- 補充 DrugBank 的作用機轉資料，並核對原適應症。
- 進入安全性篩選前，先解決仿單缺漏這個阻斷性資料缺口。
