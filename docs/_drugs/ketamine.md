# Ketamine：從麻醉/止痛用藥到頭痛障礙的老藥新用評估

## 一句話總結

Ketamine（氯胺酮）為 NMDA 受體拮抗劑類藥物，目前在本證據包中缺乏正式登記的原始適應症與許可證資料。TxGNN 模型預測它可能對**頭痛障礙 (Headache Disorder)** 有效，目前資料庫中有 **39 個相關臨床試驗**與 **19 篇文獻**，但其中直接針對頭痛適應症、且證據強度較高的僅為少數，多數文獻其實聚焦於 Ketamine/Esketamine 於難治型憂鬱症的應用。

## 為什麼這個預測合理？

結構化的 MOA 欄位標記為資料缺失，但證據包中的機轉推論指出：Ketamine 為 NMDA 受體拮抗劑，其訊號路徑涉及中樞敏感化（central sensitization）與皮質擴散抑制（cortical spreading depression）——這兩者正是慢性頭痛、偏頭痛慢性化與叢集性頭痛病理生理學中已知的關鍵機轉，具有一定的生物學合理性。

值得注意的是，這個「老藥新用」方向並非純理論推測：現有證據顯示 Ketamine 已在頭痛的臨床實務中被小範圍使用，包括一篇針對頭痛障礙住院病人的回溯性世代研究，以及多個急診頭痛情境的隨機對照試驗（比較 Ketamine 與 Ketorolac、Compazine 等標準止痛藥）。

不過整體證據仍偏薄弱：多數試驗樣本數極小（5～90 人），部分試驗狀態為「不明」（UNKNOWN），代表結果可能未正式發表；且原始適應症、MOA、安全性資料在本證據包中均缺失，限制了嚴謹度評估。

## 安全性考量

安全性資訊請參考原廠仿單。（注意：本證據包標記 TFDA 仿單警語/禁忌症為 Blocking 等級資料缺口，尚無法完成 S1 安全性初評。）

## 結論與下一步

**決策：Hold**

**理由：**
- 已有多個 Phase 3/4 試驗（含 2 個已完成）顯示 Ketamine 於頭痛相關情境的潛在療效，且已有回溯性世代研究支持其臨床實務使用，證據等級達 L3；但仿單警語/禁忌症資料缺口為 Blocking 等級，無法進入 S1 安全性初評，且本地未上市、無許可證資料，暫不建議推進。

**若要推進需要：**
- 補齊 TFDA/仿單安全性資料（警語、禁忌症）— DG001，Blocking
- 補齊完整作用機轉（MOA）資料 — DG002，High
- 因 Ketamine 屬管制藥品，需額外評估法規歸類與濫用風險管控機制
- 追蹤已完成之關鍵 Phase 3/4 RCT（NCT03081416、NCT02657031、NCT04860713）正式發表結果，以確認療效證據強度
