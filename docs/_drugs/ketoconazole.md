# Ketoconazole：從抗黴菌用藥到痤瘡

## 一句話總結

Ketoconazole 是唑類（azole）抗黴菌藥，香港有多張外用製劑許可證。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，
目前有 **1 個臨床試驗**（Phase NA、52 人、進行中）和 **14 篇文獻**，其中多數為間接證據。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。以下分析依據一般藥理知識，而非提供的資料紀錄。Ketoconazole 是唑類抗黴菌藥，可抑制馬拉色菌（Malassezia／Pityrosporum）。這類酵母菌與毛囊發炎及痤瘡樣膿疱疹有關。

它還有兩項可能相關的作用：
- **抗痤瘡桿菌**：體外研究顯示，ketoconazole 能抑制痤瘡桿菌（*P. acnes*）的生長與脂肪酶活性，而該脂肪酶會分解皮脂並引發皮膚發炎。
- **抗雄性素**：全身性使用時，它會抑制類固醇合成相關的 CYP 酶（CYP17A1、CYP11A1），降低雄性素合成，可能對多囊卵巢症候群（PCOS）等高雄性素型痤瘡有意義。

**給藥途徑**是關鍵。抗雄性素機轉只適用於全身性給藥，而全身性給藥有肝毒性與腎上腺抑制風險，且有法規限制。抗黴菌與抗發炎機轉則適用於外用，安全性好得多。

99.80% 的分數只是知識圖譜的預測，不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有 1 個小型、無結果的 Phase NA 試驗，加上體外與間接文獻，證據停留在 L4，尚無臨床療效證據。
- 香港藥品仿單的警語與禁忌資料尚未取得，這項缺口列為阻礙性，因此暫不進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌症、交互作用），完成安全性篩選。
- 追蹤 NCT07237763 的結果，確認外用 2% ketoconazole 對痤瘡的療效。
- 釐清目標給藥途徑：外用與全身性的風險差異很大，建議優先評估外用。
- 補齊 DrugBank 的作用機轉資料。
- 評估是否需要痤瘡的 RCT，並考慮與標準治療（retinoid、抗生素）比較。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
