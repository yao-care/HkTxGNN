# Labetalol：從高血壓到惡性高血壓腎病變

## 一句話總結

Labetalol 是同時阻斷 α1 與 β 受體的降血壓藥。Evidence Pack 的原適應症欄位為空，這裡是依藥物類別推定。
TxGNN 模型預測它可能對**惡性高血壓腎病變 (Malignant Hypertensive Renal Disease)** 有效。
目前**沒有臨床試驗，也沒有文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據模型推論，Labetalol 兼具 α1 與非選擇性 β 阻斷作用，可降低血管阻力與心率，在嚴重高血壓時降壓的生物學合理性成立。

惡性高血壓腎病變是嚴重高血壓造成的腎臟損傷，控制血壓是處置核心。因此，一個已上市的降壓藥被預測對它有效，在機轉上說得通。

不過要注意兩點：
- 這個預測可能只是「原適應症的延伸」，而非真正的老藥新用。
- 原適應症欄位為空，應回頭核對來源資料。

0.99 的分數只是模型輸出，沒有任何臨床或文獻資料佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 此適應症沒有任何臨床試驗或文獻，僅有模型預測分數，證據等級為 L5。
- 安全性與仿單資料也尚未取得，無法進入安全性篩選。
- 同一藥物的第 2 名預測（惡性腎血管性高血壓）僅有 2 篇個案報告，其中一篇與 Labetalol 無關，另一篇只提到它用於初期控制血壓。這對第 1 名沒有實質加分。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症。
- 補充 DrugBank 的作用機轉資料。
- 核對原適應症欄位為何為空，釐清此預測是否只是原適應症的延伸。
- 針對 Labetalol 用於惡性高血壓或高血壓腎病變，做專門的文獻與試驗檢索。
