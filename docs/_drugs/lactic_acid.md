# Lactic acid（乳酸）：從原適應症未登載到非典型主動脈縮窄

## 一句話總結

Lactic acid（乳酸）在香港有 7 張許可證，但資料中沒有登載原適應症。
TxGNN 模型預測它可能對**非典型主動脈縮窄 (Atypical Coarctation of Aorta)** 有效，預測分數很高（99.59%）。
不過目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，藥物本身也沒有登載原適應症。
這個預測只來自知識圖譜的關聯計算，我們找不到乳酸與主動脈縮窄之間的機轉連結。

先天性心臟血管結構異常屬於發育或結構性疾病。乳酸是一般代謝產物，沒有已知的藥理作用可以矯正這類結構缺陷。
因此高分只代表圖譜上的關聯性，不代表有治療上的合理性，這個預測目前只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗、文獻或機轉支持（L5），不足以推進。
- 藥物的原適應症、作用機轉與仿單安全性資料都缺漏，無法進入安全性篩選。
- 排名靠後的預測，例如乾眼症、眼疾與食道疾病，其文獻多顯示乳酸是致病因子而非治療因子，也提示需要留意安全性。

**若要推進需要：**
- 從香港衛生署取得各許可證的核准適應症與仿單（警語、禁忌）
- 從 DrugBank 補齊作用機轉（MOA）
- 提出乳酸用於主動脈縮窄的合理機轉假說，並先做前臨床研究驗證
- 確認給藥途徑是否可行（目前路徑相容性尚未評估）
