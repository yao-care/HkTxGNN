# Lamivudine：從慢性 B 型肝炎與 HIV 感染到猿猴免疫缺陷病毒感染

## 一句話總結

Lamivudine（拉米夫定）是核苷類逆轉錄酶抑制劑，原本用於慢性 B 型肝炎、HIV 感染與愛滋病治療。
TxGNN 模型預測它可能對**猿猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效，
目前**無臨床試驗**，僅有 **15 篇文獻**（以動物與體外研究為主）支持，且此適應症主要是 HIV 的動物模型，沒有直接的人類臨床意義。

## 為什麼這個預測合理？

Lamivudine 是核苷類逆轉錄酶抑制劑（NRTI），可抑制 HIV-1 與 B 型肝炎病毒的逆轉錄酶。目前缺乏詳細的作用機轉資料，以上為已知的藥物類別特性。

SIV 與 HIV 同屬慢病毒，逆轉錄酶高度同源，因此機轉上可能共通。獼猴的前臨床研究顯示，含 lamivudine 的方案具抗病毒活性，例如四合一抗病毒療法使病毒量快速下降、HAART 抑制病毒量，以及暴露後預防可阻斷陰道 SIV 傳播。SIV 逆轉錄酶上的 M184V 抗藥突變也與 HIV 相似。

需要注意：SIV 主要是 HIV 的動物模型，此預測除了既有的 HIV 適應症外，沒有額外的人類臨床價值。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅有前臨床與體外證據（L4），無臨床試驗。SIV 是 HIV 的動物模型，在人類無獨立的治療價值，而 lamivudine 已核准用於 HIV。
- 其他預測中，神經發展障礙與已淘汰的家族性複合型高脂血症無證據且機轉不明，應視為模型或知識圖譜的假象；慢性 C 型肝炎因 HCV 不使用逆轉錄酶而缺乏機轉基礎，且已有高效的直接作用抗病毒藥物，亦不建議推進。

**若要推進需要：**
- 明確界定此預測的應用目的（如僅作為 HIV 動物模型研究工具，則無需臨床開發）
- 補充詳細的作用機轉資料（MOA）
- 取得香港衛生署的仿單，補齊警語與禁忌資料（目前為阻斷性資料缺口）
- 若考慮其他預測適應症，需先有直接的臨床或機轉證據
