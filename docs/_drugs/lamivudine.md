# Lamivudine：從 HIV-1 與慢性 B 型肝炎到猿猴免疫缺陷病毒感染

## 一句話總結

Lamivudine（3TC）是核苷類逆轉錄酶抑制劑（NRTI），原本用於 HIV-1 感染與慢性 B 型肝炎。
TxGNN 模型預測它可能對**猿猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效，但目前**沒有臨床試驗**，只有 **20 篇文獻**，且多為獼猴等動物與體外研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Lamivudine 是 NRTI 類藥物，透過抑制病毒逆轉錄酶（及 HBV 聚合酶）發揮抗病毒作用，其在 HIV-1 與 HBV 的療效已被證實。

SIV 與 HIV 同屬慢病毒，其逆轉錄酶也是 NRTI 的作用標的。獼猴 SIV 感染是研究 HIV 的標準動物模型。文獻顯示含 lamivudine 的療法能在獼猴體內壓低病毒量，SIV 逆轉錄酶也會出現 M184V 抗藥突變，與人類 HIV-1 使用 3TC 的情況相似。

需要注意：SIV 是非人類病原體，這些資料只是對已核准 HIV-1 適應症的**前臨床佐證**，不構成獨立的人類老藥新用適應症。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據只有獼猴動物與體外研究，沒有任何臨床試驗。這些資料支持的是 lamivudine 已核准的 HIV-1 用途，且 SIV 是非人類病原體，不能當作獨立的人類新適應症。
- 同一份預測清單中的其他項目也不建議推進：
  - 貓後天免疫缺陷症候群：屬獸醫疾病，所列 5 個試驗皆為人類 HIV-1 研究。
  - 慢性 C 型肝炎：多為 HBV 研究或不含 lamivudine 的 HCV 研究，較可能是知識圖譜中 HBV/HCV 共同出現造成的假象。
  - 神經發育疾病與已作廢的家族性複合型高脂血症：無機轉關聯，也無任何試驗或文獻。

**若要推進需要：**
- 香港衛生署仿單的警語與禁忌資料（目前為阻斷性缺口，無法進入安全性篩選）
- 詳細的作用機轉（MOA）資料，可查詢 DrugBank
- 確認香港許可證的核准適應症文字
- 若仍要探索，應優先評估 lamivudine 在人類 HIV-1／HBV 共感染等已知適應症的定位，而非 SIV／FIV 等動物病毒疾病

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
