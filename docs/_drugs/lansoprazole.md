# Lansoprazole：從胃酸相關疾病到十二指腸胃逆流

## 一句話總結

Lansoprazole 是質子幫浦抑制劑（PPI），原本用於抑制胃酸，治療消化性潰瘍、胃食道逆流等胃酸相關疾病。
TxGNN 模型預測它可能對**十二指腸胃逆流 (Duodenogastric Reflux)** 有效，但目前**沒有臨床試驗**，只有 **2 篇文獻**，且其中 1 篇大鼠研究顯示潛在安全疑慮，證據薄弱。

## 為什麼這個預測合理？

Lansoprazole 是 H+/K+ ATP 酶（質子幫浦）抑制劑，能減少胃酸分泌。十二指腸胃逆流則是膽汁與十二指腸內容物逆流回胃部。

從機轉看，抑制胃酸或許能減輕逆流相關的胃黏膜不適。但它無法矯正根本原因，也就是胃腸動力或幽門功能異常。因此關聯性主要來自知識圖譜的間接連結，並沒有直接的療效證據。

目前唯一直接相關的文獻，是一篇大鼠研究。它指出在十二指腸胃逆流的條件下，lansoprazole 反而促進胃部致癌，這是潛在的安全訊號，不是療效支持。0.997 的 TxGNN 分數僅代表模型預測，不能取代臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測，沒有臨床試驗，證據等級僅 L4。
- 唯一直接相關的大鼠研究顯示 lansoprazole 在逆流條件下可能促進胃癌，是需要優先釐清的安全訊號。
- 抑制胃酸無法矯正逆流的成因，機轉上的支持也有限。

**若要推進需要：**
- 取得香港衛生署核准仿單，補齊警語、禁忌與適應症資料。
- 補充詳細的作用機轉資料（DrugBank）。
- 評估大鼠致癌研究對人類的相關性，並檢視是否有人體研究。
- 尋找或設計針對十二指腸胃逆流的臨床研究，確認療效與長期安全性。
