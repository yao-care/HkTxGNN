# Latanoprostene Bunod：從眼壓治療到內臟鈣化防禦 (Visceral Calciphylaxis)

## 一句話總結

Latanoprostene Bunod 是外用眼科溶液（香港品名 VYZULTA 0.024%），依機轉與產品型態推斷用於降低眼壓，例如開角型青光眼與高眼壓症。
TxGNN 模型預測它可能對**內臟鈣化防禦 (Visceral Calciphylaxis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據已知資訊，Latanoprostene bunod 會釋出兩種活性物質：
- 一氧化氮 (NO)，帶來血管擴張，並促進小樑網的房水流出。
- Latanoprost acid，一種前列腺素 F2-alpha 促效劑，經葡萄膜鞏膜路徑增加房水流出。

這兩個機轉都指向降低眼壓。預測到鈣化防禦的唯一可想像的連結，是 NO 的血管擴張作用與鈣化性小血管疾病有些關聯，但這只是推測。

這個預測在生物學上很難成立。本品是外用眼藥水，全身暴露量極低，不太可能對內臟血管產生系統性作用。0.9976 的高分較可能來自知識圖譜中相鄰節點的關聯，而不是真實的生物訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級只有 L5，沒有試驗或文獻。
- 外用眼藥水的全身暴露極低，機轉上難以作用於內臟鈣化防禦。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料，這是目前的阻擋性缺口。
- 補齊 DrugBank 的作用機轉資料，以及原適應症資料。
- 找出鈣化防禦相關的機轉或前臨床研究，證明局部給藥有可能作用於目標組織。

**補充觀察：** 同一份預測中，排名第 2 的「原發性遺傳性青光眼 (Primary Hereditary Glaucoma)」機轉較合理（同屬眼壓調控），可列為研究問題。但遺傳型或早發型青光眼常有發育性隅角異常，藥物治療反應可能不佳，且缺乏兒童的安全性與療效資料。排名第 3 至 5 的胸廓出口症候群（靜脈型、動脈型、神經型）沒有合理的機轉連結，建議不予考慮。
