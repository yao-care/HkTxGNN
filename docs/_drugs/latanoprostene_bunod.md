# Latanoprostene Bunod：從開角型青光眼到內臟鈣化防禦症

## 一句話總結

Latanoprostene bunod 是一種外用眼科藥物，原本用於治療開角型青光眼 (open-angle glaucoma) 與高眼壓症 (ocular hypertension)。
TxGNN 模型預測它可能對**內臟鈣化防禦症 (Visceral Calciphylaxis)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Latanoprostene bunod 會代謝為 latanoprost acid（前列腺素 F2α 類似物，作用於 FP 受體）與一氧化氮 (NO)。前者增加葡萄膜鞏膜途徑的房水排出，後者放鬆小梁網與 Schlemm 氏管，增加傳統途徑的排出，兩者共同降低眼壓。

從理論上看，NO 介導的血管擴張與 cGMP 訊號，或許可對抗微血管鈣化與缺血。但這只是推測。鈣化防禦症是全身性血管鈣化疾病，多見於腎衰竭患者；而本藥為外用眼科藥物，全身暴露量極低，不太可能在相關組織達到有效濃度。

因此，0.998 的高分僅是計算模型的預測結果，機轉上的支持相當薄弱。

## 結論與下一步

**決策：Hold**

**理由：**
- 內臟鈣化防禦症的預測僅來自模型分數，沒有任何臨床試驗或文獻支持（證據等級 L5）。
- 機轉上的連結屬推測，且外用眼科給藥的全身暴露量極低，與該疾病所需的全身性治療不相符。

**若要推進需要：**
- 取得 DrugBank 的完整作用機轉資料
- 取得香港衛生署仿單中的警語與禁忌症
- 進行系統性文獻回顧，確認是否有 NO 供體或前列腺素類似物用於鈣化防禦症的前臨床或臨床證據
- 評估給藥途徑的相容性（外用眼科 vs. 全身性治療需求）

**補充說明：**
同一份預測清單中，**原發性遺傳性青光眼 (primary hereditary glaucoma，分數 99.71%)** 在生物學上最為合理，因為它與本藥已核准的適應症（高眼壓導致的青光眼）病理機轉相近。不過，該分數可能主要反映與現有青光眼適應症的相似性，而非真正的新用途。建議將此項列為後續研究問題，優先回顧既有青光眼試驗中是否納入家族性病例。至於胸廓出口症候群的三種亞型（靜脈型、動脈型、神經型），則缺乏明確機轉連結，可能是圖譜相鄰性造成的假訊號。
