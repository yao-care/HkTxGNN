# Lecanemab：從阿茲海默症相關適應症到糖尿病性白內障

## 一句話總結

Lecanemab 是一種抗類澱粉蛋白-β（amyloid-beta）原纖維（protofibril）的單株抗體，在香港已有 2 張有效許可證。
TxGNN 模型預測它可能對**糖尿病性白內障 (Diabetic Cataract)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測，證據薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Lecanemab 是靶向類澱粉蛋白-β 原纖維的單株抗體，唯一可想像的關聯是：有研究曾報告晶狀體中可見類澱粉蛋白-β 沉積，但這仍屬推測，尚未獲得證實。

從機轉面來看，這個預測並不合理。糖尿病性白內障主要由高血糖、多元醇路徑（polyol pathway）活化與氧化壓力所驅動，Lecanemab 並不作用於這些路徑。此外，Lecanemab 是靜脈輸注的大分子 IgG 抗體，沒有明確途徑可進入晶狀體並改變其混濁程度。

TxGNN 的高分（98.48%）屬於計算預測結果，應視為提出假說的線索，而非療效證據。

同一批預測中，其他排名靠前的新適應症多為各類白內障（成熟型、未成熟型、老年性、皮質型、核型等）與糖尿病視網膜病變，皆同樣只有模型預測，沒有臨床試驗或文獻佐證。其中老年性白內障與阿茲海默症的關聯，可能只是來自共同的高齡族群，屬於混雜因素，而非機轉上的連結。

## 安全性考量

安全性資訊請參考原廠仿單。

另需注意：Lecanemab 與類澱粉蛋白相關影像異常（ARIA）的風險有關，這是一種血管相關的安全性疑慮。若考慮用於糖尿病視網膜病變等血管病變相關適應症，需特別謹慎。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測，沒有任何臨床試驗或文獻支持（證據等級 L5），且機轉上缺乏合理的作用路徑。
- 給藥途徑（全身性靜脈輸注的大分子抗體）與眼部晶狀體疾病並不相容，且有 ARIA 相關的安全性疑慮。

**若要推進需要：**
- 補充 Lecanemab 的作用機轉資料與原核准適應症文字
- 取得原廠仿單中的警語、禁忌與藥物交互作用資料
- 提供晶狀體或眼部存在類澱粉蛋白-β 病理並與糖尿病性白內障相關的前臨床證據
- 評估藥物是否能到達眼部組織，以及給藥途徑的可行性
- 完成上述步驟、並有基本生物學證據後，再重新評估是否值得進入研究階段
