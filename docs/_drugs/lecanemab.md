# Lecanemab：從阿茲海默症到糖尿病性白內障

## 一句話總結

Lecanemab 是一種抗類澱粉蛋白 (amyloid-beta) 單株抗體，原本用於阿茲海默症治療。
TxGNN 模型預測它可能對**糖尿病性白內障 (Diabetic Cataract)** 有效，
但目前**沒有任何臨床試驗、也沒有文獻**支持這個方向，純屬知識圖譜預測分數。

## 快速總覽

|------|------|
| 原適應症 | 阿茲海默症（Alzheimer's Disease，抗 amyloid-beta 單株抗體） |

## 為什麼這個預測合理？

目前缺乏 Lecanemab 詳細的作用機轉資料庫記錄（DrugBank MOA 欄位為資料缺口）。根據 Evidence Pack 中的機轉關聯分析，Lecanemab 是標靶腦內類澱粉蛋白 (amyloid-beta) 沉積的單株抗體，用於清除阿茲海默症患者腦部的類澱粉斑塊。

糖尿病性白內障的病理主要是晶狀體蛋白 (crystallin) 因高血糖誘發的多元醇路徑活化與氧化壓力所導致的聚集變性，與阿茲海默症的類澱粉樣蛋白聚集在「蛋白質異常聚集」這個抽象層次上有表面相似性，這可能是 TxGNN 知識圖譜給出高分的原因。

但這個連結**目前僅止於理論層面推測**：Lecanemab 是全身性投予的大分子單株抗體，並無任何證據顯示它能穿透血眼屏障並作用於晶狀體局部病灶，也沒有眼科藥動學資料佐證。Evidence Pack 中對此關聯的原始評估亦明確標註為「推測性連結」，且其餘 9 個候選適應症（多數為白內障不同亞型，以及糖尿病視網膜病變）同樣缺乏機轉或實證支持，型態高度相似的候選群聚，提示這批預測可能反映知識圖譜對「白內障」節點的整體高分傾向，而非針對 Lecanemab 的特異性訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，完全依賴 TxGNN 圖譜預測分數，無任何臨床試驗或文獻支持
- 機轉關聯屬推測性質，缺乏血眼屏障穿透性等關鍵藥動學證據，且藥物原始 MOA 資料本身即為缺口
- 該藥物尚未在香港上市，亦無法取得仿單警語進行基本安全性初評（S1 前置條件未滿足）

**若要推進需要：**
- 補齊 Lecanemab 完整作用機轉 (MOA) 資料（DrugBank API 查詢）
- 取得 TFDA/原廠仿單警語與禁忌症，完成 S1 安全性初評
- 若要驗證眼科適應症可行性，需要眼科藥動學資料（是否能穿透血眼屏障）或至少一項體外/動物機轉研究
- 排名 2-10 的其他候選（多為白內障亞型與糖尿病視網膜病變）目前共享相同的證據缺口，建議一併等待機轉或實證資料補強後再重新評估，而非逐一單獨推進
