# Levonorgestrel：從停經後骨質疏鬆到痤瘡

## 一句話總結

Levonorgestrel（左炔諾孕酮）是一種黃體素類藥物，在知識圖譜中的原適應症為停經後骨質疏鬆與骨質疏鬆。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，但目前**沒有臨床試驗**，僅有 **20 篇文獻**，且多為一般性的避孕藥回顧，缺乏針對 levonorgestrel 本身的直接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Levonorgestrel 是一種合成黃體素，帶有一些殘餘的雄性素活性。

複方荷爾蒙避孕藥可透過提高性荷爾蒙結合球蛋白（SHBG），並藉由雌激素與促性腺激素的抑制作用降低卵巢雄性素生成，因而改善痤瘡。這是預測合理的主要生物學依據。

但需要特別注意：levonorgestrel 本身的雄性素活性使「直接抗痤瘡」的機轉並不直覺，與具抗雄性素作用的黃體素（如 chlormadinone acetate、drospirenone、cyproterone acetate）不同，在部分使用者中甚至可能加重痤瘡。因此，這個極高的模型分數並未獲得針對 levonorgestrel 本身的直接證據支持。此外，原適應症（骨質疏鬆）與痤瘡之間的關聯，主要來自知識圖譜的間接關係。

## 安全性考量

- **知識圖譜標示的相關疾病禁忌／警示**（非仿單內容）：高血壓、癲癇、焦慮與神經症、紫質症、腎臟疾病、肝臟疾病、膽囊疾病、高血糖、糖尿病（含酮酸中毒）、甲狀腺功能低下、全身性紅斑性狼瘡、氣喘、凝血疾病、高三酸甘油脂血症、高鈣血症等。
- **藥物交互作用**：資料庫共查得 100 筆，以下為部分中度交互作用：Acarbose、Aprepitant、Canagliflozin、Clotrimazole、Dapagliflozin、Ertugliflozin、Exenatide、Liraglutide、Linagliptin、Nateglinide，以及多種胰島素製劑。其中多數為降血糖藥物，使用時需留意血糖變化。

正式的警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高（99.88%），但沒有任何臨床試驗，文獻也缺乏針對 levonorgestrel 單方的直接證據。levonorgestrel 的雄性素活性在機轉上反而可能不利於痤瘡，證據等級僅為 L4。
- 痤瘡已有抗雄性素黃體素的複方避孕藥等較成熟的選項，levonorgestrel 並無明顯優勢。

**若要推進需要：**
- 取得作用機轉（MOA）資料並釐清雄性素活性對痤瘡的淨效應
- 取得香港仿單的警語、禁忌與核准適應症內容，完成安全性篩選
- 針對 levonorgestrel 單方（或與其他黃體素的對照）進行痤瘡相關的臨床證據評估
- 確認給藥途徑與劑型是否適合皮膚科用途
