# Lidocaine：從皮膚與神經痛相關疾病到結膜疾病（conjunctival disorder）

## 一句話總結

Lidocaine（利多卡因）是常見的局部麻醉藥，原本用於皮膚炎、神經痛、痔瘡、疥瘡等疾病的症狀處理。
TxGNN 模型對多個眼表疾病給出高分預測，其中預測分數最高的是**點狀上皮角結膜炎**，但該項沒有任何臨床試驗或文獻支持。
目前證據相對最多的是**結膜疾病 (Conjunctival Disorder)**，有 **2 個臨床試驗**和 **20 篇文獻**，但多數屬於手術麻醉或間接相關研究，並非直接證明能治療結膜疾病。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Lidocaine 是鈉離子通道阻斷型局部麻醉藥，在眼科已有表面麻醉與手術麻醉的使用經驗，機轉上可能緩解眼表的感覺神經痛覺。

不過，這個預測的合理性有限：
- **點狀上皮角結膜炎**：Lidocaine 或許能緩解眼表疼痛，但局部麻醉藥反覆使用有角膜上皮毒性風險，對上皮病變反而不利。
- **乳突性結膜炎、酒糟性結膜炎**：沒有試驗或文獻，最多只是症狀性麻醉，無法處理發炎或瞼板腺病變。
- **異位性結膜炎**：2023 年前臨床前研究（PMID 37819721）指出神經與杯狀細胞的關聯會促進過敏原快速穿透結膜，暗示阻斷感覺神經可能調節過敏原處理；1994 年研究（PMID 8039024）顯示鼻腔麻醉影響過敏原刺激後的淚液功能。兩者都不是 Lidocaine 的臨床試驗，僅能作為假說。
- **腎病症候群、非人類動物疾病、體癬**：現有文獻多是藥動學、毒性或與疾病無關的回顧，無療效證據，其高分應視為模型輸出而非臨床訊號。

## 安全性考量

- **知識圖譜中的禁忌疾病**（來自藥物－疾病關聯，非仿單文字）：高血壓、肝衰竭／肝病／肝硬化、癲癇、腎臟病、腎上腺皮質功能不足（Addison 病）、甲狀腺功能低下、開角型青光眼、精神疾患（含思覺失調類）、骨質疏鬆、胃炎、真菌感染等。實際使用應以仿單為準。
- **藥物交互作用**：資料庫共 100 筆，以下為其中較重要者：
  - 重大 (Major)：Bupropion
  - 中度 (Moderate)：Aprepitant、Cimetidine、液態微脂體 Morphine、Obeticholic acid、含電解質聚乙二醇 3350、Picosulfuric acid、Sodium sulfate
  - 輕微 (Minor)：Dexamethasone、Kanamycin、Neomycin、Omeprazole、Streptomycin、Troglitazone
- **文獻中的安全訊號**：
  - 全身性使用的神經精神與心臟副作用（PMID 19250287）。
  - 局部使用合併其他藥物可能導致高鐵血紅素血症（PMID 41995267）。
  - 局部麻醉藥反覆使用或濫用有角膜上皮毒性風險，與眼表上皮疾病的預測尤其衝突。
  - 低劑量 Lidocaine 與 Ceftriaxone 合用於獼猴曾引發癲癇（PMID 19858165）。

香港仿單的警語與禁忌資料尚未取得，須補齊後方能進行安全性篩選。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第 1 的「點狀上皮角結膜炎」僅有模型預測，無任何試驗或文獻，且局部麻醉藥的角膜上皮毒性與該疾病的病理相衝突。
- 證據相對較多的「結膜疾病」（L4，Research Question）所依據的是手術麻醉用途（翼狀贅片手術）與 SUNCT 頭痛文獻，並未顯示 Lidocaine 能治療結膜疾病本身，也沒有符合 L1–L3 的 Phase 3 RCT。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症文字（目前為阻斷性資料缺口）。
- 補充作用機轉資料（MOA）。
- 釐清是否要以「眼表疼痛緩解」或「手術麻醉」為目標，而非「疾病治療」，並重新定義終點指標。
- 針對異位性結膜炎的神經－杯狀細胞假說，設計臨床前或小型探索性研究。
- 評估眼科局部給藥的角膜毒性風險，並確認現有劑型與給藥途徑是否適用（目前路徑相容性評估尚未完成）。
