# Linaclotide：從腸道便秘相關疾病到馬尾症候群

## 一句話總結

Linaclotide 是一種作用於腸道的鳥苷酸環化酶-C（GC-C）促效劑，一般藥理上用於便秘型腸躁症等便秘相關疾病（本次資料未提供原適應症）。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有臨床試驗和文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原始 MOA 欄位為空）。以下機轉說明來自一般藥理知識，並非本次提供的資料。

Linaclotide 幾乎不被吸收，作用於腸道局部。它會提高腸道細胞內的 cGMP，增加腸液分泌與腸道蠕動，並可能降低內臟痛覺。

馬尾症候群常造成神經性腸道功能障礙，出現便秘。因此 linaclotide 若有幫助，也只是**緩解腸道症狀**，不能治療根本的神經壓迫。模型給出的高分（0.9996）較可能反映知識圖譜中與便秘相關節點的距離很近，並非疾病修飾機轉。

同一次預測中的另外兩個結果，證據同樣薄弱：

- **神經性膀胱（已廢止的疾病術語）**（99.89%）：GC-C 促效作用與膀胱逼尿肌或括約肌控制沒有直接關聯。它常與神經性腸道功能障礙並存，linaclotide 頂多間接改善便秘。此疾病術語已在本體論中標為廢止，映射可信度低，可能是圖譜假象。
- **失眠**（99.51%）：找不到合理的機轉連結。Linaclotide 全身暴露量極低，不預期影響睡眠調控，高分很可能是圖譜鄰近性造成的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 三個預測適應症都只有模型分數，沒有臨床試驗或文獻，證據等級為 L5。
- 機轉上最多只能緩解伴隨的便秘，不能治療馬尾症候群本身，高分很可能是圖譜假象。

**若要推進需要：**
- 取得香港衛生署仿單，完成警語與禁忌症的安全性篩選（目前為阻斷性缺口）
- 從 DrugBank 補齊作用機轉資料
- 檢索是否有 linaclotide 用於神經性腸道功能障礙或脊髓損傷相關便秘的臨床研究
- 釐清預測目標是「馬尾症候群本身」還是「伴隨的腸道症狀」，必要時改以症狀性適應症重新評估
- 確認核准適應症與劑型（目前香港許可證資料為空）
