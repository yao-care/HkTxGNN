# Lisinopril：從降血壓藥（ACE 抑制劑）到後下壁心肌梗塞

## 一句話總結

Lisinopril 是一種 ACE 抑制劑（血管收縮素轉換酶抑制劑），在香港已有多張上市許可證。
TxGNN 模型預測它可能對**後下壁心肌梗塞 (Posteroinferior Myocardial Infarction)** 有效。
不過目前**沒有任何臨床試驗或文獻**直接支持這項預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Lisinopril 屬於 ACE 抑制劑，這類藥物阻斷腎素-血管收縮素系統（RAS），可降低心臟後負荷，並減緩心肌梗塞後的心室重塑。因此在機轉上，用於心肌梗塞有生物學上的合理性。

不過有兩點要注意：

- 「ACE 抑制劑用於急性心肌梗塞後」是一般醫學背景知識，並非本次資料所驗證，需對照仿單與治療指引確認。
- 後下壁心肌梗塞是心肌梗塞的解剖位置亞型。同時被預測的「後外側心肌梗塞」分數完全相同（99.90%），推測是模型從共同的上層心肌梗塞節點推得。因此它可能只是本體論中的重複節點，而非獨立的老藥新用標的。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有 TxGNN 模型分數，沒有任何臨床試驗或文獻。
- 香港仿單的警語與禁忌資料缺漏，屬阻擋性缺口，無法進入安全性篩選。
- 後下壁與後外側心肌梗塞可能只是重複的本體論節點，並非獨立的新適應症。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌、核准適應症），補齊安全性資料。
- 查詢 DrugBank，補充作用機轉資料。
- 對照現行心肌梗塞治療指引，確認 ACE 抑制劑已有的適應症，判斷此預測是否只是重複既有用途。
- 檢索 lisinopril 與心肌梗塞的 RCT 與系統性回顧。
- 其餘預測（肺高壓兩項、惡性腎血管性高血壓）同樣沒有直接證據。其中肺高壓「缺氧」項下的 20 篇文獻只是「hypoxia」關鍵字比對，與 lisinopril 無關。惡性腎血管性高血壓則有雙側腎動脈狹窄時急性腎損傷的安全疑慮，需另行評估。

本報告結果僅供研究參考，不構成醫療建議，老藥新用候選需經臨床驗證後才能應用。
