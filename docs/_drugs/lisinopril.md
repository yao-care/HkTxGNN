# Lisinopril：從高血壓與心肌梗塞到後下壁心肌梗塞

## 一句話總結

Lisinopril 是一種血管收縮素轉化酶抑制劑（ACE inhibitor），原本用於高血壓與心肌梗塞等心血管疾病。
TxGNN 模型預測它可能對**後下壁心肌梗塞 (Posteroinferior Myocardial Infarction)** 有效，但目前**沒有任何臨床試驗或針對此亞型的文獻**支持，預測主要來自與原適應症（心肌梗塞）的本體論關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Lisinopril 屬於 ACE 抑制劑類別，可抑制腎素-血管收縮素-醛固酮系統（RAAS），降低後負荷與前負荷，並限制心肌梗塞後不良的心室重塑，一般認為可改善梗塞後存活率。

後下壁心肌梗塞是心肌梗塞的解剖位置亞型，而心肌梗塞本身已是 Lisinopril 的既有適應症。因此這項預測較可能來自上位疾病的本體論關係，**並非獨立的藥物再利用證據**。同樣的分數也出現在後外側心肌梗塞，進一步支持這個判斷。

整體而言，這更接近「已被涵蓋的適應症」，而不是真正的新適應症機會。

## 安全性考量

- **知識圖譜標示的禁忌或需謹慎疾病**（非仿單內容）：
  - 血管性水腫（含遺傳性、後天性及 RAAS 阻斷劑誘發型）
  - 腎臟疾病、肝臟疾病、肝性腦病變
  - 胰臟炎、膽囊疾病
  - 全身性紅斑性狼瘡、結締組織疾病
  - 糖尿病、糖尿病酮酸中毒、低鉀血症
  - 嗜中性白血球低下、顆粒球缺乏症
  - 主動脈瓣狹窄、低血壓
  - 副甲狀腺機能亢進、骨病
- **藥物交互作用**：已查得 100 筆交互作用紀錄，其中**重大 (Major)** 等級包括：
  - 檸檬酸鉀（Potassium citrate）
  - 碳酸氫鉀（Potassium bicarbonate）

  兩者皆有高血鉀風險。另有多項中度交互作用，包括皮質類固醇（Hydrocortisone、Dexamethasone、Betamethasone、Budesonide、Triamcinolone）、降血糖藥（Metformin、Dapagliflozin、Empagliflozin、Canagliflozin、Alogliptin、Saxagliptin、Chlorpropamide）、阿斯匹靈、嗎啡及 Bupropion 等。

其餘警語與仿單禁忌資料請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 後下壁心肌梗塞屬於心肌梗塞的亞型，Lisinopril 已有心肌梗塞適應症，此預測更像是既有適應症的延伸，而非新的再利用機會。
- 高分預測可能源自本體論關聯，且缺乏任何亞型專屬的臨床試驗或文獻。

**若要推進需要：**
- 確認香港許可證核准的適應症文字，釐清心肌梗塞是否已涵蓋此亞型
- 取得原廠仿單的警語與禁忌症資料
- 補充詳細的作用機轉資料
- 若仍要探索，需尋找針對下壁或後壁心肌梗塞的 ACE 抑制劑亞群分析
