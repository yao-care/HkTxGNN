# Loperamide：從腹瀉到急性傳染性結膜炎

## 一句話總結

Loperamide 是周邊型 mu 類鴉片受體促效劑，能減緩腸道蠕動，臨床上一般作為止瀉藥使用。
TxGNN 模型預測它可能對**急性傳染性結膜炎 (Acute Contagious Conjunctivitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於僅有模型預測的 L5 等級，建議暫緩。

## 為什麼這個預測合理？

坦白說，這個預測**缺乏合理的生物學依據**。Loperamide 作用於腸道的 mu 類鴉片受體，用來減緩腸蠕動。它對結膜沒有已知的抗菌或抗發炎作用。

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。上述機轉描述來自一般藥理知識，而非資料庫。

模型給出高分，最可能是知識圖譜的拓撲結構造成，而不是真正的生物關聯。同一批預測中排名前十的大多是各種結膜炎，也支持這個判斷：這些預測彼此相似，並非各自獨立的證據。

## 安全性考量

安全性資訊請參考原廠仿單。

同一批預測的其他適應症在文獻檢索中出現了兩個值得注意的安全訊號：
- **阿米巴痢疾**：有病例報告指出使用 loperamide 後發生猛爆性阿米巴結腸炎。減緩腸蠕動可能延長寄生蟲與黏膜的接觸，增加毒性巨結腸的風險。
- **嚴重胃腸道發炎**：2026 年病例報告描述化療後嚴重胃腸道發炎的患者出現 loperamide 引起的呼吸抑制。黏膜受損可能增加全身吸收與中樞神經作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有臨床試驗、沒有文獻，也沒有機轉依據，僅是模型預測 (L5)。
- 比對到的結膜炎試驗（NCT04185402、NCT06289647）都是 azithromycin 治療砂眼的研究，並未測試 loperamide，屬於誤配，不能當作證據。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料，並說明結膜炎與 mu 類鴉片受體之間是否存在任何生物學關聯。
- 取得香港衛生署的仿單，補齊警語與禁忌症。
- 若要在同批預測中挑選方向，**胃十二指腸炎 (gastroduodenitis)** 是唯一有機轉合理性的項目（L4，僅有 1986 年一篇設計不明的舊研究）。它應先做以安全性為主的評估，再談療效。
- 阿米巴痢疾的預測與既有安全知識相衝突，建議排除。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。
