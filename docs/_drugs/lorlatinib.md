## Lorlatinib：從非小細胞肺癌到牙齦纖維瘤病
{: .text-alpha }

## 一句話總結

Lorlatinib 是第三代 ALK/ROS1 酪胺酸激酶抑制劑，知識圖譜記錄的原適應症為非小細胞肺癌。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效，
但目前**沒有任何臨床試驗或文獻**直接研究這個疾病，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，lorlatinib 是 ALK/ROS1 抑制劑，在 ALK 陽性非小細胞肺癌中的療效已有 Phase 3 CROWN 試驗支持。

然而，ALK/ROS1 抑制與牙齦纖維瘤病之間找不到明確的生物學關聯。牙齦纖維瘤病是牙齦組織的纖維性增生，並非已知由 ALK 或 ROS1 驅動。0.998 的高分只是模型預測，沒有試驗或文獻佐證，應視為假說而非有依據的再利用方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測沒有任何直接研究支持，ALK/ROS1 抑制與牙齦纖維瘤病之間也沒有可辨識的機轉關聯，僅為模型分數。
- 原適應症的 Phase 3 證據無法轉用於此疾病，且藥物有明確的代謝與神經系統不良反應，在缺乏療效訊號下不宜推進。

**若要推進需要：**
- 取得 lorlatinib 的作用機轉資料，並確認牙齦纖維瘤病是否涉及 ALK/ROS1 訊號路徑
- 進行臨床前或機轉研究，作為任何臨床試驗的前提
- 取得香港許可證的核准適應症文字與仿單警語、禁忌症
- 參考同一預測清單中其他項目，例如 ALK 驅動的神經母細胞瘤，其已有 Phase 1 試驗訊號，可作為另一個獨立適應症追蹤
