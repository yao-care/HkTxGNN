# Lorlatinib：從 ALK 陽性肺癌到牙齦纖維瘤病

## 一句話總結

Lorlatinib 是第三代 ALK/ROS1 酪胺酸激酶抑制劑，在香港已上市，臨床上用於 ALK 陽性非小細胞肺癌。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, gingival)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。已知 Lorlatinib 是 ALK/ROS1 酪胺酸激酶抑制劑，其療效在 ALK 或 ROS1 陽性的肺癌中已被證實。

牙齦纖維瘤病是牙齦的良性纖維組織過度增生。目前沒有證據顯示它與 ALK/ROS1 訊號路徑有關，因此機轉上的連結並不成立。0.998 的高分只代表知識圖譜中的關聯，沒有已知路徑支持。

**此預測目前無法用藥理機轉解釋，應視為待驗證的模型訊號，而非有依據的假說。**

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有試驗或文獻，證據等級為 L5。
- 牙齦纖維瘤病是良性纖維增生，沒有已知的 ALK/ROS1 路徑連結，機轉上缺乏支持。

**若要推進需要：**
- 找出牙齦纖維瘤病與 ALK/ROS1 訊號之間是否有生物學連結，例如組織中 ALK 表現或融合基因的證據。
- 取得完整的作用機轉資料（DrugBank）。
- 取得香港衛生署仿單的警語與禁忌症，完成安全性初篩。
- 若後續考慮其他候選，可優先看**肺門癌 (lung hilum carcinoma)**。該候選有 1 篇新輔助 Lorlatinib 於 ALK 陽性肺癌的個案報告（PMID 37934724），證據等級 L4，屬「研究問題」階段。這仍是間接的個案證據，需先確認腫瘤的 ALK 狀態。

*本報告僅供研究參考，不構成醫療建議。預測結果需經臨床驗證後才能應用。*
