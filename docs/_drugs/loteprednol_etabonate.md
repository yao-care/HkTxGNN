# Loteprednol Etabonate：從葡萄膜炎與過敏性結膜炎到慢性濾泡性結膜炎

## 一句話總結

Loteprednol etabonate 是一種局部眼用皮質類固醇，原本用於葡萄膜炎、過敏性結膜炎、春季結膜炎等眼部發炎性疾病。
TxGNN 模型預測它可能對**慢性濾泡性結膜炎 (Chronic Follicular Conjunctivitis)** 有效，
但目前**沒有臨床試驗和直接文獻**支持，僅有模型預測，屬於早期假說。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，loteprednol etabonate 是局部皮質類固醇，具抗發炎作用，在過敏性、異位性、春季及乳突性結膜炎等眼表發炎疾病中已有應用，機轉上可能透過抑制結膜的發炎介質而適用於慢性濾泡性結膜炎。

慢性濾泡性結膜炎與已核准的結膜炎適應症同屬結膜發炎，這是預測合理的基礎。不過，該疾病病因多樣（感染性、毒性、藥物誘發等），類固醇不一定有效，感染性病因甚至可能惡化。

**其他同分預測（皆為 L5、僅模型預測、無臨床試驗與文獻）：**
- **非病毒性漿液性結膜炎**（99.69%）：定義廣泛且不具特異性，機轉依據有限。
- **寄生蟲性結膜炎**（99.69%）：類固醇無法處理病因，單用可能削弱局部免疫而加重感染，僅可能作為抗寄生蟲治療的輔助。
- **結膜濾泡增生 (Conjunctival Folliculosis)**（99.69%）：多為良性、自限性，風險效益不利。
- **偽膜性結膜炎**（99.66%）：見下方文獻證據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容）：高眼壓、青光眼、單純疱疹病毒角膜炎、眼部黴菌感染、病毒性眼部感染、眼結核、眼部帶狀疱疹。
- **藥物交互作用**：資料庫查得 30 筆，但皆未標示嚴重程度，其中包括 pantoprazole、doxycycline、omeprazole、triamcinolone、prednisone、warfarin、clopidogrel 等。臨床意義需另行確認。
- **預測適應症相關風險**：類固醇可能造成眼壓升高、白內障及感染風險增加；在感染性（尤其病毒性、寄生蟲性）結膜炎中，可能延長病毒排出或使感染惡化。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.69%），但僅為計算模型結果，沒有臨床試驗或直接文獻支持。
- 目標疾病病因多樣，且多項知識圖譜禁忌涉及感染性眼疾，需審慎評估風險效益。

**若要推進需要：**
- 取得 DrugBank 作用機轉資料，進行機轉連結分析。
- 取得香港衛生署核准仿單的警語、禁忌與適應症文字。
- 進行文獻與臨床試驗的系統性檢索，並釐清慢性濾泡性結膜炎的病因分型（排除感染性）。
- 若進入評估，需規劃眼壓與感染監測方案。
