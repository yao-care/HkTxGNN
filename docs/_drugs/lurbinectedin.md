# Lurbinectedin：從小細胞肺癌到多發性內分泌腫瘤

## 一句話總結

Lurbinectedin 是一種細胞毒性轉錄抑制劑，已上市用於小細胞肺癌這類神經內分泌型惡性腫瘤。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測（證據等級 L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Lurbinectedin 是細胞毒性轉錄抑制劑，已在神經內分泌型惡性腫瘤（小細胞肺癌）中上市，機轉上與內分泌腫瘤只有鬆散的概念連結。

這個連結目前只是推測，理由有三點：

- 沒有任何試驗或文獻支持。
- 多發性內分泌腫瘤屬於種系突變驅動（如 MEN1、RET），多半生長緩慢。
- 毒性高的細胞毒性藥物不太適合這類病人。

因此高分較可能來自知識圖譜的關聯，不代表已有臨床依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有臨床試驗與文獻，機轉連結屬推測。
- 這是高毒性的細胞毒性藥物，用於生長緩慢的種系驅動疾病，風險效益不利。
- 各預測分數雖高（約 99%），其中多項是獸醫疾病或圖譜假象。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症。
- 取得 DrugBank 的作用機轉資料，分析與內分泌腫瘤的機轉連結。
- 檢索是否有多發性內分泌腫瘤相關的前臨床或臨床研究。
- 評估給藥途徑相容性，以及慢性或長期使用的可行性與安全性。
