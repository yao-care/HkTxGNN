# Magnesium Carbonate：從抗酸劑到活動性消化性潰瘍

## 一句話總結

Magnesium Carbonate（碳酸鎂）是一種抗酸劑成分，在香港已有多張許可證上市。
TxGNN 模型預測它可能對**活動性消化性潰瘍 (Active Peptic Ulcer Disease)** 有效，
目前**無登記臨床試驗**，但有 **4 篇文獻**支持這個方向。這比較接近其既有抗酸用途的延伸，而非典型的老藥新用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，碳酸鎂是抗酸劑類的成分，能中和胃酸、提高胃內 pH 值，機轉上可能有助於消化性潰瘍的癒合。

原適應症與預測新適應症的關聯很直接：抗酸與消化性潰瘍同屬胃酸相關疾病。因此，這個預測比較像是在既有抗酸用途上的延伸。

需要注意的是，現有臨床研究（1981–1985 年）測試的多為複方或高劑量抗酸製劑（如抗酸劑加抗膽鹼藥、Caved-S），對照組為 cimetidine、ranitidine 或安慰劑。這些研究並未單獨評估碳酸鎂，且多發表於 H. pylori 根除成為標準治療之前。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測與抗酸劑的既有用途高度一致，機轉上合理，但證據多來自複方製劑的早期研究，無法歸因於碳酸鎂單一成分，也沒有登記臨床試驗。
- 香港許可證缺少適應症文字，安全性警語與禁忌症資料也尚未取得，目前無法進入安全性篩選階段。

**若要推進需要：**
- 從香港衛生署取得仿單，補齊許可證適應症、警語與禁忌症（此為阻斷性缺口）
- 從 DrugBank 補充作用機轉（MOA）資料
- 檢視碳酸鎂單方的臨床資料，或釐清複方研究中各成分的貢獻
- 對照現行標準治療（PPI、H. pylori 根除）評估抗酸劑的定位

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
