# 氫氧化鎂（Magnesium Hydroxide）：從制酸劑到活動性消化性潰瘍

## 一句話總結

氫氧化鎂是常見的制酸成分，香港有多款含此成分的制酸/瀉劑產品上市，但許可證資料未列明核准適應症。
TxGNN 模型預測它可能對**活動性消化性潰瘍 (Active Peptic Ulcer Disease)** 有效。
目前**無臨床試驗登記**，但有 **19 篇文獻**支持這個方向，多為早期的抗酸劑研究、綜述與動物實驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。根據文獻，氫氧化鎂是制酸劑成分，能中和胃酸、提高胃內 pH，並降低胃蛋白酶活性。這是抗酸劑用於消化性潰瘍的主要理由。

另有文獻指出，含鋁鎂氫氧化物的抗酸劑可能有黏膜保護作用，與內源性前列腺素、表皮生長因子有關。不過這些保護作用的證據主要來自含鋁製劑（如 Maalox）與大鼠實驗，並非氫氧化鎂單方在人體上的證據。

消化性潰瘍本來就是抗酸劑的傳統用途，因此這個預測更接近「既有用途的確認」，不是全新的老藥新用。抗酸劑早期曾是潰瘍治療的主力，後來被 H2 受體阻斷劑、質子幫浦抑制劑（PPI）和幽門螺旋桿菌根除療法取代。現代定位較可能是輔助或症狀緩解，不是取代標準治療。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
抗酸劑用於消化性潰瘍是歷史悠久的既有用途，氫氧化鎂在香港已有多張許可證，且機轉（中和胃酸）直接對應潰瘍治療。但缺乏氫氧化鎂單方的現代對照試驗，現有證據多為舊研究、綜述和動物實驗。此外，香港仿單的警語與禁忌資料尚缺，資料缺口清單將其列為阻擋項目。因此只適合以輔助、症狀緩解的定位有條件推進，不適合視為潰瘍的主要療法。

**若要推進需要：**
- 取得香港衛生署核准的仿單，確認核准適應症、警語與禁忌症（目前為阻擋項目）
- 從 DrugBank 補齊作用機轉與原適應症資料
- 搜尋氫氧化鎂單方（非含鋁複方）在潰瘍癒合的對照研究，並核實 PMID 7034155 的試驗設計
- 釐清與 PPI、H. pylori 根除療法併用時的定位，並確認腎功能不全等族群的鎂蓄積風險與藥物交互作用（目前 DDI 查詢無資料）

本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後才能應用。
