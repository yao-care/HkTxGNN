## Magnesium Sulfate: 血栓性疾病 (thrombotic disease)
{: .text-alpha }

## 一句話總結

Magnesium Sulfate（硫酸鎂）是鎂鹽類藥物，目前在香港有多張有效許可證。
TxGNN 模型預測它可能對**血栓性疾病 (thrombotic disease)** 有效。
目前有 **1 個臨床試驗**（血栓性血小板減少性紫斑症，狀態未知、無結果）和數篇動物與小型臨床研究支持這個方向，整體證據等級為 **L3**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，前臨床研究顯示鎂可減少血小板沉積與血栓形成，可能與鈣拮抗、抑制血小板聚集，以及影響兒茶酚胺釋放有關。

在大鼠頸動脈血栓模型中，靜脈注射硫酸鎂可預防或延遲血栓形成（PMID 11816720）。兔與犬的動脈狹窄、血管阻斷模型也看到類似的抗血栓作用（PMID 3441141、7368083）。

臨床上，一項小型非隨機前導研究在接受冠狀動脈支架的患者中試用鎂，評估其可行性（PMID 14506544）。另有 1 個 Phase 3 隨機試驗在加護病房的血栓性血小板減少性紫斑症 (TTP) 中測試硫酸鎂，但狀態未知、尚無結果。這些證據只涵蓋特定情境，尚不足以推論一般血栓性疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的直接臨床試驗（TTP，Phase 3）狀態未知且沒有結果。其餘支持證據多為動物研究與小型非隨機前導研究，證據等級為 L3，尚不足以推進。

**若要推進需要：**
- 取得 NCT03237819 的試驗結果，或確認其現況
- 針對特定血栓情境（如支架血栓）設計隨機對照試驗
- 補充詳細的作用機轉資料
- 取得原廠仿單，確認警語、禁忌症及與抗凝血或抗血小板藥物併用的安全性
