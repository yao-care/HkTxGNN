# Maraviroc：從 HIV 感染到多發性內分泌腫瘤

## 一句話總結

Maraviroc 是 CCR5 拮抗劑，在香港以 CELSENTRI 錠劑 150mg 取得許可上市。本次資料中未收錄核准適應症文字。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia)** 有效，但目前**沒有臨床試驗和文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫未收錄）。已知 Maraviroc 是 CCR5 拮抗劑，透過阻斷 CCR5 受體發揮作用。

然而，多發性內分泌腫瘤主要由 MEN1 或 RET 基因驅動，目前並未確立 CCR5 在其發病機轉中的角色，因此**未發現直接的機轉關聯**。TxGNN 的高分（99.82%）僅屬計算預測，沒有任何試驗或文獻佐證，應謹慎看待。

## 安全性考量

- **知識圖譜標示的潛在禁忌／風險疾病**（來自藥物－疾病關聯，非仿單內容）：肝病（含藥物性肝損傷、慢性 B 型與 C 型肝炎）、腎臟疾病（含慢性腎衰竭、末期腎病）、冠狀動脈疾病與心肌梗塞／心肌缺血、姿勢性低血壓與姿勢性直立心搏過速症候群、多系統萎縮、膽囊疾病、血紅素病變、感染性疾病。
- **藥物交互作用**：共查得 93 筆，其中重大 (Major) 交互作用包括 **Clarithromycin**。中度 (Moderate) 交互作用例如 Aprepitant、Dexamethasone、Cimetidine、Eliglustat、Naltrexone、Clotrimazole、Miconazole、Cobicistat、Deferasirox 等。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測（多發性內分泌腫瘤）僅有模型分數，沒有試驗、文獻或機轉支持，證據等級為 L5。
- 安全性方面，肝、腎與心血管相關風險以及多項藥物交互作用需要審慎評估。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症
- 補充 Maraviroc 的作用機轉資料
- 針對 CCR5 與 MEN 的關聯進行前臨床驗證
- 若要優先探索，可考慮機轉較連貫的方向（如 HER2 陽性乳癌的 CCL5/CCR5 抗藥性假設），先進行前臨床研究
