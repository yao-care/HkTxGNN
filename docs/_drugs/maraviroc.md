# Maraviroc：從 HIV 感染到多發性內分泌腫瘤

> 註：本資料包未提供原適應症，標題中的「HIV 感染」是依 Maraviroc 為 CCR5 拮抗劑的一般已知用途所寫，請以原廠仿單確認。

## 一句話總結

Maraviroc 在香港以 CELSENTRI 150 mg 錠劑上市，是 CCR5 拮抗劑。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia)** 有效，
但目前**沒有臨床試驗、也沒有文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Maraviroc 是 CCR5 拮抗劑，可阻斷趨化因子受體 CCR5 的訊號。

多發性內分泌腫瘤主要由 MEN1、RET 等基因驅動。目前提供的資料中，找不到 CCR5 阻斷與這類內分泌腫瘤形成之間的合理關聯。

TxGNN 分數雖高（99.82%），但這只是知識圖譜的統計關聯，不等於機轉上可行。在有實際研究支持之前，應視為待驗證的假設。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（多發性內分泌腫瘤）只有模型分數，沒有試驗、文獻或可辨識的機轉連結，證據等級為 L5。
- 原廠仿單的警語與禁忌資料也缺漏，無法進入安全性初篩。

**若要推進需要：**
- 取得香港衛生署核准的仿單（警語、禁忌症、適應症），補齊安全性資料。
- 從 DrugBank 補上 Maraviroc 的作用機轉，評估 CCR5 與 MEN1/RET 相關腫瘤的關聯。
- 系統性檢索 CCR5 拮抗劑與內分泌腫瘤的前臨床研究，若無任何訊號，建議停止此方向。

**其他預測適應症（供參考）：**
- **HER2 陽性乳癌**：有一篇 2020 年前臨床研究顯示，自分泌 CCL5（CCR5 配體）經 ERK 路徑造成 trastuzumab 抗藥性。機轉上較一致，但未測試 Maraviroc，也無臨床證據，可作為轉譯研究題目，不宜視為治療建議。
- **原發性皮膚 T 細胞淋巴瘤**：趨化因子軸與惡性 T 細胞的皮膚歸巢有關，但唯一文獻是 ACKR1 的間接性回顧，證據薄弱。
- 其餘預測（痤瘡、兒童紅斑性狼瘡、念珠菌病等）均無直接證據。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。
