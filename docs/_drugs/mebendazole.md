# Mebendazole：從驅蟲治療到痤瘡

## 一句話總結

Mebendazole 是苯并咪唑類驅蟲藥，香港已有多張許可證上市。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，預測分數很高（99.20%）。
但目前**沒有任何臨床試驗**，僅有 **1 篇**不直接相關的病例報告，建議暫緩。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。Mebendazole 屬於苯并咪唑類驅蟲藥，一般認為它透過抑制寄生蟲微管蛋白（tubulin）聚合來發揮作用。

痤瘡的成因主要是皮脂腺分泌旺盛、毛囊角化異常與痤瘡桿菌相關發炎，與寄生蟲的微管機轉沒有已知的關聯。現有資料中找不到任何能連結 Mebendazole 與痤瘡病理的證據。

因此，這個高分預測較可能是知識圖譜相似度所造成的假象，不應視為有機轉支持的新用途。

## 結論與下一步

**決策：Hold**

**理由：**
- 痤瘡這項預測只有模型分數，沒有臨床試驗，也沒有機轉依據，證據等級為 L5。
- 香港仿單的警語與禁忌資料尚未取得，無法進行安全性篩選。

**其他預測適應症的參考：**
- **棘球蚴病（Echinococcus granulosus）**：證據最強（L3，建議 Proceed with Guardrails）。文獻中有 Mebendazole 治療 70 例包蟲病的臨床系列報告（PMID 2585032），機轉也吻合。但這比較接近既有的驅蟲用途，不算新用途。
- **肺泡型棘球蚴病**：L4，目前只有一項間接的追蹤與生物標記研究（NCT02876146），並未直接測試 Mebendazole。
- **瀰漫性皮膚利什曼病、皮脂腺蠕形蟎症**：機轉上有些可能性，但沒有任何試驗或文獻，僅列為研究問題。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與適應症資料。
- 若仍要探討痤瘡，先做文獻與機轉調查，確認是否存在有意義的生物學連結。
- 若要評估其他適應症，優先從棘球蚴病相關方向著手，並補上原適應症與作用機轉資料。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
