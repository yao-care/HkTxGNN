# Mecobalamin：從（原適應症未載明）到硬化性膽管炎

## 一句話總結

Mecobalamin（甲鈷胺）是活性型維生素 B12，在香港已有多張單方許可證，但目前編譯的資料中未載明原核准適應症。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Mecobalamin 是維生素 B12 的活性型態，一般認為參與甲基化與單碳代謝，並支持神經健康。但這屬於一般背景知識，並非本次資料所提供的機轉證據。

目前資料中無法確認硬化性膽管炎與 Mecobalamin 之間存在機轉上的關聯。膽汁淤積或免疫介導的膽管損傷，與 B12 的已知作用並無明確連結。0.995 的高分只代表模型運算結果，不等於有生物學或臨床證據。

其他預測適應症同樣只有模型分數、沒有證據：多發性內分泌腫瘤 (99.34%，為基因突變驅動的遺傳性腫瘤症候群，機轉上看不出關聯)，以及骨佩吉特氏病 (99.31%，B12 與同半胱胺酸代謝和骨代謝的關係僅是間接背景知識)。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜的藥物－疾病關係，並非仿單內容）：鉀缺乏症、慢性萎縮性胃炎、Leber 遺傳性視神經病變。
- **藥物交互作用**（共 13 筆）：
  - 中度：三氧化二砷 (Arsenic trioxide)、氯黴素 (Chloramphenicol)
  - 輕度：組織胺 H2 受體拮抗劑（Famotidine、Ranitidine、Cimetidine、Nizatidine 等）及氫離子幫浦抑制劑（Omeprazole、Esomeprazole、Lansoprazole、Pantoprazole、Rabeprazole、Dexlansoprazole 等）

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 三個預測適應症皆只有模型分數，沒有臨床試驗、文獻或機轉資料支持，證據等級為 L5。
- 作用機轉與原適應症資料缺漏，無法評估與硬化性膽管炎的關聯。

**若要推進需要：**
- 取得香港衛生署仿單，確認原核准適應症、警語與禁忌。
- 補充 Mecobalamin 的作用機轉資料（如 DrugBank）。
- 進行文獻與臨床試驗檢索，確認 B12 或 Mecobalamin 與硬化性膽管炎是否有任何研究。
- 若有初步證據，再評估給藥途徑與目標族群的可行性，並完成安全性篩選。
