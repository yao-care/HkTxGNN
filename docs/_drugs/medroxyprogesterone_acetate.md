# Medroxyprogesterone Acetate：從子宮內膜異位症到閉經

## 一句話總結

Medroxyprogesterone acetate（MPA，甲羥孕酮）是一種合成黃體素，原本用於子宮內膜異位症、子宮內膜癌及停經後骨質疏鬆等適應症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前**沒有臨床試驗**，僅有 **20 篇文獻**，且多數是避孕相關的回顧，直接證據有限。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，MPA 是合成黃體素類藥物，其黃體素作用可使增生期子宮內膜轉為分泌期，並在停藥後誘發撤退性出血。

在臨床上，「黃體素撤退試驗」本來就是診斷與治療繼發性閉經的標準做法，適用於內源性雌激素充足的無排卵患者。因此這個預測在機轉上合理，但也代表 **MPA 已被臨床用於此目的**，嚴格來說較接近既有用途，而非真正的藥物再利用。

另一點要留意：目前檢索到的文獻主要談避孕（閉經是長效 MPA 注射劑的副作用或預期結果），並非討論用 MPA 治療閉經。

其他排名較前的預測還包括乳房纖維囊腫、良性乳腺發育不良、子宮頸子宮內膜異位症與皮膚疤痕子宮內膜異位症。這些的證據更弱，且乳房相關預測與 HRT 研究顯示的乳腺增生風險方向相反。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜，非仿單內容）：高血壓、肝衰竭與肝病、膽囊疾病、腎臟病、癲癇、焦慮症、糖尿病（含酮酸中毒）、氣喘、全身性紅斑狼瘡、甲狀腺功能低下、骨質疏鬆、高鈣血症、高三酸甘油脂血症、物質濫用／依賴、**女性乳癌**等。
- **藥物交互作用**：共查得 100 筆，以中度為主，主要是降血糖藥物，例如 Acarbose、Metformin、Glimepiride、Chlorpropamide，GLP-1 類（Semaglutide、Liraglutide、Dulaglutide），SGLT2 抑制劑（Canagliflozin、Dapagliflozin、Empagliflozin），DPP-4 抑制劑（Alogliptin、Saxagliptin）與胰島素類；另有 Aprepitant、Dexamethasone、Clarithromycin。
- **乳腺風險訊號**：HRT 研究顯示含 MPA 的雌激素－黃體素療法可能增加乳房攝影密度與乳腺上皮增生；犬類研究也顯示 MPA 與乳腺變化有關。

完整警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 閉經的預測分數雖高，但 MPA 已是黃體素撤退試驗的既有用途，並非真正的再利用；現有文獻也多為避孕回顧，缺乏直接療效證據，也沒有臨床試驗。
- 其餘四個預測的證據更弱（L3–L5）。乳房纖維囊腫方面證據互相矛盾且有乳腺安全疑慮，疤痕子宮內膜異位症僅有模型預測。

**若要推進需要：**
- 先確認香港各許可證的核准適應症，判斷閉經是否已涵蓋在標示內
- 補充 MPA 作用機轉資料
- 取得香港衛生署仿單的警語與禁忌資訊
- 針對繼發性閉經的撤退性出血，檢索專門的臨床研究與治療指引
- 若考慮乳房相關適應症，需另行完成乳腺安全性評估
