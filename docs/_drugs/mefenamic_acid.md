## Mefenamic Acid: 頭痛疾患 (headache disorder)
{: .text-alpha }

## 一句話總結

Mefenamic acid 是一種非類固醇抗發炎藥，透過抑制前列腺素合成發揮作用。
TxGNN 模型預測它可能對**頭痛疾患 (headache disorder)** 有效。
目前沒有已登記的臨床試驗，但有 **18 篇文獻**，其中包含 3 項小型隨機雙盲試驗（偏頭痛），整體證據等級為 **L2**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻描述，mefenamic acid 是前列腺素合成抑制劑，透過阻斷 COX 酶來降低前列腺素的生成與作用。

前列腺素參與神經性發炎與痛覺敏化，是頭痛的重要病理環節。經期相關頭痛尤其明顯，因為月經前後前列腺素濃度會上升。因此，抑制前列腺素合成在機轉上可以解釋它對頭痛可能有效。

支持證據主要來自偏頭痛（頭痛疾患的一種亞型）的小型隨機雙盲試驗。這些試驗包括：

- 1983 年與 paracetamol 的交叉比較。
- 1986 年與安慰劑及 propranolol 的比較。
- 2000 年針對經期偏頭痛的安慰劑對照試驗。

這些試驗年代久遠、規模小，沒有大型 Phase 3 試驗，因此目前只能視為值得進一步研究的方向。

## 安全性考量

- **藥物交互作用**：已查詢到 100 筆交互作用紀錄，以下為部分重要項目。
  - 中等程度：Hydrocortisone、Dexamethasone、Betamethasone、Triamcinolone、Budesonide（皆為皮質類固醇）、Acetylsalicylic acid、Metformin、Chlorpropamide、Mesalazine、Balsalazide、Aprepitant、Potassium citrate、Potassium bicarbonate。
  - 輕微程度：Famotidine、Ranitidine、Cimetidine、Dapagliflozin、Linaclotide。
- **文獻提示的風險**：
  - 長期使用可能造成嚴重腸病變併絨毛萎縮。
  - 慢性頭痛患者長期使用止痛藥與腎臟病變有關。
  - 頻繁使用止痛藥有造成藥物過度使用型頭痛的疑慮。

仿單中的警語與禁忌症資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
有小型隨機雙盲試驗顯示 mefenamic acid 可能降低偏頭痛的發作頻率，機轉上也合理。但試驗年代久遠、規模小，且無已登記的試驗與大型 Phase 3 證據，因此只適合在嚴格控管下進行後續研究。

**若要推進需要：**
- 取得香港仿單的警語與禁忌症資料，完成安全性篩選。
- 設計現代化、樣本數足夠的隨機對照試驗，聚焦經期相關頭痛或偏頭痛的短期用藥。
- 制定使用期限與用量上限，並監測腎功能、腸胃道症狀與藥物過度使用型頭痛。
- 補充詳細的作用機轉資料。
