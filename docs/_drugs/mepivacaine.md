# Mepivacaine：從局部麻醉到胃十二指腸炎

## 一句話總結

Mepivacaine 是醯胺類局部麻醉藥，香港目前有 2 張已上市的注射劑許可證。
TxGNN 模型預測它可能對**胃十二指腸炎 (Gastroduodenitis)** 有效，但目前**沒有任何臨床試驗或相關文獻**支持，僅為模型預測（證據等級 L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Mepivacaine 是醯胺類局部麻醉藥，作用是阻斷電壓門控鈉離子通道，其局部麻醉效果已被廣泛使用。

**這個預測在機轉上並不成立。**
- 鈉離子通道阻斷與胃十二指腸黏膜發炎之間，目前沒有已建立的機轉連結。
- 即使有效，也頂多是對發炎黏膜的症狀性緩解（例如局部表面麻醉），不是改善疾病本身。
- 0.995 的高分只是模型運算結果，無法對照已知藥理驗證，很可能是藥物資料稀疏造成的假象。

另一個預測適應症**消化性潰瘍 (Peptic Ulcer Disease，分數 99.41%)** 也是同樣情況。Mepivacaine 對胃酸分泌、黏膜防禦和幽門螺旋桿菌都沒有已知作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗、文獻或合理的機轉支持，屬於 L5。
- 香港仿單的警語與禁忌資料尚未取得，無法進行安全性初篩。

**若要推進需要：**
- 從香港衛生署網站下載並解析仿單，補齊警語與禁忌症。
- 透過 DrugBank 補齊作用機轉 (MOA) 資料，重新評估機轉連結。
- 補做針對胃十二指腸炎與 Mepivacaine 的文獻檢索。若仍無證據，建議放棄此方向。
- 確認給藥途徑相容性：目前許可證皆為注射劑，而胃腸道疾病通常需要口服或局部黏膜給藥，兩者是否相容尚未評估。
