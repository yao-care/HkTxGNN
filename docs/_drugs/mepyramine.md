# Mepyramine：從過敏性鼻炎與蕁麻疹到過敏性蕁麻疹

## 一句話總結

Mepyramine 是第一代 H1 組織胺受體拮抗劑，原本用於過敏性鼻炎、蕁麻疹、血管性水腫等過敏性疾病。
TxGNN 模型預測它可能對**過敏性蕁麻疹 (Allergic Urticaria)** 有效，但目前**沒有任何臨床試驗**，僅有 **4 篇間接文獻**（多為前臨床研究，另有 1 篇犬隻血管性水腫研究）。此預測與既有適應症高度重疊，並非嚴格意義上的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA）。依已知資訊，Mepyramine 屬第一代 H1 受體拮抗劑，透過阻斷週邊 H1 受體，減緩組織胺引起的過敏反應。

過敏性蕁麻疹的核心機轉是肥大細胞釋放組織胺，因此 H1 拮抗在機轉上高度吻合。不過，蕁麻疹和血管性水腫本來就是 Mepyramine 的既有適應症，這項預測較像是對現有用途的重述，而非真正的藥物再利用。

現有文獻也只能提供間接支持：包括犬隻血管性水腫研究，以及 KCNQ/M 通道、神經傷害感受器鈉通道、H1 配體結合動力學等前臨床研究，並無人體直接證據。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（非仿單內容）：高血壓、肝衰竭、癲癇、慢性阻塞性肺病、腎臟疾病、胰臟炎、甲狀腺功能低下、消化性潰瘍、發炎性腸道疾病、糖尿病、良性攝護腺增生、冠狀動脈疾病、心肌梗塞等。
- **藥物交互作用**：共查得 100 筆，以下為主要項目：
  - **重度（Major）**：氯化鉀 (Potassium chloride)、檸檬酸鉀 (Potassium citrate)
  - **中度（Moderate）**：抗膽鹼類藥物（Atropine、Hyoscyamine、Scopolamine、Glycopyrronium、Dicyclomine 等）、鴉片類（Morphine、Opium）、Loperamide、Metoclopramide、Dronabinol、Eluxadoline

正式的警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測與既有適應症（蕁麻疹、血管性水腫）高度重疊，缺乏人體臨床試驗，現有文獻多為前臨床或獸醫研究，證據等級僅為 L4。
- 仿單的警語與禁忌資料缺口屬阻擋性，目前無法進入安全性篩選。

**若要推進需要：**
- 取得並解析香港衛生署的仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉（MOA）資料
- 確認各許可證的核准適應症，釐清是否已涵蓋過敏性蕁麻疹，以判斷是否仍具再利用價值
- 若要進一步評估，需有人體臨床研究，並與第二代抗組織胺比較
