# Methoxsalen：從（原適應症資料未提供）到局限性佩吉特樣網狀細胞增生症

## 一句話總結

Methoxsalen（甲氧沙林）是一種光敏劑，在香港有外用塗劑與錠劑兩種上市產品，但本次資料中沒有原適應症的文字。
TxGNN 模型預測它可能對**局限性佩吉特樣網狀細胞增生症 (Localized Pagetoid Reticulosis)** 有效，
但這項預測目前**沒有臨床試驗，也沒有文獻**支持，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Methoxsalen 是光化學療法（PUVA、體外光分離術）中使用的光敏劑。在 UVA 照射下，它會造成 DNA 交聯，並誘導惡性皮膚歸巢 T 細胞凋亡，也可能有免疫調節作用。

局限性佩吉特樣網狀細胞增生症是惰性皮膚 T 細胞淋巴瘤（蕈狀肉芽腫譜系）的一種變異型。以上機轉與這類疾病的生物學相符，所以預測在生物學上說得通。

但要注意，這個合理性來自模型預測和一般藥理知識，並非本次提供的臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高，機轉上也說得通，但這項預測沒有任何臨床試驗或文獻佐證，證據等級只有 L5。
- 香港仿單的警語與禁忌資料缺失，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症，並確認兩張許可證的核准適應症。
- 補齊 DrugBank 的作用機轉資料。
- 檢索 methoxsalen/PUVA 用於佩吉特樣網狀細胞增生症的病例報告與研究。
- 優先評估排名第 2 的「惰性原發性皮膚 T 細胞淋巴瘤」，它已有間接文獻，可先做系統性文獻回顧，確認 methoxsalen 相關證據。
- 確認給藥途徑與光照條件是否與預測適應症相容，目前這部分尚未評估。
