# Methoxsalen：從皮膚 T 細胞淋巴瘤到局限性類佩吉特網狀細胞增生症

## 一句話總結

Methoxsalen（甲氧沙林）原本用於原發性皮膚 T 細胞淋巴瘤與白斑症（vitiligo）。
TxGNN 模型預測它可能對**局限性類佩吉特網狀細胞增生症 (Localized Pagetoid Reticulosis)** 有效。
目前**沒有臨床試驗與文獻**直接支持此預測，僅有來自上位疾病（皮膚 T 細胞淋巴瘤）的間接推論。

## 為什麼這個預測合理？

局限性類佩吉特網狀細胞增生症（Woringer-Kolopp 病）是原發性皮膚 T 細胞淋巴瘤中進展緩慢、侵犯表皮的亞型。Methoxsalen 已被用於皮膚 T 細胞淋巴瘤，包括口服 PUVA（補骨脂素加 UVA）以及體外光分離術（extracorporeal photopheresis）中的光敏劑。

其生物學邏輯是：Methoxsalen 經 UVA 活化後，使 DNA 產生交聯，誘導惡性表皮親和性 T 細胞凋亡。因此，對這類病灶位於表皮的 T 細胞淋巴瘤，機轉上合理。

目前缺乏詳細的作用機轉資料（資料庫中 MOA 欄位空缺）。上述推論來自藥物已知的光化學特性與上位疾病類別，並非直接證據。此外，此新適應症與原適應症高度重疊，屬於同一疾病家族，再利用的創新性有限。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜，非仿單內容）：
  - 光敏感相關：光敏感性疾病、光誘發性癲癇反應
  - 紫質症類：紫質症、遲發性皮膚紫質症、混合型紫質症、紅血球生成性原紫質症等
  - 皮膚癌與腫瘤：黑色素瘤、基底細胞癌、鱗狀細胞癌、皮脂腺腺癌、汗腺癌等
  - DNA 修復或色素異常：著色性乾皮症、白化症、Waardenburg 症候群、斑駁病、Griscelli 症候群
  - 其他：肝病、膽囊疾病、系統性紅斑性狼瘡（含兒童型）、過氧化體生成異常疾病
- **藥物交互作用**：資料庫共查得 100 筆，以下為部分中度（Moderate）交互作用：
  - 抗生素：Doxycycline、Tetracycline、Minocycline、Levofloxacin
  - 降血糖藥（磺醯脲類）：Glimepiride、Glipizide、Glyburide、Chlorpropamide、Tolbutamide
  - 其他：Sulfasalazine、Promethazine、Ibuprofen、Flurbiprofen、Alosetron

香港仿單的警語與禁忌資料尚未取得，完整安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測雖分數極高（99.97%），但沒有任何直接的臨床試驗或文獻，僅為機轉推論；且屬於已核准適應症（皮膚 T 細胞淋巴瘤）的亞型，再利用價值有限。
- 目前缺少香港仿單的警語與禁忌資料，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與核准適應症
- 補充 Methoxsalen 的作用機轉資料（DrugBank）
- 搜尋局限性類佩吉特網狀細胞增生症使用 PUVA 或體外光分離術的病例報告與回顧
- 確認劑型與給藥途徑是否適用於此疾病（目前路徑相容性尚未評估）
- 針對皮膚癌風險、肝病與光敏感性等禁忌疾病訂定篩選與監測計畫

**其他預測的補充說明：**
後三項預測（成熟 B 細胞腫瘤、小腸 Burkitt 淋巴瘤、甲狀腺 MALT 淋巴瘤）皆無任何臨床證據，為 L5 等級，建議 Hold。其中小腸與甲狀腺病灶位於深部組織，UVA 光無法到達，機轉上不合理，高分可能僅反映圖譜上與淋巴瘤節點的鄰近性。
