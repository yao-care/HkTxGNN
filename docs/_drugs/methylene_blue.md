# Methylene Blue：從高鐵血紅素血症到支氣管炎

## 一句話總結

Methylene Blue（亞甲藍）原本用於治療高鐵血紅素血症（methemoglobinemia）與硫血紅素血症（sulfhemoglobinemia）。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗**，檢索到的文獻也**沒有直接支持治療用途的證據**，屬於僅有模型預測的階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥理學背景，亞甲藍可抑制一氧化氮合成酶（NOS）與鳥苷酸環化酶，並具有氧化還原循環特性，理論上可能影響呼吸道發炎或氧化壓力。

然而，檢索到的文獻**並未驗證**這個假設。這些文獻多半是將亞甲藍當作染色劑的診斷研究（如支氣管鏡染色），或是與亞甲藍無關的研究（植物精油、生物感測器、β 受體阻斷劑、心內膜炎個案）。這個關聯較可能是關鍵字檢索造成的假象，而非治療證據。

**其他預測適應症的補充說明：**
- **α 型高鐵血紅素血症**（分數 99.36%，證據 L4）：亞甲藍本身就是高鐵血紅素血症的核准用藥，並非新的再利用機會。且 α 型（如血紅素 M 變異）結構上抗還原，亞甲藍效果可能有限。檢索到的唯一文獻是蛋白質構象的生物物理研究，並非臨床證據。
- **因高鐵血紅素還原酶缺乏所致的高鐵血紅素血症**（分數 99.36%，證據 L4）：機轉合理，口服亞甲藍可用於先天性高鐵血紅素血症的長期管理，有犬隻病例與歷史人類個案報告支持。但這與原適應症高度重疊，需確認是否屬於獨立且有正式依據的適應症。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（來自 TxGNN 知識圖譜，非仿單文字，僅供參考）：

  - 肝腎：肝衰竭、肝病、肝硬化、腎臟疾病、膿尿輸尿管
  - 血液：G6PD 缺乏症、貧血、巨球性貧血、凝血疾病、血友病
  - 代謝：糖尿病、糖尿病酮酸中毒、肝醣儲積症、胱胺酸尿症、半乳糖血症、高血鈣、腎鈣質沉著症、磷代謝疾病
  - 其他：胃炎、膽囊疾病、良性攝護腺增生、重症肌無力、神經肌肉接合部疾病
- **藥物交互作用**：已查得 100 筆交互作用，以下為部分主要項目：

  - 其中多數為血清素類或擬交感神經類藥物，實際風險請參考完整交互作用資料與仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎的預測分數雖高（99.97%），但沒有臨床試驗，文獻也沒有治療證據，僅屬 L5 的模型預測，且關聯可能是檢索假象。
- 另外兩項預測落在高鐵血紅素血症範圍，與原適應症重疊，不構成新的再利用機會。

**若要推進需要：**
- 取得亞甲藍在呼吸道發炎或氧化壓力方面的機轉資料與前臨床研究（如 NOS/鳥苷酸環化酶途徑）
- 補齊 DrugBank 的作用機轉資料
- 取得香港仿單，確認核准適應症、警語與禁忌
- 若評估先天性高鐵血紅素血症（還原酶缺乏型），需釐清其是否屬於現有核准適應症的延伸
- 針對高 DDI 風險（特別是血清素症候群風險）與 G6PD 缺乏症等族群，建立安全性監測計畫
