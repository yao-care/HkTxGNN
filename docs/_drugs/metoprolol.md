# Metoprolol：從高血壓相關心血管適應症到惡性腎血管性高血壓

## 一句話總結

Metoprolol 是 beta-1 選擇性阻斷劑，為已上市的降血壓與心血管藥物。
TxGNN 模型預測它可能對**惡性腎血管性高血壓 (Malignant Renovascular Hypertension)** 有效，
但目前**沒有臨床試驗**，且僅有 **2 篇**與該疾病關聯薄弱的文獻，屬於僅有模型預測的階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank MOA 尚未取得）。依已知藥理特性，Metoprolol 是 beta-1 選擇性阻斷劑，可降低血壓並抑制腎素釋放，因此對腎素驅動型高血壓在機轉上有其合理性。

不過，Metoprolol 本身已是上市的降血壓藥物，這個預測較像是既有用途的「亞型」，而不是真正的新用途。模型分數雖高（0.999），但僅為預測，沒有試驗或直接文獻支持這個特定疾病。

## 安全性考量

安全性資訊請參考原廠仿單。

補充：Beta 阻斷劑在肺高壓與右心衰竭情境下通常需謹慎使用，但這與本預測的疾病（腎血管性高血壓）無直接關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測（L5），無臨床試驗，文獻與疾病及藥物皆無直接關聯。
- 此預測本質上是既有降血壓用途的亞型，新增價值有限。

**若要推進需要：**
- 取得香港衛生署仿單的核准適應症、警語與禁忌症
- 補齊 DrugBank 的作用機轉資料
- 確認 Metoprolol 在腎血管性或惡性高血壓的既有指引與臨床證據
- 搜尋該疾病亞型的專屬臨床研究
