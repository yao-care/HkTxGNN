# Metyrapone：從（許可證未載明原適應症）到運動誘發性惡性高熱

## 一句話總結

Metyrapone 是一種類固醇 11-β 羥化酶（CYP11B1）抑制劑，可減少皮質醇合成，在香港已有 1 張上市許可證，但許可證上沒有登載適應症。
TxGNN 模型預測它可能對**運動誘發性惡性高熱 (Exercise-induced Malignant Hyperthermia)** 有效。
目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測，也找不到機轉上的合理連結。

## 為什麼這個預測合理？

**目前看不出合理的機轉連結。** Metyrapone 抑制 CYP11B1，減少皮質醇合成。惡性高熱與運動誘發的熱相關疾病，主要由 RYR1 介導的骨骼肌鈣離子釋放失調所致。Metyrapone 對 RYR1 鈣釋放沒有已知作用。

分數高達 99.95%，較可能反映知識圖譜中的鄰近關係，例如共享的基因或表型鄰居，而不是經過驗證的藥理路徑。資料包中也缺少藥物原本的作用機轉資料，因此更難做機轉層面的解讀。

同一批預測中的其他適應症，都落在 RYR1 相關肌肉疾病這個群集：

- 惡性高熱易感性（分數 99.82%）
- King-Denborough 症候群（99.77%）
- 中央核心肌病（99.72%）
- 中度多微小核心病伴手部受累（99.72%）

這些疾病同樣沒有臨床試驗或文獻支持，機轉上也與 metyrapone 無關。這種群集現象進一步顯示，預測來自疾病間的圖譜相似性，而非藥物本身的生物學。

臨床上還有一項疑慮：metyrapone 可能在生理壓力下造成腎上腺功能不足，用於運動或熱壓力相關情境時風險特別值得注意。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有任何臨床試驗或文獻（證據等級 L5，停留在 S0 階段）。
- 機轉上，metyrapone 的 CYP11B1 抑制與 RYR1 相關的鈣失調沒有已知連結，且有腎上腺功能不足的安全疑慮，目前不建議推進。

**若要推進需要：**
- 取得香港衛生署仿單，確認原適應症、警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料，重新評估機轉連結。
- 檢索是否有 metyrapone 與惡性高熱、RYR1 或相關肌病的前臨床或機轉研究。若找不到，預測可視為圖譜假象。
- 若後續出現生物學證據，再評估腎上腺功能不足風險與給藥途徑的相容性。
