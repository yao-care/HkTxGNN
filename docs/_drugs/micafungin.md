# Micafungin：從（原適應症資料缺漏）到泌尿道感染

## 一句話總結

Micafungin 是一種靜脈注射抗黴菌藥，在香港以 MYCAMINE 品名上市，但許可證資料中沒有記載原適應症。
TxGNN 模型預測它可能對**泌尿道感染 (Urinary Tract Infection)**（文獻內容多為念珠菌泌尿道感染）有效，
目前有 **0 個臨床試驗**和 **12 篇文獻**（以病例報告與病例系列為主）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Micafungin 屬於抗黴菌藥物（文獻中被歸為 echinocandin 類），對多種念珠菌（包括部分對 fluconazole 有抗藥性的菌種）具殺菌活性。

文獻顯示，泌尿道中的念珠菌感染（念珠菌尿）治療選擇有限。傳統藥物如 fluconazole、amphotericin B 與 flucytosine，遇到 *C. krusei*、*C. glabrata* 等菌種時常因抗藥性或副作用而受限。Micafungin 在這些情境下被用作替代選擇。

不過需要留意：echinocandin 類的尿液排泄率偏低，過去並不被常規建議用於泌尿道感染。有病例報告指出，尿液中的 micafungin 濃度仍可能足以治療，但這仍屬初步觀察，而非確立的療效。此外，預測的「泌尿道感染」實際上限於真菌（念珠菌）感染，不涵蓋一般細菌性泌尿道感染。

## 結論與下一步

**決策：Hold**

**理由：**
現有證據以病例報告、病例系列和小型觀察性研究為主，沒有臨床試驗，也沒有 RCT。加上 echinocandin 尿中濃度偏低，指引也不建議常規用於念珠菌尿，療效尚未確立。香港許可證的適應症與安全性資料也都缺漏，目前無法進行安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊核准適應症、警語與禁忌症（目前為阻斷性資料缺口）
- 補充 micafungin 的作用機轉資料（例如查詢 DrugBank）
- 完成文獻的研究類型分級與相關性判讀
- 針對念珠菌泌尿道感染的族群（如 fluconazole 抗藥菌種、肝功能不全者）設計前瞻性研究，並驗證尿中藥物濃度與臨床療效的關係
- 釐清預測適應症的範圍（僅念珠菌性，而非一般泌尿道感染）

> 本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。
