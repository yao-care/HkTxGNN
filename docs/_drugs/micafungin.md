# Micafungin：從食道念珠菌症到泌尿道感染

## 一句話總結

Micafungin 是一種棘白菌素（echinocandin）類抗黴菌藥，原本用於食道念珠菌症、念珠菌血症及侵襲性（散播性）念珠菌症。
TxGNN 模型預測它可能對**泌尿道感染 (Urinary Tract Infection)**（主要為念珠菌引起的尿路感染）有效，
目前有 **0 個臨床試驗**和 **12 篇文獻**，多為病例報告與回溯性研究。

## 為什麼這個預測合理？

Micafungin 屬於棘白菌素類，作用是抑制 1,3-β-D-葡聚醣合成酶，破壞黴菌細胞壁的合成。這段機轉說明來自藥物類別的一般知識，並非本報告所整理的資料欄位內容；該藥的原始作用機轉資料目前缺乏。

念珠菌是黴菌性泌尿道感染（念珠菌尿）的主要病原，而 micafungin 對念珠菌的活性已透過其原適應症獲得證實，因此將其用於念珠菌性泌尿道感染在機轉上合理。

過去普遍認為棘白菌素經尿液排泄量低，不適合治療尿路感染。不過有一項藥物動力學研究（PMID 27424599）指出，micafungin 的尿中濃度足以治療念珠菌引起的尿路感染。多個病例系列與回溯性世代研究也報告了念珠菌尿的清除，與此機轉推論一致。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉合理，且有藥動學研究與數個回溯性世代、病例系列支持，但缺乏臨床試驗與 RCT，證據停留在 L3。此外，念珠菌尿路感染的尿中濃度與臨床療效證據仍有限，且知識圖譜把腎臟疾病列為禁忌，需先釐清安全性。

**若要推進需要：**
- 取得香港仿單的警語與禁忌症，完成安全性篩選
- 補充作用機轉資料（DrugBank）
- 針對念珠菌性泌尿道感染設計前瞻性研究，或系統性回顧現有世代與病例資料
- 評估腎功能不全患者（此族群常見念珠菌尿）的使用風險與劑量
- 確認香港許可證核准適應症是否涵蓋此用途，以釐清屬於適應症外使用的法規考量
