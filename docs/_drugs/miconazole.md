# Miconazole：從局部抗黴菌治療到痤瘡

## 一句話總結

Miconazole 是咪唑類（azole）抗黴菌藥，香港已有多張外用乳膏許可證。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，
目前僅有 **1 個臨床試驗**（相關性低）和 **4 篇文獻**，其中多為體外或間接證據，直接臨床證據不足。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Miconazole 是咪唑類抗黴菌藥，其抗黴菌療效已被廣泛使用，機轉上可能適用於痤瘡。

文獻提供了幾個間接線索：
- 體外研究顯示，azole 類抗黴菌藥對痤瘡丙酸桿菌（*Propionibacterium acnes*，痤瘡的致病菌之一）有抑制活性（PMID 20045949）。
- 一篇綜述討論 Miconazole 在皮膚疾病上的多面向作用（PMID 18627330），可能包含抗菌與抗發炎，但摘要並未明確證實。
- 抗黴菌治療可用於 Malassezia（Pityrosporum）毛囊炎（PMID 8593718）。這種病常被誤診為痤瘡，但它是**不同的疾病**，不能當作痤瘡的直接證據。

TxGNN 的高分是電腦模型預測，尚未有 Miconazole 用於尋常性痤瘡的直接臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅 L4：唯一的臨床試驗相關性低且已暫停，其餘為體外研究、綜述與不同疾病的研究，尚無 Miconazole 用於尋常性痤瘡的直接臨床證據。
- 目前屬於研究問題階段（S0）。香港仿單的警語與禁忌尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症資料
- 補充 Miconazole 的作用機轉資料（如查詢 DrugBank）
- 到 ClinicalTrials.gov 核對 NCT01244256 的介入措施與病況，確認是否含 Miconazole
- 檢索 Miconazole 單一成分用於尋常性痤瘡的臨床試驗，特別是對照試驗
- 確認外用劑型與痤瘡治療的給藥途徑是否相容
- 補上原適應症資料（目前許可證未附核准適應症文字）
