## Miconazole: 痤瘡 (acne (disease))
{: .text-alpha }

## 一句話總結

Miconazole 是咪唑類（imidazole）抗黴菌藥，在香港以外用乳膏及陰道劑型上市。
TxGNN 模型預測它可能對**痤瘡 (acne (disease))** 有效，
目前**無臨床試驗**，僅有 **4 篇文獻**（1 篇綜述、1 篇split-face 臨床研究、1 篇相關疾病治療試驗、1 篇體外研究）提供間接線索，證據等級為 **L4**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位未收錄）。依已知的藥物類別機轉，Miconazole 屬咪唑類抗黴菌藥，透過抑制 CYP51（羊毛固醇 14-α-去甲基酶）阻斷黴菌麥角固醇合成。

與痤瘡的關聯可從三方面推論：
1. 體外研究顯示唑類抗黴菌藥對痤瘡丙酸桿菌（*Cutibacterium / Propionibacterium acnes*）具抗菌活性（PMID 20045949）。
2. Miconazole 對馬拉色菌（*Malassezia*，又稱 Pityrosporum）有效；馬拉色菌毛囊炎在臨床上常被誤認為痤瘡（PMID 8593718）。
3. 已有文獻提到 Miconazole 在皮膚上可能具抗發炎作用，或有助於發炎性皮疹（PMID 18627330、15536660）。

需注意：以上為依藥物類別所作的合理推論，並非藥物專屬的已驗證機轉。TxGNN 分數是計算模型的預測，不能取代臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何針對痤瘡的臨床試驗，文獻僅為綜述、體外研究、小型臨床研究及相關疾病（馬拉色菌毛囊炎）的資料，缺乏直接證據，證據等級為 L4。
- 高分 TxGNN 預測（0.9954）僅屬計算結果，現階段適合作為研究問題而非臨床推進。

**若要推進需要：**
- 取得 Miconazole 的作用機轉資料及香港仿單中的警語與禁忌症
- 設計針對痤瘡（區分馬拉色菌毛囊炎）的對照試驗，評估外用 Miconazole 的療效與安全性
- 釐清抗菌與抗發炎作用在痤瘡病灶的實際貢獻
- 評估外用劑型的皮膚耐受性及與併用藥物的交互作用
