# Midecamycin：從細菌感染到念珠菌症

## 一句話總結

Midecamycin 是一種大環內酯類（macrolide）抗生素，在香港以膠囊劑上市，但許可證資料未載明核准適應症。
TxGNN 模型預測它可能對**念珠菌症 (Candidiasis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Midecamycin 屬於 16 元環大環內酯類抗生素，一般認為是透過結合細菌 50S 核糖體亞單位、抑制蛋白質合成而發揮抗菌作用。

**這個預測的合理性偏低。** 大環內酯類並非已確立的抗黴菌藥物，念珠菌是真菌，與細菌的核糖體標的不同，機轉上找不到直接關聯。0.99 的高分較可能反映知識圖譜中「抗感染藥物」鄰近節點的相似性，而不是真實的抗黴菌效果。

TxGNN 前 10 名預測中，**痲瘋病 (Leprosy)** 在生物學上最合理。部分大環內酯類（如 clarithromycin）對痲瘋桿菌有活性，midecamycin 的核糖體結合機轉相同。但這只是類別層級的假說，沒有 midecamycin 本身的資料，需要先有體外或動物的藥敏數據。

其餘預測多半缺乏合理機轉，可能是圖譜假象：
- **冠狀動脈疾病、心肌缺血：** 只有間接的免疫調節或感染假說。
- **肺囊蟲症：** 病原是真菌，大環內酯類不是既定療法。
- **息肉類疾病**（聲帶、子宮、中耳、額竇）：可能來自圖譜中息肉類疾病節點的聚集。
- **左冠狀動脈異常起源於肺動脈：** 這是先天結構異常，靠手術治療，很可能是偽陽性。

## 結論與下一步

**決策：Hold**

**理由：**
- 念珠菌症預測只有模型分數，沒有任何試驗或文獻，證據等級為 L5。
- 大環內酯類機轉上與抗黴菌沒有直接關聯，高分很可能只是圖譜鄰近性造成的訊號。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊核准適應症、警語與禁忌症。
- 補齊 midecamycin 的作用機轉資料（可查 DrugBank）。
- 若要探索，優先改追**痲瘋病**方向：先做 midecamycin 對痲瘋桿菌的體外或動物藥敏研究。
- 若仍要探索念珠菌症，需先有體外抗黴菌活性數據。
