# Milrinone：從心衰竭到禿髮（Alopecia）

## 一句話總結

Milrinone 是一種 PDE3 抑制劑注射劑，原本用於急性心衰竭的強心治療。
TxGNN 模型預測它可能對**禿髮 (Alopecia)** 有效，但目前**沒有臨床試驗**，也**沒有相關文獻**支持，僅屬模型預測。
另有一個次要候選方向：**頭痛疾患 (Headache Disorder)**，有 4 篇病例報告或病例系列，涉及可逆性腦血管收縮症候群 (RCVS)。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥理資料，Milrinone 會作用於 PDE3A、PDE3B，也與 PDE2A、PDE5A 有關聯。PDE3 抑制會使細胞內 cAMP 上升，產生強心與血管擴張作用。

禿髮方面，一種假設是血管擴張與 cAMP 相關訊號可能影響毛囊，類似 minoxidil 等血管擴張劑。**這只是推測**，現有資料中沒有任何證據支持。0.999 的高分只是模型預測，可能反映知識圖譜中與其他毛髮疾病的關聯性，不代表已驗證的機轉。

同一批預測中的其他毛髮相關疾病（局部頭皮毛髮稀少症、先天性毛髮稀少伴粟丘疹、瀰漫性圓禿）同樣沒有試驗與文獻支持。圓禿屬自體免疫疾病，PDE4 抑制與免疫調節有關，但 Milrinone 是 PDE3 抑制劑，兩者之間沒有資料連結。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜，並非仿單內容）：腎臟疾病、低血壓、心肌梗塞、冠狀動脈血栓、血紅素病變、心搏驟停、心臟傳導疾病、肺動脈瓣狹窄、肥厚性心肌病（含家族性）等。
- **藥物交互作用**：資料庫共有 9 筆。其中 5 筆為中度等級，涉及 Amifostine、Diatrizoate、Anagrelide、Ozanimod、Procarbazine。其餘為藥理標靶關聯（PDE2A、PDE3A、PDE3B、PDE5A）。
- 仿單的警語與禁忌資料目前缺乏，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 禿髮及相關毛髮疾病的預測僅來自模型，沒有任何試驗或文獻，證據等級為 L5。
- 次要方向（RCVS 相關頭痛）有個案層級的證據，機轉上合理，但屬間接證據。該方向適合列為研究問題，不宜直接推進。

**若要推進需要：**
- 取得 Milrinone 的完整作用機轉資料，並建立與毛囊或皮膚生物學的實質連結。
- 取得香港仿單的警語、禁忌與核准適應症。
- 針對禿髮進行前臨床研究，並評估給藥途徑的可行性。Milrinone 目前僅有注射劑型，用於局部或毛髮治療的適用性尚未評估。
- 若轉向 RCVS，需系統性回顧文獻，並評估低血壓與心律不整風險及 DDI 管理。
