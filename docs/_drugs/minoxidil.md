# Minoxidil：從高血壓與雄性禿到頭皮單純性毛髮稀少症

## 一句話總結

Minoxidil 原本用於治療高血壓及脫髮（雄性禿）。
TxGNN 模型預測它可能對**頭皮單純性毛髮稀少症 (Hypotrichosis simplex of the scalp)** 有效，
目前**無登記的臨床試驗**，但有 **3 篇文獻**（皆為病例報告）支持這個方向，證據仍屬初步。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位尚未取得）。根據文獻，Minoxidil 的硫酸鹽代謝物可開啟 ATP 敏感性鉀通道，延長毛髮生長期（anagen），並促進毛囊周圍血管擴張與毛囊增生。

頭皮單純性毛髮稀少症是一種罕見的遺傳性毛髮疾病，與 CDSN 基因（編碼角質小體蛋白 corneodesmosin）變異有關，主要表現為毛髮密度與長度不足。Minoxidil 已被廣泛用於雄性禿等毛髮稀疏疾病，在機轉上可能適用於這類以毛髮密度下降為主的疾病。

不過需注意，現有 3 篇文獻皆為病例報告或小型病例系列，且多與生長因子、PRP（富含血小板血漿）或植物萃取物合併使用，無法將療效單獨歸因於 Minoxidil。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜，非仿單文字）：心血管疾病、心肌梗塞、中風與腦血管疾患、姿勢性低血壓、腎臟疾病、嗜鉻細胞瘤、心包膜炎、心包積液與心包填塞、頭皮皮膚病變等。
- **藥物交互作用**：共查得 100 筆，以下為中度（Moderate）交互作用的主要藥物：
  - 皮質類固醇：Hydrocortisone、Prednisone、Prednisolone、Dexamethasone、Betamethasone、Triamcinolone、Budesonide
  - SGLT2 抑制劑：Canagliflozin、Dapagliflozin、Empagliflozin、Ertugliflozin
  - 其他：Bupropion、Morphine、Opium、Dronabinol、Nabilone、Sapropterin

  另有 Calcitriol、Clotrimazole、Metformin 的交互作用等級為未知。

仿單的警語與禁忌資料目前尚未取得，詳細資訊請參考原廠仿單。若考慮口服使用，須特別留意心血管風險（如水份滯留、反射性心搏過速、心包積液）。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數極高（99.99%），機轉上也有合理性，但實際證據僅有 3 篇合併療法的病例報告，無登記臨床試驗，無法判定 Minoxidil 本身的貢獻。
- 仿單安全性資料尚未取得（屬阻斷性資料缺口），目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選
- 補充 DrugBank 的作用機轉（MOA）資料
- 設計 Minoxidil 單藥（外用優先）的對照研究或較大型病例系列，區分其與 PRP、生長因子等合併療法的貢獻
- 評估外用與口服的風險效益，特別是兒童患者的心血管安全性

---

**其他預測適應症的補充說明（供參考）：**
- 瀰漫性斑禿（L4、Research Question）：文獻多為間接證據，Minoxidil 無免疫調節作用，至多作為輔助治療。
- 先天性毛髮稀少伴粟粒疹、Brocq 假性斑禿、肺動脈高壓（皆為 Hold）：缺乏疾病特異性證據，其中疤痕性禿髮因毛囊已遭破壞，預期效果有限；肺動脈高壓則因全身性血管擴張與心包積液風險而需謹慎。
