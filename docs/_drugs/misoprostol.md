# Misoprostol：從（原適應症未登載）到閉經 (Amenorrhea)

## 一句話總結

Misoprostol 是前列腺素 E1 (PGE1) 類似物，已在香港上市，但本次整理的資料中未登載其核准適應症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前**沒有臨床試驗**，僅有 **7 篇文獻**，且文獻多半談的是早期妊娠終止，並非用 misoprostol 治療閉經，直接證據薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Misoprostol 是 PGE1 類似物，能誘發子宮收縮與子宮頸軟化，作用於子宮內膜與子宮肌層，因此與生殖及月經生理在機轉上有合理的關聯。

不過，檢索到的文獻主要是 misoprostol（多與 mifepristone 併用）用於早期妊娠終止及稽留流產處置。在這些情境中，閉經只是妊娠相關的臨床背景，並非治療目標。沒有任何一項研究評估 misoprostol 是否能恢復月經。

因此，99.64% 的 TxGNN 分數屬於計算模型的預測，並未獲得直接臨床證據的支持。

另一個排名較低的預測是「非典型主動脈縮窄」(atypical coarctation of aorta，分數 99.30%，無任何臨床試驗或文獻)。這可能來自 PGE1 類別層級的連結（alprostadil 用於維持新生兒動脈導管通暢），但 misoprostol 為口服／陰道給藥，並無維持導管通暢的用途，且有已知致畸胎風險，機轉依據薄弱、安全性不利，不建議作為優先方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 閉經的預測僅來自模型計算，檢索到的文獻皆為妊娠終止情境，並無 misoprostol 恢復月經的直接證據，也沒有相關臨床試驗。
- 機轉資料不足，且藥物具有致畸胎風險，目前不適合推進。

**若要推進需要：**
- 補齊詳細的作用機轉資料，並釐清 PGE1 類似物如何影響月經週期
- 取得香港仿單的核准適應症、警語與禁忌，完成安全性篩檢
- 以閉經（非妊娠相關）為目標族群，檢索或設計臨床前與臨床研究
- 評估生育年齡女性使用的風險管理計畫（避孕與妊娠排除）
