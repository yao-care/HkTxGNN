# Mitomycin：從細胞毒性化療到胰臟骨巨細胞瘤

## 一句話總結

Mitomycin（DB00305）是傳統廣譜 DNA 交聯型烷化劑，屬細胞毒性化療藥物家族，但本 Evidence Pack 未提供其確切原始適應症與作用機轉資料。TxGNN 模型將其前 5 名預測適應症全部指向**胰臟腫瘤**的不同亞型（骨巨細胞瘤、實質乳突狀癌、混合分化癌、導管內乳突狀黏液性癌、混合導管-內分泌癌），分數集中在 **99.84%–99.86%** 區間。目前僅 1 篇文獻與此群組沾邊、且內容並非藥物治療證據，**零臨床試驗**，證據等級普遍為 **L5**。

## 為什麼這個預測合理？

Evidence Pack 中 `original_moa` 標記為資料缺失，但各候選適應症的 rationale 分析文字一致指出：Mitomycin C 屬 **DNA 交聯型烷化劑**，經生物還原活化後與 DNA 雙股產生交聯，抑制 DNA 複製，是一種廣譜細胞毒性化療藥物，理論上對任何快速分裂的實體腫瘤（包含胰臟腫瘤）都可能有非特異性毒殺作用。

然而值得注意的是，前 5 名預測適應症**全部**落在「胰臟腫瘤」的不同罕見亞型上，且分數幾乎完全相同（差異僅在小數點第 4 位）。分析文字本身也自我警示：這個分數模式更可能反映 **TxGNN 知識圖譜中「胰臟腫瘤」節點群聚（embedding clustering）** 的效應，而非藥物對這些特定罕見亞型有專屬機轉證據。換言之，模型可能是因為「胰臟腫瘤」這個疾病語意群在圖譜中彼此靠近，而非因為 Mitomycin 對骨巨細胞瘤、實質乳突狀癌等罕見亞型有特殊作用機轉。

由於原始適應症與 MOA 兩項關鍵資料皆缺失（對應 `data_gaps` 中的 DG001、DG002），目前無法對機轉合理性做出具信心的判斷。

## 細胞毒性

Mitomycin C 為已知的傳統細胞毒性抗腫瘤抗生素（非標靶、非免疫治療），以下為根據其藥理分類的一般性資訊：

| 項目 | 內容 |
|------|------|
| 細胞毒性分類 | 傳統細胞毒性藥物（DNA 交聯型烷化抗生素） |
| 骨髓抑制風險 | 高（已知具延遲性、累積性骨髓抑制特性；本 Evidence Pack 未提供仿單量化資料） |
| 致吐性分級 | 中度 |
| 監測項目 | CBC（含分類計數）、腎功能（需留意溶血性尿毒症候群風險）、肝功能、肺功能 |
| 處置防護 | 需依細胞毒性藥物處置規範操作 |

詳細劑量調整、確切骨髓抑制發生率與其他仿單警語，請參考原廠仿單的警語與注意事項。

## 結論與下一步

**決策：Hold**

**理由：**
- 5 個預測適應症皆無臨床試驗支持，僅 1 篇文獻且與藥物治療無直接關聯，證據強度不足以支撐任何行動。
- 分數集中群聚於「胰臟腫瘤」語意群，較可能是知識圖譜嵌入相似度效應，而非專屬機轉證據。
- 原始適應症、MOA、仿單警語與禁忌症等關鍵藥物層級資料均缺失（DG001 為 Blocking），安全性初評無法進行。

**若要推進需要：**
- 取得 TFDA／原廠仿單警語與禁忌症資料（DG001，Blocking）
- 確認 Mitomycin 的正式 MOA 與已核准原始適應症（DG002）
- 針對 5 個候選罕見胰臟腫瘤亞型分別檢索是否有更新、更相關的文獻或病例系列
- 評估這些適應症本身的臨床稀有度（如骨巨細胞瘤屬極罕見亞型），確認是否有足夠病人族群支持後續研究
