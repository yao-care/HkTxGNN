# Moclobemide：從（原適應症未登載）到廣場恐懼症

## 一句話總結

Moclobemide 是一種可逆性單胺氧化酶 A 抑制劑（RIMA），香港已有 1 張許可證，但資料中未登載原適應症。
TxGNN 模型預測它可能對**廣場恐懼症 (Agoraphobia)** 有效，
目前有 **0 個臨床試驗登記**，但有 **11 篇文獻**支持這個方向，其中包含 2 篇隨機對照試驗（RCT）。

## 為什麼這個預測合理？

目前缺乏經資料庫標註的詳細作用機轉。根據已知藥理，Moclobemide 是可逆性 MAO-A 抑制劑，
可提高血清素、正腎上腺素與多巴胺濃度。

這些單胺系統與恐慌症及廣場恐懼症的病理有關。
文獻指出，其他 MAO 抑制劑與血清素類抗憂鬱藥已用於焦慮症，
因此機轉上可能適用。需注意，這段機轉連結來自一般藥理知識，並非資料集提供的註解。
TxGNN 分數很高，但那只是模型預測，本身不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
文獻中有 2 篇 RCT 支持 Moclobemide 用於伴廣場恐懼症的恐慌症，但沒有臨床試驗登記，
且缺乏香港仿單的警語與禁忌資料，尚無法進入安全性篩選。目前適合作為研究問題，不宜直接推進。
證據等級 L2 是依現有 RCT 文獻判定，兩篇 RCT 的結論仍需人工確認。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與藥物交互作用
- 補齊原適應症與作用機轉（DrugBank）
- 人工審閱兩篇 RCT，確認療效結果是否針對廣場恐懼症
- 確認劑型與給藥途徑相容性
