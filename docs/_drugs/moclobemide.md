# Moclobemide：從憂鬱症到懼曠症

## 一句話總結

Moclobemide 是一種可逆性選擇性 MAO-A 抑制劑（RIMA），文獻顯示其原本用於憂鬱症治療。
TxGNN 模型預測它可能對**懼曠症 (Agoraphobia)** 有效，
目前雖無登記中的臨床試驗，但有 **12 篇文獻**（含 2 個頭對頭 RCT）支持這個方向。

## 為什麼這個預測合理？

目前缺乏 Moclobemide 的詳細官方作用機轉資料（TFDA 仿單尚未取得，DrugBank MOA 欄位亦為資料缺口）。根據現有文獻，Moclobemide 是可逆性選擇性 MAO-A 抑制劑（RIMA），透過提升突觸間隙中 serotonin、norepinephrine、dopamine 濃度，產生抗憂鬱與抗焦慮/抗恐慌作用。

文獻中多篇回顧（如 PMID 7717094、2248064、8313401）指出，RIMA 類藥物（含 moclobemide、brofaromine）在憂鬱症之外，早期即被用於恐慌症合併懼曠症、社交畏懼症等焦慮相關疾病的治療，顯示其藥理機轉與懼曠症治療之間具有既有的臨床基礎。

更關鍵的是，PMID 10448444 與 10361962 兩篇隨機對照試驗直接以「恐慌症合併懼曠症」患者為對象，比較 moclobemide 與安慰劑/CBT/clomipramine 的療效，顯示此適應症並非單純模型推論，而是有實際臨床試驗數據支持。惟因原始適應症與 MOA 官方資料缺失，機轉關聯性分析仍主要仰賴次級文獻而非仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
有 2 個頭對頭 RCT（PMID 10448444、10361962）直接針對恐慌症合併懼曠症族群評估 moclobemide 療效，加上多篇回顧文獻佐證 RIMA 類藥物的既有臨床使用基礎，證據等級達 L2；但官方安全性與機轉資料仍缺失，尚不足以直接進入安全性初評（S1）。

**若要推進需要：**
- 取得 TFDA/原廠仿單完整警語與禁忌症資料（阻斷性資料缺口 DG001）
- 補齊 DrugBank 作用機轉完整資訊（DG002）
- 因藥物尚未在香港上市，需評估上市申請路徑或以研究用藥方式進行後續臨床試驗
- 建立 MAOI 類藥物特有之飲食限制與 DDI（如與 SSRI、擬交感神經藥物併用風險）查核資料

> 補充：同批 TxGNN 預測還有第 2 名候選「良性陣發性斜頸症（嬰兒）」，因無任何支持性文獻或試驗、機轉不明且嬰兒族群使用 MAOI 有顯著安全疑慮，證據等級僅 L5，建議 **Hold**，不予進一步分析。
