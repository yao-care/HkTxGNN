## Morphine: 肌筋膜疼痛症候群 (myofascial pain syndrome)
{: .text-alpha }

## 一句話總結

Morphine 是 μ 型鴉片受體促效劑，屬於強效鴉片類止痛藥。
TxGNN 模型預測它可能對**肌筋膜疼痛症候群 (myofascial pain syndrome)** 有效，
但目前**沒有直接研究此疾病與 morphine 的臨床試驗或文獻**，證據等級為 L5，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 morphine 是 μ 鴉片受體促效劑，具確立的中樞止痛作用，因此在疼痛類疾病上有表面上的關聯。

然而，肌筋膜疼痛主要屬於周邊、肌肉骨骼性的疼痛，鴉片類藥物並非標準治療。此外，蒐集到的文獻多為間接證據，例如顳顎關節功能障礙的長期鴉片使用評論、脊椎融合術後的肌筋膜浸潤止痛，以及手術期疼痛研究，並未直接檢驗 morphine 治療肌筋膜疼痛症候群。因此，這項預測的機轉支持相當有限。

## 安全性考量

- **藥物交互作用**（共 100 筆交互作用紀錄，以下為部分重大等級）：Fentanyl、Dihydrocodeine、Codeine、Tramadol、Dichloralphenazone、Butalbital、Ethanol、Alprazolam。與其他中樞神經抑制劑、鴉片類或酒精併用，可能加重呼吸抑制與鎮靜。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何研究直接檢驗 morphine 於肌筋膜疼痛症候群，所引用的隨機試驗涉及的是脊椎融合術後疼痛，因此證據等級為 L5，僅為模型預測。
- 肌筋膜疼痛以周邊肌肉骨骼機轉為主，鴉片類並非標準治療，且有依賴與濫用風險。

**若要推進需要：**
- 取得針對肌筋膜疼痛症候群直接評估 morphine 的臨床研究，或先有機轉層面的支持
- 與非鴉片類標準治療比較療效與風險
- 完整的作用機轉資料與仿單警語、禁忌症
- 評估長期使用的依賴、耐受與痛覺過敏風險
