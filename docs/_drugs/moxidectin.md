# Moxidectin：從抗寄生蟲（獸用）到高澱粉酶血症

## 一句話總結

Moxidectin 是巨環內酯類抗寄生蟲藥，目前香港登記的 4 張許可證都是獸用產品（犬心絲蟲預防、貓體內外寄生蟲防治）。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效。
目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Moxidectin 屬於巨環內酯類抗寄生蟲藥，一般認為它作用於無脊椎動物的麩胺酸門控氯離子通道，使寄生蟲麻痺而死。這是文獻上的通則，並非本資料包記錄的 MOA。

高澱粉酶血症是一種實驗室檢驗異常，成因很多（例如胰臟或唾液腺疾病）。現有資料中，沒有任何線索把 Moxidectin 的抗寄生蟲機轉和這個病況連起來，因此**找不到合理的機轉關聯**。

98.06% 的分數只反映知識圖譜的計算結果，不代表生物學上有根據。

同一藥物排名前 10 的預測（包括多囊性高黏滯症候群、先天性無白蛋白血症、葡萄球菌燙傷樣皮膚症候群等）也都是 L5，且都找不到機轉關聯。其中貓泛白血球減少症、水貂阿留申病是獸醫疾病，很可能是圖譜的人為關聯。整體而言，這批預測的可信度偏低。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，沒有臨床試驗與文獻，也找不到機轉上的關聯。
- 香港目前只有獸用產品，沒有人用劑型可供評估。

**若要推進需要：**
- 取得香港衞生署仿單的警語與禁忌資料，這是進入安全性篩選的前提。
- 補齊 DrugBank 的作用機轉資料，重新評估與高澱粉酶血症的機轉關聯。
- 系統性檢索文獻，確認是否存在 Moxidectin 與血清澱粉酶異常的任何研究或安全性訊號。
- 確認人用製劑的取得與適用途徑，因為目前香港只有獸用產品。
