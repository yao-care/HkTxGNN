## Moxidectin：從盤尾絲蟲症到高澱粉酶血症（僅模型預測）
{: .text-alpha }

## 一句話總結

Moxidectin 是一種大環內酯類抗寄生蟲藥，原本用於治療盤尾絲蟲症（onchocerciasis）。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測，機轉上也找不到合理的關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Moxidectin 屬於大環內酯類（macrocyclic lactone），在寄生蟲體內作用於麩胺酸門控氯離子通道，因此對盤尾絲蟲症有效。

然而，高澱粉酶血症是一種實驗室檢驗上的異常發現，並不是有明確抗寄生蟲標的的疾病。原適應症（寄生蟲感染）與新適應症之間沒有明顯的病理或藥理關聯，因此較高的預測分數很可能是知識圖譜運算所產生的假象，而非真實的治療訊號。

同一份預測清單中的其他候選疾病也有類似情形，例如多株性高黏滯症候群、先天性無白蛋白血症、葡萄球菌燙傷樣皮膚症候群、天花（小型變種）感染、貓泛白血球減少症、麥粒腫、血型不合及大泡性膿痂疹。這些疾病的分數同樣在 97.5% 以上，但皆無證據等級高於 L5 的支持，也都缺乏合理的機轉連結，建議均維持 Hold。

## 結論與下一步

**決策：Hold**

**理由：**
- 這只是模型運算出的預測，沒有任何臨床試驗或文獻佐證（證據等級 L5），且高澱粉酶血症屬於檢驗異常，與 Moxidectin 的抗寄生蟲機轉無合理連結。
- 香港僅有動物用藥許可證，安全性資料也不足，目前不適合推進。

**若要推進需要：**
- 補齊 Moxidectin 的作用機轉資料，確認是否存在任何與澱粉酶代謝或胰臟相關的生物學連結
- 取得香港衛生署的仿單，補足警語與禁忌症資料
- 系統性檢索文獻與試驗登記，確認是否有任何相關的前臨床或臨床訊號
- 若上述皆無支持，建議將研究資源轉向與原適應症更接近的寄生蟲相關適應症
