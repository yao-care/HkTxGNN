# Moxifloxacin：從細菌感染（抗菌藥）到高澱粉酶血症

## 一句話總結

Moxifloxacin 是一種氟喹諾酮類（fluoroquinolone）抗菌藥，原本用於細菌感染治療。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Moxifloxacin 屬於氟喹諾酮類抗菌藥，一般認為它抑制細菌 DNA gyrase 與 topoisomerase IV，但這項機轉並未收錄在本次資料中。

高澱粉酶血症是一種實驗室檢驗異常，不是有明確藥物標靶的疾病。抗菌機轉與血中澱粉酶升高之間，目前找不到可信的機轉關聯。0.9998 的分數只代表模型輸出，沒有任何臨床試驗或文獻佐證，因此這個預測的合理性**不足**。

同批預測還有多形性高黏滯症候群、先天性無白蛋白血症、血型不合、癌前血液系統疾病，證據狀況相同，都是 L5、沒有機轉依據，建議也都是 Hold。其中先天性無白蛋白血症有 1 篇病例報告（PMID 32181025），內容是該疾病的反覆低血糖，並未評估 moxifloxacin，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，僅有模型預測，沒有臨床試驗或文獻，也找不到可信的機轉連結。
- 香港仿單的警語與禁忌資料缺失，無法進入安全性篩選。

**若要推進需要：**
- 從 DrugBank 補齊作用機轉（MOA），重新評估機轉關聯。
- 取得香港衛生署仿單，補上警語與禁忌症。
- 搜尋 moxifloxacin 與高澱粉酶血症的直接臨床或藥物安全性文獻，包括胰臟酵素變化的通報。
- 釐清高澱粉酶血症在臨床上是否為可治療的目標，還是僅為實驗室指標。
