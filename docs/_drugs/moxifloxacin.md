# Moxifloxacin：從細菌感染到高澱粉酶血症

## 一句話總結

Moxifloxacin 是一種氟喹諾酮類抗菌藥物，原本用於肺炎、腹膜炎、結膜炎及鼠疫等細菌感染。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Moxifloxacin 屬於氟喹諾酮類，一般認為是抑制細菌的 DNA 旋轉酶 (DNA gyrase) 與拓樸異構酶 IV (topoisomerase IV)，進而殺菌。

高澱粉酶血症本身是一種實驗室檢驗異常，通常繼發於胰臟或唾液腺疾病，並不是一個典型可被藥物直接治療的疾病。抗菌藥物與澱粉酶調控之間，目前看不出合理的機轉連結。

因此，雖然 TxGNN 分數很高，但這只是模型的計算結果，沒有資料支持其生物學上的合理性。此預測應視為待驗證的假說，不宜視為有效訊號。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（來源為知識圖譜，非仿單文字）：
  - 心臟相關：long QT 症候群、尖端扭轉型心室頻脈 (torsades de pointes)、心臟傳導疾病、心因性猝死、心肌缺血、冠狀動脈疾病
  - 神經肌肉相關：重症肌無力、神經肌肉接合部疾病、週邊神經病變、癲癇
  - 肌腱與骨關節相關：肌腱炎、關節周圍炎、骨贅
  - 肝臟相關：肝硬化、藥物性肝損傷
  - 其他：低鉀血症、困難梭狀芽孢桿菌結腸炎、新生兒壞死性腸炎
- **藥物交互作用**：共查得 100 筆，以下為部分例子：
  - 嚴重 (Major)：Hydrocortisone、Dexamethasone、Betamethasone、Triamcinolone（皆為皮質類固醇）、Bupropion、Chlorpropamide
  - 中度 (Moderate)：Metformin、Pioglitazone、Acarbose、Famotidine、Loperamide、Acetylsalicylic acid、含鈣製劑等

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測的新適應症沒有任何臨床試驗或文獻支持，證據等級僅為 L5，且高澱粉酶血症為實驗室異常，並非明確的治療目標。
- 作用機轉資料缺乏，也看不出合理的機轉連結。
- 另外兩項高分預測（多株性高黏滯症候群、先天性無白蛋白血症）同樣缺乏支持證據，沒有更適合轉向的候選。

**若要推進需要：**
- 補齊 Moxifloxacin 的作用機轉資料，並評估與澱粉酶調控之間是否存在生物學關聯。
- 釐清高澱粉酶血症是否為可治療的疾病實體，還是僅屬繼發的檢驗指標。
- 取得香港衛生署的仿單，補齊警語、禁忌與核准適應症。
- 若仍要探索，先以回溯性資料或前臨床研究建立初步訊號，再考慮臨床試驗。
