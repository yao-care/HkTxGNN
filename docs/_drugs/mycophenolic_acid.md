# Mycophenolic Acid：從器官移植抗排斥到血紅素病變（Hemoglobinopathy）

## 一句話總結

Mycophenolic Acid（黴酚酸）是免疫抑制劑，依一般藥理知識，主要用於器官移植後的排斥反應預防。
TxGNN 模型預測它可能對**血紅素病變 (Hemoglobinopathy)** 有效，目前有 **28 個臨床試驗**和 **9 篇文獻**與此方向相關。
但這些證據多半指向移植過程中的輔助角色（預防 GVHD、改善混合嵌合體），不是治療疾病本身。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。依一般藥理知識，Mycophenolic Acid 抑制 IMPDH 酶，阻斷嘌呤的從頭合成，進而抑制淋巴球增生。

在血紅素病變（地中海型貧血、鐮刀型貧血）中，它並不改變疾病本身。它用於異體造血幹細胞移植（allo-HSCT）的 GVHD 預防，或在移植後出現混合嵌合體時加強免疫抑制，以協助植入穩定。

因此 0.996 的高分很可能反映「移植情境」的關聯，而不是對血紅素異常的直接療效。現有證據支持它在移植中的輔助角色，不支持治療底層疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L3，且都是移植情境下的世代研究和藥動學研究，沒有以 MMF 為受試藥物的對照試驗。
- 證據顯示 MMF 在移植中扮演輔助角色，並非血紅素病變的疾病修飾治療，TxGNN 高分不足以支持新適應症。
- 其餘預測適應症（偏頭痛、腦幹先兆偏頭痛、16 號染色體短臂部分缺失、伴其他表現的 β 型地中海型貧血）沒有臨床試驗或文獻支持，均建議 Hold。伴其他表現的 β 型地中海型貧血只是重複計入上述血紅素病變的證據。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌（目前屬阻擋性資料缺口，無法進入安全性篩選）
- 補齊 DrugBank 的作用機轉資料
- 逐一查證上列試驗的 GVHD 預防與預處理方案，確認 MMF 是否為受試介入
- 界定要驗證的問題：是「移植輔助用途」（如混合嵌合體加強免疫抑制），還是「疾病治療」。前者才有現有證據可依循
- 針對孕齡族群與兒童，制定安全性監測計畫

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後方可應用。
