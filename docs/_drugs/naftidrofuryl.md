## Naftidrofuryl: 中風 (stroke disorder)
{: .text-alpha }

## 一句話總結

Naftidrofuryl 是一種血管擴張與細胞代謝調節藥物，原本用於腦血管疾病。
TxGNN 模型預測它可能對**中風 (Stroke Disorder)** 有效，
目前有 **0 個已登記臨床試驗**，但有 **17 篇文獻**（其中約 10 篇與本預測相關度較高）支持這個方向。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據已發表文獻推論，naftidrofuryl 是 5-HT2 受體拮抗劑，具有血管擴張作用，並可增強細胞氧化代謝與 ATP 生成，理論上對腦缺血有保護潛力。這項機轉說明來自文獻推論，並非來自 DrugBank 紀錄。

中風本質上屬於腦血管疾病的急性表現，因此與原適應症關係密切，藥物「轉用」的跨度很小。TxGNN 的高分預測與這種生物學上的接近性一致，但仍僅是模型預測。

需要注意的是，檢索到的文獻中有數篇討論周邊動脈疾病與一般血管擴張劑，只能提供間接支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 中風與原適應症（腦血管疾病）高度接近，且有數項急性／亞急性中風的隨機對照試驗與一篇 Cochrane 回顧，方向合理。
- 但這些試驗年代久遠，我們無法從現有資料確認療效結果，也沒有已登記的臨床試驗，安全性資料與作用機轉資料亦缺漏。證據等級 L1 僅為暫定，須待確認後才能支持推進。

**若要推進需要：**
- 閱讀 Cochrane 回顧（PMID 17443593）及主要 RCT 全文，確認療效、效果量與結論
- 取得香港原廠仿單，補齊警語、禁忌症與核准適應症
- 補充 DrugBank 的作用機轉資料
- 評估這些舊研究與現代中風照護標準的適用性
- 確認是否有進行中的臨床試驗登記
