# Natalizumab：從多發性硬化症用藥到支氣管炎

## 一句話總結

Natalizumab 是阻斷 α4 整合素的單株抗體。文獻中主要用於多發性硬化症（MS），但香港許可證資料未載明適應症。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗，也沒有相關文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未提供）。已知 natalizumab 會阻斷 α4 整合素，限制白血球往組織移動（trafficking）。理論上，這可能減輕氣道發炎，這是模型預測的可能依據。

不過這個機轉連結並未和藥物的核准適應症對應起來。這類免疫抑制機轉本身也與呼吸道感染風險有關，方向可能與治療支氣管炎相反。

0.995 的高分只反映知識圖譜中的關聯，沒有臨床或文獻佐證，不應直接視為療效證據。

## 安全性考量

許可證的警語、禁忌症與藥物交互作用資料尚未取得，請參考原廠仿單。

證據包中的文獻另提示，natalizumab 與**進行性多灶性白質腦病變 (PML)** 相關。也有多篇病例報告指出，它可能誘發或加重乾癬。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎沒有任何臨床試驗或文獻，證據等級僅 L5，只有模型預測。
- 機轉上可能不利：免疫抑制作用與呼吸道感染風險相關，PML 風險也是已知的重大安全議題。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症。
- 補充 DrugBank 的作用機轉資料，釐清 α4 整合素阻斷與氣道發炎的關聯。
- 系統性檢索支氣管炎相關的臨床前與臨床證據，並評估呼吸道感染風險與效益。
- 若要優先評估其他預測，乾癬的文獻最多，但需先釐清「誘發」與「改善」的矛盾方向，並有對照研究支持。
