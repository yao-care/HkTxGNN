# Nebivolol：從降壓藥物類別到惡性腎血管性高血壓

## 一句話總結

Nebivolol 是一種高選擇性 β1-受體阻斷劑，屬於已上市的降壓藥物類別，目前**未在香港上市**。TxGNN 模型預測它可能對**惡性腎血管性高血壓 (Malignant Renovascular Hypertension)** 有效，但目前查無任何專屬於此適應症的臨床試驗或文獻，僅為機轉推論支持的研究假說。

## 為什麼這個預測合理？

Nebivolol 為高選擇性 β1-受體阻斷劑，同時具有內皮 NO 釋放介導的血管擴張作用，屬於已上市的降壓藥物類別。惡性腎血管性高血壓臨床上常以 β-阻斷劑作為合併治療的一環，機轉上具間接合理性：透過降低腎素釋放與心輸出量來控制血壓。

不過，這個關聯性目前僅停留在「藥物類別層級」的機轉推論，本資料集中並未檢索到任何針對 nebivolol 於此特定亞型高血壓的臨床試驗或文獻，屬於 TxGNN 圖譜預測加上藥理類別推論的組合，尚未有直接證據佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- Nebivolol 目前未在香港取得許可證，無法直接評估地區可及性。
- 排序最高的候選適應症（惡性腎血管性高血壓）僅有機轉層級的推論，缺乏任何臨床試驗或文獻直接支持，證據等級為 L4。
- 安全性資料（警語、禁忌症、DDI）與詳細 MOA 均為資料缺口（DG001 為 Blocking 等級，DG002 為 High 等級），尚不足以進入安全性初評。

**若要推進需要：**
- 取得 TFDA/當地藥監局官方仿單，補齊警語與禁忌症資料（DG001）
- 查詢 DrugBank API 補齊完整作用機轉資料（DG002）
- 針對排序 1、2（惡性腎血管性高血壓、惡性高血壓性腎病變）主動檢索是否有 β-阻斷劑於此亞型高血壓的觀察性研究或病例系列
- 若無法找到直接證據，此候選應維持在假說階段，暫緩投入後續資源
