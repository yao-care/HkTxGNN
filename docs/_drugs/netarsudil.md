# Netarsudil：預測新適應症為原發性遺傳性青光眼

## 一句話總結

Netarsudil 是一種 Rho 激酶（ROCK）抑制劑眼藥水，在香港已有 2 張上市許可證。
TxGNN 模型預測它可能對**原發性遺傳性青光眼 (Primary Hereditary Glaucoma)** 有效。
但針對這個亞型，目前只有 **1 個間接相關的臨床試驗**，**沒有文獻**支持。

## 為什麼這個預測合理？

Netarsudil 同時抑制 Rho 激酶（ROCK）和去甲腎上腺素轉運體。抑制 ROCK 會讓小樑網鬆弛，增加房水的傳統外流途徑。它也能降低上鞏膜靜脈壓，並可能減少房水生成。這些作用直接針對降低眼壓的路徑，這也是模型給出高分（99.50%）的可能原因。

不過，遺傳性（先天性或青少年型）青光眼常涉及小樑網或前房角的發育異常。在這種情況下，只靠增強外流的藥物治療，效果可能有限。

目前沒有直接證據支持這個特定亞型，不能從成人開放性青光眼的資料直接推論。此外，香港許可證資料沒有記載原適應症，也缺乏完整的作用機轉資料，因此原適應症與新適應症的關聯無法進一步比對。

## 結論與下一步

**決策：Hold**

**理由：**
針對原發性遺傳性青光眼，目前僅有模型預測，沒有直接的臨床或文獻證據（L5）。唯一登記的試驗研究的是角膜內皮，與此適應症無關。遺傳性青光眼的病理以發育異常為主，增強外流的藥物可能效果有限。

同一份資料中，一般青光眼／高眼壓（預測排名第 2）已有多個已完成的 Phase 3 隨機對照試驗，證據等級為 L1。但這些是成人開放性青光眼的資料，不能直接外推到遺傳性青光眼。另外，這份資料看起來更像是原適應症欄位缺漏，而不是真正的老藥新用。

**若要推進需要：**
- 補齊香港衛生署仿單的核准適應症、警語與禁忌症，確認原適應症
- 補充 DrugBank 的作用機轉資料
- 針對遺傳性／兒童青光眼收集直接證據（例如兒童青光眼的系統性回顧、病例系列或前瞻性研究）
- 若日後評估相關族群，須監測結膜充血、角膜渦狀混濁與淚點狹窄，並區分 netarsudil 單方與 netarsudil/latanoprost 複方
