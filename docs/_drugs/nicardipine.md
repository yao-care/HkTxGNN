# Nicardipine：從（許可證未載明原適應症）到肺高壓（缺氧或肺部疾病所致）

## 一句話總結

Nicardipine 是二氫吡啶類鈣離子通道阻斷劑，香港已有一張注射劑許可證，但許可證未載明核准適應症。
TxGNN 模型預測它可能對**缺氧或肺部疾病所致肺高壓 (Pulmonary hypertension owing to lung disease and/or hypoxia)** 有效。
目前**沒有臨床試驗**，檢索到的文獻也沒有一篇直接討論 nicardipine，因此這項預測只有模型分數支持。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Nicardipine 屬於二氫吡啶類鈣離子通道阻斷劑，透過阻斷血管平滑肌的 L 型鈣離子通道使血管擴張。從藥理上看，肺血管擴張在原則上是合理的。

不過，這個方向有明顯疑慮。在缺氧或肺部疾病相關的肺高壓中，全身性血管擴張劑可能破壞通氣與灌流的配對，使氣體交換惡化。TxGNN 的 0.993 分只是知識圖譜的模型預測，並不代表臨床有效。

模型另外預測了幾個適應症，分數相近，但同樣沒有試驗或文獻支持：

- 不明多因子機轉的肺高壓（99.26%）：病因異質，機轉連結不具特異性。
- 惡性腎血管性高血壓、惡性高血壓腎病（99.13%）：降壓機轉與嚴重高血壓相符，但尚無針對性證據，屬於待查證的研究問題。
- Braddock 症候群（99.03%）：可能只是因肺高壓成分在圖譜中相近而被預測，缺乏機轉依據。

## 結論與下一步

**決策：Hold**

**理由：**
證據等級為 L5，只有模型預測，沒有試驗與相關文獻。缺氧性肺高壓中，全身性血管擴張劑還有惡化氣體交換的機轉疑慮，目前不宜推進。

**若要推進需要：**
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌症
- 補充 DrugBank 的作用機轉資料
- 針對 nicardipine 與肺高壓（含缺氧性肺高壓）做專門的文獻與試驗檢索
- 評估通氣與灌流配對惡化的風險
- 對惡性高血壓相關預測（腎血管性高血壓、高血壓腎病）另做文獻檢索，這是相對較合理的次要方向
