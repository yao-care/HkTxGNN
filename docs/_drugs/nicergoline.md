# Nicergoline：從血管擴張劑到多毛症（Hypertrichosis）

## 一句話總結

Nicergoline（尼麥角林）是麥角衍生的血管擴張劑，在香港以 Sermion 錠劑上市。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，但目前**沒有臨床試驗和文獻**支持，只有模型分數。
這項預測在藥理上也不合理，建議暫緩（Hold）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Nicergoline 屬於麥角衍生的血管擴張劑，但供應資料無法支持它與多毛症之間的機轉連結。

反而有反向的線索：minoxidil 等血管擴張劑與**引起**多毛症有關，而不是治療多毛症。99.57% 的分數只是知識圖譜的推論，沒有任何試驗或文獻佐證，因此不宜當作療效證據。

**BPH 是唯一值得追蹤的方向。** Nicergoline 一般被描述為 α1 腎上腺素受體拮抗劑，與治療 BPH 下泌尿道症狀的藥物屬同一類機轉。但這個說法來自一般藥理知識，不是供應資料，且尚未檢索到任何試驗或文獻，目前只能當作待查證的假設。

**排名 3 的文獻說明：** 系統檢索到 20 篇牙周炎相關文獻（指引、綜述、糖尿病關聯、微生物學等），列出的 10 篇標題都沒有提到 nicergoline。這些文獻反映的是疾病關鍵字，與本藥無關，不列為證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（多毛症）只有模型分數，沒有任何試驗或文獻，且藥理方向可能相反（血管擴張劑與多毛症的因果關係是引起，而非治療）。
- 5 項預測全部停留在 L5，其中只有 BPH 具備合理的藥理假設，可列為後續研究問題。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌症（此為阻斷性資料缺口，未補齊無法進入安全性篩選）。
- 從 DrugBank 取得作用機轉（MOA）資料。
- 針對 BPH 做 nicergoline 的定向文獻與試驗檢索，確認是否有 α1 阻斷相關證據。
- 確認原核准適應症（目前許可證資料皆為空白）。
