## Nicergoline: Hypertrichosis (disease)
{: .text-alpha }

## 一句話總結

Nicergoline 是麥角生物鹼衍生物，具 α1 腎上腺素受體拮抗與血管擴張作用，香港已有 3 張單方許可證，但本次彙整的許可證資料未列出核准適應症文字。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效（預測分數 0.9912）。
目前**無臨床試驗登記**，僅有 **6 篇文獻**，其中直接談及 nicergoline 與偏頭痛的僅有數篇，多為早期前臨床研究或設計不明的臨床報告。

## 為什麼這個預測合理？

目前缺乏經查證的詳細作用機轉資料。根據已知資訊與本次彙整的分析，nicergoline 是麥角衍生物，兼具血清素系統與腎上腺素系統的作用，並有調節腦血管的效果。這與偏頭痛的血管與血清素假說相符。

支持性的研究包括：
- 大鼠實驗模型顯示 nicergoline 可降低腦血管阻力，並影響由 5-HT 引起的腦血管收縮（PMID 2622296）。
- 大鼠腦突觸體研究顯示 nicergoline 為血清素攝取的競爭性抑制劑，與 methysergide 類似（PMID 2625145）。

但這些證據間接、年代久遠且以前臨床為主，只能支持進一步探討，不足以支持臨床建議。

## 結論與下一步

**決策：Hold（列為研究問題）**

**理由：**
- 偏頭痛的直接證據僅有早期前臨床研究與一篇設計不明的 1984 年臨床報告，沒有臨床試驗登記，也沒有可驗證的對照研究。
- 目前的證據只能支持進一步探討，不足以推進；其餘預測新適應症則完全沒有證據支持。

**若要推進需要：**
- 取得 1984 年臨床報告全文，確認研究設計、樣本數與結果。
- 系統性檢索 nicergoline 用於偏頭痛預防的對照試驗，並與現有標準預防用藥比較。
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症。
- 補充作用機轉資料（MOA）與完整安全性評估，特別是麥角類藥物的心血管與纖維化風險。
- 評估偏頭痛使用劑量與現有劑型是否相容。
