# Nilotinib：原適應症資料缺失 → 隆突性皮膚纖維肉瘤 (Dermatofibrosarcoma Protuberans)

## 一句話總結

Evidence Pack 中未提供 Nilotinib 的原始核准適應症與完整作用機轉資料。
TxGNN 模型預測它可能對**隆突性皮膚纖維肉瘤 (Dermatofibrosarcoma Protuberans, DFSP)** 有效，
目前僅有 **1 篇文獻**（回顧性文章）支持，尚無任何臨床試驗登記。

## 為什麼這個預測合理？

目前缺乏 Nilotinib 詳細的作用機轉資料（[Data Gap]）。但根據預測系統提供的機轉關聯分析，Nilotinib 為第二代酪氨酸激酶抑制劑，除了抑制 BCR-ABL 之外，也同時抑制 PDGFR-α/β 與 KIT。

DFSP（隆突性皮膚纖維肉瘤）的腫瘤細胞普遍帶有 COL1A1-PDGFB 融合基因，導致 PDGFR-β 持續性活化，是明確的驅動性致病機轉。這與 Nilotinib 已知的抑制靶點直接對應。

同類藥物 imatinib（同屬 PDGFR 抑制劑）已核准用於 DFSP，顯示這個藥物類別在此適應症上具有 class effect 的生物學合理性。但需注意：本筆資料中沒有任何 Nilotinib 用於 DFSP 的臨床試驗紀錄，僅有 1 篇回顧性文獻，屬於間接的機轉層級證據，尚未經過原始臨床研究驗證。

## 細胞毒性

Nilotinib 屬於標靶型酪氨酸激酶抑制劑（TKI），與傳統細胞毒性化療藥物（如 fluoropyrimidine、platinum 類）機轉不同。Evidence Pack 未提供 DrugBank 分類與毒性資料，細部風險與監測項目請參考原廠仿單的警語與注意事項。

## 安全性考量

## 結論與下一步

**決策：Hold**

**理由：**
現階段僅有機轉層級的間接證據（L4），無任何臨床試驗支持，且藥物在香港未上市。安全性資料（仿單警語、禁忌症）完全缺失且被標記為 Blocking，無法進入 S1 安全性初評。

**若要推進需要：**
- 補齊 TFDA/香港仿單警語與禁忌症資料（DG001，優先級 Blocking）
- 補充完整作用機轉資料，供交叉驗證機轉關聯性（DG002）
- 追蹤是否有 Nilotinib 用於 DFSP 的臨床試驗啟動
- 檢視 imatinib 於 DFSP 的核准資料，作為 class effect 佐證
