# Nintedanib：從非小細胞肺癌／特發性肺纖維化到皮膚纖維肉瘤 (Dermatofibrosarcoma Protuberans)

## 一句話總結

Nintedanib 原本用於非小細胞肺癌與特發性肺纖維化等肺部疾病的治療。
TxGNN 模型預測它可能對**隆突性皮膚纖維肉瘤 (Dermatofibrosarcoma Protuberans, DFSP)** 有效，
但目前**沒有臨床試驗**，僅有 **1 篇綜述文獻**間接支持這個方向，證據仍屬初步階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Nintedanib 是一種多標靶酪胺酸激酶抑制劑，標靶包括 PDGFR-α/β、FGFR1-3 與 VEGFR1-3。其在肺纖維化與肺癌中的療效已被證實，機轉上可能適用於由 PDGFR 訊號驅動的腫瘤。

DFSP 的致病機轉為 COL1A1-PDGFB 融合基因，造成 PDGFR-β 持續性自分泌活化。Nintedanib 能抑制 PDGFR，因此在機轉上具合理性。

但需注意，Imatinib 已是 DFSP 確立的 PDGFR 標靶治療，Nintedanib 的額外價值目前並不明確。此外，現有的支持證據僅為一篇 2018 年關於 PDGFR 小分子抑制劑的綜述，並非針對 Nintedanib 的臨床資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測與一篇間接的綜述文獻，沒有任何 Nintedanib 用於 DFSP 的臨床試驗。
- Imatinib 已是標準的 PDGFR 標靶治療，Nintedanib 的增益價值不明。同時，安全性仿單資料尚未取得。

**若要推進需要：**
- 取得香港衛生署仿單中的警語與禁忌症資料，完成安全性篩選
- 補齊 Nintedanib 的作用機轉資料
- 搜尋 Nintedanib 用於 DFSP 的前臨床或病例報告，並與 Imatinib 比較（含 Imatinib 抗藥或不耐受族群的潛在定位）
- 評估是否有必要設計早期（Phase 2）探索性試驗

**其他預測適應症備註：** 排名 2–10 的預測（如脂肪肉瘤、纖維肉瘤、肌萎縮性側索硬化症等）皆為 L5，僅有模型預測而無試驗或文獻，其中部分（如軸向脊椎干骺端發育不良、ALS 相關項目）在機轉上缺乏明確關聯，建議皆維持 Hold。
