# Norethisterone：從痤瘡與子宮內膜異位症到閉經

## 一句話總結

Norethisterone（炔諾酮）是一種合成黃體素類藥物，原本用於痤瘡、原發性卵巢衰竭、子宮內膜異位症、停經後骨質疏鬆及停經後萎縮性陰道炎等。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，
目前**沒有臨床試驗登記**，有 **20 篇文獻**，但多數是避孕相關的研究，並非直接以閉經為治療目標。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Norethisterone 是合成黃體素，作用於黃體素受體並抑制促性腺激素分泌。臨床上已用於誘發撤退性出血及處理荷爾蒙失衡，因此與閉經在生物學上有合理關聯。

原適應症（子宮內膜異位症、原發性卵巢衰竭、停經後相關症狀）都屬於荷爾蒙調節相關疾病，與閉經的內分泌背景相近。此外，黃體素在閉經的診斷（黃體素挑戰試驗）和成因治療中，本來就是常用工具。

但需注意：現有文獻多半是把 Norethisterone 當作避孕成分（口服、注射、微球製劑），閉經在這些研究中是**副作用或出血型態的結果**，而不是被治療的疾病。因此，0.996 的高分主要是計算預測，很可能反映藥物與月經及內分泌疾病的高度關聯，並不等於療效證據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自藥物－疾病關聯資料，並非仿單原文）：高血壓、癲癇、焦慮症、卟啉症、腎臟疾病、肝臟疾病、膽囊疾病、高血糖／糖尿病、高三酸甘油脂血症、高鈣血症、甲狀腺功能低下、系統性紅斑狼瘡、氣喘、女性乳癌等。
- **藥物交互作用**：共查得 100 筆，以下為部分中度（Moderate）交互作用：

  - GLP-1 類藥物：Albiglutide、Dulaglutide、Exenatide、Lixisenatide
  - 胰島素類：Insulin aspart、degludec、detemir、human 等
  - 其他：Aprepitant、Clotrimazole、Metreleptin、Pramlintide、Prucalopride

其餘警語與禁忌症的仿單內容，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有臨床試驗，文獻也多屬避孕研究，閉經在其中是副作用而非治療目標，證據停留在 L4（機轉合理性與模型預測）。
- 缺乏作用機轉詳細資料與仿單安全性資訊，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌症、適應症）並完成安全性篩選
- 補充 DrugBank 作用機轉資料
- 搜尋以 Norethisterone 治療閉經（如黃體素挑戰試驗、撤退性出血誘發）為主題的臨床研究
- 釐清閉經的類型（原發性／續發性）與目標族群，並評估與現有適應症及劑型的相容性
