## Ofatumumab：從急性淋巴芽細胞白血病到濾泡性淋巴瘤
{: .text-alpha }

## 一句話總結

Ofatumumab 是一種完全人源化的抗 CD20 單株抗體，知識圖譜中記錄的原適應症為急性淋巴芽細胞白血病與 Richter 症候群。
TxGNN 模型預測它可能對**濾泡性淋巴瘤 (Follicular Lymphoma)** 有效，
目前有 **11 個臨床試驗**（本報告列出其中 10 個）和 **20 篇文獻**（本報告列出其中 10 篇）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥物類別，Ofatumumab 是結合 CD20 分子的單株抗體，可透過補體依賴性細胞毒殺（CDC）與抗體依賴性細胞媒介毒殺（ADCC）清除 B 細胞。以下機轉推論來自抗 CD20 抗體的已知特性，而非本次資料中的機轉紀錄。

濾泡性淋巴瘤是 CD20 陽性的 B 細胞惡性腫瘤，與知識圖譜中記錄的 B 細胞來源血液腫瘤共享相同的標靶生物學，因此 TxGNN 給出高分在機轉上說得通。

此外，已有直接針對濾泡性淋巴瘤的臨床研究：在對 rituximab 難治的濾泡性淋巴瘤中，單藥 Ofatumumab 的整體反應率僅約 10–13%，療效有限；在未經治療的族群中則有與化療或單藥併用的 Phase 2 資料。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有多個直接針對濾泡性淋巴瘤的 Phase 2 試驗（含隨機試驗與已發表報告），機轉上也合理。但現有證據以 Phase 2 為主；唯一的 Phase 3 試驗（NCT01077518）提前終止，且目前沒有可確認的已完成 Phase 3 結果，證據等級故定為 L2。
- 在 rituximab 難治族群中單藥反應率偏低，且香港許可證未載明相關適應症，需設定使用邊界。

**若要推進需要：**
- 取得香港仿單，確認核准適應症、警語與禁忌症
- 取得 NCT01077518 的結果與終止原因，釐清 Phase 3 證據
- 補充作用機轉的正式資料
- 與現行標準治療（如 rituximab、obinutuzumab）做定位比較
- 建立感染（含 B 型肝炎再活化）與免疫抑制相關的監測計畫
