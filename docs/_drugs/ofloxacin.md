# Ofloxacin：從細菌感染治療到高澱粉酶血症（預測，證據薄弱）

## 一句話總結

Ofloxacin（DB01165）為 fluoroquinolone 類抗生素，經典用途是治療細菌感染，但本報告目前缺乏完整的原適應症與作用機轉資料。TxGNN 模型對其預測了 5 個新適應症，分數最高者為**高澱粉酶血症 (Hyperamylasemia)**（99.91%），但這 5 個預測均**無臨床試驗支持**，僅 1 項有間接文獻（2 篇），且模型自身的機轉分析都指出生物學關聯薄弱，判定為圖譜雜訊可能性高。

## 為什麼這個預測合理？

目前缺乏 Ofloxacin 詳細的作用機轉資料（MOA 標記為 Data Gap）。根據 Evidence Pack 中的機轉分析文字，Ofloxacin 已知作用為抑制細菌 DNA gyrase / topoisomerase IV，屬抗菌機轉。

高澱粉酶血症多與胰臟、唾液腺病變或腎功能異常相關，與 fluoroquinolone 的抗菌機轉**無已知生物學連結**。模型分析本身即指出，0.999 的高分很可能是知識圖譜中 hub node 或 embedding 相似性造成的偽陽性，而非真實機轉關聯。

其餘 4 個預測適應症（多株性高黏滯症候群、先天性無白蛋白血症、血型不合、癌前血液系統疾病）也同樣被模型自身評估為機轉關聯薄弱或屬間接情境關聯，並非直接治療證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 5 個預測適應症均為 L4-L5 證據等級，無任何臨床試驗支持，且模型自身的機轉分析明確指出生物學關聯薄弱，高分很可能為知識圖譜偽陽性。
- 缺乏原廠仿單警語/禁忌（Blocking 缺口），無法進行安全性初評；也缺乏 MOA 資料，無法確認機轉合理性。

**若要推進需要：**
- 補齊 TFDA 仿單警語與禁忌（DG001，向 TFDA 官網取得並解析）
- 補齊作用機轉資料（DG002，查詢 DrugBank API）
- 針對排名較高的候選適應症（尤其高澱粉酶血症）補充機轉研究或前臨床證據，若持續無實證支持則建議直接排除，不宜投入後續資源
