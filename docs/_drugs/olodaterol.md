## Olodaterol：從慢性阻塞性肺病到支氣管炎
{: .text-alpha }

## 一句話總結

Olodaterol 是一種長效 β2 受體促效劑（LABA），原本用於慢性阻塞性肺病（COPD）的維持治療。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前沒有針對支氣管炎的臨床試驗，只有 **2 篇**間接相關的文獻（COPD 治療指引與藥物回顧），證據仍屬模型預測階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥物類別，Olodaterol 屬於長效 β2 受體促效劑，一般認為它透過活化氣道平滑肌上的 β2 腎上腺素受體，引起持續的支氣管擴張，每日使用一次。

慢性支氣管炎是 COPD 的臨床表現型之一，所以原適應症與預測的新適應症高度重疊。模型給出高分，很可能反映的是這種重疊，而不是一個獨立的藥物再利用機會。

目前沒有證據支持它用於急性支氣管炎，或與 COPD 無關的支氣管炎。

模型的第二個預測是**阻塞性肺病 (Obstructive lung disease)**，分數 99.57%。它同樣涵蓋 COPD，相關的 Phase 3 試驗（如 NCT01431274、NCT00796653、NCT01525615）多半是在確認既有適應症，不算真正的新適應症。

## 安全性考量

- **藥物交互作用**：資料共收錄 100 筆交互作用。以下為部分中度（Moderate）等級的藥物：
  - 擬交感神經類／興奮劑：Epinephrine（含眼用、外用劑型）、Ephedrine（含鼻用劑型）、Isometheptene、Phentermine、Diethylpropion、Fenfluramine
  - 可能與心律（QT 間期）相關：Clarithromycin、Cisapride、Dolasetron、Palonosetron、Granisetron
  - 其他：Famotidine、Loperamide、Canagliflozin、Ertugliflozin、Semaglutide、Albiglutide

其他警語與禁忌症資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎這個預測的 TxGNN 分數很高，但目前沒有直接的臨床試驗，只有 COPD 相關文獻，證據僅達 L4。
- 高分很可能來自它與原適應症 COPD 的重疊，目前看不出獨立的再利用價值。

**若要推進需要：**
- 先釐清目標族群，是 COPD 的慢性支氣管炎表現型（屬既有適應症），還是非 COPD 的支氣管炎（目前沒有證據）。
- 補充詳細的作用機轉資料（MOA）。
- 取得香港原廠仿單的警語與禁忌症資訊。
- 若考慮延伸到 COPD 以外（例如氣喘），需要有專門的臨床證據，並設置安全防護，如避免在沒有吸入性類固醇的情況下單獨使用 LABA。
