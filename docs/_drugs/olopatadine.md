# Olopatadine：從過敏性結膜炎到酒糟性結膜炎

## 一句話總結

Olopatadine 是 H1 受體拮抗劑兼肥大細胞穩定劑，以眼用製劑上市，一般用於過敏性結膜炎。
TxGNN 模型預測它可能對**酒糟性結膜炎 (Rosacea Conjunctivitis)** 有效。
目前**沒有臨床試驗和文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Olopatadine 已知是 H1 受體拮抗劑與肥大細胞穩定劑，在過敏性結膜炎中的療效已被廣泛使用。機轉上，阻斷 H1 受體並穩定肥大細胞，可能減輕眼表的搔癢、充血與組織胺介導的發炎。

不過，眼部酒糟症的成因主要是瞼板腺功能異常、蠕形蟎 (Demodex)、先天免疫活化，以及 MMP-9 介導的發炎。這些機轉與組織胺途徑的重疊有限，因此機轉上是否適用仍不確定，也未經驗證。

高預測分數只代表模型的推論，不等於臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
目前只有 TxGNN 模型預測，沒有任何臨床試驗或文獻佐證，證據等級為 L5。酒糟性結膜炎的主要病理機轉與抗組織胺／肥大細胞穩定作用的關聯也不明確，暫不建議推進。

**若要推進需要：**
- 搜尋並確認是否有 olopatadine 用於眼部酒糟症的臨床或觀察性研究
- 釐清組織胺與肥大細胞途徑在眼部酒糟症中的角色，補足機轉論證
- 取得香港衛生署核准的仿單，確認適應症、警語與禁忌症
- 評估眼用劑型是否符合預期給藥途徑，並與現行標準治療（如瞼緣清潔、局部或口服抗生素、局部免疫調節劑）比較

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
