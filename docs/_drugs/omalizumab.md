# Omalizumab：從過敏性氣喘到支氣管炎

## 一句話總結

Omalizumab（商品名 Xolair）是抗 IgE 單株抗體，文獻顯示其核准用途為中重度過敏性氣喘（香港許可證資料未載明適應症文字）。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前僅有 **2 個間接相關的臨床試驗**和 **8 篇文獻**，且沒有直接針對支氣管炎的療效證據，這個預測分數高很可能反映的是氣喘與氣道疾病的關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻，Omalizumab 是人源化抗 IgE 單株抗體。它與游離 IgE 結合後，可降低血中游離 IgE 與 FcεRI 的表現量，進而減輕過敏原驅動的氣道發炎。這個機轉在過敏性氣喘中已有充分證實。

支氣管炎與氣喘、慢性阻塞性肺病 (COPD) 的關聯，主要在於氣道發炎和「氣喘－COPD 重疊」的族群，例如慢性支氣管炎表型。嗜伊紅性支氣管炎則與氣喘密切相關。從這個角度看，抗 IgE 治療在部分過敏型氣道發炎病人身上有理論上的合理性。

需要注意的是，目前**沒有直接針對支氣管炎的證據**。TxGNN 的高分很可能來自知識圖譜中氣喘與氣道疾病的鄰近關係，並不代表已有支氣管炎的療效資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有直接針對支氣管炎的療效證據。僅有的兩個相關試驗，一個樣本數僅 11 人且關聯性弱，另一個與支氣管炎僅間接相關。
- TxGNN 的高分很可能是氣喘與氣道疾病在知識圖譜中相鄰所致。

**若要推進需要：**
- 釐清目標族群，例如嗜伊紅性支氣管炎、慢性支氣管炎，或氣喘－COPD 重疊，並針對該族群設計對照試驗。
- 取得 Omalizumab 完整的作用機轉資料。
- 取得香港衛生署仿單中的警語與禁忌症，才能進行安全性篩選。
- 確認香港許可證的核准適應症文字。

**其他預測適應症（供參考）：**
- 阻塞性肺病：有進行中的 Phase 2 試驗 [NCT07059091](https://clinicaltrials.gov/study/NCT07059091)（過敏原致敏的 COPD，招募中，預計 334 人，尚無結果），證據較為直接。
- 異位性皮膚炎：有兒童重度異位性濕疹的安慰劑對照試驗 [NCT02300701](https://clinicaltrials.gov/study/NCT02300701)，但既有回顧顯示證據不一致。
- 支氣管腫瘤：未發現可信的機轉連結，判斷為知識圖譜的關聯假象。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
