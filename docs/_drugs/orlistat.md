# Orlistat：機轉外推至高維生素血症 (Hypervitaminosis)

## 一句話總結

Orlistat 是腸道/胰臟脂肪酶抑制劑，本應用於減少膳食脂肪吸收，但原始核准適應症資料在本次證據包中缺失。
TxGNN 模型預測它可能對**高維生素血症 (Hypervitaminosis)** 有效（推論邏輯是脂肪酶抑制會連帶降低脂溶性維生素 A/D/E/K 的腸道吸收），
但目前**沒有任何臨床試驗或文獻**支持這個方向，屬於純模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據證據包中的機轉推論，Orlistat 是腸道/胰臟脂肪酶抑制劑，會阻斷膳食三酸甘油酯的水解與吸收；
臨床上已知的常見副作用之一，就是連帶降低脂溶性維生素（A、D、E、K）的腸道吸收，甚至可能造成低維生素血症。

TxGNN 的預測方向，是把這個「副作用機轉」反向操作：理論上若能刻意降低脂溶性維生素的吸收，或許可輔助處理脂溶性維生素攝取過量（如維生素 A、D 中毒）的情況。
但這僅是機轉上的合理推論，並非已被驗證的適應症，且因原始 MOA 與原適應症資料缺失，無法交叉比對藥物官方核准用途來進一步佐證方向是否成立。
