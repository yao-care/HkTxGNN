# Oxcarbazepine：從癲癇到視覺誘發型癲癇 (Visual Epilepsy)

## 一句話總結

> Oxcarbazepine 是廣效型抗癲癇藥物，原用於局部性發作與全身強直陣攣發作的癲癇治療。
> TxGNN 模型預測它可能對**視覺誘發型癲癇 (Visual Epilepsy)** 有效，
> 目前有 **1 個間接相關臨床試驗**和 **20 篇文獻**（多為一般癲癇治療證據，非針對此亞型），證據強度中等偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料（Data Gap）。根據既有文獻，Oxcarbazepine 是電壓依賴性鈉離子通道阻斷劑，屬於第二代抗癲癇藥物，已廣泛用於局部性發作與全身強直陣攣發作的治療（PMID 37092337、33334546）。

視覺誘發型癲癇屬於反射性癲癇的一種亞型，發作機轉與一般局部性癲癇的皮質過度興奮有共通的病理生理基礎。因此理論上，廣效型抗癲癇藥物對此類反射性發作可能同樣具有抑制效果。

然而，現有證據並未針對視覺誘發型癲癇進行特異性驗證——唯一相關的臨床試驗（Liceo Study）是評估多種新型 AED（含 oxcarbazepine）作為雙藥治療局部性癲癇的一般觀察性研究，並非鎖定視覺誘發型癲癇族群。這代表機轉推論合理，但直接證據仍屬間接推論層級。

## 結論與下一步

**決策：Hold**

**理由：**
- 安全性資料（仿單警語、禁忌、DDI）完全缺失，且此缺口被標記為 Blocking，無法完成 S1 安全性初評。
- 針對視覺誘發型癲癇此一反射性癲癇亞型，現有證據僅為一般局部性癲癇治療的間接觀察性研究，缺乏亞型特異性驗證。
- 香港未上市，無在地許可證與適應症資料可佐證推進路徑。

**若要推進需要：**
- 取得 TFDA/香港藥品仿單完整安全性資料（警語、禁忌症、藥物交互作用）
- 補齊 Oxcarbazepine 作用機轉（MOA）詳細資料，強化機轉關聯性論證
- 針對視覺誘發型癲癇進行特異性臨床觀察或病例系列研究，而非僅依賴一般癲癇雙藥治療證據外推
- 若考慮香港上市申請，需備妥當地藥品許可證申請所需資料
