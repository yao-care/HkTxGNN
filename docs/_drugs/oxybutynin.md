# Oxybutynin：從（原適應症資料缺漏）到不寧腿症候群

## 一句話總結

Oxybutynin 是一種抗蕈毒鹼藥物，具肌肉滋養性抗痙攣作用，但本次資料未提供其原適應症。
TxGNN 模型預測它可能對**不寧腿症候群 (Restless Legs Syndrome)** 有效，
但目前**沒有臨床試驗和文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Oxybutynin 是抗蕈毒鹼藥物，具肌肉滋養性抗痙攣活性，但其在不寧腿症候群上的機轉關聯並不明確。

不寧腿症候群的病理與多巴胺功能異常、腦內鐵缺乏有關。現有資料無法支持抗蕈毒鹼作用與這些機轉之間存在合理連結。此外，抗膽鹼藥物的中樞效應反而可能惡化睡眠或認知功能。

因此，0.997 的高分本身不構成證據，此預測目前只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測，沒有任何臨床試驗或文獻支持不寧腿症候群，且機轉上缺乏合理連結，抗膽鹼的中樞效應還可能造成不利影響。
- 原適應症、作用機轉與安全性資料皆缺漏，目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症與核准適應症）
- 從 DrugBank 補齊作用機轉（MOA）資料
- 針對不寧腿症候群檢索並確認有無直接的臨床或機轉證據
- 評估抗膽鹼藥物對睡眠與認知的影響
