# Oxyquinoline：從牙科外用溶液（許可證未載明適應症）到骨關節炎

## 一句話總結

Oxyquinoline（8-羥基喹啉）在香港有 1 張許可證，是牙科用溶液的成分，但許可證上沒有適應症文字。
TxGNN 模型預測它可能對**骨關節炎 (Osteoarthritis)** 有效。
目前僅有 **1 個 Phase 1 試驗**（屬示蹤劑用途，並非治療試驗）和 **1 篇類似物的前臨床文獻**，證據很薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Oxyquinoline 是 8-羥基喹啉類化合物，具金屬螯合與抗菌特性。但它在原適應症中的療效資料不足，機轉上是否適用於骨關節炎，只能間接推論。

支持這個預測的唯一線索，來自結構相近的 8-羥基喹啉 Clioquinol。2025 年一篇果蠅前臨床研究顯示，Clioquinol 有抗衰老與代謝穩態效應，文中也提到它在骨關節炎和神經退化性疾病上可能有活性。細胞老化與金屬失衡都是骨關節炎中可能相關的路徑，但**沒有任何 Oxyquinoline 本身在骨關節炎的資料**。

因此，這個高分預測目前較像是知識圖譜上的關聯，而不是有實證支持的治療假說。

## 安全性考量

安全性資訊請參考原廠仿單。藥物交互作用查詢無結果。

補充一項類別層級的訊號：證據包中的 1971 年文獻（Entero-Vioform，即 Clioquinol）提到神經毒性（SMON 型）。若考慮長期全身性使用 8-羥基喹啉類，這是需要留意的風險。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有 Oxyquinoline 用於骨關節炎的治療性證據。唯一的試驗是示蹤劑用途，唯一的文獻是類似物的前臨床研究。
- 目前僅能視為研究問題，還不能進入安全性篩選。此外，同類藥物有神經毒性的歷史訊號，且香港許可證缺少適應症與仿單資料。

**若要推進需要：**
- 取得香港衛生署仿單，確認原適應症、警語與禁忌。
- 補齊 Oxyquinoline 本身的作用機轉資料（如 DrugBank）。
- 找出 Oxyquinoline 本身在骨關節炎的前臨床證據，例如軟骨細胞或動物模型，而不是只引用 Clioquinol。
- 評估給藥途徑是否可行：現有製劑為牙科用溶液，骨關節炎需要關節內或全身給藥，兩者之間的相容性尚未評估。
- 針對神經毒性與肝毒性，訂定風險評估與監測計畫。
