# Oxytetracycline：從細菌感染（抗生素類別）到慢性鼻竇炎

## 一句話總結

Oxytetracycline 是四環黴素（tetracycline）類抗生素，香港登記資料中未載明原適應症。
TxGNN 模型預測它可能對**慢性鼻竇炎 (Chronic Rhinosinusitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測（證據等級 L5）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Oxytetracycline 屬於四環黴素類抗生素，可作用於細菌定殖。慢性鼻竇炎常伴有細菌感染，因此機轉上可能適用。

四環黴素類另有文獻報導的抗發炎與抑制基質金屬蛋白酶（MMP）作用，可能與慢性黏膜發炎有關。以上推論來自藥物類別的一般藥理知識，並非本資料包內的數據，無法對照原始機轉紀錄驗證。

0.996 的分數只是計算模型的預測，不等於臨床療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測都只有模型分數，沒有臨床試驗、文獻或機轉資料佐證。
- 香港的人用劑型僅有眼用軟膏，與鼻竇炎的給藥途徑不相容，前 5 名預測中也有數項機轉連結薄弱。

**若要推進需要：**
- 補齊香港衞生署仿單的警語與禁忌資料，這是進入安全性篩選的前提。
- 補上 DrugBank 的作用機轉（MOA），以驗證抗菌與抗發炎的假設。
- 檢索慢性鼻竇炎的臨床試驗與文獻（ClinicalTrials.gov、PubMed）；四環黴素類在鼻竇炎與眼表疾病的既有研究可先做文獻回顧。
- 評估給藥途徑可行性：鼻竇炎需口服或局部製劑，眼表疾病可先看現有眼用軟膏的適用性。
- 優先處理排名 1 的慢性鼻竇炎與排名 4 的眼表疾病；副鼻竇腫瘤與感染後血管炎暫不建議投入資源。
