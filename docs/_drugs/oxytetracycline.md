# Oxytetracycline：從泌尿道感染等細菌感染到慢性鼻竇炎

## 一句話總結

Oxytetracycline（土黴素）是四環素類抗生素，原本用於泌尿道感染、支氣管炎、肺炎、結膜炎等多種細菌感染。
TxGNN 模型預測它可能對**慢性鼻竇炎 (Chronic Rhinosinusitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測的研究假說。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥物類別，Oxytetracycline 屬四環素類抗生素，一般認為透過結合細菌 30S 核糖體次單位來抑制蛋白質合成。四環素類對常見上呼吸道病原菌具抗菌活性，也被認為有抗發炎及抑制基質金屬蛋白酶 (MMP) 的作用，這些特性理論上與慢性鼻竇炎相關。

原適應症中已包含支氣管炎、咽炎、肺炎等呼吸道感染，與鼻竇炎同屬呼吸道範疇，生物學上具合理性。此外，模型也預測了慢性篩竇炎（慢性鼻竇炎的亞型），兩者分數相近且高度相關，不應視為獨立證據。

需注意，其他四環素類（如 doxycycline）的間接證據未納入本報告，因此無法計入。

## 結論與下一步

**決策：Hold**

**理由：**
- 慢性鼻竇炎的預測僅來自模型（分數高，但無任何臨床試驗或文獻佐證），機轉資料也不完整，目前只能作為研究問題。
- 香港許可證缺少適應症與警語資料，無法進行安全性篩選。

**若要推進需要：**
- 取得 DrugBank 的作用機轉資料，補足機轉連結分析
- 下載並解析香港衛生署的仿單，確認適應症、警語與禁忌
- 系統性檢索四環素類（含 doxycycline）用於慢性鼻竇炎的文獻與臨床試驗
- 確認可用劑型與給藥途徑（目前人用許可證僅有眼用軟膏）是否適合鼻竇炎治療
- 若要優先探索，點狀上皮角結膜炎因與眼用適應症相近，可能較容易驗證
