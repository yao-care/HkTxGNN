# Ozanimod：從多發性硬化症到進行性復發型多發性硬化症

## 一句話總結

Ozanimod 是一種口服的 S1P 受體調節劑，原本用於治療多發性硬化症（multiple sclerosis）。
TxGNN 模型預測它可能對**進行性復發型多發性硬化症 (Progressive Relapsing Multiple Sclerosis)** 有效。
目前**沒有相關臨床試驗登記**，僅有 **18 篇文獻**提供間接背景，多為綜述與機轉討論，尚無直接證據證明其在此亞型的療效。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻與藥物類別的一般知識，Ozanimod 是選擇性作用於 S1P1 與 S1P5 的 S1P 受體調節劑。S1P1 促效會使淋巴球表面受體內化，將淋巴球滯留在淋巴結，減少自體反應性淋巴球進入中樞神經系統。

S1P5 表現於寡突膠細胞等中樞神經細胞，因此理論上可能有直接的神經保護或髓鞘再生作用，這對進展型疾病可能特別重要。Ozanimod 已被核准用於復發型多發性硬化症，與預測的新適應症屬於同一疾病譜系。

需要注意的是，0.993 的高分主要反映它在知識圖譜中與既有多發性硬化症適應症距離很近，**並非**進行性亞型有效的獨立證據。上述機轉連結也是依據文獻與藥物類別知識推論，而非本報告所整理的藥物資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測與間接文獻，沒有針對進行性復發型多發性硬化症的臨床試驗，證據等級僅為 L4。高預測分數主要反映與既有適應症的接近程度。
- 香港已有 Ozanimod 上市，但本次整理的資料中缺少核准適應症與仿單安全性資訊，無法確認標示範圍與風險。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌
- 補充詳細的作用機轉資料（MOA）
- 查證 Ozanimod 在進行性多發性硬化症族群的直接臨床數據，例如現有試驗亞組分析或新設試驗
- 釐清「進行性復發型」與目前已核准的復發型適應症（含活動性次發進展型）的臨床差異，評估是否真的有新增價值
- 針對心血管、呼吸與心律傳導風險，擬定篩選與監測計畫
