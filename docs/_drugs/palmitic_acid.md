# Palmitic Acid（棕櫚酸）：從肺部表面活性劑成分到食道先天畸形（模型預測）

## 一句話總結

Palmitic Acid 是一種普遍存在的飽和脂肪酸，在香港以 SURVANTA 氣管內懸液（肺表面活性劑製劑）的成分形式取得許可。
TxGNN 模型預測它可能對**非症候群性食道畸形 (non-syndromic esophageal malformation)** 有效，但目前**沒有任何臨床試驗**，也沒有直接支持此用途的文獻，屬純模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Palmitic Acid 是日常飲食與人體內源性的飽和脂肪酸，也是肺表面活性劑製劑中的脂質成分之一。

就排名第一的「非症候群性食道畸形」而言，這是先天性結構異常，目前**找不到任何已知的生物學理由**說明棕櫚酸能治療它。高分僅反映知識圖譜中的計算關聯，不代表有生物學或臨床依據。

其他預測方向的文獻多半顯示脂質代謝是疾病的**驅動因子**，而非治療手段。例如：
- **乳癌**：臨床前研究顯示棕櫚酸可重塑嗜中性球、破壞血管完整性並促進乳癌肺轉移，指向潛在危害；另有研究顯示在三陰性乳癌細胞中，CD36 會增強對棕櫚酸誘導鐵死亡的敏感性，但這僅是體外觀察，且亞型不同。
- **食道疾病**：文獻多為脂肪酸代謝與食道癌、Barrett 食道進展相關的機轉或流行病學研究，部分文獻與主題無關（嬰兒配方奶、乳汁等）。
- **乾眼症**：脂肪酸是淚膜脂質層的成分，與淚膜穩定性有合理的生物物理關聯，但證據間接，且飽和游離脂肪酸可能具促發炎性。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測方向皆屬 L5（僅模型預測）或 L4（間接機轉或觀察性證據），沒有任何臨床試驗。
- 排名第一的食道畸形缺乏生物學依據；乳癌方向的現有證據甚至顯示棕櫚酸可能促進腫瘤轉移，不建議推進。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料，並確認原核准適應症
- 補齊作用機轉（MOA）資料
- 針對高分預測提出明確的生物學假說，並以體外或動物模型驗證
- 若考慮乾眼症方向，需先評估局部給藥的路徑可行性與促發炎風險；乳癌方向則需先釐清棕櫚酸的促轉移風險
