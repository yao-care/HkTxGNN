# Palonosetron：從化療引起的噁心嘔吐到偏頭痛

## 一句話總結

Palonosetron 是 5-HT3 受體拮抗劑，在香港以 ALOXI 等品牌上市（原適應症資料缺漏）。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
但目前**無臨床試驗**，唯一的藥物相關文獻（1 篇病例報告）還顯示 palonosetron 可能**誘發**偏頭痛型頭痛。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 palonosetron 是 5-HT3 受體拮抗劑，血清素訊號傳導與偏頭痛的病理機轉有可能相關，因此從機轉上可以推論其潛在適用性。

然而，這個推論並未獲得臨床證據支持。唯一與偏頭痛直接相關的藥物文獻（PMID 21132477）是一篇病例報告，描述 palonosetron 引起偏頭痛型頭痛，方向與治療效果相反。TxGNN 的高分（99.74%）缺乏任何臨床資料佐證，應視為假設而非結論。

其他預測的適應症（伴腦幹先兆的偏頭痛、偏頭痛易感性、蠕蟲狀皮膚萎縮、眉部毛髮角化性紅斑）同樣只有模型分數。皮膚疾病兩項看不出與 5-HT3 拮抗的機轉關聯，可能是知識圖譜鄰近關係造成的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的藥物相關證據是 palonosetron 誘發偏頭痛的不良反應報告，與預測方向相反；其餘預測僅有模型分數，且部分缺乏合理機轉。
- 安全性資料（香港仿單的警語、禁忌）與作用機轉尚未取得，無法進行安全性初篩。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症
- 從 DrugBank 補充作用機轉與原適應症資料
- 系統性檢索 5-HT3 拮抗劑用於偏頭痛的臨床研究，並評估 palonosetron 誘發頭痛的訊號
- 若無任何支持證據，建議不再將此預測列為優先候選

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
