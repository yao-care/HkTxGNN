# Panitumumab：從抗 EGFR 單株抗體到藥物誘發性骨質疏鬆

## 一句話總結

Panitumumab 是抗 EGFR（表皮生長因子受體）的單株抗體，在香港以 Vectibix 品名上市，但輸入資料未提供原適應症。
TxGNN 模型預測它可能對**藥物誘發性骨質疏鬆 (Drug-induced Osteoporosis)** 有效。
目前**沒有臨床試驗和文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Panitumumab 是抗 EGFR 單株抗體，EGFR 訊號參與成骨細胞與破骨細胞的調控，因此知識圖譜上出現關聯是可以理解的。

不過，這個關聯的作用方向並不明確。阻斷 EGFR 可能傷害骨骼，而不是改善骨質疏鬆。Panitumumab 常造成低血鎂與低血鈣，理論上可能使骨骼健康惡化。這個預測目前只是模型輸出，沒有實證支持，安全性訊號反而提示要謹慎。

TxGNN 另預測了**嚴重非增殖性糖尿病視網膜病變**（分數 99.05%，同為 L5、Hold）。EGFR 與視網膜發炎、血管通透性和血管新生有推測性關聯。但 Panitumumab 是靜脈注射的大分子全身性抗體，沒有眼部給藥或視網膜安全性資料。它已知的皮膚、眼表和電解質毒性，也使慢性病用途難以成立。

## 結論與下一步

**決策：Hold**

**理由：**
兩項預測都只有模型分數，沒有任何臨床試驗或文獻（L5）。電解質異常可能與骨骼健康相抵觸，且香港仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症、核准適應症）
- 從 DrugBank 補充作用機轉資料
- 檢索 EGFR 抑制與骨代謝的前臨床和文獻證據，確認作用方向
- 評估低血鎂、低血鈣對骨骼的影響
- 確認給藥途徑是否適合新適應症（目前為待確認狀態）
