# Pantothenic Acid（泛酸）：從壞血病到先天性凝血酶原缺乏症

## 一句話總結

泛酸（維生素 B5）是輔酶 A 的前驅物，在知識圖譜中的原適應症為抗壞血酸缺乏與壞血病。
TxGNN 模型預測它可能對**先天性凝血酶原缺乏症 (Congenital Prothrombin Deficiency)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知泛酸是輔酶 A 的前驅物，參與脂質與能量代謝。

先天性凝血酶原缺乏症是由 F2 基因異常造成的遺傳性凝血因子疾病，治療需補充凝血因子。泛酸在凝血酶原的合成或功能上沒有已知作用，因此**未找到可信的機轉連結**。0.9996 的高分僅反映知識圖譜中的鄰近關係，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（先天性凝血酶原缺乏症）沒有任何臨床試驗或文獻，也找不到合理的機轉連結，僅為圖譜預測，證據等級 L5。
- 仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌資料
- 補充泛酸的作用機轉資料（例如查詢 DrugBank）
- 若仍想探索，較值得優先研究的是證據等級較高的方向（葉酸缺乏性貧血、子宮發炎性疾病），並以其作為研究問題，先做機轉與前臨床驗證
- 目前不建議針對先天性凝血酶原缺乏症投入資源
