# Papain：從（原適應症未載明）到 原發性血小板釋放障礙

## 一句話總結

Papain（木瓜蛋白酶）是一種半胱胺酸蛋白酶，在香港有 5 張單一成分許可證，但本報告所彙整的資料中未載明其核准適應症。
TxGNN 模型預測它可能對**原發性血小板釋放障礙 (primary release disorder of platelets)** 有效，但目前**沒有臨床試驗**，唯一連結的文獻也與 papain 無關，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，papain 是從木瓜（Carica papaya）乳汁中取得的蛋白水解酶，在香港以單一成分製劑（含錠劑、糖漿）上市，但其核准適應症在本報告資料中並未載明。

Papain 在實驗室中可改變血小板表面糖蛋白，因此在體外研究中常被當作工具。然而，這只是研究用途，並不代表有治療價值。原發性血小板釋放障礙是血小板功能異常的疾病，目前沒有任何機轉證據顯示蛋白酶能矯正此類缺陷。

唯一連結的文獻（PMID 38430019）討論的是富白血球與貧白血球的血小板濃縮血漿（PRP）對兔子軟骨的影響，與 papain 及此疾病均無直接關係。高分數較可能來自知識圖譜中的關聯，而非實際療效訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測都只有模型分數，沒有臨床試驗，且現有文獻與 papain 治療效果無關，也找不到合理的作用機轉。

**若要推進需要：**
- 取得 papain 的作用機轉資料（例如查詢 DrugBank）
- 下載並解析香港衛生署的仿單，確認核准適應症、警語與禁忌
- 若要探討血小板相關疾病，需先有體外或動物模型證明 papain 有治療效果
- 重新篩選預測，優先評估有直接機轉依據的適應症
