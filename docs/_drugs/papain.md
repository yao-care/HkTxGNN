# Papain：原適應症資料缺失，TxGNN 預測適應症證據薄弱

## 一句話總結

Papain（DrugBank DB11193）目前在香港未上市，且缺乏原始核准適應症與作用機轉資料。
TxGNN 模型對此藥物產生了 10 個預測適應症，分數最高者為**原發性血小板釋放障礙 (Primary Release Disorder of Platelets)**，
但檢視相關文獻後發現，這些關聯很可能源自 papain 作為**實驗室裂解試劑**（用於處理血小板膜蛋白、製備抗體 Fab 片段）在文獻中的文字共現，而非真實的治療性機轉證據。

## 為什麼這個預測合理？

目前缺乏 Papain 詳細的作用機轉（MOA）資料，也沒有其原始臨床適應症的登記紀錄，無法建立完整的機轉比對基礎。

根據可查得的文獻脈絡，Papain 是一種半胱氨酸蛋白酶，在醫學研究中最常見的角色是**實驗室裂解試劑**：用於裂解血小板膜表面蛋白（如 GPIIb/IIIa）以製備供血清學分析的「papain-treated platelets」，或用於將單株抗體（如 trastuzumab）裂解為 Fab 片段供顯影標記研究。這類用途與其作為「治療藥物」的機轉完全不同。

檢視本評估案的 10 個預測適應症，多數（原發性血小板釋放障礙、Glanzmann thrombasthenia、HER2 陽性乳癌等）的支持文獻經逐篇檢視後，主題都指向 papain 作為研究工具試劑，而非治療效果的證據；另有數個預測（如乳癌分子亞型、聽力障礙相關遺傳病）完全沒有文獻或試驗支持，屬於純知識圖譜預測。整體而言，目前沒有機轉層級的證據支持 Papain 對任一預測適應症具有治療潛力。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有 10 個預測適應症的證據等級均為 L4 或 L5，且經文獻逐篇檢視後，僅有的少數文獻皆指向 papain 作為實驗室裂解試劑的方法學用途，而非真實治療機轉；其餘多數預測完全無文獻或試驗支持。
- 缺乏 MOA、原適應症、香港上市與安全性資料，S1 安全性初評所需之基本資訊尚不完整（見 DG001 為 Blocking 等級缺口）。

**若要推進需要：**
- 補齊 Papain 之作用機轉（MOA）資料（DrugBank API 查詢，DG002）
- 取得香港/其他地區仿單警語與禁忌症資料，以完成 S1 安全性初評（DG001）
- 若持續評估血小板相關適應症，需針對「papain 作為血小板膜蛋白裂解試劑」與「papain 具治療性血小板調節機轉」進行機轉層級的區分驗證，避免文字共現造成的假陽性判讀
- 若無法取得上述資料，建議將本候選案自優先開發清單中移除
