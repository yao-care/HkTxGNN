# Papaverine：從血管擴張用途到缺血性疾病 (Ischemic Disease)

## 一句話總結

Papaverine（罌粟鹼）是一種血管平滑肌鬆弛劑，香港已有多張許可證，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**缺血性疾病 (Ischemic Disease)** 有效，預測分數 99.91%。
目前有 **5 個臨床試驗**和 **20 篇文獻**，但試驗都不是測試 papaverine 療效，文獻多為老舊的描述性或動物研究，屬間接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Papaverine 是非選擇性磷酸二酯酶（PDE）抑制劑，會提高血管平滑肌內的 cAMP/cGMP，造成血管擴張。

缺血的核心問題是血流不足，血管擴張在機轉上有合理性。臨床上它已被用作局部或動脈內血管擴張劑，例如預防移植血管痙攣、處理非阻塞性腸繫膜缺血。

不過現有證據多屬程序性或診斷性用途（如冠狀動脈血流儲備量測、移植血管處理），不是改善疾病結局的療效證據。「缺血性疾病」這個詞也很籠統，TxGNN 的高分不足以代表對特定缺血疾病有效。

## 安全性考量

- **藥物交互作用**：資料庫查詢未找到記錄的交互作用。
- **文獻提及的風險**：
  - 陰莖海綿體注射 papaverine 後可能發生缺血性陰莖異常勃起（PMID 32478401）。
  - 1975 年 JAMA 報告指出 papaverine 可能拮抗 levodopa（PMID 1172755），帕金森氏症患者需留意。

主要警語與禁忌症資料缺漏，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高，血管擴張的機轉也說得通。但 5 個試驗都不是 papaverine 療效試驗，文獻多為老舊的描述性或動物研究，沒有對照性的療效證據。
- 仿單警語與禁忌症、作用機轉資料都還缺漏，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症
- 補充 DrugBank 的作用機轉資料
- 把「缺血性疾病」縮小到具體疾病（如非阻塞性腸繫膜缺血、腦血管痙攣、雷諾氏病），再查是否有對照試驗
- 釐清給藥途徑：香港有注射劑（HK-31756），而臨床證據多為動脈內或局部給藥
- 其他預測適應症（如雷諾氏病、血管功能不全）同為 L4 研究假說，證據同樣是間接的，可作後續比較

*本報告僅供研究參考，不構成醫療建議；老藥新用候選須經臨床驗證才能應用。*
