# Paroxetine：從憂鬱症與焦慮症到 Ohdo 症候群及其變異型

## 一句話總結

Paroxetine 是一種選擇性血清素再攝取抑制劑（SSRI），原本用於憂鬱症、焦慮症、創傷後壓力症候群、社交畏懼症及強迫症等精神科疾病。
TxGNN 模型預測它可能對 **Ohdo 症候群及其變異型 (Ohdo syndrome and variants)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Paroxetine 屬於 SSRI 類藥物，透過抑制血清素再攝取來改善情緒與焦慮症狀。

Ohdo 症候群及其變異型（包括與 KAT6B 基因變異相關的 Say-Barber-Biesecker-Young-Simpson 症候群）是罕見的遺傳性神經發育疾病，常見表現為智能障礙、肌張力低下與顱顏異常。其致病原因在於染色質調控缺陷，與血清素系統沒有明確關聯。

因此，目前無法從現有資料建立 SSRI 作用與此疾病致病機轉之間的合理路徑。若真有關聯，也僅可能是改善伴隨的行為或情緒症狀，並非針對疾病本身的治療。這個預測的唯一依據是模型的高分，應視為待驗證的假說。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容，僅供參考）：癲癇、雙極性疾患、重度情感性疾患、肝病、膽囊疾病、血液凝固疾病、抗精神病藥惡性症候群、抗利尿激素分泌不當症候群（含腎因性）、血清素症候群、藥物引起的靜坐不能。
- **藥物交互作用**：共查得 100 筆交互作用，以下為部分列舉。
  - 嚴重（Major）：Bupropion、Lorcaserin、Diethylpropion、Dolasetron、Eliglustat、Palonosetron、Phentermine
  - 中度（Moderate）：Morphine、Acetylsalicylic acid（阿斯匹靈）、Chlorpropamide、Cimetidine、Clarithromycin、Glimepiride、Repaglinide 等

其餘警語與禁忌的詳細內容，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，只有模型預測分數，沒有臨床試驗或文獻，也沒有可成立的作用機轉連結。
- Ohdo 症候群源自染色質調控缺陷，SSRI 不太可能改變疾病本身。

**若要推進需要：**
- 取得 Paroxetine 詳細的作用機轉資料，並釐清與 KAT6B 相關病理機轉的可能關聯
- 進行文獻與前臨床研究回顧，確認是否有任何支持證據
- 若僅考慮用於伴隨的行為或情緒症狀，需另行定義臨床目標與族群
- 取得香港衛生署仿單的警語與禁忌資料，完成安全性篩選
- 評估兒童與神經發育疾病族群使用的安全性
