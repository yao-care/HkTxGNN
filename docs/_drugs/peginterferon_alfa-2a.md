## Peginterferon alfa-2a：從慢性 C 型／B 型肝炎到 B 型肝炎病毒感染
{: .text-alpha }

## 一句話總結

Peginterferon alfa-2a 是長效型干擾素，原本用於慢性 C 型與 B 型肝炎。
TxGNN 模型預測它對 **B 型肝炎病毒感染 (Hepatitis B Virus Infection)** 有效，但慢性 B 型肝炎本來就在其原適應症內，這是已核准用途，並非真正的新適應症。
目前有 **20 個臨床試驗**和 **19 篇文獻**與此方向相關，其中多項為 Phase 3/4 研究與隨機對照試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，peginterferon alfa-2a 是聚乙二醇化的干擾素 α，兼具抗病毒與免疫調節作用，在慢性 B 型與 C 型肝炎中的療效已被證實。其機轉上可能透過誘導干擾素刺激基因、增強 HBV 特異性 T 細胞反應來對抗 B 型肝炎病毒。

由於慢性 B 型肝炎已列在原適應症中，這項預測與既有臨床用途一致，TxGNN 的高分（0.999）也反映這一點。因此，本案更適合視為「既有適應症的證據盤點」，而非跨疾病的藥物再利用。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 慢性 B 型肝炎已是 peginterferon alfa-2a 的既有適應症，且有多項已完成的 Phase 3/4 試驗與隨機對照研究支持，並已在香港上市。
- 這是已核准用途的證據確認，不是新的再利用，主要需要的是用藥時的把關。

**若要推進需要：**
- 取得香港衛生署核准的仿單，確認警語、禁忌症與正式適應症文字
- 補充作用機轉資料
- 建立病人篩選標準（HBeAg 狀態、HBV DNA、ALT）與治療中停藥規則（如 HBsAg 下降幅度）
- 建立干擾素相關不良反應（血球低下、精神神經症狀等）的監測計畫
- 針對上述重大交互作用藥物制定併用管理原則
