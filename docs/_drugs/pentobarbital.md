# Pentobarbital：從癲癇與失眠到肥胖症

## 一句話總結

Pentobarbital（戊巴比妥）是巴比妥類鎮靜安眠藥，原本用於癲癇、失眠、癲癇重積狀態及腦缺血等。
TxGNN 模型預測它可能對**肥胖症 (Obesity Disorder)** 有效，但目前**沒有臨床試驗**，檢索到的 20 篇文獻幾乎都是動物實驗，且 Pentobarbital 多半只是實驗中的麻醉劑，**並不支持**這個預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。一般已知 Pentobarbital 是 GABA-A 受體的正向異位調節劑，產生中樞神經抑制與鎮靜效果，這解釋了它在癲癇與失眠的用途。

然而，鎮靜與中樞抑制並沒有合理的減重途徑。檢索到的文獻主題為胰島素代謝、下視丘對脂肪的調控、瘦素模擬肽與糖尿病心臟重塑等，沒有任何一篇評估 Pentobarbital 治療肥胖。Pentobarbital 出現在這些文章中，很可能只是動物實驗的麻醉劑。

因此，0.9999 的高分只是圖譜演算法的推論，缺乏臨床或實驗支持，應視為訊號不足的預測。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單文字，僅供參考）：
  - 肝臟：肝衰竭、肝病、肝性昏迷／肝性腦病變
  - 呼吸：慢性阻塞性肺病、阻塞性睡眠呼吸中止症
  - 代謝／血液：紫質症（porphyria）、血小板低下、嗜中性白血球低下、顆粒球缺乏症、貧血
  - 心血管：高血壓、低血壓、心臟病
  - 其他：腎臟病、膽囊疾病、物質濫用／依賴、焦慮及神經症
- **藥物交互作用**：資料庫共 100 筆，其中 **Morphine 為 Major（重大）**，合併使用會加重中樞與呼吸抑制。其餘多為 Moderate，如 Doxycycline、Hydrocortisone、Dexamethasone、Bupropion、Aprepitant、Metronidazole 等；Pyridoxine、Cimetidine 為 Minor。
- 巴比妥類另有耐受性、依賴性、呼吸抑制及過量風險。

仿單的警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 肥胖症預測僅來自模型分數，沒有臨床試驗，文獻中的 Pentobarbital 多僅為動物實驗的麻醉劑，機轉上也無減重依據（L5）。
- 同時，Pentobarbital 具依賴與呼吸抑制風險，且香港唯一許可證為獸用產品，不適合推進人體用途。

**其他預測適應症概覽：**
- 失眠（分數 99.97%，L4）：與原適應症一致，屬於標示內使用而非真正的再利用。文獻皆為草藥或其他化合物的動物實驗，且巴比妥類因耐受、依賴與治療窗窄已非首選。
- 躁症（99.99%，L4）與重度情感疾患（99.93%，L4）：僅有 1960 年代的歷史性臨床經驗報告，無現代對照試驗，現有指引藥物更安全。
- 其餘預測（高維生素症、16p11.2 微缺失症候群、單基因肥胖、拔毛症等）：僅有模型預測，無文獻或試驗，也無合理機轉，皆為 Hold。

**若要推進需要：**
- 取得 Pentobarbital 的作用機轉資料與香港仿單的警語及禁忌內容
- 針對預測適應症進行人體相關的系統性文獻回顧，區分「作為麻醉劑」與「作為治療藥物」的研究
- 若仍想探索，先建立前臨床試驗證據並完成風險效益評估，再考慮臨床設計
