# Pentosan polysulfate：從原適應症（資料未載明）到血小板釋放障礙

## 一句話總結

Pentosan polysulfate 是類肝素（heparin-like）的半合成多醣，目前資料中未載明原適應症。
TxGNN 模型預測它可能對**血小板釋放障礙 (primary release disorder of platelets)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數，且機轉上有明顯疑慮。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Pentosan polysulfate 屬類肝素多醣，具有微弱的抗凝血作用，並與出血風險相關。

預測的疾病是血小板功能缺陷（分泌/釋放異常），患者本身就有出血傾向。抗凝血性質的藥物預期會增加出血風險，而不是矯正缺陷，所以機轉上的合理性存疑。這個預測較可能反映知識圖譜中的鄰近關係，而非實際療效。

TxGNN 同時預測了另外兩個出血性疾病：Glanzmann 血小板無力症（分數 99.65%）和假性血管性血友病（分數 99.62%）。兩者同樣沒有試驗或文獻支持，機轉上也有相同疑慮。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅有 TxGNN 分數，沒有試驗、文獻，也沒有作用機轉資料。
- 藥物的抗凝血與出血風險特性，與預測的出血性血小板疾病方向相反，目前沒有理由推進。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語與禁忌症。
- 補齊 DrugBank 的作用機轉與原適應症資料。
- 系統性檢索 pentosan polysulfate 與血小板功能異常的文獻與臨床試驗。
- 完成血小板功能與出血風險的安全性評估。
- 確認給藥途徑與劑型是否適用於預測的新適應症（目前許可證劑型未載明）。
