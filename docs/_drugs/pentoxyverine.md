## Pentoxyverine：從上呼吸道發炎與鼻炎到急性喉咽炎
{: .text-alpha }

## 一句話總結

Pentoxyverine 是一種鎮咳藥物，原本用於過敏性鼻炎、血管運動性鼻炎、咽炎、感冒等上呼吸道症狀。
TxGNN 模型預測它可能對**急性喉咽炎 (Acute Laryngopharyngitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Pentoxyverine 在香港以單方製劑形式上市，多為咳嗽糖漿，其在上呼吸道症狀的用途已有知識圖譜紀錄，但機轉上為何適用於急性喉咽炎，無法由現有資料確立。

從適應症相近度來看，咽炎、鼻咽炎和感冒都涉及上呼吸道發炎與咳嗽，急性喉咽炎可視為這些既有用途的延伸。但這只是從適應症相近性做出的推論，並非實證。此預測也很可能屬於「接近原適應症」的範圍，而非真正的新用途再利用。

另一個預測是**鼻腔疾病 (Nasal Cavity Disease)**（分數 99.57%），同樣沒有試驗或文獻支持。這是範圍很廣的類別，與既有的鼻炎類適應症高度重疊，可能反映的是標籤相近，而非新的治療訊號，且在未界定具體亞型前難以評估。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來源為知識圖譜關聯，非仿單文字）：
  - 心血管：高血壓、冠狀動脈疾病、心肌梗塞、動脈粥樣硬化、心臟傳導疾病、心臟驟停
  - 呼吸道：慢性阻塞性肺病 (COPD)
  - 消化系統：胰臟炎、消化性潰瘍
  - 精神疾病：精神病性障礙、思覺失調樣疾患、情感型思覺失調
  - 代謝：糖尿病、糖尿病酮酸中毒、代謝性酸中毒
  - 眼科：高眼壓、閉鎖性青光眼
  - 其他：良性前列腺增生、橫紋肌溶解症、血紅素病變
- **藥物交互作用**：資料庫查得 100 筆，以下為部分中度交互作用的藥物：
  - 鴉片類與止痛藥：嗎啡、可待因、二氫可待因、吩坦尼、阿芬太尼、曲馬多、鴉片
  - 止瀉藥：地芬諾辛 (Difenoxin)、地芬諾酯 (Diphenoxylate)
  - 抗組織胺：氯苯那敏 (Chlorpheniramine)、異丙嗪 (Promethazine)、Phenyltoloxamine
  - 其他中樞神經系統相關藥物：阿普唑崙、乙醇、屈大麻酚、Nabilone、甲氧氯普胺、西布曲明、Dichloralphenazone

  整體以中樞神經抑制的疊加效應為主要關注點。

仿單的警語與禁忌資料尚未取得，其他安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.59%），但沒有任何臨床試驗或文獻佐證，證據等級僅為 L5。
- 作用機轉資料缺失，且仿單警語與禁忌尚未取得，無法進入安全性篩選。
- 此預測與既有適應症高度相近，可能不構成真正的再利用。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症（目前為阻擋性缺口）
- 補齊作用機轉資料（如從 DrugBank 查詢）
- 確認急性喉咽炎是否已涵蓋於現有核准適應症內，以判斷是否屬於真正的新適應症
- 系統性檢索 pentoxyverine 用於喉咽炎的臨床與文獻證據
- 針對知識圖譜標示的心血管、COPD、青光眼等禁忌疾病，評估風險
