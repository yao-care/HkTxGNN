# Phenazopyridine：從泌尿道止痛到支氣管炎

## 一句話總結

Phenazopyridine 是一種泌尿道止痛藥，作用於泌尿道黏膜。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Phenazopyridine 是泌尿道止痛劑，作用於泌尿道黏膜，但確切機轉尚未被充分闡明。

現有資料中，沒有任何內容能把這種作用連到呼吸道的發炎或感染。口服後的全身暴露量，也沒有證據顯示與支氣管組織相關。

0.992 的高分只是模型預測，可能反映知識圖譜的拓撲結構（例如共享的症狀或發炎相關鄰居節點），不代表有生物學上的關聯。因此目前找不到可信的機轉連結，這個預測應視為待驗證的假說。
