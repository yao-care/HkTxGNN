# 苯酚 (Phenol)：從局部用化學製劑到慢性萎縮性肢端皮膚炎

## 一句話總結

苯酚 (Phenol) 是局部用化學製劑，在香港有多張外用及注射類產品的許可證，但許可證資料未載明核准適應症。
TxGNN 模型預測它可能對**慢性萎縮性肢端皮膚炎 (Acrodermatitis Chronica Atrophicans)** 有效。
目前**沒有臨床試驗和文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。苯酚是局部用化學製劑，常見用途之一是化學換膚（使角質凝固、造成可控的真皮損傷與重塑）。但現有資料無法說明這種作用如何連結到預測的疾病。

慢性萎縮性肢端皮膚炎與伯氏疏螺旋體 (Borrelia) 感染有關，是一種皮膚萎縮性病變。目前沒有支持的作用路徑，能把苯酚連到這個感染相關的皮膚病變。

因此，0.9995 的高分只代表模型在知識圖譜中的關聯很強，不等於有機轉或臨床上的支持。這個預測應視為待驗證的假說，不宜當作有證據的結論。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有臨床試驗或文獻，證據等級為 L5。
- 作用機轉資料缺漏，也沒有可信的路徑把苯酚連到伯氏疏螺旋體相關的皮膚萎縮。

**其他預測適應症：**
- 另外 4 個預測（兒童結締組織病相關次發性間質性肺病、新生兒皮肌炎、無肌病性皮肌炎、痤瘡性瘢痕疙瘩）同樣停在 S0 階段。
- 其中新生兒皮肌炎唯一連結的試驗測試的是羥氯喹 (Hydroxychloroquine) 與低劑量類固醇，並非苯酚，應是檢索誤配。
- 痤瘡性瘢痕疙瘩只有苯酚換膚用於痤瘡疤痕的間接報告，證據等級 L4，列為研究問題，外推到本適應症仍不確定。

**若要推進需要：**
- 取得苯酚的詳細作用機轉資料（可查詢 DrugBank）。
- 下載並解析香港衛生署的仿單，補齊警語、禁忌與核准適應症。
- 確認劑型與給藥途徑是否適用於目標疾病。系統性暴露的毒性是需要特別評估的疑慮。
- 進行針對性的文獻與試驗檢索，確認是否存在苯酚用於此疾病的直接證據。
