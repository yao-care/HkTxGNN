# Phenoxymethylpenicillin：從抗菌用藥（原適應症未登載）到會厭炎

## 一句話總結

Phenoxymethylpenicillin（青黴素 V）是口服青黴素類抗生素，但香港許可證資料未登載原適應症。
TxGNN 模型預測它可能對**會厭炎 (Epiglottitis)** 有效，不過目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Phenoxymethylpenicillin 屬於青黴素類抗生素，一般認為透過抑制細菌細胞壁合成而殺菌（此為藥理常識，並非本次資料所提供）。會厭炎多為細菌感染，歷史上以 B 型流感嗜血桿菌（Haemophilus influenzae type b）最常見，所以模型把抗菌藥和會厭炎連在一起，在機轉上有一定道理。

但這個預測的臨床實用性很低。口服青黴素 V 的抗菌譜較窄，而會厭炎是可能迅速阻塞呼吸道的急症，通常需要靜脈注射的廣效抗生素。0.999 的高分較可能反映知識圖譜中「青黴素類藥物」與「上呼吸道感染」的鄰近關係，不代表真正的老藥新用潛力。

另外，TxGNN 的第二個預測是**喉炎 (Laryngitis)**，已有直接證據，但結果是負面的：
- 一項雙盲試驗（PMID 3918495）發現青黴素 V 對成人急性喉炎無效。
- 多篇 Cochrane 系統性回顧（PMID 15674965、17443555、23543536、26002823）也未發現抗生素有臨床意義的益處。

這也間接說明，該藥在上呼吸道症狀的預測，不宜單憑模型分數推進。

## 結論與下一步

**決策：Hold**

**理由：**
- 會厭炎的預測只有模型分數，沒有任何臨床試驗或文獻佐證。
- 口服窄譜青黴素也不符合會厭炎的急症治療需求，因此不建議推進。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌症，以及原適應症資料。
- 補充 DrugBank 的作用機轉（MOA）資料。
- 由臨床專家評估口服青黴素 V 在會厭炎的可行性，特別是給藥途徑（目前路徑相容性尚未評估）。
- 若有研究興趣，可改以特定細菌性亞型（如喉部放線菌病個案）作為較窄的研究問題。

> 本報告僅供研究參考，不構成醫療建議。預測結果需經臨床驗證才能應用。
