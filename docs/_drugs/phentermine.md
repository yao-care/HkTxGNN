# Phentermine：從體重控制到維生素過多症 (Hypervitaminosis)

## 一句話總結

Phentermine 是一種擬交感神經胺類食慾抑制劑，一般藥理上用於體重控制。
TxGNN 模型預測它可能對**維生素過多症 (Hypervitaminosis)** 有效，但目前**沒有任何臨床試驗**，也**沒有任何文獻**支持這個方向。這個預測只來自知識圖譜的模型運算。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Phentermine 是擬交感神經胺類藥物，依一般藥理，它促進正腎上腺素釋放並抑制食慾，主要用於體重管理。

這個作用和維生素過量沒有已知的關聯。維生素過多症的處置重點在於停用過量的維生素並給予支持性治療，食慾抑制劑不會影響這個病理過程。因此這個預測的高分（99.57%）很可能反映知識圖譜的結構性關聯，而不是真實的藥理連結，在機轉上找不到合理的解釋。

模型同時給出另外三個預測：近端 16p11.2 微缺失症候群、hypertelorism（已過時的本體論詞條）和 frontorhiny。三者同樣都是 L5、無任何試驗或文獻。其中 16p11.2 微缺失症候群因為常伴隨肥胖傾向，理論上較有間接關聯，但也屬推測，且該症候群有神經發展特徵，使用類似刺激劑的藥物需要審慎評估安全性。

## 結論與下一步

**理由：**
- 這個預測只有模型分數，沒有任何臨床試驗或文獻，證據等級為 L5。
- 藥理上也找不到 phentermine 與維生素過多症之間的合理連結，不建議投入資源。
