# Phenylpropanolamine：從過敏性鼻炎與感冒到鼻腔疾病

## 一句話總結

Phenylpropanolamine 是一種擬交感神經類的鼻充血緩解劑，原本用於過敏性鼻炎、血管運動性鼻炎、咽炎及感冒等上呼吸道症狀。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，
目前**沒有臨床試驗**，僅有 **3 篇文獻**（1 篇人體比較研究、2 篇動物實驗）。這個預測在很大程度上只是原適應症的延伸，而非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Phenylpropanolamine 是一種兼具間接與直接作用的擬交感神經藥物，可刺激鼻黏膜血管上的 α 腎上腺素受體，造成血管收縮，減少黏膜腫脹並降低鼻阻力。

這個機轉與鼻塞的緩解一致，也與其已知適應症（過敏性鼻炎、血管運動性鼻炎、感冒）高度重疊。因此「鼻腔疾病」其實是原適應症的較廣泛說法，不算真正的老藥新用。

需要特別注意：此藥在美國等多個市場已因出血性中風風險而被撤回或限制使用，這是推進新適應症的重大安全障礙。

## 安全性考量

- **知識圖譜中的禁忌疾病**（非仿單內容）：高血壓、肝衰竭、癲癇、失眠、慢性阻塞性肺病、腎臟病、胰臟炎、肝病、膽囊疾病、血小板低下、甲狀腺功能低下、消化性潰瘍、發炎性腸病、良性攝護腺增生、痛風、鐮狀細胞貧血、血友病、威爾森氏症等。
- **藥物交互作用**：共查得 100 筆，以下為主要者。
  - 重度：Bupropion、Lorcaserin、Diethylpropion、Phentermine
  - 中度：Epinephrine、Isometheptene，以及多種降血糖藥（如 Metformin、Acarbose、Pioglitazone、Canagliflozin、Dapagliflozin、Empagliflozin）
- **其他重要風險**：此藥因出血性中風風險，已在美國等市場被撤回或限制使用。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 「鼻腔疾病」大致是已核准適應症的重述，並非真正的新適應症，且缺乏臨床試驗。證據僅有一篇比較研究和兩篇動物實驗，等級為 L4。
- 出血性中風風險及廣泛的心血管禁忌，使效益風險比不利。

**若要推進需要：**
- 取得香港許可證的仿單，包含核准適應症、警語與禁忌症
- 取得詳細的作用機轉資料
- 釐清「鼻腔疾病」是否與現有適應症有實質差異
- 評估出血性中風風險，並與較安全的替代減充血劑比較
