## Pibrentasvir：從慢性 C 型肝炎到 B 型肝炎病毒感染
{: .text-alpha }

## 一句話總結

Pibrentasvir 是 HCV NS5A 抑制劑，與 glecaprevir 組成複方，原本用於慢性 C 型肝炎。
TxGNN 模型預測它可能對 **B 型肝炎病毒感染 (Hepatitis B Virus Infection)** 有效，但目前**沒有任何直接研究 B 型肝炎的臨床試驗或文獻**，此預測僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，pibrentasvir 是 HCV NS5A 抑制劑，與 glecaprevir（NS3/4A 蛋白酶抑制劑）組成固定劑量複方，在 C 型肝炎中的療效已有大量文獻證實。

分數來自 TxGNN 模型（深度學習），這個高分可能反映模型學到的各種肝炎適應症之間的相似性，而非生物學證據，也不代表真正的藥物標靶重疊。HBV 沒有 NS5A 同源蛋白，複製策略也不同（cccDNA、反轉錄酶），因此**機轉上並不支持直接的作用關聯**。

本次檢索到的文獻幾乎全部是 C 型肝炎研究，沒有一篇在 B 型肝炎中測試 pibrentasvir。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗或文獻直接研究 pibrentasvir 對 B 型肝炎的作用，證據等級僅為 L5。
- 機轉上，HBV 缺乏 NS5A 標靶；分數來自 TxGNN 模型（深度學習），高分可能反映模型學到的相關疾病間相似性，而非生物學證據。

**若要推進需要：**
- 體外 HBV 複製模型中測試 pibrentasvir 的抗病毒活性
- 取得詳細作用機轉資料，以及香港許可證的核准適應症與仿單警語
- 若體外有訊號，再評估早期臨床試驗設計與安全性監測計畫

**附註：**同一批預測中的其他疾病（HIV、E 型肝炎、A 型肝炎、Omsk 出血熱、Kyasanur 森林病、動物疾病等）同樣缺乏直接證據，且機轉上均無合理連結，建議一併維持 Hold。
