## Pimecrolimus：從異位性皮膚炎到脂漏性皮膚炎
{: .text-alpha }

## 一句話總結

Pimecrolimus 是外用鈣調神經磷酸酶抑制劑，原本用於異位性皮膚炎（atopic eczema）。
TxGNN 模型預測它可能對**脂漏性皮膚炎 (Seborrheic Dermatitis)** 有效，
目前有 **1 個直接相關的 Phase 2 臨床試驗**和 **17 篇文獻**（含 2 篇隨機對照試驗的系統性回顧）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）原始資料。根據已知資訊，pimecrolimus 屬於外用鈣調神經磷酸酶抑制劑，已知可阻斷 T 細胞活化，抑制 IL-2、IL-4、干擾素-γ 與 TNF-α 等發炎細胞激素的釋放，也能抑制肥大細胞去顆粒。

脂漏性皮膚炎是一種慢性、易復發的發炎性皮膚病，與皮膚上的 Malassezia 酵母菌引發的發炎反應有關。其發炎機轉與異位性皮膚炎有重疊，因此以抗發炎為主的鈣調神經磷酸酶抑制劑，在機轉上合理可行。文獻也提到 pimecrolimus 可能對 Malassezia 有抗黴活性，但此點仍需進一步確認。

與外用類固醇相比，pimecrolimus 不含類固醇，長期使用不會有皮膚萎縮等副作用，這是它在臉部脂漏性皮膚炎的潛在優勢。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自藥物-疾病關聯資料，非仿單原文）：尋常疣、疣狀表皮發育不良、肛門生殖器人類乳突病毒感染、單純疱疹感染、淋巴系統疾病、傳染性單核球增多症、慢性 EB 病毒感染症候群、帶狀疱疹、水痘、疱疹性皮膚炎、Netherton 症候群、迴旋狀線狀魚鱗癬。
- **使用上的防護重點**：外用鈣調神經磷酸酶抑制劑有長期使用的理論性惡性腫瘤風險警語；2 歲以下嬰幼兒使用受限；免疫功能低下者及感染皮膚部位應避免使用。
- **藥物交互作用**：資料庫查得 100 筆潛在交互作用，但嚴重度分級皆為未知，例如 Phentermine、Pantoprazole、Doxycycline、Metformin、Omeprazole、Simvastatin、Prednisone 等，臨床意義需另行查證。

香港仿單的警語與禁忌症資料尚未取得，其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有 1 個已完成的 Phase 2 隨機雙盲試驗直接針對脂漏性皮膚炎，另有 2 篇 RCT 系統性回顧顯示 pimecrolimus 1% 有效且耐受性良好。但缺少 ≥2 個已完成的 Phase 3 RCT，因此證據等級為 L2。
- 香港許可證未載明此適應症，屬於仿單外使用，須搭配安全防護。

**若要推進需要：**
- 取得 NCT00403559 的結果數據，並進行 Phase 3 確認性試驗
- 取得香港仿單的警語與禁忌症全文，完成安全性篩查
- 補充詳細作用機轉資料（MOA）
- 確認長期使用的惡性腫瘤風險監測計畫，並明確限制嬰幼兒與免疫低下族群的使用

**其他預測適應症的補充說明：**
- **皮膚炎（dermatitis，排名 2）**：證據等級 L1，但主要是既有異位性皮膚炎適應症的再確認，另有慢性手部皮膚炎與口周皮膚炎的 Phase 3 試驗。決策為 Proceed with Guardrails。
- **疹（exanthem，排名 3）**：證據等級 L2，僅有口腔扁平苔癬、外陰硬化性苔癬等小型先導試驗，結果不一致，建議列為研究問題（Research Question）。
- **慢性萎縮性肢端皮膚炎（排名 4）**：僅有模型預測，無試驗與文獻，且屬螺旋體感染，外用免疫抑制劑可能適得其反，建議 Hold。
