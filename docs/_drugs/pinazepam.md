# Pinazepam：苯二氮平類藥物與失眠症的老藥新用評估

## 一句話總結

Pinazepam 是苯二氮平類（benzodiazepine）鎮靜劑，目前在香港**未上市**，且原始核准適應症資料缺失。
TxGNN 模型預測它可能對**失眠症 (Insomnia)** 有效，
但目前僅有 **1 個臨床試驗**（且與 pinazepam 本身無直接關聯）、**0 篇相關文獻**支持，證據非常有限。

## 為什麼這個預測合理？

目前缺乏 pinazepam 專屬的作用機轉（MOA）資料。根據已知資訊，pinazepam 屬於**苯二氮平類（benzodiazepine）**藥物，此類藥物的共通機轉是透過 GABA-A 受體正性異位調節，增強中樞抑制性神經傳導，產生鎮靜、抗焦慮及助眠效果，是此類藥物成員的已知 class-level 特性。

失眠症正是苯二氮平類藥物最典型、最廣泛使用的適應症之一，因此從藥理機轉角度看，此預測方向合理。但需注意：這是「藥物類別」層級的合理性推論，並非 pinazepam 本身經人體試驗驗證的專屬證據——目前查無任何直接評估 pinazepam 用於失眠症的臨床試驗或文獻。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一收錄的臨床試驗實際與 pinazepam 無關（相關性評級 C，非藥物介入研究），且完全無支持性文獻，實質證據強度僅達 L5（模型預測層級），評分系統標註的 L4 主要來自苯二氮平類的 class-level 機轉合理性，而非藥物專屬證據。
- 安全性資料（TFDA 仿單警語、禁忌症）為 Blocking 缺口，無法進行安全性初評；藥物本身也未在香港上市。

**若要推進需要：**
- 補齊 TFDA／原廠仿單安全性資料（警語、禁忌症、DDI）— 此為 Blocking 缺口，需優先處理
- 取得 pinazepam 專屬的作用機轉（MOA）資料
- 尋找真正評估 pinazepam 用於失眠症或酒精戒斷相關適應症的臨床試驗或文獻（目前各資料庫查詢均為 0 筆）
- 確認藥物在其他地區的上市與核准適應症狀態，作為原適應症的參照基準
