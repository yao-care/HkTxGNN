# Pipenzolate：從腸胃痙攣到失眠

## 一句話總結

Pipenzolate 是一種四級銨類抗膽鹼藥物（蕈毒鹼拮抗劑），香港已有上市許可。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Pipenzolate 屬於四級銨類抗膽鹼藥物，主要作用是阻斷蕈毒鹼受體，用於緩解腸胃痙攣。

從機轉推論，中樞蕈毒鹼拮抗作用以及類似抗組織胺的鎮靜效果，確實可能影響睡眠，這是預測與失眠相連結的可能原因。

但這個連結有明顯的限制：四級銨化合物不易穿過血腦屏障，會削弱其中樞性助眠效果。此外，周邊抗膽鹼副作用（口乾、尿滯留、心跳加快）可能讓失眠用藥的耐受性變差。高分數（0.994）只是計算模型的預測，並無實際研究佐證。

## 安全性考量

安全性資訊請參考原廠仿單。

另依藥理類別推測，周邊抗膽鹼作用（口乾、尿滯留、心跳加快）可能影響耐受性，使用於失眠族群時需特別留意。這屬於類別層級的推論，並非來自仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，沒有任何臨床試驗或文獻支持。
- 四級銨結構難以進入中樞，且作用機轉與安全性資料都不完整，目前不宜推進。

**若要推進需要：**
- 補齊作用機轉（MOA）資料，並評估藥物穿過血腦屏障的程度。
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症。
- 搜尋並建立抗膽鹼藥物用於失眠的臨床前或臨床證據。
- 評估周邊抗膽鹼副作用在失眠族群中的風險效益。
