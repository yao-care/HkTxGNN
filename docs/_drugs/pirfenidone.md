# Pirfenidone：從特發性肺纖維化到皮外肥大細胞瘤

## 一句話總結

Pirfenidone 是一種抗纖維化藥物，已知用於特發性肺纖維化（IPF，依 2018 年病例報告摘要）。
TxGNN 模型預測它可能對**皮外肥大細胞瘤 (Extracutaneous Mastocytoma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅是模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Pirfenidone 具有抗纖維化與抗發炎活性，主要透過降低 TGF-β 訊號與促發炎細胞激素來發揮作用。

肥大細胞瘤這類肥大細胞腫瘤通常由 KIT 訊號驅動，Pirfenidone 並非激酶抑制劑。因此目前沒有已知的機轉連結，抗纖維化作用也不能直接推論為腫瘤抑制作用。

TxGNN 的高分（0.997）只代表知識圖譜上的關聯，不代表藥理上合理。這個預測的合理性很低，不應過度解讀。

## 結論與下一步

**決策：Hold**

**理由：**
- 此適應症僅有模型預測，沒有試驗、文獻或可辨識的機轉連結（L5）。
- 疾病由 KIT 驅動，而 Pirfenidone 不是激酶抑制劑，機轉上不相容。

**若要推進需要：**
- 補齊 Pirfenidone 的作用機轉資料（DrugBank），並評估是否與肥大細胞生物學有任何關聯。
- 取得香港衛生署的仿單，確認原核准適應症與警語、禁忌症。
- 先做前臨床研究（如肥大細胞株實驗），再考慮任何臨床方向。
- 在同一份預測清單中，「纖維母細胞腫瘤 (Fibroblastic Neoplasm)」是證據較多的候選（L3，有 Dupuytren 病纖維母細胞的體外研究，以及 2003 年家族性腺瘤性息肉症desmoid 腫瘤的小型先導研究）。該方向建議另行評估，但需留意兩篇病例報告提示的潛在安全訊號（使用後出現未分化多形性肉瘤、皮膚纖維瘤惡化）。
