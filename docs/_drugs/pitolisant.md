# Pitolisant：從猝睡症到失眠 (Insomnia)

## 一句話總結

Pitolisant 是組織胺 H3 受體反向促效劑，文獻顯示它主要用於治療猝睡症的日間過度嗜睡。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有任何直接針對失眠的臨床試驗**，僅有 **1 個已撤銷的試驗**和 **7 篇間接相關文獻**。
更重要的是，這個預測在機轉上方向相反，不建議推進。

## 為什麼這個預測合理？

**這個預測在機轉上不合理。** Pitolisant 阻斷 H3 自體受體，增加腦內組織胺釋放，強化促醒訊號，因此才用於治療猝睡症的日間嗜睡。失眠是這類藥物已知的不良反應，也就是說，藥理作用與治療失眠的方向相反。

TxGNN 的高分（0.997）很可能只反映知識圖譜中，這個藥與睡眠－覺醒相關疾病距離很近，並不代表治療效果。不應把這個分數解讀為有益的證據。

目前缺乏詳細的作用機轉資料（DrugBank MOA 欄位為空），上述機轉說明來自文獻與藥理分類。

## 安全性考量

安全性資訊請參考原廠仿單。

此外，依本次評估的機轉分析，失眠是 H3 拮抗劑／反向促效劑類藥物已知的不良反應。

## 結論與下一步

**決策：Hold**

**理由：**
- 藥理機轉與失眠治療方向相反，失眠反而是已知不良反應，TxGNN 高分應視為圖譜鄰近性的假象。
- 沒有失眠相關的臨床試驗，唯一的試驗已撤銷且與失眠無關，證據僅為 L4（機轉與間接文獻）。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌資料
- 補齊 DrugBank 的作用機轉資料
- 除非有新的直接證據顯示對失眠有益，否則不建議投入資源

**同一藥物的其他預測（供參考）：**
- **注意力不足過動症 (ADHD)**（TxGNN 99.36%，L4）：機轉合理，H3 阻斷可增加腦內多種神經傳導物質釋放，但支持僅限綜述與前臨床資料，且文獻指出 H3 拮抗劑在 ADHD 的臨床試驗結果令人失望。可列為研究問題，不建議直接推進。
- **Faciodigitogenital syndrome**（TxGNN 99.29%，L5）：未找到任何機轉連結、試驗或文獻，僅為模型預測，建議 Hold。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。*
