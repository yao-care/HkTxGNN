# Plerixafor：從造血幹細胞動員到惰性漿細胞骨髓瘤

## 一句話總結

Plerixafor 是 CXCR4 拮抗劑，臨床上常與 G-CSF 併用來動員造血幹細胞（此為一般藥理知識，香港許可證資料未載明適應症）。
TxGNN 模型預測它可能對**惰性漿細胞骨髓瘤 (Indolent Plasma Cell Myeloma)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Plerixafor 是 CXCR4 拮抗劑。CXCR4/CXCL12 軸會把骨髓瘤細胞固定在骨髓微環境中。阻斷這條路徑，理論上可能干擾骨髓瘤細胞的歸巢，並使其對其他治療更敏感。

Plerixafor 已用於骨髓瘤病人的幹細胞動員（搭配 G-CSF），但那是支持性照護，不是治療惰性骨髓瘤本身。從「動員幹細胞離開骨髓」推到「治療疾病」，目前只是機轉上的假設。

TxGNN 的高分（99.97%）是計算預測。提供的資料中沒有任何試驗或文獻可以佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有模型預測，沒有臨床試驗與文獻佐證。
- 缺少香港衛生署仿單的警語與禁忌症資料，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症），完成安全性篩選
- 從 DrugBank 補齊作用機轉（MOA）資料
- 檢索 CXCR4 抑制於骨髓瘤（含惰性／冒煙型）的前臨床與臨床研究
- 確認「惰性漿細胞骨髓瘤」對應的標準疾病名稱（例如冒煙型骨髓瘤）及其臨床定義
- 評估給藥途徑的相容性（目前為注射劑，長期給藥的可行性待確認）

其餘 4 個預測適應症（CMM7、兒童軟腦膜黑色素瘤、上皮樣葡萄膜黑色素瘤、支氣管炎）同樣只有 L5 證據、無試驗與文獻，目前皆為 Hold。其中支氣管炎的機轉依據薄弱，且 Plerixafor 會引起白血球增多，風險效益不利，可能是圖譜網路的假象。
