# Polymyxin B：從抗菌用藥到支氣管炎

## 一句話總結

Polymyxin B 是作用於革蘭氏陰性菌的殺菌性多肽類抗生素，香港已有 20 張相關許可證。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有臨床試驗**，文獻多為病例系列、激發試驗和動物實驗，並無直接療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Polymyxin B 是帶陽離子的殺菌性多肽，會破壞革蘭氏陰性菌的外膜。因此它在機轉上可能適用於由多重抗藥性綠膿桿菌或不動桿菌引起的氣管支氣管感染。

文獻中確實有吸入式 Polymyxin B 用於這類感染的報告，例如呼吸器相關肺炎與氣管支氣管炎。但一般支氣管炎多為病毒性或非感染性，抗菌機轉無法直接套用，所以只有特定的革蘭氏陰性菌感染才有合理性。TxGNN 的高分（99.87%）沒有臨床資料支持，應視為待驗證的假說。

另有多篇文獻是用吸入 Polymyxin B 誘發支氣管收縮或嗜酸性球性支氣管炎的激發試驗和動物模型。這類訊號屬於安全疑慮，不是治療證據。

## 安全性考量

- **文獻提示的風險**：多篇文獻顯示吸入 Polymyxin B 可誘發支氣管收縮或氣道嗜酸性球發炎，並有專文警示吸入的危險。若考慮用於呼吸道，這是首要的安全疑慮。

香港衛生署的仿單警語與禁忌症資料尚未取得，其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎沒有任何臨床試驗，文獻只有病例系列、激發試驗與動物研究，證據等級為 L4。
- 一般支氣管炎多非細菌性，且吸入有誘發支氣管收縮的疑慮，TxGNN 的高分不足以支持推進。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症（此為阻擋性資料缺口）。
- 補齊作用機轉資料（可查 DrugBank）。
- 將適應症縮小為「多重抗藥革蘭氏陰性菌引起的氣管支氣管感染」，再評估是否有對照研究。
- 確認呼吸道給藥途徑是否可行。從品名看，香港現有許可證多為眼、耳或軟膏類產品，未見吸入劑型。

**補充：** 同一份資料中，第 3 順位的**結膜炎 (Conjunctivitis)** 證據遠較強，有 3 個臨床試驗和多篇 RCT，證據等級 L1，建議決策為 Proceed with Guardrails。但證據全部來自複方產品（如搭配 Trimethoprim 或 Neomycin），且更接近既有用途，並非真正的新用途。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證後才能應用。
