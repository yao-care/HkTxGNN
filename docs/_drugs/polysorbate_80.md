# Polysorbate 80：從賦形劑（無核准適應症）到先天性魚鱗癬樣紅皮症

## 一句話總結

Polysorbate 80 是一種非離子界面活性劑與乳化劑，主要作為藥品賦形劑，DrugBank 沒有列出原適應症。
TxGNN 模型預測它可能對**先天性魚鱗癬樣紅皮症 (Congenital Ichthyosiform Erythroderma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Polysorbate 80 是非離子界面活性劑，主要用作乳化劑和賦形劑，不是以治療疾病為目的的活性成分。因此，目前沒有已證實的藥理關聯可以連結到新適應症。

先天性魚鱗癬樣紅皮症是遺傳性角化異常疾病，常見致病基因包括 TGM1、ALOX12B、ALOXE3。TxGNN 給出 0.994 的高分，較可能反映知識圖譜中的節點連結（例如皮膚或脂質屏障相關節點），而不是真實的療效。理論上，界面活性劑可能影響角質層脂質排列或外用基質的滲透性，但這只是推測，目前沒有任何資料支持。

此外，Polysorbate 80 在某些情況下可能造成局部刺激和過敏反應，對本來就受損的皮膚是安全性疑慮。賦形劑類成分也不太可能處理基因層面的病因。整體而言，這個預測應視為低可信度的模型訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有模型預測，沒有臨床試驗或文獻。
- 機轉上沒有已知關聯，且該成分可能對受損皮膚造成刺激或過敏，因此不建議推進。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症，這是進入安全性篩選的前提。
- 查詢 DrugBank 取得作用機轉資料，評估機轉連結。
- 檢索 Polysorbate 80 與魚鱗癬、皮膚屏障相關的前臨床或機轉研究。
- 確認外用給藥途徑的可行性，以及對受損皮膚的刺激與致敏風險。
