# Polysorbate 80：從乾眼症到先天性魚鱗癬樣紅皮症

## 一句話總結

Polysorbate 80 是一種非離子性界面活性劑與乳化劑，原本用於乾眼症（dry eye syndrome）與乾眼病（xerophthalmia）的眼部潤滑。
TxGNN 模型預測它可能對**先天性魚鱗癬樣紅皮症 (Congenital Ichthyosiform Erythroderma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Polysorbate 80 是一種非離子性界面活性劑與乳化劑，在眼用製劑中主要作為潤滑與淚膜支持的成分。因此，以下推論均為推測，尚未經資料驗證。

先天性魚鱗癬樣紅皮症是一種表皮分化與脂質屏障功能異常的遺傳性皮膚疾病。理論上，polysorbate 80 可能作為外用潤膚劑或皮膚屏障的載體，或協助脂溶性藥物遞送。乾眼症需要表面潤滑，魚鱗癬需要保濕與屏障修復，兩者只有概念上的鬆散相似。

TxGNN 分數雖然很高（99.43%），但它來自知識圖譜的計算預測，並非實際研究結果。此外，界面活性劑可能刺激或致敏已受損的皮膚，這是潛在的安全疑慮。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，沒有臨床試驗與文獻佐證，且缺乏作用機轉資料，無法建立藥物專屬的機轉連結。
- 現有香港產品為眼用滴劑，與皮膚疾病所需的給藥途徑是否相容尚未評估，且界面活性劑可能刺激受損皮膚。

**若要推進需要：**
- 補充 polysorbate 80 的作用機轉資料（例如查詢 DrugBank）
- 取得香港衛生署的仿單，確認警語與禁忌症
- 評估外用皮膚製劑的給藥途徑可行性與皮膚刺激性
- 進行文獻與臨床試驗檢索，確認是否有魚鱗癬相關的前臨床或臨床研究
- 與現有魚鱗癬保濕/角質溶解療法比較，確認是否有實際臨床價值
