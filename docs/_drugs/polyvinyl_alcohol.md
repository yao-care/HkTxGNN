# Polyvinyl Alcohol：從乾眼症到先天性魚鱗癬樣紅皮症

## 一句話總結

Polyvinyl Alcohol（聚乙烯醇）是一種成膜性親水聚合物，原本用於乾眼症（dry eye syndrome）與乾燥性角結膜炎（xerophthalmia）的人工淚液。
TxGNN 模型預測它可能對**先天性魚鱗癬樣紅皮症 (congenital ichthyosiform erythroderma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Polyvinyl Alcohol 是一種成膜、親水的聚合物，作為眼用潤滑劑，在眼表形成保護膜以減緩水分散失。

一個可能但尚未驗證的推論是：它在皮膚表面可能發揮封閉（occlusive）或保濕作用，減少經皮水分散失，對脫屑的皮膚帶來表層的緩解。不過，魚鱗癬是遺傳性角質化異常疾病，潤滑劑最多只能提供症狀性、表淺的改善，無法改變疾病本身。

高分預測較可能反映知識圖譜中疾病之間的網絡相似性，而非直接的生物學證據。其他三個預測（火棉嬰兒、板層狀魚鱗癬、泳衣型魚鱗癬）同樣缺乏資料；火棉嬰兒屬自限性疾病，已有成熟的潤膚與加濕照護，且新生兒的皮膚吸收與安全性尚未評估。此外，沒有資料將其與標準的角質溶解劑、潤膚劑或維生素 A 酸類藥物比較。

## 安全性考量

- **知識圖譜標示的疾病禁忌（非仿單內容）**：高血壓、糖尿病（含酮酸中毒）、良性前列腺增生、心臟與心血管疾病（含冠狀動脈疾病、心臟猝死、心臟傳導疾病）、閉角型青光眼、甲狀腺功能亢進（含 Graves 病、甲狀腺毒症）、動脈硬化與粥狀動脈硬化。這些資料來自模型的藥物－疾病關聯，須與仿單核對後才能採用。

其餘警語、禁忌與藥物交互作用，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 四個預測適應症皆只有模型分數，沒有臨床試驗或文獻佐證（L5）。
- 作用機轉不明，魚鱗癬是遺傳性疾病，潤滑劑至多提供症狀性緩解，且新生兒用藥的安全性未評估。

**若要推進需要：**
- 補齊作用機轉資料，並評估皮膚外用的合理性。
- 取得香港仿單的警語與禁忌，完成安全性篩選。
- 確認皮膚外用的劑型與給藥途徑是否可行（目前香港許可證皆為眼用製劑）。
- 進行文獻與試驗檢索；若有支持，可考慮與標準潤膚劑比較的小型探索性研究。
