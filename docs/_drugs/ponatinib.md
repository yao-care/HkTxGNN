# Ponatinib：從原適應症（資料未載明）到遺傳性牙齦纖維瘤病

## 一句話總結

Ponatinib 是一種多標的激酶抑制劑，在香港已有 2 張上市許可證，但本次提供的資料沒有載明原核准適應症。
TxGNN 模型預測它可能對**牙齦纖維瘤病 (Fibromatosis, Gingival)** 有效。
目前**沒有臨床試驗和文獻**支持，證據僅限模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據一般藥理知識，Ponatinib 是多標的激酶抑制劑，可抑制 BCR-ABL、PDGFR、FGFR、VEGFR、KIT、RET 及 SRC 家族激酶。這個說明不是來自本次提供的資料。

其中 PDGFR、FGFR 和 SRC 與纖維母細胞增生及纖維化有關，所以推測 Ponatinib 可能影響纖維化性病變。牙齦纖維瘤病（例如 SOS1 相關的遺傳型）是良性的纖維組織過度增生，這是模型預測較可能的連結。

這個連結目前純屬推測。沒有任何試驗或文獻直接驗證，原適應症與新適應症的關聯性也尚未評估。此外，Ponatinib 已知有動脈阻塞事件、靜脈血栓、心衰竭和肝毒性的重大風險（一般知識）。對良性疾病而言，風險效益比不利。

**補充：** 模型的第二名預測是**脂肪肉瘤 (Liposarcoma)**，分數 99.00%，證據等級 L4。目前僅有 1 篇 2017 年的前臨床激酶篩選研究（PMID 29132397），從提供的資料看不出該研究是否實際測試過 Ponatinib。若要在這個藥物上找較有方向的候選，這個預測值得另行評估。

## 安全性考量

安全性資訊請參考原廠仿單。藥物交互作用查詢無結果。

一般知識提示 Ponatinib 有動脈阻塞事件、靜脈血栓栓塞、心衰竭和肝毒性的**黑框警語**，這點來自模型推論，不是提供資料中的安全性欄位。香港衛生署仿單的警語與禁忌資料尚未取得。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅有模型預測（L5），沒有任何臨床試驗或文獻支持。
- 目標疾病是良性疾病，而藥物已知有嚴重心血管與肝毒性風險，風險效益比不利。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料（目前為阻擋項目，無法進入安全性篩選）
- 補齊 DrugBank 的作用機轉資料，並確認原核准適應症
- 搜尋 PDGFR/FGFR/SRC 抑制與牙齦纖維化相關的前臨床或病例研究
- 評估是否改為優先研究脂肪肉瘤預測，並確認 PMID 29132397 是否實際涉及 Ponatinib
