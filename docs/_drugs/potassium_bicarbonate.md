# 碳酸氫鉀（Potassium Bicarbonate）：原適應症資料缺失，預測新適應症為胃十二指腸炎

## 一句話總結

碳酸氫鉀（DrugBank ID: DB11098）目前缺乏原適應症與作用機轉（MOA）資料，且尚未在香港取得任何藥品許可證。
TxGNN 模型預測它對**胃十二指腸炎 (Gastroduodenitis)** 有極高分數（99.72%），
但目前**無任何臨床試驗或文獻**支持這個方向，且已知口服鉀鹽本身具有刺激/腐蝕腸胃黏膜的風險，方向可能與「治療」相反。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，DrugBank 未提供碳酸氫鉀的 MOA 說明，也沒有記載原本核准的適應症。

根據系統提供的關聯性分析，碳酸氫鉀作為鹼化劑/電解質補充劑，理論上可能因「中和胃酸」的作用與制酸劑產生嵌入相似性，因而被 TxGNN 賦予高分。但這個關聯純屬模型嵌入相似性推論，並非明確的藥理機轉證據。

更重要的是，已知口服鉀鹽（含碳酸氫鉀、氯化鉀等）製劑本身具有刺激/腐蝕胃腸黏膜、誘發潰瘍與出血的風險——這與「治療」胃十二指腸炎的方向相反。也就是說，此預測不僅缺乏正向機轉支持，甚至可能存在方向性矛盾，需要特別謹慎看待。
