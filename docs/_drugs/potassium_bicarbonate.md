# Potassium Bicarbonate：從原適應症（資料未載明）到胃十二指腸炎

## 一句話總結

Potassium Bicarbonate（碳酸氫鉀）已在香港上市，但目前資料中沒有記載原適應症。
TxGNN 模型預測它可能對**胃十二指腸炎 (Gastroduodenitis)** 有效，預測分數 99.72%。
目前**沒有任何臨床試驗或文獻**支持，僅是模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。DrugBank 沒有收錄 MOA，也沒有原適應症紀錄，因此無法做完整的機轉關聯分析。

只能做較薄弱的間接推論：碳酸氫鹽是鹼性緩衝劑，可能中和胃酸，作用類似碳酸氫鈉這類制酸劑。這頂多帶來症狀緩解，不能治療胃十二指腸黏膜本身的發炎。

另一方面，鉀鹽已知對腸胃道有刺激性，用在已發炎的胃十二指腸黏膜可能反而不利。TxGNN 的高分（0.997）只是模型預測，沒有任何試驗、文獻或機轉證據佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據只有模型預測（L5），沒有臨床試驗、文獻或機轉資料。
- 鉀鹽對胃腸道的刺激性可能與預測的適應症相衝突。
- 香港衛生署仿單的警語與禁忌資料尚未取得（阻斷性資料缺口），無法進入安全性初篩。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語、禁忌症與核准適應症。
- 從 DrugBank 補充作用機轉（MOA）。
- 檢索 PubMed 與 ClinicalTrials.gov，確認是否有碳酸氫鹽或鉀鹽用於胃十二指腸炎的研究。
- 評估鉀鹽對發炎黏膜的刺激風險。
- 釐清各許可證產品的成分與劑型，以確認給藥途徑是否適用。
