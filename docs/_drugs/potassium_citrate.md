## Potassium Citrate: 家族性內臟肌病變 (familial visceral myopathy)
{: .text-alpha }

## 一句話總結

Potassium Citrate（檸檬酸鉀）是一種提供鉀離子與鹼性負荷（檸檬酸／碳酸氫鹽前驅物）的藥物。
TxGNN 模型預測它可能對**家族性內臟肌病變 (familial visceral myopathy)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，檸檬酸鉀可補充鉀離子，並提供檸檬酸鹽作為鹼化負荷，用於改善鉀缺乏與酸鹼失衡。

家族性內臟肌病變是一種腸道平滑肌的遺傳性疾病（例如 ACTG2 基因變異）。檸檬酸鉀對這類病理沒有已知作用，兩者之間找不到可辨識的機轉關聯。

TxGNN 的高分是以圖模型運算得出的預測，沒有臨床或文獻證據支持，因此分數本身不足以作為推進依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有任何臨床試驗或文獻直接研究此疾病，且藥理上看不出合理的作用機轉，證據等級僅為 L5。
- 家族性內臟肌病變屬於遺傳性平滑肌疾病，補充鉀與鹼化負荷無法針對其病因。

**若要推進需要：**
- 取得詳細的作用機轉資料，並說明與腸道平滑肌病變的可能關聯
- 取得原廠仿單的警語與禁忌症資料
- 先有前臨床或機轉研究顯示可能的生物學作用，再考慮臨床研究設計
