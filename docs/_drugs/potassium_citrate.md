# Potassium Citrate：從鉀缺乏症與腎小管酸中毒到腎結石

## 一句話總結

Potassium Citrate（檸檬酸鉀）原本用於鉀缺乏症、腎小管酸中毒與急性尿酸腎病變。
依 TxGNN 預測分數與證據完整度，最值得關注的新適應症是**腎結石 (Nephrolithiasis)**，目前有 **15 個臨床試驗**和 **18 篇文獻**支持這個方向。
不過腎結石與原適應症在機轉上高度重疊，較接近「適應症延伸」，而非典型的藥物再利用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊與藥理知識，檸檬酸鉀能提高尿液 pH 值與尿中檸檬酸濃度。檸檬酸可與鈣結合，抑制草酸鈣與磷酸鈣結晶的成核與生長；鹼化尿液也能溶解尿酸結石。

腎結石與原適應症（腎小管酸中毒、尿酸腎病變）同屬泌尿與酸鹼代謝問題。低檸檬酸尿症是鈣結石的常見代謝異常，也常見於遠端腎小管酸中毒。因此這項預測在機轉上相當合理，更接近已被廣泛使用的臨床用途，而非全新的適應症。

需要注意的是，磷酸鈣結石患者若過度鹼化尿液，可能升高磷酸鈣的過飽和度，所以需要監測尿液 pH。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容）：包含無尿症、腎臟疾病與腎功能受損、腎鈣化症、高血鈣、腎上腺功能不全（含 Addison 病）、消化性潰瘍、胰臟炎、心肌梗塞與冠狀動脈疾病、高血壓、代謝性酸中毒、橫紋肌溶解症、良性攝護腺增生、腹瀉性疾病等。
- **藥物交互作用**：共記錄 100 筆，以下為部分重要者：
  - 嚴重（Major）：Amiloride（保鉀利尿劑）、Benazepril（ACE 抑制劑）、Olmesartan、Valsartan（ARB）、Amitriptyline，以及多種抗膽鹼藥物（Atropine、Hyoscyamine、Homatropine、Methscopolamine）與抗組織胺（Chlorpheniramine、Acrivastine、Phenyltoloxamine）。
  - 中度（Moderate）：Ibuprofen、Ketorolac、Acetylsalicylic acid、Doxycycline、Aliskiren、Pseudoephedrine、Amphetamine、Dextroamphetamine。
- **使用時的防護重點**：需監測血鉀與腎功能，高血鉀或嚴重腎功能不全者應避免使用，磷酸鈣結石患者需監測尿液 pH。

香港仿單的警語與禁忌資料尚未取得，正式用藥請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 腎結石的機轉已相當明確，有 Phase 2 與 Phase 2/3 試驗、系統性回顧與專家共識支持，因此證據等級為 L2。但展示範圍內沒有已完成並公布結果的 Phase 3 腎結石療效試驗，且多數試驗規模小或以替代指標為主。
- 此適應症與原適應症高度重疊，風險可控，但血鉀與腎功能監測不可省略。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症文字（目前許可證資料缺漏）。
- 補充詳細的作用機轉資料（MOA）。
- 針對磷酸鈣結石等亞群，確認尿液 pH 監測方案與療效證據。
- 建立併用保鉀利尿劑、ACE 抑制劑／ARB 患者的血鉀監測計畫。
- 其他高分預測（家族性內臟肌病變、粒線體疾病、Pendred 症候群）目前無證據支持，建議暫緩（Hold）。胱胺酸症（Cystosis）僅有間接的個案報告，可列為研究問題，作為腎小管酸中毒的支持性治療，不能取代 cysteamine。
