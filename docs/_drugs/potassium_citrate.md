# 檸檬酸鉀：從（許可證未載明適應症）到家族性內臟肌病變

## 一句話總結

檸檬酸鉀（Potassium Citrate）是鹼化劑兼鉀來源，香港已有 1 張許可證（Urocit-K 緩釋錠 1080mg），但許可證未載明適應症。
TxGNN 預測分數最高的新適應症是**家族性內臟肌病變 (Familial Visceral Myopathy)**，但目前**沒有任何臨床試驗或文獻**支持，機轉上也找不到合理連結。
本批預測中證據最充分的是**腎結石 (Nephrolithiasis)**，有 **35 個臨床試驗**和 **19 篇文獻**，不過這很可能是既有的標準用途，不算真正的老藥新用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。檸檬酸鉀口服後大多代謝為碳酸氫根，作用是鹼化尿液、提高尿中檸檬酸濃度並補充鉀。

這些作用和家族性內臟肌病變（內臟平滑肌與腸道神經肌肉病變）沒有已知關聯。檸檬酸鉀對這個疾病的病理路徑也沒有已知影響。TxGNN 的高分只是知識圖譜上的關聯推算，**不能視為機轉上的支持**。

相較之下，同一批預測中的**腎結石**機轉明確：檸檬酸代謝為碳酸氫根，使尿液 pH 與尿檸檬酸上升。尿檸檬酸會螯合鈣，抑制草酸鈣與磷酸鈣結晶，鹼化也能溶解尿酸結石。這是已確立的結石預防做法。

## 結論與下一步

**決策：Hold**（針對首位預測：家族性內臟肌病變）

**理由：**
- 該預測沒有臨床試驗、文獻或合理機轉支持，屬於純模型預測，證據等級 L5。
- 香港衞生署仿單的警語與禁忌資料也尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衞生署仿單（警語、禁忌症、核准適應症），並確認腎結石是否已是標籤適應症。
- 若確認腎結石屬標籤內用途，改列為既有適應症，不再視為老藥新用。
- 若要評估腎結石方向，建議以 **Proceed with Guardrails** 處理：監測血清鉀與腎功能，留意高血鉀風險，以及與保鉀藥物併用的交互作用。
- 補充詳細的作用機轉資料（DrugBank）。
- 家族性內臟肌病變、粒線體疾病、彭德萊症候群三項預測，除非出現新的機轉或臨床證據，否則不建議投入資源。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
