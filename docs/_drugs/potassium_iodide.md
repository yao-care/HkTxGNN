# 碘化鉀：從原適應症未載明到鼻腔疾病

## 一句話總結

碘化鉀 (Potassium Iodide) 在香港已有 13 張許可證，但目前資料中沒有載明原核准適應症。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效。
目前**沒有臨床試驗**，只有 **4 篇個案報告**，且多為動物案例，證據偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。碘化鉀是長期使用的碘製劑，臨床上曾經驗性地用於部分皮下黴菌病與蟲黴菌病 (entomophthoral mycosis)。其抗黴菌或免疫調節作用有可能成立，但本資料中無法驗證。

目前找到的文獻都是鼻腔或鼻顏面部的黴菌、卵菌感染，例如腐霉病 (pythiosis)、麴菌感染、擬阿利什黴 (Pseudallescheria) 感染與鼻顏面部接合菌病。這些案例顯示碘化鉀可能對感染性鼻腔病變有幫助，但不能代表所有鼻腔疾病。

另外，4 篇文獻中有 3 篇是獸醫案例（羊、馬），對人類用藥的參考價值有限。唯一的人類個案是鼻顏面部接合菌病。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高，但目前沒有任何臨床試驗，文獻僅有個案報告，且多數是獸醫案例。
- 證據只涉及感染性（黴菌或卵菌）鼻腔病變，不足以支持一般鼻腔疾病。
- 作用機轉與安全性資料都有缺口，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症，這是目前的阻斷性缺口
- 補充 DrugBank 的作用機轉資料
- 明確界定目標族群（例如感染性鼻腔黴菌病），並蒐集人類臨床證據
- 評估碘暴露風險，包括甲狀腺影響與過敏反應
- 確認可用劑型與給藥途徑是否符合鼻腔用途

補充一項：模型另預測**急性喉咽炎 (Acute Laryngopharyngitis)**（分數 99.95%）。該預測沒有任何試驗或文獻支持，等級為 L5，同樣建議 Hold。
