## Povidone：從乾眼症到先天性魚鱗癬樣紅皮症
{: .text-alpha }

## 一句話總結

Povidone（聚維酮）是一種親水性高分子，原本用於眼科人工淚液，治療乾眼症與乾燥性角結膜炎（xerophthalmia）。
TxGNN 模型預測它可能對**先天性魚鱗癬樣紅皮症 (Congenital Ichthyosiform Erythroderma)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Povidone 是一種親水性高分子，在眼科產品中作為潤滑劑與保濕劑，用於改善乾眼症狀。

先天性魚鱗癬樣紅皮症是一種遺傳性角化異常疾病（例如 TGM1、ALOX12B、ALOXE3 基因突變），特徵是表皮屏障缺損、皮膚乾燥脫屑。從表面上看，兩者都涉及「組織乾燥、保濕不足」。一個合理但尚未驗證的推測是：Povidone 的保水與成膜特性，可能在乾燥脫屑的皮膚上發揮潤膚作用。

不過必須強調，此推測目前沒有任何前臨床或臨床資料支持。即使有效，外用保濕劑最多只能緩解症狀，無法改變疾病的基因病因與根本病理。

## 安全性考量

- **知識圖譜標示的相關疾病（非仿單內容）**：知識圖譜中，Povidone 與下列疾病存在禁忌關聯：癲癇、肝病、膽囊疾病、呼吸衰竭、房室分離、房室傳導阻滯、心臟傳導阻滯。這些關聯並非來自仿單，臨床意義需另行查證，且可能與全身性給藥而非眼用滴劑有關。
- **藥物交互作用**：查詢未找到相關紀錄。

其他安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一支持來自 TxGNN 的高預測分數（99.11%），沒有臨床試驗、文獻或已記載的作用機轉。
- 目前 Povidone 在香港僅有眼用製劑上市，且新適應症位於皮膚，屬於不同的給藥途徑。即使推測成立，也僅可能達到症狀性的保濕效果，而非疾病治療。

**若要推進需要：**
- 補齊 Povidone 的作用機轉資料（DrugBank）。
- 取得香港衛生署的仿單，確認警語與禁忌。
- 進行文獻與試驗的系統性檢索，並做皮膚屏障或角質層保濕的前臨床驗證。
- 評估外用皮膚製劑的可行性，包括劑型、濃度與經皮吸收。
- 與現行標準的魚鱗癬保濕劑和角質溶解劑比較，確認是否有附加價值。
