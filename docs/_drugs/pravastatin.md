# Pravastatin：從已上市降血脂藥到同合子家族性高膽固醇血症

## 一句話總結

Pravastatin 是 HMG-CoA 還原酶抑制劑（Statin 類），在香港已有 8 張藥品登記。
TxGNN 預測它可能對**同合子家族性高膽固醇血症 (Homozygous Familial Hypercholesterolemia, HoFH)** 有效。
目前只有 **1 個相關臨床試驗**（測試的是 alirocumab，不是 pravastatin）和 **12 篇間接文獻**，沒有直接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Pravastatin 屬於 Statin 類，抑制 HMG-CoA 還原酶以降低肝臟膽固醇合成，並上調肝臟 LDL 受體，因此能降低 LDL-C。這個機轉在雜合子家族性高膽固醇血症 (HeFH) 已被證實有效。

HoFH 的特徵是 LDL 受體功能缺失或嚴重不足。Pravastatin 主要靠上調 LDL 受體發揮作用，所以預期療效會明顯減弱。目前沒有直接測試 pravastatin 於 HoFH 的試驗。可參考的 Cochrane 系統性回顧涵蓋兒童家族性高膽固醇血症，但以雜合子為主，對 HoFH 只是間接證據。

Pravastatin 本身已是上市的降血脂藥，這個預測較可能反映「原適應症資料不完整」，不是真正的老藥新用訊號。

## 安全性考量

安全性資訊請參考原廠仿單。

若用於兒童家族性高膽固醇血症，證據包提示需注意兒童劑量、孕期避免使用，以及持續監測。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一的 Phase 3 試驗測試的是 alirocumab，沒有任何試驗直接測試 pravastatin 用於 HoFH。
- HoFH 的 LDL 受體功能缺失，機轉上預期 statin 療效有限。
- 此預測可能只是原適應症資料缺漏，不是新的老藥新用機會。

**若要推進需要：**
- 取得香港衛生署仿單，確認原核准適應症、警語與禁忌症
- 補齊 DrugBank 作用機轉資料
- 搜尋直接測試 pravastatin 於 HoFH 的臨床研究
- 確認 HoFH 是否已屬 pravastatin 的標示用途

**補充：** 同一份資料中的「HIV 感染相關血脂異常」（排名第 2）證據較強，已有 Phase 2 pravastatin 試驗與多個 RCT。建議只限於血脂與心血管風險管理，並單獨評估。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
