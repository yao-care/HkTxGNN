# Prilocaine：從局部麻醉到乳突性結膜炎（Papillary Conjunctivitis）

## 一句話總結

Prilocaine 是醯胺類局部麻醉藥，在香港以乳膏劑型上市。
TxGNN 模型預測它可能對**乳突性結膜炎 (Papillary Conjunctivitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Prilocaine 是醯胺類局部麻醉藥，作用在鈉離子通道，可阻斷神經傳導。理論上它能減輕眼表不適。

但乳突性結膜炎主要是過敏性或與隱形眼鏡相關的發炎性疾病。鈉離子通道阻斷與其致病機轉沒有明確關聯，因此機轉上的合理性偏弱。0.998 的高分只代表知識圖譜上的相近性，不等於療效證據。

此外，眼用局部麻醉劑反覆使用有角膜毒性風險，這使得長期治療慢性結膜炎的可行性更低。

## 結論與下一步

**決策：Hold**

**理由：**
- 乳突性結膜炎這項預測沒有任何臨床試驗或文獻，證據等級僅為 L5。
- 機轉上缺乏合理連結，且眼用局部麻醉劑有角膜毒性疑慮。

**若要推進需要：**
- 取得 Prilocaine 的作用機轉資料，並釐清它與結膜發炎的機轉關聯。
- 取得香港衛生署仿單的警語與禁忌資料，這是進入安全性篩選的前提。
- 評估眼用劑型與給藥途徑的可行性，目前香港上市產品皆為乳膏。

**補充觀察：**
同一份 Evidence Pack 中，另一個預測適應症**神經痛 (Neuralgia)**（分數 99.34%）的證據較多，證據等級為 L3。
- 有 1989–1999 年關於 EMLA（利多卡因-Prilocaine 複方）乳膏用於帶狀疱疹後神經痛的臨床報告，以及一項 Phase 2 開放性研究（NCT00916942）。
- 這些證據規模小、年代久，且複方的效果無法歸因於 Prilocaine 單一成分。
- 此用途也屬於局部麻醉藥的同類用途，不是獨特的老藥新用訊號。
- 若要優先投入資源，神經痛比乳突性結膜炎更值得進一步評估，但需要針對 Prilocaine 或 EMLA 的專屬療效試驗。

> 本報告結果僅供研究參考，不構成醫療建議。預測結果需經臨床驗證。
