# Procarbazine：從霍奇金氏淋巴瘤到濾泡性淋巴瘤

## 一句話總結

Procarbazine 是口服烷化類細胞毒性藥物，文獻描述其最常見用途是霍奇金氏淋巴瘤。
TxGNN 模型預測它可能對**濾泡性淋巴瘤 (Follicular Lymphoma)** 有效，目前有 **3 個臨床試驗**和 **20 篇文獻**與此方向相關。
但這些資料裡**沒有一項**明確證實 procarbazine 單獨對濾泡性淋巴瘤有效，證據偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位為空）。依一般藥理知識，procarbazine 是具甲基化、類烷化作用的細胞毒性藥物，長期用於 MOPP、BEACOPP 等淋巴瘤合併療法。這段機轉推論來自一般藥理，不是來自本次提供的資料。

濾泡性淋巴瘤和霍奇金氏淋巴瘤同屬淋巴系統惡性腫瘤，烷化類藥物對淋巴細胞惡性腫瘤的活性在生物學上說得通，這也與模型的高分預測一致。一篇 2006 年文獻報告了 2 位復發或難治的濾泡性淋巴瘤病人，長期每日服用 procarbazine 後達到完全且持久的緩解，這是最直接的支持線索。

不過這只是個案層級的證據。提供的資料中沒有任何試驗顯示 procarbazine 專門對濾泡性淋巴瘤有效，它目前也不是這個疾病的標準用藥。文獻指出，含 procarbazine 的方案在 CHOP 出現後，已逐漸退出非霍奇金氏淋巴瘤的治療。

文獻另有以下毒性訊號：
- 大鼠與小鼠的致癌性試驗（NCI 1979）。
- 含 procarbazine 的 MOPP 方案與男性無精症風險相關。
- 霍奇金氏淋巴瘤病人接受 C-MOPP 與放射治療後，出現續發性腫瘤。

## 安全性考量

安全性資訊請參考原廠仿單。香港衛生署仿單的警語與禁忌尚未取得，藥物交互作用查詢也無結果。

## 結論與下一步

**決策：Hold**

**理由：**
- 模型分數很高，機轉上也說得通，但提供的資料中沒有任何試驗直接證實 procarbazine 對濾泡性淋巴瘤有效。
- 最直接的線索只有 2 個個案，3 個試驗都無法確認 procarbazine 的貢獻。
- 安全性資料目前也不完整，尚不足以進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌與交互作用。
- 補齊 DrugBank 的作用機轉資料。
- 確認 NCT00003113 與 NCT01130194 的化療組成是否含 procarbazine。
- 全面檢索含 procarbazine 的方案（如 PEP-C）在濾泡性淋巴瘤的療效，並與現行標準治療比較。
- 評估致癌性與生殖毒性風險相對於替代療法的取捨。

**其他預測適應症：**
- 神經母細胞瘤 (L4) 目前只有歷史性或毒性相關文獻，且有兒童族群的致癌與性腺毒性疑慮，建議 Hold。
- 神經節母細胞瘤、腹膜後腫瘤、椎骨異常合併內分泌與 T 細胞功能障礙 (L4-L5) 缺乏直接證據，建議 Hold。其中最後一項較像知識圖譜的假關聯。
