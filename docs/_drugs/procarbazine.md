# Procarbazine：從何杰金氏淋巴瘤到濾泡性淋巴瘤 (Follicular Lymphoma)

## 一句話總結

Procarbazine 是傳統細胞毒性化療藥物，文獻記載其「最常用於何杰金氏病 (Hodgkin's disease) 的治療」。
TxGNN 模型預測它可能對**濾泡性淋巴瘤 (Follicular Lymphoma)** 有效，
目前有 **3 個臨床試驗**和 **20 篇文獻**支持這個方向，其中已有病例報告直接觀察到 procarbazine 用於復發性濾泡性淋巴瘤的療效。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Procarbazine 是一種口服烷化劑類化療藥物，根據本評估收集到的文獻（PMID 16690522）記載，「procarbazine hydrochloride 是一種對淋巴瘤有活性的口服烷化劑，最常用於何杰金氏病的治療」，其在含 procarbazine 的複方化療（如 MOPP、PEP-C 等方案）中作為非何杰金氏淋巴瘤治療的一部分被使用。

何杰金氏淋巴瘤與濾泡性淋巴瘤同屬淋巴系統惡性腫瘤，且同一篇文獻已直接報告兩位復發/難治性濾泡性淋巴瘤患者，經長期口服 procarbazine 治療後達到完全且持久的緩解，顯示藥理機轉上具跨適應症潛力。此外，PMID 22507790 描述的 PEP-C 低劑量口服複合化療方案（Prednisone, Etoposide, Procarbazine, Cyclophosphamide）也用於復發性/難治性淋巴瘤，進一步支持這個方向合理性。

安全性資訊請參考原廠仿單。（TFDA/香港仿單警語與禁忌症資料目前缺失，屬於本評估的阻斷性資料缺口。）

## 結論與下一步

**決策：Hold**

**理由：**
- 雖有 L2 等級證據（1 個已完成 Phase 3 試驗＋直接針對 procarbazine 治療濾泡性淋巴瘤的病例報告），機轉關聯性合理，
- 但仿單警語/禁忌症資料缺失屬於**阻斷性 (Blocking)** 缺口，無法完成 S1 安全性初評；且藥物目前在香港未上市、無許可證，實務可及性存疑。

**若要推進需要：**
- 取得 TFDA/香港仿單警語與禁忌症資料（解除 DG001 阻斷性缺口）
- 補充作用機轉 (MOA) 資料以強化機轉關聯性分析（DG002）
- 評估香港以外地區（如原廠核准地）上市與供應可行性
