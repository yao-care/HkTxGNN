# Propafenone：從心律不整到躁型雙相情感疾患

## 一句話總結

Propafenone 是 1C 類鈉離子通道阻斷劑，原本用於心律不整治療。
TxGNN 模型預測它可能對**躁型雙相情感疾患 (Manic Bipolar Affective Disorder)** 有效，但目前**沒有臨床試驗**，3 篇文獻也都是藥物不良反應或交互作用的報告，沒有任何一篇支持療效。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Propafenone 是 1C 類抗心律不整藥，透過阻斷鈉離子通道來減緩心臟傳導。就現有資訊來看，這個機轉**沒有已知的抗躁症作用**。

文獻中唯一的關聯，是 1985 年一則病例報告。作者推測 Propafenone 在化學結構上與抗憂鬱藥 bupropion 相近，可能帶有一些抗憂鬱活性，因此反而可能誘發情感性精神症狀。換句話說，文獻指出的是**藥物可能引發躁症**，不是治療躁症。

TxGNN 的高分應視為知識圖譜上的統計關聯，不代表有生物機轉或臨床證據支持。其他文獻提到 CYP2D6 相關的藥物交互作用，可能影響精神科用藥。這屬於安全性議題，不是療效證據。

## 安全性考量

安全性資訊請參考原廠仿單。

目前也查無藥物交互作用資料。不過上述文獻顯示，Propafenone 可能誘發躁症或精神症狀，與精神科藥物併用時也有交互作用風險，在雙相情感疾患族群中特別需要留意。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有臨床試驗，現有文獻反而指向 Propafenone 可能誘發躁症，機轉上也找不到合理的抗躁症作用。
- 香港仿單的警語與禁忌症資料尚未取得，這是阻擋進入安全性篩選的缺口。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與適應症資料
- 補充 DrugBank 的作用機轉資料
- 找出能支持抗躁症作用的機轉或前臨床證據，目前沒有

**其他預測適應症的參考：** 同一份預測清單中，**兒茶酚胺敏感型多形性心室心搏過速 (CPVT)** 有 RyR2 通道抑制的前臨床證據與病例報告（L4），**嬰兒持續性心室心搏過速**則有病例系列支持（L3）。兩者均為 Research Question，比躁症更值得優先評估。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
