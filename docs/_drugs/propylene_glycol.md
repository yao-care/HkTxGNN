# Propylene Glycol（丙二醇）：從眼用潤滑劑成分到支氣管炎

## 一句話總結

Propylene Glycol（丙二醇）是溶劑與賦形劑，在香港以人工淚液（眼用潤滑液）的成分上市。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但這個高分預測**缺乏實質證據支持**：
4 個相關試驗的受試藥物都是環孢素吸入液，丙二醇最多只是載體；3 篇文獻中沒有任何一篇顯示丙二醇有療效。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。丙二醇是溶劑與賦形劑，用途是溶解或穩定主成分，本身不是以治療為目的的活性成分。因此目前沒有任何治療機轉能說明它為何適用於支氣管炎。

證據反而指向相反方向。檢索到的文獻把丙二醇列為電子菸成分之一，與呼吸道刺激、可能的肺部與氣喘風險有關。

比對到的臨床試驗研究的是環孢素吸入液 (CIS)，丙二醇很可能只是其載體。
0.999 的 TxGNN 分數較可能是知識圖譜中的關聯假象（藥物與疾病在圖譜上相鄰），而不是老藥新用的訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎預測的證據停留在 L4，所有臨床試驗研究的都是環孢素吸入液，沒有任何證據顯示丙二醇本身有療效。
- 文獻反而提示丙二醇（作為電子菸成分）與呼吸道風險有關，高分預測應視為圖譜假象。
- 其他預測也不支持推進。糖尿病視網膜病變（99.68%）的唯一臨床文獻研究的是丙二醇甘露醇硫酸酯 (PMS)，與丙二醇是不同化合物，很可能是名稱相似造成的誤配。嚴重非增殖性糖尿病視網膜病變、皮質性白內障與核性老年性白內障則完全沒有試驗或文獻。

**若要推進需要：**
- 取得丙二醇作為活性成分的作用機轉資料，並確認是否存在合理的治療路徑。
- 取得香港衛生署仿單的警語與禁忌資料，這是進入安全性篩選的阻斷項。
- 確認吸入給藥的可行性與呼吸道安全性，因為現有文獻顯示可能有刺激風險。
- 目前不建議投入進一步資源，除非出現以丙二醇本身作為受試藥物的臨床證據。

*本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證才能應用。*
