# Prulifloxacin：從細菌感染到心臟病

## 一句話總結

Prulifloxacin 是氟喹諾酮類抗菌藥物 ulifloxacin 的前驅藥，原本用於抗細菌感染。
TxGNN 模型預測它可能對**心臟病 (heart disease)** 有效，但目前**沒有臨床試驗**，只有 **1 篇**前臨床動物文獻，且該文獻看起來是心律安全性研究，不是療效證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Prulifloxacin 是 ulifloxacin 的前驅藥，屬氟喹諾酮類，作用是抑制細菌的 DNA gyrase 與 topoisomerase IV。

這個機轉針對細菌，與心臟病的病理過程沒有已知關聯，因此**這項預測在機轉上缺乏合理性**。唯一連結的文獻（PMID 15018156）比較四種喹諾酮在兔子心律不整模型中的表現。這類研究通常評估 QT 間期延長與致心律不整風險，是安全性訊號，不能當作療效支持。

預測分數 99.94% 接近飽和，在沒有其他證據時參考價值很低。另外 4 個預測適應症（Laubry-Pezzi 症候群、兩種 Pierre Robin 症候群、染色體 7q 部分缺失）分數都在 0.9994 左右，且同樣沒有試驗或文獻。這些都是先天性結構或染色體異常，抗菌藥不可能治療。分數幾乎相同，也提示可能是分數飽和，或是知識圖譜鄰近節點造成的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測分數，沒有任何臨床試驗，唯一文獻是前臨床安全性研究，證據等級為 L5。
- 抗菌機轉與心臟病之間沒有合理的治療連結，而且同類藥物有心臟安全性疑慮，不建議投入資源。

**若要重新評估需要：**
- 補齊 DrugBank 的作用機轉資料，以及香港衛生署仿單的警語與禁忌症
- 取得 PMID 15018156 的完整摘要與全文，確認研究終點
- 找出可支持心臟適應症的機轉或療效研究，目前沒有
- 評估心臟安全性風險（QT 延長），再決定是否值得繼續
