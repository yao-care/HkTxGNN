# Prulifloxacin：從細菌感染到心臟病

## 一句話總結

Prulifloxacin 是一種氟喹諾酮類 (fluoroquinolone) 抗生素。
TxGNN 模型預測它可能對**心臟病 (Heart Disease)** 有效，預測分數高達 **99.94%**，
但目前唯一相關的文獻其實是**安全性警訊**（QT 間期延長／心律不整風險評估），而非療效證據，此預測缺乏機轉上的正向支持。

## 為什麼這個預測合理？

目前缺乏 Prulifloxacin 的詳細作用機轉資料。根據文獻分類，此藥物是氟喹諾酮類抗生素，其活性代謝物為 NM394 (UFX)。

唯一與「心臟病」相關的文獻（PMID 15018156）並非探討治療效果，而是在兔隻模型中評估 prulifloxacin 活性代謝物與 sparfloxacin、gatifloxacin、levofloxacin 等喹諾酮類藥物的致心律不整及 QT 延長風險。這個方向與「治療心臟病」相反，屬於安全性警訊，而非機轉上支持療效的證據。

TxGNN 分數雖高，但在缺乏正向機轉關聯、也無任何臨床試驗或療效性文獻的情況下，此預測不具臨床合理性。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一相關文獻是心律不整風險研究，方向與「治療心臟病」相反，不構成正向療效證據。
- 其餘 4 個預測適應症（Laubry-Pezzi syndrome、Pierre Robin 相關症候群 ×2、7q 長臂部分缺失）皆為先天性結構或染色體異常，與抗菌藥物機轉無生物學合理性，且完全無臨床試驗或文獻支持（皆為 L5、Hold）。

**若要推進需要：**
- 補齊 TFDA／HK 仿單警語與禁忌（DG001，Blocking）
- 補齊作用機轉 (MOA) 資料（DG002）
- 尋找機轉上更具合理性的候選適應症，而非僅依賴 TxGNN 分數
