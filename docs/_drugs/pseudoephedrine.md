# Pseudoephedrine：從過敏性鼻炎到鼻腔疾病

## 一句話總結

Pseudoephedrine（偽麻黃鹼）是一種擬交感神經減鼻充血劑，原本用於過敏性鼻炎、血管運動性鼻炎、咽炎與感冒等上呼吸道症狀。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，但目前**沒有臨床試驗**，僅有 **7 篇文獻**（多為綜述與動物模型），且鼻腔疾病大致涵蓋其既有適應症，並非真正的新適應症。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Pseudoephedrine 是間接擬交感神經藥物，具有 α-腎上腺素受體活性，可使鼻黏膜血管收縮，進而減輕鼻塞。

原適應症（過敏性鼻炎、血管運動性鼻炎、鼻咽炎等）本身就屬於鼻腔疾病範疇。因此「鼻腔疾病」較像是涵蓋既有用途的上位分類，而非真正的藥物再利用目標。模型的高分主要反映與既有適應症的重疊，而非新發現。

已檢索到的文獻支持其減鼻充血作用：一項比較口服與局部減鼻充血效果的研究（d-pseudoephedrine 對比 phenylpropanolamine），以及數個以減鼻充血劑作為藥理對照的犬、貓鼻塞模型。

## 結論與下一步

**決策：Hold**

**理由：**
- 「鼻腔疾病」主要涵蓋 Pseudoephedrine 既有適應症，不是真正的新用途；高預測分數大多反映這種重疊。
- 無任何臨床試驗，文獻僅為綜述、藥理研究與動物模型，證據停留在 L4。
- 藥物具心血管等多項潛在禁忌，且仿單安全性資料尚未取得。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症文字
- 補充詳細的作用機轉資料（MOA）
- 釐清「鼻腔疾病」中是否存在現有適應症以外的具體亞型（例如鼻竇炎、鼻息肉相關鼻塞）
- 若確定有新亞型，再設計針對該族群的臨床研究，並納入心血管風險評估
