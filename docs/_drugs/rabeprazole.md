# Rabeprazole：從消化性潰瘍與胃食道逆流到瀰漫性肥大細胞增生症（Smouldering Systemic Mastocytosis）

## 一句話總結

Rabeprazole 是一種質子幫浦抑制劑，原本用於消化性潰瘍、胃食道逆流、十二指腸潰瘍及 Zollinger-Ellison 症候群等胃酸相關疾病。
TxGNN 模型預測它可能對**惰性（Smouldering）全身性肥大細胞增生症 (Smouldering Systemic Mastocytosis)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Rabeprazole 屬於質子幫浦抑制劑類別，一般認為其作用是抑制胃壁細胞的 H+/K+ ATP 酶以降低胃酸分泌，但這一點無法在本次整理的資料中獨立驗證。

在知識圖譜中，Rabeprazole 已與全身性肥大細胞增生症 (systemic mastocytosis) 及肥大細胞增生症有關聯。這類疾病常因肥大細胞釋放組織胺而造成胃酸過度分泌，使用抑制胃酸的藥物可控制相關症狀。惰性全身性肥大細胞增生症屬於同一疾病家族，因此模型給出高分，很可能反映的是圖譜中與既有適應症的相近性。

需要注意的是，這樣的作用僅限於**症狀控制**（胃酸相關不適），並無證據顯示它能影響肥大細胞數量或疾病進展。

排名第二的預測為「伴嗜酸性白血球增多的淋巴結病變型肥大細胞增生症 (lymphoadenopathic mastocytosis with eosinophilia)」，分數 99.35%，同樣僅為模型預測，推論邏輯與上述相同，也同樣沒有臨床試驗或文獻佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有模型預測（證據等級 L5），沒有任何臨床試驗或文獻支持。
- 即使成立，預期效益也僅限於胃酸相關症狀控制，而非改變疾病本身；且該方向與既有適應症（systemic mastocytosis）高度重疊，新增價值有限。

**若要推進需要：**
- 補齊作用機轉資料（MOA）。
- 取得香港衛生署仿單中的警語與禁忌資料，完成安全性篩選。
- 檢索肥大細胞增生症患者使用質子幫浦抑制劑的臨床或觀察性研究。
- 釐清此預測與已標示的肥大細胞增生症適應症之間的差異，確認是否具實質新意。
- 若繼續推進，需明確定義臨床目標（僅症狀控制，還是疾病修飾）。
