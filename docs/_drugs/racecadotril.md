# Racecadotril：從腹瀉到高澱粉酶血症

## 一句話總結

Racecadotril 是腸道腦啡肽酶（enkephalinase）抑制劑，臨床上用於治療腹瀉。
TxGNN 模型預測它可能對**高澱粉酶血症 (Hyperamylasemia)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Racecadotril 是腦啡肽酶（neprilysin）抑制劑，具有腸道抗分泌作用，一般用於急性腹瀉。

高澱粉酶血症與腸道分泌作用之間，目前沒有資料支持的機轉連結。TxGNN 分數 97.72% 來自知識圖譜的推論，沒有任何臨床試驗或文獻佐證，應視為假說而非結論。

## 結論與下一步

**決策：Hold**

**理由：**
所有預測僅來自模型推論（L5），沒有臨床試驗、文獻或可辨識的機轉支持。部分預測（如敗血性鼠疫、急性膀胱炎）在藥理上明顯不合理。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌與核准適應症（目前為阻擋性缺口）
- 補充 DrugBank 的作用機轉資料
- 針對高澱粉酶血症進行文獻與臨床試驗檢索，確認是否有任何實證
- 若無實證，建議不優先投入資源
