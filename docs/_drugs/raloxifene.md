# Raloxifene：從停經後骨質疏鬆到十二指腸潰瘍

## 一句話總結

Raloxifene 是一種選擇性雌激素受體調節劑（SERM），原本用於停經後骨質疏鬆症的治療。
TxGNN 模型預測它可能對**十二指腸潰瘍 (Duodenal Ulcer)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Raloxifene 是作用於骨骼、乳房與子宮組織的 SERM，在停經後骨質疏鬆症中的療效已被證實。

至於十二指腸潰瘍，目前沒有已確立的機轉連結。經由雌激素受體訊號影響胃或十二指腸黏膜保護的可能性，僅屬推測，現有資料無法支持。0.997 的高分僅代表知識圖譜上的關聯，不等於治療上有效。

其他同時被預測的疾病（如低 α 脂蛋白血症、十二指腸阻塞、十二指腸胃逆流）同樣缺乏臨床證據。其中十二指腸阻塞多為結構性或機械性問題，預期不會對 SERM 有反應。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（來自藥物－疾病關聯，非仿單原文）：
  - 血栓與栓塞相關：血栓性靜脈炎、肺栓塞、血栓形成傾向、抗磷脂症候群、視網膜動脈阻塞
  - 腦血管與心血管相關：中風、腦血管疾病、腦梗塞、短暫性腦缺血發作、椎基底動脈循環不全、冠狀動脈疾病、心房顫動
  - 其他：高血壓、肝臟疾病、膽囊疾病、高三酸甘油脂血症、腎功能不全
- **藥物交互作用**：資料庫查得 100 筆，以下為部分交互作用藥物，但皆未標示嚴重程度：Calcitriol、Pantoprazole、Glimepiride、Mesalazine、Doxycycline、Metformin、Omeprazole、Simvastatin 等。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有臨床試驗、文獻或明確的機轉連結支持，證據等級為 L5。
- Raloxifene 的已知禁忌涵蓋多種血栓與心腦血管疾病，在缺乏療效證據下不宜貿然推進新適應症。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症，完成安全性篩選
- 補充 Raloxifene 的作用機轉資料，並評估與十二指腸潰瘍的機轉關聯
- 進行系統性文獻與臨床試驗檢索，確認是否存在任何前臨床或臨床訊號
- 若有前臨床訊號，再評估劑量、給藥途徑與目標族群（尤其是有血栓風險者）
