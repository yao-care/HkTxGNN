# Ramucirumab：從原適應症（資料未載明）到子宮韌帶腺癌

## 一句話總結

Ramucirumab 是一種 VEGFR-2 拮抗劑，在香港以 CYRAMZA 品名上市，但本次資料未載明其核准適應症。
TxGNN 模型預測它可能對**子宮韌帶腺癌 (Uterine Ligament Adenocarcinoma)** 有效。
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ramucirumab 是 VEGFR-2 拮抗劑，屬於抗血管新生的標靶藥物。
這類藥物透過阻斷 VEGF 訊號來抑制腫瘤血管生成，理論上可能適用於血管依賴性高的實體腫瘤，包括婦科腺癌。

這個推論只是**藥物類別層級**的合理性，沒有針對此藥物與此疾病的具體資料。
TxGNN 的高分可能反映知識圖譜中與相關婦科癌症節點的鄰近關係，而不是這個疾病特有的生物學證據。
子宮韌帶腺癌是罕見疾病，要判斷機轉是否真正成立，還需要更多研究。

另外，TxGNN 對同一藥物還預測了多個子宮頸與子宮韌帶相關的腺癌亞型（如子宮頸內膜癌，分數同為 99.95%）。這些預測也都只有模型分數，沒有試驗或文獻佐證。

## 結論與下一步

**決策：Hold**

**理由：**
這個預測只有模型分數（99.95%），沒有任何臨床試驗、文獻或藥物專屬的機轉資料。
同時，香港仿單的警語與禁忌資料缺失，被標記為阻斷性缺口，無法進入安全性篩檢。

**若要推進需要：**
- 取得香港衛生署的仿單（PDF），補齊警語與禁忌症，這是目前的阻斷項目
- 從 DrugBank 補充 Ramucirumab 的作用機轉資料
- 針對子宮韌帶腺癌及相關子宮頸腺癌亞型，做專項的臨床試驗與文獻搜尋
- 確認香港許可證的核准適應症與劑型，建立原適應症與新適應症的關聯
- 優先評估分數同樣極高、且血管生成與 VEGF 通路角色較明確的子宮頸內膜癌（建議列為「研究問題」）

本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。
