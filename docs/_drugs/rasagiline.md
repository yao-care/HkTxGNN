## Rasagiline：從帕金森氏症到 PLA2G6 相關神經退化症
{: .text-alpha }

## 一句話總結

Rasagiline 是一種 MAO-B 抑制劑，知識圖譜中記錄的原適應症為帕金森氏症及多種帕金森氏症候群。
TxGNN 模型預測它可能對 **PLA2G6 相關神經退化症 (PLA2G6-associated neurodegeneration)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅屬於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫未收錄）。依一般藥理知識，rasagiline 為不可逆的 MAO-B 抑制劑，可減少多巴胺分解，並被報告具有神經保護與抗細胞凋亡的特性。此部分為背景說明，並非本次資料所提供的證據。

PLA2G6 相關神經退化症（包含嬰兒型神經軸突營養不良與 PLA2G6 相關肌張力不全－帕金森氏症）與帕金森氏症一樣，有帕金森氏症表現及 α-突觸核蛋白病變。因此理論上，rasagiline 可能改善多巴胺功能失調所致的症狀。

不過，高預測分數很可能反映的是疾病在知識網絡中與已列帕金森氏症候群距離相近，而非實際的生物學證據。目前沒有任何試驗或文獻佐證，這個連結只是計算層面的假說。

## 安全性考量

- **知識圖譜中記錄的禁忌關聯**（來自知識圖譜，並非仿單內容）：高血壓、多系統萎縮、姿勢性低血壓、姿勢性直立心搏過速症候群、藥物引起的異動症、癲癇、雙極性疾患、肝臟疾病、膽囊疾病、黑色素瘤、嗜鉻細胞瘤及副神經節瘤等。
- **藥物交互作用**（共查得 100 筆，以下為部分）：
  - 重大：Bupropion、Morphine
  - 中度：Epinephrine、Cimetidine、Phentermine、Dronabinol，以及多種胰島素與降血糖藥（如 Glimepiride、Chlorpropamide）

其他警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自模型計算，沒有任何針對 PLA2G6 相關神經退化症的臨床試驗或文獻，證據等級為 L5。
- 該疾病為罕見遺傳性神經退化症，且知識圖譜另顯示 rasagiline 與多項疾病有禁忌關聯，需審慎評估。

**若要推進需要：**
- 補充 rasagiline 的作用機轉資料，並建立與 PLA2G6 病理（如 α-突觸核蛋白、脂質代謝異常）的具體機轉連結
- 進行文獻回顧或前臨床（細胞或動物模型）研究驗證
- 取得香港原廠仿單，完成警語與禁忌的安全性篩選
- 評估兒童及年輕族群的用藥安全性與劑量
