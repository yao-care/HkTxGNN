# Ravulizumab：從陣發性夜間血紅素尿症到 G6PC3 缺陷所致嚴重先天性嗜中性白血球減少症

## 一句話總結

Ravulizumab 是長效型 C5 補體抑制劑，原本用於治療陣發性夜間血紅素尿症 (PNH)。
TxGNN 模型預測它可能對**G6PC3 缺陷所致的體染色體隱性嚴重先天性嗜中性白血球減少症**有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Ravulizumab 是長效型 C5 補體抑制劑，透過阻斷終端補體活化來治療 PNH。

然而，G6PC3 缺陷造成嗜中性白血球減少的原因是葡萄糖代謝受損，並使嗜中性白血球凋亡增加，目前並未確立與補體驅動機轉的關聯。TxGNN 的高分（0.9996）較可能反映知識圖譜中的相近性（同屬血液學表型），而非有生物學依據的連結。

其他排名前列的預測（週期性造血、原發性高草酸尿症、嚴重先天性嗜中性白血球減少症、CXCR2 缺陷所致嗜中性白血球減少症）同樣只有計算層面的支持。其中嗜中性白血球減少相關疾病還有額外疑慮：抑制補體可能提高感染風險（尤其是有莢膜細菌），而這些病人本來就容易感染。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：腦膜炎球菌感染（來自知識圖譜的藥物－疾病禁忌關聯，非仿單原文）。
- **藥物交互作用**：共查得 4 筆，皆為輕微 (Minor) 等級，涉及人類免疫球蛋白 G（靜脈、皮下、肌肉注射，以及靜脈合併皮下製劑）。

其他警語與禁忌症資料請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型計算，沒有臨床試驗或文獻佐證，證據等級為 L5。
- 機轉上缺乏補體參與的依據，且抑制 C5 可能增加嗜中性白血球減少病人的感染風險。

**若要推進需要：**
- 取得 Ravulizumab 完整的作用機轉資料
- 取得香港仿單的警語與禁忌症，完成安全性初篩
- 建立 G6PC3 缺陷與補體活化相關的前臨床或機轉證據
- 針對嗜中性白血球減少族群的感染風險（特別是腦膜炎球菌）進行評估
- 在上述基礎成立後，才考慮設計概念驗證研究
