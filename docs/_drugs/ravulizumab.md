# Ravulizumab：從 C5 補體抑制劑到先天性嚴重嗜中性白血球低下症（G6PC3 缺乏）

## 一句話總結

Ravulizumab 是一種抗 C5 的單株抗體，作用是阻斷終端補體活化。
TxGNN 模型預測它可能對**G6PC3 缺乏所致的體染色體隱性嚴重先天性嗜中性白血球低下症**有效。
目前**沒有任何臨床試驗或文獻**支持，這個預測只是模型運算的訊號，機轉上也找不到合理的連結。

## 為什麼這個預測合理？

**目前看不出合理性。** 資料中缺乏詳細的作用機轉（MOA）和原適應症，無法與模型預測交叉比對。就現有資訊，Ravulizumab 是 C5 補體抑制劑，只阻斷終端補體活化。

G6PC3 缺乏是葡萄糖-6-磷酸酶催化次單位 3 的單基因缺陷，會造成嗜中性白血球代謝壓力、內質網壓力與細胞凋亡。這條病理路徑不由補體驅動，與 C5 抑制沒有交集。

0.9996 的高分很可能是知識圖譜中「嗜中性白血球低下」相關節點共用所造成的假象，不是生物學上的理由。補體抑制還會增加腦膜炎球菌感染風險，對嗜中性白血球低下的病人是特別大的顧慮。

## 安全性考量

- **補體抑制的感染風險**：C5 抑制會增加腦膜炎球菌感染風險。若用於嗜中性白血球低下的族群，風險更值得關注。

其餘警語、禁忌症與藥物交互作用資料，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，沒有試驗或文獻，機轉上也沒有合理連結。
- 高分疑似圖譜假象，且補體抑制對嗜中性白血球低下病人有額外感染風險。

**若要推進需要：**
- 補齊 Ravulizumab 的作用機轉與原適應症資料，重新評估預測合理性。
- 取得香港衛生署仿單的警語與禁忌症，才能進行安全性篩選。
- 先找到 C5／補體與 G6PC3 缺乏或嗜中性白血球低下之間的機轉或前臨床證據，再考慮是否重啟評估。
