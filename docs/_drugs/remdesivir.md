# Remdesivir：從 COVID-19 到多發性內分泌腫瘤

## 一句話總結

Remdesivir 是核苷酸類似物前驅藥，為抗病毒藥物，在證據包的文獻中用於治療 COVID-19。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

Remdesivir 是核苷酸類似物前驅藥，作用是抑制病毒的 RNA 依賴性 RNA 聚合酶 (RdRp)。DrugBank 的作用機轉欄位目前沒有資料，以上說明來自模型的機轉評估。

多發性內分泌腫瘤是遺傳性腫瘤症候群，沒有病毒標靶。Remdesivir 的作用機轉與這個疾病之間**找不到合理的關聯**。0.995 的高分只是知識圖譜上的關聯推論，沒有任何臨床或文獻佐證，不應解讀為有效的訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測完全來自模型分數，沒有試驗、文獻或合理的機轉支持。
- 同一份資料中排名較後的 HIV 等適應症雖掛有許多試驗，但內容幾乎都是 COVID-19 研究，也不能作為新適應症的證據。

**若要推進需要：**
- 找到多發性內分泌腫瘤與 RdRp 抑制之間的機轉依據，或前臨床研究資料。
- 取得香港衛生署的藥品仿單，補齊警語與禁忌症（目前為阻擋性資料缺口，無法進入安全性篩選）。
- 從 DrugBank 補齊作用機轉資料。
- 若要評估其他預測適應症，需先逐一確認所附試驗的實際收案疾病，排除 COVID-19 研究被誤配的情形。
