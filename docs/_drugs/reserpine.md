# Reserpine：從（原適應症未載明）到頑固型思覺失調症

## 一句話總結

Reserpine（利血平）是一種囊泡單胺轉運體抑制劑，在香港有一張複方製劑許可證，但資料中未載明原適應症。
TxGNN 模型預測它可能對**頑固型思覺失調症 (Treatment-Refractory Schizophrenia)** 有效，
目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原始 MOA 欄位為空）。不過就藥理上，Reserpine 已知會不可逆地抑制囊泡單胺轉運體（VMAT1/VMAT2），使突觸前的多巴胺、正腎上腺素與血清素耗竭。

多巴胺傳導下降，與抗精神病藥物的作用方向一致，這可能是 TxGNN 給出高分（0.990）的原因。

但這個關聯目前只是模型推導的假說：沒有提供任何臨床試驗或文獻佐證，原適應症也未載明，無法判斷與新適應症的關聯。此外，Reserpine 已知的不良反應（憂鬱、低血壓、錐體外症狀）對這類族群是值得留意的安全疑慮。
