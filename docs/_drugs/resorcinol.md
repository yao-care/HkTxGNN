# RESORCINOL：原適應症資料缺乏 → 痤瘡瘢痕疙瘩 (Acne Keloid)

## 一句話總結

RESORCINOL（DrugBank ID: DB11085）目前查無登記的原適應症與作用機轉資料。
TxGNN 模型預測它可能對**痤瘡瘢痕疙瘩 (Acne Keloid)** 有效（預測分數 99.83%），
但目前**沒有任何臨床試驗或文獻**支持這個方向，屬純模型假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料，也沒有原適應症的登記紀錄，因此無法具體說明 RESORCINOL 與痤瘡瘢痕疙瘩之間的機轉關聯性。

TxGNN 給出的預測分數雖然很高（99.83%，排名第 4000 位），但這僅反映知識圖譜上的關聯強度，並非臨床證據。在缺乏 MOA、原適應症、臨床試驗與文獻佐證的情況下，此預測目前只能視為一個待驗證的研究假說，不宜直接解讀為具有機轉合理性。
