# Resorcinol：從外用皮膚科用藥到痤瘡瘢痕疙瘩

## 一句話總結

Resorcinol（間苯二酚）在香港以外用乳膏形式上市，一般認為具有角質溶解與抗菌作用，常用於痤瘡等毛囊相關皮膚問題。
TxGNN 模型預測它可能對**痤瘡瘢痕疙瘩 (Acne Keloid)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Resorcinol 是外用皮膚科成分，一般描述為角質溶解與抗菌劑，用於痤瘡及其他毛囊性皮膚病。

痤瘡瘢痕疙瘩的特徵是毛囊發炎與瘢痕形成。因此，Resorcinol 的角質溶解與抗菌作用在機轉上有可能派上用場。但這個推論僅屬推測，沒有任何臨床或文獻資料佐證。

99.83% 的高分只是模型預測，不能視為療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測（L5），沒有任何試驗或文獻佐證。
- 作用機轉與香港仿單的警語、禁忌資料都缺漏，無法進入安全性篩選。

TxGNN 對此藥的另外 4 個預測是無肌病性皮肌炎、新生兒皮肌炎、兒童結締組織病相關間質性肺病、慢性萎縮性肢端皮膚炎。它們同樣只有 L5 證據，也都建議 Hold，且機轉關聯更弱。其中新生兒皮肌炎涉及新生兒經皮吸收的毒性風險，不建議在沒有明確理由時推進。此外，Resorcinol 為已知皮膚致敏物，並與甲狀腺效應有關，若考慮全身性使用，需另行評估安全性。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語與禁忌症。
- 從 DrugBank 補齊作用機轉資料，重新評估與痤瘡瘢痕疙瘩的機轉關聯。
- 系統性搜尋 Resorcinol 用於痤瘡瘢痕疙瘩或相關毛囊性疾病的文獻與臨床試驗。
- 若有任何研究證據，再重新評估證據等級與決策。
