## Resorcinol：從痤瘡與皮膚炎到瘢痕疙瘩性痤瘡（Acne Keloid）
{: .text-alpha }

## 一句話總結

Resorcinol（間苯二酚）是外用角質溶解與抗菌劑，原本用於痤瘡與皮膚炎。
TxGNN 模型預測它可能對**瘢痕疙瘩性痤瘡 (Acne Keloid)** 有效，
但目前**沒有臨床試驗與文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Resorcinol 是外用角質溶解與抗菌劑，已用於尋常性痤瘡，機轉上可能適用於同屬毛囊發炎的疾病。

瘢痕疙瘩性痤瘡（項部瘢痕疙瘩性毛囊炎）與痤瘡都有毛囊發炎與阻塞的特徵，因此角質溶解與抗發炎作用在理論上可能有幫助。不過這個連結是從原適應症推論而來，屬間接推測。

TxGNN 分數雖高（99.83%），但這只是計算預測，不是臨床證據。

其他排名較後的預測（無明確機轉依據）：
- **無肌病型皮肌炎、新生兒皮肌炎**：屬自體免疫疾病，Resorcinol 沒有已知的免疫調節機轉，新生兒使用還有全身吸收風險。
- **兒童結締組織病相關間質性肺病**：與肺部無已知關聯，可能只是知識圖譜中的網路鄰近性所致。
- **慢性萎縮性肢端皮膚炎**：是 Lyme 病的晚期皮膚表現，需全身性抗生素治療，外用抗菌無法處理深層螺旋體感染。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自知識圖譜關聯，並非仿單內容）：包括 G6PD 缺乏症、高鐵血紅素血症（含還原酶缺乏型）、硫血紅素血症、腎臟疾病、糖尿病與糖尿病酮酸中毒、癲癇、心臟傳導疾病、猝死性心臟驟停、周邊動脈／血管疾病、呼吸衰竭、皮膚炎、脂漏性皮膚炎、毛囊炎、尋常疣、肛門生殖器人類乳突病毒感染等。
- **特殊族群**：新生兒與嬰兒使用 Resorcinol 有全身吸收與毒性疑慮（如高鐵血紅素血症、甲狀腺影響），在無強力理由下不宜使用。
- **藥物交互作用**：未查到相關資料。

其他警語與正式禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold（列為研究問題）**

**理由：**
- 預測新適應症僅有模型分數與間接機轉推論，沒有任何臨床試驗或文獻，證據等級為 L5。
- 仿單層級的安全性資料尚未取得，且知識圖譜顯示多項潛在禁忌。

**若要推進需要：**
- 取得香港衞生署的仿單，確認核准適應症、警語與禁忌。
- 補充 Resorcinol 的作用機轉資料（例如查詢 DrugBank）。
- 系統性搜尋瘢痕疙瘩性痤瘡的相關文獻與試驗，確認是否有任何支持證據。
- 若要探索，先以小規模前臨床或觀察性研究評估外用療效與全身吸收風險。
- 明確排除新生兒、兒童及 G6PD 缺乏症等高風險族群。
