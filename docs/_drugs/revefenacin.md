# REVEFENACIN：邁向支氣管炎（Bronchitis）適應症的老藥新用評估

## 一句話總結

REVEFENACIN 的原適應症資料目前尚未取得（TFDA 仿單警語/禁忌與作用機轉皆為待補資料缺口）。TxGNN 模型將其列為對**支氣管炎 (Bronchitis)** 具高關聯分數（**99.61%**）的候選，但目前僅有 **1 個臨床試驗**、**無直接文獻**佐證，證據偏弱。值得留意的是，同一藥物對「阻塞性肺病 (Obstructive Lung Disease)」的預測分數雖略低（99.10%），卻有 **16 個臨床試驗**（含多個 Phase 3 關鍵試驗）與 **20 篇文獻**支持，證據等級達 L1，遠比支氣管炎候選紮實。

## 為什麼這個預測合理？

原廠作用機轉（MOA）欄位目前為資料缺口，尚未從 DrugBank 取得完整敘述。不過從本次證據包中「阻塞性肺病」候選項的機轉關聯分析可知，Revefenacin 是一款長效、肺選擇性毒蕈鹼受體拮抗劑（LAMA），透過阻斷 M3 受體放鬆氣道平滑肌、降低氣道阻力，這是 COPD 及相關阻塞性呼吸道疾病（tiotropium、umeclidinium 等同類藥物皆已核准用於此類適應症）的主流藥理機轉。

由於原始適應症資料尚未收集完整，暫時無法直接比對其與支氣管炎的關聯性。但慢性支氣管炎（chronic bronchitis）本身即為 COPD 的表現型之一，理論上與 revefenacin 的支氣管擴張機轉具間接關聯。不過目前唯一的相關臨床試驗實際上是以一般 COPD／阻塞性肺病族群設計的藥效學與安全性研究，並非針對「支氣管炎」本身設計療效終點，機轉合理但直接證據仍不足。

## 安全性考量

安全性資訊請參考原廠仿單。目前 TFDA 仿單警語/禁忌資料為**阻斷性缺口（Blocking）**，尚無法進行安全性初評（S1）。

## 結論與下一步

**決策：Hold**

**理由：**
支氣管炎候選僅有 1 個非以此適應症為終點設計的 Phase 2 試驗，且無文獻佐證（證據等級 L4），加上安全性資料（警語、禁忌）完全缺失，目前無法進入安全性初評階段。

**若要推進需要：**
- 補齊 TFDA／原廠仿單警語與禁忌資料（DG001，Blocking，優先處理）
- 補齊作用機轉資料（DG002）
- 若持續聚焦支氣管炎，需取得以此適應症為明確療效終點設計的臨床試驗證據
- 建議評估團隊同時檢視同一藥物對「阻塞性肺病」的候選結果（L1 證據、Proceed with Guardrails），其證據基礎顯著更成熟，可能是更值得優先推進的方向
