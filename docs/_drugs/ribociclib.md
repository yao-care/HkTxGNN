# Ribociclib：從（原適應症未登載）到骨髓性白血病

## 一句話總結

Ribociclib 是 CDK4/6 抑制劑，香港已有 1 張許可證（Kisqali），但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**骨髓性白血病 (Myeloid Leukemia)** 有效，
但目前**無已登記的臨床試驗**，僅有 **1 篇前臨床文獻**支持，另有 1 篇病例報告提示可能的安全性訊號。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ribociclib 屬於 CDK4/6 抑制劑類別，
CDK6 在部分急性骨髓性白血病（AML）亞型（例如 MLL 重排型）中被認為是關鍵依賴因子，
因此機轉上可能適用於骨髓性白血病。

支持的證據僅有前臨床層級：一項體外研究探討 CDK4/6 抑制劑如何對抗 AML 細胞的藥物動力學抗藥性（ABCB1、ABCG2 轉運蛋白過度表現）。
目前沒有人體療效資料。

需要注意：0.993 的預測分數只反映知識圖譜中的網絡鄰近性，不等於療效證據。
另有病例報告描述 CDK4/6 抑制劑治療後出現伴嗜酸性球增多的 AML，可能是安全性訊號，而非療效佐證。

## 結論與下一步

**決策：Hold**

**理由：**
骨髓性白血病的支持證據僅有一篇體外研究，沒有臨床試驗與人體療效資料，
且有病例報告顯示 CDK4/6 抑制劑後出現 AML，需先釐清安全性訊號。
此預測目前只適合作為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單，確認原適應症、警語與禁忌症
- 補齊 ribociclib 的作用機轉資料（如 DrugBank）
- 進行 AML 細胞株或動物模型的進一步前臨床驗證，特別是 CDK6 依賴型亞型
- 評估 CDK4/6 抑制劑與繼發性血液惡性腫瘤的關聯
