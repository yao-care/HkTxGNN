# Rifampicin：從肺結核到結膜炎

## 一句話總結

Rifampicin（利福平）是廣譜抗菌藥物，原本用於治療肺結核。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效，但目前**沒有已登記的臨床試驗**，僅有約 **19 篇文獻**，且多為感受性調查、病例報告與年代久遠的研究，證據屬間接。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（本報告所整理的資料未收錄 MOA）。就已知的藥理特性而言，Rifampicin 是廣譜抗菌藥，作用於細菌的 DNA 依賴性 RNA 聚合酶，對金黃色葡萄球菌 (*Staphylococcus aureus*)、砂眼披衣菌 (*Chlamydia trachomatis*) 等菌種有活性，而這些菌種正是細菌性結膜炎的常見病原。

文獻中確有相關線索：多項感受性調查探討結膜炎致病菌對抗生素的反應；1975 年突尼西亞有一項以 1% rifampicin 眼藥膏與 tetracycline 治療地方性砂眼的對照試驗；1977 年倫敦一項 63 位病人的開放性試驗顯示，1% rifampicin 眼藥膏使用 6–7 週，臨床與微生物治癒率約 90%。

不過需要提醒：外用 rifampicin 治療結膜炎並非標準治療，且已有一線眼用抗生素可用。此預測在機轉上說得通，但目前證據仍偏間接、年代久遠。另有一筆「conjunctivitis (disease)」的預測與本項高度重複，應合併看待，不能視為獨立佐證。

## 安全性考量

- **禁忌症（知識圖譜資料，非仿單內容）**：知識圖譜列出與下列情況相關的禁忌或需謹慎，包括肝衰竭、肝炎等肝臟疾病、紫質症 (porphyria)、膽囊疾病、血小板減少、嗜中性白血球減少、顆粒性白血球缺乏症、再生不良性貧血、全血球減少、周邊神經病變、糖尿病酮酸中毒、痛風、慢性乙醯化緩慢者及物質濫用/依賴等。
- **藥物交互作用**：已查得 100 筆交互作用，以下為部分中度等級者：rabeprazole、omeprazole、doxycycline、clarithromycin、metronidazole、metformin、pioglitazone、canagliflozin、chlorpropamide、bupropion、aprepitant、morphine，以及 hydrocortisone、dexamethasone、betamethasone、triamcinolone 等類固醇，還有 cholecalciferol、calcifediol、calcitriol。Rifampicin 為強效酵素誘導劑，合併用藥時需特別留意。
- **其他考量**：Rifampicin 有誘導分枝桿菌抗藥性的風險，用於良性眼部感染須謹慎。另有 1976 年的文獻提及 rifampicin 的眼部毒性。

香港仿單的警語與禁忌資料目前缺漏，詳細內容請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數很高，且有早期眼藥膏研究顯示對披衣菌眼部感染有效，但沒有已登記的臨床試驗，證據多為感受性調查與年代久遠的研究，屬 L4。
- 外用 rifampicin 並非結膜炎的標準治療，已有一線眼用抗生素；且考量保留 rifampicin 於結核病治療、避免抗藥性，目前不建議推進。

**若要推進需要：**
- 確認是否有可用的眼用劑型（目前香港許可證資料未載明劑型，路徑相容性待確認）
- 與現行一線眼用抗生素的比較性臨床試驗，以及針對披衣菌或砂眼等特定病原的現代研究
- 取得 MOA 與香港仿單的警語、禁忌資料
- 評估抗藥性風險與局部用藥的眼部安全性
