# RILPIVIRINE：從 HIV-1 感染到貓後天免疫缺乏症候群

## 一句話總結

Rilpivirine 是一種非核苷類逆轉錄酶抑制劑（NNRTI），原本用於 HIV-1 感染治療。
TxGNN 模型預測它可能對**貓後天免疫缺乏症候群 (Feline Acquired Immunodeficiency Syndrome)** 有效，
目前**無臨床試驗**，僅有 **1 篇**前臨床文獻（體外生化與結構研究）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Rilpivirine 屬於 NNRTI 類別，會結合 HIV-1 的逆轉錄酶（RT）並抑制病毒複製。

貓免疫缺乏病毒（FIV）和 HIV 同屬慢病毒，兩者的逆轉錄酶結構相近，所以知識圖譜推得這個連結，機轉上有其合理性。

不過目前唯一的證據是 NNRTI 對 FIV 與 HIV 逆轉錄酶的生化和結構比較研究，屬於體外資料，而且是獸醫領域。尚無動物體內療效或臨床資料，因此只能視為早期假說。

## 結論與下一步

**決策：Hold**

**理由：**
此預測只有體外生化與結構層級的證據，屬於獸醫領域，沒有動物體內療效或臨床資料。對人類用藥而言，這不是可推進的老藥新用機會。
另外，排名較後的預測（如先天性 HIV、AIDS 相關併發症）本質上是已核准的 HIV 適應症，並非真正的新用途。

**若要推進需要：**
- FIV 感染貓的體內藥效與藥動學研究
- 獸醫用藥的安全性與劑量資料
- 香港衛生署仿單的警語與禁忌資料（目前缺口）
- 詳細的作用機轉資料（MOA）
