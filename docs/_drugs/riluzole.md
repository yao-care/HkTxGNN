## Riluzole: 雙側旁矢狀頂枕多小腦回症 (bilateral parasagittal parieto-occipital polymicrogyria)
{: .text-alpha }

## 一句話總結

Riluzole 是一種麩胺酸釋放抑制劑，同時調節電壓門控鈉離子通道。
TxGNN 模型預測它可能對**雙側旁矢狀頂枕多小腦回症 (bilateral parasagittal parieto-occipital polymicrogyria)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Riluzole 具有抑制麩胺酸釋放及調節電壓門控鈉離子通道的特性。

多小腦回症是一種皮質發育畸形，與神經元遷移異常及神經興奮性改變有關，因此在麩胺酸訊號傳導上存在理論上的關聯。然而，這個關聯僅是推測，沒有直接的臨床或文獻證據支持。

TxGNN 分數很高（0.9999），但這只是計算模型的預測結果，需要進一步的基礎與臨床研究驗證。
