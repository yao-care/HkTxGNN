# Rimegepant：從偏頭痛到腦幹型先兆偏頭痛

## 一句話總結

Rimegepant 是 CGRP 受體拮抗劑（gepant 類），目前已用於偏頭痛的急性治療與預防。
TxGNN 模型預測它可能對**腦幹型先兆偏頭痛 (Migraine with Brainstem Aura)** 有效，
目前**無臨床試驗**，有 **13 篇文獻**，但皆為一般偏頭痛研究，並非針對此亞型，屬間接證據。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據文獻，Rimegepant 是口服小分子 CGRP 受體拮抗劑，已核准用於成人偏頭痛（有或無先兆）的急性治療，以及陣發性偏頭痛的預防。

腦幹型先兆偏頭痛本身屬於偏頭痛的一種亞型，因此 CGRP 路徑參與其中在生物學上有其合理性。此外，gepant 類藥物不像 triptan 會造成血管收縮，而 triptan 在此亞型中傳統上被避免使用，所以 gepant 在理論上是可考慮的選項。

不過，目前列出的文獻都是一般偏頭痛的綜述、藥動學與安全性研究、開放標籤研究及一項間接比較，**沒有一篇針對腦幹型先兆偏頭痛**，證據屬間接。此亞型的療效與安全性仍需確認，例如從關鍵試驗的亞組分析，或 2026 年的青少年回溯性研究（PMID 41652664）中取得資料。

## 結論與下一步

**決策：Hold**

**理由：**
Rimegepant 在偏頭痛整體上有成熟的證據，且機轉上對腦幹型先兆偏頭痛具合理性。但目前沒有任何針對此亞型的臨床試驗或研究，證據等級僅為 L4，且缺乏香港仿單的安全性資料。在安全性篩選階段上也受到阻礙。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語與禁忌症（目前為阻礙性資料缺口）
- 補齊 DrugBank 的作用機轉資料
- 取得關鍵試驗中腦幹型先兆偏頭痛患者的亞組分析
- 查證 2026 年青少年回溯性研究（PMID 41652664）是否包含此亞型
- 評估此亞型的臨床試驗設計可行性
