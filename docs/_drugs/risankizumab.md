# Risankizumab：從乾癬到異位性皮膚炎（Dermatitis）

## 一句話總結

Risankizumab 是抗 IL-23p19 單株抗體，2019 年於日本首次核准用於乾癬、乾癬性關節炎等疾病。
TxGnn 模型預測它可能對**皮膚炎 (Dermatitis，主要指異位性皮膚炎)** 有效，
目前有 **1 個直接針對此適應症的 Phase 2 RCT（172人）**，另有 **6 個間接相關試驗**與 **17 篇文獻**支持這個方向。

## 為什麼這個預測合理？

目前缺乏 DrugBank 詳細作用機轉資料（MOA 為 Data Gap）。根據文獻證據（PMID 31098898），Risankizumab 是一種人源化 IgG 單株抗體，標的為 IL-23 的 p19 次單元，透過阻斷 IL-23/Th17 訊號軸發揮抗發炎作用，此機轉已在乾癬、乾癬性關節炎、泛發性膿疱性乾癬等 Th17 主導疾病中證實有效。

乾癬與異位性皮膚炎同屬慢性發炎性皮膚疾病，傳統上異位性皮膚炎被視為 Th2 為主的疾病，但部分患者族群（尤其亞洲人及「內在型」AD）顯示顯著的 Th17/IL-23 訊號上調，這為 IL-23 阻斷提供了機轉上的合理性。事實上，NCT03706040（Phase 2、172人、安慰劑對照雙盲）已直接測試 risankizumab 於中重度異位性皮膚炎患者，對應的文獻（PMID 36588137）也已發表結果。

需留意的是，臨床上 IL-23 抑制劑對異位性皮膚炎的效果普遍不如對乾癬顯著；此外文獻中亦有多篇報告指出 risankizumab 治療乾癬患者時，反而誘發「矛盾性濕疹反應」（paradoxical eczematous reaction，如 PMID 33185530、36939506、41645692 等），提示 IL-23 阻斷與皮膚炎之間的關係可能具有雙向性，需審慎解讀。

## 安全性考量

安全性資訊請參考原廠仿單。

> ⚠️ 需注意：多篇文獻報告 risankizumab 治療乾癬患者時可能誘發矛盾性濕疹反應（如 PMID 33185530、36939506、41645692），此為使用上需監測之現象。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖有 1 個已完成的 Phase 2 RCT（NCT03706040）直接測試 risankizumab 於異位性皮膚炎，證據等級達 L2，但效果普遍不如其於乾癬適應症顯著，且文獻顯示 IL-23 阻斷與皮膚炎之間可能存在雙向（矛盾性）反應，機轉解讀需謹慎。
- 藥物目前未於香港上市，仿單警語與禁忌症資料缺失（Blocking data gap），無法完成 S1 安全性初評，故此案僅停留於研究假說（Research Question）階段。

**若要推進需要：**
- 取得 TFDA/藥廠仿單完整警語與禁忌症資料，完成 S1 安全性初評
- 補充 DrugBank 作用機轉（MOA）資料，強化機轉關聯性分析
- 待 Phase 2 完整結果發表或後續 Phase 3 試驗數據，確認異位性皮膚炎族群的療效與矛盾反應風險
