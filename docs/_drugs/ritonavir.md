## Ritonavir：從 HIV 感染到猿猴免疫缺陷病毒感染
{: .text-alpha }

## 一句話總結

Ritonavir 是 HIV-1 蛋白酶抑制劑，也常作為藥物動力學增強劑（抑制 CYP3A4），知識圖譜中記錄的相關疾病包括慢性 C 型肝炎、HIV 感染與愛滋病。
TxGNN 模型預測它可能對**猿猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效。
目前**無臨床試驗**，僅有 **10 篇文獻**，且多為動物與體外研究，並不直接證明 ritonavir 單獨的效果。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，ritonavir 是 HIV-1 蛋白酶抑制劑，同時可抑制 CYP3A4，因此常與其他抗病毒藥物合併使用以提高血中濃度。

SIV 與 HIV 同屬慢病毒（lentivirus），其蛋白酶高度相似，因此機轉上具合理性。體外研究顯示 SIVmac239 對 ritonavir 敏感（EC50 約 13 nM，HIV-1 約 25 nM）；另一項研究也顯示 HIV-2、SIV 與 SHIV 對多種抗 HIV-1 藥物有感受性。

需要注意：SIV 感染是 HIV 的動物模型，並非人類疾病。多數獼猴研究使用的是多藥合併療法，ritonavir 只是其中一環，結果無法歸因於 ritonavir 單獨作用。因此這比較像是臨床前模型的支持，而非真正的人類藥物再利用機會。

## 結論與下一步

**決策：Hold**

**理由：**
- SIV 感染是 HIV 的動物模型，並非人類疾病，ritonavir 在人類的 HIV 治療用途已有香港許可證涵蓋，因此不構成實質的人類再利用機會。
- 現有文獻多為體外與合併療法的獼猴研究，沒有臨床試驗，也無法歸因於 ritonavir 單獨作用。

**若要推進需要：**
- 取得香港仿單的核准適應症、警語與禁忌資料
- 補充 ritonavir 的作用機轉資料
- 若要做動物模型研究，需有以 ritonavir 單藥或明確對照設計的試驗
- 確認此預測是否有任何人類臨床意義；若無，建議將資源轉向其他候選適應症

**附註：** 排名第 2 的「貓愛滋病」為獸醫適應症，無試驗與文獻；排名第 3 的罕見神經發育疾病缺乏合理的機轉連結，其高分來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，而非生物學證據，兩者皆不建議推進。
