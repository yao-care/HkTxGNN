# Romiplostim：從血小板減少症治療到原發性血小板釋放障礙

## 一句話總結

Romiplostim 是血小板生成素受體（TPO 受體）促效劑，能促進血小板生成，文獻中常用於免疫性血小板低下症（ITP）。
TxGNN 模型預測它可能對**原發性血小板釋放障礙 (Primary Release Disorder of Platelets)** 有效，分數極高。
不過目前只有 **1 個不直接相關的臨床試驗**和 **2 篇機轉層級文獻**，沒有臨床資料直接支持，建議暫緩（Hold）。

## 為什麼這個預測合理？

Romiplostim 是 TPO 受體促效劑，作用是刺激巨核細胞生成與成熟，進而增加血小板數量。DrugBank 的詳細作用機轉資料目前缺乏，以上說明來自本次評估的機轉分析。

預測的新適應症屬於血小板「功能」缺陷，也就是血小板在釋放內容物時出現問題。Romiplostim 增加的是血小板「數量」，並不預期能矯正這種質的缺陷。因此機轉上的關聯性偏弱。

現有文獻只涵蓋巨核細胞與血小板生成的基礎生物學，以及 ITP 自體抗體如何抑制前血小板形成。這些只是間接的機轉層級支持，極高的 TxGNN 分數沒有臨床資料佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測僅有模型分數與間接的機轉文獻，沒有任何直接測試 romiplostim 的臨床資料。
- 增加血小板數量並不預期能矯正血小板功能缺陷，機轉上並不吻合。

**若要推進需要：**
- 取得香港衛生署的藥品仿單，補齊警語與禁忌症資料
- 補充 DrugBank 的作用機轉資料，重新評估機轉關聯
- 搜尋直接以 romiplostim 治療血小板功能異常的臨床或病例報告
- 同批預測中，**新生兒同種免疫性血小板低下症（FNAIT）**的證據相對較多（L4，建議列為研究問題），可優先評估。但相關文獻僅涵蓋母體 ITP，且孕期與胎兒安全性必須先釐清。
- 同批預測中，其餘三項（偽性類血友病因子缺乏症、Glanzmann 血小板無力症、Scott 症候群）目前僅有模型預測，無任何試驗或文獻，維持 Hold。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
