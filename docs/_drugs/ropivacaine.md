# Ropivacaine：從局部麻醉到偏頭痛

## 一句話總結

Ropivacaine 是長效醯胺類局部麻醉藥，在香港已有注射劑型上市。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前有 **2 個臨床試驗**和 **3 篇文獻**支持這個方向，但證據以小型試驗與觀察性研究為主。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記載。根據已知資訊，Ropivacaine 是長效醯胺類局部麻醉藥，可阻斷電壓門控鈉通道，降低痛覺神經的傳導。

在偏頭痛的應用上，它是以區域神經或神經節阻斷的方式使用，例如蝶顎神經節 (sphenopalatine ganglion) 阻斷、星狀神經節阻斷與扳機點注射。這些做法可能調節與頭痛相關的三叉神經血管與副交感神經路徑。

需要注意，這種作用是局部且屬於處置性質，並非全身性作用，與一般口服偏頭痛藥物是不同的使用方式。其餘預測對象（腦幹先兆偏頭痛、腎因性抗利尿不適當症候群、輕度憂鬱症）缺乏臨床試驗與文獻。腦幹先兆偏頭痛的高分可能只反映與偏頭痛的本體論相近性；後兩者機轉上缺乏合理連結，高分可能是模型假象。

## 安全性考量

- **禁忌症（知識圖譜推論，非仿單內容）**：TxGNN 知識圖譜顯示的相關疾病包括慢性阻塞性肺病、氣喘、呼吸衰竭、腎臟疾病、肝臟疾病、膽道疾病、心血管疾病、心臟病、重症肌無力、神經肌肉接合部疾病、丁醯膽鹼酯酶缺乏症、腸阻塞、麻痺性腸阻塞、顱內高壓、尿道狹窄等。這些僅供風險提示，須以正式仿單為準。
- **藥物交互作用**：資料庫共記錄 64 筆。已列出的中度交互作用包括 Obeticholic acid、Morphine (liposomal)、Deferasirox、Fostamatinib；其餘多為輕度或等級未知（如 Cimetidine、Clarithromycin、Miconazole、Epinephrine 等）。

正式的仿單警語與禁忌症尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 偏頭痛的支持證據僅有一個 n=10 的 Phase 4 小型試驗、一個非偏頭痛專屬的兒童頭痛試驗，以及觀察性研究，尚無足以支持 L1/L2 的已完成 Phase 3 或 Phase 2/3 RCT。
- 香港仿單的警語與禁忌症資料缺口屬於阻斷性，無法完成初步安全性篩選。

**若要推進需要：**
- 取得並解析香港衛生署的仿單（警語、禁忌症、核准適應症）
- 取得作用機轉的完整資料
- 取得上述兩個試驗的結果，並尋找較大型的隨機對照試驗（針對偏頭痛的神經阻斷處置）
- 確認給藥途徑與劑型（神經節阻斷、扳機點注射）是否與現有注射劑許可範圍相符
- 其餘預測適應症（腦幹先兆偏頭痛、腎因性抗利尿不適當症候群、輕度憂鬱症）暫不建議推進
