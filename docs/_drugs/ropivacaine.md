# Ropivacaine：從局部麻醉到偏頭痛

## 一句話總結

Ropivacaine 是長效醯胺類局部麻醉藥，在香港以 Naropin 注射液上市。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前有 **4 個臨床試驗**和 **6 篇文獻**，但多為小型或非偏頭痛專一的研究，尚無偏頭痛的 Phase 2/3 RCT。

## 為什麼這個預測合理？

Ropivacaine 阻斷電壓門控鈉離子通道，是長效局部麻醉藥。用於區域神經阻斷（蝶顎神經節、星狀神經節或激痛點注射）時，可以中斷副交感與交感神經的輸出，也能抑制三叉神經血管系統的痛覺傳導。這些路徑被認為與偏頭痛疼痛有關。

這個機轉依賴給藥途徑與部位，全身性給藥沒有這樣的理論基礎。TxGNN 的高分與上述機轉相符，但模型分數不是臨床證據。

目前的直接證據僅限於小型或非偏頭痛專一的試驗，以及觀察性研究。

## 結論與下一步

**決策：Hold**

**理由：**
偏頭痛方向目前只有觀察性研究和小型試驗，唯一設計相符的 RCT 僅 10 人，沒有 Phase 2/3 RCT。TxGNN 高分只能視為研究假說。其他預測適應症（腎因性抗利尿不當症候群、輕鬱症）沒有合理機轉，也沒有任何試驗或文獻；腦幹先兆偏頭痛只有一篇不良反應病例報告。

**若要推進需要：**
- 設計以偏頭痛為主要終點的 Phase 2 RCT，明確限定給藥途徑與部位（如蝶顎神經節或星狀神經節阻斷）
- 取得香港衛生署仿單的警語與禁忌症，完成安全性篩查
- 補充 DrugBank 的作用機轉資料
- 確認各神經阻斷途徑與現有劑型、規格是否相容
- 追蹤 NCT06470581 的結果
