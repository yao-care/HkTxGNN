# Safinamide：從帕金森氏症到 Rasmussen 亞急性腦炎

## 一句話總結

Safinamide 在香港已上市，依藥理資料，原本用於帕金森氏症動作波動的輔助治療。
TxGNN 模型預測它可能對 **Rasmussen 亞急性腦炎 (Rasmussen subacute encephalitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。一般認為 Safinamide 是選擇性 MAO-B 抑制劑，同時會阻斷電壓門控鈉通道並減少麩胺酸釋放。這些作用理論上可能與癲癇控制有關。

Rasmussen 腦炎的核心是 T 細胞介導的神經發炎，屬於免疫性病程。現有資料沒有顯示 Safinamide 對這個過程有作用。因此這個預測的機轉連結偏推測，也可能只是知識圖譜結構造成的假象。

另外兩個預測是脊髓炎 (myelitis，99.46%) 和 PLA2G6 相關神經退化症 (99.22%)。脊髓炎同樣缺乏機轉依據。PLA2G6 相關神經退化症的生物學連結相對合理，因為部分表型有帕金森症狀和肌張力不全。即使有效，也較可能只是症狀改善，而非改變疾病進程。該預測被標為「研究問題」，適合以前臨床或個案層級探討。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有 TxGNN 預測分數，沒有臨床試驗或文獻，證據等級為 L5。
- Rasmussen 腦炎的免疫性機轉與 Safinamide 的已知作用缺乏連結。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語與禁忌症。
- 補齊 DrugBank 作用機轉資料，重新評估機轉連結。
- 以 Rasmussen 腦炎、癲癇、神經發炎等關鍵字系統性檢索文獻與試驗登記。
- 若仍要探索，優先研究 PLA2G6 相關神經退化症，以前臨床或個案層級驗證。

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。*
