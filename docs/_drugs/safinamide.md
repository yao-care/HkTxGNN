# Safinamide：原適應症資料缺失，TxGNN 預測 3 項神經系統適應症假說

## 一句話總結

Safinamide（DB06654）原適應症與作用機轉資料目前均缺失，無法確認其核准用途。
TxGNN 模型針對此藥物提出 3 項高分預測，最高分為 **Rasmussen 亞急性腦炎**（分數 99.63%），
但目前**無任何臨床試驗或文獻**支持，全數屬於模型純預測（**L5**），尚未進入安全性初評階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原始 MOA 為資料缺失，原適應症亦未提供）。
根據 DrugBank 藥物分類，Safinamide 已知為**選擇性可逆 MAO-B 抑制劑**，並具電位依賴型鈉通道阻斷及麩胺酸釋放調節作用——這是社群普遍認知的藥理特性，但本 Evidence Pack 中並未提供該資料作為正式佐證，故以下推論僅供參考，尚待補齊 DG002（MOA 資料缺口）後重新驗證。

**Rasmussen 亞急性腦炎（rank 1）**：此為自體免疫性癲癇症候群，病理主要涉及 T 細胞介導之神經元破壞與麩胺酸興奮毒性。Safinamide 的抗麩胺酸作用理論上可能減緩興奮毒性，但與其抗自體免疫核心病理無直接關聯，機轉合理性偏弱。

**Myelitis 脊髓炎（rank 2）**：多屬發炎性/自體免疫性脊髓病變，核心病理為免疫細胞浸潤與髓鞘/軸突損傷，與 Safinamide 已知的多巴胺能神經保護機轉無直接機轉重疊，僅為知識圖譜高分配對，生物學合理性論證薄弱。

**PLA2G6 相關神經退化症（rank 3）**：成人型常表現類帕金森症狀，病理涉及粒線體功能異常、鐵沉積及 α-突觸核蛋白病變，與 Safinamide 於帕金森氏症之多巴胺能神經保護、抗麩胺酸興奮毒性機轉在理論上重疊度最高，是三者中機轉合理性最強的假說。

## 結論與下一步

**決策：Hold**

**理由：**
三項預測適應症均無任何臨床試驗或文獻佐證，僅為 TxGNN 知識圖譜評分（L5），且原廠適應症、作用機轉（DG002）、安全性警語與禁忌症（DG001, Blocking）均缺失，尚未達最低安全性初評（S1）門檻。

**若要推進需要：**
- 取得 TFDA/香港仿單警語與禁忌症資料（DG001，Blocking，阻斷進入 S1）
- 補齊 DrugBank 詳細作用機轉資料（DG002）
- 針對三項候選適應症進行專屬文獻與機轉檢索，優先驗證機轉合理性最高的 PLA2G6 相關神經退化症
- 確認香港上市可行性與藥品可及性（目前 0 張許可證）
