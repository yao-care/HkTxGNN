# Safinamide：從帕金森氏症到 Rasmussen 亞急性腦炎

## 一句話總結

Safinamide 是一種 MAO-B 抑制劑，原本用於治療帕金森氏症。
TxGNN 模型預測它可能對 **Rasmussen 亞急性腦炎 (Rasmussen subacute encephalitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅屬模型預測階段。

## 為什麼這個預測合理？

目前缺乏本報告所編纂資料中的詳細作用機轉。根據一般藥理知識，safinamide 是可逆性 MAO-B 抑制劑，同時可阻斷電壓門控鈉離子通道並抑制麩胺酸釋放。這些特性理論上可能與 Rasmussen 腦炎的癲癇發作及興奮性毒性神經損傷有關。

然而，Rasmussen 腦炎主要由 T 細胞介導的自體免疫發炎所驅動，safinamide 並不針對這一病理機制。因此，這項連結屬於根據一般藥理推論，並非來自實際研究資料，說服力有限。

其他排名較前的預測還包括：

- **脊髓炎 (myelitis)**（分數 99.46%）：可能的理由是神經保護作用，但該病病因多元（自體免疫、感染、感染後），safinamide 無已知免疫調節或抗感染活性，連結屬推測。
- **PLA2G6 相關神經退化症 (PLA2G6-associated neurodegeneration)**（分數 99.22%）：三者中生物學上最合理。此病包含 PARK14 肌張力不全-帕金森症，safinamide 對帕金森症狀可能有症狀性助益，但不太可能延緩疾病進程，且早發、快速進展型可能反應不佳。

三個預測目前皆無臨床試驗或文獻支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.63%），但目前僅有模型預測（L5），沒有臨床試驗或文獻佐證。
- Rasmussen 腦炎以自體免疫發炎為主因，safinamide 的機轉無法直接針對此病理，生物學合理性有限。

**若要推進需要：**
- 取得詳細的作用機轉資料（MOA），釐清與 Rasmussen 腦炎病理的關聯
- 取得香港仿單的警語與禁忌症資料，完成安全性篩選
- 進行文獻與試驗的系統性檢索，並考慮前臨床（如癲癇、興奮性毒性模型）驗證
- 若優先考慮生物學合理性，可評估將 PLA2G6 相關神經退化症（帕金森症狀）作為替代首選候選
