# Salbutamol：從原適應症（許可證未載明）到乳突性結膜炎

## 一句話總結

Salbutamol 是一種已在香港上市的藥物，但本次資料中的許可證並未載明原適應症。
TxGNN 模型預測它可能對**乳突性結膜炎 (Papillary Conjunctivitis)** 有效，預測分數很高。
然而目前**沒有任何臨床試驗或文獻**支持這個方向，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，原適應症也未在許可證中登載。可以確定的是，Salbutamol 屬於 β2 腎上腺素受體促效劑。

從這個藥理類別推測，β2 促效作用可能影響肥大細胞的介質釋放和眼部血管張力，這是本預測唯一的機轉線索。這個推論目前純屬推測：沒有任何試驗或文獻驗證，且原適應症與乳突性結膜炎的關聯性也尚未評估。

TxGNN 分數雖然高達 99.996%，但分數本身不等於臨床支持。在沒有實證資料的情況下，這個預測只能視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
這個預測只有模型分數，沒有任何臨床試驗或文獻佐證，機轉推論也屬推測，證據等級僅 L5。目前不適合投入資源推進。

**若要推進需要：**
- 補齊 Salbutamol 的作用機轉與原適應症資料
- 取得香港衛生署仿單的警語與禁忌症，完成安全性初篩
- 評估給藥途徑是否可行，因為已知的香港劑型為口服與靜脈，沒有眼用劑型
- 先做前臨床或機轉研究，確認 β2 促效作用與結膜發炎的關聯，才有進入 L4 的基礎

另外，同一份資料中的**支氣管炎 (Bronchitis)** 預測有較多試驗和文獻（證據等級 L3）。但該疾病定義模糊，也可能只是原有的支氣管痙攣用途，不算真正的老藥新用。若要優先評估，建議另行處理。

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
