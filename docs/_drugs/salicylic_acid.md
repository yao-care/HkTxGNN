# Salicylic acid：從足癬與關節炎等適應症到乳頭狀結膜炎

## 一句話總結

Salicylic acid（水楊酸）是常見的外用角質溶解劑與抗發炎成分，原本用於足癬、痤瘡、脂漏性皮膚炎、類風濕性關節炎、過敏性鼻炎等多種疾病。
TxGNN 模型預測它可能對**乳頭狀結膜炎 (Papillary Conjunctivitis)** 有效，
但目前**沒有臨床試驗也沒有文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。一般認為水楊酸可能透過抑制 COX 酵素、減少前列腺素合成而發揮抗發炎作用，但這一點尚缺乏公開的生物活性數據佐證，也未能確認其主要分子標的。

乳頭狀結膜炎帶有過敏性／異位性發炎成分，而水楊酸已被用於過敏性鼻炎，因此模型的預測在概念上有一點關聯。

不過，現有資料並不支持眼部使用。外用水楊酸具有角質溶解作用且刺激性強，一般不適合用於眼睛。這個關聯屬於推測，僅建立在 TxGNN 預測分數上。

**其他高分預測的說明：** 排名前十的預測中，大多數是罕見遺傳性骨骼或發育異常疾病（如 brachyolmia、pseudoachondroplasia、acromesomelic dysplasia 等），並未找到合理的機轉關聯，高分很可能來自知識圖譜的結構性假象。其中生物學上最合理的是**脊椎關節病變易感性 (Spondyloarthropathy, susceptibility to)**：水楊酸類屬 COX 抑制劑，NSAIDs 是脊椎關節炎的第一線治療。但目前同樣沒有試驗或文獻證據，建議列為研究問題，可先針對水楊酸類藥物用於軸性脊椎關節炎進行文獻回顧。

## 安全性考量

- **藥物交互作用**：藥理資料庫顯示水楊酸與 ASIC3（酸感應離子通道 3）有藥理關聯，但這是標的層級的資料，並非臨床上的藥物間交互作用，且未標示嚴重程度。

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有任何臨床試驗或文獻佐證，證據等級僅為 L5。
- 外用水楊酸具刺激性與角質溶解作用，不適合眼部使用，且機轉與安全性資料均不足。

**若要推進需要：**
- 取得並確認作用機轉（MOA）資料
- 取得香港仿單的警語與禁忌症資訊
- 針對水楊酸類藥物用於軸性脊椎關節炎進行文獻回顧，這是最合理的替代方向
- 若仍要探討眼部適應症，需先評估眼部耐受性與給藥途徑的可行性
