# Sebelipase alfa：從溶小體酸性脂肪酶缺乏症到 Scheie 症候群

## 一句話總結

Sebelipase alfa（香港商品名 KANUMA）是重組人類溶小體酸性脂肪酶（LAL），用於溶小體酸性脂肪酶缺乏症（LAL-D）的酵素替代治療。
TxGNN 預測它可能對 **Scheie 症候群 (Scheie syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，只有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據證據包的評估內容，Sebelipase alfa 是重組人類 LAL，能恢復溶小體內膽固醇酯與三酸甘油酯的水解，用於改善 LAL-D 的肝病變與血脂異常。

Scheie 症候群（輕症型黏多醣症 I 型）是 α-L-艾杜糖醛酸酶缺乏，造成糖胺聚醣堆積。兩者受質與缺陷酵素都不同，**機轉上沒有可信的關聯**。

TxGNN 的高分（99.80%，全體排名 4615）最可能反映兩者在知識圖譜中同屬溶小體貯積症的鄰近區域，而非特定的作用機轉。這個預測應視為模型假象，不宜當作可轉譯的假說。

## 結論與下一步

**決策：Hold**

**理由：**
Scheie 症候群這項預測只有模型分數，沒有試驗、文獻或機轉支持，證據等級為 L5。Sebelipase alfa 補充的是 LAL，與 Scheie 症候群缺陷的酵素不同，因此不建議推進。

**其他預測的參考資訊：**
- 同一份預測清單中，**膽固醇酯貯積症 (cholesteryl ester storage disease)** 有 Phase 3 隨機對照試驗（ARISE，NCT01757184）支持，證據等級 L1。這是藥物本身的已上市適應症，並非真正的再利用。
- **Wolman 病相關節點**的證據等級為 L3，有世代研究與病例系列支持。該節點的疾病名稱需先確認是否對應經典 Wolman 病。
- 其餘預測（Hurler 症候群、Gaucher 病、Tay-Sachs 病等）多為 L4–L5，機轉上無直接關聯。

**若要推進需要：**
- 補齊原適應症（`original_indications`）與作用機轉（MOA）欄位，這兩項在證據包中是空的。
- 取得香港衛生署核准的仿單，確認適應症、警語與禁忌。
- 若仍想評估 Scheie 症候群，需先有酵素活性或細胞模型等前臨床機轉資料，並與 Scheie 症候群專用的酵素替代治療做比較。

*本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。*
