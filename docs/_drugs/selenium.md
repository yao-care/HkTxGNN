# Selenium（硒）：從微量元素補充到硬化性膽管炎

## 一句話總結

Selenium（硒）是人體必需微量元素，目前在香港**未有藥品許可證上市**，也缺乏明確的原始核准適應症資料。TxGNN 模型給出高達 **99.04%** 的預測分數，指向硬化性膽管炎（Sclerosing Cholangitis），但目前**沒有任何臨床試驗**支持，僅有 **5 篇文獻**，且核心文獻的方向與「補充硒可治療此病」的假說**並不一致**。

## 為什麼這個預測合理？

目前缺乏硒的詳細作用機轉（MOA）資料，屬於 Data Gap。根據可取得的文獻，唯一直接相關的研究（PMID 9053974）發現原發性硬化性膽管炎（PSC）病人肝臟中的**銅與硒呈現滯留蓄積**，而非缺乏——這暗示膽汁淤積導致微量元素排除障礙是**疾病造成的結果**，而非硒缺乏引發疾病。這個方向與「補充硒可治療 PSC」的假說是**相反**的。

其餘 4 篇文獻分別是飲食調查、動物模型蛋白質體學、腸道外營養比較，以及一篇與大腸癌化學預防相關但與 PSC 無直接關聯的回顧文章。這些都無法建立硒補充與 PSC 治療之間的機轉連結。

因此，TxGNN 給出的高分很可能是透過知識圖譜中「肝病／氧化壓力」相關節點產生的**間接關聯**，存在被判定為 false positive 的風險，而非具備實證支持的真實藥理機轉。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 分數雖高，但核心文獻顯示硒在 PSC 病人體內是**蓄積而非缺乏**，方向與「補硒治療」假說矛盾；加上無臨床試驗、無 MOA 資料、香港未上市，整體證據等級僅 L5，不足以支持推進。

**若要推進需要：**
- 硒補充對 PSC 病程影響的機轉研究（動物或體外實驗），釐清因果方向
- 硒的 DrugBank 完整 MOA 資料
- 香港/原廠仿單警語與禁忌症資料（DG001）
- 至少 1 個探索性臨床研究或病例對照研究，直接檢驗硒補充是否對 PSC 有治療效果
