# Selinexor：從多發性骨髓瘤/瀰漫性大B細胞淋巴瘤到藥物性骨質疏鬆症

## 一句話總結

Selinexor 是 XPO1（exportin-1）抑制劑，臨床上用於多發性骨髓瘤與瀰漫性大B細胞淋巴瘤的治療。
TxGNN 模型預測它可能對**藥物性骨質疏鬆症 (Drug-induced Osteoporosis)** 有效，
但目前**沒有臨床試驗或文獻**支持，且機轉方向可能與此適應症假設相矛盾。

## 為什麼這個預測合理？

目前缺乏 Selinexor 詳細的作用機轉資料。根據評估報告中的既有描述，Selinexor 為 XPO1（exportin-1）抑制劑，臨床上用於多發性骨髓瘤與瀰漫性大B細胞淋巴瘤，已知毒性包括食慾不振、體重下降、疲勞、血球減少。

這些已知毒性與「骨質保護」機轉並無明確關聯。更值得注意的是，Selinexor 治療常合併皮質類固醇使用，而類固醇本身正是藥物性骨質疏鬆症的常見誘因之一。換言之，機轉方向與此適應症假設存在**潛在矛盾**——藥物本身或其常用併用藥可能反而增加骨質疏鬆風險，而非改善之。

此預測完全由 TxGNN 知識圖譜分數（0.992）驅動，缺乏任何機轉推論或臨床實證支持，應審慎看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 此適應症僅有 TxGNN 模型預測分數支持（證據等級 L5），無任何臨床試驗、文獻或機轉研究佐證。
- 機轉方向可能與適應症假設相矛盾（Selinexor 常合併皮質類固醇使用，而類固醇為藥物性骨質疏鬆症常見誘因），需優先釐清此矛盾點再考慮後續行動。

**若要推進需要：**
- 補齊 TFDA/原廠仿單安全性資料（警語、禁忌症）— 目前為 Blocking 等級資料缺口
- 補齊 Selinexor 詳細作用機轉（MOA）資料，以釐清與骨質代謝的實際關聯
- 尋找臨床前或機轉層級研究，確認方向是否成立（例如是否有次族群顯示骨質保護效果）
- 待有實際研究或文獻支持後，方可重新評估證據等級並考慮進入下一階段
