# Selinexor：從原適應症（資料未載明）到藥物誘發性骨質疏鬆

## 一句話總結

Selinexor 在香港以 XPOVIO 錠劑 20mg 上市，但本次資料未載明其原適應症。
TxGNN 模型預測它可能對**藥物誘發性骨質疏鬆 (Drug-induced Osteoporosis)** 有效，
目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Selinexor 一般被描述為 XPO1（exportin-1）抑制劑，但這點未在本次資料中驗證，也沒有任何與骨代謝相關的機轉被提供或確認。

藥物誘發性骨質疏鬆是一個範圍很廣的繼發性疾病。這個高分預測可能只是反映知識圖譜中的「鄰近關係」（共享的相鄰節點），不代表有治療上的合理性。TxGNN 分數 (99.22%) 只是模型預測，不是臨床證據。

另外，Selinexor 已知的耐受性問題（如食慾不振、體重減輕、疲倦）可能對骨骼或營養狀態有不利影響。在推進任何假說前，應先檢視這個方向，再從一手資料釐清它與骨代謝是否有合理連結。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有 TxGNN 模型預測（L5），沒有臨床試驗、文獻或已驗證的機轉支持。
- 香港仿單的警語與禁忌尚未取得，無法進行安全性篩選。

**若要推進需要：**
- 從香港衞生署網站下載並解析仿單（警語、禁忌症、核准適應症）
- 透過 DrugBank 補齊作用機轉（MOA）
- 從一手資料檢視 XPO1 抑制與骨代謝（成骨／蝕骨細胞）的關聯，包括前臨床證據
- 檢視 Selinexor 的耐受性問題（食慾不振、體重減輕、疲倦）對骨骼與營養狀態的可能負面影響
- 確認藥物誘發性骨質疏鬆的具體族群與目標，再評估劑型與給藥途徑是否相容

*本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。*
