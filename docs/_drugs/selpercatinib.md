# Selpercatinib：從 RET 驅動癌症到肺高壓

## 一句話總結

Selpercatinib 是選擇性 RET 激酶抑制劑，現有文獻顯示它用於 RET 基因異常的癌症（例如 RET 融合陽性非小細胞肺癌）。
TxGNN 模型預測它可能對**肺高壓 (Pulmonary Hypertension)** 有效，但目前**沒有任何臨床試驗**，兩篇文獻也都不是研究肺高壓，證據僅止於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Selpercatinib 是高選擇性的 RET 激酶抑制劑，用於 RET 驅動的癌症，但沒有資料說明 RET 抑制與肺高壓之間的生物學關聯。

唯一勉強的連結是：部分多標靶激酶抑制劑（如 imatinib）曾被探索用於肺動脈高壓。這個推論不能延伸到高選擇性的 RET 抑制劑。

因此這個預測缺乏機轉支持，高分主要來自知識圖譜的鄰近關係。已檢索到的兩篇文獻談的是 RET 驅動癌症的療效與不良事件，並未涉及肺高壓的治療。此外，高血壓是這類藥物已知的不良反應，現有訊號反而偏向安全疑慮，而非療效。

## 安全性考量

- **重要提醒**：高血壓是這類藥物已知的不良反應。對肺高壓族群使用前需特別評估血流動力學風險。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有臨床試驗，現有文獻也非肺高壓研究，機轉上找不到支持的生物學依據，證據僅為模型預測。
- 安全性訊號（高血壓）反而偏向風險。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症，完成安全性初篩。
- 補充 Selpercatinib 的作用機轉資料（DrugBank）。
- 針對 RET 訊號與肺血管重塑（pulmonary vascular remodeling）的關聯，做機轉文獻回顧或前臨床驗證。
- 評估高血壓類不良反應對肺高壓族群的風險。

**其他預測適應症：**
偏頭痛 (Migraine Disorder，99.17%) 與腦幹型先兆偏頭痛 (Migraine with Brainstem Aura，99.05%) 同樣沒有試驗與文獻，證據等級均為 L5，建議同樣 Hold。後者很可能與前者共用同一個圖譜鄰域，不是獨立的證據。
