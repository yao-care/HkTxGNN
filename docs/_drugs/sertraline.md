# Sertraline：從焦慮症與強迫症到思覺失調型人格障礙（Schizoid Personality Disorder）

## 一句話總結

Sertraline（舍曲林）是一種選擇性血清素再吸收抑制劑（SSRI），原本用於焦慮症、創傷後壓力症候群、強迫症、社交畏懼症等。
TxGNN 模型預測它可能對 **思覺失調型人格障礙 (Schizoid Personality Disorder)** 有效，但目前**沒有臨床試驗**，僅有 **1 篇間接相關文獻**，證據非常薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sertraline 屬於 SSRI 類藥物，已知具有抗焦慮與抗憂鬱作用，理論上可能改善人格障礙患者合併的焦慮、憂鬱或社交退縮症狀。

不過，目前沒有直接證據顯示它能改善思覺失調型人格障礙的核心特質（如情感疏離、對人際關係缺乏興趣）。分數雖高（99.93%），但看起來主要反映的是知識圖譜中「人格障礙」這個共同類別，而非具體的作用機轉。同一批預測中，分裂型、做作型、妄想型人格障礙的分數完全相同，也支持這個判斷。

因此，這個預測目前只適合視為研究假說，不宜當作療效結論。

## 安全性考量

- **知識圖譜標示的相關禁忌疾病**（非仿單內容）：癲癇、躁鬱症、重度情感性疾患、肝臟疾病、膽囊疾病、凝血疾病、抗精神病藥惡性症候群、抗利尿激素不適當分泌症候群（SIADH）、腎因性抗利尿激素不適當症候群、血清素症候群。
- **藥物交互作用**：共查得 100 筆，以下為部分重要者：
  - **嚴重 (Major)**：Bupropion、Lorcaserin、Diethylpropion、Dolasetron、Eliglustat、Palonosetron、Phentermine
  - **中度 (Moderate)**：Acetylsalicylic acid（阿斯匹靈）、Morphine、Clarithromycin、Famotidine、Loperamide、Glimepiride、Chlorpropamide 等

仿單中的警語與禁忌資料尚未取得，詳細資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有任何針對思覺失調型人格障礙的臨床試驗，文獻也僅為暴食症的間接資料，證據等級為 L5，且缺乏作用機轉資料。
- 此預測可能源自知識圖譜的疾病分類相似性，而非具體的藥理機轉。

**若要推進需要：**
- 取得 Sertraline 的作用機轉資料，並分析與思覺失調型人格障礙病理的關聯
- 系統性搜尋人格障礙（特別是 Cluster A）使用 SSRI 的研究
- 取得香港仿單的警語、禁忌與核准適應症，完成安全性篩選
- 若要探索，可先針對人格障礙合併焦慮或憂鬱的族群設計小型探索性試驗，而非直接以核心特質為目標
