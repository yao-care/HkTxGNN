# Silodosin：從良性攝護腺肥大到 Ambras 型先天性全身多毛症

## 一句話總結

Silodosin 是一種用於治療良性攝護腺肥大 (BPH) 的藥物。
TxGNN 模型預測它可能對 **Ambras 型先天性全身多毛症 (Ambras type hypertrichosis universalis congenita)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型的運算預測。

| 原適應症 | 良性攝護腺肥大 (benign prostatic hyperplasia) |
| 預測新適應症 | Ambras 型先天性全身多毛症 (Ambras type hypertrichosis universalis congenita) |

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Silodosin 是選擇性 α1A 腎上腺素受體拮抗劑，用於緩解良性攝護腺肥大的下泌尿道症狀。

Ambras 症候群是一種罕見的先天性多毛症，與影響 TRPS1 調控的基因組重排有關，屬於發育與遺傳層面的機轉。目前看不出 α1A 受體阻斷與此疾病之間有明確的生物學連結。

TxGNN 的高分 (99.99%) 僅是知識圖譜的運算結果，可能來自網路鄰近性，而非真正的藥理關係，不應視為證據。若要提出假說（例如影響毛囊平滑肌或血管張力），也屬推測，需先經前臨床驗證。

其他排名靠前的預測（多毛症、伴牙齒或牙周異常的畸形症候群、Dandy-Walker 畸形相關症候群、孤立性遺傳性毛幹異常）同樣沒有臨床或文獻支持，且多為遺傳或發育性結構缺陷，症狀性泌尿道藥物不太可能具疾病修飾作用。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（來自知識圖譜，並非仿單內容）：多系統萎縮症、姿勢性直立心搏過速症候群、姿勢性低血壓、肝衰竭、腎臟疾病、輸尿管積膿、術中虹膜鬆弛症候群 (IFIS)。
- **藥物交互作用**：共查得 99 筆。
  - 嚴重 (Major)：Clarithromycin。
  - 中度 (Moderate)：Bupropion、Aprepitant、Morphine、Dexamethasone、Cimetidine、Canagliflozin、Dapagliflozin、Empagliflozin、Miconazole、Clotrimazole 等。

仿單層級的警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測僅來自模型分數，沒有任何臨床試驗或文獻佐證，機轉上也找不到合理連結，證據等級為 L5。
- 目標疾病多為遺傳或發育性異常，α1A 受體拮抗劑不太可能有效；加上藥物有 99 筆交互作用，若無明確療效訊號，不宜讓患者承擔全身性暴露風險。

**若要推進需要：**
- 補充 Silodosin 的作用機轉資料 (MOA)
- 取得香港仿單的警語與禁忌資料
- 進行前臨床研究（如毛囊細胞或動物模型），驗證 α1A 阻斷與毛髮生長的關聯
- 評估是否有局部給藥途徑可降低全身性風險
- 評估其他預測疾病中是否有較具生物學合理性的標的
