# Silodosin：從（原適應症資料缺失）到 Ambras 型先天性全身性多毛症

## 一句話總結

Silodosin（DB06207）原適應症資料因香港未上市而缺失，各候選理由文字顯示其藥理機轉為 **α1A 腎上腺素受體拮抗劑**。
TxGNN 模型對此藥產生 5 個高分（>99.9%）預測適應症，但**全數為罕見遺傳性疾病**，且模型自身在 `repurposing_rationale` 中已明確標註「無生物學連結」或「關鍵字誤配」。
目前 **0 個臨床試驗**支持任一候選，證據等級均為 **L5**（僅模型預測），判定為模型在稀疏節點上的雜訊。

## 為什麼這個預測合理？

正式的 `original_moa` 欄位缺失（DG002，High severity），但五個候選理由欄位均一致提及本藥為 **α1A 腎上腺素受體拮抗劑**，可作為背景推論依據。

然而，這個藥理機轉與五個候選適應症——多毛症候群、牙周/牙齒畸形症候群、Dandy-Walker 畸形、遺傳性毛幹異常——**均無已知生物學連結**。模型自身的 rationale 文字已逐一說明：

- Rank 1、2（多毛症相關）：屬基因異常疾病，與 α1A 訊號無關，疑似罕見病節點嵌入稀疏導致的模型雜訊
- Rank 3（牙周/牙齒畸形症候群）：雖附有 20 篇文獻，但全數為牙周病一般性研究，未提及 silodosin 或任何 α1 拮抗劑，屬**關鍵字誤配**而非藥物專一性證據
- Rank 4（Dandy-Walker 畸形）：先天性後顱窩結構異常，無關聯
- Rank 5（毛幹結構異常）：角蛋白/毛囊發育缺陷，無關聯

結論是：這批高分預測**不構成有效的老藥新用候選**，而是模型在證據稀疏的罕見病節點上輸出的統計雜訊。

## 結論與下一步

**決策：Hold**

**理由：**
五個候選適應症證據等級皆為 L5（僅有模型預測，無實質研究支持），且模型自身標註的機轉理由已明確指出無生物學合理性或屬關鍵字誤配。加上原始藥物之作用機轉（DG002）與香港仿單安全性資料（DG001，Blocking）皆缺失，目前無法進入 S1 安全性初評。

**若要推進需要：**
- 補齊仿單警語與禁忌資料（DG001，Blocking，來源：官方仿單 PDF）
- 補齊 DrugBank MOA 資料以進行正式機轉關聯性分析（DG002，High）
- 針對本藥已知的 α1A 拮抗機轉，重新檢索與泌尿/攝護腺系統相關的候選適應症，取代目前這批罕見病雜訊候選
- 若持續在稀疏節點（罕見病）產生高分雜訊，建議檢視 TxGNN 模型在此類節點上的信心校正方法
