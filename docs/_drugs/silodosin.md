## Silodosin：從良性前列腺增生到安布拉斯型全身性先天多毛症
{: .text-alpha }

## 一句話總結

Silodosin 是一種藥物，知識圖譜中記錄的原適應症為良性前列腺增生。
TxGNN 模型預測它可能對**安布拉斯型全身性先天多毛症 (Ambras type hypertrichosis universalis congenita)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Silodosin 屬於選擇性 α1A 腎上腺素受體拮抗劑，在良性前列腺增生的下尿路症狀處置上有其角色。

然而，α1A 受體阻斷與安布拉斯症候群之間並沒有明確的生物學關聯。安布拉斯症候群是先天性毛髮生長異常的疾病，已報告的病因包括影響 TRPS1 調控的染色體重排。這個預測分數來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，而非生物學證據。

此外，排名前六的預測（多毛症、牙及牙周畸形症候群、Dandy-Walker 畸形症候群、遺傳性毛幹異常、家族性睫毛過長症）多屬先天性或遺傳性疾病，與 Silodosin 的藥理作用缺乏可信的連結。因此，本預測應視為假說產生，而非可行動的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測分數，沒有臨床試驗或文獻直接研究此疾病，證據等級為 L5。
- 缺乏機轉依據，α1A 阻斷與先天性毛髮生長異常之間沒有合理的生物學連結。

**若要推進需要：**
- 補充 Silodosin 的作用機轉資料與香港仿單的警語、禁忌與適應症內容
- 進行機轉層面的文獻回顧，確認 α1A 腎上腺素訊號是否參與毛囊週期
- 若有機轉支持，先進行前臨床研究（如毛囊細胞或動物模型）驗證
- 評估此疾病的治療目標（減少毛髮生長）與藥物可能作用方向是否一致
