# Siltuximab：從特發性多中心卡斯爾曼氏病 (iMCD) 到 TAFRO 症候群

## 一句話總結

Siltuximab 是抗 IL-6 單株抗體，原本核准用於治療 HIV/HHV-8 陰性的**特發性多中心卡斯爾曼氏病 (iMCD)**（此背景資訊來自本評估所附文獻，如 PMID 25601959「FDA approval: siltuximab for the treatment of patients with multicentric Castleman disease」）。
本次評估共產生 **10 個候選適應症**，其中證據最充分的是 **TAFRO 症候群**——TAFRO 被視為 iMCD 的臨床變異型，目前有 **20 篇文獻**支持（含直接以 siltuximab 治療 TAFRO 的病例報告），但**目前無專門針對 TAFRO 的臨床試驗登記**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（MOA: Data Gap）。但根據本評估附帶的文獻證據，siltuximab 是抗人類 IL-6 之嵌合單株抗體，其原始核准適應症 iMCD 的病理機轉主要由 IL-6 過度分泌所驅動。

TAFRO 症候群（Thrombocytopenia, Anasarca, Fever, Reticulin fibrosis, Organomegaly）在多篇文獻中被描述為 iMCD 的一種臨床變異型或重疊症候群，兩者共享 IL-6 驅動的發炎病理生理機轉。因此這並非典型的「跨疾病領域老藥新用」，而更接近**同一機轉路徑下的適應症光譜延伸**——這也是本候選在 10 個預測中證據等級最高（L2）、且已有真實世界病例報告直接使用 siltuximab 治療 TAFRO 的原因。

## 結論與下一步

**決策：Proceed with Guardrails**（僅適用於 TAFRO 症候群此一候選；其餘 9 項候選維持 Hold）

**理由：**
- TAFRO 症候群與原始核准適應症 iMCD 機轉高度重疊，已有多篇病例報告直接支持 siltuximab 於 TAFRO 之使用，證據等級達 L2。
- 但香港未上市、無許可證資料，且 MOA 與仿單警語資料均缺，限制了完整的安全性評估。

**若要推進需要：**
- 補齊 MOA 資料（DrugBank API 查詢，DG002）
- 取得 TFDA/原廠仿單警語與禁忌症資料——此為 **Blocking** 等級缺口，無法進入 S1 安全性初評（DG001）
- 評估香港特殊藥品進口/恩慈療法申請管道（目前未上市）
- 針對 TAFRO 適應症設計前瞻性研究或擴大病例登錄，強化 L2 → L1 證據等級
