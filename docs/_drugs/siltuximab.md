# Siltuximab：從多中心型 Castleman 氏病到腹外肥大細胞瘤

## 一句話總結

Siltuximab 是抗介白素-6（IL-6）的單株抗體，文獻顯示它已獲核准用於特發性多中心型 Castleman 氏病（iMCD）。
TxGNN 模型預測它可能對**腹外肥大細胞瘤 (Extracutaneous Mastocytoma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Siltuximab 是中和 IL-6 的單株抗體，在 IL-6 驅動的 iMCD 中的療效已有隨機分派試驗證實（PMID 25042199）。

肥大細胞的生物學研究曾提到 IL-6 的角色，這是兩者唯一可推測的關聯。但肥大細胞增生性疾病主要由 KIT 訊號驅動，IL-6 的參與目前只是推測。

因此，0.996 的高分只是知識圖譜的預測結果，沒有臨床或前臨床資料支持，目前不能視為有效的證據。

## 結論與下一步

**決策：Hold**

**理由：**
這個適應症沒有任何臨床試驗或文獻，證據等級為 L5，只有模型預測。IL-6 與肥大細胞疾病的機轉連結也只是推測，不足以推進。

**若要推進需要：**
- 肥大細胞腫瘤中 IL-6 訊號角色的機轉或前臨床研究
- 取得香港衛生署仿單，補齊警語與禁忌症
- 取得 DrugBank 的作用機轉資料
- 另外，同一份預測清單中的 **TAFRO 症候群**（排名第 10）證據明顯較強：已有病例報告、治療指引，且屬於 IL-6 驅動的 iMCD 亞型。若要優先評估，建議改以該適應症另行產生報告。
