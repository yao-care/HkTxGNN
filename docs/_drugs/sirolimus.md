## Sirolimus：從腎細胞癌與淋巴管平滑肌瘤病到脂肪肉瘤
{: .text-alpha }

## 一句話總結

Sirolimus（西羅莫司）是 mTOR 抑制劑，在香港以 Rapamune 之名上市。知識圖譜記錄它與腎細胞癌、淋巴管平滑肌瘤病有關聯。
TxGNN 模型預測它可能對**脂肪肉瘤 (Liposarcoma)** 有效，但目前只有 **1 個臨床試驗**（單臂 Phase 2，且併用其他藥物）和 **7 篇文獻**。文獻多為綜述或間接研究，證據仍很薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Sirolimus 抑制 mTORC1，而軟組織肉瘤（含脂肪肉瘤）有 mTOR 路徑活化的報告。因此在機轉上，抑制 mTOR 可能減緩腫瘤生長。

脂肪肉瘤的高分來自 TxGNN 模型（深度學習），可能反映模型從相關疾病之間學到的相似性，並非生物學證據。

目前唯一直接相關的人體研究是 NCT02821507。它是單臂 Phase 2 試驗，把 Sirolimus 與環磷醯胺併用，對象為黏液樣脂肪肉瘤與軟骨肉瘤。本報告取得的資料沒有療效結果，也沒有對照組，無法分離出 Sirolimus 單獨的貢獻。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一直接相關的試驗是單臂、併用化療、未提供結果的 Phase 2，沒有 RCT，也沒有 Sirolimus 單藥對脂肪肉瘤的療效證據。
- 文獻多為綜述或移植族群的間接研究，所以證據等級為 L4。
- 模型分數高且 mTOR 機轉合理，值得持續追蹤，但目前尚不足以推進臨床應用。

**若要推進需要：**
- 取得 NCT02821507 的結果，並釐清 Sirolimus 的單獨貢獻。
- 確認脂肪肉瘤各亞型的 mTOR 路徑活化證據。
- 補充詳細的作用機轉資料。
- 取得香港原廠仿單的核准適應症、警語與禁忌。
- 規劃評估 Sirolimus 單藥或對照設計的臨床研究，並制定感染、血脂、血糖、肺毒性與藥物交互作用的監測計畫。
