# Sodium carbonate：從（原適應症未登載）到馬尾症候群

## 一句話總結

Sodium carbonate（碳酸鈉）是一種鹼化劑，在香港以 Eno 檸檬味水果鹽的成分上市，但許可證未登載適應症。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個預測，只有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Sodium carbonate 是鹼化劑，香港上市產品為 Eno 水果鹽，但許可證沒有登載核准適應症，因此無法比對原適應症與新適應症的關聯。

馬尾症候群是壓迫性的神經外科急症，由脊髓末端的神經根受壓引起。Sodium carbonate 的藥理作用與這類壓迫損傷沒有已知連結，所以我們**找不到合理的機轉**。

TxGNN 分數很高（99.80%，排名 4596），但沒有已知藥理可以驗證，這個分數很可能只是知識圖譜中的關聯雜訊，不宜直接當作療效線索。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測（L5），沒有臨床試驗、文獻或可辨識的機轉。
- 馬尾症候群是需要緊急手術減壓的疾病，不適合以缺乏證據的候選藥物作為研究方向。

**若要推進需要：**
- 補齊 Sodium carbonate 的作用機轉資料（可查詢 DrugBank）。
- 取得香港衛生署的仿單，確認警語與禁忌症。
- 建議把研究重心移到同一藥物的其他預測。**修格連氏症候群 (Sjögren syndrome)** 目前達 L4、決策為「Research Question」，有 1 篇碳酸鈉（含碳酸氫鈉）口腔噴劑搭配口腔衛生處置的探索性研究（PMID 27813150，Gerodontology，2017），但只能緩解口乾症狀，不能改變自體免疫疾病本身，需先全文審閱該研究的設計與族群。
- 預測清單中的「obsolete neurogenic bladder」與「obsolete bundle branch block」是已過時的疾病詞條，應先重新對應到現行概念再評估。
