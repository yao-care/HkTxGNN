# Sodium Citrate：從原適應症（資料未載明）到乳突狀結膜炎

## 一句話總結

Sodium Citrate（檸檬酸鈉）在香港有 20 張有效許可證，但現有資料沒有載明原核准適應症。
TxGNN 模型預測它可能對**乳突狀結膜炎 (Papillary Conjunctivitis)** 有效。
目前**沒有任何臨床試驗或文獻**直接支持這個預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，原適應症也沒有記錄，因此無法建立 Sodium Citrate 與乳突狀結膜炎之間的機轉連結。

從香港許可證的品名來看，Sodium Citrate 出現在血液濾過溶液（REGIOCIT）、檸檬酸鈉溶液以及複方咳嗽或祛痰製劑中。這代表它有多種用途，但這些資料不足以推論它對眼科疾病有效。

這個預測目前只有 TxGNN 的高分（排名第 1559 位）支持。在釐清作用機轉、原適應症與眼用劑型的可行性之前，它只是一個待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測只有模型分數支持，沒有臨床試驗、文獻或機轉資料，證據等級為 L5。
- 原適應症、作用機轉與香港仿單的警語和禁忌症資料都缺漏，無法進入安全性初篩。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語、禁忌症與核准適應症。
- 從 DrugBank 補充作用機轉，再評估它與乳突狀結膜炎的機轉關聯。
- 確認是否有適合眼部使用的劑型或給藥途徑，目前香港許可證資料中沒有相關記錄。
- 檢索 Sodium Citrate 用於結膜或眼表疾病的直接研究。

**其他預測適應症的參考：**
- 「鼻腔疾病」有 7 筆試驗，但評估後都與 Sodium Citrate 無關，僅為頭頸癌或鼻竇炎的關鍵字比對，仍為 L5。
- 「胃部疾病」目前僅有體外研究，其中 3-bromopyruvate 加檸檬酸鈉的組合在胃癌細胞株中抑制糖解並誘導凋亡，屬前臨床（L4），並未顯示對一般胃部疾病有效。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。*
