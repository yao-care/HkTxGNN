# Sodium Fluoride：從（原適應症未載明）到會厭炎

## 一句話總結

Sodium Fluoride（氟化鈉）在香港是微量元素輸液濃縮液的成分之一，但資料中沒有記載原適應症。
TxGNN 模型預測它可能對**會厭炎 (Epiglottitis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，氟化鈉是微量元素輸液濃縮液的成分之一，用於補充微量元素，但原適應症資料未載明，無法判斷其在原適應症中的機轉是否可延伸到會厭炎。

體外研究顯示，氟離子可抑制細菌的烯醇酶（enolase）與糖解作用，主要見於口腔菌叢。但這並未證實與會厭炎相關。會厭炎常見致病菌為 B 型流感嗜血桿菌（H. influenzae type b）或鏈球菌，氟化物對這些菌的臨床抗菌效果沒有資料。

因此，0.999 的高分只是模型預測，目前沒有可驗證的機轉連結。

其他預測（皆為 L5、Hold、無試驗與文獻）：

| 排名 | 預測適應症 | TxGNN 分數 |
|------|-----------|-----------|
| 2 | 泌尿道感染 | 99.91% |
| 3 | 解脲脲漿菌尿道炎 (Ureaplasma urethritis) | 99.90% |
| 4 | 淋菌性尿道炎 (Gonococcal urethritis) | 99.90% |
| 5 | 子宮發炎性疾病 | 99.85% |

排名 3 和 4 的分數完全相同，可能是知識圖譜鄰近節點造成的現象，而非疾病特異性訊號。氟化物在可耐受的全身濃度下抗菌活性弱，且全身暴露受氟中毒（骨骼與牙齒氟斑症）限制。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測皆只有模型分數，沒有臨床試驗、文獻或可驗證的機轉支持（L5）。
- 氟化物全身暴露有毒性限制，且缺乏安全性資料（仿單警語與禁忌症），無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症
- 補充 DrugBank 的作用機轉（MOA）資料
- 確認原適應症與各劑型資訊
- 針對會厭炎等預測適應症，進行體外抗菌活性（如對 B 型流感嗜血桿菌）與文獻檢索，確認是否有任何前臨床證據
