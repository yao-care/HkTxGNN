## Sodium Sulfate：從（原適應症未記載）到消化不良
{: .text-alpha }

## 一句話總結

Sodium Sulfate（硫酸鈉）是一種滲透性鹽類瀉劑，在香港以腸道準備用口服溶液粉劑的形式上市，但目前許可證資料中未記載明確的核准適應症。
TxGNN 模型預測它可能對**消化不良 (Dyspepsia)** 有效，但目前**沒有臨床試驗**，檢索到的 **3 篇文獻**皆為動物或前臨床研究，且與本藥的治療用途無直接關聯，因此證據僅停留在模型預測層級。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，也沒有記錄原適應症。根據已知資訊，硫酸鈉是滲透性鹽類瀉劑，常見於腸道準備用的複方口服溶液（例如含聚乙二醇與電解質的產品）。其作用方式是增加腸腔內滲透壓，促進水分滯留與腸道排空。

若要連結到消化不良，只能推測為間接作用，例如影響腸道動力或腸腔滲透壓。這個推論並無實證支持。TxGNN 的高分（99.09%）來自知識圖譜的網路關聯，並不代表已有機轉或臨床上的確認。

需要特別注意：檢索到的 3 篇文獻談的是**葡聚糖硫酸鈉 (Dextran Sodium Sulfate, DSS)**，這是用來在動物身上誘發大腸炎的化學物質，與硫酸鈉是不同的化合物，也不是治療藥物。這些文獻不能視為支持本預測的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自網路模型（L5），無任何臨床試驗，且檢索到的文獻皆涉及 DSS 而非硫酸鈉，不構成有效證據。
- 缺乏作用機轉與原適應症資料，且藥物本身是腸道準備用瀉劑，用於消化不良的合理性與安全性（例如電解質紊亂、腸阻塞風險）都尚未釐清。

**若要推進需要：**
- 補充香港許可證的核准適應症與仿單警語、禁忌資料
- 取得 DrugBank 的作用機轉資料
- 重新檢索針對硫酸鈉（非 DSS）與消化不良的文獻與臨床試驗
- 釐清瀉劑劑量與消化不良治療情境是否相容，並評估電解質與腸道安全性風險
