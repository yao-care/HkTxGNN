# Sodium tetradecyl sulfate：從靜脈曲張到食道靜脈曲張

## 一句話總結

Sodium tetradecyl sulfate（STS）是一種清潔劑型硬化劑，原本用於靜脈曲張治療。
TxGNN 模型預測它可能對**食道靜脈曲張（Esophageal varices，未出血型）**有效，
目前**無登記臨床試驗**，但有 **20 篇文獻**支持這個方向（其中 1 篇為 1990 年的隨機對照試驗）。

## 快速總覽

| 項目 | 內容 |
|------|------|
| 原適應症 | 靜脈曲張（varicose disease） |
| 預測新適應症 | 食道靜脈曲張，未出血型（Esophageal varices without bleeding） |
| TxGNN 預測分數 | 99.97% |
| 證據等級 | L2 |
| 香港上市 | ✓ 已上市 |
| 許可證數 | 4 張 |
| 建議決策 | Proceed with Guardrails |

> 備註：同一藥物對「出血型食道靜脈曲張」的預測分數相同（99.97%），證據等級同為 L2。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，STS 是一種清潔劑型硬化劑，會破壞靜脈內皮，引發血栓形成與血管纖維化，使血管閉塞。

這個機轉在下肢靜脈曲張中用於閉塞曲張的靜脈。食道靜脈曲張同樣是異常擴張的靜脈，可經內視鏡注射硬化治療，因此機轉上可以類推適用。文獻中也有以 STS 進行內視鏡硬化治療、經皮肝穿刺栓塞，以及氣球閉塞逆行經靜脈閉塞術（BRTO，用於胃靜脈曲張）的報告。

但須注意：對未出血的食道靜脈曲張做預防性硬化治療，現今已大多被 β 受體阻斷劑與內視鏡套扎術取代。硬化治療本身也有食道穿孔、狹窄等風險。因此這個方向較適合視為「研究問題」，而非即將推廣的新用途。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（非仿單內容，僅供參考）：血栓性靜脈炎、遊走性血栓性靜脈炎、甲狀腺毒症／甲狀腺機能亢進、葛瑞夫茲氏病、動脈硬化／粥狀動脈硬化、血栓閉塞性脈管炎、靜脈功能不全、血液疾病、感染性疾病、腫瘤／癌症。
- **文獻揭示的程序風險**：食道穿孔（約 2.9%）與食道狹窄（約 15.5%）。

其他警語、禁忌症與藥物交互作用，請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- STS 的硬化機轉與靜脈曲張治療一致，且有 1 個隨機對照試驗與多項觀察性研究支持其用於食道靜脈曲張。
- 但該 RCT 為 1990 年的藥劑間比較，無登記臨床試驗；現行標準治療以套扎術與血管活性藥物為主，且有穿孔、狹窄風險，因此證據停留在 L2，宜視為研究問題。

**若要推進需要：**
- 取得香港仿單，確認核准適應症、警語與禁忌症
- 取得作用機轉資料
- 與現行標準治療（套扎術、β 受體阻斷劑）進行比較的現代研究設計
- 明確的適用族群（如套扎失敗或胃靜脈曲張 BRTO 場景）與併發症監測計畫
- 確認香港核准的給藥途徑是否涵蓋內視鏡或血管內使用

**其他預測適應症：** 排名 3–10 的預測（如 Steel syndrome、pseudo-von Willebrand disease 等）皆無臨床試驗與文獻，也無合理機轉連結，僅有模型分數，證據等級 L5，建議 **Hold**。
