# Sodium zirconium cyclosilicate：從高血鉀症到乳房纖維囊腫病

## 一句話總結

Sodium zirconium cyclosilicate 是一種不被人體吸收的腸道鉀離子結合劑，在香港以 LOKELMA 品名上市。
TxGNN 模型預測它可能對**乳房纖維囊腫病 (breast fibrocystic disease)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sodium zirconium cyclosilicate 是一種不被吸收的無機陽離子交換劑，在腸道內選擇性捕捉鉀離子（以及部分銨離子）。

目前找不到這種作用與乳房組織病變之間的已知關聯。藥物幾乎不進入全身循環，因此不太可能影響乳房組織。TxGNN 的高分（93.41%）僅來自知識圖譜的鄰近關係，並無試驗或文獻佐證。

排名前 8 的預測（乳房纖維囊腫病、良性乳腺發育不良、鈍性乳腺管腺病、乳房大汗腺腺病、乳房脂肪壞死、乳房膿瘍、泌乳疾病、乳房腺病）全都集中在良性乳房疾病群。這較可能反映圖譜結構上的相似，而不是真正的藥理作用。排名第 9、10 的肝素輔因子 2 缺乏症、第 2 型抗凝血酶缺乏症同樣沒有機轉依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數，沒有臨床試驗、文獻或合理的作用機轉支持，證據等級為 L5。
- 藥物不被吸收，與乳房疾病之間缺乏生物學關聯，目前不建議投入資源。

**若要推進需要：**
- 補齊作用機轉資料，並說明這種腸道作用如何可能影響乳房組織。
- 取得香港仿單中的警語、禁忌症與核准適應症，完成基本安全性評估。
- 取得任何支持性的前臨床或臨床資料。若無，建議轉向評估排名較後、機轉上更合理的候選適應症。
