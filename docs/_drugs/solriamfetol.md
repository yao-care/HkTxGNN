## Solriamfetol：從猝睡症到注意力不足過動症 (ADHD)
{: .text-alpha }

## 一句話總結

Solriamfetol 是一種促醒藥物，知識圖譜中記錄的相關用途包括猝睡症與阻塞性睡眠呼吸中止症候群。
TxGNN 模型預測它可能對**注意力不足過動症 (ADHD)** 有效，
目前有 **5 個臨床試驗**和 **6 篇文獻**與此方向相關，其中包含 1 個已完成的成人 Phase 3 隨機對照試驗。

**證據等級說明：** 已有 1 個已完成的成人 Phase 3 隨機對照試驗（NCT05972044）和 1 個已完成的 Phase 2/3 先導試驗（NCT04839562），直接研究 ADHD。但 Phase 3 試驗結果在本次彙整資料中尚未呈現，且只有 1 個已完成的 Phase 3，未達 L1 所需的 2 個，因此判定為 L2。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉登錄資料。根據已知資訊，solriamfetol 是多巴胺與正腎上腺素再攝取抑制劑 (DNRI)。增強前額葉的兒茶酚胺訊號，正是 ADHD 常用藥物（如 methylphenidate、atomoxetine）的藥理基礎。

猝睡症等嗜睡疾患與 ADHD 都涉及注意力與覺醒調節，且都與多巴胺、正腎上腺素系統有關。因此 DNRI 機轉在 ADHD 上具備合理性，目前的臨床開發計畫也與此一致。

需注意，ADHD 的療效尚待確認，且與其他刺激性藥物類似，需關注血壓、心跳、精神方面不良事件與濫用風險。兒童與青少年的安全性仍在評估中。

## 安全性考量

- **藥物交互作用**：已查詢到 35 筆交互作用紀錄，以下為部分重點：
  - **重大 (Major)**：Methylene blue
  - **中度 (Moderate)**：擬交感神經藥物與支氣管擴張劑，包括 epinephrine、ephedrine、pseudoephedrine、phenylephrine、isometheptene、mazindol、salbutamol、formoterol、olodaterol、vilanterol、isoprenaline 等
- **預測依據中提及的注意事項**：需監測血壓與心跳、精神方面不良事件與濫用或誤用風險；兒童與青少年的安全性仍在評估中。

警語與禁忌症資料請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有 1 個已完成的成人 Phase 3 隨機對照試驗與 1 個已完成的 Phase 2/3 先導試驗直接針對 ADHD，另有 3 個兒童與青少年 Phase 3 試驗進行中，開發方向明確。
- 但 Phase 3 結果尚待核對，且安全性（心血管、精神、濫用風險）需設置防護措施。

**若要推進需要：**
- 取得並核對 NCT05972044 的主要療效結果，以及 NCT04839562 的完整數據
- 取得香港仿單的警語與禁忌症資料，完成安全性篩選
- 補充詳細的作用機轉資料
- 制定血壓、心跳、精神症狀與濫用風險的監測計畫
- 追蹤兒童與青少年試驗（NCT07717892、NCT07717879、NCT07773883）的進展
