# Solriamfetol：從猝睡症到注意力不足過動症 (ADHD)

## 一句話總結

Solriamfetol 是一種促醒藥物，原本用於猝睡症、阻塞性睡眠呼吸中止症等相關的日間過度嗜睡。
TxGNN 模型預測它可能對**注意力不足過動症 (Attention Deficit-Hyperactivity Disorder)** 有效，
目前有 **5 個臨床試驗**和 **6 篇文獻**支持這個方向，其中包含 1 個已完成的成人 Phase 3 試驗。

## 為什麼這個預測合理？

目前缺乏經核實的詳細作用機轉資料。根據一般藥理知識（需對照原始文獻確認），Solriamfetol 是多巴胺與正腎上腺素再回收抑制劑 (DNRI)。

多巴胺與正腎上腺素調節，正是 methylphenidate、atomoxetine 等既有 ADHD 療法的核心機轉。因此 Solriamfetol 在藥理上可能改善注意力不足與過動、衝動症狀。此外，ADHD 患者常合併睡眠與清醒度問題，促醒作用也可能有額外幫助。

需要注意，這項機轉推論尚未經原始資料驗證。實際療效應以臨床試驗結果為準。

## 安全性考量

- **藥物交互作用**：共查得 35 筆交互作用，以下僅列出部分。
  - 重度 (Major)：Methylene blue
  - 中度 (Moderate)：多為擬交感神經類藥物，例如 Epinephrine、Ephedrine、Pseudoephedrine、Phenylephrine、Isometheptene、Mazindol，以及 β 促效劑（Salbutamol、Formoterol 等）
- 這些藥物與 Solriamfetol 併用時，需留意血壓與心跳等心血管影響。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 成人 ADHD 已有 1 個完成的 Phase 3 試驗（n=516）和 1 個完成的 Phase 2/3 先導試驗，另有 3 個兒童與青少年 Phase 3 試驗正在進行，發展方向明確。
- 但目前缺乏已核實的作用機轉與仿單安全性資料，Phase 3 結果也尚待確認，因此需設置防護條件。

**若要推進需要：**
- 取得並審閱 NCT05972044 的完整療效與安全性結果
- 從 DrugBank 等來源核實作用機轉
- 取得香港衛生署仿單的警語與禁忌症
- 建立心血管（血壓、心跳）與擬交感神經藥物併用的監測計畫
- 追蹤兒童與青少年試驗進展及長期安全性

**其他預測適應症備註：**
- 失眠 (Insomnia) 的機轉與促醒作用相悖，目前僅適合作為研究問題，須優先評估對睡眠連續性的影響。
- ADHD 注意力不足型為 ADHD 的亞型，證據為間接推論，無專屬試驗。
- 顏指生殖器症候群 (Aarskog-Scott 症候群) 與軟骨黏液樣纖維瘤沒有可辨識的機轉關聯，也無試驗或文獻，建議 Hold。
