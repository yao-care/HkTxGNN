# Sorbitol：從滲透性瀉劑到運動誘發型惡性高熱

## 一句話總結

Sorbitol（DB01638）目前在香港未取得藥品許可證上市，已知臨床用途為滲透性瀉劑、藥物賦形劑/稀釋劑及灌洗液成分。
TxGNN 模型預測它可能對**運動誘發型惡性高熱 (Exercise-induced Malignant Hyperthermia)** 有效，
但目前**無任何臨床試驗或文獻**支持，屬於純模型推論階段。

## 為什麼這個預測合理？

目前缺乏 Sorbitol 詳細的作用機轉資料。根據已知資訊，Sorbitol 是一種糖醇類滲透性物質，臨床上主要作為滲透性瀉劑、藥物賦形劑/稀釋劑及灌洗液成分使用，其作用機轉為滲透壓調節，並不涉及骨骼肌鈣離子代謝路徑。

惡性高熱（尤其是運動誘發型）的病理機轉核心在於骨骼肌 ryanodine receptor（RYR1）異常導致鈣離子大量釋放，標準治療藥物 Dantrolene 正是針對此受體發揮作用。目前沒有任何資料顯示 Sorbitol 對 RYR1 或相關鈣離子調節路徑有直接或間接的藥理作用。

TxGNN 給出的高分（0.994）較可能反映知識圖譜中節點間的間接連結（例如與其他賦形劑、代謝路徑節點共同出現的模式），而非真實存在的藥理機制。加上原始 MOA 資料缺失、原適應症清單為空、藥物本身未於香港上市，多重因素使這項預測的可信度偏低，目前僅適合列為需要進一步機轉研究驗證的假說，不建議直接推進。

## 結論與下一步

**決策：Hold**

**理由：**
此預測缺乏任何臨床試驗或文獻支持（L5，僅有模型分數），且藥理機轉上找不到 Sorbitol 與惡性高熱病理路徑（RYR1／鈣離子代謝）的合理連結，藥物本身也尚未在香港上市，現階段不具備推進條件。

**若要推進需要：**
- 補齊 Sorbitol 的完整作用機轉（MOA）資料，釐清是否存在未被記錄的骨骼肌相關藥理作用
- 取得 TFDA／香港衛生署仿單警語與禁忌症資料，完成基本安全性初評（S1）
- 尋找是否有動物實驗或個案報告可佐證此關聯性，若持續無任何支持證據，建議直接排除此候選
