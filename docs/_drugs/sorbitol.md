# Sorbitol：從輸液成分到運動誘發惡性高熱

## 一句話總結

Sorbitol（山梨醇）是一種糖醇，常作為滲透性藥劑、甜味劑與賦形劑，在香港有多張輸液類產品的許可證，但許可證上未登載原適應症。
TxGNN 模型預測它可能對**運動誘發惡性高熱 (Exercise-induced Malignant Hyperthermia)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Sorbitol 是滲透性藥劑與賦形劑，已知用於輸液類產品，但這些資料不足以建立與新適應症的機轉連結。

惡性高熱（包含運動誘發型）主要由骨骼肌鈣離子釋放失調引起，常與 RYR1 基因變異有關，治療以 dantrolene 與支持性降溫為主。Sorbitol 對 ryanodine 受體訊號、鈣離子調控或體溫調節都沒有已知作用，因此**目前找不到已確立的機轉關聯**。

0.994 的高分只是模型預測。可能原因是知識圖譜中的鄰近關係，例如與多元醇或滲透性藥劑相近，或與 dantrolene 類製劑的賦形劑同時出現。這些推測都未經驗證。此外，原適應症與作用機轉資料缺漏，也削弱了以圖譜推論的可信度。即使預測有生物學意義，面對需要快速、標靶介入的急性致命疾病，Sorbitol 也不是合適的候選藥物。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，只有模型預測，沒有任何臨床試驗或文獻。
- 找不到合理的機轉關聯，且目標疾病是急性致命疾病，有既定的標靶治療。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症，這是目前阻擋安全性初篩的缺口。
- 補齊 Sorbitol 的作用機轉資料（可查詢 DrugBank）。
- 釐清高分的來源，例如是否來自賦形劑共現，並確認是否有生物學意義。
- 檢索是否有任何支持 Sorbitol 與惡性高熱關聯的前臨床或機轉研究。若仍找不到，建議不再投入資源。
