# Sotalol：從心律不整到體染色體顯性竇房結症候群 2 型

## 一句話總結

Sotalol 是兼具 β 受體阻斷與第三類鉀離子通道阻斷作用的抗心律不整藥物。
TxGNN 模型預測它可能對**體染色體顯性竇房結症候群 2 型 (Sick Sinus Syndrome 2, Autosomal Dominant)** 有效，但**目前沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sotalol 同時具備 β 受體阻斷與第三類鉀離子通道阻斷作用，會減慢竇性心率與房室傳導。

從藥理上看，這個預測**不合理**。竇房結功能異常和心搏過緩，本來就是 Sotalol 已知的安全性顧慮，用它來治療竇房結症候群方向相反。模型給出高分，較可能是因為知識圖譜中，它與心律不整及離子通道基因（如 HCN4、SCN5A）距離相近，而不是真的有治療效果。

因此這項預測應視為**安全性訊號**，而非老藥新用的機會。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數，沒有試驗或文獻佐證，證據等級為 L5。
- 藥理作用與疾病方向相反，不建議推進作為治療用途。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語與禁忌症
- 補齊 Sotalol 的作用機轉資料（DrugBank）
- 若仍想探討，先做竇房結功能障礙的安全性文獻回顧，而非療效試驗

**補充：** 同一份分析中，「中風 (stroke disorder)」的證據較多。它是房顫抗心律不整藥物族群中的間接關聯，目前為 L4、Research Question 階段。所有檢索到的試驗都不是以 Sotalol 預防或治療中風為主題，建議另案以房顫族群的中風結果為題做文獻回顧。
