# Spectinomycin：從淋病到子宮闊韌帶疾病

## 一句話總結

Spectinomycin 是一種氨基環醇類抗生素，原本用於治療淋病與急性淋球菌性子宮頸炎。
TxGNN 模型預測它可能對**子宮闊韌帶疾病 (disease of uterine broad ligament)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原廠 MOA 欄位無資料）。就一般藥理知識，Spectinomycin 是氨基環醇類抗生素，透過結合細菌 30S 核糖體次單位，抑制細菌蛋白質合成，核准用途是針對淋病奈瑟菌（包括淋球菌性子宮頸炎）。

原適應症與新適應症之間，只存在間接關聯：若闊韌帶疾病屬感染性（例如合併淋球菌感染的骨盆腔炎），抗生素才可能有作用。若是非感染性疾病（如囊腫、腫瘤、子宮內膜異位），抗菌機轉並無相關性。

TxGNN 分數雖高（0.996），但這是模型預測，沒有試驗或文獻佐證，可能反映知識圖譜中生殖道相關疾病的鄰近關係，而非真實療效。

其他排名前列的預測（腹腔異位妊娠、腹腔動脈壓迫症候群、腹腔囊性淋巴管瘤、淋巴結柵欄狀肌纖維母細胞瘤）同樣缺乏合理的抗菌機轉，也無任何臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（證據等級 L5），沒有任何臨床試驗或文獻，且抗菌機轉與多數闊韌帶疾病缺乏合理關聯。
- 缺少仿單的警語與禁忌資料，尚無法進行安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症
- 補充 DrugBank 作用機轉資料
- 釐清「闊韌帶疾病」的具體類型，判斷是否為感染性
- 進行系統性文獻與臨床試驗檢索，確認是否有任何支持證據
- 確認人用劑型與給藥途徑的可行性（目前許可證含獸用產品）
