# Stannous Fluoride：從原適應症未載明到腦膜炎球菌感染

## 一句話總結

Stannous Fluoride（氟化亞錫）在資料庫中沒有記載原適應症，常見用途是牙科外用的抗菌與抗牙菌斑。
TxGNN 模型預測它可能對**腦膜炎球菌感染 (Meningococcal Infection)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，資料庫也沒有記載原適應症，因此無法拿預測結果對照已知藥理。

Stannous Fluoride 是牙科外用藥劑，具抗菌與抗牙菌斑活性。全身暴露量極低，要直接作用於侵襲性腦膜炎雙球菌 (*Neisseria meningitidis*) 疾病（腦膜炎、敗血症），在生物學上不太可能。

勉強能提出的假說，是它對口咽部帶菌狀態有局部抗菌作用，但這一點從未被驗證。99.66% 的高分較可能來自知識圖譜的拓撲關聯，而不是經驗證的機轉。因此這個預測目前缺乏可信的支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅有模型預測（L5），沒有臨床試驗、文獻或機轉資料支持。
- 外用牙科藥劑全身暴露量極低，用於侵襲性腦膜炎球菌感染在生物學上不合理，不建議推進。

**若要推進需要：**
- 補齊作用機轉資料（例如查詢 DrugBank），確認是否有可連結到腦膜炎球菌的抗菌機轉。
- 取得香港衛生署的仿單，補足警語與禁忌症，才能進行安全性篩選。
- 釐清香港許可證中 Stannous Fluoride 的實際角色與原適應症。
- 進行體外抗 *Neisseria meningitidis* 活性或口咽帶菌的前臨床研究，作為最低限度的機轉驗證。

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
