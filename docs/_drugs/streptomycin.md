# Streptomycin：從結核病等細菌感染到結膜炎

## 一句話總結

Streptomycin 是史上第一個被發現的胺基糖苷類抗生素，傳統用於結核病、鼠疫、兔熱病、布氏桿菌病等細菌感染的治療。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效，
目前**無相關臨床試驗登記**，但有 **21 篇文獻**支持這個方向，多為 1940-1950 年代的病例報告與田野試驗。

## 為什麼這個預測合理？

Evidence Pack 中缺乏 DrugBank 的完整作用機轉描述，但根據預測模型附帶的機轉推論：Streptomycin 屬於胺基糖苷類抗生素，透過抑制細菌 30S 核糖體次單元的蛋白質合成而發揮殺菌作用。理論上這個機轉對造成細菌性結膜炎的病原菌（包括結核桿菌、兔熱病病原體 *Francisella tularensis* 等）具有抗菌活性。

文獻中也確實記載了 Streptomycin 用於眼科局部治療的歷史案例，例如摩洛哥地區以 streptomycin 眼藥水預防季節性結膜炎（沙眼相關）、原發性結核性結膜炎的局部與全身合併治療等，顯示這類用法並非全無先例。

然而，這些證據集中在 1940-1950 年代，當時眼科用藥尚無現代標準，而 Streptomycin 全身注射與局部眼用製劑在吸收與滲透特性上與現行眼藥（如 Tobramycin）並不相同。目前缺乏近代、設計嚴謹的臨床試驗來驗證此適應症，機轉上的合理性尚未轉化為臨床實證。

## 結論與下一步

**決策：Hold**

**理由：**
現有證據幾乎全部來自 1940-1950 年代的病例報告與田野試驗，缺乏現代設計嚴謹的臨床研究；且無臨床試驗登記可供追蹤。此外，作用機轉（MOA）與仿單警語/禁忌症資料皆為缺失（Blocking gap），尚無法進入安全性初評階段。

**若要推進需要：**
- 補齊仿單警語與禁忌症資料（Blocking gap，來源：藥監局仿單）
- 補齊完整作用機轉（MOA）資料（來源：DrugBank）
- 現代眼科局部劑型之藥動/藥效資料，釐清與全身注射用途的差異
- 針對細菌性結膜炎設計之前瞻性臨床研究，驗證歷史證據在現代情境下的適用性
