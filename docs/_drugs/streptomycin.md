## Streptomycin：從結核病等細菌感染到結膜炎
{: .text-alpha }

## 一句話總結

Streptomycin（鏈黴素）是一種胺基糖苷類抗生素，知識圖譜中記錄的用途包括肺結核、鼠疫、兔熱病、布氏桿菌病等細菌感染。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效，但目前**沒有臨床試驗**，僅有數篇間接相關的文獻（多為個案報告、舊文獻或感受性研究），沒有直接研究其治療結膜炎療效的證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Streptomycin 屬於殺菌性胺基糖苷類抗生素，一般認為其作用是抑制細菌 30S 核糖體次單位，進而阻斷蛋白質合成。

結膜炎若由細菌引起，理論上可能涵蓋 Streptomycin 具活性的病原體。例如，由土倫法蘭西斯菌（兔熱病）引起的眼腺型症候群（Parinaud 症候群），以及布氏桿菌角膜結膜炎，均有個案報告。不過，這種關聯是透過病原體譜間接建立的，所提供的文獻並不支持以局部眼用方式使用 Streptomycin。

需特別說明：所列文獻多數是個案報告、病原體感受性調查、動物研究或基礎研究，並未直接評估 Streptomycin 對結膜炎的療效，因此證據等級只能判定為 L5。

## 安全性考量

- **知識圖譜中記錄的禁忌關聯**（非仿單文字）：腎臟疾病、膿輸尿管、高鈣血症、腎鈣質沉著症、磷代謝疾病、中樞神經源性眩暈、重症肌無力（含成人型）、神經肌肉接合部疾病、帕金森氏症候群及帕金森氏症。
- **藥物交互作用**：共查得 100 筆，以下列出主要者。
  - 嚴重 (Major)：Botulinum toxin type A、人類免疫球蛋白 G（靜脈注射）、Bacitracin。
  - 中度 (Moderate)：Amikacin、Amphotericin B（含脂質複合物）、Neomycin（局部）、Ketorolac、Ibuprofen、Celecoxib、阿斯匹靈等，其中多為腎毒性或耳毒性疊加相關的組合。
  - 輕微 (Minor)：Lidocaine。
- 相關的 Streptomycin 耳毒性線索：本次資料中有一筆文獻描述 Streptomycin 引起的迷路炎，提示前庭與耳蝸毒性風險。

完整警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何直接研究 Streptomycin 治療結膜炎的臨床試驗或文獻，現有資料只是透過病原體譜的間接推論，證據等級為 L5。
- 局部眼用使用未獲文獻支持，且已有其他眼用抗生素可選；全身性使用則需考量腎毒性與耳毒性。

**若要推進需要：**
- 確認結膜炎的致病菌（如兔熱病、布氏桿菌、結核等特定病原）中，Streptomycin 具有明確療效的亞型。
- 取得作用機轉與香港許可證核准適應症文字。
- 取得原廠仿單的警語與禁忌資訊。
- 評估給藥途徑（全身性與局部）及其安全性，並與現有眼用抗生素進行比較。
