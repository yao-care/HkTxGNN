# Streptomycin：從結核病等細菌感染到結膜炎

## 一句話總結

Streptomycin（鏈黴素）是一種氨基糖苷類抗生素，原本用於肺結核、鼠疫、兔熱病、布氏桿菌病等細菌感染。
TxGNN 模型預測它可能對**結膜炎 (Conjunctivitis)** 有效，但目前**沒有臨床試驗**，僅有數篇間接相關的文獻（多為病例報告、綜述與微生物學研究），證據強度偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Streptomycin 屬於氨基糖苷類抗生素，對可引起結膜感染的細菌具抗菌活性，其在結核病、兔熱病與布氏桿菌病等感染中的療效已被證實。

結膜炎與原適應症的關聯是**間接的**：兔熱病與布氏桿菌病可表現為眼腺型症候群（Parinaud oculoglandular syndrome）或角結膜炎，Streptomycin 是治療其背後的全身性感染，結膜炎只是該感染的表現之一。

需要特別注意：目前沒有證據支持 Streptomycin 可作為一般結膜炎的治療。一般細菌性結膜炎通常使用局部眼用氨基糖苷類（如 tobramycin），而全身性使用 Streptomycin 因耳毒性與腎毒性，不適合用於常見的細菌性結膜炎。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有臨床試驗，文獻多為間接證據（兔熱病、布氏桿菌病、結核病的眼部表現），且 Streptomycin 的作用是治療背後的全身感染，並非治療結膜炎本身。
- 局部眼用氨基糖苷類已是常規選擇，而全身性 Streptomycin 有耳毒性與腎毒性風險，風險效益不佳。

**若要推進需要：**
- 釐清是否僅限於特定病原（如土拉弗朗西斯菌、布氏桿菌、結核分枝桿菌）所致的眼部感染，而非泛稱結膜炎。
- 取得香港仿單的警語、禁忌與核准適應症，以及詳細的作用機轉資料。
- 評估是否有局部眼用劑型的需求與可行性，以及相對於現有局部抗生素的優勢。
- 若有進一步探索價值，可先以系統性文獻回顧整理特定感染相關眼部表現的治療結果。
