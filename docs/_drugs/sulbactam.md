# Sulbactam：從細菌感染到細菌性關節炎

## 一句話總結

Sulbactam 是一種 β-內醯胺酶抑制劑，通常與 Ampicillin 併用於治療各類細菌感染。
TxGNN 模型預測它可能對**細菌性關節炎 (Bacterial Arthritis)** 有效，
目前無正式登記的臨床試驗，但有 **20 篇文獻**支持這個方向，其中包含多篇歷史隨機對照研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sulbactam 是 β-內醯胺酶抑制劑，通常與 Ampicillin 併用形成複方，其成分在各類細菌感染治療中的療效已被廣泛證實，機轉上可能適用於細菌性關節炎（敗血性關節炎）。

Sulbactam 透過不可逆抑制細菌 β-內醯胺酶，恢復 Ampicillin 對產酶菌株（如金黃色葡萄球菌、流感嗜血桿菌、擬桿菌屬）的活性。骨關節感染常見致病菌恰好包含這些產 β-內醯胺酶菌種，因此機轉上具有合理性。

更重要的是，文獻證據顯示 Ampicillin/Sulbactam 併用治療兒童與成人的敗血性關節炎、骨髓炎已有數十年臨床使用經驗（如 1986、1989 年發表的隨機比較研究），顯示這並非單純模型推測，而是已有實際臨床實踐基礎的適應症延伸。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖有多篇歷史文獻（含隨機對照研究）支持 Ampicillin/Sulbactam 併用於骨關節感染已有數十年臨床實踐基礎，機轉合理性高；
- 但關鍵安全性資料（仿單警語、禁忌症）完全缺失（DG001，Blocking），且香港尚未上市（0 張許可證），無法進行安全性初評，故暫緩推進。
