# Sulfasalazine：從類風濕性關節炎到骨關節炎

## 一句話總結

Sulfasalazine 原本用於類風濕性關節炎、潰瘍性結腸炎、發炎性腸道疾病、幼年型特發性關節炎及脊椎關節病變。
TxGNN 模型預測它可能對**骨關節炎 (Osteoarthritis)** 有效，但目前**沒有臨床試驗**，僅有約 **10 篇與骨關節炎相關的前臨床研究和綜述**，證據屬於早期階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料。根據已知資訊，sulfasalazine 具有抗發炎作用，可抑制 NF-κB 訊號、xCT（胱胺酸/麩胺酸反向轉運體）以及前列腺素與白三烯的釋放。它在類風濕性關節炎、脊椎關節病變等發炎性關節疾病中的療效已被確立。

骨關節炎雖以退化為主，但滑膜發炎與軟骨降解是其重要病理環節。前臨床研究顯示，sulfasalazine 可阻止細胞激素刺激下軟骨蛋白聚醣與膠原蛋白的釋放並下調金屬蛋白酶（PMID 19690126），也在前十字韌帶切斷合併內側半月板切除的動物模型中減緩軟骨破壞（PMID 26466556）。含 sulfasalazine 的玻尿酸製劑在大鼠骨關節炎模型中降低發炎並減少軟骨降解（PMID 29548914）。

需要注意：目前沒有人體骨關節炎療效證據。可見文獻多為前臨床研究、綜述，或討論其他風濕性疾病，因此這個預測在機轉上合理，但臨床價值尚未驗證。

## 結論與下一步

**決策：Hold（作為研究問題持續追蹤）**

**理由：**
- 骨關節炎預測有合理的抗發炎與軟骨保護機轉，並有多項前臨床研究支持（L4），但沒有任何人體臨床試驗或 RCT。
- 骨關節炎族群常為年長者並合併使用 NSAIDs，而 sulfasalazine 與多種 NSAIDs 有交互作用，且具血液學、肝腎相關風險，效益風險比尚無法判斷。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與適應症資料（目前為阻擋性資料缺口）
- 補齊詳細作用機轉（MOA）資料
- 設計小規模探索性臨床試驗（如發炎性或滑膜炎表型明顯的骨關節炎族群），驗證人體療效
- 評估局部給藥（如關節內玻尿酸製劑）以降低全身毒性的可行性
- 針對與 NSAIDs 併用的情境，擬定血液學與肝腎功能監測計畫
