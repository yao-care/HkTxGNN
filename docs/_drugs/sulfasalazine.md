## Sulfasalazine: Brachydactyly-syndactyly syndrome
{: .text-alpha }

## 一句話總結

Sulfasalazine 在知識圖譜中記錄的相關疾病包括類風濕性關節炎、潰瘍性結腸炎與發炎性腸道疾病。
TxGNN 模型預測它可能對**骨關節炎 (Osteoarthritis)** 有效，但目前沒有臨床試驗，僅有數篇前臨床研究（細胞與動物實驗）與間接文獻，整體屬於初步假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻，sulfasalazine 具抗發炎作用，可能涉及 NF-κB 通路與胱胺酸/麩胺酸反向轉運體 (system xc-) 的抑制。

前臨床文獻提供了一些間接線索：
- 在細胞實驗中，sulfasalazine 可減少細胞激素刺激下軟骨的蛋白聚醣與膠原蛋白釋放，並下調基質金屬蛋白酶（PMID 19690126）。
- 在前十字韌帶切斷合併內側半月板切除的動物模型中，sulfasalazine 可減輕軟骨破壞，機轉與抑制 system xc- 有關（PMID 26466556）。
- 含 sulfasalazine 的玻尿酸製劑在大鼠骨關節炎模型中減少發炎與軟骨降解（PMID 29548914）。

不過，這些證據都來自體外或動物研究，沒有人體骨關節炎試驗。骨關節炎也常是慢性、非典型發炎性疾病，全身性用藥需與消化道、血液及肝臟風險一併權衡。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何針對骨關節炎的臨床試驗，現有證據僅為體外與動物實驗，依規則為 L5。
- 全身性使用 sulfasalazine 有血液、肝臟與消化道方面的風險，對於慢性骨關節炎需審慎評估風險效益。

**若要推進需要：**
- 取得 sulfasalazine 的作用機轉資料，釐清與骨關節炎的機轉連結
- 設計並進行人體骨關節炎的探索性臨床研究（例如炎症性或滑膜炎表型的亞群）
- 評估局部給藥（如關節腔內製劑）的可行性，以降低全身毒性
- 取得香港仿單的警語、禁忌與核准適應症內容，以完成安全性評估

**其他預測適應症備註：**其餘 7 個預測（如 WHIM 症候群、肢端中段發育不良等）皆無試驗或文獻，也無明確機轉連結，同為 L5 並建議 Hold。
