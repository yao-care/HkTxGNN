# Sultamicillin：從抗菌治療到支氣管炎

## 一句話總結

Sultamicillin 是 ampicillin 與 sulbactam 的雙重前驅藥，屬於口服抗菌藥，來源資料未載明原適應症。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，
目前**無臨床試驗登記**，但有 **15 篇文獻**，多為 1984–1993 年的開放性或非隨機臨床研究。這個方向較接近既有的抗菌用途，並非真正的跨領域再利用。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sultamicillin 是 ampicillin（β-內醯胺類抗生素）與 sulbactam（β-內醯胺酶抑制劑）以酯鍵連接的前驅藥，口服後在體內釋出兩個成分。

支氣管炎，特別是慢性支氣管炎急性惡化，常由流感嗜血桿菌 (*H. influenzae*)、卡他莫拉菌 (*M. catarrhalis*) 等呼吸道細菌引起，其中不少會產生 β-內醯胺酶。Sulbactam 可保護 ampicillin 不被這類酵素分解，因此機轉上直接適用於支氣管感染。

需要注意：這比較像「既有的抗菌用途」，而不是全新的再利用。原適應症欄位為空，應視為來源資料缺漏。若是病毒性支氣管炎，抗菌藥的效益也不確定。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 有多項臨床研究顯示 Sultamicillin 對支氣管炎及下呼吸道感染有效，機轉也合理（β-內醯胺酶抑制劑保護 ampicillin）。
- 但證據僅限於 1984–1993 年的開放性或非隨機研究，無登記試驗，且原適應症與機轉資料缺漏，所以只能附帶條件推進。

**若要推進需要：**
- 取得並解析香港衛生署仿單，完成警語與禁忌症的安全性篩選（目前為阻斷性缺口）。
- 補齊 DrugBank 的作用機轉與原適應症資料。
- 以現代指引與當地抗藥性資料重新評估療效；若要正式支持，需要近期的對照研究。
- 確認原適應症是否已涵蓋呼吸道感染，以判斷這是否算真正的再利用。

**其他預測適應症（簡述）：** 排名第 2 至第 10 的預測多為血栓、凝血抑制物缺乏或罕見先天性疾病，皆無合理機轉，建議 Hold。喉氣管炎 (laryngotracheitis) 在生物學上可行，但無任何試驗或文獻，僅列為研究問題。
