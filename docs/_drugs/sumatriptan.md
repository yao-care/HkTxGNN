# Sumatriptan：從偏頭痛治療到伴腦幹先兆偏頭痛

## 一句話總結

Sumatriptan 是 5-HT1B/1D 受體促效劑，在香港已上市，用於偏頭痛急性治療（由藥物類別推論，供應資料未載明原適應症）。
TxGNN 模型預測它可能對**伴腦幹先兆偏頭痛 (Migraine with Brainstem Aura)** 有效，
目前**無臨床試驗**，有 **17 篇一般偏頭痛相關文獻**，但沒有任何一篇專門研究 sumatriptan 用於此亞型。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sumatriptan 屬於 triptan 類別，為 5-HT1B/1D 受體促效劑，可能透過收縮顱內大血管及抑制三叉神經血管系統釋放血管活性神經肽，來緩解偏頭痛發作。

伴腦幹先兆偏頭痛是伴先兆偏頭痛的亞型，所以和偏頭痛急性治療有明顯關聯。不過，0.997 的高分很可能反映的是知識圖譜中 sumatriptan 與偏頭痛本來就有的關聯，並非真正的新用途訊號。

需特別注意：triptan 類藥物的標示通常將基底型（腦幹先兆）及偏癱型偏頭痛列為禁忌，理論上有血管收縮造成缺血的風險。此外，一項世代研究（PMID 25841032）指出，sumatriptan 在伴先兆偏頭痛的療效低於無先兆偏頭痛，這對本預測並不利。

## 安全性考量

- **禁忌症（類別層級提醒，非本資料提供）**：triptan 類藥物標示通常將基底型（腦幹先兆）偏頭痛與偏癱型偏頭痛列為禁忌，原因是理論上有血管收縮造成缺血的風險。這項疑慮必須在任何推薦前釐清。

其餘安全性資訊（警語、藥物交互作用）請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據只有模型預測，加上一般偏頭痛文獻，沒有臨床試驗，也沒有專門研究 sumatriptan 用於腦幹先兆的文獻。
- 高分多半反映既有的偏頭痛關聯，而非新的再利用訊號。此外，triptan 類對此亞型有禁忌疑慮，且伴先兆偏頭痛的療效較低。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語、禁忌症與核准適應症
- 補充作用機轉資料（DrugBank）
- 針對腦幹先兆偏頭痛的缺血風險做專項安全性評估
- 尋找或設計專門針對此亞型的臨床研究
