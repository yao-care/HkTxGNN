# Sumatriptan：從偏頭痛到伴腦幹先兆的偏頭痛

## 一句話總結

Sumatriptan 是一種曲普坦（triptan）類藥物，原本用於偏頭痛、叢集性頭痛等頭痛疾病的治療。
TxGNN 模型預測它可能對**伴腦幹先兆的偏頭痛 (Migraine with brainstem aura)** 有效，
但目前**沒有臨床試驗登記**，僅有 **18 篇間接相關文獻**，證據仍屬初步。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。依一般藥理知識，Sumatriptan 是 5-HT1B/1D 受體促效劑，推測透過收縮顱內血管、抑制三叉神經血管系統釋放血管活性神經肽來緩解偏頭痛。這一點是根據文獻內容與一般知識推論，並非來自本次整理的藥物資料。

伴腦幹先兆的偏頭痛本身就是偏頭痛的亞型，與原適應症共享三叉神經血管的病理機制。因此 0.997 的高分，很可能反映的是疾病分類上的高度接近，而不是真正的新藥理發現。

需特別注意的是，曲普坦類藥物在有腦幹症狀的先兆亞型（如基底型偏頭痛）上，因後循環血管收縮的理論疑慮，歷來有警示或禁忌。另有一篇文獻（PMID 25841032）指出 Sumatriptan 在有先兆偏頭痛的療效低於無先兆偏頭痛。因此這個預測雖然合理，但不等於可以直接使用。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單原文，僅供參考）：高血壓、冠狀動脈疾病、心肌梗塞、充血性心衰竭、中風與腦血管疾病、周邊血管疾病、肝衰竭與肝病、腎臟病、癲癇、糖尿病、血液凝固疾病等。其中心腦血管相關項目，與腦幹先兆偏頭痛的後循環血管疑慮尤其相關。
- **藥物交互作用**：共查得 100 筆，以下為主要者：
  - **重大 (Major)**：Dexfenfluramine、Fenfluramine、Lorcaserin、Sibutramine（血清素相關風險）；Dolasetron、Granisetron、Ondansetron、Palonosetron（5-HT3 拮抗劑）
  - **中度 (Moderate)**：Morphine（含脂質體劑型）

仿單的警語與禁忌資料尚未取得，其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測主要反映疾病分類上的接近，並非新的藥理發現，且目前沒有臨床試驗登記，也沒有專門針對腦幹先兆亞型的研究。
- 曲普坦類在腦幹症狀亞型有血管收縮的理論疑慮，且仿單警語與禁忌資料尚未取得，無法完成安全性初篩。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語、禁忌與核准適應症
- 補充 Sumatriptan 的作用機轉資料（DrugBank）
- 系統性檢索曲普坦在基底型／腦幹先兆偏頭痛的安全性與療效證據
- 評估後循環血管風險，並規劃心腦血管風險族群的排除與監測方案
