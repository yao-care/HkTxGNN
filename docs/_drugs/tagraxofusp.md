# Tagraxofusp：從母細胞性漿細胞樣樹突細胞腫瘤 (BPDCN) 到斜視 (Esotropia)

## 一句話總結

Tagraxofusp（品牌名 ELZONRIS）是一種 CD123 標靶的細胞毒性融合蛋白（IL-3 接上白喉毒素），原本用於 BPDCN 治療。
TxGNN 模型預測它可能對**內斜視 (Esotropia)** 有效，但目前**沒有任何臨床試驗或文獻**支持，這個預測只是圖譜層級的關聯。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。已知 Tagraxofusp 是 CD123 (IL-3 受體 α) 標靶的細胞毒素，由 IL-3 與白喉毒素融合而成，用於表現 CD123 的血液惡性腫瘤。

內斜視是眼球運動失調的疾病，與 CD123 表現的血液腫瘤沒有已知的生物學關聯。我們找不到合理的機轉能解釋這個藥對斜視有效。

因此 0.997 的高分應視為圖譜預測的假象，而不是有意義的臨床訊號。

## 安全性考量

安全性資訊請參考原廠仿單。

目前資料中沒有警語、禁忌症與藥物交互作用的記錄。已知此藥有毛細血管滲漏症候群與肝毒性風險，用於良性眼科疾病難以合理化。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測沒有任何臨床試驗或文獻支持，機轉上也無合理關聯，屬於僅有模型預測的 L5 證據。
- 全身性細胞毒素的已知毒性，與斜視的疾病嚴重度明顯不成比例。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌症資料，並補齊 DrugBank 的 MOA 資料。
- 找出 CD123 或 IL-3 受體與眼外肌或斜視病理相關的生物學證據；若找不到，建議直接終止此方向。

**補充：**同一份預測清單中，第 2 名「癌前病變 (pre-malignant neoplasm)」有 5 個血液惡性腫瘤相關試驗，證據等級為 L4，可作為研究問題另案評估。其中 NCT05476770（兒童復發/難治血液惡性腫瘤，Phase 1）與 NCT03113643（含高風險 MDS 與 AML，Phase 1）直接測試 Tagraxofusp，但受試者都是已確診的惡性腫瘤，不是癌前病變。

> 本報告結果僅供研究參考，不構成醫療建議。老藥新用候選需經過臨床驗證才能應用。
