## Tamoxifen: Mammary Paget disease
{: .text-alpha }

## 一句話總結

Tamoxifen 是選擇性雌激素受體調節劑，原本用於治療女性乳癌（包括浸潤性乳管癌）。
目前有 **30 餘個相關臨床試驗**（含多個已完成的 Phase 3 RCT）和 **20 篇文獻**（含多篇 RCT）支持這個方向。

> 說明：TxGNN 預測的排名第 1 適應症為乳腺佩吉特氏病 (mammary Paget disease)，但其證據僅為間接（1 個關聯性低的試驗與個案報告，證據等級 L4，決策為 Hold）。因此本報告改以證據最充分的乳腺原位癌為主軸，並在結論附上其他預測適應症的比較。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Tamoxifen 是選擇性雌激素受體調節劑（SERM），在乳腺組織中拮抗雌激素受體（ER）訊號，這是它治療荷爾蒙受體陽性乳癌的既有機轉。

乳腺原位癌（DCIS）是浸潤性乳癌的前驅病變，與原適應症同屬乳腺上皮腫瘤。在荷爾蒙受體陽性的 DCIS 中，阻斷雌激素訊號可降低同側及對側的復發風險。因此這個預測較接近乳癌範疇內的延伸，而非全新疾病的重新定位。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（非仿單文字）：血小板低下、高血鈣、腎鈣質沉著症、磷代謝疾病、中風及腦血管疾病、腦梗塞、肺栓塞、白血球低下、視覺障礙、失明。
- **藥物交互作用**：共查得 100 筆。主要（Major）交互作用包括 bupropion、lorcaserin、cimetidine、dolasetron、eliglustat、cisapride、dexfenfluramine、fenfluramine；中度包括 famotidine、loperamide、aprepitant、dexamethasone、clarithromycin、granisetron、levofloxacin 等。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 乳腺原位癌有多個已完成的 Phase 3 RCT 與長期追蹤（TAM-01、IBIS-II、NSABP B-24 等）支持 tamoxifen，證據等級 L1。
- 此適應症屬乳癌範疇的延伸，而非全新疾病，且 tamoxifen 在香港已有 14 張有效許可證。

**若要推進需要：**
- 取得香港仿單的警語與禁忌資料，完成安全性篩選（目前為阻斷性資料缺口）。
- 補齊作用機轉（MOA）資料。
- 限定使用於 ER 陽性疾病；評估血栓栓塞與子宮內膜癌風險；考慮低劑量方案（5 mg/日）以改善耐受性。
- 用藥前評估 CYP2D6 與藥物交互作用，特別是上列 Major 交互作用藥物。
