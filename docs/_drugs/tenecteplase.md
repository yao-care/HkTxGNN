# Tenecteplase：從原適應症（資料未提供）到後下壁心肌梗塞

## 一句話總結

Tenecteplase（替奈普酶）是一種纖維蛋白專一性的組織型纖維蛋白溶酶原活化劑（tPA）變異體，目前在香港已有 1 張上市許可證，但本資料包未提供原適應症。
TxGNN 模型預測它可能對**後下壁心肌梗塞 (Posteroinferior Myocardial Infarction)** 有效，
但這個適應症目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Tenecteplase 屬於纖維蛋白專一性的 tPA 類血栓溶解劑，能溶解冠狀動脈中的血栓。

後下壁心肌梗塞是急性心肌梗塞的一個解剖亞型，成因同樣是冠狀動脈被血栓阻塞。血栓溶解劑可使阻塞血管再通，因此機轉上合理，高分預測可能也反映了這一點。

不過，本資料包沒有原適應症和作用機轉的資料，因此無法確認急性心肌梗塞是否已在仿單適應症內。另外，沒有任何研究是專門針對這個亞型的。

資料包中的其他預測適應症，證據強弱不一：

- **後側壁心肌梗塞**：分數相同，同樣沒有證據。
- **間隔心肌梗塞**：只有間接文獻，且是以肺栓塞為主的個案報告和研究。
- **先天性冠狀動脈異常**：機轉上較弱，僅有一篇溶栓失敗的個案報告。
- **冠狀動脈狹窄**：證據最多，有 1 個已完成的 Phase 2 隨機試驗（NCT00604695，40 人，冠狀動脈內低劑量 Tenecteplase 輔助初級 PCI），另有相符的可行性與安全性論文（PMID 31870492）。該試驗人數少，僅能支持可行性與安全性，無法證明療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測只有模型分數，沒有任何針對後下壁心肌梗塞的臨床試驗或文獻，屬於 L5。
- 資料包中安全性（仿單警語、禁忌）與原適應症都缺資料，其中香港衛生署仿單被列為阻斷性缺口，目前無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌、核准適應症），確認急性心肌梗塞是否已在標示內。
- 補充 DrugBank 的作用機轉資料。
- 搜尋急性 STEMI 的 Tenecteplase 大型試驗，確認後下壁亞型是否已涵蓋在其中。
- 若要優先投入資源，可先看「冠狀動脈狹窄」（L2），並評估是否需要更大規模的試驗。
