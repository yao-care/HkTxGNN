# Tenofovir Alafenamide：從抗病毒治療到猿猴免疫缺乏病毒感染

## 一句話總結

Tenofovir Alafenamide（TAF）是 tenofovir 的前驅藥，屬核苷酸類逆轉錄酶抑制劑，在香港以 HIV 複方及 Vemlidy 等產品上市。
TxGNN 模型預測它可能對**猿猴免疫缺乏病毒感染 (Simian Immunodeficiency Virus Infection)** 有效。
目前有 **1 個臨床試驗**（相關性低）和 **8 篇文獻**，文獻全為獼猴等動物的前臨床研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，也沒有登錄原適應症。根據已知資訊，TAF 是 tenofovir 的前驅藥，屬核苷酸類逆轉錄酶抑制劑。香港上市產品包括 Vemlidy、Descovy、Odefsey 與 Biktarvy 等。原適應症需另行查證。

SIV 與 SHIV 都是慢病毒，其逆轉錄酶與 HIV-1 的高度相近，所以 TAF 的抑制作用在機轉上合理。

SIV 是非人類靈長類的模型病原體，不是人類疾病。這個預測主要反映 TAF 已知的 HIV-1 抗病毒活性，不代表新的人類適應症。支持文獻多為獼猴的暴露前與暴露後預防（PrEP/PEP）研究，用於評估 HIV 預防策略。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅為獼猴等前臨床研究，唯一的臨床試驗與 TAF 無直接關聯。
- SIV 是動物模型病原體，不是人類適應症。
- 同批預測的「貓後天免疫缺乏症候群」是獸醫適應症，且無任何證據，評為 Hold。
- 「伴隨共濟失調步態、無語言能力及皮質白質減少的神經發育障礙」看不出機轉關聯，可能是知識圖譜的假象，也評為 Hold。

**若要推進需要：**
- 確認 TAF 在香港的核准適應症（HIV-1、HBV），並取得原廠仿單的警語與禁忌症。
- 補齊 DrugBank 的作用機轉資料。
- 釐清此預測的實際價值。若重點是 HIV 預防或治療，應以人類臨床證據評估，而非 SIV 動物模型。
