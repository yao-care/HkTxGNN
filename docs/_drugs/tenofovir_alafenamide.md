# Tenofovir Alafenamide：從 HIV 感染到猴免疫缺陷病毒感染（動物模型）

## 一句話總結

Tenofovir Alafenamide (TAF) 是一種核苷酸逆轉錄酶抑制劑的前驅藥，原本用於 HIV 感染與愛滋病治療。
TxGNN 模型預測它可能對**猴免疫缺陷病毒感染 (Simian Immunodeficiency Virus Infection)** 有效，
目前有 **8 篇前臨床文獻**（皆為動物或模型研究），**無臨床試驗**登記。需要注意，這個預測屬於已核准 HIV 適應症的動物模型版本，並非獨立的新人類適應症。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記載。根據已知資訊，TAF 是 tenofovir 的前驅藥，進入淋巴細胞後轉換為活性代謝物 tenofovir diphosphate，透過終止病毒 DNA 鏈延長來抑制逆轉錄酶。

SIV 與 SHIV（猴／人類嵌合免疫缺陷病毒）和 HIV 同樣依賴逆轉錄酶進行複製，因此機轉上可直接轉用。巨猴（macaque）實驗顯示 TAF（單用或與 emtricitabine 合用）可預防直腸與陰道的 SHIV 感染，也具有暴露後保護效果。

不過，SIV 感染本質上是已核准 HIV 適應症的動物模型，不是獨立的新人類疾病。因此這個預測的價值主要在於支持前臨床研究與預防劑型開發，而非開拓新的臨床適應症。

## 結論與下一步

**決策：Hold（僅作為研究問題）**

**理由：**
- 證據全為獼猴與小鼠的前臨床研究，無任何臨床試驗；且此適應症是已核准 HIV 適應症的動物模型，並非獨立的新人類適應症。TAF 已在香港上市，因此此預測的實際價值有限。
- 同批預測中，貓愛滋病（feline AIDS）僅有模型分數、無任何證據；另一項罕見神經發育疾病則找不到合理的機轉關聯，應視為知識圖譜的假象，不建議追蹤。

**若要推進需要：**
- 補齊作用機轉資料（目前缺乏）
- 取得香港衛生署仿單的警語與禁忌症
- 若目標是局部或長效預防劑型（栓劑、植入物），需從人體試驗與劑型可行性評估著手
- 釐清此預測是否有超出現行 HIV 適應症的實際研發價值
