# Tenoxicam：從關節疾病到類風濕性關節炎

## 一句話總結

Tenoxicam 是 oxicam 類非類固醇消炎止痛藥（NSAID），原本用於關節炎及關節病變。
TxGNN 模型預測它可能對**類風濕性關節炎 (Rheumatoid Arthritis)** 有效，但這其實接近原適應症的延伸，而非全新用途。
目前無登記的臨床試驗，但有 **20 篇文獻**支持，其中包含數項針對類風濕性關節炎的對照研究。

## 為什麼這個預測合理？

Tenoxicam 是 oxicam 類 NSAID，透過抑制 COX-1 與 COX-2、減少前列腺素介導的發炎、疼痛與腫脹。目前缺乏 DrugBank 的詳細作用機轉資料，以上機轉為依藥物類別所作的說明。

類風濕性關節炎的關節症狀（疼痛、僵硬、腫脹）同樣由前列腺素介導的發炎所驅動，與其原適應症（關節炎性疾病）的機轉相同。因此類風濕性關節炎實質上屬於適應症內或近似適應症，不是真正的藥物再利用。

需注意：NSAID 只能緩解症狀，並不改變疾病進程，這與疾病修飾型抗風濕藥不同。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 類風濕性關節炎與 tenoxicam 原有的關節炎適應症機轉相同，多項對照研究與回顧文獻顯示其療效與 piroxicam 等 NSAID 相當。
- 但缺乏登記的臨床試驗，部分文獻年代較早且研究設計僅由標題推斷，加上安全性與機轉資料不完整，因此需附帶防護條件。

**若要推進需要：**
- 取得香港衛生署核准的仿單，確認核准適應症、警語與禁忌症
- 補充 DrugBank 的作用機轉資料
- 逐篇核實主要研究的設計與結果
- 規劃 NSAID 類藥物常見風險（腸胃道、心血管、腎臟）的監測方案

### 其他預測適應症的簡要說明

- **頭痛疾患 (Headache Disorder)**（分數 99.68%，證據等級 L4）：有 1 項 Phase 4 試驗 [NCT06786650](https://clinicaltrials.gov/study/NCT06786650)（靜脈注射 ibuprofen 與 tenoxicam 用於急性偏頭痛，100 人，進行中、尚無結果）。相關文獻僅為偏頭痛治療的一般性比較，未確認含 tenoxicam 專屬數據，建議列為研究問題，待試驗結果。
- **骨關節炎易感性 (Osteoarthritis Susceptibility)**（分數 99.70%）：tenoxicam 可用於症狀性骨關節炎，但此預測針對遺傳易感性，無證據支持，建議暫緩 (Hold)。
- **短指併指症候群、眼缺損小眼畸形-肢根型發育不良症候群**（分數約 99.80%）：均為先天性發育異常，機轉上無合理關聯，也無任何臨床或文獻證據，高分應屬模型假象，建議暫緩 (Hold)。
