# Teprotumumab：從甲狀腺眼病到單體 X 症（Monosomy X）

## 一句話總結

Teprotumumab 是一種 IGF-1R（類胰島素生長因子-1 受體）抑制劑，在香港以 TEPEZZA 品名上市，一般公開資料顯示其主要用於甲狀腺眼病（本次資料未提供香港核准適應症文字）。
TxGNN 模型預測它可能對**單體 X 症 (monosomy X，即透納氏症相關)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

Teprotumumab 的作用機轉是抑制 IGF-1R。單體 X 症（透納氏症）的特徵是生長遲緩與性腺發育不全，與生長激素／IGF-1 軸有關，這可能是模型把兩者連在一起的原因。

不過方向上有明顯問題：IGF-1R 被抑制，預期會抵銷而非促進生長，因此目前找不到合理的治療依據。同一批預測中，還有透納氏症（結構性 X 染色體異常）、嵌合型單體 X、性染色體性發育異常、X 染色體數目異常等條目。它們屬於同一個 X 染色體疾病群集，分數高度相關，不能視為獨立證據。

其他高分預測（食道靜脈曲張、靜脈曲張疾病、粒線體氧化磷酸化疾病等）同樣沒有試驗、文獻，也看不出與 IGF-1R 抑制的機轉關聯，分數可能只是圖譜拓撲的結果。

## 安全性考量

安全性資訊請參考原廠仿單。本次資料中，警語與禁忌症均無內容，藥物交互作用查詢也無結果。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測只靠模型分數，沒有任何臨床試驗或文獻（證據等級 L5）。
- IGF-1R 抑制的方向與透納氏症的生長生物學相反，找不到合理的機轉依據。

**若要推進需要：**
- 補齊香港衛生署仿單的警語、禁忌症與核准適應症。
- 補充 DrugBank 的作用機轉資料。
- 進行系統性文獻回顧，確認 IGF-1R 抑制與單體 X 症之間是否有任何機轉或臨床證據。
- 若沒有支持性證據，建議不再投入資源，改評估其他預測適應症或直接排除。
