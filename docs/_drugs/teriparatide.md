# Teriparatide：從（原適應症資料缺漏）到十二指腸潰瘍

## 一句話總結

Teriparatide 是重組人類副甲狀腺素片段 PTH(1-34)，屬骨質形成促進劑，但本次資料未提供原適應症。
TxGNN 模型預測它可能對**十二指腸潰瘍 (Duodenal Ulcer)** 有效，
目前**沒有任何臨床試驗或文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Teriparatide 是 PTH(1-34) 重組片段，會活化 PTH1R，具骨質形成（bone anabolic）作用。

就現有資料而言，找不到 PTH1R 活化與潰瘍癒合之間的合理機轉。相反地，慢性副甲狀腺素過多（副甲狀腺機能亢進）所引起的高血鈣，與胃泌素及胃酸分泌增加有關，這比較像是潛在的**不良訊號**，而非療效。

因此，0.9986 的高分只是知識圖譜的推論結果，不代表生物學上的支持。其他排名前列的預測（食道畸形、十二指腸阻塞、十二指腸胃逆流、食道疾病）同樣沒有試驗或文獻佐證，多半是消化道疾病節點在圖譜中相近所產生的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 僅有模型預測（L5），沒有任何臨床試驗或文獻，且機轉上找不到合理的連結，甚至有高血鈣增加胃酸分泌的潛在風險。
- 安全性資料（仿單警語、禁忌症）尚未取得，無法進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語與禁忌症
- 補齊 DrugBank 的作用機轉（MOA）與原適應症
- 以 PTH1R 訊號與胃黏膜／胃酸分泌為主題，進行前臨床或文獻回顧，確認是否存在任何支持性機轉
- 在上述證據出現之前，不建議投入臨床試驗規劃
