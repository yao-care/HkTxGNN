# Teriparatide：從骨質疏鬆症到十二指腸潰瘍

## 一句話總結

Teriparatide（PTH(1-34) 類似物）原用於骨質疏鬆症治療，主要機轉是活化 PTH1R 受體以促進骨形成。
TxGNN 模型預測它可能對**十二指腸潰瘍 (Duodenal Ulcer)** 有效，
但目前**無任何臨床試驗或文獻支持**，證據等級為最低的 **L5**（純模型預測），且證據包本身的機轉分析也判定此關聯性極弱。

## 為什麼這個預測合理？

Teriparatide 的作用機轉是活化蝕骨細胞/成骨細胞上的 PTH1R 受體以促進骨形成，臨床用於骨質疏鬆症治療。本評估包缺乏正式 MOA 資料（Data Gap），僅能從各候選適應症的機轉分析文字中還原此背景資訊。

十二指腸潰瘍的病理機轉主要涉及幽門螺旋桿菌感染、胃酸分泌過多與黏膜防禦機制受損，與 PTH1R 訊息傳導及骨代謝路徑**沒有已知的生理連結**。目前也沒有證據顯示全身性 PTH 濃度升高（如原發性副甲狀腺機能亢進）與消化性潰瘍有明確因果關係。

證據包本身對此預測的評語相當直接：此關聯很可能是知識圖譜中骨代謝相關基因與腸胃道基因間接共現所產生的統計雜訊，而非真實的生物學訊號。因此本預測的機轉合理性偏低。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅 L5，無任何臨床試驗或文獻支持；
- 機轉分析明確指出十二指腸潰瘍與 teriparatide 的骨代謝路徑無已知生理關聯，很可能是知識圖譜雜訊。
- 其餘 4 個預測適應症（食道發育異常、十二指腸阻塞、十二指腸胃逆流、食道疾病）也呈現相同模式：高分但機轉關聯性薄弱、無實證支持。

**若要推進需要：**
- 補齊 teriparatide 的正式作用機轉（MOA）與 TFDA/衛生署仿單警語、禁忌症資料（目前為 Blocking 等級的 Data Gap）
- 尋找是否有動物實驗或臨床觀察性研究探討 PTH 訊號路徑與腸胃道黏膜修復的關聯
- 在無新增證據前，不建議投入資源進行此適應症的進一步開發
