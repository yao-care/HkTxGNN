# Tetryzoline：從咽炎與普通感冒到鼻腔疾病

## 一句話總結

Tetryzoline 是一種咪唑啉（imidazoline）衍生物，原本用於咽炎與普通感冒的相關治療。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個預測，僅有模型運算結果。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥物類別，Tetryzoline 屬於咪唑啉衍生物，是 α-腎上腺素受體促效劑（血管收縮劑）。局部使用可減少黏膜血流與腫脹，理論上能緩解鼻塞。但這個推論來自藥物類別的一般知識，並非本次彙整資料中的記錄。

原適應症（咽炎、普通感冒）與鼻腔疾病同屬上呼吸道，症狀上有重疊，例如黏膜充血與水腫。血管收縮劑只能緩解症狀，不具抗感染或抗發炎作用。

另外需注意，Tetryzoline 在許多地區已作為鼻用或眼用的減充血劑上市，因此這個預測可能只是既有用途，而非真正的新用途。本次資料無法確認這一點。

另一個預測適應症是**急性喉咽炎 (Acute Laryngopharyngitis)**（TxGNN 分數 99.98%），與原適應症咽炎在解剖與臨床上高度相近，較像是既有用途的延伸，而非獨立的再利用機會。同樣沒有試驗或文獻支持。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（來自 TxGNN 知識圖譜的藥物－疾病關聯，並非仿單內容）：糖尿病、糖尿病酮酸中毒、心血管疾病、心臟病、甲狀腺機能亢進、Graves 病、甲狀腺毒症。

其餘警語、禁忌症與藥物交互作用資料不足，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測（證據等級 L5），沒有臨床試驗或文獻支持。
- 鼻腔疾病的預測可能只是既有用途，且香港現有產品皆為眼用劑型，路徑尚未對應。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症
- 補充詳細的作用機轉（MOA）資料
- 確認該藥在其他地區是否已有鼻用或咽喉用的核准適應症，以判斷是否為真正的新用途
- 評估給藥途徑（鼻用／咽喉用）與現有眼用劑型的相容性
- 針對糖尿病、心血管疾病與甲狀腺疾病族群，建立安全性評估
- 檢索臨床試驗與文獻，補充實際證據
