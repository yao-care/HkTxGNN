# Ticagrelor：從急性冠心症抗血小板治療到顱內動脈硬化

## 一句話總結

Ticagrelor 是可逆性的 P2Y12 血小板抑制劑，臨床上用於冠心症等動脈粥狀硬化血栓疾病的抗血小板治療。
TxGNN 模型預測它可能對**顱內動脈硬化 (Intracranial Arteriosclerosis)** 有效。
目前有 **2 個直接針對顱內動脈狹窄的進行中試驗**、**3 篇直接相關文獻**，另有鄰近族群（腦中風/TIA、周邊動脈、冠心症）的 Phase 3 證據，但尚無已完成的顱內動脈硬化專屬 RCT。

## 為什麼這個預測合理？

Ticagrelor 是可逆性 P2Y12 受體拮抗劑，**不需經 CYP2C19 代謝活化**。這點與 clopidogrel 不同。顯示症狀性顱內動脈粥狀硬化狹窄的病人，可能因血小板驅動的血栓形成與動脈到動脈的栓塞而中風，這正是 P2Y12 抑制可介入的環節。

在 CYP2C19 功能缺失基因型的帶因者中，clopidogrel 效果較差，ticagrelor 因此有潛在優勢。CHANCE-2 試驗（腦中風/TIA 族群）已顯示 ticagrelor 優於 clopidogrel，這是目前最接近的間接證據。目前進行中的研究也呼應這個方向，包括基因型導向的 P2Y12 抑制劑選擇試驗，以及 CAPTIVA 試驗。

需要注意：目前提供的資料中，**沒有已完成的 Phase 3 RCT 專門在顱內動脈硬化測試 ticagrelor**。支持度主要來自鄰近族群的 Phase 3 試驗、進行中的顱內動脈狹窄 (ICAS) 研究，以及神經介入的劑量經驗。目前也缺乏詳細的作用機轉資料（DrugBank MOA 欄位未填）。

## 結論與下一步

**決策：Hold**（定位為研究問題）

**理由：**
- 機轉合理，且有直接針對顱內動脈狹窄的 Phase 3 (CAPTIVA) 與基因型導向試驗正在進行，但都尚未有結果。
- 目前沒有已完成的顱內動脈硬化專屬 RCT，且香港仿單的警語與禁忌資料尚未取得，安全性篩選無法進行。
- 抗血小板藥物的出血風險（尤其與 aspirin 併用）必須納入評估。

**若要推進需要：**
- 取得香港衛生署核准仿單，補齊警語、禁忌症與藥物交互作用。
- 追蹤 CAPTIVA (NCT05047172) 與 NCT06714526 的結果，確認 ticagrelor 在顱內動脈狹窄的實際療效。
- 補充 DrugBank 作用機轉資料。
- 評估病人選擇條件（如 CYP2C19 基因型）與出血風險管理計畫。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。*
