## Ticarcillin：從細菌感染到淋巴結柵狀肌纖維母細胞瘤
{: .text-alpha }

## 一句話總結

Ticarcillin 是一種羧苄青黴素類（carboxypenicillin）的 β-內醯胺抗生素，原本用於泌尿道感染、細菌性肺炎、金黃色葡萄球菌感染等細菌性疾病。
TxGNN 模型預測它可能對**淋巴結柵狀肌纖維母細胞瘤 (Lymph node palisaded myofibroblastoma)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ticarcillin 是 β-內醯胺類（羧苄青黴素）抗生素，透過結合青黴素結合蛋白（PBP）抑制細菌細胞壁合成，在細菌感染中的療效已被證實。

淋巴結柵狀肌纖維母細胞瘤是罕見的良性間質腫瘤，沒有細菌病因，因此抗菌機轉**預期與此疾病無關**。我們目前找不到可信的機轉連結，0.998 的高分只是知識圖譜的預測結果，不代表有生物學或臨床上的依據。

其他排名前列的預測（腹腔動脈壓迫症候群、腹部囊性淋巴管瘤、腹部子宮外孕、薦骨脊索瘤）同樣缺乏機轉合理性與任何試驗或文獻佐證。其中子宮外孕的關聯，可能只是因為原適應症含骨盆腔炎與輸卵管炎，屬於解剖位置上的接近，而非治療上的依據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（非仿單內容）：腎臟疾病、輸尿管積膿、困難梭狀芽孢桿菌結腸炎、新生兒壞死性腸炎、傳染性單核球增多症、慢性 Epstein-Barr 病毒感染症候群。
- **藥物交互作用**：共查得 23 筆，本報告資料中列出 20 筆，以下為主要項目：
  - **中度**：
    - 四環黴素類（Doxycycline、Tetracycline、Minocycline、Demeclocycline、Oxytetracycline）
    - 胺基糖苷類（Gentamicin、Amikacin、Kanamycin、Streptomycin）
    - 抗凝血劑（Warfarin、Dicoumarol）
    - Chloramphenicol、Ethinylestradiol、Picosulfuric acid、碘 I-123 / I-131
  - **輕度**：Clarithromycin、Erythromycin、Heparin

其餘警語與禁忌請參考原廠仿單。
