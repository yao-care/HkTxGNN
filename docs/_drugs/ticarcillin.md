# Ticarcillin：從抗綠膿桿菌感染治療到淋巴結栅狀肌纖維母細胞瘤

## 一句話總結

Ticarcillin 是抗綠膿桿菌盤尼西林類抗生素，主要透過抑制細菌細胞壁合成發揮抗菌作用。
TxGNN 模型預測其可能對**淋巴結栅狀肌纖維母細胞瘤 (Lymph Node Palisaded Myofibroblastoma)** 有效，
但目前**無任何臨床試驗或文獻證據**支持，且機轉分析顯示此關聯缺乏生物學合理性。

## 為什麼這個預測合理？

Ticarcillin 是抗綠膿桿菌（*Pseudomonas aeruginosa*）盤尼西林類抗生素，作用機轉為抑制細菌細胞壁合成（結合 penicillin-binding proteins, PBPs）。此為評估報告中唯一可取得的機轉資訊，正式的 `original_moa` 欄位目前仍缺漏。

淋巴結栅狀肌纖維母細胞瘤是一種罕見的良性梭形細胞腫瘤，其病理機轉屬於間質細胞增生，與細菌感染或細胞壁合成路徑並無已知的生物學關聯。

TxGNN 給出的 99.82% 高分，較可能反映知識圖譜中此類罕見疾病節點連結稀疏所導致的雜訊，而非真實的機轉合理性。事實上，本評估報告中排名前 5 的候選適應症（詳見下方「其他候選適應症」）皆呈現相同模式——分數集中在 99.8% 上下、疾病彼此互不相關、且機轉分析一致指出缺乏生物學連結。這種訊號通常代表模型在該藥物的嵌入空間中缺乏足夠的已知關聯做為錨點，而非真正發現了新適應症。

**若要推進需要：**
- 補齊 Ticarcillin 之正式作用機轉（MOA）資料（DrugBank API）
- 取得 TFDA（或相當機構）仿單，解析警語與禁忌症
- 針對候選適應症搜尋是否有未被收錄的病例報告或機轉研究，以提升證據等級
- 在缺乏上述資料前，不建議投入額外資源於此批候選適應症
