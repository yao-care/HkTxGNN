# Tildrakizumab：從斑塊型乾癬到嚴重非增殖性糖尿病視網膜病變

## 一句話總結

Tildrakizumab 是抗 IL-23p19 單株抗體，公開已知原核准適應症為斑塊型乾癬（此資訊非本地上市資料，因本藥尚未在香港取得許可證）。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效，
但目前**無任何臨床試驗、無任何文獻**支持，純屬知識圖譜計算推論。

## 快速總覽

| 項目 | 內容 |
|------|------|
| 原適應症 | 斑塊型乾癬（公開已知資訊，非香港官方許可資料） |
| 預測新適應症 | 嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy) |
| TxGNN 預測分數 | 99.63%（排名 7229） |
| 證據等級 | L5 |
| 香港上市 | 未上市 |
| 許可證數 | 0 |
| 建議決策 | Hold |

## 為什麼這個預測合理？

目前 DrugBank 未提供正式的作用機轉 (MOA) 資料，此為資料缺口（DG002，High severity），無法確認官方機轉描述。根據公開已知資訊，Tildrakizumab 為抗 IL-23p19 單株抗體，核准適應症為斑塊型乾癬，透過抑制 IL-23/Th17 發炎軸達到治療效果。

TxGNN 推論此藥物與嚴重非增殖性糖尿病視網膜病變之間具有高關聯分數（99.63%），理論基礎在於 IL-23/Th17 慢性發炎路徑與糖尿病視網膜病變的血管發炎機轉存在部分理論重疊。然而，此連結完全缺乏臨床試驗或文獻佐證，僅反映知識圖譜的統計關聯強度，無法排除混雜因子或反向因果，生物學合理性尚待驗證。

### 同批次其他預測適應症

此 Evidence Pack 同時列出 4 個候選適應症，皆為 L5、Hold，機轉合理性依序遞減：

| 排名 | 預測適應症 | TxGNN 分數 | 機轉合理性摘要 |
|------|-----------|-----------|---------------|
| 2 | Diabetic Retinopathy（糖尿病視網膜病變） | 99.53% | 與 rank 1 類似的 IL-23 相關血管發炎理論連結，無實證支持 |
| 3 | Diabetic Cataract（糖尿病性白內障） | 99.21% | 白內障主機轉為晶狀體糖化/氧化壓力，與 IL-23 路徑距離較遠，合理性較弱 |
| 4 | Drug-induced Osteoporosis（藥物誘發骨質疏鬆） | 99.20% | IL-23/Th17 與 RANKL 破骨細胞活化有部分文獻理論關聯，合理性略高，但同樣零實證 |

四項候選皆無臨床試驗或文獻佐證，建議暫緩，優先補齊藥物基礎資料。

**若要推進需要：**
- 補齊 TFDA/香港衛生署仿單警語與禁忌症資料（DG001，Blocking）
