# Tildrakizumab：從（原適應症資料缺漏）到嚴重非增殖性糖尿病視網膜病變

## 一句話總結

Tildrakizumab 是一種抗 IL-23 p19 的單株抗體，在香港已有上市許可證，但目前資料中未載明其原適應症。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (severe nonproliferative diabetic retinopathy)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Tildrakizumab 是一種針對 IL-23 p19 次單位的單株抗體，可阻斷 IL-23/IL-17 發炎路徑。

有研究提出，慢性低度發炎（包括 IL-23/IL-17 軸的活性）可能參與糖尿病視網膜病變中的視網膜微血管損傷，但這個連結目前**僅屬推測**。糖尿病視網膜病變 (rank 2) 與此預測高度重疊，並非獨立的證據。

此預測的限制很明顯：
- 唯一支持是模型的高分，沒有臨床試驗或文獻。
- 大分子單株抗體經全身給藥後，眼部穿透性有限。
- 現有標準治療（抗 VEGF、雷射、皮質類固醇）的證據遠比此預測強。

其他預測的合理性也偏低：糖尿病白內障主要由多元醇路徑活化、滲透壓與氧化壓力造成，與 IL-23 抑制沒有明確關聯，可能只是圖譜中與其他糖尿病併發症共享鄰近節點所致。藥物引起的骨質疏鬆方面，IL-23/IL-17 軸雖可經 RANKL 促進破骨細胞生成，但此類骨質疏鬆主要由成骨細胞/骨細胞的直接影響與鈣代謝造成，IL-23 的角色證據薄弱。

## 安全性考量

- **藥物交互作用**：已查詢到 78 筆交互作用紀錄，以下為部分重點。
  - **重度 (Major)**：Adalimumab、Baricitinib、Certolizumab pegol、Cladribine
  - **中度 (Moderate)**：Roflumilast、Tacrolimus、Azathioprine、Cyclosporine、Anakinra、Canakinumab、Alefacept、Alemtuzumab、Denosumab，以及部分疫苗（破傷風類毒素、炭疽疫苗、霍亂活疫苗）
  - **輕度 (Minor)**：各種鋅製劑（硫酸鋅、醋酸鋅、葡萄糖酸鋅、氯化鋅）

  整體而言，多數重度與中度交互作用涉及其他免疫抑制劑或生物製劑，合併使用時需留意免疫抑制疊加。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測適應症都只有 TxGNN 模型分數支持，沒有臨床試驗或文獻，證據等級為 L5。
- 機轉連結偏推測，且單株抗體的眼部穿透性有限，現有標準治療的證據遠較強。

**若要推進需要：**
- 補齊香港許可證的核准適應症與仿單內容（警語、禁忌症）
- 補充詳細的作用機轉資料（MOA）
- 針對 IL-23/IL-17 軸在糖尿病視網膜病變的前臨床或機轉研究
- 評估全身給藥的眼部暴露量，或考慮局部給藥的可行性
- 進一步檢視是否有任何臨床前或早期臨床訊號，再重新評估
