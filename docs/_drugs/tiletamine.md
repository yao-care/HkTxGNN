# Tiletamine：從獸用製劑到失眠

## 一句話總結

Tiletamine 在香港目前僅見獸用注射劑（Zoletil）的許可證，核准適應症資料未提供。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，分數很高（99.83%）。
但目前**沒有任何臨床試驗或文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，輸入資料也未列出原適應症。以下機轉說明來自一般藥理知識，並非來自本次資料。

Tiletamine 是解離性麻醉劑，屬 NMDA 受體拮抗劑，主要在獸醫領域與 zolazepam（一種苯二氮平類藥物）組成固定複方使用。
一個合理但尚未驗證的連結是：NMDA 拮抗作用（類似 ketamine）會影響麩胺酸訊號與睡眠結構，因此模型可能據此預測其與失眠相關。

這個推論有明顯限制：
- 解離性鎮靜或麻醉不等於生理性睡眠的誘導或維持。
- 已上市複方的鎮靜效果，大部分應來自 zolazepam，機轉不同，也會混淆判讀。
- 長期或每晚使用於人體，可能有精神擬似效應與濫用風險，且缺乏人體使用的安全性資料。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有 TxGNN 模型分數，沒有臨床試驗或文獻支持（L5）。
- 香港許可證僅為獸用產品，且缺乏安全性資料與人體使用經驗，不宜推進。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料，分析與失眠之間的機轉連結。
- 取得香港衛生署的仿單，確認警語與禁忌。
- 查證 tiletamine 單方（不含 zolazepam）對睡眠的前臨床或人體資料。
- 評估精神擬似效應、濫用風險與人體使用安全性，確認是否值得進入下一階段。
- 確認是否有人用劑型與給藥途徑，目前尚無可用資料。
