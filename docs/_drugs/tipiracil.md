## Tipiracil: 盲腸絨毛狀腺瘤 (cecum villous adenoma)
{: .text-alpha }

## 一句話總結

Tipiracil 是胸苷磷酸化酶抑制劑，與 trifluridine 組成複方（Lonsurf）使用。
TxGNN 模型預測它可能對**盲腸絨毛狀腺瘤 (cecum villous adenoma)** 有效，
但目前**沒有任何臨床試驗或直接相關文獻**支持，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，tipiracil 是胸苷磷酸化酶抑制劑，在複方中的作用是抑制 trifluridine 被快速分解，以提高其血中濃度。

預測的疾病為良性結腸腺瘤，與藥物目前使用的部位同為大腸，因此模型可能是由組織位置的相近性推得此關聯。然而，目前沒有機轉或臨床證據顯示，細胞毒性治療適合用於良性病灶。

整體而言，這項預測的合理性僅建立在解剖部位的相近上，生物學上的支持薄弱，需視為假說而非可行動的結論。
