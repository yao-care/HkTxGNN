# Titanium dioxide（二氧化鈦）：從原適應症未登載到藥物性骨質疏鬆

## 一句話總結

Titanium dioxide 是一種化學性質穩定的無機顏料與紫外線遮蔽劑，香港有 1 張含此成分的許可證，但許可證未登載原適應症。
TxGNN 模型預測它可能對**藥物性骨質疏鬆 (Drug-induced Osteoporosis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Titanium dioxide 在藥品中主要作為顏料與紫外線濾光劑，沒有已知的抗骨吸收或促進骨生成活性，也找不到可信的藥理關聯。

有一點需要區分。二氧化鈦奈米管塗層可改善鈦植入物的骨整合，但那是醫材表面的效果，不能支持全身性使用來治療骨質疏鬆。

預測分數接近 1.0，較可能是知識圖譜分數飽和造成的假象，而不是由機轉推導出的訊號。因此我們不認為這個預測在機轉上合理。

此外，模型還預測了多個眼科適應症，包括糖尿病視網膜病變、各型白內障（糖尿病性、未成熟、成熟、核性老年性等）。這些預測同樣缺乏機轉與證據：
- 外用或防曬使用的全身暴露極低，也無法到達視網膜或水晶體。
- 多個白內障亞型的分數完全相同（0.99998152），顯示是疾病本體論（ontology）傳遞造成的假象，不是各亞型的特異性生物訊號。
- 嚴重非增殖性糖尿病視網膜病變很可能只是上位疾病預測的下位詞。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有模型預測（L5），沒有任何臨床試驗、文獻或可信的作用機轉支持。
- 預測分數看起來是知識圖譜的假象，不是由機轉推導出的訊號。

**若要推進需要：**
- 取得香港衛生署的仿單，確認警語、禁忌與核准適應症（目前為阻斷性缺口，無法進入安全性篩選）。
- 從 DrugBank 補充作用機轉資料。
- 先做文獻與前臨床檢索，確認是否有任何骨代謝相關的實證，再決定是否重新評估。
- 確認給藥途徑與目標適應症是否相容（目前尚未評估）。
