## Tizanidine：從 [原適應症資料缺漏] 到偏頭痛
{: .text-alpha }

## 一句話總結

Tizanidine 是中樞 α2 腎上腺素受體促效劑，在香港已有 2 張單一成分許可證，但本報告所整理的資料中沒有核准適應症文字。
TxGNN 模型預測它可能對**偏頭痛 (migraine disorder)** 有效。
目前有 **1 個直接針對偏頭痛預防的 Phase 3 臨床試驗（尚無結果）**，以及多篇相關文獻，其中包含 1 項針對慢性每日頭痛的安慰劑對照 RCT。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫中的 MOA 欄位為空）。根據藥理學一般知識，tizanidine 是中樞 α2 腎上腺素促效劑，可能降低三叉神經痛覺傳遞與中樞敏感化，並放鬆顱周肌肉緊張，因此在機轉上可能適用於偏頭痛預防。

本報告所整理的資料未載明香港許可證的核准適應症，因此無法比較原適應症與偏頭痛的關聯。在文獻方面，多篇回顧與一份巴西頭痛學會共識，將 tizanidine 列為慢性偏頭痛或頭痛預防的可考慮選項。

支持證據中最直接的是一項雙盲、安慰劑對照、多中心研究（PMID 12167135），結果顯示 tizanidine 作為輔助預防治療，對慢性每日頭痛（含慢性偏頭痛、偏頭痛樣頭痛與緊張型頭痛）具有療效。該研究對象並非嚴格限定為偏頭痛。

## 安全性考量

- **知識圖譜中記錄的禁忌關聯**（來自知識圖譜，並非仿單內容）：肝衰竭、腎臟疾病、輸尿管積膿、精神病性疾患、類精神分裂症、精神疾患、情感性精神分裂症、低血壓性疾患。
- **藥物交互作用**：共查得 100 筆，以下為部分範例。
  - 嚴重（Major）：famotidine、cimetidine、morphine、dolasetron、obeticholic acid
  - 中度（Moderate）：hyoscyamine、atropine、loperamide、clarithromycin、levofloxacin、metoclopramide、naltrexone 等

其他安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有直接針對偏頭痛預防的 Phase 3 RCT（NCT05484349），但狀態未知且無結果。
- 現有的 RCT 證據來自慢性每日頭痛，並非嚴格限定於偏頭痛。
- 另有多篇回顧與共識支持其機轉合理性。
- 安全性與仿單資料仍有缺口，故需附帶防護條件推進。

**若要推進需要：**
- 追蹤 NCT05484349 的最新狀態與結果。
- 取得香港衛生署的仿單，確認核准適應症、警語與禁忌。
- 補齊作用機轉資料。
- 評估與 famotidine、cimetidine、morphine 等嚴重交互作用藥物併用時的風險，以及肝腎功能不全、低血壓與精神疾患族群的使用限制。

**其他預測適應症（皆為 L5，建議 Hold）：**
- 伴腦幹先兆的偏頭痛
- Tourette 症候群
- 蠕蟲狀萎縮性皮膚病
- 眉部毛囊紅斑

這些預測僅有模型分數，缺乏直接研究支持。
