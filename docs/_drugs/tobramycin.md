# Tobramycin：從細菌性腦膜炎與眼部感染到暴露性角膜炎

## 一句話總結

Tobramycin 是一種胺基糖苷類（aminoglycoside）抗生素，原本用於細菌性腦膜炎、葡萄球菌感染、結膜炎及葡萄膜炎等眼部感染。
TxGNN 模型預測它可能對**暴露性角膜炎 (Exposure Keratitis)** 有效，但目前**沒有臨床試驗**，僅有 **8 篇間接相關文獻**，且多為個案報告或體外研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（資料庫未收錄）。依一般藥理知識，Tobramycin 透過結合細菌 30S 核糖體次單位來抑制蛋白質合成，已用於眼部細菌感染的局部治療。

暴露性角膜炎是眼瞼無法完全閉合造成角膜乾燥、受損的疾病，常見的併發症是繼發性細菌感染。因此從抗菌覆蓋的角度，使用 Tobramycin 在機轉上說得通。

但要注意：目前檢索到的文獻多屬一般細菌性角膜炎（隱形眼鏡相關、MRSA、多重抗藥菌等），並非針對暴露性角膜炎本身。另有一篇體外研究指出胺基糖苷類對角膜上皮有毒性，對於表面本已受損的眼睛是安全性疑慮。

## 安全性考量

- **知識圖譜中標示的相關疾病禁忌／慎用**：腎臟疾病、重症肌無力與神經肌肉接合疾病、帕金森氏症、青光眼與高眼壓、單純疱疹病毒角膜炎、病毒性／黴菌性眼部感染、眼部結核、眼部帶狀疱疹、困難梭狀芽孢桿菌結腸炎、糖尿病與糖尿病酮酸中毒、高血鈣、腎鈣化症等（此為知識圖譜關聯，非仿單原文）。
- **藥物交互作用**：共查得 100 筆，以下為部分主要項目：
  - **重大（Major）**：硫酸鎂 (Magnesium sulfate)、甘露醇 (Mannitol)
  - **中度（Moderate）**：Amphotericin B、Vancomycin、Kanamycin、Neomycin、Acetylsalicylic acid，以及多種質子幫浦抑制劑（Omeprazole、Pantoprazole、Lansoprazole 等）和 5-ASA 類藥物（Mesalazine、Sulfasalazine 等）
- **文獻提示的風險**：胺基糖苷類可能造成角膜上皮毒性，對受損的眼表面尤需留意；全身性使用時另有腎毒性與耳毒性疑慮。

仿單的警語與禁忌資料尚未取得，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何針對暴露性角膜炎的臨床試驗，文獻也只是一般細菌性角膜炎的間接證據，TxGNN 高分僅屬模型預測（證據等級 L4）。
- 胺基糖苷類的角膜上皮毒性，與暴露性角膜炎的受損眼表面形成安全性疑慮。

**若要推進需要：**
- 取得香港仿單的警語、禁忌與核准適應症資料（目前為阻斷性資料缺口）
- 補齊作用機轉資料
- 針對暴露性角膜炎進行文獻回顧，確認是否有直接證據，並評估局部抗生素與潤滑、眼瞼保護等標準處置的相對角色
- 評估角膜上皮毒性風險與劑型（眼藥水／軟膏）的適用性
- 若證據支持，設計小型探索性臨床研究

### 補充：其他預測適應症

資料中另有幾項預測，證據皆弱於暴露性角膜炎：

- **外耳炎 (Otitis externa)**，分數 99.81%，證據等級 L4：Tobramycin 對外耳炎主要致病菌（綠膿桿菌、金黃色葡萄球菌）有殺菌作用，文獻包含惡性外耳炎的個案報告，但多數為獸醫或抗藥性監測研究，無人體臨床試驗。若鼓膜穿孔需考量耳毒性。建議為「研究問題」，值得後續追蹤。
- **非人類動物疾病**（99.83%）：類別過於籠統，無法建立機轉連結，也無證據。
- **感染後血管炎**（99.80%）：屬免疫介導疾病，Tobramycin 的抗菌機轉無法針對，且胺基糖苷類有腎毒性，不建議。
- **細菌感染後疾病**（99.79%）：登記的兩個 Phase 3 試驗（NCT01069705、NCT00982930）為囊性纖維化吸入式 Tobramycin 的單臂延伸研究，屬既有適應症，與此疾病標籤無法明確對應，僅能視為間接證據。
