# Tobramycin：從眼用抗菌劑到暴露性角膜炎

## 一句話總結

Tobramycin（妥布黴素）是胺基糖苷類抗生素，在香港上市的製劑以眼用藥水和眼膏為主。
TxGNN 模型預測它可能對**暴露性角膜炎 (Exposure Keratitis)** 有效。
目前只有 **2 個臨床試驗**（相關性皆低）和 **7 篇文獻**（多為個案報告與體外研究），沒有直接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Tobramycin 屬於胺基糖苷類抗生素，對革蘭氏陰性菌（含綠膿桿菌）和葡萄球菌有抗菌活性。香港上市的製劑多為眼用劑型，機轉上可能適用於暴露性角膜炎。

暴露性角膜炎是眼瞼閉合不全造成角膜表面乾燥受損，受損的角膜上皮容易繼發細菌感染。這是模型預測的合理切入點：局部使用 tobramycin 可以處理繼發的細菌感染，但這不是針對暴露性角膜炎本身的治療。

目前沒有任何研究直接在暴露性角膜炎中測試 tobramycin。體外研究（PMID 2707046）還顯示胺基糖苷類對角膜上皮細胞有毒性，而暴露性角膜炎的上皮本來就已受損，這是需要特別留意的風險。

## 安全性考量

- **文獻提示的風險**：體外研究（PMID 2707046）顯示胺基糖苷類（含 tobramycin）對角膜上皮細胞有毒性。暴露性角膜炎的角膜上皮本來就受損，局部使用需評估是否會延遲癒合。

其餘警語、禁忌症與藥物交互作用資料目前缺乏，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.93%），但沒有任何試驗或人體研究直接測試 tobramycin 於暴露性角膜炎，既有證據僅有個案報告與體外研究。
- 已有體外證據顯示角膜上皮毒性，與暴露性角膜炎的病理背景有衝突。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症（目前為阻擋性缺口）。
- 補齊作用機轉資料（可查詢 DrugBank）。
- 設計或尋找 tobramycin 局部用於暴露性角膜炎（尤其是合併細菌感染）的對照研究，並評估其對受損上皮的影響。
- 同時評估模型的其他預測：「耳外膜炎 (otitis externa)」有 L3 文獻支持，可作為研究問題；「post-bacterial disorder」有多個 Phase 3 試驗，但疾病對應過於籠統，且試驗以囊性纖維化吸入劑型為主，需先重新對應到具體疾病。

*本報告結果僅供研究參考，不構成醫療建議；老藥新用候選需經過臨床驗證才能應用。*
