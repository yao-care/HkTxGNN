## Tobramycin：從細菌性腦膜炎與眼部感染到暴露性角膜炎
{: .text-alpha }

## 一句話總結

Tobramycin 是胺基糖苷類抗生素，知識圖譜中記錄的原適應症涵蓋細菌性腦膜炎、結膜炎、葡萄膜炎及金黃色葡萄球菌感染等。
TxGNN 模型預測它可能對**暴露性角膜炎 (Exposure Keratitis)** 有效，但目前**沒有臨床試驗**，僅有 **8 篇文獻**，且多為細菌性角膜炎病例與體外研究，並未直接研究暴露性角膜炎的治療。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Tobramycin 屬於胺基糖苷類抗生素，對革蘭氏陰性菌及金黃色葡萄球菌有抗菌活性，局部用於細菌性眼部感染。

暴露性角膜炎是眼瞼閉合不全造成角膜乾燥、受損的疾病，本身並非感染性疾病。Tobramycin 的角色僅限於預防或治療繼發性細菌感染，並非針對疾病本身。

需特別注意：檢索到的一篇體外研究顯示胺基糖苷類藥物具有角膜上皮毒性。對於上皮已受損的暴露性角膜炎，這是值得重視的安全疑慮。

## 安全性考量

- **知識圖譜記錄的禁忌關聯（非仿單文字）**：腎臟疾病、重症肌無力與神經肌肉接合部疾病、帕金森氏症、青光眼與高眼壓、單純皰疹病毒角膜炎、黴菌或病毒性眼部感染、困難梭狀芽孢桿菌結腸炎等。
- **藥物交互作用**：共查得 100 筆，以下為主要項目。
  - 重度：硫酸鎂 (Magnesium sulfate)、甘露醇 (Mannitol)
  - 中度：兩性黴素 B、萬古黴素、新黴素、康黴素、阿斯匹靈，以及多種氫離子幫浦抑制劑與水楊酸類藥物
- **文獻提示的風險**：體外研究顯示胺基糖苷類具角膜上皮毒性，應用於上皮受損的暴露性角膜炎時需審慎。

完整警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 暴露性角膜炎主要是乾燥與暴露造成的損傷，tobramycin 最多只能預防或治療繼發感染；沒有臨床試驗，文獻也多為細菌性角膜炎病例與體外資料，並未直接研究此疾病，因此證據等級為 L5。
- 角膜上皮毒性的疑慮使風險效益評估不利。

**若要推進需要：**
- 取得香港仿單的核准適應症、警語與禁忌資料
- 補充作用機轉資料
- 針對暴露性角膜炎合併細菌感染族群設計比較研究，並評估角膜上皮毒性
- 釐清與保護性治療（人工淚液、眼瞼保護）相比的附加價值
