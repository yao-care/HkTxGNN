## Tocilizumab：從類風濕性關節炎到僵直性脊椎炎
{: .text-alpha }

## 一句話總結

Tocilizumab 是一種作用於介白素-6 受體 (IL-6R) 的單株抗體，知識圖譜中記錄的已知用途包括類風濕性關節炎、幼年型特發性關節炎等發炎性關節疾病。
TxGNN 模型預測它可能對**僵直性脊椎炎 (Ankylosing Spondylitis)** 有效，目前有 **2 個已終止的 Phase 3 隨機對照試驗**，以及多篇相關文獻。
但這兩個試驗皆提前終止，文獻也顯示 IL-6 阻斷的效果不如 TNF 與 IL-17 抑制劑，因此屬於「值得研究，但尚未證實」的階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 的 MOA 欄位尚未取得）。依已知資訊，Tocilizumab 是 IL-6 受體拮抗型單株抗體，透過阻斷 IL-6 訊號傳遞來抑制發炎反應。

IL-6 被認為與脊椎關節炎的軸向發炎和骨代謝有關。Tocilizumab 與僵直性脊椎炎的連結，其分數來自 TxGNN 模型（深度學習），可能反映模型從相關疾病之間學到的相似性，並非生物學證據。

然而，這個機轉合理性尚未獲得臨床證實。兩項 Phase 3 僵直性脊椎炎試驗皆提前終止，且文獻描述 IL-6 阻斷在此疾病的效果不及 TNF 與 IL-17 抑制劑。因此這個預測屬「機轉上可行，臨床上未確認」。

## 安全性考量

- **藥物交互作用**：已查詢到 100 筆交互作用紀錄，以下列出部分具代表性者：
  - 嚴重 (Major)：Deferiprone
  - 中度 (Moderate)：Warfarin、Apixaban、Rivaroxaban、Dicoumarol、Simvastatin、Rosuvastatin、Hydroxychloroquine、Chloroquine、Metronidazole、Naltrexone、Disulfiram、Lidocaine
  - 輕微 (Minor)：多種鋅製劑（硫酸鋅、醋酸鋅、葡萄糖酸鋅、氯化鋅）

文獻也指出，生物製劑會增加感染風險（含結核病），使用前需要篩檢。其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 兩項直接測試僵直性脊椎炎的 Phase 3／Phase 2/3 對照試驗都提前終止，無法支持正向療效結論，且文獻顯示 IL-6 阻斷不及 TNF 與 IL-17 抑制劑；目前較適合作為研究問題，不宜直接推進臨床使用。
- 香港許可證資料未載明核准適應症文字，也缺少仿單的警語與禁忌症，安全性評估尚不完整。

**若要推進需要：**
- 取得兩項已終止試驗的完整結果與終止原因，確認是療效不足、安全性問題還是其他因素
- 取得香港仿單（警語、禁忌症、核准適應症）以完成安全性篩查
- 補充詳細的作用機轉資料（MOA）
- 評估在 TNF 與 IL-17 抑制劑已有明確地位下，Tocilizumab 是否有特定的目標族群（例如合併 AA 類澱粉變性者）

### 其他預測適應症備註

- **發炎性脊椎病變 (Inflammatory Spondylopathy)**：證據主要借用自僵直性脊椎炎的同一批試驗，並非獨立證據，結論相同。
- **尾骨過度活動 (Hypermobility of Coccyx)**、**Kummell 病**：無臨床試驗與文獻，機轉上也無明確 IL-6 關聯，僅為模型預測，證據等級 L5，建議 Hold。
- **脊椎疾病 (Vertebral Disease)**：此為廣泛類別，檢索到的文獻多與類風濕性關節炎等相關，並未直接研究此疾病，等同無直接研究，證據等級應視為 L5，建議 Hold。
