# Tolperisone：從中樞性肌肉鬆弛劑到 Laubry-Pezzi 症候群

## 一句話總結

Tolperisone 是一種中樞作用的肌肉鬆弛劑，香港許可證未載明核准適應症。
TxGNN 模型預測它可能對 **Laubry-Pezzi 症候群 (Laubry-Pezzi syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，且機轉上找不到合理關聯。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。依評估內容，Tolperisone 是中樞作用的肌肉鬆弛劑，會阻斷電壓門控鈉離子與鈣離子通道。

Laubry-Pezzi 症候群是先天性心臟疾病（心室中隔缺損合併主動脈瓣逆流），屬於結構性問題，主要靠手術處理。肌肉鬆弛或離子通道阻斷，並沒有已知的途徑能修正這類結構缺陷。

因此，**這個預測目前找不到合理的機轉連結**。0.9992 的高分很可能是知識圖譜的假象：同類先天性疾病在圖譜上彼此相近，推高了分數，與藥理無關。排名前 10 的預測大多是先天性心臟或顱顏畸形，也呈現同樣的模式。

**心臟病（排名 8）的 3 篇文獻**：
- 1983 年大鼠實驗：測試神經與精神作用藥物對麩胺酸鈉誘發心律不整的影響（PMID [6869689](https://pubmed.ncbi.nlm.nih.gov/6869689/)），屬前臨床研究。
- 2018 年病例報告：討論醛固酮受體阻斷與慢性心衰竭（PMID [30295205](https://pubmed.ncbi.nlm.nih.gov/30295205/)），與 Tolperisone 無直接關係。
- 1981 年病例報告：多種藥物（含 Tolperisone）過量後疑似惡性高熱（PMID [6117987](https://pubmed.ncbi.nlm.nih.gov/6117987/)），屬於安全性訊號，並非療效證據。

「心臟病」一詞太籠統，最多只能用來產生針對特定心臟表型的研究假設。

## 安全性考量

安全性資訊請參考原廠仿單。

補充：藥物交互作用查詢無結果。1981 年的過量病例報告提示，多藥過量可能出現類似惡性高熱的反應（僅為單一病例）。Pierre Robin 症候群相關預測若被考慮，需留意肌肉鬆弛可能加重呼吸道問題。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有預測都只有模型分數，沒有任何臨床試驗，也沒有支持主預測的文獻。
- 主預測及多數排名靠前的預測在機轉上沒有合理關聯，高分很可能是知識圖譜的假象。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語、禁忌症與核准適應症（目前是阻擋性缺口）
- 補齊 DrugBank 的作用機轉資料
- 若仍想探索心臟方向，先界定具體的心臟表型，再做文獻回顧與機轉驗證
