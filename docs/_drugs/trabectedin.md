# Trabectedin：從卵巢癌到女性乳癌

## 一句話總結

Trabectedin（曲貝替定）是一種源自海洋生物的抗腫瘤藥物，原本用於卵巢癌治療。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效，
目前有 **1 個臨床試驗**登記（但為 QT 間期安全性研究，非療效試驗）和 **20 篇文獻**，其中包含數項乳癌的 Phase 2 研究。

## 為什麼這個預測合理？

目前缺乏來自原始資料的詳細作用機轉記錄，以下機轉說明是根據文獻推論。Trabectedin 會結合 DNA 小溝並使鳥嘌呤 N2 烷基化，造成 DNA 損傷，這些損傷須經由轉錄偶聯核苷酸切除修復處理。同源重組缺陷的細胞（例如 BRCA1/2 突變的乳癌腫瘤）據報告對此藥特別敏感。

卵巢癌與乳癌在 BRCA 相關的 DNA 修復缺陷上有共同的生物學基礎。文獻亦指出，Trabectedin 可減少腫瘤相關巨噬細胞 (TAM)，調節腫瘤微環境，前臨床研究顯示它可能增強 IL-12 在三陰性乳癌中的免疫治療效果。

需要注意的是，TxGNN 的高分 (0.997) 屬於計算預測，不能取代臨床證據。

## 安全性考量

- **藥物交互作用**：資料庫共查得 100 筆交互作用，其中部分重點如下：
  - 重大 (Major)：Clarithromycin
  - 中度 (Moderate)：Aprepitant、Dexamethasone、Cimetidine、Metronidazole、Miconazole、Levofloxacin、Simvastatin、Rosuvastatin 等

  使用時應留意併用藥物，尤其是會影響肝臟代謝酵素的藥物。

- **QT 間期**：已有專門研究評估 Trabectedin 對晚期實體腫瘤患者 QT 間期的影響（NCT00786838 與 PMID 21739119），臨床使用時可留意。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 乳癌方面已有數項 Phase 2 單臂或隨機方案比較研究，且機轉（HR 缺陷敏感性、調節腫瘤微環境）具合理性，但登記的臨床試驗屬 QT 安全性研究，並無確認的療效結果，也沒有已完成的 Phase 3 RCT，目前證據等級為 L3，屬研究假說階段。
- 香港許可證資料未載明核准適應症，且安全性警語與禁忌症資料缺漏，尚不足以進入安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與核准適應症
- 補充 DrugBank 的作用機轉資料
- 逐篇核實乳癌 Phase 2 研究（PMID 25239225、24692579、27266804）的療效結果，特別是 BRCA1/2 突變族群
- 確認是否有以乳癌為主要適應症的療效試驗，並評估 Phase 3 設計的可行性
- 制定血液學與肝功能監測及 DDI 管理計畫
