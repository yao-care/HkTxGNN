# Trastuzumab emtansine：從 HER2 陽性乳癌到黃體素受體陽性乳癌

## 一句話總結

Trastuzumab emtansine (T-DM1) 是抗 HER2 抗體藥物複合體 (ADC)，目前已核准用於 HER2 陽性乳癌治療。TxGNN 模型將「黃體素受體陽性乳癌 (PR+)」列為預測新適應症，但目前僅有 **4 個相關臨床試驗**、**無直接文獻支持**，且證據本身指出這實質上是既有 HER2+ 適應症的亞群重疊，並非真正的機轉延伸假說。

## 為什麼這個預測合理？

目前缺乏 Trastuzumab emtansine 的詳細作用機轉資料（Data Gap）。但根據證據內文與多篇文獻交叉比對，T-DM1 是抗 HER2 單株抗體與微管抑制劑 DM1 (mertansine) 的抗體藥物複合體，已核准用於 HER2 陽性乳癌，透過抗體導向遞送細胞毒殺酬載至 HER2 表現腫瘤細胞。

然而，此次預測的「黃體素受體 (PR) 陽性乳癌」與 HER2 陽性狀態在機轉上並無直接關聯——PR 是獨立於 HER2 的受體路徑，兩者僅在臨床上常有共同表現（HER2+/HR+ 亞群）。證據自身的評估明確指出：這個「新適應症」實質上是 T-DM1 既有 HER2+ 乳癌適應症下的一個亞群，屬於標籤內重疊，而非真正意義上的機轉延伸或老藥新用候選。

換言之，TxGNN 給出的高分（99.82%）較可能反映知識圖譜中 HER2+ 與 PR+ 乳癌節點的高度共現，而非獨立的新機轉假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測適應症（PR+ 乳癌）證據等級僅 L2，且證據本身評估認為這是既有 HER2+ 乳癌適應症的亞群重疊，而非獨立的新機轉假說；無文獻支持，臨床試驗多非直接測試此族群。
- 安全性資料存在 Blocking 等級缺口（仿單警語/禁忌未知），無法完成 S1 安全性初評。

**若要推進需要：**
- 補齊 TFDA/藥監局仿單警語與禁忌症資料（DG001，Blocking）
- 補齊作用機轉 (MOA) 詳細資料（DG002，High）
- 若欲在同批候選中尋找更具實質意義的研究方向，建議評估同一 Evidence Pack 中 **rank 3「黃體素受體陰性乳癌 (PR-)」**——該候選證據等級達 L1、決策階段 S3，建議為 Proceed with Guardrails，具多項直接測試 T-DM1 的 Phase 2/3 RCT 支持，機轉與 HER2+ 族群高度共存，較本候選更具參考價值。
