# Tremelimumab：從腫瘤免疫治療到糖尿病白內障

## 一句話總結

Tremelimumab 是 CTLA-4 阻斷型單株抗體，在香港以 IMJUDO 品名上市，用於腫瘤免疫治療。
TxGNN 模型預測它可能對**糖尿病白內障 (Diabetic Cataract)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅為模型運算結果。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Tremelimumab 是 CTLA-4 阻斷型單株抗體，用於腫瘤免疫治療，其作用是解除 T 細胞的免疫抑制、增強抗腫瘤免疫反應。

白內障是水晶體的退化性疾病，主要由氧化壓力與滲透壓失衡造成，與 T 細胞檢查點訊號無關。因此**機轉上找不到支持的連結**。高分的預測較可能來自知識圖譜中與糖尿病、白內障節點的鄰近性，而非生物學理由。

此外，免疫檢查點抑制劑較常與眼部免疫相關不良反應（如葡萄膜炎）有關，而非眼部益處。

同一批預測中，其他白內障類型（第二型糖尿病相關白內障、未成熟、成熟、核性老年性、皮質性、老年性、顱縫早閉性、手足搐搦性白內障）以及糖尿病視網膜病變，分數介於 98.2%–98.5%，同樣沒有臨床試驗或文獻，也同樣缺乏機轉依據。

## 結論與下一步

**決策：Hold**

**理由：**
預測僅來自模型運算，沒有臨床試驗與文獻支持，機轉上也無合理連結，且檢查點抑制劑有眼部免疫相關不良反應的風險。目前不建議推進。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料（目前為阻擋性缺口，無法進入安全性篩選）
- 補充 DrugBank 作用機轉資料，重新檢視機轉連結
- 找到支持 CTLA-4 阻斷與水晶體或視網膜病變之間關聯的前臨床或臨床證據
- 若無上述證據，建議將此預測視為模型假陽性，不再投入資源
