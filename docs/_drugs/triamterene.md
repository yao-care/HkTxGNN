# TRIAMTERENE：原適應症資料缺口 → 預測新適應症「惡性腎血管性高血壓」

## 一句話總結

TRIAMTERENE（Triamterene）是保鉀性利尿劑，但本 Evidence Pack 中**原適應症資料缺失**、且**香港未上市**（0 張許可證）。
TxGNN 模型預測它可能對**惡性腎血管性高血壓 (Malignant Renovascular Hypertension)** 有效，
但目前**無任何臨床試驗、無相關文獻**支持，屬於純模型推論，尚無法進入安全性評估階段。

## 為什麼這個預測合理？

目前缺乏 Triamterene 詳細的作用機轉（MOA）官方資料，此為 **Blocking / High** 等級的資料缺口（DG001、DG002），需分別透過 TFDA/香港藥監機構仿單與 DrugBank API 補齊，才能進行機轉關聯性分析與安全性初評。

根據 Evidence Pack 內部提供的機轉推論，Triamterene 屬於上皮鈉離子通道（ENaC）阻斷劑／保鉀性利尿劑，理論上可透過影響腎素-血管張力素-醛固酮系統（RAAS）下游效應輔助血壓控制。這是此預測背後唯一的機轉假說，**純屬 TxGNN 知識圖譜拓樸相似性推論，並無任何直接臨床或文獻資料支持**。

值得特別注意的是：惡性高血壓腎病常合併**高鉀血症風險**，與 Triamterene 的保鉀特性存在潛在安全性衝突。在缺乏 MOA 與安全性仿單資料的情況下，此預測的風險面尚無法評估，應優先於效益面之前處理。

## 結論與下一步

**決策：Hold**

**理由：**
- 本候選預測適應症之證據等級為 **L5**（僅有模型分數，無臨床試驗或文獻佐證），未達最低可推進門檻。
- 藥物層級存在 **Blocking 等級資料缺口**（仿單警語/禁忌症缺失），依規則無法進入 S1 安全性初評。
- 惡性腎血管性高血壓與 Triamterene 保鉀機轉存在理論上的高鉀血症安全性疑慮，需先釐清風險才能談效益。

**品質提醒（其他候選適應症）：**
- Rank 3「pulmonary hypertension owing to lung disease and/or hypoxia」檢索到的 20 篇文獻經人工核對均為 "hypoxia" 關鍵字誤配之基礎生物學/腫瘤研究，**與本藥物或該適應症無實質關聯**，屬假陽性文獻匹配，應於下一輪流程中排除或加強篩選條件。
- Rank 5「Braddock (CHOPS) syndrome」為罕見遺傳性發育症候群，病因與轉錄調控相關，與利尿劑機轉無已知病理生理連結，建議視為模型雜訊，不建議投入後續資源。

**若要推進需要：**
- 取得 TFDA／香港衛生署官方仿單，補齊警語、禁忌症資料（DG001，Blocking）
- 透過 DrugBank API 查詢完整 MOA 資料（DG002，High）
- 針對惡性腎血管性高血壓，補充至少 L3 等級（觀察性研究或系統性回顧）之直接證據
- 若無法補齊上述資料，建議暫緩本候選之後續開發評估
