# Triclocarban：從外用抗菌成分到偏頭痛 (Migraine Disorder)

## 一句話總結

Triclocarban 是一種常見於皂類產品的外用抗菌劑，目前並無正式核准的全身性治療適應症資料。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效（分數 99.27%），
但目前**沒有任何臨床試驗或文獻**支持這個方向，純屬知識圖譜統計關聯。

## 為什麼這個預測合理？

目前缺乏 Triclocarban 詳細的作用機轉（MOA）資料。根據 Evidence Pack 提供的背景資訊，Triclocarban 是一種外用抗菌劑，主要作為皂類產品中的防腐/抗菌成分使用，並非全身性治療藥物。

偏頭痛的病理機轉涉及神經血管系統與中樞神經傳導路徑，與 Triclocarban 已知的抗菌作用機轉在生物學上並無明顯關聯。TxGNN 的高分數（0.993）僅反映知識圖譜中的節點連結強度，並不代表藥理機轉上的合理性。

此外，Triclocarban 在公開毒理學文獻中已知具內分泌干擾（endocrine disruption）疑慮，這與「治療」偏頭痛的方向並不一致，反而提示在推進此假說前，須優先排除潛在的安全性風險，而非直接假設具治療效益。

## 結論與下一步

**決策：Hold**

**理由：**
- 偏頭痛此一預測適應症缺乏任何臨床試驗或文獻證據，證據等級僅為 L5（純模型預測）。
- 原始藥物作用機轉（MOA）與 TFDA 安全性資料皆為缺口（Data Gap），且後者屬 Blocking 等級，無法進行任何安全性初評。
- Triclocarban 已知具內分泌干擾疑慮，在缺乏機轉解釋的情況下貿然推進具潛在風險。

**若要推進需要：**
- 取得 Triclocarban 的作用機轉資料（DrugBank API 查詢）
- 取得完整仿單警語與禁忌症資料（TFDA 官網下載解析）
- 尋找是否有任何動物實驗或體外研究支持 Triclocarban 與偏頭痛病理路徑的關聯
- 釐清內分泌干擾疑慮是否會與此適應症方向產生安全性衝突
