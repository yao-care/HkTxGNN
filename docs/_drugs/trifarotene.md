# Trifarotene：從尋常性痤瘡到血漿鋅濃度升高 (Zinc, Elevated Plasma)

## 一句話總結

Trifarotene 是外用的選擇性 RAR-γ（視黃酸受體 γ）促效劑，原本用於尋常性痤瘡。
TxGNN 模型預測它可能對**血漿鋅濃度升高 (zinc, elevated plasma)** 有效，但目前**沒有任何臨床試驗或文獻**支持，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏 DrugBank 的詳細作用機轉資料。根據已知資訊，Trifarotene 是外用的選擇性 RAR-γ 促效劑，作用於皮膚毛囊與表皮角質細胞，調節角質化與發炎，全身暴露量極低。

就機轉而言，**目前找不到合理的關聯**。沒有已知的途徑把 RAR-γ 促效作用和血漿鋅的調節連在一起。外用劑型的全身吸收很少，也很難影響血中鋅濃度。

0.994 的高分很可能是知識圖譜的統計假象，並非真實的生物學訊號。分數高不代表值得投入資源，實際判斷要看臨床與文獻證據，而這兩者目前都是空白。

## 結論與下一步

**決策：Hold**

**理由：**
- 只有模型預測，沒有試驗或文獻，證據等級為 L5。
- 機轉上沒有可信的關聯，外用且全身暴露極低，影響血漿鋅的可能性很低。

**若要推進需要：**
- 取得 DrugBank 的作用機轉資料，確認是否存在任何與鋅代謝相關的途徑。
- 取得香港衛生署仿單的警語與禁忌症，以進行安全性篩選。
- 先有前臨床或觀察性證據，說明 RAR-γ 與鋅調節的關係，才值得重新評估。

**其他排名較前的預測（僅供研究參考）：**
- **PAPA 症候群（化膿性關節炎-壞疽性膿皮症-痤瘡）**：間接且薄弱。只有痤瘡皮損可能與核准用途重疊，核心的自體發炎病理無法由外用藥處理。
- **皮脂腺蠕形蟎症 (Demodicidosis)**：機轉上合理但未經證實。Trifarotene 沒有殺蟎活性，最多改善症狀，且視黃酸類的刺激性可能使病情惡化。
- 其餘預測（脊椎關節病變、瘧疾、Zollinger-Ellison 症候群等）皆無可信關聯，均建議 Hold。

本報告僅供研究參考，不構成醫療建議；老藥新用候選需經臨床驗證後才能應用。
