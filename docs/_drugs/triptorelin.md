# TRIPTORELIN：原適應症資料缺失，預測適應症為多毛症 (Hypertrichosis)

## 一句話總結

Triptorelin（DrugBank ID: DB06825）是一種 GnRH 促效劑，但本證據包中未收錄其原適應症與許可證資料，且藥品尚未於香港上市。
TxGNN 模型預測它可能對**多毛症 (Hypertrichosis)** 有效，
但目前僅有 **1 篇文獻**支持，且該文獻實質上是**反例**（顯示性腺抑制未能預防藥物誘發之多毛症），證據極為薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料，且原適應症紀錄也未收錄於本證據包中，無法比對原適應症與預測新適應症之間的臨床關聯性。

根據 TxGNN 提供的機轉推論，Triptorelin 為 GnRH 促效劑，長期使用會抑制垂體-性腺軸、降低睪固酮/雌激素分泌，理論上可能影響雄性素依賴性的毛髮生長模式。但唯一引用的文獻（PMID 41822646）描述的是一位接受「睪固酮阻斷劑」治療的跨性別女性，因合併使用 ciclosporin 而誘發全身性多毛症——這代表**性腺抑制並未能預防多毛症的發生**，方向與預測假設相反，屬於反例而非支持性證據。

其餘 4 個候選適應症（Ambras 型先天性全身多毛症、齒列畸形症候群、Dandy-Walker 畸形、遺傳性毛幹結構異常）皆屬先天性/遺傳性結構疾病，病理機轉與 GnRH 促效劑的性腺軸調控作用無已知關聯，且完全無臨床試驗或文獻支持，判定為模型預測雜訊。

## 結論與下一步

**決策：Hold**

**理由：**
- 5 個預測適應症的證據等級均為 L5，rank 1（多毛症）唯一的文獻證據實質上是反例，其餘 4 個適應症完全無臨床或文獻支持，機轉關聯性薄弱甚至不合理（如先天性顱腦或毛幹結構異常與 GnRH 機轉無關）。
- 藥品尚未於香港上市（0 張許可證），原適應症、MOA、安全性警語與禁忌症皆屬資料缺口，其中仿單警語/禁忌屬 Blocking 等級，已阻斷進入 S1 安全性初評。

**若要推進需要：**
- 補齊當地藥監局（如 TFDA）仿單警語與禁忌症資料（DG001，Blocking）
- 查詢 DrugBank API 取得完整作用機轉資料（DG002）
- 補充原適應症與許可證/上市狀態資料
- 若持續評估多毛症方向，需取得直接研究 triptorelin（而非合併睪固酮阻斷劑整體療法）與毛髮生長調控關係的證據，目前唯一文獻方向與假設相反
