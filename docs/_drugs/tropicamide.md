# Tropicamide：從眼科散瞳劑到馬尾症候群

## 一句話總結

Tropicamide 是短效抗蕈毒鹼（muscarinic antagonist）眼科用藥，原本用於散瞳與睫狀肌麻痺檢查。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，
但目前**沒有任何臨床試驗或文獻支持**，且此預測極可能是知識圖譜的偽陽性關聯。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉正式資料（Evidence Pack 標註為 Data Gap）。根據已知資訊，Tropicamide 是短效抗蕈毒鹼藥物，阻斷 M3/M4 蕈毒鹼受體，僅作為眼科局部用藥使用於散瞳與睫狀肌麻痺，並無全身性投藥的藥動學或安全性資料。

馬尾症候群的病理機轉是神經根受結構性壓迫導致的神經傳導阻斷（外科急症），與蕈毒鹼受體訊號異常無直接關聯。**此預測很可能是 TxGNN 知識圖譜透過「神經性膀胱功能障礙」節點產生的偽陽性關聯**——馬尾症候群常見症狀包含神經性膀胱，模型可能因此節點的共現關係誤判出高分數，而非真正捕捉到藥理上的因果機轉。

值得一提的是，該藥物候選清單中另有兩個排名較低但機轉合理性較高的預測：神經性膀胱（obsolete neurogenic bladder，rank 2）與大腸激躁症（IBS，rank 3）。這兩者屬於抗蕈毒鹼藥物的傳統適應症類別（逼尿肌/腸道平滑肌 M3 受體阻斷），具有類別層級的機轉合理性，但同樣缺乏臨床試驗與文獻佐證，且神經性膀胱疾病節點本身標註為「obsolete」（本體已棄用術語），需留意映射品質問題。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的預測適應症（馬尾症候群）缺乏臨床試驗、文獻及機轉上的直接支持，且證據包內的機轉分析本身已指出這極可能是知識圖譜偽陽性關聯（經由神經性膀胱節點產生），不具備推進的科學合理性。
- 證據等級為 L5（僅有模型預測，無任何實際研究佐證），且該藥物在香港未上市，缺乏本地安全性與法規資料，無法進入下一階段初評。

**若要推進需要：**
- 取得 Tropicamide 正式 MOA 與原始適應症之官方仿單資料，補齊 Data Gap
- 若考慮探索抗蕈毒鹼類別層級的其他適應症（如神經性膀胱、IBS），建議改以已核准之全身性抗蕈毒鹼藥物（如 oxybutynin、hyoscine butylbromide）作為主要研究標的，而非局部散瞳劑
- 重新檢視 TxGNN 知識圖譜中經由症狀共現節點（如神經性膀胱）產生的關聯，評估是否需要調整模型以降低此類偽陽性
