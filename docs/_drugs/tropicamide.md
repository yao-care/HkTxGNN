# Tropicamide：從眼科散瞳到脊髓馬尾症候群

## 一句話總結

Tropicamide 是眼科局部使用的抗蕈毒鹼類藥物，香港有 3 張眼用溶液許可證。
TxGNN 模型預測它可能對**脊髓馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Tropicamide 是局部眼用的蕈毒鹼受體拮抗劑，以下機轉推論來自藥物類別，並非 DrugBank 的 MOA 記載。

馬尾症候群的核心病理是神經根受壓，需要緊急手術減壓。抗蕈毒鹼藥物最多只能透過抑制膀胱逼尿肌過度活動，改善併發的神經性膀胱症狀。這是症狀治療，無法處理壓迫本身，所以兩者之間沒有直接的機轉關聯。此外，眼用劑型的全身暴露量很低，TxGNN 的高分只是圖譜層面的預測。

同一份預測還有另外兩個候選，證據同樣是 L5、建議同樣是 Hold：

- **神經性膀胱（本體論中已標為過時的術語）**：抗蕈毒鹼藥物如 oxybutynin、tolterodine 已是神經性逼尿肌過度活動的標準治療，類別層級合理（分數 99.13%）。但 tropicamide 沒有口服或膀胱內劑型，也沒有相關藥動學資料，且疾病術語需改對應到現行用語（如 neurogenic detrusor overactivity）。
- **大腸激躁症**：hyoscine、dicyclomine 等抗痙攣藥已用於腹痛，類別層級合理（分數 99.12%）。但 tropicamide 作用時間短、全身吸收極少，除非開發新劑型，否則不太可能對腸道有效。現有抗蕈毒鹼藥物已涵蓋此用途，重新開發的附加價值不明。

## 結論與下一步

**決策：Hold**

**理由：**
三個預測適應症都只有模型分數，沒有任何臨床試驗或文獻佐證，證據等級為 L5。Tropicamide 只有短效眼用劑型，全身暴露低，缺乏可到達目標器官的劑型。對於馬尾症候群，即使機轉成立也只能緩解症狀，不能取代手術減壓。

**若要推進需要：**
- 取得香港衛生署仿單，確認警語與禁忌症
- 補齊 DrugBank 的作用機轉資料
- 將「obsolete neurogenic bladder」重新對應到現行疾病術語
- 評估是否有全身性或膀胱內劑型，並取得相關藥動學資料
- 針對神經性膀胱或大腸激躁症，與已核准的抗蕈毒鹼藥物比較附加價值
- 系統性搜尋 tropicamide 在上述適應症的臨床與前臨床研究

> 本報告僅供研究參考，不構成醫療建議。老藥新用候選需經臨床驗證才能應用。
