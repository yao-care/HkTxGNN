# TRYPTOPHAN：從（尚無核准適應症）到不寧腿症候群

## 一句話總結

> TRYPTOPHAN（色胺酸）目前在香港**尚未取得藥品許可證**（0 張許可證），無正式核准適應症資料。
> TxGNN 模型預測它可能對**不寧腿症候群（Restless Legs Syndrome）**有效，

## 為什麼這個預測合理？

目前缺乏 TRYPTOPHAN 詳細的作用機轉（MOA）資料。根據藥理學共識，Tryptophan 是必需胺基酸，也是血清素（serotonin）與褪黑激素（melatonin）生合成的前驅物質，此路徑機轉廣為文獻證實。

然而，將此機轉直接套用到不寧腿症候群存在方向性疑慮。RLS 的主流病理生理機轉被認為與**多巴胺功能失調**有關，而非血清素不足。文獻回顧顯示，會提高血清素活性的藥物（如鋰鹽、抗憂鬱藥）反而可能**誘發或惡化** RLS 症狀（PMID 32546134、PMID 1777530），這與「補充血清素前驅物可改善 RLS」的假設方向相反。

另一方面，1986 年一篇小型臨床試驗（PMID 3953904）曾報告 L-Tryptophan 對 RLS 有治療效果，顯示過去確實存在正向訊號，但該研究規模小、年代久遠，且後續缺乏重複驗證，現有證據仍不足以支持明確的機轉關聯性。

## 結論與下一步

**決策：Research Question（研究性問題）**

**理由：**
- 目前僅有 L3 等級證據（1 篇小型臨床試驗、系統性回顧與多篇個案/回顧文獻），且機轉方向與 RLS 主流的多巴胺假說存在衝突，加上香港尚無 TRYPTOPHAN 藥品許可證，現階段不足以支持積極開發。

**若要推進需要：**
- 補齊 TRYPTOPHAN 作用機轉（MOA）及安全性仿單資料（目前皆為資料缺口）
- 執行機轉層級研究，釐清血清素路徑與 RLS 病理生理（多巴胺功能失調）之間的相容性
- 若考慮申請香港藥品許可證，需先取得完整的臨床前與安全性資料
