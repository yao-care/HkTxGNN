# Tyrosine（酪胺酸）：從營養輸液成分到馬尾症候群 (Cauda Equina Syndrome)

## 一句話總結

Tyrosine 是胺基酸，在香港主要作為營養輸液與胺基酸製劑的成分上市。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前只有 **0 個臨床試驗**和 **1 篇不相關的病例報告**，證據僅停留在模型預測層級。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Tyrosine 是兒茶酚胺（多巴胺、正腎上腺素）、甲狀腺素與黑色素的前驅物。香港的相關產品多為胺基酸營養輸液，其中的 Tyrosine 是作為營養成分，而非針對特定疾病的治療成分。

馬尾症候群是脊髓末端神經根受壓迫或損傷造成的疾病，與 Tyrosine 的代謝角色之間沒有可信的機轉連結。目前唯一檢索到的文獻，是 S1 神經根透明細胞肉瘤（黑色素譜系腫瘤）的病例報告。它屬於診斷病理描述，並未測試 Tyrosine 治療。因此 99.77% 的高分只能視為模型預測，不能當作療效證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 馬尾症候群的預測沒有任何臨床試驗，文獻只有一篇與 Tyrosine 無關的病例報告，也沒有可信的作用機轉，證據等級為 L5。
- 同批預測的其他候選（青光眼、甲狀腺功能亢進、姿勢性直立心搏過速症候群等）也同樣是 Hold。其中不少檢索結果是把 "tyrosine kinase inhibitor" 誤配成 "tyrosine" 的關鍵字假象，其機轉也有相反方向的疑慮。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌症，才能進入安全性篩選。
- 從 DrugBank 補齊作用機轉資料，並評估與馬尾症候群之間是否存在任何機轉連結。
- 目前沒有任何研究以 Tyrosine 作為馬尾症候群的治療介入，建議先做文獻與前臨床探索，確認有合理依據再考慮規劃臨床研究。
