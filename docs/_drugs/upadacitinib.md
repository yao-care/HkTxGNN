# Upadacitinib：從自體免疫發炎疾病到缺損性小眼症合併肢短骨骼發育異常症候群（機轉關聯性存疑）

## 一句話總結

Upadacitinib（DrugBank ID: DB15091）是一款 JAK1 選擇性抑制劑，目前主要應用於自體免疫發炎疾病。
TxGNN 模型本次預測其可能對**缺損性小眼症合併近端肢短骨骼發育異常症候群**（colobomatous microphthalmia-rhizomelic dysplasia syndrome）有效，
但目前**無任何臨床試驗、無任何文獻證據**支持，且機轉分析判定此關聯性極低，可能為模型拓樸鄰近性造成的偽陽性。

## 為什麼這個預測合理？

**結論：目前證據不支持此預測的機轉合理性。**

Upadacitinib 是選擇性 JAK1 抑制劑，作用於細胞因子訊號傳導，主要應用於自體免疫發炎疾病。而本次排名第一的預測適應症——缺損性小眼症合併近端肢短骨骼發育異常症候群——是一種先天性眼部發育缺陷合併近端肢短骨骼發育異常的罕見遺傳症候群，病因通常涉及胚胎期眼裂閉合基因（如 PAX6、SHH 通路）或過氧化體/骨骼發育相關基因突變。

這是一種**結構性先天發育疾病**，而非發炎或免疫介導的病理過程，與 JAK1 抑制劑的抗發炎/免疫調節機轉並無已知生物學關聯。Evidence Pack 本身的機轉分析已明確指出：「txgnn_score 高分應視為知識圖譜拓樸鄰近性所致，缺乏機轉合理性支持」。

排名第二的預測適應症「短指併指症候群」（brachydactyly-syndactyly syndrome）情況類似——病因多與 BMP/FGF 訊號通路或肢芽發育基因（HOXD、GLI3）突變相關，同屬結構性發育疾病，與 JAK1 抑制之免疫調節機轉無合理連結，同樣被判定為「模型預測偽陽性可能性高」。

## 結論與下一步

**決策：Hold**

**理由：**
- 兩個預測適應症皆為罕見遺傳性結構發育疾病，與 Upadacitinib 之 JAK1 選擇性抑制機轉缺乏已知生物學關聯，Evidence Pack 內部機轉分析已明確標註為可能的模型偽陽性。
- 證據等級僅為 L5（無任何臨床試驗或文獻支持），且藥物本身尚未在香港上市，MOA 與安全性資料均存在關鍵缺口。

**若要推進需要：**
- 補齊 TFDA/當地藥監局仿單警語與禁忌症資料（DG001，Blocking，方法：下載仿單 PDF 解析）
- 取得 DrugBank API 完整 MOA 資料（DG002，High）
- 若日後出現任何臨床前研究、動物模型或病例報告支持此連結，應重新評估機轉合理性
- 建議優先檢視 TxGNN 對該藥物其他機轉上更合理（如自體免疫/發炎相關）的預測候選，而非依賴目前這兩個拓樸分數偏高但生物學上不合理的候選
