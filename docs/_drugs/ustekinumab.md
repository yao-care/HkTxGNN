## Ustekinumab：從乾癬到皮膚炎
{: .text-alpha }

## 一句話總結

Ustekinumab 是針對 IL-12/IL-23 的單株抗體，知識圖譜中記錄的原適應症為乾癬性關節炎、乾癬與類乾癬。
TxGNN 模型預測它可能對**皮膚炎 (dermatitis)** 有效，目前有 **6 個相關臨床試驗登記**和 **20 篇文獻**，其中直接針對異位性皮膚炎的有 2 個 Phase 2 試驗與數篇文獻。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記載。根據已知資訊，ustekinumab 會阻斷 IL-12 與 IL-23 共有的 p40 次單元，抑制 Th1 與 Th17/Th22 路徑。這些路徑與乾癬相關，也參與部分皮膚炎的發病，特別是帶有 Th1/Th17 特徵的慢性異位性皮膚炎。

不過，異位性皮膚炎主要由 Th2 路徑（IL-4/IL-13）驅動，因此機轉契合度只是部分成立。已發表的 Phase 2 資料顯示療效有限且結果不一致，這也是本報告不建議直接推進的主因。

其他預測對象（如多種皮肌炎、類苔蘚糠疹等）僅有模型預測，沒有臨床試驗或文獻支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前有兩個針對異位性皮膚炎的 Phase 2 試驗與相關文獻，但樣本小，結果被描述為療效有限且不一致。由於 Phase 2 證據為主、未見 Phase 3 確證，不建議直接推進。
- 其餘預測適應症僅有模型預測，缺乏任何臨床證據。

**若要推進需要：**
- 取得原廠仿單中的警語、禁忌與核准適應症文字，補足安全性與香港核准範圍資料
- 查證 NCT01945086 與 NCT01806662 的完整結果，確認主要終點與療效幅度
- 釐清可能受益的亞群（例如 Th1/Th17 特徵明顯的慢性異位性皮膚炎）
- 補充作用機轉資料，並與現有異位性皮膚炎標準治療比較
