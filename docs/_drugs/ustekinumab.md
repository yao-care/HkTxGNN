# Ustekinumab：從乾癬性關節炎／乾癬到皮膚炎

## 一句話總結

Ustekinumab 是 IL-12/23 拮抗劑，原本用於乾癬性關節炎、乾癬等疾病。
TxGNN 模型預測它可能對**皮膚炎 (Dermatitis)** 有效，
目前有 **6 個臨床試驗**和 **20 篇文獻**與此方向相關，但其中直接針對異位性皮膚炎的 Phase 2 試驗療效訊號有限。

## 為什麼這個預測合理？

Ustekinumab 是一種人類單株抗體，作用於 IL-12 與 IL-23 共有的 p40 次單元，進而抑制 Th1 與 Th17 路徑。目前缺乏來自藥品仿單的詳細作用機轉資料，以上說明來自文獻與分析資料。

異位性皮膚炎以 Th2 路徑為主，但部分亞型（慢性、內因性、亞洲族群表型）也有 Th1/Th17/Th22 活性，因此機轉上有可能但幅度有限的合理性。與 Th2 標靶藥物（如 dupilumab、IL-13 抑制劑）相比，ustekinumab 在異位性皮膚炎的臨床療效並不一致。

TxGNN 的高分很可能反映了該藥在乾癬（同屬發炎性皮膚疾病）的已確立療效，而非皮膚炎本身的直接證據。

## 安全性考量

- **藥物交互作用**：資料庫共記錄 100 筆交互作用，以下為部分主要項目。
  - 中度：皮質類固醇（hydrocortisone、triamcinolone、dexamethasone、betamethasone、budesonide、prednisone、prednisolone）、simvastatin、抗凝血藥（warfarin、apixaban、rivaroxaban、dicoumarol）、放射性藥物（iobenguane I-131、ibritumomab tiuxetan、tositumomab）
  - 輕度：鋅製劑（硫酸鋅、醋酸鋅、葡萄糖酸鋅、氯化鋅）

其餘警語與禁忌症請參考原廠仿單。此外，針對新生兒族群或感染性病因的疾病，使用免疫抑制性生物製劑需特別謹慎。

## 結論與下一步

**決策：Hold**

**理由：**
- 兩項直接針對異位性皮膚炎的 Phase 2 試驗規模小，療效訊號有限，且未見 Phase 3 證據。高 TxGNN 分數多半反映該藥在乾癬的既有療效，而非皮膚炎的獨立證據。
- 目前缺乏仿單的警語與禁忌資料，無法完成安全性初篩。

**若要推進需要：**
- 取得香港衛生署核准的仿單，補齊警語、禁忌症與適應症資料
- 取得藥品作用機轉資料（MOA）
- 釐清最可能受益的皮膚炎亞型（如慢性、內因性、亞洲表型），再設計針對性的臨床研究
- 與已上市的 Th2 標靶藥物比較，評估其定位與價值

**其他預測適應症（排名 2–5）：** 新生兒皮肌炎、痤瘡瘢痕瘤、慢性萎縮性肢端皮炎、無肌病性皮肌炎，皆僅有模型預測、無臨床試驗或文獻（L5），建議 Hold。其中慢性萎縮性肢端皮炎為伯氏疏螺旋體感染所致，以抗生素治療為主，免疫抑制可能有害。
