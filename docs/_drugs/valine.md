## Valine：從營養補充（原適應症資料缺漏）到硬化性膽管炎
{: .text-alpha }

## 一句話總結

Valine（纈胺酸）是一種支鏈胺基酸（BCAA），在香港以單一成分或胺基酸輸液成分的形式上市。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有臨床試驗**，僅有 **2 篇間接相關文獻**，且都不是評估纈胺酸治療效果的研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Valine 是必需的支鏈胺基酸，與白胺酸、異白胺酸同屬一類，在香港多以胺基酸輸液、肝病用胺基酸製劑及腸外營養產品的成分上市。

慢性膽汁淤積性肝病（包括原發性膽汁性膽管炎與原發性硬化性膽管炎）中，已有研究描述支鏈胺基酸與芳香族胺基酸比例失衡。這是本預測唯一合理的連結，但屬於間接關聯。

需要強調的是，目前的文獻只顯示代謝異常與疾病相關，並未顯示補充纈胺酸能改善硬化性膽管炎的結果。高預測分數來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，而非生物學證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測雖有高分，但無任何臨床試驗，文獻僅顯示代謝關聯，沒有證據顯示補充纈胺酸能改善硬化性膽管炎。
- 本藥物的原適應症、作用機轉與安全性資料皆有缺漏，無法進行安全性篩選。

**若要推進需要：**
- 取得香港衛生署仿單，補齊核准適應症、警語與禁忌症
- 補充作用機轉資料（例如查詢 DrugBank）
- 針對支鏈胺基酸補充與膽汁淤積性肝病進行更完整的文獻回顧
- 若文獻支持，先設計小規模探索性研究，再考慮正式臨床試驗
