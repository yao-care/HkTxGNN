# Valine：從無核准適應症到硬化性膽管炎

## 一句話總結

Valine 是必需支鏈胺基酸（BCAA）之一，目前在香港未上市，也沒有正式核准的適應症資料。
TxGNN 模型預測它可能與**硬化性膽管炎 (Sclerosing Cholangitis)** 有關，
但目前僅有 **0 個臨床試驗**和 **2 篇文獻**提供間接證據，證據強度非常有限。

## 為什麼這個預測合理？

目前缺乏 Valine 詳細的作用機轉（MOA）資料，Evidence Pack 中此欄位為資料缺口。Valine 為必需支鏈胺基酸，一般已知參與蛋白質合成與能量代謝，但沒有資料顯示其被正式用作治療特定疾病的藥物，也無登記在案的原適應症。

針對排名第一的預測「硬化性膽管炎」，目前找到的 2 篇文獻分別是：(1) 探討原發性膽汁性肝硬化與原發性硬化性膽管炎患者血漿中**酪胺酸**（非纈胺酸）濃度與疲勞的關聯的世代研究；(2) 以孟德爾隨機化法分析多種血液代謝物與膽汁淤積性肝病因果關係的研究，並非針對纈胺酸的特異性證據。

換言之，這兩篇文獻只呈現胺基酸代謝異常與肝膽疾病之間的間接關聯訊號，並沒有提供纈胺酸補充或拮抗可直接治療硬化性膽管炎的機轉證據。此預測目前僅屬模型層級的訊號，尚無機轉或臨床證據支持。

**額外提醒**：此候選藥物的其餘 9 個預測適應症中，多數（如青光眼、甲狀腺素過高血症等）的文獻證據經檢視後屬於**命名巧合造成的偽陽性**——文獻描述的是基因位點「Val」突變（如 V509A、Val109）致病，而非「投予纈胺酸」的藥理效應，與 Valine 藥物本身無關。唯一證據等級相對較高的是排名第 3 的「甲狀腺功能亢進」（L4／S1／Research Question），其中部分文獻確實探討 BCAA 血中濃度與甲狀腺功能狀態的關聯，但因果方向未明，且無介入性試驗。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅 L5，僅有 2 篇間接關聯性文獻、無臨床試驗，且無機轉資料佐證因果關係
- 仿單警語與禁忌症資料缺失（Blocking），無法進行安全性初評

**若要推進需要：**
- 補齊仿單警語／禁忌症等安全性資料（Blocking data gap，優先處理）
- 取得 Valine 完整作用機轉（MOA）資料
- 尋找針對纈胺酸與硬化性膽管炎的直接介入性研究，而非僅代謝關聯性研究
- 可考慮改以排名第 3 的「甲狀腺功能亢進」（L4／S1）作為次要研究方向，但仍需釐清 BCAA 濃度與甲亢的因果方向及安全性風險
