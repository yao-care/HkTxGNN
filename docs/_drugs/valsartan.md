# Valsartan：從高血壓到惡性高血壓性腎病變

## 一句話總結

Valsartan（DrugBank ID: DB00177）是廣泛使用的血管收縮素受體阻斷劑（ARB），原用於治療高血壓等心血管疾病。TxGNN 模型預測它可能對**惡性高血壓性腎病變 (Malignant Hypertensive Renal Disease)** 有效，目前僅有 **1 篇動物實驗文獻**間接支持，尚無臨床試驗佐證。

## 為什麼這個預測合理？

目前 Evidence Pack 缺乏 Valsartan 詳細的作用機轉（MOA）資料。根據公開藥理學知識，Valsartan 屬於選擇性 Angiotensin II Type 1（AT1）受體阻斷劑，透過抑制 Angiotensin II 介導的血管收縮與腎絲球內壓上升，達到降血壓與潛在腎臟保護效果。

惡性高血壓性腎病變是嚴重高血壓所引發的急性腎臟損傷，其病理機轉與腎素—血管收縮素—醛固酮系統（RAAS）過度活化密切相關。ARB 類藥物阻斷 AT1 受體，理論上可能減緩此類腎損傷進展，因此 TxGNN 對 Valsartan 的預測在機轉層面具備一定合理性。

然而，目前唯一支持此預測的文獻（PMID 24368192）實際研究對象是 Avosentan（一種 Endothelin 受體拮抗劑），並非 Valsartan 或 ARB 類藥物，屬於間接佐證而非直接機轉證據。仍需針對 Valsartan 本身的研究來確認此關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 唯一相關文獻研究的是 Avosentan 而非 Valsartan，屬動物實驗間接佐證，證據等級僅 L4；藥物於香港尚未上市，且缺乏 MOA 與安全性（警語、禁忌）等關鍵資料，尚不足以支持進入下一階段評估。

**若要推進需要：**
- 補齊仿單警語與禁忌症資料（標記為 Blocking 的資料缺口）
- 取得 Valsartan 完整作用機轉（MOA）資料
- 尋找直接以 Valsartan 或 ARB class 治療惡性高血壓性腎病變的人體臨床研究
- 確認香港上市狀態與可用劑型/給藥途徑
