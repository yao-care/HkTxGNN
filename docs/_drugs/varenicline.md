# Varenicline：從戒菸輔助到偏頭痛

## 一句話總結

Varenicline 原本作為戒菸輔助藥物使用，作用於 α4β2 菸鹼型乙醯膽鹼受體。TxGNN 模型預測它可能對**偏頭痛（Migraine Disorder）**有效，但目前僅有 **1 篇文獻**（且非直接療效證據），**無任何臨床試驗**支持此方向。

## 為什麼這個預測合理？

Varenicline 是 α4β2 菸鹼型乙醯膽鹼受體（nAChR）的部分促效劑，原本用於輔助戒菸。此受體理論上在三叉神經血管系統的疼痛調控中扮演某種角色，這是模型連結偏頭痛適應症的機轉基礎。

然而，尼古丁類物質對偏頭痛的影響在既有文獻中呈現**雙向性**——部分報告顯示可誘發頭痛發作，部分則顯示可能緩解，方向並不一致。目前的機轉關聯屬於理論推測層次，尚未有明確、單一方向的藥理路徑證實 Varenicline 對偏頭痛具有治療效果。

整體而言，這是一個機轉關聯薄弱、缺乏直接支持證據的預測，仍需更多基礎研究釐清方向後才適合進入臨床驗證階段。

## 結論與下一步

**決策：Hold**

**理由：**
- 排名第一的偏頭痛適應症僅有 1 篇不直接相關的安全性個案報告支持，無任何臨床試驗證據，機轉關聯亦被明確標註為「薄弱且方向不明確」。
- 該藥物目前未於香港上市，缺乏完整的仿單警語與禁忌症資料，無法完成基本安全性初評（S1 階段）。

**若要推進需要：**
- 補齊 Varenicline 完整作用機轉（MOA）資料
- 取得仿單警語與禁忌症資訊，以完成安全性初評
- 尋找 nAChR 促效劑與偏頭痛之基礎藥理或動物實驗證據，釐清機轉方向
- 若後續有機轉研究支持，再評估是否啟動探索性臨床試驗
