# Varenicline：從戒菸到偏頭痛

## 一句話總結

Varenicline 是 α4β2 菸鹼型乙醯膽鹼受體的部分促效劑，香港已有 2 張許可證，但許可證未載明適應症，一般藥理認知中用於戒菸輔助。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前**沒有臨床試驗**，僅檢索到 **1 篇**文獻，而且是心跳停止的個案報告（安全性訊號），不支持療效。

## 為什麼這個預測合理？

Varenicline 是 α4β2 菸鹼型乙醯膽鹼受體的部分促效劑。菸鹼訊號與皮質擴散性抑制 (cortical spreading depression) 及三叉神經疼痛路徑之間，理論上有一些關聯，這是預測唯一的機轉依據。

這條關聯目前只是推測，沒有任何療效資料支持。此外，頭痛本身是 varenicline 已知的藥品不良反應，與預測方向相反。0.999 的高分只代表模型在知識圖譜中的推論，不等於臨床證據。

同批預測還包含「伴腦幹先兆的偏頭痛」，它是偏頭痛的亞型，與主預測高度相關，並非獨立證據。其餘三項預測（先天性少毛症伴粟丘疹、頭皮單純性少毛症、瀰漫性圓禿）也沒有可信的機轉連結，且都缺乏試驗與文獻。這些預測多半是知識圖譜結構造成的假象，均為 L5、建議 Hold。

## 安全性考量

- **已知不良反應**：頭痛是 varenicline 的標示不良反應，與偏頭痛的預測方向相衝突。
- **心血管安全訊號**：檢索到 1 篇使用 varenicline 後心跳停止的個案報告。

其餘警語、禁忌症與藥物交互作用資料缺漏，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測只有模型分數，沒有任何臨床試驗或療效文獻。
- 唯一文獻是心跳停止的個案報告，頭痛又是已知不良反應，現有資訊反而不利推進。

**若要推進需要：**
- 取得香港衛生署的仿單資料，補齊警語與禁忌症，才能進入安全性篩選。
- 補充 DrugBank 的作用機轉資料，檢視菸鹼受體與偏頭痛病理之間的連結是否站得住腳。
- 做系統性文獻檢索，確認有無偏頭痛相關的前臨床或臨床研究。
- 目前所有預測都沒有支持證據，建議先觀察，不宜投入資源。
