# Venetoclax：從原適應症（資料缺漏）到 CLL/SLL 前生發中心亞型

## 一句話總結

Venetoclax 是口服選擇性 BCL-2 抑制劑，原適應症在本次資料中缺漏。
TxGNN 模型預測它可能對**前生發中心慢性淋巴球性白血病／小淋巴球性淋巴瘤 (pregerminal center CLL/SLL)** 有效。
這個預測目前沒有臨床試驗，只有 **1 篇** B 細胞受體生物學的前臨床／轉譯性文獻，屬於間接支持。

## 快速總覽

| 項目 | 內容 |
|------|------|
| 預測新適應症 | 前生發中心 CLL/SLL (pregerminal center chronic lymphocytic leukemia/small lymphocytic lymphoma) |
| TxGNN 預測分數 | 99.55% |
| 證據等級 | L4 |
| 香港上市 | ✓ 已上市 |
| 許可證數 | 3 張 |
| 建議決策 | Hold |

## 為什麼這個預測合理？

DrugBank 的作用機轉欄位目前是空的。文獻摘要則一致將 venetoclax 描述為高親和力、選擇性的 BCL-2 抑制劑，能恢復惡性細胞的細胞凋亡。

此預測的疾病是 CLL/SLL 中 IGHV 未突變的分子亞型。CLL 細胞的存活高度依賴 BCL-2，這正是 venetoclax 的作用標的，因此機轉上合理。

不過要注意兩點：

- 這是既有疾病的亞型，不是新疾病。原適應症與香港許可證的適應症文字都是空的，無法確認 CLL/SLL 是否已在仿單上。若已核准，這不算真正的老藥新用。
- 第二筆預測（IGHV 突變亞型）的分數與本筆完全相同（0.9955），較可能反映 CLL/SLL 共用的圖譜鄰域，而不是亞型專屬的訊號。

## 安全性考量

安全性資訊請參考原廠仿單。本次資料中的警語與禁忌症皆缺漏，也未查到藥物交互作用資料。

文獻與預測資料中另有以下提示，並非仿單內容：

- 需注意血球減少與感染風險。
- 需預防腫瘤溶解症候群。
- 與 CYP3A 抑制劑併用時需調整劑量。

## 其他預測適應症（供參考）

主要預測的證據最弱。下表是同一份資料中的其他預測：

| 排名 | 預測適應症 | 分數 | 證據等級 | 建議 |
|-----|-----------|------|---------|------|
| 2 | CLL/SLL（IGHV 突變亞型） | 99.55% | L5 | Hold |
| 3 | 何杰金氏淋巴瘤 | 99.51% | L4 | Hold |
| 4 | 骨髓性白血病（AML） | 99.47% | L2 | Proceed with Guardrails |
| 5 | BCR-ABL1 陽性慢性骨髓性白血病 | 99.36% | L2 | 列為研究性問題 |

- **何杰金氏淋巴瘤**：檢索到的試驗與文獻幾乎都是非何杰金 B 細胞惡性腫瘤，沒有何杰金專屬證據。Reed-Sternberg 細胞對 BCL-2 的依賴性較低，外推力弱。
- **AML**：證據最完整。有 Phase 2 與 Phase 2/3 隨機試驗（NCT06317649、NCT05939180），目前都仍在招募，尚無結果，因此嚴格判為 L2。若能確認有已完成的 Phase 3 RCT，可升為 L1。同樣需先確認是否已是仿單適應症。
- **CML**：有 Phase 2 單臂研究（NCT02689440、NCT04188405、NCT05701215），但沒有 Phase 3。標準 TKI 在慢性期已很有效，加上 venetoclax 的額外效益未證實。價值可能在急變期、加速期與 TKI 後殘存的幹細胞疾病。

## 結論與下一步

**決策：Hold**

**理由：**
- 本筆預測沒有臨床試驗，唯一文獻是 BCR 生物學的前臨床資料，只有模型分數與 BCL-2 依賴性的機轉合理性。
- 這可能是既有適應症的亞型，而香港仿單適應症資料缺漏，無法判斷。

**若要推進需要：**
- 取得香港衛生署仿單，確認核准適應症、警語與禁忌症（DG001，阻擋性缺口）。
- 補齊 DrugBank 作用機轉資料（DG002）。
- 確認 CLL/SLL 是否已在仿單上。若是，本預測應改列為既有適應症的亞型，不屬於老藥新用。
- 搜尋 IGHV 亞型專屬的 venetoclax 療效數據。
- 若要優先投入資源，建議改評估 AML（Proceed with Guardrails），並查證是否有已完成的 Phase 3 RCT。
