# Venetoclax：從資料缺口的原適應症到生發中心前期慢性淋巴細胞白血病/小淋巴細胞淋巴瘤

## 一句話總結

Venetoclax（DrugBank ID: DB11581）目前在 Evidence Pack 中缺乏完整的原適應症與作用機轉資料。
TxGNN 模型預測它可能對**生發中心前期慢性淋巴細胞白血病/小淋巴細胞淋巴瘤（pregerminal center CLL/SLL）**有效，
預測分數高達 **99.55%**，但這個特定亞型目前**沒有直接對應的臨床試驗**，僅有 **1 篇相關文獻**支持，證據強度有限。

## 為什麼這個預測合理？

目前缺乏 Venetoclax 詳細的作用機轉（MOA）與原適應症資料，這是本次評估最主要的資料缺口（DG002, High severity）。不過從本次收集到的文獻證據中可以看出，Venetoclax 在多篇獨立文獻中被描述為「高度選擇性的口服 BCL-2 抑制劑，能恢復癌細胞的細胞凋亡機制」（如文獻 PMID 28724540、PMID 35659041），這是目前唯一可佐證其機轉的資訊來源。

生發中心前期慢性淋巴細胞白血病/小淋巴細胞淋巴瘤（U-CLL）是 CLL/SLL 疾病中一個具特定生物學特徵的亞型，其特徵是免疫球蛋白重鏈可變區基因（IGHV）未突變，屬於預後較差的族群（文獻 PMID 35158929）。由於 BCL-2 過度表現是 B 細胞淋巴瘤/白血病共通的病理特徵之一，而 Venetoclax 作為 BCL-2 抑制劑的機轉理論上能適用於此亞型。

值得注意的是，本次評估批次中還有其他高度相關的預測候選（詳見文末），包括一般型 CLL/SLL、何杰金氏淋巴瘤、骨髓性白血病與慢性骨髓性白血病，這些候選項目擁有遠比本項預測更豐富的臨床試驗與文獻證據，顯示 Venetoclax 在血液腫瘤領域的機轉關聯性有相當程度的外部佐證，即使本項特定亞型本身的直接證據仍然薄弱。

## 細胞毒性

多篇文獻與試驗摘要（屬本評估批次收集之證據）一致指出，Venetoclax 作為選擇性 BCL-2 抑制劑，在血液腫瘤治療中具有以下風險特徵：

| 項目 | 內容 |
|------|------|
| 細胞毒性分類 | 標靶藥物（選擇性 BCL-2 抑制劑） |
| 骨髓抑制風險 | 高（文獻明確指出嚴重嗜中性白血球減少是導致 Venetoclax 減量或停藥的主因） |
| 致吐性分級 | 請參考原廠仿單的警語與注意事項 |
| 監測項目 | CBC（含分類）、腫瘤溶解症候群（TLS）相關指標（電解質、腎功能、尿酸） |
| 處置防護 | 需依細胞毒性/標靶抗腫瘤藥物處置規範操作；因腫瘤溶解症候群風險，起始劑量須階梯式調升並密切監測 |

## 結論與下一步

**決策：Hold**

**理由：**
- TFDA/HK 仿單警語與禁忌症資料為 Blocking 等級缺口（DG001），無法進入 S1 安全性初評。
- 本項預測適應症（生發中心前期 CLL/SLL）本身缺乏直接的臨床試驗證據，僅有 1 篇背景性文獻，證據等級偏低（L4）。

**若要推進需要：**
- 補齊 Venetoclax 的 TFDA/香港仿單警語、禁忌症與 DDI 資料（DG001，優先處理）。
- 補齊作用機轉（MOA）資料，確認與此亞型的機轉關聯性（DG002）。
- 確認 Venetoclax 是否已在其他市場核准用於一般型 CLL/SLL，以釐清此預測是否為「亞型擴充」而非全新適應症。
- 若要推進本候選，建議優先評估同批次中證據等級較高的候選適應症（見下方）。
