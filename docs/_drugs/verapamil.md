# Verapamil：從心血管用藥（許可證未載明適應症）到束支傳導阻滯（已淘汰術語）

## 一句話總結

Verapamil 是 L 型鈣離子通道阻斷劑，在香港已有多張上市許可證，但許可證資料未載明原適應症。
TxGNN 模型預測它可能對**束支傳導阻滯 (obsolete bundle branch block)** 有效，但目前**沒有任何臨床試驗或文獻**支持。
這個預測在機轉上不合理，建議暫緩。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Verapamil 屬於 L 型鈣離子通道阻斷劑，會減慢房室結傳導。

這代表它的作用是抑制傳導，而不是恢復傳導，所以對束支傳導阻滯有益在機轉上很難成立，甚至可能讓傳導疾病惡化。

此外，該疾病名稱在本體論中被標為「obsolete（已淘汰）」，這個高分更可能是知識圖譜的人為產物，不是真實的藥理訊號。0.996 的分數只是模型預測，沒有臨床證據佐證。

## 結論與下一步

**決策：Hold**

**理由：**
- 首位預測（束支傳導阻滯）沒有任何臨床或文獻證據，且 verapamil 抑制傳導的作用與該疾病相反，可能使病況惡化。
- 在所有預測中，只有惡性腎血管性高血壓具備機轉合理性（L4，列為研究問題），但仍缺乏直接證據。

**若要推進需要：**
- 取得香港衛生署的仿單資料（警語、禁忌症），這是安全性篩選前的必要資料。
- 從 DrugBank 補齊作用機轉資料。
- 若要探索惡性腎血管性高血壓，須先界定腎血管性與惡性期的目標族群，並檢索直接評估 verapamil 的研究。
- 評估是否排除已淘汰的本體論術語，避免產生誤導性預測。
