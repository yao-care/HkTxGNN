# Vildagliptin：從第二型糖尿病到僵硬人症候群 (Classic Stiff Person Syndrome)

## 一句話總結

Vildagliptin 是 DPP-4 抑制劑類藥物，臨床上原用於第二型糖尿病治療。
TxGNN 模型預測它可能對**僵硬人症候群 (Classic Stiff Person Syndrome)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（Evidence Pack 中 original_moa 未提供）。根據一般已知資訊，Vildagliptin 屬於 DPP-4 抑制劑類藥物，機轉為抑制 DPP-4 酶延緩腸泌素（GLP-1/GIP）分解，進而促進胰島素分泌並抑制升糖素釋放，臨床上用於血糖控制。

僵硬人症候群屬自體免疫疾病，多與抗 GAD65 抗體及 GABA 能神經傳導異常相關。根據 Evidence Pack 提供的機轉關聯性分析，DPP-4 抑制劑之腸泌素/血糖代謝路徑與此疾病之免疫/GABA 神經傳導路徑**並無已知直接關聯**，此預測較可能來自 TxGNN 知識圖譜的節點鄰近效應，而非具生物學合理性的機轉推論。

因此，此預測屬於純模型驅動的假說階段，尚無機轉、臨床前或臨床證據支持，須以審慎態度看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 所有候選適應症之證據等級均為 L5，僅有模型預測分數，無任何臨床試驗、文獻或機轉研究支持。
- 藥物於香港未上市，且缺乏 MOA 與安全性仿單資料，無法進行 S1 安全性初評。
- Evidence Pack 本身的機轉關聯性分析已指出，排名前列之候選適應症與 DPP-4 抑制機轉多屬「知識圖譜節點鄰近效應」，生物學合理性薄弱。

**若要推進需要：**
- 補齊 DrugBank MOA 完整資料，進行機轉關聯性重新評估
- 蒐集香港或國際原廠仿單（警語、禁忌、藥物交互作用）
- 尋找任何臨床前研究，驗證 DPP-4 路徑與神經免疫/GABA 相關疾病之潛在連結
- 若機轉合理性持續無法建立，建議不再投入此候選適應症的後續資源
