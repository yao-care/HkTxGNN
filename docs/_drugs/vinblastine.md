# Vinblastine：從霍奇金氏淋巴瘤等血液與皮膚淋巴系統惡性腫瘤到橫紋肌肉瘤

## 一句話總結

Vinblastine（長春花鹼）是長春花生物鹼類抗癌藥，原本用於霍奇金氏淋巴瘤、非霍奇金氏淋巴瘤、蕈樣肉芽腫及蘭格漢斯細胞組織球增生症等。
TxGNN 模型預測它可能對**橫紋肌肉瘤 (Rhabdomyosarcoma)** 有效，
目前**沒有登記的臨床試驗**，僅有 **7 篇文獻**（多為個案報告與前臨床研究）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Vinblastine 屬於長春花生物鹼類，可結合微管蛋白 (tubulin)、干擾微管組裝，使細胞停滯於有絲分裂期。快速分裂的腫瘤細胞因此可能對其敏感。

長春花生物鹼類（以 vincristine 為標準藥物）本來就是橫紋肌肉瘤治療方案的核心成分。Vinblastine 也曾出現在兒童節拍式（metronomic）化療組合及數則個案報告中。因此，在機轉與同類藥物經驗上，預測具有合理性。

不過，Vinblastine 本身在橫紋肌肉瘤的臨床證據薄弱：多為小型、年代久遠的個案或先導研究，且常與其他藥物合併使用，無法單獨判斷 Vinblastine 的貢獻。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉合理，且同類藥物（vincristine）已是橫紋肌肉瘤標準用藥，但 Vinblastine 本身僅有小型、年代久遠的個案與前臨床資料，無登記臨床試驗，證據停留在 L3。
- 此藥為高骨髓抑制風險的細胞毒性藥物，且香港仿單安全資料缺漏，在無更強證據下不宜推進。

**若要推進需要：**
- 取得香港衛生署仿單（警語、禁忌、適應症）
- 補齊作用機轉資料（如 DrugBank）
- 系統性回顧 Vinblastine 在橫紋肌肉瘤的既有臨床資料，並與 vincristine 為基礎的標準方案比較
- 若要進入臨床探索，需設計明確的劑量與血液學監測計畫
