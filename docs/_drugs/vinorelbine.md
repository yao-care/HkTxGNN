## Vinorelbine: 尤文氏肉瘤 (Ewing sarcoma)
{: .text-alpha }

## 一句話總結

Vinorelbine 是長春花生物鹼類的抗微管化療藥，知識圖譜中記錄的原適應症為非小細胞肺癌與肺癌。
TxGNN 模型預測它可能對**尤文氏肉瘤 (Ewing sarcoma)** 有效，
目前有 **3 個臨床試驗**和 **6 篇文獻**與這個方向相關，其中直接針對尤文氏肉瘤的研究以 Phase 2 合併用藥試驗與一篇系統性回顧為主。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Vinorelbine 屬於長春花生物鹼類，一般認為透過抑制微管聚合，使快速分裂的細胞停滯於有絲分裂期並走向凋亡。

在兒童與年輕成人的復發或難治性肉瘤中，Vinorelbine 搭配低劑量持續口服 cyclophosphamide（節拍式療法）已有 Phase 2 研究探討。另有前臨床研究顯示，微管干擾藥物（含 vinorelbine）與 PLK1 抑制劑在尤文氏肉瘤細胞中有協同誘導凋亡的作用。

肺癌與尤文氏肉瘤雖然是不同的腫瘤，但同屬快速增殖的惡性腫瘤，抗有絲分裂藥物在機轉上有合理的適用空間。

**證據等級說明：** 已檢索到的試驗與文獻中，沒有已完成、專門以尤文氏肉瘤為對象的 Phase 3 RCT；現有試驗多為混合性兒童實體瘤族群，屬間接證據。依證據規則，最高判定為 L3（系統性回顧與 Phase 2 研究層級的證據）。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 已有 Phase 2 研究與前臨床資料支持 vinorelbine 搭配 cyclophosphamide 用於復發或難治性兒童肉瘤，且國際 INTER-EWING-1 試驗正以此組合作為維持治療的依據；但尤文氏肉瘤專屬的隨機對照證據仍不足，故需設定防護條件。

**若要推進需要：**
- 取得尤文氏肉瘤專屬的療效資料（INTER-EWING-1 結果或相關 Phase 2/3 試驗）
- 取得原廠仿單的警語、禁忌症與作用機轉資料，補足目前缺口
- 擬定骨髓抑制監測與藥物交互作用管理計畫（特別是 CYP3A4 相關藥物，如 clarithromycin）
- 確認香港許可證的核准適應症文字與兒童族群使用的相關規範
