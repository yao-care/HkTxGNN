# Vitamin A：從維生素A缺乏症到先天性凝血酶原缺乏症

## 一句話總結

Vitamin A（維生素A）是人體必需的脂溶性維生素，傳統上用於預防與治療維生素A缺乏症相關病症。TxGNN 模型預測它可能對**先天性凝血酶原缺乏症（Congenital Prothrombin Deficiency）**有效，預測分數高達 **99.97%**，但目前僅有 **5 個臨床試驗**且經審查後皆與此適應症的作用機轉無直接關聯，證據等級為最低的 **L5**，暫不建議推進。

## 為什麼這個預測合理？

目前缺乏 Vitamin A 的詳細作用機轉資料（DrugBank MOA 尚未取得），這也是本次評估的一項高優先級資料缺口。

儘管 TxGNN 對「先天性凝血酶原缺乏症」給出極高的預測分數，但深入檢視相關性後發現，這很可能是模型的偽陽性結果。凝血酶原（Prothrombin, Factor II）的合成依賴 **Vitamin K 依賴性 γ-羧化作用**，屬於 Vitamin K 訊號路徑範疇，與 Vitamin A（視黃醇／RAR-RXR 受體）訊號路徑並無交集。推測 TxGNN 在知識圖譜的 embedding 空間中，可能將 Vitamin A 與 Vitamin K 的節點產生了混淆，導致此高分預測。

檢視目前收集到的 5 個臨床試驗，內容涵蓋內皮功能補充劑研究、肝硬化治療、血友病骨質流失、凝血因子濃縮物（BERIPLEX）及先天性代謝異常登記研究，皆與 Vitamin A 或凝血酶原缺乏症的治療機轉無直接關聯。因此，本候選適應症的機轉基礎薄弱，建議視為模型侷限性案例，暫不作為老藥新用的優先方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 該適應症的機轉關聯性薄弱，現有分析顯示 TxGNN 高分預測極可能源自 Vitamin A／Vitamin K 在模型 embedding 空間中的混淆，而非真實的生物學關聯。
- 現有 5 個臨床試驗經逐一檢視後，皆與 Vitamin A 治療凝血酶原缺乏症無直接關聯，且無任何文獻支持，證據等級僅達 L5（純模型預測）。

**若要推進需要：**
- 補齊 Vitamin A 之作用機轉（MOA）資料，以利後續機轉關聯性分析。
- 取得原廠仿單警語與禁忌症資料，此為目前的阻斷性（Blocking）資料缺口，若不解決將無法進入 S1 安全性初評階段。
- 若欲尋找更具潛力的老藥新用方向，建議改為評估同一份證據包中證據等級較高的候選適應症，例如「周產期疾病」（極低體重早產兒之支氣管肺發育不良，L1，已有多版 Cochrane 系統性回顧支持）或「細胞增生疾病」（ATRA 於急性前骨髓性白血病之應用，L2，機轉已充分驗證），這兩者的證據強度遠高於本報告所評估的候選適應症。
