# 維生素E（Vitamin E）：原適應症資料缺失 → 先天性膽紅素代謝障礙

## 一句話總結

Evidence Pack 目前未提供維生素E（Vitamin E）的原適應症與作用機轉資料。TxGNN 模型預測它可能對**先天性膽紅素代謝障礙（Inborn Disorder of Bilirubin Metabolism）**有效，
但目前僅有 **3 個臨床試驗**（皆非以維生素E為介入藥物，相關性均評為 C 級）與 **2 篇文獻**（僅間接關聯，未直接研究維生素E），證據強度偏弱。

## 為什麼這個預測合理？

目前缺乏維生素E詳細的作用機轉資料，也沒有原適應症紀錄可供比對，因此無法從「原適應症與新適應症的關聯性」來支持這項預測。

根據現有的機轉分析：先天性膽紅素代謝障礙多源於 UGT1A1、ATP8B1 等基因異常，屬於酵素/轉運蛋白層級的先天缺陷；而維生素E的已知作用是抗氧化、清除自由基。兩者在機轉路徑上**目前無已知交集**。相關文獻僅描述新生兒黃疸的病理分類與膽汁淤積症的膽酸合成缺陷，並未實際研究維生素E的介入效果。

換言之，這項預測目前主要來自 TxGNN 知識圖譜的拓樸關聯，缺乏機轉層面與臨床層面的直接支持。

## 結論與下一步

**決策：Hold**

**理由：**
- 機轉上無已知交集，現有臨床試驗均非以維生素E為介入藥物（相關性皆為C級），文獻證據僅為間接關聯，證據等級為 L4，尚不足以支持推進。
- 原適應症與作用機轉資料均缺失，且安全性仿單資料為 Blocking 等級缺口，無法完成基本安全性初評。

**若要推進需要：**
- 補齊 TFDA／香港衛生署仿單之警語與禁忌症資料（Blocking，DG001）
- 補齊維生素E的作用機轉（MOA）資料（High，DG002）
- 補齊原適應症紀錄，以利進行原-新適應症關聯性分析
- 尋找以維生素E為直接介入藥物、針對膽紅素代謝疾病的臨床證據

**備註：** 同一份 Evidence Pack 中，另一預測適應症「bilirubin metabolism disease」（rank 2）證據強度明顯較高（L2，含一項 Phase 4 RCT：NCT04977661，n=102，直接比較維生素E、UDCA、Pentoxifylline於NASH患者），建議另行針對該適應症產出獨立評估報告。
