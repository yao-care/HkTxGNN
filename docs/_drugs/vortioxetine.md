# Vortioxetine：從重度憂鬱症到神經質疾患

## 一句話總結

Vortioxetine（商品名 Brintellix）是一種抗憂鬱藥，原本用於重度憂鬱症。
TxGNN 模型預測它可能對**神經質疾患 (Neurotic Disorder)** 有效，
但目前僅有 **1 個間接相關的臨床試驗**和 **1 篇文獻**，證據很薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據文獻（PMID 25016186），vortioxetine 是多重機轉的抗憂鬱藥。它抑制血清素轉運體 (SERT)，同時作用於 5-HT1A、5-HT1B、5-HT3、5-HT7 等受體。這段機轉來自文獻，不是輸入資料本身。

「神經質疾患」是較舊的廣義名稱，涵蓋憂鬱與焦慮譜系的疾病。Vortioxetine 在憂鬱症與焦慮症狀上的療效，讓這個預測在機轉上有間接合理性。

但目前沒有任何針對「神經質疾患」這個族群的研究。現有支持證據都來自重度憂鬱症，所以這個預測只能視為研究假說。模型分數雖高，不等於臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
這個預測只有高分的模型輸出，加上一個非針對該族群的回溯性研究和一篇不是專談 vortioxetine 的文獻，沒有直接證據。「神經質疾患」又是過時的廣義名稱，難以定義研究族群。

同一份 Evidence Pack 中，**憂鬱症相關預測（如 melancholia）** 有多個已完成的 Phase 3 試驗支持，證據明顯較強。若要優先投入資源，建議改評估該方向。

**若要推進需要：**
- 先把「神經質疾患」對應到現行診斷（如持續性憂鬱症、廣泛性焦慮症等），再決定具體研究族群
- 取得香港衛生署核准的仿單，確認原適應症、警語與禁忌
- 補齊詳細的作用機轉資料（DrugBank）
- 查找針對該族群的對照研究，再重新評估證據等級
