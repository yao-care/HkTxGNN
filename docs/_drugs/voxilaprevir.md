## Voxilaprevir：從慢性 C 型肝炎到 B 型肝炎病毒感染
{: .text-alpha }

## 一句話總結

Voxilaprevir 是 C 型肝炎病毒（HCV）NS3/4A 蛋白酶抑制劑，知識圖譜記錄的原適應症為慢性 C 型肝炎病毒感染。
TxGNN 模型預測它可能對 **B 型肝炎病毒感染 (Hepatitis B Virus Infection)** 有效，
但目前**沒有任何針對 B 型肝炎的臨床試驗或研究**，證據僅停留在模型預測層級。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Voxilaprevir 是 HCV NS3/4A 蛋白酶抑制劑，在 C 型肝炎中的角色已被廣泛研究，常與 sofosbuvir、velpatasvir 組成複方使用。

從機轉上看，這個預測的支持度很弱。B 型肝炎病毒不編碼 NS3/4A 類型的絲胺酸蛋白酶，而是依賴反轉錄酶／聚合酶與衣殼相關機制，因此與 voxilaprevir 的標靶沒有明確同源性。這個分數來自 TxGNN 模型（深度學習），可能反映模型學到的相關疾病之間的相似性，並非生物學證據。

已取得的文獻幾乎都在談 HCV 的再治療（如 DAA 治療失敗後使用 sofosbuvir/velpatasvir/voxilaprevir），僅在藥價比較、牙科感染標記等文章中附帶提到 B 型肝炎，沒有 B 型肝炎專屬的療效資料。因此，直接研究該疾病的證據並不存在，證據等級為 L5。

## 結論與下一步

**決策：Hold**

**理由：**
- B 型肝炎沒有任何直接研究，證據等級為 L5。
- HBV 缺乏與 voxilaprevir 標靶相似的蛋白酶，機轉上缺乏支持，高分更可能來自網絡鄰近性。
- 其他排名較前的預測（如 A 型肝炎、HIV）所連結的試驗與文獻也都是在治療 HCV，並非直接驗證該疾病，因此同樣無法支持推進。

**若要推進需要：**
- 提出可信的 HBV 機轉假說，並進行體外抗 HBV 活性的前臨床驗證
- 取得 voxilaprevir 的作用機轉資料
- 取得香港仿單的警語、禁忌症與核准適應症文字，完成安全性篩選
- 在有前臨床訊號之前，不建議投入臨床試驗
