# Xylazine：從（未登載原適應症）到偏頭痛

## 一句話總結

Xylazine 是一種 α2 腎上腺素受體促效劑，在香港以獸用鎮靜／止痛注射劑形式上市。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
但目前僅有 **0 個臨床試驗**和 **1 篇前臨床文獻**，且該文獻並未將 xylazine 作為治療藥物測試，證據相當薄弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，xylazine 屬於 α2 腎上腺素受體促效劑，臨床上作為獸用鎮靜與止痛藥使用。同類藥物（如 clonidine）曾被探索用於偏頭痛，因此在類別層級上有一定的機轉合理性，但這僅屬推測。

唯一連結的文獻（PMID 27122032）研究初級感覺皮質對擴散性去極化 (spreading depolarization) 的易感性，而擴散性去極化被認為與偏頭痛先兆有關。不過該研究為動物前臨床研究，xylazine 似乎只是麻醉方案的一部分，並非被測試的治療介入。因此高分預測主要來自模型推論，而非實際臨床支持。

另外兩個相關預測為「伴腦幹先兆的偏頭痛」，其證據來自同一篇文獻，很可能只是反映疾病本體論上的關聯，並非獨立證據。

## 安全性考量

安全性資訊請參考原廠仿單。

補充說明：xylazine 並未核准供人類使用。依本報告整理的資料，其已知風險包括中樞神經與呼吸抑制、心搏過緩、低血壓，以及非法使用時出現的嚴重皮膚傷口。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型，唯一文獻為前臨床研究，且 xylazine 並非被研究的治療藥物，證據等級為 L5。
- Xylazine 為獸用藥，系統性使用的安全疑慮明顯，而且已有其他 α2 促效劑與既有偏頭痛療法可用。

**若要推進需要：**
- 取得 xylazine 的作用機轉資料，並釐清與偏頭痛的機轉關聯
- 取得香港衛生署核准的仿單，確認警語與禁忌症
- 評估同類 α2 促效劑（如 clonidine）在偏頭痛的既有臨床證據，作為替代候選
- 若仍要探索，需先有針對性的前臨床研究，並評估人用安全性與給藥途徑
