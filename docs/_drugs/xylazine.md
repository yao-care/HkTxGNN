# Xylazine：從獸用藥品到偏頭痛

## 一句話總結

Xylazine 在香港登記為獸用注射劑，許可證未載明原適應症。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前**沒有臨床試驗**，只有 **1 篇**間接相關的動物實驗文獻，證據僅達模型預測層級。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Xylazine 屬於 α2 腎上腺素受體促效劑，同類藥物（如 clonidine）在偏頭痛預防上有使用紀錄，但證據有限且結果不一致。

與預測相關的唯一文獻（PMID 27122032）研究皮質擴散性去極化 (spreading depolarization)，這是偏頭痛預兆的生理基礎。從標題判斷，這是小鼠等動物的神經生理研究，xylazine 很可能只是麻醉劑或實驗條件，並非被測試的治療藥物。因此 TxGNN 的高分更可能來自知識圖譜中的關聯，不是臨床證據。

Xylazine 未核准供人使用，且有嚴重安全疑慮（深度鎮靜、心搏過緩、低血壓、呼吸抑制）。相較已核准的 α2 促效劑，看不出明顯優勢。

TxGNN 另外預測了三項適應症，證據都同樣薄弱：

- **開角型青光眼**（99.55%）：只有類別層級的合理性，α2 促效劑如 brimonidine 可降眼壓。唯一文獻（PMID 22359566）是動物血壓與眼壓研究，xylazine 可能只是麻醉劑，其全身血行動力學效應反而可能干擾結果。
- **伴腦幹先兆的偏頭痛**（99.54%）：與偏頭痛同一份文獻，可能只是圖譜上靠近偏頭痛節點。
- **原發性遺傳性青光眼**（99.53%）：無任何試驗或文獻。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據僅為模型預測（L5），唯一文獻是動物研究，xylazine 很可能只是麻醉背景，並非治療因子。
- Xylazine 是未核准供人使用的獸用藥，全身毒性明顯，且已有更安全的 α2 促效劑可用，開發誘因低。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語與禁忌症
- 補充 DrugBank 作用機轉資料
- 審閱 PMID 27122032 全文，確認 xylazine 在研究中的角色
- 與已核准的 α2 促效劑（clonidine、brimonidine）做比較，確認 xylazine 有無獨特價值
- 確認是否存在適合人體使用的劑型與給藥途徑
