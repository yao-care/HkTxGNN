# Xylometazoline：從鼻充血到鼻腔疾病

## 一句話總結

Xylometazoline 是局部使用的鼻用減充血劑，在香港已有多張鼻用製劑許可證。
TxGNN 模型預測它可能對**鼻腔疾病 (Nasal Cavity Disease)** 有效，
目前有 **2 個臨床試驗**和 **7 篇文獻**支持這個方向。
不過這項預測與其現有的鼻用減充血用途高度重疊，較接近既有用途而非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據藥理學一般知識，Xylometazoline 是局部使用的 α-腎上腺素受體促效劑，
會使鼻黏膜血管收縮，降低鼻腔阻力、減輕鼻塞。

這與鼻腔疾病的表現（黏膜腫脹、鼻腔阻力增加）直接相符。
該藥在香港本來就以鼻用減充血劑上市，因此這個預測較接近既有用途，而不是跨領域的新用途。

需要注意：現有的臨床試驗證據多為鼻腔手術或內視鏡檢查前的準備用途，
並非直接治療鼻腔疾病，屬於間接證據。因此證據等級定為 L2，而非 L1。

## 其他預測適應症：急性喉咽炎

TxGNN 對**急性喉咽炎 (Acute Laryngopharyngitis)** 的預測分數為 99.89%，但目前沒有任何臨床試驗或文獻支持（證據等級 L5，決策 Hold）。
Xylometazoline 為鼻內給藥劑型，沒有證據顯示它能有效作用於喉咽黏膜，
這個高分較可能來自知識圖譜中與鼻部、上呼吸道適應症的相鄰關係。除非有機轉依據或臨床資料，否則不建議投入評估。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
Xylometazoline 的血管收縮作用與鼻腔疾病的表現相符，並已在香港以鼻用減充血劑上市，有多項隨機或前瞻性研究支持。
但唯一的 Phase 3 試驗是複方製劑、樣本僅 16 人、終點為操作止痛，屬間接證據，因此維持在 L2。

**若要推進需要：**
- 補齊香港衛生署仿單的警語與禁忌資料，這是目前阻擋安全性篩選的缺口
- 取得 DrugBank 的作用機轉資料
- 補全許可證的劑型與核准適應症欄位，並確認原適應症
- 用藥原則：僅限短期使用，避免反彈性鼻充血（藥物性鼻炎）；心血管疾病患者及使用 MAO 抑制劑者需特別留意
- 急性喉咽炎：需先有機轉依據與臨床資料才值得重新評估
