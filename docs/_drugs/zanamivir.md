# Zanamivir：從流感到腎盂腎炎

## 一句話總結

Zanamivir 是病毒神經胺酸酶（neuraminidase）抑制劑，原本用於 A 型與 B 型流感。
TxGNN 模型預測它可能對**腎盂腎炎 (Pyelonephritis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Zanamivir 抑制流感病毒的神經胺酸酶（sialidase），用來治療 A 型與 B 型流感。

腎盂腎炎通常是細菌感染，最常見的致病菌是泌尿道致病性大腸桿菌。兩者的病原體不同，現有資料找不到機轉上的關聯。

一種純推測的路徑是抑制細菌的唾液酸酶，但 Zanamivir 並未被證實對細菌酵素有活性，本次提供的資料也沒有支持。0.998 的高分只是模型預測，沒有臨床試驗或文獻佐證，不能視為證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數，沒有試驗或文獻，證據等級為 L5。
- Zanamivir 針對病毒，腎盂腎炎多為細菌感染，找不到機轉上的連結。

**若要推進需要：**
- 補齊 DrugBank 的作用機轉資料，確認是否有抗細菌或其他相關活性
- 取得香港衛生署仿單的警語、禁忌與核准適應症
- 做體外或前臨床研究，驗證對泌尿道致病菌（如大腸桿菌）是否有活性
- 確認給藥途徑：Zanamivir 在香港僅有口腔吸入劑型，是否能達到腎臟與泌尿道的有效濃度尚待評估

**補充：** 第二名預測「酪胺酸代謝異常 (disorder of tyrosine metabolism)」檢索到的 3 篇文獻，內容都是流感神經胺酸酶抑制劑抗藥性、檢測方法與病毒突變，與該適應症無關，不能當作支持證據。
