# Zanamivir：從流感抗病毒藥物到腎盂腎炎

## 一句話總結

Zanamivir（扎那米韋）為神經胺酸酶抑制劑類抗病毒藥物，目前**未在香港上市**，且原始核准適應症與作用機轉資料均缺失。TxGNN 模型預測其對**腎盂腎炎 (Pyelonephritis)** 具有極高關聯分數（99.84%），但目前**沒有任何臨床試驗或文獻證據**支持這個方向，且系統本身的機轉分析已明確指出此預測極可能是知識圖譜推論產生的**假陽性**。

## 為什麼這個預測合理？

目前缺乏 Zanamivir 詳細的作用機轉資料（原始核准適應症與 MOA 均標記為資料缺失，屬於本評估的關鍵阻斷性缺口）。根據 Evidence Pack 中附帶的文獻內容判斷，Zanamivir 屬於神經胺酸酶（neuraminidase）抑制劑類藥物，作用標的為流感病毒表面醣蛋白，具高度特異性的抗病毒活性，**不具抗菌作用**。

腎盂腎炎多由大腸桿菌等細菌感染泌尿道所致，其致病機轉與病毒神經胺酸酶抑制**無已知關聯**。系統內建的機轉分析已明確指出：TxGNN 給出的高分（0.998）判斷為知識圖譜連結型態產生的推論假陽性，**沒有任何支持性臨床或文獻證據**，機轉上不具生物學合理性。

換言之，這是一個「模型分數高、但機轉與證據皆不支持」的典型案例，不建議依此分數本身推進任何後續行動。

## 安全性考量

目前缺乏 Zanamivir 的仿單警語、禁忌症與藥物交互作用資料，且此項缺口（TFDA/仿單資料）被標記為**阻斷性（Blocking）**等級，代表在補齊此資料前，此候選藥物**無法進入下一階段的安全性初評（S1）**。

安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 兩項預測適應症均無臨床試驗或有意義的文獻支持，證據等級皆為 L5（僅模型預測）。
- 系統自身的機轉分析已明確判定排名第一的腎盂腎炎預測為疑似假陽性，缺乏生物學合理性。
- 該藥物於香港未上市，且原始適應症、作用機轉、仿單警語等關鍵安全性資料均缺失，其中仿單資料缺口屬阻斷性等級。

**若要推進需要：**
- 補齊 TFDA/原廠仿單警語與禁忌症資料（DG001，阻斷性缺口，優先處理）
- 補齊 DrugBank 作用機轉（MOA）資料（DG002）
- 若後續發現支持腎盂腎炎或其他適應症的實際臨床或機轉證據，應重新評估；在此之前不建議投入資源推進本候選。
