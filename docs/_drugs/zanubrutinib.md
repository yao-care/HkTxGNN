# Zanubrutinib：從 B 細胞淋巴系惡性腫瘤到骨髓性白血病

## 一句話總結

> Zanubrutinib 是新一代 BTK（Bruton's tyrosine kinase）抑制劑，目前核准用途集中於慢性淋巴性白血病/小淋巴球性淋巴瘤（CLL/SLL）、華氏巨球蛋白血症與套膜細胞淋巴瘤等 B 細胞淋巴系惡性腫瘤。
> TxGNN 模型預測它可能對**骨髓性白血病 (Myeloid Leukemia)** 有效，
> 但目前僅有 **2 個間接相關的臨床試驗**（皆非直接測試 zanubrutinib 於此適應症）與 **9 篇文獻**（多聚焦於 CLL/SLL 而非骨髓性白血病），機轉上的直接證據薄弱。

## 為什麼這個預測合理？

DrugBank 結構化欄位中的作用機轉資料目前缺失（Data Gap），但根據其他佐證資訊，Zanubrutinib 為次世代、高選擇性的 BTK 抑制劑，透過阻斷 B 細胞受體（BCR）訊號傳導路徑，抑制 B 淋巴細胞的增殖與存活，因此核准適應症集中於 B 細胞來源的淋巴系惡性腫瘤。

骨髓性白血病（myeloid leukemia）屬於骨髓系（myeloid lineage）造血細胞的惡性增生，與 BTK 主要表現的 B 淋巴細胞譜系在細胞來源上並不相同。雖然文獻中存在少數探討 BTK/PI3K 訊號路徑在 AML 細胞內訊號傳導扮演角色的間接研究，但目前沒有直接證據顯示 zanubrutinib 對骨髓性白血病具有明確療效或機轉合理性。

換言之，這是一個由知識圖譜連結推導出的**探索性假說**，而非有機轉或臨床證據直接支持的候選適應症，需要審慎看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗或文獻直接測試 zanubrutinib 用於骨髓性白血病，僅有的兩個相關試驗評估的是其他藥物（CG-806、PRT2527），且其中一項已終止。
- Zanubrutinib 的作用機轉（BTK 抑制、B 細胞受體訊號阻斷）與骨髓性白血病的骨髓系細胞來源缺乏直接機轉關聯，rationale 明確指出「無直接機轉支持」。
- 香港未上市、無許可證資料，且藥物安全性關鍵資料（仿單警語、禁忌症、MOA）均為 Data Gap，其中仿單資料屬於 Blocking 等級缺口。

**若要推進需要：**
- 補齊 TFDA/HK 仿單警語與禁忌症資料（Blocking 缺口，優先處理）
- 取得完整的作用機轉（MOA）資料，釐清 BTK 於骨髓系細胞中的表現與功能角色
- 進行 BTK 在骨髓性白血病細胞株或動物模型中的體外/體內機轉研究，建立初步機轉證據
- 若機轉證據支持，才考慮啟動早期臨床探索性研究
