# Zinc acetate：從原適應症未明載到嚴重非增殖性糖尿病視網膜病變

## 一句話總結

Zinc acetate（醋酸鋅）在香港登記於 4 張靜脈輸注乳劑類產品，但資料中沒有載明原適應症。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效。
目前**沒有任何臨床試驗或文獻**支持這項預測，僅有模型分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。從香港許可證的品名判斷，Zinc acetate 是 B. Braun 靜脈輸注乳劑產品（Nutriflex、Omegaflex 系列）的成分之一，但各許可證均未提供核准適應症文字。

鋅是 SOD（超氧化物歧化酶）等抗氧化酵素的輔因子，也存在於視網膜組織，因此推測可能與氧化壓力相關的視網膜病變有關。這個推論僅是合理猜測，沒有任何試驗或文獻佐證。TxGNN 分數不等同臨床證據。

另外，排名第 3 的「糖尿病視網膜病變」是本預測的上位疾病，兩筆預測並非彼此獨立的證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 首要預測（嚴重非增殖性糖尿病視網膜病變）只有模型分數，沒有任何臨床試驗或文獻，證據等級為 L5。
- 作用機轉與香港仿單的警語、禁忌症資料均缺漏，無法進入安全性篩選。
- 香港已登記的產品為靜脈輸注乳劑，與眼科用途的劑型和給藥途徑是否相容，目前尚未評估。

**若要推進需要：**
- 取得香港衛生署的仿單（警語、禁忌症、核准適應症），這是目前的阻斷性缺口。
- 補齊 DrugBank 的作用機轉資料。
- 系統性搜尋鋅與糖尿病視網膜病變的臨床與前臨床研究。
- 評估給藥途徑的可行性（靜脈輸注乳劑 vs. 口服或眼科用途）。
- 若要優先投入資源，可先評估證據相對較多的方向：鋅用於呼吸道感染（需要支氣管炎專屬的研究），以及鋅補充對感染的影響。
