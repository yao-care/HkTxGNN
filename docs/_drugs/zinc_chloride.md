# Zinc Chloride：原適應症資料缺乏，預測新適應症為重度非增殖性糖尿病視網膜病變

## 一句話總結

Zinc Chloride（氯化鋅）目前缺乏原適應症與作用機轉資料，且尚未在香港上市。
TxGNN 模型預測它可能對**重度非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，屬純模型計算預測。

## 為什麼這個預測合理？

目前缺乏 Zinc Chloride 詳細的作用機轉（MOA）資料，也沒有記錄到的原始核准適應症，因此無法從既有臨床用途推論到新適應症的關聯性。

根據 TxGNN 提供的理論推論：視網膜及視網膜色素上皮層本身含有高濃度的鋅，鋅在生理上扮演抗氧化酵素（如 SOD）的輔因子角色。理論上，補充鋅可能有助於減緩氧化壓力相關的視網膜病變，這與糖尿病視網膜病變的部分病理機轉（氧化壓力損傷）有理論上的連結。

**需特別強調的是**：這個關聯目前僅來自 TxGNN 知識圖譜的計算預測分數，**沒有任何臨床試驗或文獻資料**佐證此假說，機轉外推的強度非常有限，屬於高度早期、探索性的假說。

## 結論與下一步

**決策：Hold**

**理由：**
此預測僅有 TxGNN 模型分數（99.34%）支持，屬 L5 證據等級（無實際研究佐證），且藥物本身缺乏作用機轉、原適應症與安全性資料，尚未具備進入下一階段評估的基礎。

**若要推進需要：**
- 補充 Zinc Chloride 的作用機轉（MOA）資料（DrugBank 查詢，對應 Data Gap DG002）
- 查證原廠仿單警語與禁忌症資料（對應 Data Gap DG001，Blocking 等級，需優先處理）
- 尋找糖尿病視網膜病變相關的臨床試驗或文獻，驗證機轉假說
- 確認此藥物是否具備可用於眼科給藥的劑型（現有 route_compatibility 資料為 pending，尚未確認）

**附註 — 其他候選適應症：**
本次證據包中另評估了 2 個候選適應症，證據強度略有差異，可作為後續研究參考：

- **Sjögren 氏症候群**：TxGNN 分數 99.18%，同樣為 L5（無臨床試驗或文獻），Hold。
- **乾眼症 (Dry Eye Syndrome)**：TxGNN 分數 99.18%，證據等級 **L3**，已有 2 個完成的臨床試驗（NCT02951910, Phase 4；NCT01541891, Phase 2），但受試藥物為鋅-玻尿酸複合鹽或 PRO-148 複方，非單純氯化鋅，屬間接支持證據，決策階段為 S1（Research Question）。此候選的證據強度明顯優於本報告聚焦之首選適應症，建議列為優先追蹤方向。
