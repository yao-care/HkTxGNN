# Zinc Oxide：從皮膚保護劑到痤瘡 (Acne)

## 一句話總結

Zinc Oxide（氧化鋅）目前並無正式登記的核准適應症資料，屬於長期廣泛使用於皮膚保護、防曬及爽身製劑的外用成分。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，
目前有 **0 個臨床試驗**登記，但有 **7 篇文獻**（含至少 1 篇系統性文獻回顧）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉（MOA）資料。根據文獻與既有藥理學常識，氧化鋅已知具有抗菌、抗發炎及調節皮脂分泌的特性，這也是其長期被用於各類外用皮膚製劑（防曬、皮膚保護劑、爽身粉）的原因之一。

痤瘡的病理機轉涉及皮脂腺分泌過多、毛囊發炎及痤瘡桿菌（*Cutibacterium acnes*）感染，這與氧化鋅已知的抗菌與抗發炎作用機轉在方向上相符。相關文獻也顯示氧化鋅奈米顆粒已被應用於痤瘡治療的新劑型開發（如微針貼片、抗菌塗層織物），顯示此一預測方向在臨床實務上已有初步探索基礎。

由於目前缺乏正式登記的原適應症與 MOA 資料，此預測的機轉關聯性仍需透過補齊 DrugBank 機轉資訊（見下方資料缺口 DG002）進一步確認。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有文獻層級證據（含 1 篇系統性文獻回顧與若干基礎/臨床研究），尚無直接針對氧化鋅治療痤瘡的臨床試驗，證據強度有限。
- 缺乏 TFDA/當地藥監機構之仿單警語與禁忌症資料，屬於 Blocking 等級資料缺口，無法進行安全性初評（S1）。
- 尚無作用機轉（MOA）正式資料，機轉關聯性分析尚未完整。
- 該藥物目前於香港未上市，無許可證可供銜接既有法規路徑。

**若要推進需要：**
- 補齊仿單警語/禁忌症資料（DG001，Blocking，建議自 TFDA 官網下載並解析仿單 PDF）
- 補齊作用機轉（MOA）資料（DG002，High，建議查詢 DrugBank API）
- 規劃或檢索是否已有氧化鋅外用製劑治療痤瘡的臨床試驗設計
- 確認在香港（或目標市場）申請上市或臨床試驗許可的可行路徑
