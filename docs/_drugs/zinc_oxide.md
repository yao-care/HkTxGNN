# 氧化鋅：從外用皮膚保護製劑到痤瘡

## 一句話總結

氧化鋅 (Zinc Oxide) 在香港以燒燙傷乳液、尿布疹軟膏、鋅膏等外用製劑上市（許可證未載明適應症，此用途是依品名推斷）。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，但目前**沒有任何臨床試驗**，僅有 **7 篇文獻**，且多為綜述或前臨床研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，氧化鋅是一種常見的外用鋅化合物，用於皮膚保護，機轉上可能適用於痤瘡。

鋅具有抗發炎與調節皮脂的作用，對痤瘡的致病菌 *Cutibacterium acnes* 也有一定抑制效果。前臨床研究顯示，氧化鋅奈米粒子與氧化鋅複合材料具有抗菌及活性氧（ROS）介導的作用。因此，從機轉推論，這個預測有其合理性。

需要注意的是，現有臨床文獻多半討論口服或其他鋅鹽，不能直接證明外用氧化鋅對痤瘡有效。另外，上述機轉評估僅依文獻標題判斷，尚未審閱摘要全文。TxGNN 的高分是模型預測，不是臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，文獻以綜述與前臨床研究為主，而且多數是其他鋅鹽的資料，無法直接支持外用氧化鋅治療痤瘡。
- 香港衛生署仿單的警語與禁忌資料尚未取得，無法進入安全性篩選。
- 另外 4 個預測（肛門直腸狹窄、肛門息肉、乳突性結膜炎、感染後血管炎）僅有模型預測，沒有試驗或文獻，也找不到明確的機轉關聯，均屬 L5 / Hold。

**若要推進需要：**
- 取得香港衛生署的仿單，補齊警語與禁忌資料。
- 補充作用機轉（MOA）資料，可查詢 DrugBank。
- 審閱上述文獻的摘要全文，確認 PMID 15536660 的介入是否為氧化鋅。
- 檢索外用氧化鋅治療痤瘡的對照臨床試驗，必要時規劃早期臨床研究。
