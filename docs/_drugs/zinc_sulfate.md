# Zinc Sulfate：從（原適應症資料缺漏）到咽炎

## 一句話總結

Zinc Sulfate（硫酸鋅）在香港以眼藥水、靜脈營養輸液等產品上市，但資料中沒有登記原適應症。
TxGNN 模型預測它可能對**咽炎 (Pharyngitis)** 有效，
目前有 **4 個臨床試驗**和 **3 篇文獻**與此方向相關，但多為間接證據，沒有直接證明對咽炎有效的研究。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，硫酸鋅是多種產品（眼用製劑、靜脈營養輸液）的成分之一，但香港許可證並未登記明確的適應症，因此無法從原適應症推導與咽炎的關聯。

鋅在一般生物學上具有免疫調節、潛在抗病毒及黏膜保護作用，因此推測可能有助於咽部黏膜的症狀。不過這是根據鋅的一般特性推論，並非來自本次提供的資料。

目前最直接相關的試驗是鋅口含錠用於術後喉嚨痛，但術後喉嚨痛屬插管造成的機械性刺激，不同於感染性咽炎，只能算間接支持。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 分數很高，但沒有任何研究直接證明硫酸鋅對咽炎有效。現有試驗多為 COVID-19 或術後喉嚨痛，屬間接證據。此外，香港許可證缺乏適應症與安全性資料，原作用機轉也不明，目前只適合作為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單，補齊警語、禁忌症與適應症資料（目前為阻斷性缺口）
- 補充 DrugBank 的作用機轉資料
- 設計直接針對感染性咽炎的隨機對照試驗
- 確認劑型與給藥途徑是否適用於咽部（如口含錠、漱口水），因現有香港產品為眼用與靜脈輸液，與咽炎用途不符
