# Zinc Sulfate：原適應症未載明，預測新適應症為咽炎

## 一句話總結

> Evidence Pack 中未記載 Zinc Sulfate（硫酸鋅）目前核准的原始適應症資料。
> TxGNN 模型預測它可能對**咽炎 (Pharyngitis)** 有效，
> 目前有 **4 個臨床試驗**和 **3 篇文獻**支持這個方向，但多數試驗實際上是針對 COVID-19 設計，僅 1 項直接測試咽喉痛療效。

## 為什麼這個預測合理？

目前缺乏 Zinc Sulfate 詳細的作用機轉資料，且 Evidence Pack 中也未記錄其原始核准適應症，因此無法直接比較新舊適應症之間的臨床關聯性。

根據現有的機轉推論，鋅離子具有黏膜抗發炎、促進傷口癒合，以及抑制鼻病毒複製的抗病毒作用，理論上有可能縮短喉嚨痛/咽炎相關病程。然而，這組證據中大多數臨床試驗實際上是以 COVID-19 為研究目標（鋅僅為合併治療或預防措施之一），TxGNN 的疾病標籤與試驗實際適應症不完全吻合，機轉上的關聯性主要來自單一直接相關的研究——術前口服鋅錠劑對降低插管術後喉嚨痛的隨機對照試驗。

整體而言，鋅對咽炎的潛在療效有一定生物學合理性，但實證強度仍偏薄弱，需要更多針對咽炎本身（而非以鋅為輔助介入的 COVID-19 研究）設計的臨床試驗來驗證。

## 安全性考量

安全性資訊請參考原廠仿單。

> 補充說明：Evidence Pack 標記「TFDA 仿單警語/禁忌」為 **Blocking 級資料缺口**，導致目前**無法進入 S1 安全性初評階段**。在取得完整的仿單警語、禁忌症與藥物交互作用資料前，不應對此候選適應症做出安全性相關結論。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖然咽炎的證據等級達 L2，但相關臨床試驗中僅 1 項（NCT02405832）直接針對喉嚨痛/咽炎，其餘 3 項試驗實際上是以 COVID-19 為研究目的，證據的疾病特異性偏弱。
- 安全性初評因缺乏 TFDA 仿單警語/禁忌症資料而被列為 Blocking 缺口，在此資料補齊前無法進行下一階段評估。

**若要推進需要：**
- 取得 Zinc Sulfate 的 TFDA/香港藥品仿單警語與禁忌症資料，以完成 S1 安全性初評（Blocking，優先處理）
- 透過 DrugBank API 或其他來源補充詳細作用機轉 (MOA) 資料
- 確認硫酸鋅是否已在香港申請上市或取得許可證
- 規劃專門針對急性咽炎（而非以鋅為輔助介入的 COVID-19 研究）設計的隨機對照試驗，以驗證療效外推性
