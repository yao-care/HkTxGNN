# Ziprasidone：從躁鬱症與思覺失調症到重度情感疾患（Major Affective Disorder）

## 一句話總結

Ziprasidone 是非典型抗精神病藥物，原本用於治療躁期雙相情感障礙、雙相情感障礙與思覺失調症。
TxGNN 模型的最高分預測為 trichotillomania，但該預測沒有任何臨床資料；證據最完整的方向是**重度情感疾患 (Major Affective Disorder)**，目前有 **7 個臨床試驗**和 **20 篇文獻**支持這個方向。

> 註：TxGNN 排名第 1 的 trichotillomania 與排名第 2 的 hydranencephaly 皆無臨床試驗或文獻。本報告以證據最完整的重度情感疾患為主軸，並於文末補充 Tourette 症候群。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知的藥理資訊，Ziprasidone 具有 5-HT2A/D2 拮抗、5-HT1A 促效，以及血清素/正腎上腺素再回收抑制作用，這些特性支持抗憂鬱與情緒穩定的活性。

原適應症（雙相情感障礙）與重度憂鬱同屬情緒疾患。躁鬱症本身已是核准適應症，因此真正待釐清的問題集中在單極性憂鬱的輔助治療、憂鬱混合狀態及精神病性憂鬱。

已有數個 Phase 2 隨機對照試驗，以及多篇增強治療策略的系統性回顧與網絡統合分析支持此方向。不過，已發表的回顧指出，Ziprasidone 輔助治療重度憂鬱的證據結果不一，且不如其他輔助用非典型抗精神病藥物穩固。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**：長 QT 症候群（含家族性）、尖端扭轉型心室頻脈、心臟傳導疾病、心肌梗塞、猝死性心臟驟停、姿勢性低血壓、癲癇、肝衰竭、腎臟疾病、嗜中性白血球低下、顆粒性白血球缺乏症、糖尿病與酮酸中毒、高血糖、高血脂、肥胖、低鉀血症等。（此為知識圖譜關聯，並非仿單原文。）
- **藥物交互作用**：資料庫共記錄 100 筆，列出的重要項目包括：
  - 嚴重（Major）：Hydrocortisone、Amphotericin B（含脂質複合物）、Bupropion、Morphine
  - 中度（Moderate）：Acarbose、Famotidine、Epinephrine、Metformin、Pioglitazone、Atropine 等
- **心臟安全**：對 Tourette 方向的文獻指出，兒童與青少年的 QT 延長是需特別注意的風險（PMID 39549076）。

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**（針對重度情感疾患方向）

**理由：**
- 有 4 個已完成的 Phase 2 或 Phase 2/3 試驗（含雙盲安慰劑對照），並有多篇系統性回顧支持，證據等級為 L2。但沒有 Phase 3 隨機對照試驗確認療效，且已發表回顧認為證據不一致，故需設定保護條件後再推進。
- 其餘預測（trichotillomania、hydranencephaly 等）僅有模型分數，建議暫緩（Hold）。Tourette 症候群證據有限，且有心臟安全疑慮，建議列為研究問題。

**若要推進需要：**
- 取得香港衛生署仿單的警語與禁忌資料（目前缺口，屬阻斷性）
- 補充作用機轉資料（如 DrugBank）
- 規劃 Phase 3 隨機對照試驗，釐清輔助治療的實際效益
- 建立 QT 間期與心電圖監測計畫，並檢視與 QT 延長藥物的交互作用
- 評估代謝與血糖風險，以及併用藥物（如 Bupropion、Morphine）的管理
